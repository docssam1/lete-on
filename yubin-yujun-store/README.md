# 유빈유준 편의점

집의 5칸 과자 수납장을 휴대폰으로 관리하는 GitHub Pages 앱입니다.

## 현재 기능

- 1층(맨 위)부터 5층(맨 아래)까지 위치별 관리
- 포장 앞면 사진과 유통기한 면 사진 등록
- 브라우저 안에서 OCR로 과자 이름·종류·날짜 초안 인식
- 유통기한 남은 일수 계산 및 빨리 먹을 과자 우선 표시
- 쿠키·사탕·초콜릿·스낵·젤리·기타 분류
- 현재 개수, 처음 산 개수, 봉지의 남은 양 기록
- 절반 이하 표시와 `1개 먹음` 빠른 기록
- 층 전체 사진 저장
- JSON 백업과 복원
- IndexedDB에 사진, localStorage에 재고 저장

## 인식 범위와 주의

정적 GitHub Pages에서 API 키를 노출하지 않기 위해 Tesseract.js OCR을 기기 안에서 실행합니다. 날짜와 포장 글자를 자동으로 채우지만, 흐린 인쇄·곡면 포장·한글 장식 글씨는 틀릴 수 있으므로 저장 전에 반드시 확인합니다. 사진 속 여러 과자의 개수를 정확히 세는 기능은 별도의 비전 서버가 필요하므로 현재 개수는 사용자가 확인해 입력합니다.

## 데이터 저장

데이터는 해당 브라우저/기기에만 저장됩니다. 다른 휴대폰과 자동 동기화하려면 Supabase 또는 Firebase 같은 로그인형 데이터베이스 연결이 필요합니다.
