# 유빈유준 편의점 v0.1 작업 내용

- 수납장 방향을 `맨 위 5층 / 맨 아래 1층`으로 고정
- 기존 v1 로컬 데이터가 있으면 원본 스냅샷을 먼저 저장한 뒤 층 번호를 한 번만 반전
- 오늘 정리한 재고 23종을 기본 복구 목록으로 내장
- 기존 로컬 데이터가 있으면 덮어쓰지 않고 빠진 품목만 합침
- 사진·OCR·검색·수정·삭제·수량 차감·백업/복원 기능 유지
- 실제 5단 수납장처럼 보이는 모바일 UI 적용
- 위치나 제품명이 불확실한 항목은 삭제하지 않고 `확인 필요` 영역에 유지
