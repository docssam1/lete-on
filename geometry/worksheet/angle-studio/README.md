# 각도 탐구 학습지

Angle Studio 공통 문항 API를 사용하는 한국어 인쇄 학습지입니다. 기존 학습지, 게임, 로비는 수정하지 않습니다.

## 현재 연결

- `../../games/angle-studio/core.js?v=angle-1`: 활동 목록, 문항, 지문, 힌트, 풀이, 답, 작도 검증.
- `../../games/angle-studio/render.js?v=angle-1`: 학생용·답안용 그림.
- `../../games/shape-transform/ui-icons.js?v=shape-transform-5`: 뒤로 가기·새 문제 아이콘.
- `../shape-transform/icons/printer.svg`: 기존 Lucide 인쇄 아이콘. 라이선스는 같은 폴더의 `LICENSE`에 있습니다.

활동 선택지는 `domains` 배열에서만 생성합니다. 현재 연결된 활동은 각도 어림하기, 점판에서 직각 만들기, 다각형의 각도, 평행선과 각입니다. 평행선은 메인 담당자의 원본 확인과 API 활성화 후 연결했습니다. 파일이 있더라도 학습지 자체에서 활동을 추가하지 않습니다. 비공개 원본과 원본 경로는 이 폴더에 포함하지 않습니다.

공통 API가 누락되거나 문항·답·그림 검증에 실패하면 학습지와 인쇄를 차단하고 다시 불러오기를 제공합니다. 준비되지 않은 활동 주소를 다른 활동으로 조용히 바꾸지 않습니다.

## 선택과 출력

- 기본 주소 및 `?domain=all`: 전체 20문항. 현재 4개 활동에서 각각 5문항을 선택합니다. API가 세 활동만 제공할 때는 7·7·6문항으로 구성됩니다.
- `?domain=estimate`, `?domain=right-angle`, `?domain=polygon`, `?domain=parallel`: 해당 활동 10문항.
- `?level=1..4`, `?level=all`도 지원합니다. 활동 번호는 API에서 확인합니다.
- `?count=1..20` 지원. 수량 입력은 1~20 범위로 조정하며 활동을 바꾸지 않습니다.
- 표지·정답·풀이 전환과 인쇄는 선택된 문항의 값과 순서를 유지합니다. 새 문제, 활동 변경, 수량 변경은 새 구성을 만듭니다.
- 새 문제는 같은 순열의 다른 구간을 사용합니다. 한 학습지에는 같은 문항이 두 번 나오지 않습니다. 한 활동에서 10문항 이하를 고르면 다음 구성과도 겹치지 않습니다. 20문항을 모두 선택한 경우에는 새로운 원문을 만들지 않고 순서만 바뀝니다.
- 다각형은 API의 `kind`를 기준으로 삼각형 분할·내각의 합·빠진 각·정다각형을 고르게 선택합니다. 선택 집합은 유지한 채 이 학습 순서로 정렬하며, 같은 유형 안에서는 선택된 순서를 유지합니다. 따라서 전체 20문항에서도 새 문제로 유형 안의 순서를 바꿀 수 있습니다. 원문 지문, 수치, 좌표는 변경하지 않습니다.
- A4 210×297mm, 활동별 독립 쪽 나누기. 일반 문항은 최대 3문항, 점판 작도는 최대 2문항입니다. 점판의 실제 점 간 전체 폭은 출력에서 약 60.7mm입니다.
- 표지·문제·답안 모두 GFIELD 워터마크를 유지합니다. 정답·풀이는 같은 페이지 구성에서 문제 버전을 대체하며, 표지 유무는 별도 선택입니다.
- 각도 어림하기는 어림값·실제 각도·차이 기록칸을 제공합니다. 학생용에는 90° 기준만 표시하고 목표 각도나 정오 판정을 노출하지 않습니다.
- 점판은 OA만 주고 OB를 직접 그립니다. 답안은 허용된 점 하나로 만든 `예시 답안`이며 다른 올바른 작도도 답임을 명시합니다.
- 다각형의 작도 지문은 수동 작도로 유지합니다. 학생 그림에 정답용 분할선을 미리 표시하지 않습니다. `count`는 개, `degree`는 °로 구분합니다.
- 평행선 위치 답은 `unit: count`, `responseKind: angle-label`일 때 빈칸과 정답 모두 `번`을 사용합니다. 일반 개수 문항과 혼동하지 않습니다.

## 검증

저장소 루트에서 실행합니다. Node와 패키지는 설치된 환경 또는 Codex 번들 런타임을 사용할 수 있습니다. 브라우저 검사는 `playwright`, `pdf-lib`가 필요하며 번들 패키지 경로를 `NODE_PATH`에 지정합니다.

```powershell
node geometry/worksheet/angle-studio/workbook.selftest.mjs
$env:GFIELD_BASE_URL = "http://127.0.0.1:8765"
node geometry/worksheet/angle-studio/workbook.browsercheck.mjs
```

공통 API가 작성 중일 때 선택 로직만 검사하려면 `workbook.selftest.mjs --model-only`를 사용합니다. 이 옵션은 실제 문항 검증을 대신하지 않습니다.

2026-09-08 로컬 검증 결과:

- 선택 4,000건, 실제 80문항 연결, 직각의 유효한 점 72개 통과. 점판 전체 점의 내적을 별도로 계산해 복수 답안과 검증 함수를 대조했습니다. 평행선 20문항의 위치 답·각도 값·평행 조건도 별도 확인했습니다.
- 화면 폭 1280·768·390px, 학생용·답안용 781개 문항 배치 검사 통과. 가로 넘침, 문항·풀이 영역 겹침, 페이지 넘침, 워터마크 누락 없음.
- 40개 SVG 픽셀 검사와 실제 어림각의 두 변 사이 각도 검사 통과. 두 축의 배율이 같은지 검사했습니다.
- 문항 수 1~20, 수량 제한, 주소의 활동·단계, 표지·답안 전환의 선택 유지, 새 문제와 다음 구성의 중복 방지, 다각형 학습 순서, 키보드 초점, 인쇄 호출, 누락 API·미등록 활동의 차단 검증 통과.
- 실제 PDF 7개: 전체20 학생용·답안용 각 10쪽, 표지 없는 두 버전 각 9쪽, 점판10 학생용·답안용 각 6쪽, 한 문항 표지 없음 1쪽.
- 화면 PNG 19개와 최신 전체20 학생용·답안용 PDF의 렌더 PNG 20개를 생성했습니다. 표지, 어림각, 점판, 다각형, 평행선과 답안을 시각 확인했습니다. Poppler의 Type 3 글꼴 경계 경고가 있었으나 확인한 페이지에 글자 누락이나 잘림은 없었습니다.
