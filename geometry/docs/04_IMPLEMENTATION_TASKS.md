# 낮은 단계 Codex용 작업 순서

이 문서는 한 번에 하나씩 맡길 수 있는 작업 단위다. 앞 작업이 완료되기 전에는 다음 작업을 시작하지 않는다.

## 작업 1. 현재 원형 안정화

범위: 현재 `index.html`, `app.js`, `styles.css`

- 한국어, 중국어, 일본어, 영어가 깨지지 않는지 확인한다.
- 똑같이 쌓기 레벨 1~3의 기존 동작만 유지한다.
- 드래그, 다른 자리 이동, 더미에 놓아 제거, 자동 성공, 다음 문제를 검사한다.
- 기능과 무관한 디자인 변경은 하지 않는다.

완료: 데스크톱과 모바일에서 레벨 1의 5문제를 연속으로 풀 수 있다.

## 작업 2. 공통 파일 분리

범위: `shared` 폴더 생성

- Three.js 장면 생성, 블록 재질, 번역, 진행 저장을 각각 분리한다.
- 현재 화면과 동작이 바뀌지 않게 한다.

완료: 원형 게임이 공통 모듈을 불러와 이전과 동일하게 동작한다.

## 작업 3. 똑같이 쌓기 독립 게임

범위: `games/copy-build`

- 독립 `index.html`, `app.js`, `styles.css`, `levels.js`, `i18n.js`를 만든다.
- 레벨 1~3을 레벨당 5문제로 옮긴다.

완료: 이 폴더의 화면만 열어도 게임을 처음부터 끝까지 할 수 있다.

## 작업 4. 완성 뒤 개수 세기

범위: `games/copy-build`

- 상태를 `build -> estimate -> count -> result`로 나눈다.
- 숫자 예상 입력과 블록을 하나씩 떨어뜨리는 세기 단계를 만든다.
- 완성 직후 확인 버튼 없이 성공 연출이 시작되게 한다.

완료: 5문제 모두 쌓기와 세기를 마쳐야 다음 문제로 간다.

## 작업 5. 직육면체와 다른 조각

범위: `games/copy-build` 레벨 4~5

- 크기, 방향, 차지한 단위 칸 계산 함수를 먼저 만든다.
- 조각 충돌과 공중 배치를 막는다.
- `exactPieces`와 `occupiedCells` 판정을 각각 만든다.

완료: 레벨 4와 5가 각각 5문제이며 서로 다른 판정 규칙을 통과한다.

## 작업 6. 주제 모양과 색

범위: `games/copy-build` 레벨 6

- 성, 동물, 집, 로켓 등 5문제를 직접 작성한다.
- 다섯 색 견본과 색 정답 판정을 추가한다.

완료: 위치와 조각이 맞아도 색이 틀리면 성공하지 않는다.

## 작업 7. 높이로 개수 세기

범위: `games/count-heights`

- 높이 배열로 3D 모양과 위에서 본 표를 만든다.
- 두 입력 화면이 같은 답 상태를 공유하게 한다.
- 전체 합 자동 채점을 만든다.

완료: 레벨 1~5, 총 25문제를 마우스와 터치로 풀 수 있다.

## 작업 8. 벽 없는 숨은 쌓기나무

범위: `games/count-hidden` 레벨 1~3

- 보이는 블록 계산기와 문제 검사기를 만든다.
- 블록 ID 기반 탭 세기와 식 입력을 만든다.

완료: 레벨 1~3의 저장 정답과 계산 정답이 모두 일치한다.

## 작업 9. 벽 있는 숨은 쌓기나무

범위: `games/count-hidden` 레벨 4~6

- 한쪽 벽과 두 벽 장면을 만든다.
- 카메라가 벽 뒤로 넘어가지 않게 한다.
- 반투명 힌트와 정답 공개를 만든다.

완료: 벽 방향을 제외한 보임 계산과 화면 결과가 일치한다.

## 작업 10. 마무리 검사

범위: 두 게임, 세 독립 실행 모듈 전체

- 네 언어의 빠진 문장과 잘린 버튼을 검사한다.
- 모든 음성을 로컬 MP3로 연결한다.
- 작은 휴대폰, 태블릿, 데스크톱에서 겹침을 검사한다.
- 콘솔 오류, 빈 3D 화면, 잘못된 문제 데이터를 검사한다.
- 각 게임의 레벨 진행과 별 저장을 검사한다.

완료: 세 개발 모듈을 각각 단독 실행할 수 있고, 통합 화면에서는 두 게임으로 보이도록 게임 ID와 시작 주소가 정리되어 있다.
