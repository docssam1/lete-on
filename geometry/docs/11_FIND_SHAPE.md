# 11. 단서로 모양 찾기

층별 쌓기나무 수와 앞·오른쪽에서 본 모양을 함께 읽고, 모든 단서를 만족하는 입체를 고르는 선택형 게임이다.

## 레벨

- 레벨 3: 최대 2층, 보기 3개
- 레벨 4: 최대 3층, 보기 4개
- 레벨 5: 최대 4×4×4, 보기 4개
- 각 레벨은 10문제 문제은행에서 한 회차당 5문제를 출제한다.

## 문항 원칙

- 같은 문항의 모든 보기는 층별 쌓기나무 수가 같다.
- 앞과 오른쪽에서 본 모양을 함께 비교해야 정답이 결정된다.
- 보기의 바닥 모양은 상하좌우로 연결되며 공중에 뜬 블록은 없다.
- 정답 단서와 일치하는 보기는 정확히 하나인지 시작 시 자동 검증한다.
- 전체 크기는 4×4×4를 넘지 않는다.

## 학습 흐름

1. 층별 쌓기나무 수를 확인한다.
2. 앞에서 본 높이를 확인한다.
3. 오른쪽에서 본 높이를 확인한다.
4. 모든 단서를 만족하는 모양을 선택하고 확인한다.

첫 진입에만 큐비가 세 단계로 방법을 안내한다. 오답은 맞지 않는 방향 단서만 옅게 빛나며, 정답일 때는 성공 연출과 포인트를 제공한다.
