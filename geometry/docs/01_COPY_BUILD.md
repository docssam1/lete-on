# 게임 1: 쌓기나무 똑같이 쌓기

## 1. 학습 목표

- 입체 모양의 위치와 높이를 관찰한다.
- 같은 모양을 직접 구성한다.
- 완성한 모양에 사용된 블록 수를 센다.
- 높은 레벨에서는 직육면체의 방향, 다른 조각의 조합, 색까지 관찰한다.

## 2. 한 문제의 흐름

```text
문제 관찰 -> 더미에서 블록 가져오기 -> 빨간 자리에 놓기
-> 자동 완성 판정 -> 성공 연출 -> 개수 예상하기
-> 하나씩 눌러 떨어뜨리며 세기 -> 다음 문제
```

완성 직후 바로 다음 문제로 넘어가지 않는다. 성공 연출 뒤 같은 문제의 `몇 개일까?` 단계가 열린다.

### 개수 세기 단계

1. 아이가 먼저 예상 개수를 숫자판으로 입력한다.
2. `하나씩 세기`를 누르면 블록을 탭할 수 있다.
3. 현재 꺼낼 수 있는 블록을 누르면 바닥으로 떨어지고 수가 `1, 2, 3...` 올라간다.
4. 직육면체 문제는 문제에 따라 `블록 조각 수` 또는 `단위 쌓기나무 수`를 센다.
5. 모두 세면 예상한 값과 실제 값을 함께 보여 준다.

## 3. 레벨 구성

모든 레벨은 5문제다. 레벨 6에서만 색을 정답 조건으로 사용한다.

| 레벨 | 판과 높이 | 사용하는 조각 | 문제 특징 | 채점 기준 |
|---|---|---|---|---|
| 1 | 최대 2x2x2 | 단위 정육면체 | 한 층 또는 2층, 3~5개 | 차지한 칸 |
| 2 | 최대 3x3x2 | 단위 정육면체 | 계단, ㄱ자, 대칭, 5~8개 | 차지한 칸 |
| 3 | 최대 3x3x4 | 단위 정육면체 | 가려진 받침 추론, 회전 관찰, 7~12개 | 차지한 칸 |
| 4 | 최대 3x3x4 | 정육면체와 직육면체 | 조각의 방향까지 똑같이 놓기 | 조각 종류, 위치, 방향 |
| 5 | 최대 3x3x4 | 여러 크기의 조각 | 다른 조각 조합으로 같은 부피 채우기 | 최종 단위 칸 점유 |
| 6 | 최대 3x3x4 | 여러 조각과 색 | 성, 동물, 집, 로켓 등 주제 모양 | 조각, 위치, 방향, 색 |

### 레벨 4 조각 종류

- 정육면체 `1x1x1`
- 세로 블록 `1x2x1`
- 가로 블록 `2x1x1`
- 긴 블록 `3x1x1`
- 넓은 블록 `2x1x2`

처음에는 위 다섯 종류만 사용한다. 아치, 원기둥, 지붕 조각은 별도 확장 단계에서 추가한다. 조각마다 잡는 면과 놓기 미리보기를 충분히 크게 만든다.

### 레벨 5의 핵심

문제 모양과 아이가 쓴 조각 구성이 달라도 최종적으로 차지한 단위 칸이 같으면 정답이다. 예를 들어 `1x2x1` 직육면체 하나 대신 정육면체 두 개를 사용해도 된다.

### 레벨 6 주제 모양

- 작은 성문
- 강아지 또는 고양이의 단순한 몸체
- 로켓
- 집
- 의자 또는 자동차

동물 모양은 눈이나 얼굴 그림으로만 동물처럼 보이게 하지 않는다. 블록의 몸통, 다리, 머리 배치만으로 실루엣이 읽히게 만들고 작은 얼굴 장식은 보조로만 쓴다.

## 4. 놀이판 조작

- 더미의 조각을 누른 채 3D 판으로 끌어온다.
- 놓을 수 있는 정확한 칸은 빨간 반투명 조각으로 미리 보인다.
- 놓을 수 없으면 빨간 표시를 숨기고 손을 놓아도 원래 자리로 돌아간다.
- 판에 놓인 조각도 다시 잡아 다른 자리로 옮길 수 있다.
- 조각을 더미 영역에 놓으면 제거된다.
- 직육면체는 잡고 있는 동안 작은 회전 버튼 또는 두 손가락 회전으로 90도 돌린다.
- 카메라 회전과 블록 이동을 구분한다. 빈 바닥을 드래그하면 카메라, 블록을 길게 누르면 블록 이동이다.

## 5. 정답 판정 모드

문제마다 아래 둘 중 하나를 지정한다.

```js
rules: {
  matchMode: "exactPieces" // 또는 "occupiedCells"
}
```

- `exactPieces`: 조각 종류, 크기, 위치, 방향을 비교한다.
- `occupiedCells`: 각 단위 칸이 채워졌는지만 비교한다.
- 레벨 6은 여기에 색 비교를 추가한다.

```js
rules: {
  matchMode: "exactPieces",
  matchColor: true,
  countUnit: "pieces" // 또는 "unitCells"
}
```

## 6. 색 규칙

색은 레벨 6에서만 사용한다.

- 파랑, 노랑, 초록, 빨강, 주황의 다섯 색만 사용한다.
- 색만으로 위치를 구분하지 않는다. 모양과 명암도 함께 보여 준다.
- 더미에서 조각 종류를 먼저 고르고 색을 고른다.
- 색 선택은 작은 글자 버튼이 아니라 실제 색 견본으로 표시한다.

## 9. 완료 조건

- 6개 레벨이 각각 5문제를 가진다.
- 레벨 1~3은 현재 정육면체 드래그 기능으로 완주할 수 있다.
- 레벨 4에서 모든 직육면체 방향과 충돌을 올바르게 판정한다.
- 레벨 5에서 서로 다른 조각 조합도 같은 점유 칸이면 성공한다.
- 레벨 6에서 위치는 같아도 색이 다르면 아직 성공하지 않는다.
- 완성 후 개수 예상과 하나씩 떨어뜨려 세기가 모든 레벨에서 동작한다.
- 마우스와 터치에서 카메라 회전과 블록 이동이 섞이지 않는다.
- 성공하면 확인 버튼 없이 바로 연출과 다음 단계가 시작된다.
