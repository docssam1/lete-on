# 게임 1: 쌓기나무 똑같이 쌓기

## 1. 학습 목표

- 입체 모양의 위치와 높이를 관찰한다.
- 같은 모양을 직접 구성한다.
- 색이 있는 문제에서는 각 블록의 색 위치까지 관찰한다.
- 높은 레벨에서는 직육면체의 방향과 여러 입체 조각의 조합을 활용한다.

## 2. 한 문제의 흐름

```text
문제 관찰 -> 더미에서 블록 가져오기 -> 빨간 자리에 놓기
-> 자동 완성 판정 -> 성공 연출 -> 다음 문제
```

`똑같이 쌓기`에서는 모양과 색을 그대로 만드는 데 집중한다. 하나씩 없애며 세는 활동은 `쌓기나무 개수 세기` 게임에서 다룬다.

## 3. 레벨 구성

레벨 1~3은 원목 5문제와 같은 난이도의 컬러 5문제를 합쳐 각 10문제다. 컬러 문제에 가려진 블록이 있으면 더미에 색별 전체 개수를 제시한다.

| 레벨 | 판과 높이 | 사용하는 조각 | 문제 특징 | 채점 기준 |
|---|---|---|---|---|
| 1 | 최대 3x3x2 | 단위 정육면체 | 낮은 원목 5 + 컬러 위치 맞추기 5 | 위치, 높이, 컬러 문제의 색 |
| 2 | 최대 3x3x3 | 단위 정육면체 | 계단, ㄱ자, 대칭 원목 5 + 컬러 5 | 위치, 높이, 컬러 문제의 색 |
| 3 | 최대 4x4x4 | 단위 정육면체 | 큰 원목 구조와 가려진 블록이 있는 컬러 구조 | 위치, 높이, 색, 주어진 색별 개수 |
| 4 | 최대 4x4x4 | 직육면체 | 눕힘, 세움, 90도 회전을 똑같이 놓기 | 조각 종류, 위치, 방향 |
| 5 | 최대 4x4x4 | 정육면체, 직육면체, 삼각기둥, 각뿔·원뿔 | 성, 동물, 집, 다리 등 활용 모양과 자유 창작 | 미션 조건 또는 작품 완성 |

### 레벨 4 조각 종류

- 세로 블록 `1x2x1`
- 가로 블록 `2x1x1`
- 긴 블록 `3x1x1`
- 넓은 블록 `2x1x2`

직육면체마다 잡는 면과 놓기 미리보기를 충분히 크게 만든다.

### 레벨 5의 핵심

레벨 5는 앞 단계의 쌓기 규칙을 여러 입체로 확장하는 활용 단계다.

- 작은 성문
- 강아지 또는 고양이의 단순한 몸체
- 로켓과 탑
- 집
- 다리, 의자 또는 자동차

동물 모양은 눈이나 얼굴 그림으로만 동물처럼 보이게 하지 않는다. 블록의 몸통, 다리, 머리 배치만으로 실루엣이 읽히게 만들고 작은 얼굴 장식은 보조로만 쓴다.

미션을 마친 뒤 작품을 원하는 각도로 돌려 PNG로 캡처하거나 모바일 공유 메뉴로 보낼 수 있다.

## 4. 놀이판 조작

- 더미의 조각을 누른 채 3D 판으로 끌어온다.
- 놓을 수 있는 정확한 칸은 빨간 반투명 조각으로 미리 보인다.
- 놓을 수 없으면 빨간 표시를 숨기고 손을 놓아도 원래 자리로 돌아간다.
- 판에 놓인 조각도 다시 잡아 다른 자리로 옮길 수 있다.
- 조각을 더미 영역에 놓으면 제거된다.
- 직육면체는 잡고 있는 동안 작은 회전 버튼 또는 두 손가락 회전으로 90도 돌린다.
- 카메라 회전과 블록 이동을 구분한다. 빈 바닥을 드래그하면 카메라, 블록을 길게 누르면 블록 이동이다.

## 5. 정답 판정 모드

레벨 1~4 문제마다 아래 판정 방식을 지정한다.

```js
rules: {
  matchMode: "exactPieces" // 또는 "occupiedCells"
}
```

- `exactPieces`: 조각 종류, 크기, 위치, 방향을 비교한다.
- `occupiedCells`: 각 단위 칸이 채워졌는지만 비교한다.
- 레벨 1~3의 컬러 문제는 여기에 색 비교를 추가한다.

```js
rules: {
  matchMode: "exactPieces",
  matchColor: true,
  countUnit: "pieces" // 또는 "unitCells"
}
```

## 6. 색 규칙

색은 레벨 1~3의 뒤쪽 5문제에서 사용한다.

- 파랑, 노랑, 초록, 빨강, 주황의 다섯 색만 사용한다.
- 색만으로 위치를 구분하지 않는다. 모양과 명암도 함께 보여 준다.
- 더미에는 목표에 필요한 색과 남은 개수를 정확히 표시한다.
- 가려진 블록이 있는 문제에서는 색별 전체 개수가 추론 조건이 된다.
- 색 선택은 작은 글자 버튼이 아니라 실제 색 견본으로 표시한다.

## 9. 완료 조건

- 레벨 1~3은 원목 5문제와 컬러 5문제를 각각 가진다.
- 레벨 1~3의 컬러 문제는 색 위치와 색별 재료 수를 함께 판정한다.
- 레벨 4에서 모든 직육면체 방향과 충돌을 올바르게 판정한다.
- 레벨 5에서 정육면체, 직육면체, 삼각기둥, 각뿔·원뿔을 이용해 미션과 자유 창작을 할 수 있다.
- 레벨 5 작품을 원하는 시점으로 캡처하고 저장 또는 공유할 수 있다.
- 마우스와 터치에서 카메라 회전과 블록 이동이 섞이지 않는다.
- 성공하면 확인 버튼 없이 영어 3D 성공 연출이 시작된다.
