# 주사위 자료 분류와 이동 표현 계약

## 자료 해석 경계

- 첨부 교재 이미지는 유형과 시각 표현을 확인하는 비공개 근거다.
- 원본 판면을 복제하지 않고 같은 수학 개념을 내부 데이터와 도형으로 다시 구성한다.
- 전개도 지시문은 사용자 작업 지시가 아니라 문제 유형의 근거로만 읽는다.

## 난이도 기준

- 전개도에서 마주 보는 면 찾기: `입문`, `초급`.
- 점뿐 아니라 색, 단순한 그림, 기호를 면 표식으로 사용할 수 있다.
- 화살표와 글자 방향까지 추적하는 문제는 단순 그림 표식과 분리한다.
- 굴리기, 보이지 않는 면의 합, 맞닿는 면 조건, 겉면의 합과 최댓값·최솟값은 `초급`, `중급`으로 구성한다.

## 굴리기 장면 계약

- 큰 전체 격자 대신 실제 경로에 놓인 작은 연결 발판만 표시한다.
- 주사위 한 변은 `1`, 발판 한 변은 `1.08`로 두어 발판이 조금 더 크게 보이게 한다.
- 다음 발판의 중심 간격은 주사위 한 변과 같은 `1`이다.
- 한 칸 이동은 바닥에 닿은 모서리를 축으로 한 정확한 90도 회전이다. 위치 보간이나 점프를 사용하지 않는다.
- 굴리는 동안 입력을 잠그고, 회전이 끝난 뒤 문제의 논리 자세와 3D 자세를 함께 확정한다.
- 나무결, 광택, 세 면의 눈, 접촉 그림자를 유지한다.
- `prefers-reduced-motion`에서는 같은 최종 자세로 즉시 이동한다.
- 납작 주사위의 다섯 영역과 면별 공개 기능은 별도 학습 보기로 유지한다.

## 자동 검증

- 24가지 주사위 자세에서 논리 면과 3D 면 법선이 모두 일치해야 한다.
- 5단계 50문항의 정답과 역방향 경로 유일성을 기존 독립 검사로 유지한다.
- 브라우저 검사는 발판/주사위 비율, 굴림 중 입력 잠금, 한 칸 뒤 윗면 변화, 캔버스 픽셀 분산, 모바일 넘침을 확인한다.
- 학습지는 동일한 문제 데이터를 사용하고 A4 한 페이지 출력 범위를 지킨다.
