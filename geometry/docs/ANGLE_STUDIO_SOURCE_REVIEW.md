## 확인 범위

- 1과정: 기존 1~10권 원본 대조표와 현재 Geometry의 실제 활동 목록을 비교했다. 3권 7·10~12쪽, 6권 46~47쪽은 이번에 수업용 원본 화면도 직접 확인했다.
- 2과정: G1~G5 목차와 아래 표의 대표 페이지 원본 화면을 확인했다. 교사용 지도서의 인쇄 쪽수와 PDF 페이지가 일치했다. 모든 문항을 전수 검수한 것은 아니다.
- 기존 점판의 넓이 계산 보조 함수가 있다는 이유만으로 넓이 학습 활동이 이미 있다고 판단하지 않는다. 현재 점판은 재현·도형 찾기·분할 활동이고, 단위넓이 측정 활동과 다르다.

## 기존 활동으로 흡수할 내용

- 1과정 1·4권의 거울·회전·합동 분할: 기존 거울 저택, 도형 변환 공방, 똑같이 나누기의 심화로 연결한다.
- 1과정 4·9권의 쌓기나무·세 방향: 기존 입체 활동과 대조한 뒤 빠진 조건만 확장한다.
- 1과정 5권의 크고 작은 도형 세기: 숨은 도형 탐정과 중복되므로 독립 프로그램을 늘리지 않는다.
- 2과정 G2 2단원 42쪽의 피보나치 사각형: 도형 조작을 사용할 수 있으나 핵심은 수 규칙이다. 수 규칙 과정의 후속 후보로 둔다.

## 이번 각 탐구와의 연결

- 각도 어림하기, 점판에서 직각 만들기, 다각형의 내각은 서로 분리한다.
- 1과정 3권 7쪽의 삼각자·직각 설명은 직각 만들기의 선행 개념으로 참고할 수 있다.
- 2과정 G3 3단원 78쪽 활동02 `평행선과 각`: 동위각·엇각의 위치 관계와 평행 조건을 별도 영역으로 다룬다.
- 2과정 G3 75쪽의 정다각형 중심각·외각·내각은 후속 각 활동 후보다. 현재 내각 문항을 중심각·외각까지 구현한 것으로 표시하지 않는다.
- 엇각·동위각의 위치 관계와 각의 크기가 같은 조건을 구별한다. 평행하지 않은 두 선에서 같은 크기를 가정하지 않는다.
- 장 제목에 시계가 있어도 시계 문제를 이 각 활동에 자동으로 포함하지 않는다.

## 제외·보류

- 정식 닮음 과정은 제외한다. 기존의 `절반으로 줄이기`·`2배로 늘리기`와 혼동하지 않는다.
- 도형 기호가 나오는 복면산·마방진·수 배열을 도형 학습으로 분류하지 않는다.
- 입체 단면·자르기와 G4의 독립적인 도형 복원 활동은 이번 검토에서 상세 원본 근거가 부족하므로 보류한다.
- 원본 대표 페이지 확인만으로 유사문제 생성기 전체를 승인하지 않는다. 신규 구현 전에 조건·답 범위·수학 모델·출력 표현을 별도로 검수한다.
