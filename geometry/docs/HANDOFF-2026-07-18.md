## 저장 구조

브라우저 `localStorage`의 `gfield-profile`에 아래 정보가 저장된다.

- `name`: 사용자가 정한 이름 또는 별명
- `setupComplete`: 첫 설정 완료 여부
- `character`, `color`: 캐릭터와 색상
- `equipped`: 분류별 착용 아이템
- `unlocked`: 구매한 아이템 목록
- `progress`: 게임별 마지막 레벨과 문제 번호

포인트는 기존과 동일하게 `gfield-points`를 사용한다. 현재 저장은 같은 기기와 브라우저에서 이어지는 방식이다. 기기 간 이어하기는 이후 로그인 또는 서버 저장이 필요하다.

## 배포와 계정 상태

- 현재 Geometry에는 별도 로그인·백엔드·Geometry 전용 DB가 없다.
- 이름, 캐릭터, 색상, 포인트, 아이템, 게임 진행은 브라우저 `localStorage`에 저장된다.
- 루트 `Dockerfile`은 저장소 전체를 nginx 이미지에 포함하고, 루트 `cloudbuild.yaml`은 Cloud Run 서비스 `hf-viewer` 배포 경로를 정의한다.
- 확인된 `.github/workflows/deploy-pages.yml`은 `reading-world`만 GitHub Pages 대상으로 하므로 Geometry를 Pages 배포 경로로 간주하면 안 된다.
- 기기 간 이어하기를 추가하려면 먼저 기존 계정/DB를 재사용할지, Geometry 전용 인증·저장 API를 만들지 결정해야 한다.
