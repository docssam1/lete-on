# 게임 2-A: 높이를 더해 쌓기나무 개수 세기

## 1. 학습 목표

위에서 본 각 자리의 가장 높은 층 수가 그 자리에 쌓인 쌓기나무 수라는 것을 이해한다. 각 자리의 높이를 적고 모두 더해 전체 개수를 구한다.

최대 범위는 `4 x 4 x 4`, 전체 개수는 최대 64개다.

## 2. 두 가지 입력 화면

한 문제 안에서 언제든 두 화면을 바꿀 수 있다. 입력한 숫자는 두 화면이 같은 상태를 공유하므로 전환해도 사라지지 않는다.

### 입체에 쓰기

- 3D 모양의 각 기둥 맨 위 면을 누른다.
- `1, 2, 3, 4` 숫자 선택판이 가까이에 열린다.
- 고른 숫자는 맨 위 면 바로 위에 또렷하게 표시한다.
- 잘못 쓴 숫자는 다시 눌러 바꿀 수 있다.

### 위에서 쓰기

- 위에서 본 바탕 그림의 각 칸을 누른다.
- `0, 1, 2, 3, 4` 중 하나를 쓴다.
- 블록이 없는 칸은 문제에 따라 빈칸으로 두거나 `0`을 넣는다.
- 3D에서 쓴 숫자와 같은 값이 즉시 표시된다.

화면 전환은 `입체에 쓰기 | 위에서 쓰기`의 두 칸 선택 버튼으로 만든다.

## 3. 답 입력 흐름

1. 각 기둥의 높이를 모두 입력한다.
2. 화면 아래 덧셈 줄에 입력한 수가 자리 순서대로 나타난다.
3. `전체는 몇 개?` 칸에 0~64 숫자를 입력한다.
4. 모든 필수 칸이 채워지면 자동으로 검사한다.
5. 높이 값은 맞고 합만 틀리면 높이 표시는 그대로 두고 다시 더하게 한다.
6. 모두 맞으면 `Great job!` 또는 `Good job!`과 함께 다음 문제로 넘어간다.

숫자 입력은 휴대폰 키보드를 띄우지 않는 큰 숫자판을 기본으로 한다. 실제 키보드의 숫자 입력도 함께 지원한다.

## 4. 레벨 구성

| 레벨 | 판과 높이 | 문제 특징 | 보조 기능 |
|---|---|---|---|
| 1 | 최대 2x2x2 | 2~4개 기둥, 높이 1~2 | 한 칸을 예시로 채워 줌 |
| 2 | 최대 3x3x3 | 계단 모양, 4~6개 기둥 | 덧셈 줄 자동 표시 |
| 3 | 최대 3x4x4 | 빈칸이 있는 불규칙 모양 | 두 입력 화면 자유 전환 |
| 4 | 최대 4x4x4 | 7~12개 기둥, 같은 높이 반복 | 힌트 없이 입력 |
| 5 | 최대 4x4x4 | 복합 계단과 가려진 낮은 층 | 제한된 힌트, 식 완성 |

각 레벨은 5문제다. 문제는 높이 배열만 무작위로 만들지 않고, 모양이 읽히는 계단, 대칭, ㄱ자, 십자 모양을 직접 고른다.

## 5. 문제 데이터

`heights[z][x]`는 그 자리의 쌓기나무 높이다.

```js
const problem = {
  id: "height-l2-01",
  game: "count-heights",
  level: 2,
  board: [3, 3],
  maxHeight: 3,
  heights: [
    [3, 3, 0],
    [2, 2, 1],
    [1, 1, 1]
  ],
  requiredCells: [
    [0, 0], [1, 0],
    [0, 1], [1, 1], [2, 1],
    [0, 2], [1, 2], [2, 2]
  ],
  answer: {
    total: 14
  }
};
```

문제를 불러올 때 `heights`의 합과 `answer.total`이 같은지 자동 검사한다.

## 6. 3D 숫자 표시

- 숫자는 카메라 방향에 따라 기울어져 읽기 어려워지지 않게 만든다.
- 숫자용 작은 캔버스 텍스처를 만들고 각 기둥 위에 평면 또는 스프라이트로 올린다.
- 숫자는 장면을 가리지 않는 흰색 원판과 진한 글자로 표시한다.
- 카메라를 돌려도 각 숫자가 어느 기둥 값인지 선이나 위치로 분명해야 한다.
- 숫자 표시를 누르면 해당 기둥의 입력을 수정한다.

## 7. 피드백

- 빈 칸: 부드러운 점선
- 입력한 칸: 흰 원판과 진한 숫자
- 다시 볼 칸: 짧게 흔들리는 주황 테두리
- 맞은 칸: 계속 초록색으로 칠하지 않고 작은 확인 표시만 잠깐 보여 줌
- docssam 말풍선 예: `맨 위 숫자는 그 기둥의 높이야.`

틀린 칸의 정답을 바로 보여 주지 않는다. 첫 힌트는 틀린 칸의 위치만, 두 번째 힌트는 해당 기둥을 층별로 잠깐 분리해 보여 준다.

## 9. 완료 조건

- 5개 레벨이 각각 5문제를 가진다.
- 3D 위 입력과 위에서 본 그림 입력이 같은 답 상태를 공유한다.
- 최대 4x4 판의 모든 칸이 손가락으로 정확히 선택된다.
- 높이 4까지 입력할 수 있고 전체 답은 64까지 입력할 수 있다.
- 모든 기둥 높이와 전체 합이 모두 맞아야 성공한다.
- 입력 화면을 바꾸거나 카메라를 돌려도 답이 사라지지 않는다.
- 자동 채점 뒤 다음 문제로 자연스럽게 넘어간다.
