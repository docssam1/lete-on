# Geometry World 문항 ID·색인 규격

## 1. 목적

한 문항을 여러 교재, 단계, 난이도, 게임, 학습지에서 복제하지 않고 참조한다. 예를 들어 같은
문항이 `킨더 상`과 `키즈 하`에 모두 적합하면 문항 본체는 하나만 두고 배치 레코드만 두 개를
연결한다. 단계와 난이도는 문항 ID의 일부가 아니다.

이 규격은 황소 중등 복구 문제은행의 검증된 원칙을 Geometry World에 맞게 축약한다.

- 원본 위치와 문항 본체를 분리한다.
- 단원 수준 확인과 세부유형 확인을 구분한다.
- 비슷한 이름만으로 유형을 자동 병합하지 않는다.
- 검수 전 원본 문항은 잠그고 공개하지 않는다.
- 정답, 그림 가시성, 단일 정답, 사용자 승인을 각각 독립적으로 검사한다.

## 2. 다섯 개 레코드

| 레코드 | 예시 | 역할 |
|---|---|---|
| 문항 | `qst-geo-0123...` | 실제 조건·그림·정답이 같은 한 문항 |
| 문항군 | `fam-geo-0123...` | 도움 표시만 다르거나 명시적으로 동치인 변형 묶음 |
| 유형 | `typ-geo-0123...` | 묻는 것과 풀이 구조가 같은 세부유형 |
| 배치 | `plc-geo-0123...` | 문항 하나를 특정 단계·난이도에 놓는 색인 |
| 출처 | `src-geo-0123...` | 검수한 교재·내부 생성기의 비공개 원본 레지스트리 참조 |

ID는 모두 안정 키를 16자리 소문자 16진수로 요약한다. ID에는 교재명, 파일 경로, 페이지,
정답, 단계 이름 같은 내용을 노출하지 않는다.

## 3. 문항 ID와 문항군 ID

생성형 학습지의 문항 ID는 다음 기계 판독 정보로 만든다.

```text
유형 코드 + 그림·조건 데이터 + 구조화된 정답
```

다음 값은 문구를 번역하거나 고쳐도 ID가 바뀌지 않도록 제외한다.

- 화면 지문과 정답 문장
- 풀이 도움말
- 한국어 방향·무늬 이름
- 시트 안 묶음 제목
- 단계와 난이도

문항군 ID는 여기에 더해 숫자 쓰기 칸, 점선, 풀이표, 추가 질문 같은 발판을 제외한다. 따라서
같은 입체에 숫자표가 있는 문항과 없는 문항은 **서로 다른 문항 ID**이면서 **같은 문항군 ID**가
된다.

회전·반사 동치를 자동 가정하지 않는다. 앞·오른쪽 방향이 중요한 쌓기나무 문항은 돌린 모양을
다른 문항군으로 유지한다. 칠교·점판처럼 회전 또는 반사를 같은 것으로 보아야 하는 유형만 독립
검산기가 만든 `familyKey`를 제공해 같은 문항군으로 묶는다.

## 4. 단계·난이도 중복 색인

배치 레코드는 다음 두 축을 가진다.

- 단계: `L0 킨더`, `L1 키즈`, `L2 Pre`, `L3 입문`, `L4 초급`, `L5 중급`, `L6 2과정`,
  `L7 3과정`, `L8 4과정`
- 난이도: `1 하`, `2 중`, `3 상`

예시는 다음과 같다.

```js
placements: [
  { stage: "L0", difficulty: 3 },
  { stage: "L1", difficulty: 1 }
]
```

두 배치는 서로 다른 `plc-geo-*` ID를 가지지만 같은 `qst-geo-*`를 가리킨다. 사용자가 킨더를
고르면 킨더 배치만 조회하므로 키즈 하를 함께 선택할 필요가 없다. 교재 수준이 겹쳐도 문항 복제와
중복 인쇄는 발생하지 않는다.

## 5. 원본 교재 문항

원본 교재 문항은 생성형 문항과 다르게 먼저 위치 ID를 만든다.

1. 원본 SHA-256, PDF 페이지, 페이지 안 슬롯으로 비공개 locator를 만든다.
2. `page_located → visual_verified`로 실제 주문항 경계를 확인한다.
3. `pending → reviewed_unit → reviewed_detail`로 단원과 세부유형을 따로 확인한다.
4. 원본 답지 대조와 독립 계산을 통과해야 답안을 `verified`로 올린다.
5. 같은 문항이 다른 교재에서 발견되면 내용 지문을 대조한 뒤 대표 문항 ID의 별칭 출처로 연결한다.

OCR, 교재 목차, 비슷한 유형명만으로 문항을 합치지 않는다. 확인하지 못한 문항은
`releaseStatus: locked`로 유지한다. 공개 저장소에는 원문, 정답, 풀이, 로컬 경로를 넣지 않는다.

## 6. 학습지 코드와의 관계

`#GW-<유형>-<문항수>x<시드>`는 **학습지 전체를 재생성하는 코드**이고 `qst-geo-*`는
**개별 문항의 정체성**이다. 둘은 대체 관계가 아니다.

- 기존 `#GW` 코드는 형식을 바꾸지 않는다.
- 같은 코드로 다시 만들면 같은 문항 ID 배열이 나온다.
- 문제 카드에는 문항·문항군·배치 ID를 데이터 속성으로 남긴다.
- 브라우저 검수 객체 `window.__WS`에서 전체 ID 배열을 확인할 수 있다.

## 7. 공개 전 검사

1. 문항 ID 충돌이 없는지 확인한다.
2. 한 학습지 안에서 같은 문항 ID가 뜻하지 않게 반복되지 않는지 확인한다.
3. 같은 문항군의 과도한 반복을 막는다.
4. 정답 유일성 또는 허용되는 모든 정답을 독립 계산으로 확인한다.
5. 그림에서 필요한 정보가 모두 보이고 위치가 모호하지 않은지 확인한다.
6. 단계·난이도 배치에 원본 근거 또는 사용자 승인 기록이 있는지 확인한다.
7. 데스크톱, 모바일, A4 인쇄에서 문항 그림과 선택지를 확인한다.

## 8. 현재 적용 범위

현재 코드는 지오메트리 랩의 생성형 쌓기나무 학습지에 문항·문항군·유형·현재 배치 ID를 붙인다.
기존 게임 고정 문제와 색종이 문제은행의 ID는 다음 이관 단계에서 이 규격으로 연결한다. 출처와
단계 배치를 확인하지 않은 기존 문항을 자동 승인된 것으로 가장하지 않는다.
