# 전개도 전망대 50문제 독립 검산

작성일: 2026-08-31

## 학습 순서

| 단계 | 수준 | 활동 | 최대 추론 단계 |
|---:|---|---|---:|
| 1 | 입문 | 접기 애니메이션으로 그림의 마주 보는 면 찾기 | 2 |
| 2 | 초급 | 단순한 네 칸 띠부터 정육면체 전개도 판별 | 3 |
| 3 | 초급 | 합이 7인 주사위의 마주 보는 면과 면 쌍 찾기 | 1 |
| 4 | 중급 | 면 위치를 맞춘 뒤 한 화살표 방향으로 정답 가르기 | 3 |
| 5 | 중급 | 면의 모양·수와 맞닿는 면 수로 정다면체 탐구 | 2 |

입문에서 전개도 세 개를 동시에 머릿속으로 접게 하던 순서를 바꿨다. 먼저 하나의 그림 전개도를
직접 접어 보며 마주 보는 면을 찾고, 다음 단계에서 정육면체가 되는 전개도를 판별한다.

## 독립 계산

문제 생성기의 `foldCubeNet()`과 보기 판정 함수를 정답 계산에 재사용하지 않는다. 별도 검산기는
평면의 각 면에 오른쪽·아래쪽·바깥쪽 3차원 방향을 배정하고, 이웃한 면을 90도씩 접어 여섯 바깥
방향이 한 번씩 생기는지 확인한다.

- 자유 헥소미노 35개 중 정육면체 전개도 11개를 독립 분류
- 50문제의 정답과 세 보기 중 단일 정답 확인
- 그림 반대 면의 평면 연결 거리를 3 이하로 제한
- 2단계 첫 회차는 네 칸이 일렬로 이어진 단순 전개도만 사용
- 4단계는 화살표를 지우면 정답 후보가 둘 이상 남도록 검사
- 정답 위치를 단계마다 `3, 3, 4` 또는 `4, 3, 3`으로 분산
- 완전히 같은 문제와 같은 보기의 중복 금지
- 50문제 모두 `internal-variation`으로 출처 구분

## 자동 검사

```text
node geometry/games/net-observatory/net-observatory-content-audit.mjs
node geometry/games/net-observatory/net-observatory.selftest.mjs
node geometry/games/net-observatory/net-observatory.browsercheck.mjs
```

자가검사는 정답을 없는 보기로 바꾼 복사본과 입문 문제의 추론 단계를 4로 올린 복사본을 넣어
두 오류를 모두 잡는지 확인한다.

2026-08-31 로컬 통합 검사에서 전개도 전망대, 주사위 이동, 소마큐브와 두 인쇄 학습지를 포함한
8개 검사가 모두 통과했다. 전개도 전망대는 50문제 단일 정답, 자유 헥소미노 35개, 정육면체
전개도 11개를 다시 확인했고 데스크톱·작은 화면·A4에서 잘림이 없음을 확인했다.

## 출처 경계

첨부 교재는 활동 유형과 시각 표현을 확인하는 비공개 근거다. 공개된 50문제는 원본 판면이나
공식 답안을 복제한 것이 아니라 같은 개념으로 다시 만든 내부 변형문제다. 기존 비공개 출처
장부의 공개 코드 해시는 현재 파일과 달라 이번 검산의 최신 증거로 사용하지 않았다.
