# 색종이 활동 커리큘럼

## 큰 분류

색종이 활동은 접기 횟수가 아니라 학습자가 하는 사고 활동으로 나눈다. 한 번, 두 번,
세 번 접기는 각 활동 안의 난이도 조건이다.

| 영역 | 핵심 질문 | 응답 방식 |
| --- | --- | --- |
| 접어 자르기 | 펼치면 절단선과 조각이 어떻게 되는가 | 놓이는 쪽, 수 선택, 결과 연결 |
| 구멍 뚫기 | 역순으로 펼치면 구멍이 어디에 몇 개 생기는가 | 놓이는 쪽, 위치 선택, 결과 연결 |
| 접어 계산하기 | 잘리거나 남은 칸의 수는 얼마인가 | 수 선택, 목표 합 역선택 |
| 겹친 색종이 순서 | 어느 종이가 위나 아래에 있는가 | 맨 위·아래 선택, 전체 순서 |
| 방향 추적 | 접힌 종이나 모양을 움직인 결과는 무엇인가 | 결과 선택, 자른 선 되짚기 |

쌓기나무의 위·앞·옆 모양은 색종이 영역에 포함하지 않는다.

## 기존 문제은행 대조

사용자 참고 자료는 한·두·세 번 접기, 직선·대각선 접기, 자른 모양, 조각과 도형 수,
구멍 위치와 개수, 숫자 칸의 잘린 합, 겹친 순서를 포함한다. 기존 문제은행에서 추가로
유지할 항목은 다음 세 가지다.

1. 잘라 낸 수가 아니라 남은 수의 합
2. 목표 합을 주고 잘라 낼 칸을 거꾸로 찾는 문제
3. 여러 번 접은 뒤 맨 위에 놓이는 색이나 수 추적

대각선 방향이나 L자 절단처럼 모양만 다른 항목은 새 영역으로 만들지 않고 같은 생성기의
매개변수로 다룬다.

## 게임 흐름

1. 접을 때 종이가 놓이는 쪽이나 펼칠 때 대칭을 그릴 쪽을 먼저 고른다.
2. 한 단계의 답을 누르면 확인 버튼 없이 즉시 채점한다.
3. 접은 순서의 반대로 한 단계씩 펼친다.
4. 마지막에 위치, 모양, 개수 또는 합을 고른다.
5. 오답은 한 번만 펼친 경우, 접는 방향을 반대로 본 경우, 한쪽만 센 경우로 만든다.

선 잇기는 세 연결이 끝나는 즉시 채점한다. 잘린 닫힌 모양은 모양 선택 후 위치를 찍고,
직선이나 꺾은선은 선 도구로 표시한다. 자유 그리기는 인쇄 학습지에서만 사용한다.

## 생성·검산 규칙

- 모든 접기와 펼치기는 같은 좌표 데이터에서 계산한다.
- 조각 수는 서로 다른 두 해상도의 연결 영역 계산이 일치할 때만 출제한다.
- 구멍과 절단선은 접은 선 위에 우연히 겹쳐 답의 개수가 달라지지 않아야 한다.
- 순서 문제는 보이는 겹침 관계로 전체 순서 또는 요청한 위치가 하나로 결정되어야 한다.
- 수 문제는 잘린 칸 집합을 먼저 확정한 뒤 잘린 합과 남은 합을 독립 계산한다.
- 게임과 학습지는 같은 문항 ID와 정답 데이터를 사용한다.
