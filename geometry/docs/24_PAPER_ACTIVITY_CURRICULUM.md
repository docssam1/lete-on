# 색종이 활동 커리큘럼

## 분류 원칙

색종이 활동은 접기 횟수가 아니라 학습자가 하는 사고 행동으로 나눈다. 한 번, 두 번,
세 번 접기는 각 활동 안의 난이도 조건이다. 자르기와 수의 합처럼 결과 소재가 비슷해도
학생의 풀이 행동이 다르면 같은 영역으로 합치지 않는다.

| 영역 | 핵심 질문 | 대표 응답 |
| --- | --- | --- |
| 접어 자르고 펼치기 | 잘린 선이나 영역은 한 장씩 펼칠 때 어디로 옮겨지는가 | 면 터치, 칸 색칠, 선·영역 완성 |
| 접어 구멍 뚫고 펼치기 | 중간·전체 펼침에서 구멍의 위치·모양·개수는 무엇인가 | 면 터치, 위치·모양 선택 |
| 접어 세고 계산하기 | 조각·도형·수의 개수나 합은 얼마인가 | 영향받는 칸 표시 후 수 입력 |
| 접는 방법 거꾸로 찾기 | 이 결과를 한 번 접어 만들 수 있는가, 접는 선은 어디인가 | 가능 여부 선택, 접는 선 표시 |
| 겹친 색종이 순서 | 어느 종이가 위나 아래에 있는가 | 맨 위·아래 선택, 전체 순서 |

회전·뒤집기·연속 방향 이동은 `paper-turn`의 별도 방향 추적 과정으로 둔다. 쌓기나무의
위·앞·옆 모양은 색종이 영역에 포함하지 않는다.

## 출처 대조와 현재 범위

사용자가 첨부한 33장의 문항별 대조는 `25_PAPER_FOLD_SOURCE_COVERAGE.md`가 단일 기준이다.
현재 게임의 두 과정은 전체 커리큘럼이 아니라 다음 부분 구현이다.

| 현재 과정 | 지원하는 것 | 아직 지원하지 않는 것 |
| --- | --- | --- |
| 색종이 접어 자르기 | 1~2회 접기, 삼각형 절단 영역의 면·최종 모양 선택, 절단선과 전체 조각 수 | 원본의 모든 격자 무늬, 곡선 절단, 도형별 개수 |
| 색종이 접어 구멍 뚫기 | 1~2회 접기, 원형 및 삼각형·사각형 혼합 구멍의 위치·모양·개수 | 원본의 모든 복합 접기, 3회 이상 접기 |
| 기존 학습지 | 수의 합, 일부 조각·원·반원, 겹침 순서 | 한 번 접기 가능성, 접는 선 찾기, 원본 전체 문법 |

2026-10-17 `games/number-paper/`에 가로·세로 두 번 접기의 숫자 색종이 게임을 추가했다.
현재 화면은 직접 접기 → 빗금 자르기 → 역순 펼치기 → 조각 수집의 별도 2활동, 총 40모양이다.
처음의 칸 선택·합 입력 UI는 사용자 피드백으로 교체했다. 기본은 수집 결과로 합을 표시한다.
2026-10-18 추가한 도전 난이도는 모두 담은 뒤 직접 합을 입력해 확인한다. 공식 성적·성취도 판정은 하지 않는다.
기존 학습지의 칸 대응 모델을 공유하며 화면용 문항은 내부 창작이다. 대각선 수 종이,
맨 위 수와 겹침 순서는 게임 지원 범위로 올리지 않는다. 위의 기존 학습지 지원 범위와 구별한다.
2026-10-18 `worksheet/number-paper/`를 현재 게임5장과 순서 그대로 연결했다. 학생은 펼친 모양을
예상해 잘린 칸 또는 남을 칸을 표시하고 합을 구한다. 교사용에는 역순 펼침과10만들기 풀이를 분리한다.
내부 창작40모양을 재사용하며 원본33장 전체를 지원한다는 판정을 확대하지 않는다.

`미지원` 항목은 메인 화면에서 완성된 과정으로 소개하지 않는다. 기존 학습지 생성기는
삭제하거나 축소하지 않고, 새 게임 유형의 문제 문법과 정답 검산 기준으로 보존한다.

## 역순 펼치기 흐름

1. 원본 종이, 첫 번째 접기, 두 번째 접기, 자르기·구멍 상태를 순서대로 보여 준다.
2. 학생이 처음 종이의 화살표 시작 면을 눌러 접기를 실행한다.
3. 마지막 접기부터 거꾸로 펼칠 결과 종이를 활성화한다.
4. 학생은 새 절단선·구멍이 생길 실제 종이 면을 직접 누른다.
5. 정답 면을 누르면 해당 단계의 반사 결과가 나타나고 다음 접기 선이 활성화된다.
6. 위치 선택 후 최종 모양을 고르는 문항에서는 정답 선택 전 완성 그림을 숨긴다. 개수 문항은 펼친 결과에서 개수를 고른다.

한 번만 펼친 결과를 묻는 문항은 중간 상태에서 멈추어 답을 받는다. 선 잇기는 세 연결이
끝나는 즉시 채점하고, 틀린 연결만 지운다. 자유 그리기를 강요하지 않고 격자 영역은 칸
선택, 절단선은 선 도구, 구멍은 모양·위치 선택을 사용한다.

## 시각 규칙

- 접기 화살표는 움직이는 면에서 도착 면으로 종이 경계 안에서 그린다.
- 결과 종이에는 화살표를 넣지 않는다. 접기 방향은 앞의 조건 그림에서 읽는다.
- 접힌 상태는 숫자 표시 대신 겹쳐진 종이의 측면과 층 경계로 구분한다.
- 정답 영역은 실제 종이 외곽으로 잘라 낸 SVG 터치 면이며 별도 방향 상자로 대체하지 않는다.
- 현재 단계의 종이만 강조하고, 이전 단계 그림은 설명 자료로 남긴다.
- 모바일에서도 접기 순서가 위→아래 또는 좌→우로 끊김 없이 읽혀야 한다.

## 생성·검산 규칙

- 모든 접기와 펼치기는 같은 좌표 데이터에서 계산한다.
- 절단선과 구멍은 `접힌 상태 → 중간 펼침 → 전체 펼침` 상태를 모두 저장한다.
- 조각 수는 서로 다른 두 해상도의 연결 영역 계산이 일치할 때만 출제한다.
- 구멍과 절단선은 접은 선 위에 우연히 겹쳐 답의 개수가 달라지지 않아야 한다.
- 모양별 개수는 연결 영역 수와 별도로 도형 분류를 검산한다.
- 수 문제의 모델은 잘린 칸 집합·잘린 합·남은 합을 독립 검산한다. 숫자 색종이 공방은 기본에서 합을 보여 주며, 도전에서는 조각 수집 후 합을 입력해 확인한다.
- 순서 문제는 보이는 겹침 관계로 요청한 위치 또는 전체 순서가 하나로 결정되어야 한다.
- 게임과 게임 연계 학습지는 문항 ID, 단계별 좌표, 정답을 공유한다.

## 출시 기준

1. 출처 대조표에서 해당 대표 문항이 `지원`이어야 한다.
2. 데이터 검산과 별도로 데스크톱, 390px 세로, 모바일 가로를 직접 푼다.
3. 문제지와 답안지를 A4로 렌더해 중간 단계, 빈 답 공간, 정답 위치를 확인한다.
4. 보이지 않는 클릭 영역, 화살표 이탈, 종이 외곽과 터치 면 불일치를 검사한다.
5. 미지원 유형을 다른 유형의 문항 수로 채워 전체 반영으로 표현하지 않는다.
