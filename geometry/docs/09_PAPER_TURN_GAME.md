# GFIELD 접고 돌리고 뒤집기 게임 설계

## 교재 근거

기존 `색종이 접기` 5단계는 필즈 더 클래식 1과정 1N권의 두 번째 단원인
`색종이 접기`를 바탕으로 한다. 이 게임은 반·대각선 접기, 자르기와 구멍,
작업 위치, 대칭 도형, 잘린 수의 합을 다룬다.

두 번째 코스는 필즈 더 클래식 1과정 7N권의 다음 흐름을 바탕으로 별도 구성한다.

- 6~8쪽: 접힌 색종이 뒤집기
- 9~15쪽: 색종이 자르기와 접기, 접은 순서를 거꾸로 추적하기
- 34~38쪽: 도형 돌리기와 뒤집기

두 교재는 모두 색종이를 사용하지만 학습 목표가 다르다. 1N권은 접은 종이를
`펼쳐 대칭 결과를 찾는 것`이 중심이고, 7N권은 접힌 상태를 `뒤집고 돌린 뒤
위치와 방향을 추적하는 것`이 중심이다. 따라서 한 게임의 레벨 6~10으로 붙이지
않고 오리가미 스튜디오 안의 두 번째 5단계 코스로 분리한다.

## 학습 흐름

### 레벨 1 - 접힌 종이 뒤집기

- 앞면과 뒷면의 색이 다른 접힌 종이를 한 방향으로 뒤집는다.
- 아이는 뒤집은 뒤 보이는 무늬와 방향을 3개 후보에서 고른다.
- 첫 문제는 손가락 애니메이션과 큰 화살표로 좌우/위아래 뒤집기를 보여 준다.
- 종이의 크기와 모양은 바뀌지 않고 앞뒤와 위치만 바뀐다는 것을 익힌다.

### 레벨 2 - 자른 선 되짚기

- 펼친 결과와 접는 선을 보고 접힌 종이에서 어떤 선을 잘랐는지 찾는다.
- 접기 순서를 거꾸로 한 단계씩 되돌리는 애니메이션을 제공한다.
- 보기에는 같은 계열의 절단선만 사용하고, 답이 두 개가 되는 대칭선 위 절단은 제외한다.

### 레벨 3 - 모양 돌리기

- 모눈 위의 비대칭 도형을 90도씩 돌린다.
- 한 번 돌리기부터 두 번 연속 돌리기까지 다룬다.
- 도형의 위치, 꼭짓점 방향, 안쪽 표식을 함께 추적한다.

### 레벨 4 - 모양 뒤집기

- 세로축 또는 가로축을 기준으로 도형을 뒤집는다.
- 회전과 거울 뒤집기의 차이를 비교한다.
- 방향이 없는 원처럼 답을 구분할 수 없는 도형은 단독 문항으로 사용하지 않는다.

### 레벨 5 - 순서대로 추적하기

- 돌리기와 뒤집기 2~3개를 순서대로 적용한다.
- 아이가 선택하면 각 동작을 한 번씩 재생한 뒤 최종 모양과 비교한다.
- 접기/회전 순서를 바꾸면 결과가 달라지는 문제를 중심으로 출제한다.

## 문제 데이터

모든 문항은 4x4 모눈의 비대칭 셀 패턴으로 저장한다. 답은 원본 패턴과 변환
목록으로 계산하며, 정답 그림을 별도로 손으로 입력하지 않는다.

```js
{
  id: "paper-turn-l5-01",
  level: 5,
  interaction: "transform-choice",
  start: ["0000", "0110", "0100", "0000"],
  operations: ["rotate-cw", "flip-vertical"],
  choices: [/* 계산된 서로 다른 세 결과 */],
  answer: 1,
  worksheet: { mode: "turn-sequence", difficulty: "hard" }
}
```

- 시작 패턴은 반드시 비대칭이어야 한다.
- 세 보기는 서로 달라야 하고 정답은 정확히 하나여야 한다.
- 최근에 푼 문제와 같은 시작 패턴·연산 순서를 한 회차에 다시 내지 않는다.
- 게임과 학습지는 같은 `id`, 시작 패턴, 연산, 정답을 공유한다.

## 화면과 피드백

- 왼쪽: 시작 모양과 큰 동작 화살표
- 가운데: 동작 순서 또는 펼친 결과
- 오른쪽/하단: 크기가 같은 3개 결과 후보
- 첫 문제와 힌트에서만 폴디가 등장하며 매 문제 음성은 반복하지 않는다.
- 정답이면 동작을 실제 순서대로 짧게 재생한 뒤 `GOOD JOB!`, `GREAT JOB!`,
  `SUCCESS!` 중 하나를 표시한다.
- 오답은 선택한 보기만 옅게 흔들고 정답 위치나 색을 바로 노출하지 않는다.

## 학습지 연결

| 게임 레벨 | 학습지 유형 | 정답지 풀이 |
| --- | --- | --- |
| 1 접힌 종이 뒤집기 | 뒤집은 뒤의 모양 고르기 | 앞/뒷면과 이동 방향 표시 |
| 2 자른 선 되짚기 | 펼친 결과에 맞는 절단선 고르기 | 펼치기를 역순으로 접어 절단선 확인 |
| 3 모양 돌리기 | 회전 전후 모양 연결하기 | 90도 회전 단계를 화살표로 표시 |
| 4 모양 뒤집기 | 대칭축에 맞는 모양 고르기 | 대응 꼭짓점과 방향 표시 |
| 5 순서대로 추적하기 | 연속 변환의 마지막 모양 고르기 | 각 중간 모양을 모두 표시 |

학습지 메뉴에서는 두 색종이 코스를 구분해 보여 주되, 교사는 유형을 여러 개
선택하여 혼합 출제할 수 있다.

## 검증 기준

1. 모든 문항의 보기 3개가 서로 다르고 정답이 하나여야 한다.
2. 회전과 뒤집기 계산은 게임, 학습지, 정답지에서 같아야 한다.
3. 모바일 세로·가로에서 세 보기가 잘리거나 겹치지 않아야 한다.
4. 빠르게 연속으로 눌러도 변환 애니메이션과 채점은 한 번만 실행되어야 한다.
5. 기존 `paper-fold` 진행 기록과 `gfield-profile`을 덮어쓰지 않는다.
