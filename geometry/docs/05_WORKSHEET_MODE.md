# Cube Town 학습지 모드 설계

## 목적

학습지 모드는 게임을 그대로 인쇄하는 기능이 아니다. 같은 문제은행을 사용하되, 종이에서는 관찰, 색칠, 기록, 정답 확인이 자연스럽게 이어지는 교재형 출력으로 만든다.

## 기본 구성

1. 표지
   - GFIELD Geometry World / Cube Town 브랜드를 크게 표시한다.
   - 이름, 날짜, 레벨, 회차를 적는 칸을 둔다.
   - 큐비와 원목 큐브 일러스트를 넣어 게임과 같은 세계관을 유지한다.

2. 문제지
   - 한 장에 4~6문제를 기본으로 한다.
   - 저학년용은 여백을 넓게 두고, 큐브 그림을 크게 배치한다.
   - 문제 번호, 레벨, 활동 유형을 명확히 표시한다.

3. 색칠 활동지
   - 컬러 큐브 문제가 있을 때 사용한다.
   - 왼쪽에는 색이 들어간 목표 쌓기나무를 보여 준다.
   - 오른쪽에는 같은 구조의 무채색 쌓기나무를 두고 같은 위치에 색칠하게 한다.
   - 흑백 출력도 가능하도록 색마다 기호를 함께 둔다.
     - 초록: 원
     - 파랑: 삼각형
     - 노랑: 별
     - 빨강/코랄: 네모

4. 정답지
   - 문제지와 같은 순서를 유지한다.
   - 답만 작게 나열하지 않고, 각 문제의 완성 모양을 보기 좋게 다시 보여 준다.
   - 색칠 문제는 완성 색칠본을 정답으로 제공한다.

## 똑같이 쌓기 학습지 대응

똑같이 쌓기 게임은 직접 드래그해서 만드는 디지털 활동이다. 학습지에서는 같은 활동을 아래 두 가지 방식으로 변환한다.

### A. 원목 문제

- 목표 쌓기나무 그림을 크게 보여 준다.
- 아래에는 위에서 본 바닥판을 제공한다.
- 학생은 각 칸의 높이나 위치를 표시한다.
- 정답지는 3D 완성 그림과 바닥판 높이 답을 함께 제공한다.

### B. 컬러 문제

- 목표 쌓기나무 그림은 컬러로 제공한다.
- 오른쪽에는 같은 모양의 빈 큐브 그림을 제공한다.
- 학생은 같은 위치의 큐브에 같은 색을 칠한다.
- 정답지는 색칠 완료본으로 제공한다.

## 디자인 기준

- 화면 UI와 같은 원목 질감, 둥근 보드, 큐비 캐릭터 톤을 유지한다.
- A4 인쇄에서 큐브가 작아 보이지 않게 문제당 그림 크기를 충분히 확보한다.
- 표지, 문제지, 정답지가 같은 브랜드 체계로 보여야 한다.
- 게임 버튼, 입력창 같은 화면용 UI 흔적은 학습지에 넣지 않는다.
- 인쇄용은 배경을 과하게 어둡게 쓰지 않고 잉크 사용량을 줄인다.

## 문제 수 옵션

- 5문제: 짧은 연습
- 10문제: 기본 학습지
- 20문제: 복습/숙제

문제는 선택한 레벨에서 최근 게임 문제와 겹치지 않도록 우선 배정한다. 나중에 문제은행이 커지면 같은 레벨 다른 문제를 무작위로 구성한다.

## Cube Town 메뉴 연결

Cube Town의 학습지 메뉴에는 아래 항목을 둔다.

- 똑같이 쌓기: 원목 관찰 활동
- 똑같이 쌓기: 컬러 색칠 활동
- 쌓기나무 개수 세기
- 숨은 쌓기나무 세기
- 정답지 포함 여부

처음 구현은 똑같이 쌓기 원목/컬러 활동지와 정답지를 우선 만든다.

## 똑같이 쌓기 레벨별 학습지 대응

게임의 레벨을 그대로 종이에 복사하지 않고, 각 레벨의 핵심 사고만 학습지 활동으로 바꾼다.

| 레벨 | 게임 활동 | 학습지 활동 |
|---|---|---|
| 1 | 낮은 원목 쌓기 모양을 똑같이 만들기 | 완성 모양을 보고 바닥판 위치를 표시하거나 간단한 높이 수를 적기 |
| 2 | 3x3x3 범위의 원목 구조 만들기 | 위에서 본 칸에 각 자리 높이를 쓰고 전체 모양을 확인하기 |
| 3 | 3x3x3 컬러 구조 또는 4x4x4 원목 구조 만들기 | 컬러 문제는 같은 위치에 같은 색 칠하기, 원목 문제는 큰 바닥판에 높이 기록하기 |
| 4 | 직육면체만으로 똑같이 만들기 | 직육면체의 방향을 화살표나 회전 표시로 표시하고 같은 방향을 찾기 |
| 5 | 여러 가지 모양 만들기와 작품 캡처 | 내 작품 사진 붙이기/그리기, 사용한 블록 종류와 개수 기록하기 |

## 큐비 성장 연동

게임 화면에서 큐비는 레벨에 따라 색과 장식이 조금씩 업그레이드된다. 학습지에도 같은 성장 흐름을 작게 반영한다.

- 레벨 1: 기본 큐비
- 레벨 2: 색감이 살짝 바뀐 큐비
- 레벨 3: 작은 황금 모자
- 레벨 4: 파란 띠 또는 배지
- 레벨 5: 별 메달

표지와 문제지에는 큐비를 크게 남발하지 않고, 표지·레벨 시작 카드·정답지 하단에만 작게 사용한다. 학습지의 주인공은 문제 그림과 학생의 기록이어야 한다.

## 인쇄 디자인 원칙

- 표지는 게임 UI와 같은 원목, 짙은 브라운, 따뜻한 조명 톤을 사용한다.
- 문제지는 여백을 넉넉하게 두고, 한 페이지에 너무 많은 3D 그림을 넣지 않는다.
- 컬러 문제는 반드시 흑백 출력 보조 기호를 함께 둔다.
- 정답지는 빠르게 채점할 수 있도록 문제 그림을 작게 반복하고 정답 표시를 선명하게 둔다.
- 화면용 버튼, 말풍선, 조작 UI는 인쇄물에 넣지 않는다.
