# 점판 공작소 콘텐츠 감사

검사일: 2026-08-31

## 공개 범위

- 5단계, 55문항, 한 회차 5문항
- 1단계 초급 하: 점 두 개와 열린 선 10문항
- 2단계 초급 상: 삼각형·사각형·오각형 재현 15문항
- 3단계 중급 하: 정사각 점판의 정사각형 종류와 전체 개수 10문항
- 4단계 중급 중: 삼각 점판의 정삼각형 종류와 전체 개수 10문항
- 5단계 중급 상: 선 1개 또는 2개로 삼각형·사각형 분할 10문항

각 문항은 `stage`, 단계 안 난이도 `difficulty`, 출처 성격, 정답 정책,
추론 단계와 언어·표상·선수 개념·추론 부하·응답 방식의 학습자 적합성 값을 따로 가진다.

## 독립 수학 검산

`geoboard-content-audit.mjs`는 게임의 판정 함수를 호출하지 않고 격자점 조합과 평면 분할을
다시 열거한다. 정사각 점판의 정사각형은 `3x3: 3종류/6개`, `4x4: 5종류/20개`,
`5x5: 8종류/50개`다. 삼각 점판의 정삼각형은 한 변의 못이 3·4·5개일 때 각각
`2종류/5개`, `4종류/15개`, `6종류/35개`다.

레벨 5의 공개 문항별 정답 조합 수는 `2, 5, 3, 1, 2, 5, 21, 28, 12, 11`이다.
같은 분할 목표가 겹치던 세 문항은 표시된 못을 반드시 지나는 조건으로 구별했으며, 필터링된
모든 정답 조합을 인정한다. 표시 못만 빠뜨린 답에는 도형 수가 틀렸다는 안내 대신 표시 못 전용
피드백을 제공한다.

## 편향과 오답 통제

- 정사각형 전체 개수 보기의 정답 위치는 1·2·3번에 각각 1회다.
- 정삼각형 전체 개수 보기의 정답 위치도 1·2·3번에 각각 1회다.
- 종류는 크기로 구별하며 위치·회전·반사는 새 종류로 세지 않는다.
- 전체 개수는 실제 점 위치가 다르면 따로 센다.
- 잘못된 배치 개수와 비어 있는 분할 정답을 주입하는 negative control이 반드시 실패한다.

## 화면과 조작 관문

브라우저 검사는 다섯 단계의 실제 풀이, 성공 후 자동 진행과 보조 다음 버튼, 마지막 단계 완료,
네 언어, 1280x900·844x390·390x844 무넘침, 가로 힌트 무잘림, 세로 힌트와 답안 영역 분리,
44px 이상 터치 영역, 화살표 키 이동, Enter/Space 선택, 대화상자 초점, reduced motion을 확인한다.
점판은 목재 결, 테두리 깊이, 금속 못, 고무줄 명암과 그림자를 사용하되 정답 정보는 재질로
노출하지 않는다.
