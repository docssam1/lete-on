# 길 잇기 산책로 내용·화면 감사

감사일: 2026-08-31

## 공개 계약

- 5단계, 단계별 10문제, 전체 50문제
- 한 회차 5문제
- 난이도: `입문 → 초급 → 초급 → 중급 → 중급`
- 단계 순서: `한 길 → 숨은 타일 → 두 목적지 → 막힌 길 → 최단 경로`
- 성공 연출 뒤 다음 문제로 자동 이동
- 한국어·영어·중국어·일본어와 키보드·가로·세로 화면 지원

## 자료 경계

- RAY B4-2 책 p.68-74(PDF 파일 p.58-64)의 길 카드, 여러 목적지, 막힌 칸 최단 경로 활동을 사고 구조의 근거로 사용한다.
- 레벨 2의 숨은 타일은 같은 변-가운데 연결 규칙을 사용한 GFIELD 내부 확장이다.
- 공개 파일에는 원본 페이지나 답안 이미지를 포함하지 않는다.
- 최단 경로의 칸 수는 원문처럼 출발 칸과 도착 칸을 제외해 표시한다.

## 감사에서 발견한 문제와 수정

1. 844×390 화면에서 게임판이 하단 도구막대와 겹치고 숨은 타일 보기 3개가 잘렸다.
   - 짧은 가로 화면에서는 게임판 크기를 실제 남은 높이에 맞추고, 보기 3개를 게임판 옆에 세로로 배치했다.
2. 성공 뒤 다음 문제 버튼을 다시 눌러야 했다.
   - 성공 연출 뒤 자동으로 다음 문제 또는 완료 창으로 이동한다. 동작 줄이기 설정에서는 대기 시간을 짧게 한다.
3. 키보드로 타일을 돌리면 새 타일에 초점이 남지 않았다.
   - 다시 그린 같은 칸으로 초점을 되돌리고, 행·열·길 방향을 접근성 이름으로 제공한다.
4. 마지막 단계에도 `다음 레벨`이 표시됐다.
   - 마지막 단계에서는 해당 버튼을 실제로 숨긴다.
5. 숨은 타일 10문제의 정답이 모두 두 번째 보기였다.
   - 정답 위치를 1·2·3번에 `4/3/3`으로 분산했다.
6. 단계별 조작 부담이 쉬운 순서와 어긋났다.
   - 한 길, 숨은 타일, 두 목적지, 막힌 길, 최단 경로 순으로 재배치했다.
7. 힌트가 정답 타일을 바로 고치거나 한 최단 경로만 강제했다.
   - 첫 힌트는 살펴볼 범위를 표시하고, 다음 힌트에서 한 단계만 돕는다. 최단 경로는 현재 위치에서 가능한 모든 최단 다음 칸을 인정한다.
8. 길 타일이 평면 SVG 배관처럼 보였다.
   - 문제 좌표는 유지하면서 타일 표면, 홈, 레일, 반사광, 눌림 상태를 더해 에나멜 교구처럼 보이게 했다.

## 독립 계산

`path-walk-content-audit.mjs`는 운영 코드의 회전·연결 검사 함수를 사용하지 않고 다음을 다시 계산한다.

- 회전 타일 30문제의 초기 미완성, 완성 연결성, 정확히 1개인 해
- 숨은 타일 10문제의 서로 다른 보기 3개와 정확히 1개인 정답
- 최단 경로 10문제의 거리, 저장 경로, 복수 최단 경로 인정 정책
- 50개 ID, 자료 구분, 추론 단계, 난이도 순서
- 숨은 타일 정답 위치 `4/3/3`

최단 경로의 해 개수는 문제별로 `17, 2, 6, 2, 34, 24, 41, 1, 7, 7`이다. 따라서 게임은 저장된 한 경로만 강제하지 않고 길이가 같은 모든 최단 경로를 정답으로 인정한다.
