# GFIELD Geometry World 전체 게임 로드맵

## 1. 문서의 목적

이 문서는 Geometry World에서 최종적으로 제공할 게임을 교재의 실제 기하 활동 단위까지 펼친 마스터 목록이다.
게임 화면에서는 `레벨 1~5`를 사용하지 않고 `킨더`, `키즈`, `PRE`, `입문`, `초급`, `중급`을 사용한다.
한 게임이 여러 단계에 걸치면 카드에 `킨더-초급`, `입문-중급`처럼 권장 범위를 표시한다.

- 단계는 학습 범위이고, `하·중·상`은 각 단계 안의 문항 난이도다.
- 기존 숫자 레벨 ID는 저장 기록 호환을 위해 코드 내부에만 유지한다.
- 현재 구현된 게임을 삭제하거나 다른 게임에 흡수하지 않는다.
- 지도에는 75채의 건물을 늘어놓지 않는다. 9개 지역을 두고, 지역에 들어가 게임 카드를 고른다.
- 문제은행은 같은 학습 목표를 인쇄형 문제로 바꾸지만, 게임은 교구 조작을 중심으로 설계한다.

## 2. 자료 근거와 검수 상태

세부 유형은 다음 자료의 기하·측정 단원을 교차 확인해 재구성했다.

| 자료 | 사용 범위 | 상태 |
|---|---|---|
| RAY Kids, RAY, Prism 목차 | 패턴블록, 쌓기나무, 색종이, 주사위, 전개도, 점판, 넓이, 각, 작도 | 목차 행 단위 확인 |
| 뉴소마 세부목차 | A1부터 F1까지 게임 목표와 교과 연계 | 설명 행 단위 확인 |
| 프리미어 목차 | 초급·중급·GE의 기하 확장 | 목차 행 단위 확인 |
| 프리미어 하이퍼포커스 기출 유형 점검 | 겹친 정사각형, 끊긴 선 판별, 삼각 배열 점판의 정삼각형 찾기 | 문항 16·17·19와 정답·지도 포인트 시각 확인 |
| 1031·팩토 단계별 교재 | PRE·입문·초급·중급 난이도 보정 | 파일과 단계 확인, 문항별 시각 검수는 출제 전에 수행 |
| 저장소 source-memory | 기존 설계 결정, 단일정답·가시성 규칙 | 검증 기록 사용 |

교재 문항을 복제하지 않는다. 학습 목표와 사고 과정을 새 인터랙션과 새 문제 데이터로 구현한다.

### 점판 공작소 단계 확장

점판은 한 종류로 고정하지 않는다. 사각 격자 점판은 다각형·둘레·넓이 활동에 사용하고,
삼각 배열 점판은 정삼각형과 기울어진 정삼각형 찾기에 사용한다. 정수 좌표의 사각 격자에서는
정확한 정삼각형을 만들 수 없으므로 화면만 비슷하게 그려 정답으로 인정하지 않는다.

| 단계 | 활동 | 점판 |
|---|---|---|
| 키즈 | 선분, 열린 선, 제시된 삼각형·사각형을 같은 위치에 만들기 | 사각 격자 |
| PRE | 꼭짓점·변 조건으로 도형 만들기, 단순 그림 속 도형 하나씩 찾기 | 사각 격자 |
| 입문 | 같은 둘레·다른 넓이, 같은 넓이·다른 모양 만들기 | 사각 격자 |
| 초급 | 크기와 방향이 다른 정사각형·삼각형을 모두 찾아 분류하기 | 사각·삼각 배열 |
| 중급 | 오목한 도형, 겹친 도형, 끊긴 선이 섞인 복합 그림에서 조건별 도형 모두 찾기 | 사용자 정의 점 배열 |

### 도형 개수 탐정의 조작과 채점

1. 아이는 숫자를 먼저 입력하지 않고, 찾은 도형의 꼭짓점을 차례로 눌러 테두리를 완성한다.
2. 완성된 도형은 반투명 색으로 남고 `작은 것·큰 것·기울어진 것` 모음에 자동 분류된다.
3. 같은 도형을 시작점이나 진행 방향만 바꿔 다시 누르면 중복으로 세지 않는다.
4. 선이 끊겼거나 한 변이 완성되지 않은 모양은 도형으로 인정하지 않는다.
5. 선의 교차점은 점으로 표시된 경우에만 꼭짓점으로 쓴다. 표시 없는 교차점은 새 꼭짓점이 아니다.
6. 큰 도형은 각 변이 기존 선분으로 빈틈없이 이어질 때만 센다.
7. 마지막 도형까지 찾으면 크기·방향별 개수와 전체 합을 함께 보여 준다.

문항 데이터는 출제 전에 가능한 단순 폐곡선을 전부 열거한다. 삼각형은 세 변의 길이 조건,
정사각형은 네 변과 직각 조건으로 걸러 정답 집합을 만들고, 게임 채점은 아이가 고른 집합과 이 정답
집합을 비교한다. 하이퍼포커스 검증 문항은 회귀 검사로 둔다. 문항 16·17의 복합 정사각형은 각각
10개, 문항 19의 삼각 배열 점판은 정삼각형 12개가 검출되어야 한다. 이 수가 달라지면 문제를
출제하지 않는다.

`도형 만들기`, `복합 도형 찾기`, `삼각 배열 점판`을 처음 여는 순간에는 각각 별도의 짧은 개념
튜토리얼을 한 번 제공한다. 닫힌 선, 끊긴 변, 큰 도형, 기울어진 도형을 실제 점판 위 애니메이션으로
비교한다. 손 모양 포인터가 점을 누르고 고무줄을 이어 정답 도형 하나를 만드는 조작도 자동 시범으로
보여 준다. 이후 아이가 연습 도형 하나를 직접 찾으면 본 문제로 들어간다. 튜토리얼은 채점·포인트에서 제외하고
완료 기록을 저장하며, 이후에는 도움말의 `개념 다시 보기`로만 재생한다.

하이퍼포커스의 펜토미노 채우기 문항처럼 답이 여러 개인 활동은 `가능한 답 여러 개` 모드로만
사용한다. 정확히 하나를 고르는 문제로 위장하지 않는다. 최소 정사각형 분할과 두 선으로 여러 조각
만들기는 점판 채점에 섞지 않고 각각 `똑같이 나누기`와 `선과 다각형 제작대`의 상위 미션으로 보낸다.

## 13. 단계와 문항 난이도

게임 카드의 단계 범위와 문항 난이도는 별개다.

| 표시 | 의미 | 대표 활동 |
|---|---|---|
| 킨더 | 직접 맞추고 비교하는 조작 | 같은 모양, 블록 놓기, 길이 비교 |
| 키즈 | 한두 조건을 관찰해 구성 | 대칭 완성, 조각 채우기, 입체 분류 |
| PRE | 위치·방향·개수를 함께 처리 | 세 방향, 주사위 방향, 점판 도형 |
| 입문 | 초등 교과 개념을 사고력 조작으로 확장 | 전개도, 둘레·넓이, 각도, 이동 |
| 초급 | 여러 조건과 두 단계 추론 | 최대·최소, 합동, 작도, 복합 넓이 |
| 중급 | 중학교 기하 개념과 설명 | 닮음, 피타고라스, 삼각비, 원의 성질 |

각 단계 안에서 다시 `하·중·상`을 둔다. 예를 들어 `입문-하`와 `초급-하`는 같은 뜻이 아니다.

## 14. 공통 게임 규칙

1. 게임의 첫 진입과 새로운 조작 모드의 첫 진입에만 짧은 튜토리얼을 제공하고 완료 기록을 저장한다.
2. 기본 조작은 교구를 끌어 놓고, 회전하고, 선을 긋고, 도구로 재는 행동이다.
3. 보이는 정보만으로 정답이 하나인 문제는 자동 검증기로 유일성을 확인한다.
4. 여러 답을 찾는 활동은 `가능한 답 여러 개`라고 명시하고 회전·반사 동치 여부를 데이터에 기록한다.
5. 잘못된 조작에는 칭찬 음성을 재생하지 않고 짧은 효과와 옅은 안내만 준다.
6. 완료할 때만 강한 성공 효과와 다음 문제 선택을 제공한다.
7. 게임 카드에는 단계 범위를, 게임 안에는 현재 단계명과 `하·중·상`을 표시한다.
8. 동일한 문제 데이터가 게임 채점과 학습지 정답에서 다르게 계산되지 않도록 교차 검사한다.

## 15. Geometry World에서 제외할 교재 유형

교재에 함께 있는 시계·달력·무게·마방진·수열·확률·복면산·논리표는 좋은 사고력 활동이지만
기하 월드에는 넣지 않는다. 시각·달력·수 계산은 Number Magic, 논리·확률·경로 전략은 별도 Logic World의
후보로 보낸다. 단, 길이·둘레·넓이·겉넓이·부피는 기하 측정이므로 Geometry World에 유지한다.

## 16. 구현 순서

| 순서 | 범위 | 이유 |
|---:|---|---|
| 1 | 현재 16개 게임 모바일·PC 검수와 단계명 전환 | 이미 제공 중인 경험을 먼저 안정화 |
