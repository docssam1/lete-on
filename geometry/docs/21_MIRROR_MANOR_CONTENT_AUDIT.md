# 거울 저택 콘텐츠·출시 감사

## 범위

- 게임: `geometry/games/mirror-manor/`
- 활동지: `geometry/worksheet/mirror-manor/`
- 문제은행: 5단계, 단계별 10문항, 총 50문항
- 난이도: 입문, 초급, 초급, 중급, 중급

## 학습 순서

1. 반쪽 칠하기: 거울선과 같은 줄·같은 거리의 칸을 직접 완성한다.
2. 같은 거리 찾기: 사각·삼각 점판에서 세 보기 중 대응점 하나를 고른다.
3. 물건 배치: 모양의 좌우 방향과 거리를 함께 판단한다.
4. 기호 반사: 글자와 화살표의 방향을 세로·가로·대각 거울에서 비교한다.
5. 두 거울: 한 원본 칸마다 세 반사 복사본을 완성한다.

입문 첫 회차는 정답 칸이 2~6개인 문항부터 시작한다. 각 단계의 두 번째 회차에는 조작량이
더 큰 문항을 배치한다. 선택형 정답 위치는 같은 거리와 기호 단계 모두 `4/3/3`이다.

## 출처 계약

- 레벨 1·3: RAY C1-1 PDF p.7-10의 거울 물체 원리를 모바일 격자 활동으로 재구성했다.
- 레벨 2: 같은 반사 원리를 점판의 같은 거리 선택 활동으로 확장했다.
- 레벨 4: 한국어 7문항은 플러스북 본문 p.19-23의 거울 글자 활동에 연결한다.
- 레벨 4의 영문자·가로축·대각축 3문항과 레벨 5는 GFIELD 내부 확장이다.

원본 이미지는 공개 저장소로 복사하지 않는다. 각 문항은 `provenanceKind`, `sourceRef`,
`answerPolicy`를 가지며 원본 기반과 내부 확장을 구분한다.

## 독립 검산

`mirror-manor-content-audit.mjs`는 게임의 반사 함수를 호출하지 않고 별도 좌표식으로 다음을
다시 계산한다.

- 반쪽 칠하기와 두 거울의 정확한 칸 집합
- 물건별 반사 위치와 보관대의 정답 조각 수
- 점판 대응점의 단일정답과 서로 다른 10개 좌표 구조
- 기호·점판 보기 위치 `4/3/3`
- 물건 방향 오답의 보관대 위치 분산
- 세로축 대칭 글자가 정답·일반 보기를 같게 만들지 않는지
- 첫 회차가 단계 안에서 쉬운 순서인지

Self-test에는 칠하기 정답과 점판 보기를 고의로 훼손했을 때 독립 감사가 실패하는 음성 대조가
포함된다.

## 화면·접근성

- 성공 후 일반 모드 약 1.15초, 감속 모드 약 0.7초 뒤 자동으로 다음 문항으로 이동한다.
- 물건 배치는 드래그뿐 아니라 조각 선택 후 칸 선택으로도 풀 수 있다.
- 다시 그린 칸의 키보드 포커스를 유지하고 모달의 Tab 순환과 Escape 닫기를 지원한다.
- 힌트는 정답을 대신 선택하지 않고 원본 칸·거울선·거리 기준만 강조한다.
- 은경, 청록 에나멜, 산호색 정답 타일과 금속 프레임을 한 재질 체계로 사용한다.
- `844×390`, `390×844`, 데스크톱, 감속 설정과 네 언어를 브라우저로 검사한다.
- 활동지는 동일한 50문항에서 여섯 문제를 뽑고 A4 한 페이지와 모바일 무가로넘침을 검사한다.
