# 도형 변환 공방 학습 설계

## 학습 영역

| 영역 | 판단 대상 | 오답의 근거 | 학생의 확인 활동 |
|---|---|---|---|
| 모양 관찰 | 꺾인 구간의 위치와 길이 | 내부 구간 하나가 조금 이동 | 다른 보기에 달라진 구간 표시 |
| 평행이동 | 지정 방향과 이동 거리 | 반대 방향 또는 다른 거리 | 점 A의 이동 경로 그리기 |
| 회전 | 고정 중심과 방향·각도 | 그대로인 도형 또는 다른 회전 | O를 고정하고 A의 경로 표시 |
| 확대 | 모든 길이의 2배 | 그대로이거나 한 축만 확대 | 대응하는 변 AB 비교 |
| 줄이기 | 모든 길이의 절반 | 그대로이거나 한 축만 줄임 | 대응하는 변 AB 비교 |

관찰 문항에 확대·회전을 끼워 넣지 않는다. 변환 문항에서 모양을 조금 바꾸는 오답으로
관찰 능력만 평가하지 않는다. 정식 닮음 단원이나 합동 조건 증명은 포함하지 않는다.

## 문제와 표상

- 직접 설계한 50문항, 영역별 10문항. 각 영역은 평면 다각형과 열린 꺾은선을 번갈아 제시한다.
- 기준과 보기의 좌표틀은 모두 동일한 정사각형이다. 자동 맞춤 확대를 금지한다.
- 모눈 한 칸은 좌표 10단위다. 평행이동은 정수 칸으로 제시한다.
- 회전·확대·줄이기의 중심은 [50, 50]으로 고정한다. 회전의 추적점은 중심과 다른 점이다.
- 회전 지시는 원 위의 화살표로 표시한다. 90°는 반의 반 바퀴, 180°는 반 바퀴이며 시계·반시계 방향을 명시한다.
- 줄이기는 슬래시 분수나 소수 대신 `절반`, 확대는 `2배`로 표시한다. 각도 기호는 `°`를 사용한다.
- 크기·색상·정답 표시가 답을 암시하지 않도록 보기의 재질과 색을 동일하게 유지한다.
- 교재 캡처는 유형·수준 참고만 하며, 이미지·교사용 답안·문제를 복제하지 않는다.

## 게임 흐름

영역 선택 → 원리 및 별도 예시 → 기준과 보기 관찰 → 선택 → 실제 변환 확인 → 다음 문제.
한 번에 5문항이며 다시 연습하면 같은 영역의 나머지 5문항을 사용한다.
평행이동·회전에서는 앞의 3문항을 보기로 판단하고 마지막 2문항은 직접 조작한다.
두 격자의 크기는 같으며, 원래 도형과 학생이 움직인 도형을 비교한다. 미리 정답 도형을 표시하지 않는다.
드래그·터치와 방향/회전 버튼, 키보드로 같은 좌표 상태를 조작하고 최종 도형으로 채점한다.
평행이동은 한 칸씩, 회전은 90°씩 맞춘다. 회전 중간 경로나 클릭 횟수를 평가하지 않는다.
정답 후에만 변환 과정을 표시한다. 다시 풀기나 영역 전환은 조작 상태를 초기화한다.
오답에서는 선택한 보기의 실제 좌표 차이를 계산하여 방향·거리·각도·한쪽 길이 변화 등을 구별한다.
모양 관찰 피드백은 달라진 구간과 이웃 선분을 말하며 내부 좌표 단위를 학생에게 노출하지 않는다.
관찰의 정답 확인에서는 잘못된 보기와 겹쳐 다른 부분을 확인할 수 있다.
감속 모션 설정에서는 애니메이션 없이 정확한 최종 위치를 보여 준다.

## 학습지

- 게임에서 넘어온 영역을 기본 선택한다. 직접 열면 모양 관찰 10문항이다.
- 단일 영역의 보유량은 10문항이다. 초과 요청은 명시적으로 10문항으로 조정한다.
- 전체 영역은 최대 20문항이며 20문항 선택 시 각 영역에서 4문항씩 중복 없이 추출한다.
- 본문 한 페이지에는 한 영역만 배치한다. 전체 20문항은 본문 5쪽, 표지 포함 6쪽이다.
- 단일 영역 10문항은 그리기 여백을 확보하여 본문 3쪽, 표지 포함 4쪽이다. 마지막 그리기 두 문항은 가능하면 같은 쪽에 둔다.
- 객관식 그림은 동일한 30mm 정사각형이다. 직접 그리기에는 기준과 빈 모눈을 각각 55mm로 제공한다.
- 영역당 1문항은 객관식, 2~3문항이면 마지막 1문항, 4문항 이상이면 마지막 2문항을 직접 그린다.
- 마지막 그리기에는 평면 다각형을 포함한다. 두 문항이면 열린 꺾은선과 평면 다각형을 함께 제공한다.
- 원래 문제은행 좌표를 덮어쓰지 않는다. 그리기 전용 좌표는 각 축의 순서와 꺾임·중심을 유지하며 모눈 교점에 맞춘다.
- 그리기 표현에는 원문항 ID, 원좌표, 축별 대응표와 변환 조건을 기록하고, 별도의 좌표 계산으로 답을 검산한다.
- 학생용 빈 모눈에는 정답 경로·점선 윤곽·힌트 점을 넣지 않는다. 중심 O가 필요한 영역만 O를 표시한다.
- 표지의 예시는 평가 문항과 별도 도형이다. 표지·정답 전환은 선택 문항과 순서를 유지한다.
- 정답 모드에서는 실제 이동 경로·회전 경로·대응 변 또는 다른 구간을 시각적으로 확인한다.

## 검증

- `games/shape-transform/shape-transform.selftest.mjs`: 영역별 연산·오답·고유성 계약, 오류 주입 차단.
- `games/shape-transform/domain-content-audit.mjs`: 독립 좌표, 교차, 길이, 유일 정답 검산.
- `games/shape-transform/notation.selftest.mjs`: 원호의 끝점·방향·화살촉과 4언어 수학 표기 검사.
- `games/shape-transform/choice-feedback.selftest.mjs`: 실제 오답 100개·정답 50개, 보기 재배열과 잘못된 입력 차단.
- `games/shape-transform/manipulation.selftest.mjs`: 평행이동·회전 20문항의 9,940개 조작 상태와 독립 정답 검사.
- `games/shape-transform/manipulation.browsercheck.mjs`: 32개 직접 조작 문항, PC·모바일 터치/취소·키보드·다시 연습·4언어 검사.
- `games/shape-transform/shape-transform.browsercheck.mjs`: 5영역의 PC·모바일 진행, 같은 그림 크기, 4언어, 힌트·정답·다시 연습, 실제 애니메이션.
- `worksheet/shape-transform/workbook.selftest.mjs`: 문항 선택·영역별 페이지·독립 좌표 검사.
- `worksheet/shape-transform/workbook.browsercheck.mjs`: 50문항 렌더 경로, 표지 예시 독립성, 정답·표지 전환, A4 PDF 쪽수, 390/768/1280px 배치.
