# Geometry World 단계·난이도 기준

## 1. 기준

사용자가 직접 확인해 제공한 킨더, 키즈팩토, 초등팩토 1 대표 문항을 기준으로 단계 경계를
정했다. 공개 저장소에는 교재 원문이나 페이지 이미지를 넣지 않고, 확인된 풀이 구조와 범위만
요약한다.

단계는 단순히 그림 크기로 정하지 않는다. 다음 항목을 함께 본다.

- 회전, 합성, 반사, 역추론이 몇 단계 필요한가
- 색, 격자, 방향 화살표, 조각 외곽선이 얼마나 제공되는가
- 직접 관찰인지, 보이지 않는 부분이나 이동 결과의 추론인지
- 답이 하나인 선택·수 문항인지, 여러 답을 허용하는 활동형인지

난이도 `하·중·상`은 같은 단계 안의 세기다. 인접한 `킨더 상`과 `키즈 하`처럼 범위가
겹칠 수 있으며, 이때 문항은 복사하지 않고 배치 ID만 다르게 둔다.

## 2. 단계 경계

| 단계 | 직접 확인 또는 결정한 기준 |
|---|---|
| L0 킨더 | 3~8개의 작은 입체, 반드시 2층 포함, 색·점판·외곽선 도움, 같은 모양 회전 찾기 |
| L1 키즈 | 작은 입체의 회전·두 조각 합성, 색이 있는 여러 방향 관찰, 한 번 접기와 펼치기, 규칙이 보이는 수열 |
| L2 Pre | 초등팩토 1 기준. 2~3층 계단형 세기, 숨은 구조의 분리 질문, 두 조각 보완, 전개·거울·겹침 역추론 |
| L3 입문 | Pre의 풀이 구조를 유지하고 3x3 중심으로 확대, 두 조건 결합과 한 단계 계산 추가 |
| L4 초급 | 4x3~4x4 판, 여러 행·열 비교, 두 단계 계산과 조건 결합 |
| L5 중급 | 4x4와 4~5층, 큰 전체 개수, 규칙의 역질문·증가량과 복합 조건 |

L3~L5는 별도 교재 페이지를 가장하지 않는다. 사용자가 맡긴 범위에 따라 L0~L2에서 확인한
같은 풀이 구조를 유지하면서 크기와 사고 단계만 보수적으로 확장한 내부 난이도 결정이다.

## 3. 쌓기나무 직접 세기

직접 세기(`IC`)는 모든 기둥의 윗면을 읽을 수 있어야 한다. 고정 카메라에서 먼 모서리가 가장
높고, 보는 사람 쪽으로 올수록 높이가 같거나 낮아지는 계단형만 만든다. 그림으로 확인할 수 없는
쌓기나무를 임의로 가정하게 하는 문항은 직접 세기가 아니라 숨은 개수 유형으로 분리한다.

시선도 문항 조건의 일부로 검사한다. 학습지 등각 그림은 `+x, +z, +y` 쪽에서 바라보며,
`x=0, z=0`이 가장 먼 바닥 모서리다. 생성기는 이 시선에서 보이는 `윗면, +x면, +z면`을
기준으로 가까운 기둥이 먼 기둥의 높이 또는 윗면을 가리는지 검사한다. 문항 데이터와 SVG에는
같은 시선 코드 `iso-plus-x-plus-z-v1`을 기록한다. 시선이 바뀌면 같은 높이 지도라도 별도
문항으로 취급한다.

이 원칙은 직접 세기에만 한정하지 않는다. 벽이 있는 숨은 개수, 상자 채우기, 정육면체 완성,
색칠된 면, 구멍, 규칙 그림 등 모든 등각 쌓기나무 문항이 문항 데이터와 SVG에 시선 코드를
가진다. 위에서 더 내려다보는 계단식 사각뿔 그림은 별도 코드 `iso-top-plus-x-plus-z-v1`을
사용한다.

| 단계 | 하 | 중 | 상 |
|---|---|---|---|
| 킨더 | 2~4기둥, 3~5개, 높이 2 | 3~4기둥, 4~6개, 높이 2 | 4기둥, 6~8개, 높이 2 |
| 키즈 | 3~4기둥, 5~7개 | 4~5기둥, 6~8개 | 5~6기둥, 8~11개, 높이 3까지 |
| Pre | 4~5기둥, 6~9개 | 5~7기둥, 8~11개 | 6~8기둥, 10~14개 |
| 입문 | 6~8기둥, 11~16개 | 7~10기둥, 14~22개 | 9~12기둥, 18~28개 |
| 초급 | 8~10기둥, 18~26개 | 10~13기둥, 24~36개 | 12~16기둥, 32~48개 |
| 중급 | 11~14기둥, 26~40개 | 13~16기둥, 36~52개 | 14~16기둥, 48~68개 |

모든 칸은 적어도 한 기둥이 2층 이상이다. `Pre 하`도 킨더의 한 층짜리 소형 문항으로
후퇴하지 않는다.

## 4. 유형별 시작 단계

| 유형 | 시작 단계 | 근거와 제한 |
|---|---|---|
| 똑같이 쌓기 | 킨더 | 3~5개 입체의 회전 비교부터 시작 |
| 쌓기나무 직접 세기 | 킨더 | 작은 2층 모양, 모든 기둥 높이 판독 가능 |
| 쌓기나무 규칙 찾기 | 키즈 | `1, 3, 6` 다음의 네 번째 계단 모양처럼 규칙이 그림에 드러난 경우 |
| 바탕그림 숫자와 개수 | Pre | 칸별 높이 수가 주어지는 초등형 표상 |
| 정육면체 완성 개수 | Pre | 2x2x2부터 시작하고 조각 회전 선택형과는 별도 유형 |
| 상자 채우기 | Pre | 전체 용량과 현재 개수의 차를 계산 |
| 숨은 개수 | 별도 유형 | 직접 세기와 섞지 않으며 가시성 규칙과 단일정답 검증 필요 |
| 여러 방향에서 본 모양 | 키즈~Pre | 키즈는 색·방향 안내형, Pre부터 독립적인 무채색 바탕그림 추론 |

## 5. 응답 형식

- 단일정답: 수 쓰기, 하나 고르기, 정확한 나머지 조각 찾기
- 복수정답: 여러 방법으로 채우기, 여러 방법으로 같은 두 부분 나누기
- 활동형: 점판에 그리기, 접힌 선 그리기, 조각을 실제로 배치하기

복수정답·활동형을 단일정답 자동 채점 문제로 변환하지 않는다.
