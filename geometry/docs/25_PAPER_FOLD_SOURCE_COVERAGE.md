# 색종이 자료 33장 출처 대조표

## 목적

이 문서는 사용자가 이 작업에 첨부한 색종이 자료 33장을 빠짐없이 추적한다. 첨부 이미지는
저장소에 복사하지 않으며, 공개 문서에는 첨부 파일 식별자를 기록하지 않는다.
게임의 생성 문항은 원본 문항을 그대로 복제한 것으로 간주하지 않는다.

상태는 다음과 같이 구분한다.

- `지원`: 원본의 핵심 사고 행동과 응답 방식이 현재 학습지 또는 게임에 있다.
- `부분`: 비슷한 좌표 계산은 있지만 원본의 단계, 모양 또는 응답 방식이 빠져 있다.
- `미지원`: 별도 설계와 생성기가 필요하다.

## 큰 분류

| 영역 | 원본에서 학생이 하는 일 | 현재 판정 |
| --- | --- | --- |
| 접어 자르고 펼치기 | 색칠한 부분이나 절단선을 접은 순서의 반대로 옮겨 완성한다 | 부분 |
| 접어 구멍 뚫고 펼치기 | 중간 펼침과 전체 펼침에서 구멍 위치·모양·개수를 찾는다 | 부분 |
| 접어 세고 계산하기 | 조각·도형별 개수, 잘린 수·남은 수의 합, 맨 위 수를 구한다 | 부분 |
| 접는 방법 거꾸로 찾기 | 가능한 접기, 불가능한 결과, 접는 선을 찾는다 | 미지원 |
| 겹친 색종이 순서 | 보이는 경계를 이용해 맨 위·아래 또는 전체 순서를 찾는다 | 지원(학습지) |
| 방향 추적 | 회전·뒤집기·연속 동작을 추적한다 | 별도 과정 |

## 대표 문항 설계 기준

각 영역은 아래 대표 문항이 먼저 원본과 같은 사고 과정을 재현해야 생성형 확장을 허용한다.

| 대표 | 검증할 화면 흐름 | 통과 조건 |
| --- | --- | --- |
| PF-A01 | 두 번 접기 → 절단 → 한 장 펼치기 → 전체 펼치기 | 새 절단 영역이 매 단계 거울 위치에 나타난다 |
| PF-C03 | 구멍 → 한 번만 펼친 답 → 완전히 펼친 답 | 중간 답을 건너뛰지 않는다 |
| PF-C05 | 혼합 구멍을 한 장씩 펼치기 | 모양과 방향이 보존된다 |
| PF-B09 | 절단선 펼치기 → 조각 분리 → 모양별 분류 | 총수와 도형별 수를 각각 검산한다 |
| PF-B05 | 잘린 원래 칸 표시 → 합 계산 | 기하 추적 전에 합을 보여 주지 않는다 |
| PF-C06 | 가능한 겹침 판정 → 접는 선 표시 | 두 부분의 합동과 겹침을 독립 검산한다 |
| PF-C10 | 겹침 쌍 찾기 → 부분 순서 → 전체 순서 | 유일한 전체 순서가 있을 때만 출제한다 |

## 출시 게이트

1. `지원`으로 바꾸려면 대표 원본, 생성 데이터, 학생 화면, 풀이 화면, 정답지의 대응을 확인한다.
2. 게임의 직접 터치는 보이지 않는 다음 버튼이 아니라 종이의 실제 면과 정확히 일치해야 한다.
3. 두 번 이상 접기는 마지막 접기부터 한 장씩 펼치며 중간 상태를 보존한다.
4. 구멍 모양과 절단 영역은 위치뿐 아니라 모양·방향도 좌표 데이터로 검산한다.
5. 데스크톱, 390px 세로, 모바일 가로, A4 문제지와 답안지를 실제 렌더로 확인한다.
6. `미지원` 유형은 메인 화면에서 완성된 과정처럼 소개하지 않는다.
