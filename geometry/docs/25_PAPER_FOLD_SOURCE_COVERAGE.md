# 색종이 자료 33장 출처 대조표

## 목적

이 문서는 사용자가 이 작업에 첨부한 색종이 자료 33장을 빠짐없이 추적한다. 첨부 이미지는
저장소에 복사하지 않으며, 공개 문서에는 첨부 파일 식별자를 기록하지 않는다.
게임의 생성 문항은 원본 문항을 그대로 복제한 것으로 간주하지 않는다.

상태는 다음과 같이 구분한다.

- `지원`: 원본의 핵심 사고 행동과 응답 방식이 현재 학습지 또는 게임에 있다.
- `부분`: 비슷한 좌표 계산은 있지만 원본의 단계, 모양 또는 응답 방식이 빠져 있다.
- `미지원`: 별도 설계와 생성기가 필요하다.

## 대표 문항 설계 기준

각 영역은 아래 대표 문항이 먼저 원본과 같은 사고 과정을 재현해야 생성형 확장을 허용한다.

| 대표 | 검증할 화면 흐름 | 통과 조건 |
| --- | --- | --- |
| PF-A01 | 두 번 접기 → 절단 → 한 장 펼치기 → 전체 펼치기 | 새 절단 영역이 매 단계 거울 위치에 나타난다 |
| PF-C03 | 구멍 → 한 번만 펼친 답 → 완전히 펼친 답 | 중간 답을 건너뛰지 않는다 |
| PF-C05 | 혼합 구멍을 한 장씩 펼치기 | 모양과 방향이 보존된다 |
| PF-B09 | 절단선 펼치기 → 조각 분리 → 모양별 분류 | 총수와 도형별 수를 각각 검산한다 |
| PF-B05 | 잘린 원래 칸 표시 → 합 계산 | 기하 추적 전에 합을 보여 주지 않는다 |
| PF-C06 | 가능한 겹침 판정 → 접는 선 표시 | 두 부분의 합동과 겹침을 독립 검산한다 |
| PF-C07 · PF-C08 | 종이 제시 → 만들 수 있는 결과 모두 선택 | 오답은 전수 탐색으로 불가능을 증명한 것만 쓴다 |
| PF-C10 | 겹침 쌍 찾기 → 부분 순서 → 전체 순서 | 유일한 전체 순서가 있을 때만 출제한다 |

## 접는 방법 거꾸로 찾기의 현재 범위

게임 레벨 3 `접는 방법 거꾸로 찾기`는 두 가지 상호작용을 가진다.

| 상호작용 | 학생이 하는 일 | 정답 계약 |
| --- | --- | --- |
| 접는 선 찾기 | 종이와 한 번 접은 결과를 보고 종이 위 후보 선을 직접 누른다 | 단일정답 |
| 만들 수 있는 결과 모두 찾기 | 결과 보기 넷 중 한 번 접어 만들 수 있는 것을 모두 누른다 | 복수정답(정답 2 · 오답 2) |

검산 기준은 다음과 같다.

- 결과 도형은 합집합 다각형을 계산하지 않고 고정된 조각과 반사된 조각을 그대로 보관한다.
- 도형 동일성은 해상도 181과 257의 내부 판정이 모두 일치할 때만 같다고 본다.
- 비교는 위치·회전 불변이 아니라 화면에 놓인 좌표 그대로 한다.
- 각도 0~179도를 1도 간격, 오프셋을 각 각도의 투영 구간에서 200단계로 훑어
  종이마다 36,180개의 접는 선을 전수 탐색한다. 오답 후보는 그중 어느 것으로도
  만들어지지 않아야 하고, 정답 선은 탐색에서 찾은 모든 일치가 같은 직선이어야 한다.
- 검사는 `geometry/games/paper-fold/reverse-fold.selftest.mjs`와
  `geometry/games/paper-fold/reverse-fold.browsercheck.mjs`가 담당한다.

세 행의 판정을 `지원`으로 올리려면 원본 33장의 실제 도형과 보기를 대조해야 한다.
현재는 학습 행동만 구현했고 원본 대조는 하지 않았다.

## 출시 게이트

2026-10-17 숫자 색종이 게임 추가: PF-A04·A05·B05·B06의 `잘린 원래 칸 표시 → 합 계산`을
내부 창작 40모양으로 구성했다. 현재는 사용자의 놀이 중심 요청에 따라 직접 접고 자르고
펼쳐 조각을 수집하는 UI다. 기본은 합을 보여 주고, 2026-10-18 추가한 도전은 모두 담은 뒤 합을 입력해 확인한다.
잘린 조각과 남은 종이는 별도 20모양씩이며 공식 성적·성취도 판정으로 사용하지 않는다.
기존 학습지와 칸 대응·합 계산을 공유한다. 원본 33장과 새 게임의 숫자·그림을 직접 대조한
것은 아니므로 원본 전체 지원 판정을 확대하지 않는다. PF-A06·B07의 대각선 등은 기존 상태다.

1. `지원`으로 바꾸려면 대표 원본, 생성 데이터, 학생 화면, 풀이 화면, 정답지의 대응을 확인한다.
2. 게임의 직접 터치는 보이지 않는 다음 버튼이 아니라 종이의 실제 면과 정확히 일치해야 한다.
3. 두 번 이상 접기는 마지막 접기부터 한 장씩 펼치며 중간 상태를 보존한다.
4. 구멍 모양과 절단 영역은 위치뿐 아니라 모양·방향도 좌표 데이터로 검산한다.
5. 데스크톱, 390px 세로, 모바일 가로, A4 문제지와 답안지를 실제 렌더로 확인한다.
6. `미지원` 유형은 메인 화면에서 완성된 과정처럼 소개하지 않는다.

## 2026-10-18 원자료 실제 열람 후 정정

Mac에서 기존 Drive 원본 PNG33장을 열고 보존본과 크기·SHA-256을 모두 대조했다.
원본 파일과 식별자는 기존 원자료 Drive·작업 검수 기록에 보존한다. 첫 시각 대조에서 다음을 정정했다.

- PF-B01은 처음 종이가4x4 격자다. 기존3x3 표기를 수정했다.
- PF-A06·B07은 대각선을 두 번 접는 숫자 종이다.
- PF-A12는 대각선 한 번 접기이고, PF-C01의 숫자1~16은 삼각 칸이다.
- PF-B06 원문은 잘려나간 수의 합이다. 사용자가 요청한 남은 수 게임은 별도 확장으로 보존한다.
- PF-C08의 시작 종이는 사각형이다. 기존 오각형·L자 연습은 추가 연습이며 원문 도형과 구별한다.

새 `games/paper-craft/`와 연계 학습지는 학습 행동을 내부 창작 문항으로 구현하는 **로컬 초안**이다.
33개 참조·126개 연습 변형은 원본126문항 또는 서로 다른126개 도형이라는 뜻이 아니다.
원문의 그림·숫자·정답을 복제한 것으로 소개하지 않는다.
새 게임의 학생 화면과 풀이·PDF 검수가 끝나기 전에는 기존 판정을 일괄 `지원`으로 올리지 않는다.

## 2026-10-18 새 공방의 학습 행동 지원표

원자료33장 전부를 열람하고 보존 색인의 이름·크기·체크섬과 대조했다. 아래는 새
`games/paper-craft/`와 `worksheet/paper-craft/`의 **학습 행동 지원** 판정이다.
원문의 숫자·무늬·공식 정답·보기 개수를 그대로 복제했다는 뜻이 아니다. 각 ID는
