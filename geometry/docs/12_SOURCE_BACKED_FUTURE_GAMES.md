# GFIELD Geometry World 자료 기반 후속 게임 설계

## 1. 설계 원칙

이 문서는 RAY와 프리즘 교재에서 확인한 도형 활동을 그대로 복제하지 않고, Geometry World에 맞는
새 게임 규칙으로 재구성한 후속 개발 기준이다. 원본 파일과 개인 드라이브 경로는 공개 저장소에 넣지
않으며, 자료명과 확인한 PDF 페이지 범위만 근거로 남긴다.

- 현재 완성된 Cube Town과 색종이 공방의 학습 목표를 반복하지 않는다.
- 한 화면에는 하나의 핵심 행동만 둔다. 모바일은 가로 화면에서 스크롤 없이 조작한다.
- 모든 게임은 5레벨, 레벨별 검수된 문제은행 10문제, 한 회차 5문제를 기본으로 한다.
- 첫 진입의 첫 문제만 튜토리얼을 제공하고 이후에는 힌트를 요청할 때만 안내한다.
- 문제는 자동 생성할 수 있어도 정답의 유일성, 물리적 가능성, 난이도를 사전 검증한다.
- 한국어, 중국어, 일본어, 영어와 기존 프로필, 포인트, 캐릭터 성장 규칙을 공유한다.
- 같은 문제 데이터로 게임과 인쇄 학습지를 만들되, 종이에서 불편한 조작은 인쇄용 활동으로 바꾼다.

## 2. 현재 게임과의 경계

| 현재 영역 | 이미 다루는 내용 | 후속 게임에서 피할 중복 |
|---|---|---|
| Cube Town | 쌓기, 개수, 숨은 블록, 세 방향, 투명 케이스, 최대·최소 | 단순 큐브 쌓기와 개수 세기 |
| 색종이 공방 | 접기, 펼치기, 자르기, 구멍, 회전, 반사 | 종이를 접고 자르는 대칭 문제 |
| 큐브 조각 연구소 | 회전한 큐브 조각으로 빈자리 맞추기 | 소마큐브 조각 하나만 고르는 문제 |

따라서 거울 활동은 종이가 아닌 물체·문자·좌표를 사용하고, 소마큐브는 여러 조각을 실제로 결합하는
상위 활동으로 만든다. 전개도는 주사위와 다면체의 면 관계를 핵심으로 삼는다.

## 3. 월드맵과 개발 순서

### 공개 A - 거울 저택과 점판 공작소

현재 월드맵의 `Mirror Manor`, `Geoboard Home Yard`를 실제 게임 입구로 완성한다. 기존 2D 입력과
반사 계산을 재사용할 수 있어 가장 먼저 제작하기 좋다.

### 공개 B - 도형 조각 정원

`Tangram Home Garden` 안에 `폴리오미노 퍼즐`과 `똑같이 나누기`를 각각 독립 게임으로 둔다.
두 게임은 같은 격자, 드래그, 회전, 정답 검증 엔진을 공유한다.

### 공개 C - 전개도 전망대와 소마큐브 공방

`Dice Vista`에는 전개도 전망대를, Cube Town의 상위 연구 구역에는 소마큐브 공방을 연다.
둘 다 3D 검증이 필요하므로 2D 게임을 안정화한 뒤 진행한다.

### 공개 D - 길 잇기 산책로

월드맵의 길 자체를 짧은 퍼즐로 사용한다. 캐릭터가 완성한 길을 따라 다음 장소로 걸어가게 하면
내비게이션과 미니게임이 자연스럽게 연결된다.

## 4. 게임 1 - 거울 저택

### 핵심 경험

가운데 거울선을 기준으로 물체, 무늬, 글자, 좌표를 반대편에 완성한다. 접힌 종이를 펼치는 게임이
아니라 실제 거울 속 방향과 위치를 이해하는 게임이다.

| 레벨 | 활동 |
|---:|---|
| 1 | 반쪽 그림의 나머지를 칸 단위로 색칠하기 |
| 2 | 도미노와 간단한 물체를 거울 반대편에 끌어 놓기 |
| 3 | 삼각 격자와 사각 격자에서 같은 거리의 위치 찾기 |
| 4 | 방향이 있는 글자·기호·화살표를 정확히 반사하기 |
| 5 | 가로·세로 거울 두 개와 일부 가려진 무늬 완성하기 |

2026-08-27 현재 거울 저택 레벨 1~3을 공개한다. 레벨 3은 사각 격자 5문제와 삼각 격자
5문제로 구성되며, 각 문제에서 기준 점 하나와 보기 점 세 개를 보여 주고 거울선까지의
거리와 같은 줄을 만족하는 점 하나만 고르게 한다. 정답 점은 `reflectCell`로 계산하고,
각 문제의 사각 격자 전수 후보가 1개인지, 거리 오답과 줄 오답 보기가 각각 존재하는지
`validateDistance`와 독립 self-test에서 다시 확인한다.

2026-08-27 레벨 4를 추가 공개한다. RAY C1-1 플러스북 p.19-23의 "거울에 비친 글자"
활동처럼 글자·단어·기호를 세로 거울 앞에 두고, 모바일에서는 직접 쓰기 대신 세 보기 중
좌우가 반전된 하나를 고르게 한다. 10문제 중 7문제는 원본에 나온 자모·글자·단어,
1문제는 영문자, 2문제는 위아래·대각선 화살표로 구성한다. 영문자와 화살표는 같은 반사
규칙의 내부 확장으로 표시하며, 정답 역할은 문제당 하나만 허용한다.

2026-08-27 레벨 5를 사용자 승인 내부 확장으로 추가 공개한다. 정확히 대응하는 교재 원문은
현재 출처 메모리에서 확인되지 않았으므로 원본 문항으로 표기하지 않는다. 8×6 격자의 왼쪽 위
사분면에 2~7개의 칸을 주고, 가운데 세로·가로 거울에 비친 나머지 세 사분면을 완성한다.
10문제의 정답 칸은 손으로 입력하지 않고 각 원본 칸을 두 축에 반사해 계산하며, 독립 self-test가
세 복사본의 중복·누락·범위·원본 겹침과 단일 정답을 다시 검산한다.

- 놓는 동안 원본과 거울선까지의 거리를 얇은 점선으로 보여 준다.
- 정답 후보는 모양만 같은 오답, 방향만 틀린 오답, 거리가 한 칸 틀린 오답으로 제한한다.
- 학습지에서는 거울 반대편 그리기, 좌표 쓰기, 올바른 반사 그림 고르기를 제공한다.
- 근거: RAY plus C1-1, PDF p.7-10(거울선에 비친 모자·리본 반사 활동), p.19-23
  (거울에 비친 글자 활동) 및
  `geometry.mirror-manor.ray-c1-1-reflection` 출처 기록. 레벨 3의 사각·삼각 점 보기
  확장은 이 원리를 모바일 선택 활동으로 재구성한 내부 설계이며, 레벨 4 영문자·화살표와
  레벨 5 두 거울 문제는 원본 문항 복사가 아닌 같은 원리의 내부 확장이다. 공개 전
  50문제·4개 언어·단일 정답 검증을 통과한다.

## 5. 게임 2 - 점판 공작소

### 핵심 경험

점판의 못을 터치해 고무줄을 걸고 도형을 만든다. 완성된 모양을 단순히 고르는 데서 끝내지 않고,
같은 조건을 만족하는 다른 도형을 찾아 공간 구성 능력을 기른다.

| 레벨 | 점판 | 활동 |
|---:|---|---|
| 1 | 정사각 점판 | 점 두 개를 이어 선분과 열린 모양 만들기 |
| 2 | 정사각 점판 | 제시된 삼각형·사각형·오각형을 같은 위치에 만들기 |
| 3 | 정사각 점판 | 반듯한 정사각형과 기울어진 정사각형의 종류·전체 개수 찾기 |
| 4 | 삼각 점판 | 점 세 개를 이어 크기·방향이 다른 정삼각형의 종류·전체 개수 찾기 |
| 5 | 복합 점판 | 점과 선 그림에 숨은 삼각형·사각형을 빠짐없이 찾아 세기 |

- 점을 누른 순서대로 선이 생기며 마지막 점을 처음 점에 연결하면 도형이 닫힌다.
- 자기 교차, 겹친 선, 중복 꼭짓점은 규칙에 따라 즉시 표시한다.
- Geoboard의 사용자 표시 용어는 `점판`으로 통일한다.
- 정사각 격자점만으로 정확한 정삼각형을 만들 수 없으므로 정삼각형 문제는 삼각 점판에서만 출제한다.
- `서로 다른 종류`는 평행이동만 다른 모양을 같은 종류로 묶고, `전체 개수`는 점판의 서로 다른 위치를 각각 센다. 문제 문구와 채점 데이터에 어느 기준인지 명시한다.
- 정사각형과 정삼각형은 가능한 꼭짓점 조합을 전수 열거해 정답을 계산한다. 손으로 입력한 개수와 열거 결과가 다르면 문항을 잠근다.
- 점 세 개를 잇는 일반 삼각형 문제는 정사각 점판에서 먼저 다룬다. `3x3` 점판에는 실제 배치 76개와 합동 기준 8종류가 있어, 어린 단계에서는 전체 76개를 한꺼번에 세게 하지 않고 조건에 맞는 종류를 만들거나 작은 후보군에서 찾게 한다.
- 정사각형은 반드시 점 네 개를 잇는다. 정사각 점판의 검산 기준은 `3x3: 3종류/6개`, `4x4: 5종류/20개`, `5x5: 8종류/50개`다.
- 정삼각형은 점 세 개를 잇되 삼각 점판에서만 다룬다. 한 변의 점이 3·4·5개인 삼각 점판의 검산 기준은 각각 `2종류/5개`, `4종류/15개`, `6종류/35개`다.
- `종류`는 합동인 도형을 하나로 묶고, `전체 개수`는 점의 위치가 다르면 따로 센다. 문제 화면에는 반드시 어느 값을 묻는지 한 가지만 표시한다.
- 레벨 3·4의 `종류 찾기`는 아이가 목표 개수만큼 서로 다른 합동 종류를 직접 만들어 수집한다. 같은 종류를 위치나 방향만 바꿔 다시 만든 경우에는 새 종류로 세지 않는다.
- 레벨 3·4의 `전체 개수`는 못 선택 조작과 섞지 않고, 전수 열거로 확정한 하나의 수를 숫자 보기에서 고른다. 오답을 눌러도 정답을 노출하지 않는다.
- 현재 공개 문제는 레벨 1·2의 위치·방향 재현 25문제, 레벨 3·4의 격자 탐색 20문제,
  레벨 5의 원본 대조 복합도형 5문제로 총 50문제다. 레벨 5는 한 그림에서 삼각형을 먼저
  세고 사각형을 이어서 세는 2단계 선택형이다. 점 위치·모눈 간격·기본선·추가 굵은 선을
  PDF p.38·46의 다섯 그림과 각각 대조하고, 점이 없는 교차 위치는 꼭짓점으로 만들지 않는다.
  두 답은 선분 연속성 전수 열거와 독립 표본·순열 계산이 일치한 문항만 공개한다.
- 학습지에서는 점판에 도형 그리기, 삼각형·사각형 개수 세기, 조건에 맞는 다른 답 그리기를 제공한다.
- 근거: RAY B1-2, PDF p.36(점판에 삼각형·사각형·오각형 만들기),
  p.38·46(점과 선으로 된 그림에서 삼각형·사각형 개수 세기). 원본 페이지를 2026-08-20에
  시각 확인했다. 레벨 1의 열린 선 활동은 교재 본 활동에 들어가기 위한 게임 조작 연습이며,
  레벨 2와 레벨 5는 교재 활동에 직접 연결한다. 레벨 3·4의 격자별 정사각형·정삼각형 탐색은
  2026-08-27 사용자 결정이며, 교재 원본 대조와 전수 열거 검산을 통과한 문항만 공개한다.

## 6. 게임 3 - 폴리오미노 퍼즐

### 핵심 경험

격자 조각을 돌리고 뒤집어 분류하고, 빈 판을 빈틈과 겹침 없이 채운다. 탱그램처럼 윤곽만 맞추는
것이 아니라 단위 정사각형의 연결과 정확한 덮기를 학습한다.

| 레벨 | 활동 |
|---:|---|
| 1 | 도미노와 트로미노를 같은 조각끼리 모으기 |
| 2 | 회전하면 같은 조각과 뒤집어야 같은 조각 구분하기 |
| 3 | 같은 조각으로 작은 직사각형과 생활 그림 덮기 |
| 4 | 펜토미노를 분류하고 일부가 놓인 판 완성하기 |
| 5 | 제한된 조각으로 큰 판 채우기와 다른 해법 찾기 |

- 조각은 드래그, 90도 회전, 뒤집기를 명확히 분리한다.
- 정답이 하나여야 하는 문제는 정확 덮기 탐색으로 유일성을 검증한다.
- 여러 답이 목표인 문제에는 이미 찾은 해법과 회전·반사만 다른 해법을 같은 답으로 처리한다.
- 학습지에서는 같은 조각 찾기, 남은 조각 고르기, 격자 채우기를 제공한다.
- 근거: RAY A4-2, PDF p.8-26 및 p.30-48.

## 7. 게임 4 - 똑같이 나누기

### 핵심 경험

격자 위에 선을 그어 전체 도형을 같은 넓이 또는 합동인 조각으로 나눈다. 하나의 모범 답만 따라
그리지 않고 조건을 만족하는 여러 해법을 인정한다.

| 레벨 | 활동 |
|---:|---|
| 1 | 한 줄로 같은 넓이 두 부분 만들기 |
| 2 | 두 줄 이상으로 같은 넓이 3~4부분 만들기 |
| 3 | 같은 넓이이면서 연결된 조각 만들기 |
| 4 | 서로 포개지는 합동 조각으로 나누기 |
| 5 | 생활 배치와 복합 윤곽을 여러 방법으로 나누기 |

- 선은 격자점 사이에만 그리며 되돌리기와 지우기를 제공한다.
- 넓이만 같은 단계와 회전·반사하면 포개지는 합동 단계를 섞지 않는다.
- 검증기는 각 영역의 넓이, 연결성, 정규화된 모양을 함께 비교한다.
- 학습지에서는 자르는 선 그리기와 두 해법 비교하기를 제공한다.
- 근거: 프리즘 D1-1, PDF p.8-20; 프리즘 E4-3, PDF p.7-26.

## 8. 게임 5 - 전개도 전망대

### 핵심 경험

평면 전개도를 접어 입체가 되는 과정을 보고, 서로 마주 보는 면과 만나는 면, 기호의 방향을 추론한다.
잘못된 전개도는 접는 도중 면이 겹치는 장면으로 이유를 보여 준다.

| 레벨 | 활동 |
|---:|---|
| 1 | 정육면체가 되는 전개도 고르기 |
| 2 | 전개도를 단계별로 접고 완성 입체 고르기 |
| 3 | 주사위의 서로 마주 보는 면과 이웃한 면 찾기 |
| 4 | 글자·화살표·색이 있는 면의 완성 방향 추론하기 |
| 5 | 정사면체·정팔면체 등 규칙적인 입체의 면 관계 탐구하기 |

- 전개도를 손으로 임의 변형하지 않고 면 단위 힌지 애니메이션으로 접는다.
- 모든 문제는 실제로 접었을 때 면 겹침이 없는지 3D로 검증한다.
- 답이 여러 개인 문제는 조건에 맞는 답을 모두 선택하도록 문장을 분명히 한다.
- 학습지에서는 전개도 판별, 반대 면 쓰기, 완성된 입체 고르기를 제공한다.
- 근거: 프리즘 D4-1, PDF p.8-25; 프리즘 E4-1, PDF p.7-26.

## 9. 게임 6 - 소마큐브 공방

### 핵심 경험

일곱 소마큐브 조각을 여러 방향으로 돌려 목표 입체를 완성한다. 기존 큐브 조각 연구소의 회전과
충돌 검사를 재사용하되, 한 조각 고르기가 아니라 여러 조각을 끝까지 조립하는 상위 게임으로 만든다.

| 레벨 | 활동 |
|---:|---|
| 1 | 회전된 소마 조각을 같은 조각끼리 찾기 |
| 2 | 두 조각으로 제시된 작은 입체 만들기 |
| 3 | 세 조각으로 윤곽과 세 방향 그림 맞추기 |
| 4 | 일부가 완성된 3x3x3 큐브의 나머지 채우기 |
| 5 | 일곱 조각으로 목표 입체 완성하고 다른 조립법 찾기 |

- 24가지 정육면체 회전을 정규화해 같은 조각을 판정한다.
- 배치 중 겹침과 공중에 뜬 조각을 막고, 가능한 스냅 위치만 옅게 표시한다.
- 유일한 답 문제와 여러 조립법 문제를 데이터에 명시한다.
- 학습지에서는 회전해 같은 조각 찾기, 필요한 조각 고르기, 세 방향 그림 맞추기를 제공한다.
- 근거: RAY A4-1, PDF p.32-48.

## 10. 게임 7 - 길 잇기 산책로

### 핵심 경험

길이 그려진 타일을 돌려 출발점과 목적지를 연결한다. 완성하면 대표 캐릭터가 실제 월드맵 길을
따라 걸어가 다음 장소에 도착한다.

| 레벨 | 활동 |
|---:|---|
| 1 | 타일 1~2개 돌려 한 갈래 길 연결하기 |
| 2 | 막힌 길을 피해 시작과 끝 연결하기 |
| 3 | 두 목적지에 모두 닿는 갈림길 만들기 |
| 4 | 제한된 회전 횟수 안에 길 완성하기 |
| 5 | 일부 그림과 길 단서로 숨은 타일 방향 추론하기 |

- 연결선은 타일 변의 가운데에서만 만나도록 데이터화한다.
- 출발점에서 탐색해 목적지 도달 여부, 끊긴 길, 불필요한 고리를 검증한다.
- 학습지는 타일 방향 그리기, 올바른 타일 고르기, 최단 회전 수 쓰기로 바꾼다.
- 근거: RAY B4-2, PDF p.54-64.

## 11. 공통 문제 데이터와 검증

```js
const futureProblem = {
  id: "mirror-l2-01",
  game: "mirror-manor",
  level: 2,
  interaction: "drag-reflection",
  promptKey: "mirror.l2.01.prompt",
  scene: {},
  answer: {},
  validation: {
    solutionCount: 1,
    allowRotationEquivalent: false,
    allowReflectionEquivalent: false
  },
  worksheet: {}
};
```

출시 전 문제 검증은 다음을 자동화한다.

1. 좌표와 조각이 판 범위를 벗어나지 않는지 검사한다.
2. 정답이 없거나 의도보다 많은 문제를 제외한다.
3. 회전·반사만 다른 중복 문제를 같은 문제군으로 묶는다.
4. 한 회차에 같은 문제군이 두 번 나오지 않게 한다.
5. 최근 푼 문제보다 아직 풀지 않은 문제를 우선한다.
6. 문제 이미지와 선택지가 모바일 가로 화면에서 잘리지 않는지 캡처 검사한다.
7. 게임 정답과 학습지 정답이 같은 데이터에서 계산되는지 비교한다.

## 12. 공통 화면과 피드백

- 상단에는 작은 워터마크, 진행 수, 음소거, 나가기만 둔다.
- 오른쪽 도구막대는 현재 단계에서 필요한 도구만 보여 준다.
- 정답을 제출하는 `확인`은 필요한 게임에만 사용하고, 자동 판정이 자연스러운 활동은 즉시 피드백한다.
- 잘못된 조작에는 칭찬 음성을 재생하지 않는다. 짧은 효과와 옅은 위치 표시만 제공한다.
- 성공 시 `GOOD JOB!`, `GREAT JOB!`, `SUCCESS!` 중 하나를 강한 1초 연출과 함께 재생한다.
- 캐릭터는 첫 튜토리얼, 요청한 힌트, 레벨 완료에만 말한다.
- 레벨 완료 후에는 `같은 레벨 더 풀기`, `다음 레벨`, `마을로`를 제공한다.

## 13. Geometry World 밖으로 보낼 활동

확인 자료에는 색 스도쿠, 숫자 행렬, 마방진, 규칙 찾기, 수론, 전략 게임도 포함되어 있다. 이들은
좋은 활동이지만 Geometry World에 넣으면 지도와 학습 목표가 흐려진다. 수 배열과 색 스도쿠는
Number Magic, 논리 추론과 전략 게임은 별도 Logic 지역의 후보로 기록하고 이번 Geometry 개발
범위에서는 제외한다.

## 14. 권장 첫 구현

첫 구현은 `거울 저택 레벨 1~2`로 한다. 반사 변환, 드래그 스냅, 다국어, 첫 문제 튜토리얼을
공통 모듈로 완성한 뒤 레벨 3~5를 확장한다. 다음으로 같은 2D 장면 체계를 재사용할 수 있는
`점판 공작소`를 개발한다. 두 게임이 모바일 실기기 검수를 통과한 뒤 폴리오미노와 도형 분할의
공용 격자 엔진을 만든다.
