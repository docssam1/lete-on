# 소마큐브 공방 50문제 독립 검산

작성일: 2026-08-31

## 학습 순서

| 단계 | 수준·난이도 | 활동 | 추론·조작 단위 |
|---:|---|---|---:|
| 1 | 키즈·하 | 돌아간 조각과 같은 조각 찾기 | 1 |
| 2 | Pre·하 | 낮고 바닥에 닿은 목표를 두 조각으로 만들기 | 2 |
| 3 | 입문·중 | 서로 다른 세 조각으로 같은 모양 만들기 | 3 |
| 4 | 초급·중 | 고정 조각을 보고 3→4→5조각 채우기 | 3~5 |
| 5 | 중급·상 | 5→6조각으로 서로 다른 두 조립법 만들기 | 6~7 |

첫 회차는 쉬운 문제, 두 번째 회차는 더 많은 조각과 높은 목표를 사용한다. 1단계는 V 조각의
두 보기부터 시작하고, 4단계는 고정 조각 4개에서 2개로, 5단계는 2개에서 1개로 줄어든다.

## 발견하고 고친 문제

- 기존 `soma-l2-10`은 목표 전체가 바닥에서 한 칸 떠 있어 첫 조각을 놓을 수 없었다.
- 2·3단계 목표 전체를 24방향으로 돌려 가장 낮은 자세를 고르고 바닥 높이를 0으로 맞췄다.
- 4·5단계의 어려운 문항이 먼저 나오던 순서를 이동 조각 수가 늘어나는 순서로 바꿨다.
- 4단계와 5단계가 같은 고정 조각 배치를 반복하지 않도록 생성 단계에서 제외했다.
- 첫 힌트는 조각 또는 오답 하나만 알려 주고, 두 번째 힌트에서 방향과 위치를 보여 준다.
- 최종 성공은 약 1초 뒤 다음 문제로 자동 이동한다. 5단계의 첫 조립은 같은 문제에 남고,
  두 번째로 다른 조립법까지 완성한 뒤에만 이동한다.
- 마지막 단계의 완료 화면에서는 존재하지 않는 `다음 단계` 버튼을 숨긴다.
- 움직임 줄이기 환경에서는 반복 애니메이션을 끄고 성공 뒤 기다리는 시간도 줄인다.

## 독립 계산

검산기는 게임의 회전 정규화와 정확 덮기 함수를 정답 계산에 재사용하지 않는다.

- 별도 회전 행렬로 정육면체의 24방향 확인
- 일곱 소마 조각이 회전으로 서로 다른 모양이며 전체 부피가 27인지 확인
- 1단계 열 문제 모두 회전 동치 정답이 하나인지 확인
- 2~4단계의 정확 덮기와 바닥에서 시작 가능한 조립 순서 확인
- 5단계 열 문제마다 전체 회전으로 같지 않은 해가 두 개 이상인지 확인
- 저장된 두 조립법이 고정 조각을 포함하고 27칸을 빈틈·겹침 없이 채우는지 확인
- 50개 ID, 완전히 같은 문제, 4·5단계의 같은 시작 배치 중복 확인
- 모든 문항의 `reasoningSteps`와 `internal-variation` 출처 구분 확인

## 자동 검사

```text
node geometry/games/soma-cube/soma-cube-content-audit.mjs
node geometry/games/soma-cube/soma-cube.selftest.mjs
node geometry/games/soma-cube/soma-cube.browsercheck.mjs
node geometry/geometry-release.browsercheck.mjs
```

브라우저 검사는 1~5단계, Pre의 두 번째 다섯 문제, 단계형 힌트, 일반·움직임 줄이기 자동
진행, 중급의 서로 다른 두 조립법, 마지막 단계 완료 화면, 네 언어 가로 화면과 세로 안내를
확인한다. 자가검사는 목표를 바닥에서 띄우거나 추론 단계를 0으로 바꾼 복사본을 넣어 두 오류를
모두 잡는지도 확인한다.

## 출처 경계

RAY Kids A4-1은 회전 동치와 2~3조각 합성 활동의 비공개 개념 근거다. 공개된 문제는 원본
판면이나 답안을 복제하지 않은 내부 변형이다. 4~5단계의 3×3×3 완성과 두 조립법은 같은 조작
원리를 확장한 GFIELD 내부 도전으로 구분한다.
