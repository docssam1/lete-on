# GFIELD 색종이 접고 펼치기 게임

## 학습 범위

게임은 활동 목표가 다른 두 영역을 분리한다.

1. `색종이 접어 자르기`: 한 번 또는 두 번 접고 자른 절단선을 펼쳐 조각 수를 구한다.
2. `색종이 접어 구멍 뚫기`: 한 번 또는 두 번 접고 뚫은 구멍의 위치와 개수를 구한다.

가로·세로·대각선과 접기 횟수는 별도 대단원이 아니라 각 영역 안의 난이도 조건이다.
숫자 합과 겹친 색종이 순서는 기존 문제은행 학습지로 분리하고, 회전·뒤집기는
`paper-turn`에서 다룬다. 전체 분류는 `24_PAPER_ACTIVITY_CURRICULUM.md`를 따른다.

## 문제 흐름

1. 접힌 뒤 종이가 놓이는 쪽이나 펼칠 때 대칭을 더 그릴 쪽을 고른다.
2. 두 번 접기는 첫 번째와 두 번째 접기를 순서대로 확인한다.
3. 접은 순서의 반대로 펼친다.
4. 조각 수, 구멍 수, 펼친 결과 또는 연결 상대를 고른다.

각 선택은 확인 버튼 없이 즉시 채점한다. 선 잇기는 세 연결이 완성되는 즉시 검사하고,
틀린 연결만 지워 다시 시도하게 한다.

## 세션

- 기본 세션은 10문제이며 이어서 최대 20문제까지 푼다.
- 한 세션에는 개별 선택과 선 잇기가 모두 포함된다.
- 최근 20문항 ID를 기억해 다음 세션에서 우선 제외한다.
- `?count=20`이면 처음부터 20문제를 구성한다.

## 데이터

`geometry/games/paper-fold/curriculum.js`가 게임과 게임 연계 학습지의 공용 원본이다.
각 영역은 결정적으로 생성한 36문항을 가진다.

- 자르기: `piece-count`, `connect-match`
- 구멍: `hole-count`, `hole-result`, `connect-match`
- `folds`: 접은 순서
- `stagePolygons`: 단계별 종이 외곽
- `cutSegments` / `unfoldedSegments`: 접힌 절단선과 펼친 절단선
- `punches` / `unfoldedPoints`: 접힌 구멍과 펼친 구멍
- `placementSteps`: 단계별 놓이는 쪽과 선택지

조각 수는 두 해상도의 연결 영역 계산이 일치하는 문항만 채택한다. 접기와 펼치기에는
같은 좌표 데이터를 사용하고, 반사를 두 번 적용하면 원래 점으로 돌아오는지 검사한다.

## 화면과 학습지

- 접기 화살표 머리는 SVG 사용자 좌표에서 9 이하로 고정한다.
- 한 번 접기는 세 장면, 두 번 접어 자르기는 네 장면으로 표시한다.
- 모바일 세로와 가로에서도 그림, 연결선, 선택 버튼이 잘리지 않아야 한다.
- 게임과 학습지는 문항 ID, 접는 순서, 절단선·구멍, 정답을 공유한다.
- 학습지는 A4용 캔버스에 다시 그리며 게임 화면 캡처를 사용하지 않는다.

## 검증 기준

1. 자르기 영역에 구멍 문항이 없고 구멍 영역에 절단선 문항이 없다.
2. 각 영역에 한 번·두 번 접기 문제가 포함된다.
3. 선택 즉시 채점되고 별도 확인 버튼이 없다.
4. 10문제와 추가 10문제가 이어져 20문제에서 종료된다.
5. 데스크톱, 390px 세로, 모바일 가로와 A4 학습지를 실제 렌더로 확인한다.
