# GFIELD 색종이 접기 게임 설계

## 목표

색종이 학습지의 12개 유형을 게임에서는 5개 학습 레벨로 묶는다. 아이는 긴 설명을 읽기보다 종이를 직접 접고, 구멍을 뚫고, 자르고, 다시 펼치며 규칙을 발견한다. 게임과 학습지는 같은 개념 분류와 난이도 용어를 사용한다.

## 캐릭터

- 이름: 폴디(Foldy)
- 역할: Origami Studio Guide
- 형태: 한쪽 모서리가 접힌 정사각 색종이 몸체, 접힌 선, 종이학 배지
- 사용: 레벨 1 첫 문제의 조작 튜토리얼, 힌트, 오답, 레벨 완료에만 등장
- 성장: 레벨 1~5 완료에 따라 민트 → 하늘 → 보라 → 코랄 → 금색 테두리로 종이 색이 변하고 액세서리가 추가된다.
- 저장: 기존 `gfield-profile`에 캐릭터 ID `foldy`를 추가한다. 이름, 포인트, 장착 아이템과 기존 진행 기록은 변경하지 않는다.

## 레벨 구성

| 레벨 | 게임 이름 | 학습지 유형 | 새 조작 |
|---|---|---|---|
| 1 | 반으로 쏙 | hole2, foldtop 기초 | 반짝이는 접는 선을 탭해 한 번 접기 |
| 2 | 구멍 탐정 | hole3d, punch | 대각선 접기, 펀치, 거꾸로 펼치기 |
| 3 | 숫자 접기 | numsum, numcut, numdiag | 숫자 대응, 남은 수/잘린 수 계산 |
| 4 | 자르고 펼치기 | pieces, numinv, unfoldshape | 가위선 선택, 펼친 모양 예측 |
| 5 | 겹침 마스터 | stackfind, stackorder, 혼합 | 위아래 순서와 여러 개념 혼합 |

각 레벨은 한 회차 5문제다. 첫 문제만 안내 모드로 시작하며 이후에는 문제와 필요한 도구만 보인다. 같은 레벨을 다시 연습할 때는 최근 문제를 피한 문제은행 순서를 사용한다.

## 조작 원칙

1. 레벨 1에서는 화면에 접을 종이와 한 개의 강조선만 둔다.
2. 접는 선 또는 강조된 종이 면을 탭하면 접기 애니메이션이 실행된다.
3. 도구는 해당 레벨에서 처음 필요할 때 하나씩 나타난다.
4. 오답은 정답을 바로 노출하지 않고 접힌 방향 또는 펼치는 순서를 짧게 강조한다.
5. 힌트 사용 문제와 건너뛴 문제에는 포인트를 주지 않는다.
6. 레벨 완료 후 `다음 레벨`, `같은 레벨 더 풀기`, `색종이 공방`을 선택한다.

## 학습지 연결

- 색종이 공방의 각 레벨 카드에 `이 레벨 학습지` 버튼을 둔다.
- 학습지에서는 해당 레벨에 포함된 유형 버튼을 미리 선택해 연다.
- 정답지의 거꾸로 펼치기 풀이와 게임의 정답 애니메이션은 같은 순서를 사용한다.
- 게임 문제는 안정적인 ID를 사용하고, 생성 파라미터는 문제 데이터와 분리한다.

## 검증 기준

- 초등 저학년이 글을 읽지 않아도 레벨 1 첫 접기를 완료할 수 있어야 한다.
- 모바일 세로와 가로에서 종이, 선택지, 다음 버튼이 한 화면에 들어와야 한다.
- 대각선 접기와 펼치기 결과가 학습지 생성 규칙과 일치해야 한다.
- 오답 후 긍정 칭찬 음성이 나오지 않아야 한다.
- 기존 `gfield-profile`, 포인트, 큐브타운 진행 기록을 덮어쓰지 않아야 한다.
