# GFIELD 색종이 접고 펼치기 게임

## 현재 학습 범위

현재 게임은 전체 색종이 커리큘럼 중 두 과정만 구현한다.

1. `색종이 접어 자르기`: 접힌 종이의 잘린 영역이 옮겨질 면과 최종 모양을 고르거나 절단선과 조각 수를 구한다.
2. `색종이 접어 구멍 뚫기`: 원형 및 삼각형·사각형 구멍의 위치, 모양, 개수를 구한다.

수가 쓰인 종이와 겹친 순서는 기존 학습지에 있다. 원본의 모든 절단 무늬,
모양별 조각 수, 한 번 접기 가능성과 접는 선 찾기는 아직 게임에 없다. 전체 지원 상태는
`25_PAPER_FOLD_SOURCE_COVERAGE.md`, 분류 원칙은 `24_PAPER_ACTIVITY_CURRICULUM.md`를 따른다.

## 문제 흐름

1. 처음 종이의 화살표가 시작하는 면을 눌러 주어진 접기를 실행한다.
2. 접기 완료 후 두꺼운 종이의 절단·구멍 상태가 나타난다.
3. 마지막 접기부터 거꾸로 생각하며 새 표시가 생길 면을 결과 종이에서 직접 누른다. 이 그림에는 방향 화살표가 없다.
4. 두 번 접기는 중간 펼침을 거친다. 최종 모양 선택 전에 완성된 정답을 보여 주지 않는다.
5. 영역 절단·구멍 모양 문항은 아래 세 보기에서 최종 모양을 고른다. 회전해도 같은 그림이 되는 보기는 제거한다.
6. 조각 수·구멍 수 문항은 펼친 그림에서 개수를 고른다. 모양 문제의 정답 선택 후에는 완성된 결과를 보여 준다.

각 선택은 확인 버튼 없이 즉시 채점한다. 선 잇기는 세 연결이 완성되는 즉시 검사하고,
틀린 연결만 지워 다시 시도하게 한다.

## 세션

- 기본 세션은 10문제이며 이어서 최대 20문제까지 푼다.
- 한 세션에는 단계별 펼치기와 선 잇기가 모두 포함된다.
- 한 판과 이어 풀기에서는 같은 그림의 중복을 제외한다. 새 판도 같은 과정에서 이전에 푼 문항을 제외하며, 부족하면 반복 출제하지 않는다.
- `?count=20`이면 처음부터 20문제를 구성한다.
- 함께하기는 같은 기기에서 한 문제 전체를 푼 뒤 A와 B의 차례를 바꾼다.
- 한 기기 배틀은 2~4명을 선택한다. 같은 난이도·문항 묶음의 시작 위치를 참가자마다 달리하고 보기 순서도 별도로 섞는다. 다중 기기 접속은 지원하지 않는다.
- 배틀은 한 문항을 처음에 정확히 풀면 3점, 틀린 시도가 한 번이면 2점, 두 번 이상이면 1점이다. 속도에 따른 보너스는 없다.
- 배틀에서는 아바타를 숨기고 문제 영역을 넓힌다. 먼저 끝난 참가자의 답은 대기 화면으로 가리며, 모두 끝나면 순위·점수·완료 수·틀린 시도 수를 표시한다. 동점은 같은 순위다.

## 데이터

`geometry/games/paper-fold/curriculum.js`가 게임과 게임 연계 학습지의 공용 원본이다.
자르기 52문항, 구멍 뚫기 36문항으로 총 88문항 ID를 가진다. 새 한 번 접기 삼각형 문항은 16개다.
그림 기준 중복을 제외한 현재 출제 풀은 각각 50개, 24개이며 한 판에 같은 그림을 넣지 않는다.

- 자르기: `region-unfold`, `piece-count`, `connect-match`
- 구멍: `hole-count`, `hole-result`, `mixed-hole-result`, `connect-match`
- `folds`: 처음 접은 순서
- `stagePolygons`: 원본부터 마지막 접힌 종이까지의 외곽
- `segmentStages`: 접힌 절단선부터 한 장씩 펼친 절단선 상태
- `pointStages`: 접힌 구멍부터 한 장씩 펼친 구멍 상태
- `unfoldSteps`: 마지막 접기부터의 축, 새 표시가 생기는 면, 터치 선택지
- `unfoldedSegments` / `unfoldedPoints`: 완전히 펼친 최종 상태

조각 수는 두 해상도의 연결 영역 계산이 일치하는 문항만 채택한다. 반사를 두 번 적용하면
원래 점으로 돌아오는지, 단계 배열의 길이가 접기 수보다 하나 많은지 검사한다.

## 화면과 학습지

- 접기 화살표는 처음 접는 장면에만 표시한다. 결과 그림에는 화살표가 없다.
- 접힌 종이는 숫자 배지 없이 실제로 겹쳐진 측면과 층 경계의 두께로 구분한다.
- 활성 터치 영역은 처음에는 접는 종이, 다음에는 새 표시가 생길 결과 종이로 이동한다.
- 한 번 접기는 세 장면, 두 번 접기는 네 장면으로 표시한다.
- 모바일 세로에서는 네 장면을 지그재그 순서로 배치해 화살표 흐름을 보존한다.
- 게임 연계 학습지는 같은 문항 ID와 좌표를 A4 캔버스에 다시 그린다.

## 검증 기준

1. 자르기 영역에 구멍 문항이 없고 구멍 영역에 절단선 문항이 없다.
2. 각 영역에 한 번·두 번 접기가 포함된다.
3. `unfoldSteps`의 순서는 `folds`의 역순이며 정답 면은 원래 움직였던 면이다.
4. 중간 단계의 절단선·구멍 수가 이전 단계보다 줄지 않고 마지막 상태와 최종 답이 같다.
5. 실제 종이 면을 누르면 즉시 채점되고 별도 방향 선택 상자가 없다.
6. 데스크톱, 390px 세로, 모바일 가로와 A4 학습지를 실제 렌더로 확인한다.
