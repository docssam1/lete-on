# GFIELD 색종이 공방 게임 설계

## 학습 목표

학습지의 유형 이름을 그대로 게임 메뉴로 옮기지 않는다. 아이가 실제 색종이를 다루듯
`접기 -> 눌러 보기 -> 구멍 뚫기/오리기 -> 거꾸로 펼치기 -> 결과 설명하기` 순서로 익히게 한다.

- 레벨마다 문제은행 10문제를 둔다.
- 한 회차에는 최근 문제와 겹치지 않는 5문제를 출제한다.
- 레벨 1과 2는 접힌 종이를 보고 펼친 결과를 고르거나 서로 연결한다.
- 레벨 3은 모눈의 작업 위치를 터치하고, 레벨 4는 대칭 도형을 끌어 놓는다.
- 정답 확인 때는 접은 순서의 반대로 종이를 펼쳐 실제 대칭 결과를 보여 준다.
- 첫 안내 문제와 힌트를 사용한 문제에는 포인트를 주지 않는다.

## 캐릭터

- 이름: 폴디(Foldy)
- 형태: 앞면과 뒷면 색이 다른 접힌 색종이 캐릭터, 종이학 배지
- 등장: 레벨 1 첫 문제의 튜토리얼, 사용자가 요청한 힌트, 레벨 완료에만 등장
- 음성: 짧은 만화 캐릭터 톤 MP3를 우선 사용하고 파일 재생이 실패할 때만 TTS로 대체한다.
- 성장: 레벨 완료에 따라 민트 -> 하늘 -> 보라 -> 코랄 -> 금색 테두리와 액세서리가 추가된다.
- 저장: 기존 `gfield-profile`의 이름, 포인트, 장착 아이템, 다른 게임 기록을 덮어쓰지 않는다.

## 레벨 구성

### 레벨 1 - 반으로 쏙

작은 제목은 `한 번 접은 색종이 펼친 모양 찾기`다.

- 좌우 또는 위아래로 색종이를 한 번 접는다.
- 접힌 종이에 선을 그리거나, 자르거나, 구멍을 뚫는다.
- 펼쳤을 때의 완성 모양 후보 2개를 좌우에 제시한다.
- 아이는 직접 선을 그리지 않고 결과 그림을 터치한다.
- 정답이면 종이를 거꾸로 펼치고 대칭 선, 잘린 윤곽, 구멍이 이어서 나타난다.
- 사선, 계단, V자, 곡선, 반원, 삼각형 등 실제 한 번 접기로 만들 수 있는 모양만 출제한다.

### 레벨 2 - 대각선 한 번 접기

- 두 대각선 방향과 각 모서리에서 시작하는 접기를 모두 다룬다.
- 왼쪽에는 접힌 삼각형과 자르기/그리기/구멍 작업을 보여 준다.
- 오른쪽에는 펼친 결과 후보 2개를 같은 크기와 위치로 제시한다.
- 원과 반원, 세로와 대각선 캡슐, 삼각형과 사각형처럼 차이가 분명한 후보를 사용한다.
- 접힌 그림과 펼친 결과 두 쌍을 연결하는 줄 잇기 유형도 포함한다.
- 모바일 줄 잇기는 두 그림을 차례로 터치하면 연결선이 자동으로 그려진다.
- 첫 안내 문제에서만 대각선으로 거꾸로 펼쳐지는 과정을 먼저 보여 준다.

### 레벨 3 - 작업 위치 찾기

펼친 결과와 접는 과정을 보고 자르거나 구멍 뚫을 위치를 찾는다.

- 4x4 모눈을 기본으로 사용한다.
- 가로, 세로, 양쪽 대각선 접기를 포함한다.
- 대각선이 칸을 가르면 사각 칸을 두 개의 삼각형 터치 영역으로 나눈다.
- `칸 선택 문제`에서는 정답 위치를 터치하면 옅은 선택색만 표시한다.
- `구멍 문제`에서는 펀치 도구로 한 곳 이상을 콕콕 눌러 실제 구멍을 배치한다.
- 같은 위치를 다시 누르면 선택 또는 구멍을 취소할 수 있다.
- 완료 후 `접기 -> 작업 -> 거꾸로 펼치기`를 재생해 결과와 일치하는지 보여 준다.
- 쉬운 사각 칸부터 삼각형 반쪽, 직사각형, ㄱ자 영역 순으로 난이도를 올린다.

### 레벨 4 - 대칭 도형 놓기

쌓기나무를 보관함에서 끌어 놓듯 대칭 도형을 종이 위에 배치한다.

- 문제 종이에 표시되는 도형은 1~3개로 제한한다.
- 기본 도형은 정삼각형, 직각삼각형, 원, 정사각형이다.
- 보관함에는 문제와 관계없는 도형을 섞지 않는다.
- 원 문제에는 원, 정사각형 문제에는 정사각형의 방향 후보처럼 같은 계열만 제공한다.
- 삼각형은 꼭짓점과 직각 모서리 방향이 다른 후보를 사용한다.
- 놓은 도형은 사라지지 않고 종이 위에 남으며 다시 잡아 위치를 고칠 수 있다.
- 정답 위치 가까이 놓으면 모눈 또는 대칭 위치에 스냅한다.
- 대칭이동은 도형의 크기와 종류를 바꾸지 않는다. 합쳐진 전체 윤곽만 마름모나 연꼴처럼 보일 수 있다.

### 레벨 5 - 잘려 나간 수 더하기

한 번 접은 색종이에서 잘려 나간 부분을 먼저 찾고, 그 칸에 쓰인 수의 합을 구한다. 한 화면에서
위치 찾기와 덧셈을 동시에 요구하지 않고 반드시 두 단계로 나눈다.

1. `어느 부분이 잘려 나갈까?` 단계에서 펼친 4x4 숫자 모눈의 칸 또는 삼각형 반쪽을 터치한다.
2. 선택한 위치가 모두 맞아야 `잘 찾았어! 이제 잘려 나간 부분의 수를 더해 볼까?` 안내와 함께 합 구하기 단계로 넘어간다.
3. 두 번째 단계에서는 선택된 칸을 계속 강조하고, 해당 수를 순서대로 식에 자동 표시한 뒤 학생이 합만 입력한다.
4. 두 단계가 모두 맞아야 접기, 자르기, 거꾸로 펼치기 애니메이션과 강한 성공 연출을 재생하고 포인트를 준다.

- 가로·세로 한 번 접기부터 두 대각선 접기까지 다룬다.
- 쉬운 두 칸, 직사각형 영역, 삼각형 반쪽, ㄱ자 영역 순으로 난이도를 올린다.
- 접는 선이나 자르는 선이 숫자 자체를 통과해 답이 애매해지는 문제는 만들지 않는다.
- 첫 단계가 틀리면 합 입력으로 넘어가지 않으며, 틀린 선택만 짧게 표시한 뒤 다시 고르게 한다.
- 첫 단계를 맞힌 뒤에는 선택 위치를 바꿀 수 없고 `위치 다시 고르기`로만 이전 단계로 돌아간다.
- 정답 데이터에는 잘린 영역, 해당 숫자 목록, 계산식, 합을 함께 저장한다.

예시 데이터는 다음과 같이 위치 정답과 계산 정답을 분리한다.

```js
{
  id: "paper-l5-01",
  level: 5,
  interaction: "cut-number-sum",
  grid: {
    size: 4,
    values: [[1,3,4,2],[8,6,7,5],[4,1,2,3],[6,5,7,8]]
  },
  fold: { axis: "vertical", side: "left", target: "right" },
  cutRegions: ["r1c1", "r3c1"],
  answer: {
    cells: ["r1c1", "r3c1", "r1c4", "r3c4"],
    values: [1,4,2,3],
    expression: "1 + 4 + 2 + 3",
    sum: 10
  }
}
```

`answer.cells`에는 접힌 종이에 표시된 원래 위치와 접는 선을 기준으로 펼쳐진 반사 위치를 모두 넣는다.
따라서 2단계의 합은 실제로 잘려 나간 모든 칸의 수를 더한 값이다.

## 조작 엔진

현재의 단순 `scale()` 축소 애니메이션은 사용하지 않는다. 종이를 면 단위로 관리하고 접는 선을
기준으로 움직이는 면을 반사시킨다.

```js
{
  id: "paper-l2-01",
  level: 2,
  paper: { shape: "square", front: "mint", back: "coral" },
  folds: [
    { axis: "vertical", side: "left", target: "right" },
    { axis: "horizontal", side: "bottom", target: "top" }
  ],
  action: { type: "punch", shape: "circle", point: [0.72, 0.28] },
  answer: { count: 4, points: [[0.28,0.28],[0.72,0.28],[0.28,0.72],[0.72,0.72]] }
}
```

- 각 접기마다 현재 종이 다각형, 앞/뒷면, 층 순서를 저장한다.
- 접는 면은 `transform-origin`을 접는 선에 고정하고 3D 회전으로 넘어간다.
- 애니메이션이 끝나면 학습지와 같은 다각형 반사 계산 결과로 상태를 확정한다.
- 거꾸로 펼치기는 저장된 접기 이력을 역순으로 재생한다.
- 빠르게 여러 번 눌러도 한 동작만 실행되도록 입력을 잠근다.
- `prefers-reduced-motion`에서는 중간 회전을 생략하고 전후 상태를 짧은 페이드로 연결한다.

## 화면 구성

- 상단: 나가기, 작은 워터마크, 레벨/문항, 음소거
- 중앙: 종이가 가장 크게 보이는 작업대
- 오른쪽 도구: 현재 필요한 도구만 표시(접기, 펀치, 가위, 펼치기)
- 하단: 현재 미션과 필요한 경우에만 정답 선택지 또는 도형 보관함
- 레벨 5 하단: 1단계에는 `선택 완료`, 2단계에는 선택된 수의 식과 합 입력 패드를 표시
- 모바일 가로: 한 화면 안에 작업대, 도구, 정답을 모두 배치
- 모바일 세로: 작업대를 우선하고 도구와 정답을 하단 고정 영역에 배치
- 폴디는 작업대를 가리지 않으며 튜토리얼 이후에는 상시 노출하지 않는다.

## 피드백

- 접기 완료: 짧은 종이 스침 효과음
- 펀치/오리기: 서로 구분되는 짧은 효과음
- 오답: 낮고 짧은 알림음과 잘못 추적한 접기 단계만 강조
- 정답: `GOOD JOB!`, `GREAT JOB!`, `SUCCESS!` 중 하나와 강한 성공 연출
- 매 조작마다 캐릭터 음성을 반복하지 않는다.

## 학습지 연결

- 공방의 각 레벨 카드에 `이 레벨 학습지` 버튼을 둔다.
- 해당 버튼은 연결된 유형을 미리 선택하되, 사용자가 다른 유형을 추가해 혼합 출제할 수 있다.
- 문제의 안정적인 ID와 생성 파라미터를 게임과 학습지가 공유한다.
- 학습지 정답지는 접기 순서를 거꾸로 펼치는 실제 풀이 그림과 계산식을 제공한다.
- 레벨 5 학습지는 `잘린 칸 표시 -> 잘린 칸의 수 나열 -> 덧셈식 -> 합` 순서가 정답지에 모두 보여야 한다.

| 게임 레벨 | 학습지 연결 유형 | 게임과 공유할 핵심 데이터 |
| --- | --- | --- |
| 1 반으로 쏙 | 가로·세로 한 번 접고 펼친 모양 고르기 | 접는 축, 작업 선/구멍/절단 다각형, 정답·오답 윤곽 |
| 2 대각선 한 번 접기 | 대각선 접기 결과 선택, 접힌 그림과 펼친 그림 줄 잇기 | 대각선 종류, 접는 쪽, 작업 도형, 반사 결과 |
| 3 작업 위치 찾기 | 모눈에서 자를 칸·구멍 위치 표시 | 4x4 모눈, 사각/삼각 터치 영역, 선택 위치, 펼친 결과 |
| 4 대칭 도형 놓기 | 대칭 위치·방향 완성하기 | 도형 계열, 시작 위치, 대칭축, 목표 위치와 방향 |
| 5 잘려 나간 수 더하기 | 잘린 부분 표시 후 수의 합 구하기 | 4x4 숫자판, 잘린 영역, 값 목록, 계산식, 합 |

학습지는 게임 전용 선택형 문제를 그대로 스크린샷으로 옮기지 않는다. 같은 데이터로 A4에 맞는 문제 그림을
다시 그리고, 정답지에는 단순 답만이 아니라 `접기 역순 -> 대칭 위치 -> 계산`을 보여 준다.

공용 문제 레코드는 최소한 아래 필드를 가진다.

```js
{
  id: "paper-l3-04",
  level: 3,
  family: "location",
  paper: { shape: "square", grid: 4, front: "sky", back: "coral" },
  folds: [{ axis: "horizontal", movingSide: "bottom" }],
  operation: { type: "cut", regions: ["r3c1", "r3c4"] },
  interaction: { type: "region-select", maxSelections: 2 },
  answer: { regions: ["r1c1", "r1c4"] },
  worksheet: { mode: "cut-location", difficulty: "easy" }
}
```

- 게임은 `interaction`을 사용해 터치·선택·드래그 UI를 만든다.
- 학습지는 `worksheet`와 동일한 기하 데이터를 사용해 문제와 풀이 이미지를 그린다.
- 렌더링 결과가 달라도 정답 필드와 문제 ID는 하나만 존재해야 한다.

## 검증 기준

1. 초등 저학년이 글을 읽지 않아도 레벨 1의 첫 접기를 완료할 수 있어야 한다.
2. 접힌 면의 앞/뒷면 색과 층 순서가 모든 단계에서 일관되어야 한다.
3. 게임의 구멍 위치, 조각 수, 숫자 답이 학습지 생성기와 일치해야 한다.
4. 두 가지 답이 가능한 문제는 데이터 검증에서 거부한다.
5. 모바일 세로/가로와 데스크톱에서 주요 요소가 잘리거나 겹치지 않아야 한다.
6. 음소거, 백그라운드 복귀, 빠른 연속 입력에서 음성과 애니메이션이 중복되지 않아야 한다.
7. 기존 `gfield-profile`, 큐브타운 진행, 포인트를 덮어쓰지 않아야 한다.
8. 레벨 5는 위치 선택을 맞히지 않고 합 입력 단계로 넘어갈 수 없어야 한다.
9. 레벨 5의 선택된 칸, 표시된 수, 계산식, 합은 게임과 학습지에서 완전히 같아야 한다.
