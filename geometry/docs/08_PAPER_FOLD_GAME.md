# GFIELD 색종이 접어 자르기 게임

## 학습 범위

이 게임은 색종이를 **한 번만** 접어 자른 뒤 펼친 결과를 생각하는 활동이다.
내용 유형은 아래 두 개뿐이며, 문제 제시 방식은 유형으로 세분화하지 않는다.

1. 색종이 접어 자르기: 가로 또는 세로로 반을 한 번 접는다.
2. 대각선으로 접어 자르기: 두 대각선 중 하나를 따라 한 번 접는다.

숫자 색종이, 여러 번 접기, 맨 위의 수, 구멍 개수는 이 게임의 레벨로 넣지 않는다.
별도 학습지에 존재하는 독립 유형은 유지하되 게임 연계 항목과 섞지 않는다.

## 문제 흐름

- 펼친 색종이에 점선 접는 선과 접는 방향을 보여 준다.
- 접힌 종이는 실제 직사각형 또는 삼각형 비율로 그린다.
- 접힌 종이에 자르는 선과 가위를 표시한다.
- 펼친 결과에는 접는 선과 대칭인 잘린 윤곽을 표시한다.
- 모든 문제 레코드는 `folds.length === 1`이어야 한다.
- 정답은 생성기와 별도의 반사 계산으로 검산한다.

## 제시 방식

내용 유형은 두 개로 고정하지만 한 세션 안의 문제 방식은 유연하게 섞는다.

- 결과 선택: 접어 자른 모습을 보고 펼친 결과 세 개 중 하나를 고른다.
- 선 잇기: 접어 자른 모습 세 개와 펼친 결과 세 개를 알맞게 연결한다.
- 모바일 선 잇기는 왼쪽과 오른쪽 그림을 차례로 누르면 연결선이 나타난다.
- 같은 제시 방식이 세 문제 이상 연속되지 않도록 세션을 구성한다.

## 세션

- 기본 세션은 10문제다.
- 10문제 완료 뒤 `10문제 더 풀기`로 이어서 최대 20문제까지 푼다.
- 완료 뒤 같은 유형의 새로운 10문제를 시작하거나 다른 유형으로 이동할 수 있다.
- 최근 20문항 ID를 기억하고 다음 세션에서 우선 제외한다.
- `?count=20`으로 들어오면 처음부터 20문제 세션을 만든다.

## 데이터

`geometry/games/paper-fold/levels.js`가 게임과 게임 연계 학습지의 공용 원본이다.

```js
{
  id: "paper-straight-01",
  level: 1,
  interaction: "result-choice",
  fold: { axis: "vertical", side: "left", target: "right" },
  folds: [{ axis: "vertical", side: "left", target: "right" }],
  profileId: "triangle",
  cut: [{ x: 0.5, y: 0.2 }, { x: 0.76, y: 0.5 }, { x: 0.5, y: 0.8 }],
  choices: [],
  answer: "a"
}
```

- `cut`은 펼친 정사각형 좌표계의 자르는 선이다.
- 펼친 윤곽은 `cut`을 접는 선 반대쪽에 반사해 계산한다.
- 일반 반 접기 36문항, 대각선 접기 36문항을 결정적으로 생성한다.
- 선택과 선 잇기는 같은 접기·자르기 기하 데이터를 사용한다.

## 화면과 피드백

- 중앙에는 실제 문제 그림을 가장 크게 배치한다.
- 선택 문제는 `펼친 종이 -> 접어 자르기 -> 펼친 결과` 순서를 유지한다.
- 선 잇기 문제는 왼쪽 접힌 그림과 오른쪽 펼친 그림의 크기를 통일한다.
- 정답 뒤 펼친 결과가 짧게 나타나며 `prefers-reduced-motion`에서도 즉시 확인할 수 있다.
- 축하 효과와 안내 말풍선은 다음 문항으로 넘어갈 때 즉시 사라진다.
- 효과음과 음성은 문항 시작마다 반복하지 않는다.

## 학습지 연결

- 게임 연계 선택지는 `색종이 접어 자르기`, `대각선으로 접어 자르기` 두 개다.
- 게임과 학습지는 문항 ID, 접는 축, 접는 쪽, 자르는 선, 정답을 공유한다.
- 학습지는 같은 데이터를 A4용 캔버스에 다시 그리며 게임 화면 캡처를 사용하지 않는다.
- 기존 학습지의 다른 독립 유형은 게임 연계 항목과 별도로 유지한다.

## 검증 기준

1. 두 내용 유형만 게임과 진입 화면에 보인다.
2. 생성된 모든 문항은 정확히 한 번만 접는다.
3. 한 세션에 선택과 선 잇기가 모두 포함된다.
4. 기본 10문제와 추가 10문제가 중복 없이 이어지고 20문제에서 종료된다.
5. 데스크톱, 390px 세로, 모바일 가로에서 그림·연결선·버튼이 잘리지 않는다.
6. 게임 연계 학습지의 미리보기와 정답 그림이 같은 기하 데이터를 사용한다.
