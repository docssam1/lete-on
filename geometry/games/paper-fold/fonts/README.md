## Language Fallbacks

Korean and English use these bundled fonts. Chinese prioritizes PingFang SC,
Microsoft YaHei, and Noto Sans SC. Japanese prioritizes Hiragino Kaku Gothic
ProN, Yu Gothic, Meiryo, and Noto Sans JP. These are local fallbacks, not
redistributed assets. Both lists end with the platform sans-serif family.
