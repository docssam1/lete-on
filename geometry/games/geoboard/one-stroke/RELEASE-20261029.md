# One-Stroke Geoboard Release Scope

## Included

- A separate Euler-trail activity inside the existing Geoboard: 12 internally authored graphs, three exploratory stages and four locales.
- Learner-selected start, non-revealing invalid-start feedback, repeated-edge rejection, legal vertex revisits, undo and an always-visible Draw again command.
- Continuous pointer/touch preview, last-peg resume, cancellation/rotation recovery, validated save/reload and offline entry.
- Existing wood textures, brass pegs and SUIT. Procedural material cues use the shared mute preference; no voice recording or external audio service is introduced.
- A sixth lobby card and an original-game level-dialog link. The original five activities, engine, question data and profile-storage implementation remain unchanged.
- A user-space SVG gradient to keep horizontal and vertical bands visible. Runtime modules, font, textures and bank are listed together in service-worker cache `gfield-geo-v61-geoboard-euler`.

The other local Piece Move course, cross-game audio integrations and unrelated open PRs are not part of this release.

## Focused Verification

- Independent NetworkX 3.6.1 verification: 60 starting-point checks across 12 graphs. Separate exhaustive checks cover 270 valid trails and 243 reference transitions. False-start metadata, duplicate edges, corrupt saves and forged progression negative controls pass.
- Browser matrix: 80 states across four locales and five viewports; 32 full mouse/touch problem paths. Covers wrong start, reset, undo, dead-end recovery, keyboard, live preview, reused edges, off-line detours, cancellation, rotation, secondary touch, storage failure, missing required texture and offline reload. Wood/edge pixel checks include an intentionally invisible-edge negative control.
- Original Geoboard: 55-question self-test, content audit and browser regression for five activity levels and four locales.
- Existing Geoboard worksheet: five levels, selected bank questions, mobile layout and five-page A4 PDF generation.
- Lobby regression retains exact curriculum bands for the original five activities and checks the new route separately.

Skills applied: `test-playable-web-games` for real-input/state/pixel regression and `ship-web-games` for exact-commit integration and public-readback checks. The original implementation additionally used `learning-ui-editorial` and `evidence-gated-learning-pipeline` for learner fit and independent mathematical gates.

## Limits

These are automated browser and desktop visual checks, not physical phone/tablet tests, actual printer output, audio listening approval or teacher/child learning approval. No full all-Geometry release-suite pass is claimed. Commit, main merge, deployment and live readback must be recorded separately in the release receipt.

Rollback scope is the change set of this release only. Do not reset unrelated main commits or remove the protected original Windows worktree.
