# 마지막 정리 검수 상태

## 원본

- 문제지: `중등과정 선발 대비 모의고사 마지막 정리.pdf`
- 문항 수: 40문항
- 답안 PDF: 별도 파일 없음
- 풀이 영상: `data.js`의 `videos.final-review`

## 반영 원칙

마지막 정리는 답안 PDF가 없는 상태에서 영상 대본만으로 정답을 확정하면 서비스 채점 오류가 생길 수 있다. 따라서 현재는 문제지와 풀이 영상 링크만 제공하고, 40문항 답안이 별도 검수되기 전까지 자동 점수와 약점 분석을 잠근다.

| 기능 | 현재 상태 |
|---|---|
| 문제지 열람 | 가능 |
| 워터마크 인쇄 | 가능 |
| 전체 수업 영상 | 가능 |
| 답안 입력 | 준비 |
| 정답표 보기 | 검수 후 공개 |
| 자동 채점 | 검수 후 활성화 |
| 약점 유형 분석 | 검수 후 활성화 |

## 다음 검수 때 기록할 항목

1. 1~40번 정답과 허용 답안 형식
2. 문항별 학기·유형·코멘트
3. 풀이 영상의 문항별 시작 시각
4. 수동 채점 문항 여부

검수 전에는 마지막 정리를 최종 모의고사의 문제지·영상 열람 과정으로만 노출한다.
