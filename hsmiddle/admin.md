# 중등 진단 승인 운영

학생은 이메일 없이 `이름 + 승인번호`로 입장합니다. 승인과 권한은 `data.js`에서 관리합니다.

1. `students`에 학생 이름을 추가합니다.
2. `studentCode`에 해당 이름과 승인번호를 추가합니다.
3. `access`에 `diagnostic` 권한을 추가합니다.
4. GitHub에 저장한 뒤 승인번호를 카카오톡으로 전달합니다.

실제 운영에서는 필즈 더 클래식의 `admin.html`처럼 GitHub 저장 버튼을 붙여 같은 방식으로 관리합니다. 이메일 주소는 저장하거나 화면에 노출하지 않습니다.
