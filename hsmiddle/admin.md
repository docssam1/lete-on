# 중등 진단 승인 운영

학생은 이메일 없이 `이름 + 승인번호`로 입장합니다. 승인과 시험지 권한은 공개 파일이 아니라 `admin.html`의 관리자 화면에서 서버에 저장합니다.

1. 관리자 이름과 승인번호로 입장합니다.
2. 학생 이름, 새 승인번호, 허용할 시험지를 선택합니다.
3. `승인 저장`을 누릅니다.
4. 발급한 승인번호는 학생에게 별도로 전달합니다.

승인번호 원문은 저장하지 않고 느린 비밀번호 해시로만 보관합니다. 관리자 목록에도 승인번호와 해시는 표시하지 않습니다.

## 저장 범위

- Supabase 데이터베이스에는 계정 해시, 시험지 권한, 짧은 로그인 세션, 성적 숫자와 문항별 O/X 상태만 저장합니다.
- 교재 원본 PDF, 교재 이미지, 문제지, 풀이 파일은 Supabase Storage에 올리지 않습니다.
- 공개 화면에 필요한 기존 문제 자산은 GitHub Pages에서 제공하며, 비공개 교재 원본은 기존 원본 위치에 그대로 보존합니다.
- 이메일 주소는 저장하거나 화면에 노출하지 않습니다.
