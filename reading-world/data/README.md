# Lesson data

- `lesson1.js` — 공개 가능한 자료만 담습니다: 핵심 단어 12개, 학습용 창작 지문(추가 학습·새 지문 연습), 창작 문항.
- `lesson1.original.js` — **비공개(라이선스) 자료**: 교재 원문 지문과 원문 12문항. `window.LESSON1_ORIGINAL`을 정의합니다.
  - 이 파일은 `.gitignore`로 제외되어 있어 커밋되지 않습니다.
  - 배포(예: GitHub Pages) 시에는 비공개 경로에서 이 파일을 서버에 직접 올려야 "교재 풀기 / 교재 학습" 단계가 열립니다.
  - 파일이 없으면 앱은 해당 두 단계에 안내 카드를 보여주고, 나머지 단계(단어·추가 학습·새 지문 연습)는 정상 동작합니다.

## 장기 데이터 모델 메모
여러 책을 담는 플랫폼으로 확장할 때는 `bookId / levelId / lessonId / lessonTheme / rewardPoints`
필드를 갖는 JSON 구조로 이전할 예정입니다. 책별(지문·삽화·단어·문제·테마)과 공통(프로필·포인트·기록) 자산을 분리합니다.
