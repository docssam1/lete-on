## Special visual questions

There are only three reusable visual-question component types in Level D: `sequence`, `cause-effect`, and `branch-map`. The confirmed special questions are:

- cd2 Q3: `sequence`, 3 boxes, blank index 2, no step numbers.
- cd3 Q4: `cause-effect`, effect box blank.
- cd5 Q2: `branch-map`, 4 child boxes, child index 1 blank.
- cd6 Q3: `sequence`, 3 boxes, blank index 1, no step numbers.
- cd7 Q4: `cause-effect`, effect box blank.
- cd10 Q3: `sequence`, 3 boxes, blank index 1, show 1/2/3.
- cd13 Q3: `sequence`, 3 boxes, blank index 0, no step numbers.
- cd14 Q3: `sequence`, 3 boxes, blank index 2, show 1/2/3.

The scan itself is **never** used as the exercise image for these questions. Box text comes from private OCR/source data and is rendered as live HTML. Therefore answer circles, red markings, pencil marks and scan noise cannot appear in the student UI.

## Rendering rule

OCR is a text source, not a layout source. Before changing a source layout, check the PDF/full-page image for:

1. instruction typography,
2. source title typography,
3. body columns and paragraph flow,
4. figure position and scale,
5. special inset/list/poster typography,
6. visual-question box order, arrows and blank position.

Recreated illustrations live separately from text so replacing an image never changes selectable text or TTS reading order.
