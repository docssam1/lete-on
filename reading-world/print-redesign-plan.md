# 인쇄 센터 리디자인 설계서 (print.html v2)

> 작성: 2026-08-09. 이 문서는 **구현 지시서**다. 다음 세션(다른 모델)이 이 문서만 읽고
> print.html을 개편할 수 있어야 한다. 엔진(시트 생성·채점·브랜드·로고 처리)은 전부
> 재사용하고 **화면 구조(IA)와 조작 흐름만** 바꾼다.

---

## 1. 문제 정의

현재 print.html은 왼쪽 사이드바에 8개 패널(브랜드 / 출력단위 / 표지 / 진단 / 채점 /
교재 / 약점유형 / 옵션)이 한 번에 쌓여 있다. 처음 연 강사는 무엇부터 눌러야 할지 모른다.

사용자 요구 (원문 요지):
- 강사가 들어가면 **진행할 과정을 먼저 선택**: `상담용 진단 테스트` / `CARS B` / `CARS C` / `CARS D`
- 선택 화면은 **uep.html의 3D 서재처럼** 직관적으로
- 과정을 고른 뒤에 그 과정에 맞는 것만: 어떻게 인쇄할지, 표지 등
- **오른쪽에 미리보기 상시 표시**

## 2. 화면 구조 (2단)

```
Screen A · 과정 선택 (서재)          Screen B · 작업실 (과정별)
┌──────────────────────────┐        ┌────────┬─────────────────────┐
│  [학원로고] 교재 제작 센터  ⚙ 📖 │        │ ←과정   CARS Level B      │
│                                  │        │ [인쇄] [단원 평가]  (탭)   │
│   ┌────┐ ┌────┐ ┌────┐ ┌────┐   │        ├────────┬─────────────────┤
│   │진단 │ │ B  │ │ C  │ │ D  │   │  ───►  │ STEP    │                 │
│   │시험지│ │책  │ │책  │ │책  │   │        │ 아코디언 │   미리보기       │
│   └────┘ └────┘ └────┘ └────┘   │        │ (좌 38%) │   (우 62%)      │
│    상담용   G2    G3    G4       │        │         │   sticky·스크롤  │
└──────────────────────────┘        └────────┴─────────────────────┘
```

### Screen A — 과정 선택
- **uep.html의 서재 CSS 재사용** (`.shelf .book .spine .pages .face` — 복사해 온다).
  책 3권은 동일한 3D 볼륨. **진단은 책이 아니라 '시험지 묶음' 카드**로 구별:
  클립보드/시험지 스택 모양(흰 종이 + 상단 클립, 살짝 부채꼴로 겹친 3장), 라벨
  `상담용 진단 테스트 · P~H 10레벨`.
- 카드 클릭 → Screen B로 전환 (`location.hash='#c=diag|b|c|d'`, SPA 전환, 새로고침 유지).
- 우상단 아이콘 2개만: `⚙ 브랜드 설정`(모달), `📖 운영 매뉴얼`(manual-academy.html 링크).
- **브랜드 설정은 모달로 이동** — 이름/부제/2색/로고 업로드. 기존 `brand` 객체·
  `applyBrand()`·`loadLogo()`(흰배경 제거+여백 트림) 그대로. 최초 방문(브랜드 미설정)
  시 모달을 자동으로 한 번 띄운다.

### Screen B — 작업실
공통 프레임:
- 헤더: `← 과정 선택` | 과정명 + 요약칩(선택 요약: "3개 단원 · 원본+유사 · 문장형 표지") |
  탭 2개 | 우측 인쇄 버튼(과정별로 다름).
- 좌측 38% = **아코디언 스텝**(한 번에 하나 펼침, 완료된 스텝은 접힌 채 요약 표시,
  헤더 클릭으로 재편집). 우측 62% = 미리보기(현행 `.pv-body` 그대로, sticky).
- 미리보기 상단 칩은 **출력물 선택과 겸용**: 여기서 고른 것이 인쇄 버튼의 대상이 된다.

#### B-1. 진단 과정 (`#c=diag`)
탭: `시험지 인쇄` / `채점 · 분석지`

시험지 인쇄 스텝:
1. **레벨** — 10개 카드(P~H). B·C·D에 `교재 연계` 뱃지. 다중 선택 가능.
   보조 버튼: `학습서 있는 레벨만` / `전체` / `해제` (기존 data-pick 재사용).
2. **옵션** — 이름·날짜란, 언어(EN 기본/KO). *표지·분리·삽화 옵션은 여기선 숨김*
   (진단은 낱장 시험지라는 전제).
3. 인쇄 버튼: `문제지 PDF` `답안지 PDF`.

채점·분석지 탭 = 기존 채점 패널 그대로 이동(레벨 선택 + A/B/C/D 그리드 + 분석지
미리보기·PDF). **이 탭에서는 미리보기가 자동으로 분석지 모드**가 된다.

#### B-2. 교재 과정 (`#c=b|c|d`)
탭: `교재 인쇄` / `단원 평가`

교재 인쇄 스텝(아코디언 순서):
1. **범위** — 세그먼트 `책 한 권(통권)` / `단원 골라서`. 단원이면 챕터 그리드 노출
   (현행 `[data-ch]` 셀 재사용, 셀에 과번호+제목). 통권이면 전체 자동 선택.
   접힌 요약 예: `통권 · 15개 단원` / `단원 3개 (1·4·7과)`.
2. **구성** — 큰 토글 카드 4개(아이콘+제목+한 줄 설명):
   `📖 원본 지문`(⚠ 라이선스 문구 카드 안에), `📝 낱말`, `➕ 추가 학습`, `🔁 유사 지문`.
   하단 접이식 `약점 유형만 뽑기` → 12전략 체크(기존 stratList).
3. **표지 · 마감** — 표지 5종 썸네일(기존 스와치를 **실제 coverSheet 축소 렌더**로
   업그레이드: iframe 아닌 `transform:scale` 미니 시트), 속표지 토글, 세부 옵션
   (지문/문항 분리 · 삽화 · 이름란 · 낱말 빈칸/우리말 칸 · 전략 표시 · 해설 · 언어).
4. **인쇄** — 페이지 수 요약(`표지 1 + 속표지 3 + 학습지 12 + 답안지 2 = 18쪽`) +
   버튼 3개: `통권 PDF`(주버튼) `문제지만` `답안지만`.

단원 평가 탭 = 기존 채점 패널의 `교재 단원` 모드를 **이 책 범위로 스코프**해서 표시
(70개 전체 대신 이 책 단원만). 분석지 미리보기·PDF 동일.

## 3. 상태·코드 매핑 (기존 → v2)

| 기존 | v2 위치 | 변경 |
|---|---|---|
| `brand`, `applyBrand`, `loadLogo`, `keyOutWhite`, `trimCanvas` | ⚙ 모달 | 로직 무변경 |
| `SCOPE`/`ONLY` (출력단위) | 스텝1 범위 | `ONLY` 단일 → **다중 선택 배열**로 일반화 (`sel.book[x].ch`가 이미 다중이므로 SCOPE='unit'일 때 ch 체크 그대로 쓰고 ONLY 제거) |
| `sel.book[id].parts` | 스텝2 구성 | 무변경 (original 포함 4키) |
| `sel.strat`, `filterQs` | 스텝2 접이식 | 무변경 |
| `brand.cover`, `coverSheet` | 스텝3 | 썸네일을 실렌더 축소로 |
| `opt*` 체크박스 | 스텝3 | id 유지 (엔진이 `opt('optSplit')` 등으로 읽으므로 **id 절대 변경 금지**) |
| `jobs()`, `paperSheets`, `keySheets`, `build()` | 그대로 | 진단 과정에서는 diag 잡만, 교재 과정에서는 해당 book만 나오도록 `jobs()`에 현재 과정 필터 한 줄 추가 |
| `grade`, `gradeGrid`, `reportSheet` | 각 과정 탭2 | `gradeSource()`의 unit 목록을 현재 book으로 필터 |
| `originalFor`, `origCache` | 무변경 | |
| 탭 `paper/key/book/report` | 미리보기 칩 | report 칩은 채점 탭에서만 표시 |

**삭제되는 것 없음** — 사이드바 HTML만 재배치. 엔진 함수 시그니처 유지.

## 4. 스타일 지침

- 서재: uep.html 톤(네이비+골드) 그대로. Screen A 배경은 `--bg` 크림, 카드에 그림자.
- 아코디언 스텝: 번호 원형 뱃지(브랜드색), 완료 스텝은 체크+요약 한 줄, 현재 스텝만
  내용 펼침. `manual-academy.html`의 `.steps` 모양과 통일.
- 토글 카드(구성): 선택 시 브랜드색 테두리+연한 배경. 아이콘은 이모지 유지.
- 모바일(<1020px): 미리보기가 아래로 내려가고 `미리보기 보기` 플로팅 버튼으로 점프.
- 인쇄 CSS(@media print)는 **한 글자도 건드리지 않는다** (SVG 표지·분리 인쇄 검증 완료 상태).

## 5. 딥링크 · 저장

- `#c=diag|b|c|d` — 과정. 없으면 Screen A.
- localStorage `gfPrint.course` 에 마지막 과정 저장, Screen A에서 "이어서: CARS B" 칩 표시.
- 기존 저장 키(`gfPrint.name/color/logo/cover/lang/scope`) 전부 유지.

## 6. 구현 순서 (커밋 단위)

1. Screen A 서재 + 과정 상태 + 해시 라우팅 (기존 사이드바는 숨김 처리로 공존)
2. Screen B 프레임(헤더/탭/아코디언 껍데기) + 기존 패널들을 스텝 안으로 이식
3. 진단 과정 전용 뷰 + 채점 탭 스코프
4. 교재 과정 전용 뷰 + 단원 평가 스코프 + 페이지 수 요약
5. 표지 실렌더 썸네일 + 브랜드 모달 + 최초 방문 온보딩
6. Playwright 검증: 서재→B 과정→통권 18쪽 생성→답안지→단원평가 분석지, 콘솔 에러 0
   (기존 테스트 t2/t5/t13 시나리오를 새 DOM 셀렉터로 갱신)
