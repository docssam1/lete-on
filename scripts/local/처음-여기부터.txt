OmniVoice 목소리 복제 — PC 에서 하는 법
================================================================

■ 1. 저장소 폴더가 PC 에 있나요?

  파일 탐색기 주소창에 아래를 붙여 넣고 엔터 — 폴더가 열리면 있는 겁니다.
  없으면 아래 2번으로.

      %USERPROFILE%

  그 안에 lete-on 폴더가 보이는지 찾아보세요.
  (다른 데 받아 두셨을 수도 있습니다. 탐색기 검색창에 lete-on 으로 찾아도 됩니다.)


■ 2. 없으면 — 한 번만 받으면 됩니다

  ① 윈도우 키 → cmd 입력 → 엔터 (검은 창이 열립니다)
  ② 아래 두 줄을 한 줄씩 붙여 넣고 엔터

      cd %USERPROFILE%
      git clone https://github.com/docssam1/lete-on.git

  git 이 없다고 나오면 https://git-scm.com/download/win 에서 설치한 뒤 다시.


■ 3. 실행 — 더블클릭 한 번

  받은 폴더에서 아래 경로를 따라 들어가 파일을 더블클릭하세요.

      lete-on \ scripts \ local \ omnivoice-clone.cmd

  최신 코드 받기(git pull)는 스크립트가 알아서 합니다. 따로 치실 것 없습니다.
  처음 한 번은 설치·모델 내려받기로 몇 분 걸리고, 그다음부터는 바로 돕니다.


■ 4. 소리는 어떻게 듣나요? (원격이면 중요)

  끝나면 clone\듣기.html 이 열립니다. 원본과 복제를 나란히 눌러 비교하는 화면입니다.

  원격 데스크톱이라 소리가 안 넘어오면 — 그 파일 한 장에 소리가 전부 들어 있습니다.
  카톡·메일 무엇으로든 본인 휴대폰으로 보내면 그냥 열려서 재생됩니다.

  (원격 프로그램의 소리 설정을 켜는 게 더 편합니다. 윈도우 원격 데스크톱이면
   연결 창 → 옵션 표시 → 로컬 리소스 → 원격 오디오 → 설정 → "이 컴퓨터에서 재생")


■ 5. 다 되면 알려 주실 두 가지

  · RTF 숫자 (검은 창 마지막에 찍힙니다)
  · 원본과 복제가 같은 목소리로 들리는지

  실패하면 검은 창 내용을 그대로 복사해서 주시면 됩니다.
