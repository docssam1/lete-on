# 원장 PC 에서 돌리는 것들 (로컬 전용)

클라우드 세션(Claude)에는 **GPU 가 없고** huggingface.co 도 막혀 있습니다. GPU 가 필요한
일은 여기 스크립트를 **원장님 PC 에서 더블클릭**으로 돌립니다.

| 파일 | 하는 일 | 키가 필요한가 |
|---|---|---|
| **`omnivoice-clone.cmd`** | **지금 쓰는 우리 목소리를 복제**해 `clone\` 에 담는다 ← **먼저 이것부터** | **아니오** |
| `omnivoice-audition.cmd` | 목소리를 새로 *설계*해 본다(누미·독쌤·할아버지 4종) | **아니오** |
| `_setup-omnivoice.cmd` | 위 둘이 같이 쓰는 준비 단계(가상환경·설치·GPU 확인) | — |

## omnivoice-clone.cmd ← 원장 지시(2026-09-21): "그냥 우리 나온 목소리 복제해"

**이게 먼저입니다.** 아이들이 이미 아는 누미 목소리가 바뀌면 안 되니까요. 목소리를 새로
설계하면 잘 나와도 *다른* 목소리가 되고, 게다가 설계는 중국어·영어로만 학습돼 한국어에서
불안정합니다. 복제는 그 둘을 한 번에 풉니다.

더블클릭하면:
1. 우리 MP3(공개 URL)에서 **언어마다 3~10초짜리 참조 음성**을 뽑습니다.
   `clone-ref\ko.wav` · `en.wav` · `zh.wav` + 같은 이름의 `.txt`(그 대사).
   **전사를 지어내지 않습니다** — 우리가 합성에 쓴 바로 그 문장을 그대로 씁니다.
   자동 전사(Whisper)를 쓰면 거기서 오차가 생깁니다.
2. 그 참조로 앱 대사를 다시 읽혀 `clone\` 에 담습니다.
3. **`clone\듣기.html`** 을 엽니다 — 원본과 복제가 한 화면에 나란히 있어 번갈아 눌러
   비교할 수 있습니다. 같은 사람 목소리로 들리면 성공입니다.

### 원격 데스크톱이라 소리가 안 들릴 때

원장 지적(2026-09-21): **"원격이라 소리를 어떻게 들어."** 맞습니다 — 원격 프로그램이
오디오를 안 넘기면 PC 에서 아무리 만들어도 들을 수가 없습니다.

**먼저 원격 프로그램 설정을 보세요.** 대개 이걸로 끝납니다.
- Windows 원격 데스크톱: 연결 창 → `옵션 표시` → `로컬 리소스` → `원격 오디오` → `설정`
  → **"이 컴퓨터에서 재생"**
- Chrome 원격 데스크톱: 기본으로 넘어옵니다
- AnyDesk: `설정` → `오디오` → "원격 컴퓨터 소리 전송"
- TeamViewer: `옵션` → `원격 제어` → "컴퓨터 소리 및 음악 재생"

**그래도 안 되면 `clone\듣기.html` 한 장만 옮기세요.** wav 를 base64 로 파일 안에 박아
넣었기 때문에 **그 파일 하나에 소리가 전부 들어 있습니다.** 메일·메신저·USB 무엇으로든
보내면 휴대폰에서도 그냥 열려서 재생됩니다 — 인터넷도, 같은 폴더의 다른 파일도 필요 없습니다.

참조만 먼저 확인하고 싶으면:
```
python scripts\omnivoice-clone.py --refs-only
```

> ⚠ 짚고 넘어간 것: TTS 업체가 만들어 준 음성을 복제하는 것은 일반적으로 약관이 다루는
> 영역이고, 그 목소리들은 실제 성우를 계약해 만든 것입니다. 구글 약관의 해당 조항은
> 확인하지 못했습니다(약관 페이지가 자바스크립트로 그려집니다). 위험을 아시고 진행하기로
> 한 것입니다. 깨끗한 대안은 **선생님이 직접 3~10초 읽는 것**이고, 그러면 독쌤이 진짜
> 선생님 목소리가 됩니다.

## omnivoice-audition.cmd — 목소리를 *새로* 설계해 보고 싶을 때

더블클릭하면 됩니다. 처음 한 번은 가상환경 만들기 + torch/OmniVoice 설치 + 모델
내려받기로 시간이 좀 걸리고, 그다음부터는 바로 돕니다.

- 결과는 저장소 루트의 `audition\` 폴더에 `<목소리>-<대사>.wav` 로 들어갑니다.
- 대사는 앱에 **실제로 들어 있는 것**을 씁니다(누미 3줄 + 영어·중국어 1줄씩) —
  시청용 문장을 따로 지어내면 지금 쓰는 구글 음성과 비교가 안 됩니다.
- 목소리 4종: `numi`(여아·높은 음) · `docssam`(남성·청년) · `elder`(남성·노년) ·
  `auto`(모델이 알아서 — 기준선).

### 들으실 때 볼 것 두 가지

1. **한국어가 쓸 만한가.** OmniVoice 한국어 학습량은 8,609시간으로 영어(206,061)의 1/24 입니다.
   게다가 공식 문서가 **목소리 설계(instruct)는 중국어·영어로만 학습**됐다고 못 박습니다 —
   즉 위 4종은 한국어에서 불안정할 수 있습니다. 여기서 별로면 **복제(clone)** 로 갑니다.
2. **RTF.** 로그 끝에 찍힙니다. "음성 1초를 만드는 데 몇 초 걸렸나"이고, 1 보다 작으면
   실시간보다 빠릅니다. 이 숫자가 운영에 쓸 수 있는지를 정합니다.

### 설계가 별로면 — 복제로

3~10초짜리 참조 음성 하나면 그 목소리로 전부 읽습니다. 문서가 "가장 안정적"이라고
한 쪽입니다.

```
python scripts\omnivoice-audition.py --out audition-clone --ref ref.wav --ref-text "안녕하세요, 저는 독쌤이에요."
```

> ⚠ 참조 음성은 **권리가 깨끗한 것**만 씁니다. 다른 TTS 업체가 만들어 준 음성을 복제하는
> 것은 약관 위반이 될 수 있습니다. **선생님이 직접 3~10초 읽는 것**이 가장 깨끗하고,
> 그러면 독쌤이 **진짜 선생님 목소리**가 됩니다 — 구글로는 애초에 못 하는 일입니다.
