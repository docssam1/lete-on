# 원장 PC 에서 돌리는 것들 (로컬 전용)

클라우드 세션(Claude)에는 **GPU 가 없고** huggingface.co 도 막혀 있습니다. GPU 가 필요한
일은 여기 스크립트를 **원장님 PC 에서 더블클릭**으로 돌립니다.

| 파일 | 하는 일 | 키가 필요한가 |
|---|---|---|
| `omnivoice-audition.cmd` | OmniVoice 로 누미·독쌤·할아버지 목소리를 만들어 `audition\` 에 담는다 | **아니오** — 아무것도 올리지 않습니다 |

## omnivoice-audition.cmd

더블클릭하면 됩니다. 처음 한 번은 가상환경 만들기 + torch/OmniVoice 설치 + 모델
내려받기로 시간이 좀 걸리고, 그다음부터는 바로 돕니다.

- 결과는 저장소 루트의 `audition\` 폴더에 `<목소리>-<대사>.wav` 로 들어갑니다.
- 대사는 앱에 **실제로 들어 있는 것**을 씁니다(누미 3줄 + 영어·중국어 1줄씩) —
  시청용 문장을 따로 지어내면 지금 쓰는 구글 음성과 비교가 안 됩니다.
- 목소리 4종: `numi`(여아·높은 음) · `docssam`(남성·청년) · `elder`(남성·노년) ·
  `auto`(모델이 알아서 — 기준선).

### 들으실 때 볼 것 두 가지

1. **한국어가 쓸 만한가.** OmniVoice 한국어 학습량은 8,609시간으로 영어(206,061)의 1/24 입니다.
   게다가 공식 문서가 **목소리 설계(instruct)는 중국어·영어로만 학습**됐다고 못 박습니다 —
   즉 위 4종은 한국어에서 불안정할 수 있습니다. 여기서 별로면 **복제(clone)** 로 갑니다.
2. **RTF.** 로그 끝에 찍힙니다. "음성 1초를 만드는 데 몇 초 걸렸나"이고, 1 보다 작으면
   실시간보다 빠릅니다. 이 숫자가 운영에 쓸 수 있는지를 정합니다.

### 설계가 별로면 — 복제로

3~10초짜리 참조 음성 하나면 그 목소리로 전부 읽습니다. 문서가 "가장 안정적"이라고
한 쪽입니다.

```
python scripts\omnivoice-audition.py --out audition-clone --ref ref.wav --ref-text "안녕하세요, 저는 독쌤이에요."
```

> ⚠ 참조 음성은 **권리가 깨끗한 것**만 씁니다. 다른 TTS 업체가 만들어 준 음성을 복제하는
> 것은 약관 위반이 될 수 있습니다. **선생님이 직접 3~10초 읽는 것**이 가장 깨끗하고,
> 그러면 독쌤이 **진짜 선생님 목소리**가 됩니다 — 구글로는 애초에 못 하는 일입니다.

### 다음 단계 (아직 안 만들었습니다)

시청 결과가 좋으면 그때 **운영 생성기**를 만듭니다 — 로컬 GPU 로 MP3 를 만들어 Supabase 에
