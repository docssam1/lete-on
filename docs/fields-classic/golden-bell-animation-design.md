# 골든벨 개념 애니메이션 설계

작성: 2026-09-06. 대상: 7세 8월부터 초등 1학년 초반, 필즈 더 클래식 1과정.

## 학습의 기준

한 설명은 한 문항의 조건과 그림으로 시작해서 같은 문항의 검산으로 끝난다.
다른 문항이나 다른 유형은 별도로 선택한다. 설명 재생에는 정답 입력 조건을 두지 않는다.
개념을 보고 문제를 풀 때는 기존의 문항별 입력, 힌트, 풀이, 넘어가기, 추가 학습을 활용한다.

연결 단위는 `과정 / 권 / 단원 / 활동 / 문항 / 소문항`이다.
원본의 순번과 내부 문항 ID를 함께 유지한다. 원본 그림과 공식 답의 출처는 비공개 자료에서 관리한다.
10권은 교사용 지도서의 활동을 근거로 만드는 자체 골든벨이다. 독립된 골든벨 원본이 있는 것으로 표시하지 않는다.

## 화면의 순서

1. 설명할 문제를 선택한다.
2. 문제와 조건, 처음 그림을 모두 보여준다.
3. 한 장면에서 한 행동만 설명한다.
4. 그림에서 바뀐 부분을 강조하고 수나 식을 함께 연결한다.
5. 결과를 처음 조건에 다시 넣어 확인한다.
6. 골든벨 문항과 같은 유형의 추가 학습으로 이어간다.

문제 위에 결과만 묻는 별도 퀴즈를 먼저 놓지 않는다.
어떤 수나 도형이 바뀌었는지 설명 없이 새 숫자로 교체하지 않는다.
설명의 마지막 장면까지 본 사실은 학생의 독립적인 문제 해결과 구분한다.

## 장면 데이터와 기존 코드 재사용

| 필드 | 의미 |
| --- | --- |
| sourceItemId | 설명 전체에서 바뀌지 않는 실제 문항 ID |
| problem / visual | 그 문항의 지문과 그림 데이터 |
| family | 실제 풀이 전략: 합쳐 등분, 같은 부분 빼기 등 |
| beats | 고유 장면 ID, 한 문장 설명, 동작, 유지 시간 |
| printSteps | 화면과 같은 데이터로 재현할 인쇄 장면 번호 |

그림과 수를 별도로 베껴 저장하지 않고 기존 문항 데이터에서 장면을 만든다.
쌓기나무는 `geometry/worksheet/generators.js`와 `render.js`의 높이맵, 시점, 투영, 숨김 판정을 사용한다.
화면 렌더러와 정지 장면 렌더러는 같은 함수를 사용한다.
공식 답이나 풀이를 새 공개 모듈에 하드코딩하지 않는다. 승인된 학습 세션에서 설명 재생을 연다.

## 우선 구현하는 장면

### 4권: 숨은 쌓기나무

원본 연결: 골든벨 활동 02, 슬라이드 18의 (1), (2), (3).
세 문항 각각에 독립적인 설명을 만든다.

1. 문제와 동일한 쌓기 모양을 고정한다.
2. 기둥을 하나씩 짚고 윗면에 그 기둥의 층수를 적는다.
3. 같은 자리를 위에서 본 바탕 그림에 표시한다.
4. 모든 층수를 더해 전체 개수를 구한다.
5. 그림에서 보이는 개수를 확인한다. 같은 나무의 여러 면을 중복해서 세지 않는다.
6. 전체에서 보이는 수를 빼 숨은 수를 구한다. 이 장면의 윗면 숫자는 '기둥에서 숨은 개수'라고 명시한다.
7. 보이는 수와 숨은 수를 더해 전체 수와 맞는지 확인한다.

설명 도중 모양, 시점, 바닥 칸을 바꾸지 않는다.
층수와 숨은 개수는 제목과 색을 함께 구분한다. 색만으로 뜻을 구분하지 않는다.
현재 제공된 높이맵과 시점에 대한 검산은 원본 그림만 보고 모든 숨은 배치를 유일하게 복원했다는 주장과 구분한다.

### 10권: 두 식을 합쳐 등분하기

원본 연결: 교사용 지도서 더딥 연습문제 1번 (1), (2).

1. 처음 두 저울의 모양 수와 무게를 보여준다.
2. 두 식의 모양들을 합친다. 총무게도 함께 더한다.
3. 같은 구성이 되도록 모양들을 묶는다.
4. 묶음 수에 맞춰 총무게를 똑같이 나눈다.
5. 한 묶음의 값을 처음 식에서 빼 각 모양의 값을 구한다.
6. 구한 값을 처음 두 식에 각각 넣어 검산한다.

### 10권: 같은 부분 빼기

원본 연결: 교사용 지도서 더딥 연습문제 2번.

1. 두 조건을 같은 순서로 나란히 놓는다.
2. 두 조건에 공통으로 있는 모양과 개수를 연결한다.
3. 두 조건에서 정확히 같은 부분을 함께 지운다.
4. 남은 모양과 무게의 차를 비교한다. 여러 개가 남으면 등분한다.
5. 구한 값을 처음 조건에 넣어 다른 모양을 구한다.
6. 처음 두 조건이 모두 성립하는지 확인한다.

### 10권: 과녁 점수 비교

원본 연결: 교사용 지도서 더딥 연습문제 3번.

1. 과녁의 구역과 두 사람의 맞힌 횟수, 총점을 함께 보여준다.
2. 두 기록에서 같은 구역을 같은 횟수만큼 맞힌 부분을 묶는다.
3. 공통된 부분을 양쪽에서 제거한다.
4. 남은 구역의 횟수와 점수 차로 한 번의 점수를 구한다.
5. 처음 기록에 넣어 물어본 구역의 점수를 구한다.
6. 두 기록의 총점을 모두 다시 확인한다.

## 다른 유형으로 확장할 설계

아래는 확장 설계이며 전 유형 구현 완료를 뜻하지 않는다. 실제 원본 문항을 연결한 뒤 구현한다.

| 유형 | 반드시 보여줄 변화 |
| --- | --- |
| 시계 / 회전 | 고정 시작점, 회전 방향과 이동량, 이동 경로, 도착점 |
| 접기 / 자르기 | 접는 축, 앞뒤 겹침, 실제 자른 위치, 역순으로 펼친 결과 |
| 도형 나누기 | 조건 제시, 경계선 직접 연결, 조각별 조건·합동 확인 |
| 표 안 도형의 수 | 근거가 되는 줄 강조, 같은 도형 위에 같은 값, 다음 줄 대입 |
| 세로셈 복면산 | 연산별 자리 정렬, 일의 자리, 받아올림·내림 또는 부분곱, 검산 |
| 삼각수 | 한 줄씩 점을 놓아 줄 길이가 하나씩 늘어남 |
| 사각수 | 가로·세로 배열, 새 테두리가 붙는 과정 |
| 삼각 계단 쌓기 | 실제 삼각형 층을 쌓기, 층별 개수와 누적 개수 구분 |
| 논리 / 조건표 | 문제 조건 먼저 제시, 근거 문장과 대응 칸, 후보 제거 |
| 숫자 카드 | 사용한 카드 표시, 남은 카드 수와 자리의 수를 함께 갱신 |
| 일정한 간격 | 시작과 끝 포함 여부, 이동한 간격 수와 점 수 구분 |
| 따라잡기 | 처음 차이, 한 번마다 변하는 두 양, 줄어드는 차이, 만나는 때 |

## 조작과 속도

- 재생, 멈춤, 이전, 다음, 다시, 장면 직접 선택을 제공한다.
- 처음 문제를 읽는 시간도 확보한다. 기본 장면 유지 시간은 약 4~5.5초이며 속도 선택을 적용한다.
- 이전·장면 직접 선택은 해당 상태를 즉시 재현한다. 다음 장면의 이동만 재생한다.
- 문제·권 변경, 인쇄, 화면을 떠날 때 재생을 멈춘다. 이전 문제의 타이머가 새 문제를 움직이지 않게 한다.
- 동작 줄이기 설정에서는 모든 장면의 정보가 정지 상태로 유지된다.
- 본문과 풀이 설명은 20px 이상, 수식은 약 22~24px, 터치 영역은 44px 이상을 기준으로 실제 모바일 화면을 확인한다.

## 인쇄

현재 학습 인쇄에는 선택한 개념 설명의 핵심 장면과 기존 골든벨·추가 학습을 포함한다.
쌓기나무 설명은 한 장에 최대 두 장면, 조건식과 계산을 함께 보여주는 10권 설명은 한 장에 한 장면을 배치한다.
설명용으로 풀이가 표시된 예제와 학생이 풀 문제를 구분한다. 학생 답칸에 정답을 채워 넣지 않는다.
각 문항의 지문·그림·답칸은 한 묶음이며, 애니메이션 제어와 잘린 장면은 인쇄하지 않는다.
교재 전체 인쇄는 현재 선택한 수업에는 선택한 설명 예제를, 다른 수업에는 첫 설명 예제를 사용한다. 원본 문제와 추가 학습은 전부 유지한다.

| 담당 | 작업 | 완료 근거 |
| --- | --- | --- |
| 주 에이전트 | 개념 구조, 장면의 수학적 의미, 통합·최종 판단 | 같은 문항 조건, 원본 대조, 렌더 결과 |
| LUNA 높은 | 지정된 원본 문항·그림 조사, 독립 검토 | 실제 열어 본 파일과 문항 식별자 |
| TERRA 높은 | 정해진 유형의 장면 렌더러와 검산 | 지정 파일 패치, 독립 계산, 정지·동작 장면 |

구현자와 최종 확인자를 구분한다. 파일 소유 범위는 겹치지 않게 지정한다.
원본, 공식 답, 단일 정답 여부, 학습 수준, PC·모바일·A4는 서로 다른 확인 항목이다.
이 설계의 그림 검산 통과로 1~10권 전체 문항의 원본 대조가 완료되었다고 표시하지 않는다.
정답이 하나인 문항은 유일성을 확인하고, 그리기·나누기처럼 여러 해가 허용되면 별도의 판정 기준을 사용한다.

## 현재 구현 범위

- 4권 활동 02의 숨은 쌓기나무 세 문항: 문항별 장면 재생에 연결.
- 10권 합쳐 등분 / 공통 부분 제거 / 과녁 비교: 지원하는 문항별 렌더러에 연결.
- 기존 다른 수업, 학생별 정오답 기록, 보호 답안 API, 연습문항은 재사용.
- 각 권 나머지 유형의 장면 제작과 전수 원본 검수는 후속 작업.
- 커밋·배포 상태와 실제 검증 결과는 작업 종료 보고에서 별도로 확인한다.

## 2026-09-06 검증 기록

- 원본 이미지 대조: 4권 슬라이드 18의 세 소문항, 10권 지도서 67~69쪽의 1번 두 소문항 및 2~4번. 10권의 오른쪽 목표 저울 세 개를 설명에도 유지하고, 근거를 구한 단계에서만 값을 표시한다.
- 수학 검산: 쌓기나무는 높이 0~3인 비어 있지 않은 2x2 배열 255개를 독립 점유 모델로 확인. 합과 차 세 유형은 원본 답을 복사하지 않은 별도 수치 예제의 양의 정수해를 열거하고 보존식·소거·등분을 검사했다.
- 화면 자동 검사: 1440px와 390px 각각 8문항, 70장면. 같은 문항 ID, 쌓기 모양의 동일 좌표, 넘침, 재생·멈춤·문항 변경 후 타이머 정지, 동작 줄이기를 검사했다.
- A4: 8문항의 설명을 각각 선택해 PDF 생성. 4권 해당 학습은 5쪽씩, 10권 해당 학습은 19~20쪽씩이며 원래 문항과 추가 학습을 포함한다. 의도한 페이지 수와 실제 PDF 페이지 수가 일치하고 바닥글 겹침이 없었다.
- 직접 확인한 출력: 쌓기나무 층수·전체 수, 저울 목표와 등분, 구슬 나누기 장면의 PDF 래스터 이미지. 모든 장면을 사람이 전수 육안 검수했다는 의미는 아니다.
- 보호 회귀 검사는 10권의 답 참조 2,272개를 통과했다. 화면 자동 검사는 빈 답안 응답을 쓰는 분리된 테스트 세션이므로 실제 운영 서버의 인증 성공이나 배포 완료의 증거는 아니다.
- 위 결과는 새로 연결한 8문항의 범위다. 1~10권의 모든 골든벨·본교재·추가 생성문항에 대한 원본·공식 답·학습 수준·유일답 전수 검수는 완료되지 않았다.

재현 검사: `golden-bell-cube-animation-audit.mjs`, `golden-bell-book10-animation-audit.mjs`, `golden-bell-source-animation-browser-audit.mjs`, `golden-bell-protection-audit.mjs`.
PDF와 화면 캡처는 비공개 검수 위치에 보관하며 공개 코드에 포함하지 않는다.
