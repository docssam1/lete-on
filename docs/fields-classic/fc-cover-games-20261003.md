# FC 표지 게임 안내

## 적용 범위

- 표지의 제목은 `게임으로 개념 익히기`이다. 본문 마지막 연습 페이지의 `게임으로 연습하기`는 유지한다.
- 선택한 학습 범위의 단원명, 게임 이름, 게임 전용 QR을 표지에 표시한다. 같은 게임은 표지에서 한 번만 표시한다.
- 현재 게임 카탈로그가 있는 1권 7개 게임에만 적용한다. 미구현 권의 게임이나 별도의 문제은행 링크를 대신 넣지 않는다.
- `게임 QR 포함`을 끄거나 표지 없음을 선택하면 표지 QR은 없다. 답안만·빠른 정답에는 표지 자체가 없다.
- 미리보기에는 게임 이름과 QR 자리만 표시한다. 미리보기를 열거나 단원을 선택한다고 링크를 발급하지 않는다. 실제 인쇄에서 기존 서버 발급·검증을 거친 QR만 넣는다.

## 인쇄와 권한

- 표지의 기존 단원·유형·개념 목록과 이름·날짜·워터마크를 보존한다. 표지 게임 수에 따라 27mm 또는 22mm QR을 배치하며 실제 PDF 해독을 검수한다.
- 인쇄 폰트·이미지 준비와 A4 본문/QR/푸터 겹침 검사를 완료한 뒤 인쇄한다. 표지의 배경 그림은 학습 본문이 아니므로 겹침 측정 대상에서 제외한다.
- 표지와 본문의 같은 게임은 같은 발급 URL을 쓴다. 발급 실패 시 인쇄물을 비우고 인쇄를 중단한다. QR 자리 표시자가 실제 출력물에 남지 않는다.
- 기존 게임 전용 서명 토큰을 재사용한다. QR의 권한은 해당 게임뿐이며 일반 로그인·문제은행 답안·링크 재발급 권한이 아니다. 기존 승인 계정 권한은 유지한다.
- 공개 주소의 직접 입력을 전역 차단하는 기기 잠금은 아니다. 서버·인증 함수·DB 스키마는 이번 표지 변경에서 수정하지 않는다.

## 검수

- `golden-bell-cover-games-audit.mjs`: PC/390px 미리보기, 선택 단원, 배경 두 종류, 실제 PDF, QR 해독, 인쇄 네 모드, QR 제외·표지 제외·지원하지 않는 권·실패 경로.
- `golden-bell-game-qr-audit.mjs`: 기존 게임 링크/인쇄 회귀. 표지 QR의 새 계약에 맞춰 기존 표지 QR 없음 기대값만 변경한다.
- `golden-bell-selected-print-audit.mjs`: 선택 범위·표지·답안·양면·다른 권의 기존 인쇄 회귀.
- 휴대폰 카메라와 실제 프린터로 스캔하는 검수는 브라우저/PDF 검수와 별개이다. 전권 수학 내용 재검수 완료를 뜻하지 않는다.
