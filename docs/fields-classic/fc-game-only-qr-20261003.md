# FC 학습지 게임 전용 QR

## 제공 범위

- 현재 제작·검수된 1권 체험 7개를 사용한다. 새로운 게임을 임의 생성하거나 다른 권에 잘못 연결하지 않는다. 향후 다른 권의 게임을 승인하면 서버의 고정 게임 목록과 단원 연결을 함께 확장한다.
- 학습지와 함께 인쇄할 때 각 학습의 마지막 추가 연습 페이지 아래에 `게임으로 연습하기`, 게임 이름, 27mm 벡터 QR, 한국 시간 기준 만료 날짜·시각을 표시한다. 추가 연습이 없으면 원문 연습 페이지를 사용한다. 같은 학습의 앞쪽 페이지에는 QR을 반복하지 않는다.
- 표지, 개념 설명 그림, 답안·풀이, 빠른 정답, 양면용 빈 면에는 넣지 않는다. 기존 단원 선택·배경 표지·답안 포함·양면 시작 면을 유지한다.
- `게임 QR 포함` 기본 선택. 승인 계정의 기존 Fields 세션으로 발급한다. 비로그인 또는 발급 실패 시 깨진 QR을 인쇄하지 않는다. QR을 제외하면 기존 학습지 인쇄가 가능하다.

## 권한 경계

1. 인쇄 시 `fields-game-link`의 `issue`가 기존 `x-fields-session`을 서버에서 검증한다. 공개 계정명이나 학생 URL을 인증 수단으로 사용하지 않는다.
2. 서버가 게임 ID·만료를 HMAC-SHA256으로 서명한다. URL 조각(fragment)에는 해당 게임의 제한 토큰만 담는다. 이름, 연락처, 학생 로그인 토큰, 정답을 넣지 않는다.
3. `game.html`은 정상 로그인 세션을 읽거나 저장하지 않고 제한 토큰만 서버에 보내 검증한다. 검증 전에는 체험 모듈을 가져오지 않는다. 정상 승인 사용자의 기존 세션을 삭제하거나 변경하지 않는다.
4. 검증된 한 게임의 도전과 다시 시작만 제공한다. 다른 게임 탭·문제은행 링크·연결 문제 풀기 버튼을 제공하지 않는다. URL의 다른 게임·권 선택 매개변수는 사용하지 않는다.
5. 이 토큰은 기존 로그인·답안 API의 세션 형식과 다르고 발급 권한도 없다. `resolve`에 게임·권을 별도 지정하는 요청은 거부한다. QR 접속을 일반 문제은행 로그인으로 승격하지 않는다.

게임 링크는 발급 시점부터 365일 유효한 전달 가능한 링크다. 개별 학생 인증이나 개인 성적 기록을 뜻하지 않는다. 링크를 가진 사람은 그 게임을 연습할 수 있다. 개별 취소 기능은 없으며 서버 서명 키 변경 시 기존 링크가 무효화된다.

이 기능은 QR 화면·권한을 제한하는 것이며 브라우저를 잠그는 키오스크가 아니다. 다른 공개 사이트/문제은행의 공개 URL에 직접 접속하는 행위까지 차단하지 않는다. 기존 정상 승인 사용자의 문제은행 접근 권한도 박탈하지 않는다.

## 검수

- 독립 에이전트 서버 구현 후 주 담당 통합·검수. 서버 단위 테스트 39개: 실제 세션 확인, 비활성·만료 계정, 변조·만료·범위 변경, 다른 서명 키, 크기 제한, CORS, 기존 세션 불변.
- `golden-bell-game-qr-audit.mjs`: PC 1440px·모바일 390px에서 7개 게임×3도전, 완료 후 같은 게임 재시작, 타 게임 URL 매개변수 무시, 원래 세션 불변, 문제은행 모듈/API 미요청, 잘못된 QR·만료·실패 상태.
- 학습지·학습지+풀이·풀이·빠른 정답 및 모바일 학습지 실제 A4 PDF. QR 14개 인쇄 해상도 이미지와 실제 PDF QR 영역 2개 해독. 종이 영역·풀이 시작 면·QR 제외 페이지·실패 시 인쇄 차단 확인.
- 기존 QR 제외 인쇄의 선택·표지·원문 진행 검수는 별도의 기존 감사 스크립트로 유지한다. 그 스크립트는 QR을 제외하고, QR 포함 흐름은 전용 감사에서 검사한다.
- 기존 체험 회귀는 `golden-bell-hands-on-audit.mjs --game-only`로 검사한다. 이 구형 스크립트의 전체 인쇄 모드는 현재 원문 학습과 무관한 `D*` 체험 문항 3개의 인쇄를 강제해 실패한다. 그 문항을 다시 교재에 끼워 넣거나 검사 실패를 통과로 기록하지 않는다. 현행 원문 인쇄는 `golden-bell-book01-source-browser-audit.mjs`의 8개 모드·화면 조합과 선택 인쇄 감사로 별도 검증한다.
- 독립 재검토에서 UTC 만료 날짜 표기를 발견해 `Asia/Seoul` 날짜·시각으로 수정하고 자정 경계 테스트 및 PDF 5종을 재검수했다. 전권 원문·수학 검수 완료 주장이 아니다.
- 실제 서버 15개 검증: 승인 발급 7개, 익명 해당 게임 열기, 변조·범위 변경 거부, 게임 토큰으로 로그인·답안·다른 링크 발급 거부. 검수용 로그인 세션은 종료한다.
- E 드라이브 검수 근거: `E:/Codex/visualizations/2026/08/21/01a02559-fa29-7082-8f7d-90a53fd070e2/fc-game-qr-20261003`. 교재 원본·정답 파일을 공개 저장소에 추가하지 않는다.

## 서버 배포

새 `fields-game-link` 함수에만 `verify_jwt=false`를 사용하고, 함수 본문의 기존 세션 검사/제한 서명 검사를 필수로 유지한다. 기존 인증·답안 함수나 DB 스키마는 변경하지 않는다. 함수 배포가 정적 Pages 배포와 별도임을 구분한다.

기존 `number_magic/vendor/qrcode.js`의 MIT 라이선스 `qrcode-generator 2.0.4`를 FC 내부에 그대로 재사용한다. 검수용 디코더 `jsQR 1.4.0`은 E 검수 폴더에만 보관하고 npm SHA512 무결성을 확인한다. 브라우저 인쇄용 QR은 벡터이고 외부 QR 서비스에 토큰을 전달하지 않는다.

실제 휴대전화 카메라와 실제 종이·프린터의 스캔은 별도 확인 대상이다. PDF 해독 성공을 실물 기기 전수 확인으로 표시하지 않는다.
