# 지오메트리 문제은행 연결표

필즈 문제은행의 쌓기나무 그림과 계산을 따로 복제하지 않는다. 아래 유형은
`geometry/worksheet/generators.js`, `render.js`, `card.js`를 직접 사용한다.
따라서 같은 시드라면 지오메트리 학습지와 필즈 문제은행의 모양·정답이 같다.

## 출처 표시 원칙

- `sourceMatched: true`: 실제 시험지 문항의 그림·조건·답과 1:1 대조가 끝난 유형이다.
- `bankApproved: true`: Geometry World에서 수학·SVG·정답을 독립 검산한 공용 확장
  유형이다. 필즈 시험 원본에 나온 유형이라고 표시하지 않는다.
- 두 유형 모두 무한 생성할 수 있지만, 화면에는 각각 `실제 출제 유형`과
  `연계 문제은행 유형`으로 구분해 보여 준다.
- 실제 시험에서 대조된 연결은 `cube-step-sequence`, `cube-hidden-count-walled`,
  `cube-fill-box`, `cube-count-solid`, `cube-hidden-count`다. 나머지 공용 연결은
  사용자가 승인한 문제은행 확장 범위다.

## 공용 13유형

| 코드 | 필즈 유형 ID | 세부 유형 | 구분 기준 |
|---|---|---|---|
| TC | `cube-top-number-grid` | 위에서 본 바탕그림의 수로 전체 개수와 앞·옆 모양 구하기 | 칸 안에 각 기둥의 높이가 주어짐 |
| VC | `cube-three-views` | 위·앞·옆 모양을 보고 전체 개수 구하기 | 세 방향 그림이 모두 주어짐 |
| VM | `cube-three-view-minmax` | 세 방향 그림으로 가능한 최대·최소 개수 구하기 | 가능한 입체가 여러 개임 |
| VP | `cube-missing-view` | 두 방향을 보고 나머지 한 방향 그리기 | 답이 숫자가 아니라 그림임 |
| IC | `cube-count-solid` | 입체 그림에서 전체 개수 세기 | 실제 쌓은 입체가 보임 |
| IH | `cube-hidden-count-walled` | 벽 모서리에서 보이지 않는 개수 | 뒤·왼쪽 벽이 있음 |
| IN | `cube-hidden-count` | 벽 없이 어느 쪽에서도 보이지 않는 개수 | 바깥 모든 방향을 기준으로 셈 |
| FB | `cube-fill-rectangular-box` | 직육면체 상자 채우기 | 가로·세로·높이가 서로 다를 수 있음 |
| CU | `cube-fill-box` | 정육면체 완성 | 가로·세로·높이가 같음 |
| PN | `cube-painted-faces` | 겉면을 칠한 뒤 면·낱개 개수 구하기 | 색칠된 면 수로 분류함 |
| BW | `cube-black-white-alternating` | 같은 색이 맞닿지 않는 흰색·검은색 개수 | 3차원 흑백 교차 규칙 |
| HL | `cube-tunnel` | 여러 방향으로 구멍을 뚫은 뒤 남은 개수 | 교차 구멍은 한 번만 뺌 |
| SQ | `cube-pattern-sequence` | 여러 모양으로 커지는 쌓기나무 규칙 | 단계별 모양과 전체 개수가 함께 변함 |

## 시험 원본 전용 연결

- `cube-step-sequence`: 파이널 3회 원본과 같은 **삼각 계단**만 뽑는다. 공용 SQ의
  십자·정사각형·사각뿔 등과 섞지 않는다.
- `cube-hidden-count-walled`: 파이널 2회 원본의 벽 있는 구조를 유지한다.
- `cube-fill-box`: 파이널 3회 원본과 비슷한 현재 배치 수 범위를 유지한다.

전용 생성기가 있는 위 세 유형은 공용 코드도 기록하지만, 필즈에서는 전용 생성기를
먼저 호출한다. 전용 생성이 실패했다고 공용 문제로 바꾸지 않고 문항을 만들지 않는다.

## 난이도 규칙

- `worksheetLevel`: `같게`에서 쓰는 기준 크기와 선행 단계를 고정한다.
- 문제은행의 `쉽게·같게·어렵게`: 강도 1·2·3을 적용하고, 어렵게는 지원되는
  다음 단계가 있으면 한 단계 올린다. 쉽게는 기준보다 낮은 지원 단계가 있을 때만
  한 단계 내린다.
- 강도는 숫자만 키우는 값이 아니다. 묻는 항목 수, 그려야 하는 방향, 가능한 배치의
  수, 구멍 방향 수처럼 풀이 단계를 바꾼다.
- VM 최대·최소 유형은 답안에 최대 배치와 최소 배치를 각각 그린다. 두 답을 한
  배치 그림으로 대신하지 않는다.

## 금지

- `앞·옆·위`를 한 유형으로 다시 합치지 않는다. VC·VM·VP는 서로 다른 문제다.
- 벽 있는 숨은 개수(IH)와 벽 없는 숨은 개수(IN)를 합치지 않는다.
- 직육면체 채우기(FB)와 정육면체 완성(CU)을 합치지 않는다.
- 실제 필즈 문항을 쌓기나무 색칠·본뜨기 활동으로 바꾸지 않는다.
- SVG와 정답 공식을 필즈 폴더에 한 벌 더 복사하지 않는다.
