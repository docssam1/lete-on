# 실전 모의고사 1~6회 원본 대조표

## 범위와 근거

- 대상: `필즈선발대비 실전 모의고사 실전 1회.pdf`부터 `실전 6회.pdf`
- 문제 이미지: `assets/print/mock-set/page_001.webp`~`page_063.webp`
- 정답 근거: 비공개 원본 `필즈온라인셋트답지.pdf`의 해당 회차 풀이 페이지
- 보조 근거: 회차별 강의 대본. 자동 전사가 원본 계산과 다르면 문제 그림과 계산을 우선한다.
- 이 문서는 원본 지문이나 페이지 이미지를 복제하지 않고 문항 구조, 정답, 유형과 위치만 기록한다.
- 진단 모의고사와 기존 처방전 유사문제는 이 표의 변경 대상이 아니다.

## 검증 규칙

1. 문제 그림, 조건, 물은 값, 답지 풀이를 한 문항씩 함께 확인한다.
2. 여러 칸을 채우거나 그림을 그리는 문항은 단일 숫자로 축약하지 않는다.
3. 대본 숫자가 흐리거나 잘못 전사된 경우 독립 계산으로 다시 확인한다.
4. 같은 단원명이어도 구조가 다르면 세부 유형을 분리한다.
5. 아래 100문항은 원본 답지와 문제 구조 대조를 마친 승인본이다.
