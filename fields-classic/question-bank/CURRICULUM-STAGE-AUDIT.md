# 더클래식 1과정 교재 단계·문제번호 감사

## 적용 원칙

- 교재 단원별 문제은행은 `개념·유형·연습·심화` 네 단계를 유지한다.
- 페이지 번호는 판본마다 달라질 수 있으므로 런타임 연결에 사용하지 않는다.
- 문항의 안정 키는 `권-단원-섹션-그룹-문제번호`로 만든다.
- 예: `book-02/unit-03/check-02/q-04`는 2권 3단원 두 번째 확인 구역 4번이다.
- 시험 문제은행의 `이 문제보다 쉽게·같게·어렵게`와 교재 네 단계는 서로 다른 축이다.
- 원본 PDF와 전체 페이지 이미지는 공개 저장소에 넣지 않는다. 파일명과 구조화된 색인만 기록한다.

## 색인 결과

- 10권, 40단원, 4단계
- 244개 문제번호 구간
- 1,618개 중복 없는 원본 문항 키
- 교재에 연결된 세부 유형 149종
- 149종 모두 개념 단계용 풀이 발판을 별도로 가짐
- 1권 32종, 2권 33종, 3권 41종은 세부 유형별 실제 등장 단계와 문제번호를 따로 저장한다.
- 1권 163문항, 2권 154문항, 3권 146문항은 누락·중복 없이 정확히 한 세부 유형에 배정된다.
- 세 권의 상세 분류는 총 106개 유형, 463개 원본 문항이다.
- 대부분 단원은 활동과 확인 구역이 각각 2개다.
- 7권 2단원과 10권 1단원은 활동과 확인 구역이 각각 3개다. 따라서 두 구역으로 고정해 추정하지 않고 원본 구역 수를 그대로 저장한다.
