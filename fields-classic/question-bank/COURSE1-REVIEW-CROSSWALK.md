# 더클래식 1과정 리뷰 연결 기준

## 결정

2권부터 책 뒤에 있는 리뷰는 현재 권의 새 단원이 아니다. 바로 앞 권의 핵심 유형을 다시 묻는 누적 복습 자료다.

| 2권 | 1권 | 1권 세부 유형의 복습·재출제 근거 |
| 3권 | 2권 | 2권 세부 유형의 복습·재출제 근거 |

1권 뒤 자료는 앞 권 연결 대상이 없으므로 이 교차표에는 넣지 않는다. 골든벨은 리뷰 교차표나 4단계 문항 수에 섞지 않고, 별도 개념 설명·원본 확인·스토리 확장 학습 트랙으로 연결한다.

## 원본 확인

- 2권 리뷰 첫 묶음은 거울·회전, 다음 묶음은 색종이 접기, 이어서 마방진·수 추리로 1권 네 단원의 구조를 다시 묻는다.
- 3권 리뷰는 똑같이 가르기, 양팔저울, 수열, 약속과 스도쿠로 2권 네 단원의 구조를 다시 묻는다.
- 위 확인은 교사용 PDF의 리뷰 묶음과 앞 권 원본 대조표를 함께 본 결과다.
- 4~10권도 같은 연결 원칙을 적용하되, 세부 유형 선택은 각 리뷰의 인쇄 문제번호를 원본과 1:1로 대조한 뒤에만 연다.

## 문제번호 키

페이지는 판본에 따라 달라질 수 있으므로 런타임 키로 쓰지 않는다.

```text
book-02/review-of-book-01/review-01/q-01
book-03/review-of-book-02/review-02/q-04
```

각 리뷰 문항은 다음 항목을 가진다.

- `hostBook`: 리뷰가 실린 권
- `sourceBook`: 실제 학습 유형이 속한 앞 권
- `reviewGroup`: 리뷰 묶음의 인쇄 번호
- `questionNumber`: 묶음 안의 인쇄 문제번호
- `typeId`: 앞 권에서 확정한 세부 유형 ID
- `difficultyRole`: 같은 수준 복습, 쉬운 회상, 심화 재적용 중 하나

## 문제은행 반영 규칙

1. 리뷰 문항을 현재 권의 유형 수에 더하지 않는다.
2. 앞 권 생성기를 그대로 재사용하고 새 생성기를 중복으로 만들지 않는다.
3. 리뷰에 다시 나온 횟수는 시험 출제 가능성을 판단하는 반복 근거로 집계한다.
4. 단원테스트와 모의고사에서 같은 유형이 나오면 `교재 본문 → 다음 권 리뷰 → 단원테스트 → 모의고사`의 출처 사슬을 남긴다.
5. 문제번호 대조가 끝나지 않은 리뷰 유형은 선택 UI에서 잠근다.
6. 문제 지문·보기·그림·정답 계산 구조가 같을 때만 같은 유형으로 연결한다. 단원명이 같다는 이유만으로 합치지 않는다.
7. 원본 PDF와 전체 페이지 이미지는 비공개 드라이브에만 두고 공개 저장소에는 연결표와 검증 기록만 저장한다.

## 현재 상태

- 2권 리뷰 → 1권: 36문항 문제번호별 연결 완료
- 3권 리뷰 → 2권: 37문항 문제번호별 연결 완료
- 4~10권 세부 문제번호 → 유형 ID: 순차 대조 중

세부 문제번호 연결이 끝날 때마다 각 `BOOKNN-SOURCE-AUDIT.md`에 리뷰 교차표를 추가하고, 누락·중복 0건을 확인한 뒤 UI를 연다.
