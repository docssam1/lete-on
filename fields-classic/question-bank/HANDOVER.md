# 필즈 더 클래식 문제은행 인수인계

## 현재 목표

진단 모의고사의 기존 유사문제는 그대로 둔다. 새 `question-bank`는 실제 선발시험, 필즈 더 클래식 1과정 교재 본문, 권별 단원 테스트를 원본 문항과 1:1로 대조한 뒤에만 무한 생성 문제를 여는 별도 상품이다. 장기적으로는 필즈 더 클래식 전용 목록이 아니라 여러 사고력 교재와 시험을 한 공통 분류 체계로 연결하는 통합 문제은행으로 확장한다.

교재 1과정은 단순 원본 뷰어가 아니다. 각 권과 단원에서 다음을 모두 만든다.

1. 교재 본문 원본 문제 보기
2. 교재 본문과 구조가 같은 유사문제 무한 생성·학습
3. 권별 단원 테스트 원본 문제와 단원 테스트 유사문제 학습

교재 본문과 단원 테스트의 유사문제도 실제 선발시험과 같이 원본 그림·조건·답을 문항별로 대조하고, 쉬움·같게·어려움별 검산을 통과한 유형만 연다.

## 문제은행 UI의 세 가지 구성

메인 화면에서는 아래 세 가지 기준을 서로 분명하게 나누어 제공한다. 세 화면 모두 여러 문항과 여러 유형을 동시에 체크할 수 있어야 한다.

### 1. 시험 종류에 따른 문제은행

- 실제 선발시험, 실전 모의고사, 교재 단원 테스트 등 시험 종류를 먼저 고른다.
- 선택한 시험지의 실제 문항 번호가 1번부터 끝까지 표시된다.
- 사용자는 원하는 원본 문항 번호를 여러 개 체크해 그 문항들과 같은 구조의 문제지 또는 유사문제 학습을 만든다.
- 원본 대조와 생성기 검증이 끝나지 않은 문항은 보이되 선택할 수 없게 한다.

### 2. 시기에 따른 문제은행

- 사용자가 지정한 시험 시기 순서로 선택한다: 6세 12월-7세 2월, 7세 3-5월, 7세 6-8월, 7세 9-12월, 7세 12월-8세 2월, 초1 3-5월, 초1 6-8월, 초1 8-10월, 초1 11월-1월.
- 시기를 선택하면 그 시기에 해당하는 실제 시험지·교재 단원·검증된 세부 유형을 한 화면에 보여 준다.
- 시기별 문제지는 원본 출제 수준을 기준으로 구성하고, 필요하면 `이 문제보다 쉽게·같게·어렵게`를 선택한다.

### 3. 유형에 따른 문제은행

- `대분류 > 중분류 > 세부 유형`의 펼침형 체크 트리를 사용한다.
- 대분류 예: 수와 연산, 규칙과 관계, 논리와 문제해결, 도형과 공간.
- 세부 유형마다 연결된 실제 시험지 이름과 문항 번호를 표시한다.
- 서로 구조가 다른 문항은 이름이 비슷해도 같은 세부 유형으로 합치지 않는다.
- 선택한 여러 유형의 문항 수, 난이도, 출제 순서 또는 섞어서 보기를 설정해 문제지를 만든다.

교재 단원별 선택은 위 세 화면과 별도로 없애는 기능이 아니다. `시험 종류`에서는 단원 테스트로, `시기`에서는 해당 시기의 교재 단원으로, `유형`에서는 해당 단원의 세부 유형으로 각각 접근할 수 있어야 한다.

## 절대 규칙

1. 문항 번호별로 원본 문제지 그림, 조건, 답안지를 모두 대조한다.
2. 제목이 비슷해도 구조가 다르면 다른 세부 유형으로 만든다.
3. 생성기는 답을 코드로 계산하고, 쉬움·같게·어려움은 원본 대비 조건 수와 구조로 조절한다. 숫자 범위만 바꿔 난이도를 표시하지 않는다.
4. 원본 대조와 난수 검산이 끝난 문항만 `verified: true` 및 `sourceMatched: true`로 연다.
5. Golden Bell, 연산 테스트, 2권 이후 교재 뒤 리뷰는 제외한다.
6. `fields-classic/prescription/` 및 `fields-classic/problem-bank/prescription/`의 기존 진단 유사문제는 수정하지 않는다.
7. 문항 제작 세부 기준은 `QUESTION-AUTHORING-GUIDE.md`를 먼저 읽고 따른다.
8. 대·중·세부 유형명은 특정 교재나 시험 이름에 종속시키지 않는다. 출처명·권·단원·문항 번호는 근거 메타데이터로 보존하고, 공통 사고 구조는 통합 유형명으로 관리한다.
9. 같은 공통 유형 안에서도 풀이 구조가 같고 도형 재료만 달라지는 경우에는 변형으로 나눈다. `성냥개비 도형 수열`의 허용 변형은 `삼각형·사각형·오각형·육각형`까지만이며 칠각형 이상은 만들지 않는다. 증가 규칙이나 물어보는 값이 달라지면 별도 세부 유형으로 분리한다.

## 연산 자료의 시험 시기 기준

연산은 이 문제은행 본체가 아니라 별도의 연산 연습 프로그램으로 만든다. 파일명에 적힌 학년만 보고 시험 시기를 판단하면 안 된다.

- `3더_클래식_2학년_선발시험.pdf`는 **초1 11월 연산 테스트**로 사용한다.
- 초1 11월 이전 연산은 공통 연산 단계로 사용한다.
- 초1 선발시험의 시기 구분은 별도 시험지 기준으로 관리한다: 초1 3-5월, 6-8월, 8-10월, 11월-1월.
- 연산 문제를 추가할 때에도 원본 범위, 받아올림·받아내림 여부, 답 형식을 대조한 뒤 생성기로 옮긴다.
