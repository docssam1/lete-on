# 필즈 시험문제 문제은행

진단 모의고사의 기존 유사문제와 분리된 시험문제 생성기입니다.

## 분류 기준

- 시험 시기: 연령과 월 구간
- 문제 영역: 수와 연산, 규칙과 관계, 논리 추리, 도형과 공간, 쌓기나무·입체
- 세부 유형: 한 가지 풀이 원리가 유지되는 최소 단위
- 난이도: 원본 대비 쉽게·같게·어렵게. 조건 수, 추론 단계, 그림 복잡도로 조절
- 수의 범위: 문항 유형에 필요할 때만 별도 조건으로 사용하며 난이도와 혼동하지 않음

문항 제작, 보기 구성, 그림 렌더, 검산, 저작권 원본 저장 기준은 [`QUESTION-AUTHORING-GUIDE.md`](./QUESTION-AUTHORING-GUIDE.md)를 먼저 확인합니다.

## 쌓기나무

쌓기나무 문제는 `geometry/cube-town/`의 기존 데이터와 출력기를 사용합니다. 새 그림을 복제하지 않습니다.

현재 출력 연결 유형:

- 똑같이 쌓기 · 원목 관찰
- 똑같이 쌓기 · 컬러 색칠
- 쌓기나무 개수 세기

Geometry World의 12개 세부 유형은 `catalog.js`의 `GEOMETRY_CUBE_TYPES`에 등록되어 있습니다.
