# 2과정 설계 — 1과정과 같은 틀, 개념은 더 깊게

> 원장 2026-11-21 「이제 2과정. 1과정과 같은 형태로 설계, 단 개념 부분이 좀 더 디테일해야 돼. 지금처럼 2과정을 나열하는 게 아니라 설계부터」
> 이 문서가 2과정 작업의 기준이다. 만들기 전에 여기부터 읽고, 정한 것이 바뀌면 여기를 먼저 고친다.

---

## 1. 지금 상태와 고칠 점

| | 1과정 | 2과정(지금) |
|---|---|---|
| 들어가는 길 | 권 → 단원 → 차시 카드 | 권 카드에 그림 논증·체험·권별 테스트 칩을 **나열** |
| 차시 덱 | 10권 82차시 모두 | G1 한 권만 시범(9차시) |
| 개념 | 판서 → 게임 → 워밍업이 개념마다 한 묶음 | 논증 48개가 따로 논다. 차시마다 깊이가 들쭉날쭉(G1 4단원 1차시는 개념 0개) |
| 교재 번호 ↔ 유형 | 전 권 | G1만(172문항) |
| 차시 교재 인쇄 | 전 차시 | G1만 |
| 진도표·잠금·관리 | 됨 | G1 일부만 |

고칠 점은 둘이다.

1. **나열 → 한 줄기.** 2과정 10권을 1과정과 같은 「권 → 단원 → 차시」로 세운다. 논증·체험·테스트는 차시 안의 제자리로 들어간다.
2. **개념을 깊게.** 지금 개념 장은 「보여 주고 끝」이다. 정리·예제·확인이 없어 교재 문제로 바로 넘어간다. 2과정은 문제마다 여러 성질을 이어 써야 하므로 개념 하나를 **여섯 장 꾸러미**로 가르친다(4절).

---

## 2. 원칙

1. **틀은 1과정 것을 그대로 쓴다.** 시작 화면·차시 덱·진도표·오답 유사문제·차시 교재 인쇄·회원 잠금·강사용 교안 — 2과정용 화면을 따로 만들지 않는다(같은 파일, 권 id만 `course-02-…`).
2. **다른 것은 개념 하나뿐이다.** 1과정 = 「해 보니 그렇다」. 2과정 = 「왜 반드시 그런가」 + 「그래서 어떻게 쓰는가」.
3. **차시 = 교재의 「활동」 묶음 하나**(1과정과 같은 규칙). **개념 = 그 활동 안의 풀이 생각 하나** — 한 차시에 개념이 2~4개 들어간다(G1 3단원 1차시: 삼각형 세 각 · 이등변삼각형 · 정다각형 내각 · 외각 · 시계 각).
4. **신판(N30)만 기준.** 워밍업 원본이 없으므로 워밍업 장은 만들지 않고, 그 자리에 「개념 확인」을 둔다.
5. 정답은 비공개 DB에만, 화면 말·그림·수식 규칙은 지금 것 그대로(「교재」「유사문제」「건너뛰기」, 분수는 수식, 회사 이름 금지).

## 3. 구조 — 과정 → 권 → 단원 → 차시

- **권 10** — 기하 G1~G5, 대수 A1~A5. 권마다 4단원.
- **차시** — 단원의 활동 묶음 수만큼(2개면 2차시, 3개면 3차시). G1은 9차시(3·2·2·2). 다른 권도 8~9차시로 보면 2과정은 **약 85차시**.
- **한 차시의 차례**(1과정과 나란히):

| 차례 | 1과정 | 2과정 |
|---|---|---|
| 1 | 표지 · 교재 인쇄 묻기 | 같음 |
| 2 | 데일리 테스트 4문제(2차시부터) | 같음 |
| 3 | 개념 판서 → 게임 → 워밍업 (개념마다) | **개념 꾸러미 여섯 장** (개념마다, 4절) |
| 4 | 공부하기(교재 확인·연습·도전) | 같음 |
| 5 | 워크북 간지 → 오늘의 과제 | 같음 |
| 6 | 단원 평가 10문제(단원 마지막 차시) | 같음 |
| 7 | 권별 테스트(권 마지막 차시) | 같음(시험지는 이미 10권 다 있음) |

## 4. 개념 꾸러미 — 개념 하나를 여섯 장으로

| 장 | 이름 | 하는 일 | 지금 있는 것 |
|---|---|---|---|
| ① | **되짚기** | 이 개념에 필요한 앞 개념 한 장. 1과정 판서의 마지막 장면이나 앞 단원 정리 카드를 보여 주고 한 번 묻는다 | 1과정 판서 |
| ② | **해 보기** | 설명 전에 손으로 먼저 — 체험 도구·게임. 끝에 「무엇이 늘 같았나요?」를 한 번 고르게 한다 | 체험 4종, 연습 게임, 지오메트리 게임 |
| ③ | **따져 보기** | 그림 논증. 장면마다 주장 + 까닭이 쌓이고 「다른 모양으로」로 일반화 | 논증 48개(기하만) |
| ④ | **정리** | 용어 뜻 · 성질 · 식을 한 장에. 인쇄 교재의 「개념 정리」 칸과 같은 내용 | **없음 — 새로** |
| ⑤ | **예제 따라 풀기** | 교재 활동 문제 가운데 이 개념의 대표 문제 하나를 단계로. 한 번에 한 칸만 채우고, 틀리면 그 단계의 까닭을 되묻는다 | **없음 — 새로** |
| ⑥ | **개념 확인** | 같은 유형 3문제(쉬움 · 교재와 같게 · 흔한 실수를 건드리는 문제). 틀리면 ③의 그 장면으로 돌아가는 단추 | 유형 생성기(G1만) |

- **흔한 실수 한 줄**을 꾸러미마다 둔다(예: 「시계 두 바늘 사이 각 — 시침이 그동안 움직인 만큼을 빼먹는다」). ⑥의 셋째 문제가 그 실수를 건드린다.
- ①②는 짧게(각 1~2분), 무게는 ③④⑤에 둔다. ②가 마땅치 않은 개념(순수한 셈 규칙)은 ②를 빼도 되지만 **④⑤⑥은 빠지면 안 된다.**
- **대수(A권)의 ③은 「식으로 따져 보기」** — 저울·수 배열·달력·마방진 칸·세로셈이 움직이며 규칙을 보이고, 마지막 장면에서 식으로 묶는다. 엔진은 같은 `proof-board.js`, 그림 도구만 더한다.

### 자료 꼴

권마다 `course2-concepts/<권>.js` 한 파일. 지금의 `SESSION_CONCEPTS`(종류가 섞인 목록)는 꾸러미 id 목록으로 바꾼다.

```js
{ id: "triangle-sum", unit: 2, part: 1, activity: 1, title: "삼각형의 세 각의 합",
  recall:  { board: "<1과정 판서 열쇠>", ask: "반 바퀴는 몇 도인가요?" },   // 판서가 없으면 card: {…}
  explore: { lab: "angles", ask: "세 각을 모으면 늘 어떤 모양이 되나요?" },
  proof:   "triangle-sum",                                  // course2-proofs/g1.js
  summary: { terms: [["내각", "도형 안쪽의 각"]], facts: ["삼각형의 세 각의 합은 180°"], figure: drawFn },
  example: { typeId: "c2-triangle-angle", steps: [{ ask, blank, why }, …] },
  check:   ["c2-triangle-angle@easy", "c2-triangle-angle", "c2-joined-polygon-angle@trap"],
  pitfall: "이등변삼각형에서 같은 두 각이 어느 것인지 헷갈린다" }
```

### 개념 하나가 「끝」인 기준

- 여섯 장이 다 있다(②만 뺄 수 있다).
- 논증 장면마다 까닭이 있고, 다른 모양에서도 맞는다.
- 정리 카드가 인쇄 교재의 개념 정리와 글자까지 같다(한 자료에서 둘 다 그린다).
- 예제 단계의 답을 코드가 계산해 검산한다.
- 확인 문제 생성기가 100번 돌려 오류·같은 문제 되풀이가 없다.

## 5. 차시 교재(인쇄)

1과정 차례에 **개념 정리 쪽**이 더해진다.

표지 → (데일리) → **개념 정리**(개념마다 정리 카드 + 예제 빈칸 풀이) → 공부하기 → 워크북 간지 → 오늘의 과제 → (단원 평가) → 정답

- 개념 정리는 개념 하나가 반 칸~반 쪽, 한 차시에 한두 쪽. 빈 곳 없이 이어 담기·번호 차례 지키기·조건 상자 모양 등 인쇄 규칙은 1과정과 같다.

## 7. 화면 — 들어가는 길과 딸린 것

- **사고력 문제은행 「2과정」 탭** — 권 카드 나열을 걷고 1과정과 같은 「권 → 단원 → 차시 카드」(`start.html?course=2`)로. 논증·체험 칩 목록은 권 카드 아래 「개념 모아 보기」로 접어 둔다(복습용).
- **진도표·내 학습 상황·이어서 하기** — 2과정 권을 같은 계산에 넣는다.
- **회원 잠금** — GM 권별·기간 방식의 권 목록과 관리자 화면 권 고르기에 2과정 10권을 더한다(서버 `fields-membership.js`와 복사본 함께).
- **강사용 교안** — 같은 덱의 수업용 그대로. 꾸러미의 ⑥ 개념 확인은 채점 없이 문제만.
- **독쌤 음성** — 2과정 덱 대사는 틀이 굳은 뒤 한 번에 녹음한다(원장 「음성은 마지막에」).

## 8. 만드는 차례

**0단계 — 틀을 한 차시로 시범.** 꾸러미 장 세 가지(④ 정리 · ⑤ 예제 따라 풀기 · ⑥ 개념 확인)와 인쇄 「개념 정리」 쪽을 만들고, **G1 3단원 1차시**(삼각형 세 각 · 이등변삼각형 · 정다각형 내각 · 외각 · 시계 각 — 논증과 생성기가 이미 다 있다)에 채워 원장이 본다. 여기서 틀을 굳힌다.

**1단계 — G1 나머지 8차시**를 꾸러미로 채운다. 지금 섞여 있는 1과정 판서 빌려 쓰기는 ① 되짚기로 내려간다.

**2단계 — 권마다 같은 일을 되풀이.** 한 권 = ① 교재 번호표 → ② 유형·생성기 → ③ 꾸러미(논증 보충 포함) → ④ 차시 교재 인쇄·화면 확인·검사기. 권이 끝날 때마다 `course2-list.js STUDY_BOOKS`에 올려 연다.

**3단계 — 딸린 것.** 진도표·잠금·관리자 화면에 2과정 권 연결, 덱 대사 녹음.

검사기(권마다 돌린다): 번호표 빈 번호 없음 · 생성기 100회 · 꾸러미 여섯 장 빠짐 없음 · 인쇄 쪽 넘침 없음.

## 9. 원장이 정할 것

1. **권 차례** — 진도표가 차시를 날짜에 놓으려면 2과정 10권의 수업 차례가 필요하다. (기하·대수를 번갈아 G1 → A1 → G2 → … 인지, 학원 시간표대로 다른 차례인지)
2. **만드는 차례** — 기하부터 끝내고(G2 → G5) 대수로 갈지, 수업 차례대로 갈지. 논증이 이미 있는 기하부터가 빠르다.
3. **0단계 시범 차시** — G1 3단원 1차시로 해도 되는지.
