# 문제은행 학습맵 출처 및 적용 원칙

## 목적

GFIELD 문제은행의 세부 유형은 원본 시험지·교재 대조와 생성기 검산을 기준으로 유지한다. 학습맵은 이 분류를 대체하지 않고, 사용자가 유형의 상위 교육과정 위치와 학습 흐름을 빠르게 이해하도록 돕는 별도 탐색 계층이다.

## 사용한 공개 자료

- 자료: [Korean Elementary Learning Map](https://github.com/DECK6/korean-elementary-learning-map)
- 라이선스: MIT
- 데이터 릴리스: `kr-full-depth-v0.4`
- 확인 커밋: `3ef0563084aa2a9baaa47da2c1ec0ebf5d7edc5c`
- 확인일: 2026-08-21

`learning-map.js`에는 초1~2 수학의 공개 식별자, 성취기준 코드 범위, 독립적으로 작성한 짧은 묶음 이름만 사용한다. 원본 교과서·시험지·성취기준 전문이나 페이지 이미지는 복제하지 않는다.

## 표시 의미

- `교육과정 관련`: 해당 GFIELD 유형과 관련성이 분명한 상위 학습 요소를 표시한다.
- `사고력 확장`: 국가 성취기준 하나에 억지로 연결하지 않고 GFIELD의 독립 세부 유형으로 관리한다.
- `개념 확인 → 표현과 연결 → 적용과 설명`: 공개 학습맵의 prerequisite 구조를 사용자용 3단계 흐름으로 요약한 것이다.

이 표시는 공식 기관의 승인, 성취기준과의 1:1 대응, 학생 개인의 진단 결과를 뜻하지 않는다. 문항의 정답, 난이도, 출처 검증 여부에도 영향을 주지 않는다.

## 참고만 한 구조

[Open Source Taxonomy](https://github.com/withmarbleapp/os-taxonomy)는 계층형 분류와 선수 관계를 분리하는 구조만 참고했다. ODbL 1.0 또는 CC BY-SA 4.0 적용 데이터와 콘텐츠는 이 문제은행에 복사하거나 결합하지 않았다.

## 유지보수 규칙

1. 기존 `typeId`, 대영역, 중영역, 세부 유형명을 학습맵에 맞추기 위해 변경하지 않는다.
2. 교육과정 관련성이 분명하지 않으면 `사고력 확장`으로 둔다.
3. 공개 학습맵 버전을 올릴 때 커밋과 릴리스를 함께 갱신하고, 204개 전체 유형 매핑 검사를 다시 실행한다.
4. 진단·처방 시스템의 분류와 판정에는 이 학습맵을 사용하지 않는다.
5. 저작권 있는 원본은 비공개 저장소에 두고 공개 저장소에는 메타데이터와 검증 위치만 기록한다.
