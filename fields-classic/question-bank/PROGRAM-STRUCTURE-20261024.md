# FC 1과정 「스스로 공부」 프로그램 구조 (2026-10-24)

원장 지시: 「이건 필즈더 클래식 문제은행뿐 아니라 스스로 공부할 수 있는 자체 프로그램이야. 그냥 시험지 만드는 것이 아니야.
1. 시험지형 — 권별테스트 원본형 + 교재에서 유형별이나 난이도별로 출제, 선택 가능하도록
2. 학습형 또는 수업형 교재 만들기 — 1) 지도서 방법대로 유형별 개념 영상 또는 튜토리얼(골든벨 대표 문제로, 방향은 따로 고민) 2) 게임으로 개념 익히기 3) 골든벨 4) 더클 본책
확인해 봐. 지금은 그냥 시험지 만드는 느낌인데 조작이 너무 여러 가지 있어.」

## 1. 무엇이 문제였나 (점검 결과)
- 들어오는 곳이 **문제은행 편집 화면(`index.html`) 하나**였다. 첫 화면부터 시험지별·교재 단원별·유형별 탭과 검색·난이도·문항 수·순서·풀이·워터마크가 다 보였다.
  화면에 보이는 조작 수: 시험지별 68개 · 교재 단원별 84개 · 유형별 813개. 어느 길로 가도 끝은 「문제 구성 확인」 → 학습지였다.
- 골든벨(개념 → 골든벨 → 추가 학습)과 게임은 그 화면 탭 옆의 링크 하나로만 닿았고, 본책 단원과 짝지어 보이지 않았다.
- 권별테스트는 「교재 단원별」 탭 안쪽에 25개 체크 상자로 묻혀 있었다.

## 2. 새 구조 — 시작 화면 `start.html`
```
① 교재(권) 고르기   1권 … 10권
② 무엇을 할까요
   ├─ 공부하기  [학습형 혼자 | 수업형 선생님 화면·교재 인쇄]
   │    단원마다:  ① 개념 → ② 게임 → ③ 골든벨 → ④ 더클 본책(개념·유형·연습·심화)
   └─ 시험지 만들기
        ├─ 권별테스트 원문 풀기 (교재 권별테스트 원문 그대로 1세트 → 답안지·○✕ 채점 → 틀린 번호 유사문제)
        ├─ 권별테스트 유사문제  (번호마다 원문과 같은 유형·구조, 숫자를 바꾼 새 시험지)
        └─ 교재에서 골라 만들기 (단원 ☑ · 난이도 개념/유형/연습/심화 · 10/20/30문제)
   └─ (작게) 선발시험 기출·모의고사·유형 하나하나 → 문제은행 자세히 고르기(index.html, 기존 화면 그대로)
```
- 시작 화면은 **길 안내만** 한다. 문제를 만들고 채점하는 일은 기존 화면이 그대로 맡고, 시작 화면은 그 화면들이 받는 주소만 만든다.
  그래서 검증 게이트(검증된 문항·유형만 나옴)는 하나도 바뀌지 않았다.
- 원장 지시(2026-10-24): 「교재 권별테스트는 원본 문제 그대로 1세트가 있고, 유사문제로 공부하는 거야.」
  → 원문은 `unit-test-viewer.html`(원문 풀기)에서 그대로 보고 풀며, 유사문제는 문제은행이 만든다. 원문 정답은 화면에 두지 않는다(채점은 선생님 답지로 ○✕).
  원문 쪽 그림 `assets/unit-tests/book01~10/page-01~07.png`는 원문 PPT의 문제 슬라이드만(표지·답안 슬라이드 제외) 원본 비율로 렌더했다(예전 그림은 가로로 늘어나 있었고 2·3권은 1~4번 쪽이 없었다). 공개 저장소에 두는 것은 원장 결정.
- 「유사문제」와 「교재에서 골라 만들기」는 **바로 학습지가 나온다**(`build=1`). 조작이 필요한 사람만 「문제은행 자세히 고르기」로 간다.
- 골든벨 학습은 본책 4단원 아래에 나눠 보인다. 짝짓기 기준: 학습이 다루는 세부 유형(`sourceTypeIds`)과 단원 유형이 겹치는 수 → 단원 이름.
  어느 단원에도 안 붙는 학습(골든벨 자료에만 있는 주제)은 「그 밖의 골든벨」로 따로 보인다(지어서 붙이지 않는다).
- 학습형/수업형 차이: 학습형 ④는 10문제 학습지(화면에서 풀고 답 확인), 수업형 ④는 **교재형 본문**(`form=lesson`) 20문제 인쇄. ①~③은 같은 화면을 선생님이 띄운다.

### 주소 (다른 화면에 새로 생긴 것)
| 화면 | 주소 | 하는 일 |
|---|---|---|
| `index.html` | `mode=curriculum&book=book-03` | 그 권을 연다 |
| | `&set=unit-test&fresh=1` | 권별테스트 유사문제(같은 구조, 새 숫자). `fresh` 없이는 고정 seed(늘 같은 유사문제) |
| | `&numbers=3,7` | 권별테스트 그 번호만(원문 풀기에서 틀린 번호) |
| | `&units=0,2&stage=practice&count=20` | 단원·단계·문항 수 |
| | `&form=lesson` | 이번 한 번 교재형 본문(저장된 인쇄 양식은 그대로) |
| | `&build=1` | 고른 대로 바로 학습지 |
| `golden-bell.html` | `book=book-01&lesson=<id>` | 그 학습을 바로 연다 |
| | `&phase=original` | 골든벨 문항부터(개념 전이면 개념이 먼저 — 기존 잠금 그대로) |
| `unit-test-viewer.html` | `book=book-02` | 권별테스트 원문 풀기(원문 7쪽 + 답안지, 답은 기기에 저장) |
| `start.html` | `book=…&door=test&as=class` | 권·문·학습형/수업형 |

학습지 제목: 권별테스트만 고르면 「N권 권별테스트 유사문제」. 골든벨 화면의 「← 처음 화면」, 문제은행의 「처음 화면」, 소개 화면의 시작 단추가 모두 `start.html`로 간다.

## 2-1. 학생용 단원 공부 (원장 지시 2026-10-24)
「학생용은 우선 권 단원 고르기. 1단원을 2번 정도로 나누어 공부하는 거야, 개념을 절반으로 나누어서. 개념 배우기 · 게임하기 · 골든벨 · 공부하기(본책은 이미 책을 줄 거야. 모르는 문제를 클릭하면 유사문제가 나오도록).」
「독쌤 사이언스 랩처럼 학생용은 되어야 해. 아래로 내려가며 공부하는 게 아니라.」
- 시작 화면 학습형 → 단원마다 **차시 단추**(1차시 · 개념 1 / 2차시 · 개념 2) → `study.html?book=&unit=&part=`.
- 차시 나누기 = 본책의 활동·확인 묶음(group 1·2, 7권 2단원·10권 1단원은 3). 유형은 처음 나오는 묶음의 차시, 연습·도전 문항은 그 유형의 차시로(`study-map.js`). 40단원 전부 본책 문항이 빠짐없이 어느 차시에 들어간다(1,613문항, 하나에 하나).
- **차시 화면 = 한 장씩 넘기는 덱**(사이언스 랩 「스스로 공부하기」와 같은 틀). 화면 전체가 한 장이고 페이지는 스크롤하지 않는다.
  - 순서: 표지(오늘 할 일 4칸) → ① 개념 배우기(학습마다 한 장) → ② 게임하기(게임마다 한 장) → ③ 골든벨(학습마다 한 장) → ④ 공부하기(본책 묶음마다 한 장: 활동 1 · 확인 1 · 연습 · 도전) → 끝(다음 차시 · 다음 단원).
  - 위: 순서 칩 4개(지금 단계 강조, 눌러서 그 단계로) + 진행 막대. 아래: 독쌤(표정 3장 `docssam-guide/thinking/praise.webp`) 말풍선 + ‹ 이전 · 다음 ›. ←/→ 키.
  - 독쌤 말은 글이 원본, 음성은 기기 음성(ko-KR) 켜기/끄기. 소리 없이 입을 움직이는 그림은 쓰지 않는다.
  - 게임을 끝까지 하거나(「연결 문제 풀기」) 골든벨 문항을 다 풀면 독쌤이 칭찬하고 **저절로 다음 장**(다음 단추가 차오름). 「넘김 멈춤」으로 끄고, 화면을 만지면 그 번은 멈춘다.
  - 골든벨 학습은 덱 안의 창 하나(`golden-bell.html?embed=1&lesson=&view=concept|game|bell&game=`)를 계속 쓰고, 장이 바뀌면 postMessage로 그 학습만 연다. 개념은 **덩어리(생각할 문제 · 상황 · 체험 · 정리 …)마다 한 장**으로 나눠, 덱의 「다음」이 창 안의 장을 먼저 넘기고 끝이면 덱의 다음 장으로 간다(「1 / 4장」 표시). 개념 → 유형별 예제가 있는 학습(LESSON_FLOWS)은 예제까지 개념 장에 이어진다. 창 안에서는 골든벨 머리줄·단계 단추·학습 목록·「문제로 확인하기」를 숨긴다(덱이 대신한다).
  - 본책 번호를 누르면 같은 유형 유사문제 한 개가 **그 장 위에 덮여** 뜬다(문제은행 학생 화면 `index.html?…&as=student&embed=1`) — 답 확인(처음 틀리면 「다시 생각해 보세요」, 두 번째에 정답·풀이) · 다른 문제 · 「‹ 본책 번호판」. 눌러 본 번호는 ○ 표시(기기 저장).
  - 주소의 `&s=N`이 지금 장이라 새로고침해도 그 장에서 이어진다. 골든벨 학습이 없는 차시(예: 4권 2단원)는 표지 → 본책 → 끝이고, 표지에 「준비 중」으로 보인다.
- **그림 액자 틀**(원장 2026-10-24: 「밝아야 돼」 → 「배너 말고 틀」 → 그림 액자 틀을 고름). 섬 그림(`assets/study/world-map.webp`, 연산 로드맵 그림 지도와 같은 원본 그림, 글자 없음)이 화면 가장자리를 액자처럼 두르고, 가운데 넓은 흰 칸(흰 매트 한 겹)에서 공부한다.
  - 위 액자: 이름 알약 · 공부 순서 알약(개념 배우기 · 게임하기 · 골든벨 · 공부하기 · 완료, 누르면 그 단계로) · 학생. 아래 액자: 왼쪽 모서리에 선 독쌤 + 말풍선, 오른쪽에 ‹ 이전 · 다음 →. 띠(배너)를 깔지 않고 그림 위에 알약만 띄운다.
  - 장이 바뀌면 그림이 지금 섬 쪽으로 조금 옮겨 가 가장자리 풍경이 바뀐다(`study.js` `ISLANDS`). 휴대폰은 액자를 얇게, 독쌤 말은 단추 위 두 줄.
  - 색은 그림의 보라색 길에 맞춘 보라(`--v #5b3d99`) 하나.
- **게임하기 = 덱 안에 바로 뜨는 우리 게임**(원장: 「게임은 이 정도 그래픽이면 안 돼. 지오메트리 쪽 봐 봐」 → 「링크를 가져오는 거 아냐. 우리 걸 써야 돼. 그걸 발전시켜 우리 학습에 맞는 게임으로」).

## 2-3. 연습 공방 — 게임이 없는 차시의 「게임하기」 (2026-10-27)

원장에게 다음 일을 물었더니 「게임 없는 단원에 게임 만들기」를 골랐다. 학생 덱 126차시 중 우리 게임·골든벨 게임이 붙은 차시는 1·2권 앞 차시뿐이고 나머지는 「게임하기 준비 중」이었다.

- **문제는 문제은행 실제 유형 그대로**: 원장 기준(「너무 쉬워. 실제 문제를」)에 맞춰, 문제를 새로 짓지 않고 문제은행 생성기(`generators.js`의 `GENERATORS`)를 문제은행 화면과 같은 방식(`{ max: 30, difficulty }`, null이면 다시 뽑기)으로 부른다. 그림도 문제은행 화면과 같은 `bookNN-renderers.js`·`styles.css`로 그린다 — 본책·문제은행과 어긋날 수 없다.
- **세 단계**: 연습(난이도 1) → 실전(2) → 도전(3), 단계마다 세 문제. 숫자판으로 답을 쓰고, 한 번 틀리면 풀이의 첫 걸음을 귀띔, 두 번 틀리면 답과 풀이를 보여 주고 넘어간다. 처음에 맞히면 별.
- **파일**: `drill.html`·`drill.js`·`drill.css`(창 안에서 도는 공방 — 문제은행 `styles.css`를 써야 해서 덱과 따로 둔다) · `game-drill.js`·`game-drill.css`(덱에 창을 띄우고 말·끝을 이어 준다) · `drill-recipes.js`(차시 → 유형 id). `study-map.js`가 레시피가 있는 차시에 「연습 공방」을 붙인다(우리 게임이 있으면 그쪽이 먼저).
- **유형 고르기**: 그 단원 문제은행 유형(`CURRICULUM` `typeIds`) 가운데 차시 개념과 같은 풀이를 쓰는 것만. 답 꼴이 수 하나 · 수 + 단위(12㎠, 15개) · 쉼표로 쓴 수인 유형만 쓴다(그림 그리기·문장 답은 숫자판으로 못 받는다).
