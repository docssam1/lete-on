## 무엇이 어디에
- `reports/report-book-NN.md` — 권별 원본 대조 결과(번호마다 맞음/일부 다름/다름, 고칠 방향). 교재 문장·수는 없다.
- `BRIEF.md` — 작업자(에이전트)에게 준 공통 지시. 모듈 계약·지킬 것·확인 순서. 다시 이어서 할 때 그대로 쓴다.
- 이미 있는 유형으로 옮긴 번호: `../../textbook-remaps.js TEXTBOOK_REMAPS`.
- 권마다 새 생성기: `../../bookNN-structure-generators.js` — `BOOKNN_STRUCTURE_GENERATORS · _TYPE_ROWS · _GUIDES · _REMAPS`
  (+ 권에 따라 `_CHECKS`). `source-data.js`(유형·핵심 방법·번호 옮기기)와 `generators.js`가 이미 열 권 모두 부른다.
  그림은 `visual: { kind: "fig", html: "<svg…>" }`(app.js → `.fig-visual`).
- 새 유형마다 독립 검산은 그 권 `bookNN-audit.mjs`에 있다.
