# 1과정 골든벨 원본·학습 감사

## 운영 원칙

골든벨은 일반 학습지 문제 수와 `개념·유형·연습·심화` 4단계 집계에 섞지 않는다. 각 권의 학생용 무답본과 교사용 정답본을 `권·단원·슬라이드(또는 페이지)·하위 문항`까지 대조한 뒤 아래 순서로만 연다.

1. 아이 눈높이의 짧은 스토리로 대표 개념 설명
2. 수치·그림·문장·보기 유무·답안 형식을 잠근 원본 골든벨 확인
3. 원본과 같은 풀이 구조와 답안 형식을 새로운 이야기 상황에 적용
4. 원본형과 스토리형을 모두 맞힌 개념만 학습 완료 처리

원본 전체 페이지 이미지와 PPTX/PDF는 공개 저장소에 넣지 않는다. 공개 코드에는 새로 만든 설명·스토리·SVG, 원본을 다시 찾을 수 있는 파일명과 슬라이드 위치, 검수 상태만 둔다.

## 1권 공개 범위

1권 전체 174개 하위 문항을 모두 공개한 상태가 아니다. 아래 4개 대표 개념의 원본 12문항만 교사용·학생용을 대조해 먼저 열었다. 나머지는 동일한 원본 잠금 절차를 거친 뒤 순차 추가한다.

| 단원 | 원본 위치 | 원본 확인 | 스토리 확장 |
| --- | --- | --- | --- |
| 도형 움직이기 | 슬라이드 2 활동 01 | 12에서 한·반·반의 반 바퀴 5문항, 원본과 같은 직접 입력 | 3에서 시계 방향 반 바퀴 직접 입력 |
| 색종이 접기 | 슬라이드 10 활동 01 (1) | 한 번 접고 삼각형 모양을 자른 뒤 펼친 모양 `3번` | 접힌 두 겹을 한 번 뚫은 구멍 수 |

## 2권 공개 범위

교사용 41슬라이드와 학생용 40슬라이드는 교사용 중간 설명 슬라이드 한 장 때문에 뒷부분 번호가 한 칸씩 다르다. 같은 그림·문장·빈칸을 직접 비교해 아래 네 대표 개념의 12문항만 먼저 열었다.

| 단원 | 학생용·교사용 위치 | 원본 확인 | 스토리 확장 |
| --- | --- | --- | --- |
| 매트릭스와 주고받기 | 학생용·교사용 슬라이드 4 활동 01 | 덧셈 매트릭스 6문항, 직접 입력 | 같은 도형 식에서 숨은 수 직접 입력 |
| 양팔저울 | 학생용·교사용 슬라이드 14 활동 02 | A·B·C 무게 비교 3문항, 직접 입력 | 세 동물의 무게 순서 직접 입력 |
| 규칙찾기와 수열 | 학생용 23·교사용 24 활동 04 (1) | 모양 주기 4와 색 주기 3의 이중패턴 1문항, 직접 입력 | 다른 모양·색 이중패턴 직접 입력 |

각 위치에서 학생용에는 빈칸만 있고 교사용에는 같은 위치에 빨간 정답만 추가되어 있음을 이미지로 확인했다. 교사용 설명이 학생용 문항을 덮는 매트릭스 슬라이드는 학생용 그림을 기준으로 렌더하고 교사용 수치만 답 감사에 사용한다.

| 단원 | 교사용·학생용 위치 | 원본 확인 | 스토리 확장 |

학생용 무답본은 확인되지 않았다. 대신 같은 47쪽 교사용 PPTX와 PDF를 전 페이지 렌더해, 문제 그림·검은 지문과 빨간 정답 표시가 시각적으로 분리되는 아래 네 대표 개념만 열었다. 교사용 표시가 원문 요소와 겹치거나 관계가 불명확한 문항은 답이 적혀 있어도 열지 않는다.

## 6권 공개 범위

32슬라이드 전체 자료와 답안 자료는 렌더 결과 27장이 완전히 같고, 차이가 난 5장도 대부분 주차 표지와 설명층이었다. 16슬라이드 1·2주차 자료 역시 전체 자료의 앞 16장 중 15장이 같아 무답본으로 간주하지 않았다. 세 자료를 모두 교사용 표시 자료로 취급하고, 검은 문제 구조와 표시 답을 분리해 독립 계산할 수 있는 네 대표 개념만 열었다.

| 가로수 심기 | 슬라이드 50 원 모양 호수 활동 05~07 | 닫힌 둘레 `300m, 96m, 120m` | 18그루를 9m 간격으로 심은 둥근 화단 |
| 대칭수와 벤다이어그램 | 슬라이드 63 활동 01 | 겹침 `4`, 왼쪽만 `3`, 오른쪽만 `8`, 하나만 `11` | 전체 24명인 두 동물 취향 조사 |

슬라이드 52의 ‘한 자리 대칭수’처럼 교사용 표시에서 정의를 바로잡거나 지운 흔적이 있는 문항, 날짜 표기 방식에 따라 개수가 달라지는 문항, 빨간 풀이를 제거하면 조건을 확정하기 어려운 문항은 이번 공개 범위에서 제외했다. 위 13문항만 원본 구조를 새 HTML·SVG로 다시 그렸으며 원본 슬라이드 이미지는 공개 저장소에 넣지 않았다.

## 8권 공개 범위

39슬라이드 E2용 PPTX는 학생용 무답본이 아니라 교사용 표시 자료다. 교사용 지도서로 네 단원 순서를 확인하고, 검은 문제 구조와 빨간 풀이가 분리되며 답을 별도 식이나 전수 대입으로 재현할 수 있는 네 대표 개념만 열었다.

| 단원 | 교사용 위치 | 원본 확인 | 스토리 확장 |
| --- | --- | --- | --- |
| 묶음수와 매트릭스 | 슬라이드 2 덧셈 매트릭스 (1)~(4) | 빈 세로 합 `16, 10, 7, 22`, 직접 입력 | 같은 3×3 도형 합에서 지워진 세로 합 |
| 복면산 | 슬라이드 16 복면산 연습 (1)~(4) | 지정 도형값 `8, 7, 8, 9`, 직접 입력 | 같은 두 자리 도형 세로셈의 네모 값 |
| 합차와 배수문제 | 슬라이드 22 주고 받기 (1)~(3) | 같게 만들기 위해 옮기는 수 `2, 4, 9`, 직접 입력 | 28권과 16권 책꽂이를 같게 만들기 |
| 거꾸로 생각하기 | 슬라이드 31 거꾸로 풀기 (1)~(4) | 처음 수 `6, 18, 8, 12`, 직접 입력 | 네 계산을 거꾸로 되돌려 출발 수 찾기 |

슬라이드 15의 빈칸 합처럼 교사용 빨간 표시와 문제 칸의 경계를 학생용 무답본 없이 확정하기 어려운 문항, 정정 흔적이 있는 문항, 표시 답만으로 원문 조건을 복원해야 하는 문항은 잠금 상태를 유지한다. 위 15문항은 원본 관계를 새 HTML로 다시 그렸고 원본 슬라이드 이미지는 공개 저장소에 넣지 않았다.

## 9권 공개 범위

11쪽 교사용 골든벨 PDF는 학생용 무답본이 아니라 빨간 풀이가 겹친 자료다. 150쪽 교사용 지도서에서 단원명과 개념 순서를 교차 확인하고, 원문 그림과 조건만으로 답을 독립 계산할 수 있는 네 대표 개념만 열었다.

| 단원 | 교사용 위치 | 원본 확인 | 스토리 확장 |
| --- | --- | --- | --- |
| 도형의 분할과 넓이 | PDF 1쪽 Q1 (1)~(2) | 직사각형 넓이 `2, 6`, 대각선으로 반을 나눈 삼각형 넓이 `1, 1`, 직접 입력 | 4×3 직사각형을 대각선으로 나눈 삼각형 |
| 쌓기나무의 개수 | PDF 3쪽 첫째 줄 세 입체 | 위에서 본 자리별 높이를 더한 전체 `8, 10, 14`, 직접 입력 | 높이 `3, 2, 1, 1`인 네 기둥의 전체 |
| 마방진 | PDF 7쪽 Q1 첫째·둘째 표 | 한 줄의 합 `18, 21`에서 빈칸 `10, 9`, 직접 입력 | 한 줄의 합이 15인 3×3 마방진 |
| 연속수의 합 | PDF 11쪽 Q1 앞 네 식 | 1부터 `6, 10, 14, 20`까지의 합 `21, 55, 105, 210`, 직접 입력 | 1번부터 18번까지 계단 번호의 합 |

지도서의 넷째 단원은 논리 추리이지만, 현재 골든벨 PDF의 10~11쪽에는 분배법칙과 연속수의 합 활동이 실려 있다. 공개 학습은 지도서 내용을 새로 끼워 넣지 않고 실제 골든벨 PDF 11쪽의 연속수 문항을 그대로 기준으로 삼았다. 나머지 복잡한 도형 분할, 쌓기나무 최대·최소, 여러 칸이 비어 있는 마방진은 학생용 무답본 또는 더 정밀한 도형 대조 전까지 잠금 상태를 유지한다.

## 검증 게이트

- 객관식 원본은 정답이 보기 안에 정확히 한 번 존재
- 주관식 원본에는 임의의 보기를 추가하지 않고 직접 입력으로 유지
- 스토리 확장은 원본과 같은 `structureKey`와 답안 형식을 사용
- 원본 확인 문항을 모두 맞히기 전 스토리 확장 잠금
- 스토리 확장까지 맞힌 뒤에만 개념 완료 기록
- 1~10권 자리는 유지하되 원본 대조 전 권은 문제를 노출하지 않음
- PC·모바일에서 한 단계씩 학습하고 수평 넘침이 없어야 함
- 기존 시험지별·교재 단원별·유형별 문제 생성 동작은 변경하지 않음
