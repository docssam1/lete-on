# 1과정 골든벨 원본·학습 감사

## 운영 원칙

골든벨은 일반 학습지 문제 수와 `개념·유형·연습·심화` 4단계 집계에 섞지 않는다. 각 권의 학생용 무답본과 교사용 정답본을 `권·단원·슬라이드(또는 페이지)·하위 문항`까지 대조한 뒤 아래 순서로만 연다.

1. 아이 눈높이의 짧은 스토리로 대표 개념 설명
2. 수치·그림·문장·보기 유무·답안 형식을 잠근 원본 골든벨 확인
3. 원본과 같은 풀이 구조와 답안 형식을 새로운 이야기 상황에 적용
4. 원본형과 스토리형을 모두 맞힌 개념만 학습 완료 처리

원본 전체 페이지 이미지와 PPTX/PDF는 공개 저장소에 넣지 않는다. 공개 코드에는 새로 만든 설명·스토리·SVG, 원본을 다시 찾을 수 있는 파일명과 슬라이드 위치, 검수 상태만 둔다.

## 1권 공개 범위

1권 전체 174개 하위 문항을 모두 공개한 상태가 아니다. 아래 4개 대표 개념의 원본 12문항만 교사용·학생용을 대조해 먼저 열었다. 나머지는 동일한 원본 잠금 절차를 거친 뒤 순차 추가한다.

| 단원 | 원본 위치 | 원본 확인 | 스토리 확장 |
| --- | --- | --- | --- |
| 도형 움직이기 | 슬라이드 2 활동 01 | 12에서 한·반·반의 반 바퀴 5문항, 원본과 같은 직접 입력 | 3에서 시계 방향 반 바퀴 직접 입력 |
| 색종이 접기 | 슬라이드 10 활동 01 (1) | 한 번 접고 삼각형 모양을 자른 뒤 펼친 모양 `3번` | 접힌 두 겹을 한 번 뚫은 구멍 수 |
| 마방진과 가쿠로 | 슬라이드 20 활동 01 (1)~(3) | 교차 줄 빈칸 3문항, 원본과 같은 직접 입력 | 가로·세로 합이 같은 새 교차 줄 직접 입력 |
| 수추리와 논리추리 | 슬라이드 32 (1)~(3) | 서로 다른 선택 3문항, 원본과 같은 직접 입력 | 축제 음식 배정 논리 직접 입력 |

슬라이드 32의 (4)는 공개된 문장만으로 인물 조건이 완전하지 않아 원본 확인 트랙에서 보류한다. 답안에 값이 있다는 이유만으로 불완전한 지문을 열지 않는다.

## 2권 공개 범위

교사용 41슬라이드와 학생용 40슬라이드는 교사용 중간 설명 슬라이드 한 장 때문에 뒷부분 번호가 한 칸씩 다르다. 같은 그림·문장·빈칸을 직접 비교해 아래 네 대표 개념의 12문항만 먼저 열었다.

| 단원 | 학생용·교사용 위치 | 원본 확인 | 스토리 확장 |
| --- | --- | --- | --- |
| 매트릭스와 주고받기 | 학생용·교사용 슬라이드 4 활동 01 | 덧셈 매트릭스 6문항, 직접 입력 | 같은 도형 식에서 숨은 수 직접 입력 |
| 양팔저울 | 학생용·교사용 슬라이드 14 활동 02 | A·B·C 무게 비교 3문항, 직접 입력 | 세 동물의 무게 순서 직접 입력 |
| 규칙찾기와 수열 | 학생용 23·교사용 24 활동 04 (1) | 모양 주기 4와 색 주기 3의 이중패턴 1문항, 직접 입력 | 다른 모양·색 이중패턴 직접 입력 |
| 약속과 스도쿠 | 학생용 31·교사용 32 활동 01 (1) | 위 수가 나머지 세 수의 합인 약속 2문항, 직접 입력 | 같은 약속의 새 보석 그림 직접 입력 |

각 위치에서 학생용에는 빈칸만 있고 교사용에는 같은 위치에 빨간 정답만 추가되어 있음을 이미지로 확인했다. 교사용 설명이 학생용 문항을 덮는 매트릭스 슬라이드는 학생용 그림을 기준으로 렌더하고 교사용 수치만 답 감사에 사용한다.

## 검증 게이트

- 객관식 원본은 정답이 보기 안에 정확히 한 번 존재
- 주관식 원본에는 임의의 보기를 추가하지 않고 직접 입력으로 유지
- 스토리 확장은 원본과 같은 `structureKey`와 답안 형식을 사용
- 원본 확인 문항을 모두 맞히기 전 스토리 확장 잠금
- 스토리 확장까지 맞힌 뒤에만 개념 완료 기록
- 1~10권 자리는 유지하되 원본 대조 전 권은 문제를 노출하지 않음
- PC·모바일에서 한 단계씩 학습하고 수평 넘침이 없어야 함
- 기존 시험지별·교재 단원별·유형별 문제 생성 동작은 변경하지 않음
