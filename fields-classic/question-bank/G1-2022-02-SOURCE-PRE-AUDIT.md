## 오류·편집 잔재

- **10번 원본 누락:** 문제지 렌더에서 ‘주어진 수’ 목록이 표시되지 않는다. 다만 공식 답은 2~9를 한 번씩 사용하는 배치이며, 행·열 곱 조건을 다시 대입하면 제시된 배치가 유일하게 결정된다. 공개 문서와 생성기에는 누락 사실을 함께 남긴다.
- **답안 PPTX 편집 잔재:** 답안 파일 화면 밖에 현재 문항과 무관한 편집 객체가 남아 있다. 실제 문제·답이 렌더된 슬라이드 3~7의 문항 내용과 답에는 영향을 주지 않으므로, 화면 밖 객체는 원본 오류나 정답 오류로 판정하지 않는다.
- 1~20번의 원본 구조와 공식 답은 모두 일치하며, 위 두 항목은 공개 시 오해를 막기 위한 출처 주의사항이다.

## 공개 조건

1. 각 확정 유형은 난이도별 3,000회 생성·독립 검산을 통과한 뒤 공개한다.
2. 조건형 문항은 매 생성값마다 답 후보가 단일해인지 확인한다.
3. 배치 전체나 여러 값을 답으로 쓰는 문항은 답의 읽는 방향과 복합 답 순서를 문제·답안·채점기에 동일하게 유지한다.
4. PC와 모바일에서 표·수식·복합 답이 잘리지 않는지 확인한다.
5. A4 인쇄와 미리보기에서 페이지 나눔, 표 폭, 답안 배치가 유지되는지 확인한다.
6. 미리보기의 문제·답 연결이 원본 문항 번호와 어긋나지 않는지 확인한다.
7. 워터마크가 지문·그림·답·문항 번호를 가리지 않는지 확인한다.
8. 공개 문서에는 원문 지문과 원본 페이지 이미지를 복제하지 않고, 구조·답·연결·검수 결과만 요약한다.
