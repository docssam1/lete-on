# 시험지 편집 기능 재사용 평가

기준일: 2026-08-25

외부 참고 화면은 기능 흐름을 검토하는 용도로만 사용한다. 상표, 문항, 이미지, 색상, 배치와 표현은 복제하지 않으며 필즈 더 클래식의 검증 자료와 기존 UI 체계를 유지한다.

## 현재 판정

| 기능 | 판정 | 적용 기준 |
|---|---|---|
| 시험지별·교재 단원별·유형별 범위 선택 | 그대로 사용 | 현재 대분류·중분류·세부 유형 및 원본 문항 번호 색인을 유지한다. |
| 여러 유형·문항 동시 선택 | 그대로 사용 | 체크 선택과 전체 선택이 이미 지원된다. |
| 문제 수·난이도·배열 설정 | 그대로 사용 | 문제 수, 원본 대비 쉬움·같음·어려움, 출제 순서·영역별·섞기를 유지한다. |
| 유형 마우스 미리보기 | 그대로 사용 | 실제 생성기를 호출하므로 고정 예시 이미지로 대체하지 않는다. |
| 교재 개념·유형·연습·심화 | 그대로 사용 | 페이지가 아니라 교재의 문제 번호 색인을 기준으로 한다. |
| 선택 결과 문제 확인 | 수정 사용 | 생성 결과 화면을 편집 단계로 함께 사용한다. |
| 문항 순서 변경 | 수정 사용 | 데스크톱 드래그와 위·아래 버튼을 함께 제공한다. |
| 같은 유형의 문항 교체 | 수정 사용 | 해당 문항의 유형·출처·난이도는 보존하고 생성 결과만 다시 만든다. |
| 문항 삭제 | 수정 사용 | 원본 유형·생성기는 삭제하지 않고 현재 시험지 배치에서만 제외한다. |
| 정답·풀이 핵심 | 그대로 사용 | 승인·검산된 생성기 결과만 사용하며 문제 번호 변경 시 자동으로 다시 매긴다. |
| 이름 워터마크·문제/답안 인쇄 | 그대로 사용 | 화면과 인쇄 모두 학생 이름을 사용하고 편집 도구는 인쇄하지 않는다. |
| 학생용·교사용 분리 | 추후 적용 | 권한과 상품 구성이 확정된 뒤 답안 접근을 역할별로 분리한다. |
| QR·영상 연결 | 조건부 적용 | 실제 승인된 강의 링크가 있는 문항에만 연결한다. 가짜 링크는 만들지 않는다. |
| 오답 통계·정답률 | 추후 적용 | 실제 답안 입력 자료가 쌓인 뒤 계산하며 임의 수치를 표시하지 않는다. |
| 외부 문제 가져오기 | 사용하지 않음 | 저작권 문항과 이미지는 공개 번들에 복사하지 않는다. |
| 외부 화면 디자인 복제 | 사용하지 않음 | 정보 구조만 참고하고 필즈 UI와 인쇄 규격으로 독자 구현한다. |

## 데이터 원칙

- 원본 문항과 시험지에 배치된 문항을 구분한다.
- 순서 변경과 삭제는 현재 시험지 배열만 바꾸며 유형 원본과 생성기는 보존한다.
- 한 문항 교체는 같은 `typeId`, 출처 설명, 난이도를 유지한다.
- 교체 결과는 현재 시험지의 다른 문항 및 교체 전 문항과 중복되지 않아야 한다.
- 문항 번호와 답안 번호는 현재 배열에서 다시 계산한다.
- 검증되지 않은 유형은 이름이 비슷한 생성기로 대신 열지 않는다.
- 진단 모의고사와 처방 시스템의 기존 유사문제 로직은 수정하지 않는다.

## 이번 반영

- 생성된 문항을 끌어서 순서를 바꿀 수 있다.
- 모바일에서도 위·아래 버튼으로 순서를 바꿀 수 있다.
- 한 문항만 같은 유형과 난이도로 다시 만들 수 있다.
- 한 문항을 현재 시험지에서 삭제할 수 있다.
- 답을 입력한 뒤 순서를 바꿔도 입력값을 유지한다.
- 편집 버튼은 문제·답안 인쇄에 나타나지 않는다.
