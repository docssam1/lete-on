# 지필드 클래식 디자인 시안 (2026-10-23)

원장 지시 「폰트만 바꾸지 말고 색·여백·정렬·문항 배치까지 제대로 설계」 「푸르딩딩한 것 말고」에 따른
첫 시안. **아직 기능이 붙은 화면이 아니라 생김새를 정하는 시안**이다. 방향이 정해지면 이 규칙을
`index.html`(문제은행)·`print` 쪽에 실제로 입힌다.

보는 곳: `…/fields-classic/question-bank/design-draft/` (Pages 배포 후)
- `index.html` — 문제은행 화면: 왼쪽 단원 필터 · 가운데 문제 목록 · 오른쪽 미리보기+시험지 바구니
- `exam.html` — A4 3장: 시험지(1단) · 연습지(2단) · 교재형(개념+예제+문제). **1단/2단, 시험지/교재는 같은 문항 부품에 틀만 바꾸는 선택지**
- `covers.html` — 교재 표지 3안 (A 종이 오리기 풍경 · B 쌓기나무 탑 · C 전면 무늬+가운데 패). 그림은 전부 이 파일 안 원본 SVG — 외부 템플릿을 베끼지 않음(어도비·캔바는 배치 관습만 참고)

## 규칙 (이 시안의 결정 사항)

| 항목 | 규칙 |
|---|---|
| 색 | 따뜻한 종이 바탕(`#fdfbf5`·`#f1ece1`) + 먹색 글자(`#2a241c`). 강조는 **깊은 초록 `#2f6b4a` 하나만 넓게**, 감색 `#b4512e`(경고·별표)·금색 `#a87c22`(배점·출처)는 점처럼. **파랑·하늘색 금지** — 기존 화면의 `#315d7b`·`#149fe7` 계열을 쓰지 않는다 |
| 글꼴 | 화면 = Pretendard(`../assets/fonts/pretendard-var.woff2`, 굵기 100~700 — 900 금지). 인쇄 본문·표지 = **FC Serif**(Noto Serif KR 400/600/700 자체 탑재, `./fonts/`, OFL — 구글 폰트 CDN 안 씀) |
| 화면 짜임 | 교사용 편집 도구: 큰 카드·장식 대신 **얇은 선(1px `#e2d9c6`)·여백·정렬**. 목록은 표 꼴(줄마다 체크·번호·한 줄 미리보기·난이도 점·담기), 선택 줄은 왼쪽 초록 막대 |
| 시험지 | 흑백만. 머리말 = 과정 띠·큰 제목(명조)·이름/반/날짜 줄·배점표(문항/점수 2행, 본문 배점에서 자동 집계할 자리). 문항 = 번호(고딕)+`[N점]`+본문(명조), 필요한 문항에 **풀이 칸**(괘선)과 **답 줄**. 바닥글 = 브랜드·쪽번호 |
| 표지 | 시리즈형, 전면 그림(종이 오리기·쌓기나무·무늬) + 또렷한 제목 블록 + 권 배지 + 아래 발행처 줄. **권마다 색·교구·번호만 바꾼다**. 글자는 항상 진짜 글자(이미지로 굽지 않음), 그림은 원본 SVG |
| 인쇄 | `@page A4; margin:0`, 종이 자체에 여백(16/15/14mm). 화면 전용 요소는 `@media print`에서 숨김 |

## 제외 기준 (원장이 거른 것 — 다시 꺼내지 말 것)
- 파랑·하늘색 위주 배색 («푸르딩딩», 2026-10-23)
- 두껍고 둥근 AI풍 글씨(굵기 800~900 남발, 2026-10-23 골든벨 글꼴 정리와 같은 지시)
- 큰 카드·그라데이션·이모지 장식 위주의 화면

## 문항 배치 선택지 (2026-10-23 원장: 「다단이 될 수도 안 될 수도, 교재형일 수도 시험지형일 수도」)
- **단 수**: 문항이 짧으면 2단(`.sheet-body.cols-2`), 그림·풀이 칸이 크면 1단. 문항 부품(번호·배점·본문·풀이 칸·답 줄)은 동일.
- **꼴**: 시험지형(흑백·배점표·시험 시간) ↔ 교재형(단원 머리말·개념 상자·예제·집에서 한 번 더). 색은 교재형에만 초록 하나 옅게.
- 인쇄 설정에 「1단/2단」 「시험지/교재」 두 선택만 두면 된다.

## 다음 단계 (방향이 정해지면)
1. 원장이 표지 A/B/C 중 하나와 화면·시험지 느낌을 고른다 (색·여백 조정 요청 포함).
2. 고른 규칙을 `styles.css`(문제은행 본 화면)에 단계적으로 입힌다 — 기능 코드는 그대로, 색 토큰·글꼴·목록 짜임부터.
3. 시험지 실제 출력은 지금 렌더러에 이 머리말·배점표·풀이 칸 규칙을 입히고, 여러 쪽 나눔이 필요해지면 Paged.js(MIT) 도입을 검토.
4. 표지는 고른 안을 `print` 표지 생성기에 넣어 「표지 선택 → 제목·과정·회차 → PDF」로 연결. 고정 3~4종을 재사용한다(매번 새로 꾸미지 않음).
