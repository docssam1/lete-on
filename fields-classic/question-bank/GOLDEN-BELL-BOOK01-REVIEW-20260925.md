# 골든벨 1권 체험 감수 기록

상태: 1권만 검수 중. 2권 이후 확장과 추가 배포는 보류한다. 이 문서는 수학 자동 검사를 원본 적합성 승인으로 취급하지 않는다.

## 대조 근거

- 원본: `더클래식_1과정_1N30권_골든벨_220222`의 교사용 표시가 있는 슬라이드 2~34를 대조했다. 원본 그림과 정답이 포함된 파일 자체는 저장소에 복사하지 않는다.
- 화면: 1440px 및 390px에서 13개 체험의 66도전을 각각 실행했다. 계산·판정과 132개 화면 도전, 50개 체험-문제 연결 경로는 통과했다.
- 판정: 완성된 답은 확인 버튼 없이 즉시 판정한다. 오답은 바로 안내하며 수정할 수 있고, 정답은 2초 뒤 다음 도전으로 이동한다. 마지막 도전은 완료 상태와 연결 문제 버튼을 유지한다. 정답 뒤 다시 시작하면 대기 중인 이동을 취소한다.
- 음성: 사용자가 승인한 새 녹음의 말투로 시계 체험 시작·오답·정답의 로컬 시안 세 개를 연결했다. 시작 대사는 "반의 반 바퀴씩 돌려 문제를 맞춰 보자."다. 원본·참조 녹음은 저장소 밖에 보관하고, 승인된 시계 체험용 생성 MP3 세 개만 Git에 포함한다. 재생은 로컬 호스트에 한정하며 다른 체험·공개 배포는 아직 승인하지 않았다. 사용한 OmniVoice 모델 카드의 비상업용 조건은 서비스 배포 전 별도로 확인해야 한다.
- 전환: 12개 학습마다 해당 체험이 열리고 현재 학습의 문제 화면으로 돌아간다. 이 수정은 검수 브랜치에만 있으며 아직 배포하지 않았다.
- 인쇄: `fold-two-cut` 학습의 실제 A4 PDF 네 모드를 확인했다. 학습지 6쪽, 답안 3쪽, 빠른 정답 1쪽, 함께 인쇄 9쪽이며 함께 인쇄의 답안은 7쪽에서 시작한다. 추가 학습의 `explanation`에 저장된 기존 풀이를 답안 인쇄에서 읽도록 수정했다.
- 범위: 대표 슬라이드의 체험 적합성 1차 점검이다. 1권 전체 문항·답안·풀이·인쇄 승인은 아직 하지 않았다.

## 빠진 연결과 보류

1. 두 번 접고 자르기는 아직 직교 격자 절단 위주다. 원본 15~17쪽의 대각선 접기와 비정형 절단까지 확장해야 한다. 잘린 칸의 숫자 합은 구현·검산했지만 원본 모든 절단 형태를 대표하지는 않는다. 한 번 접기에도 접는 선에 걸친 절단 유형이 남아 있다.
2. 공개 인쇄에는 새 체험 13종의 종이 연습과 답안이 아직 없다. 이번 PDF 검사는 기존 `fold-two-cut` 학습만 대상으로 했다. 책 전체 인쇄와 모든 학습의 풀이 품질은 별도로 검수해야 한다.
3. 교사용 전체 문항·유사문항·풀이의 전수 대조와 음성 시험 샘플의 사용자 확인은 남아 있다. 대표 슬라이드 일치만으로 1권 완료를 선언하지 않는다.

승인 조건: 원본 사고 행동과 그림의 일치, 도전별 오답·복수해 검토, 학생/교사용 화면, 390px, 실제 A4 문제·답안 PDF를 각각 확인한다. 이 조건을 통과하기 전에는 2권으로 넘어가지 않는다.
