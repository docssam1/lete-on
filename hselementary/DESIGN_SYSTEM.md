# LETE-ON Elementary UI Direction

## Product character

- A carefully edited advanced-math workbook and worksheet studio.
- The real question, diagram, answer space, and print result are the visual assets.
- The interface should feel authored by an education team, not assembled from AI dashboard components.

## Visual system

- Paper: cool light gray and white, not cream or beige.
- Ink: deep green-blue.
- Curriculum accent: clear blue.
- Feedback accent: coral for warnings, green for approved states, ochre for source labels.
- Corners: 0-6px for working surfaces and controls.
- Shadows: only for floating previews or sheets above a dark review stage.
- Type: Pretendard for controls and Korean learning text. Large type is reserved for the public introduction page.

## Interaction rules

- Selection, configuration, and review each have one dominant action.
- Type hover and keyboard focus reveal the representative source-shaped problem.
- Motion explains selection or continuity and stays between 120ms and 260ms.
- Reduced-motion mode must remain complete.
- Liquid-metal styling is limited to the primary create button border on hover, with a solid static fallback.
- Orbs and thinking animation are allowed only when a real generation or verification wait state exists.

## Learning and print rules

- One source problem equals one detailed type unless source evidence proves otherwise.
- Do not change the reasoning path, spatial arrangement, answer unit, or diagram topology for visual convenience.
- Every public generator must keep one intended answer.
- Dense, sparse, text-only, graph, and geometry samples are checked on desktop, mobile, and A4 print.
- Print remains plain paper: no app chrome, decorative effects, or screen-only colors that weaken legibility.
