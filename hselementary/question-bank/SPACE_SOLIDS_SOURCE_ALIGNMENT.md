# 6-2 공간과 입체 원본 정렬 기준

## 원본 범위

- 심화 교재의 공간과 입체 범위: 인쇄 32~36쪽, 개념탐구 1~4와 예제·미션
- 원본은 구조와 난이도를 확인하는 데만 사용한다. 지문·그림·정답 표기를 그대로 복제하지 않는다.

## 유형 계약

원본의 네 개념탐구를 아래 네 생성기 묶음으로 나눈다. 각 묶음은 6개 세부 유형으로 구현한다.

### 1. 위·앞·옆에서 본 그림

1. 높이표로 앞·오른쪽 투영의 칸 수 구하기
2. 세 방향 투영을 바꾸지 않고 뺄 수 있는 맨 위 조각 찾기
3. 세 방향 투영을 만족하는 높이표의 방법 수 구하기
4. 높이표 쌓기의 겉넓이 구하기
5. 지정한 조각을 뺀 뒤 세 투영의 변화 구하기
6. 층별 색 규칙의 조각 수 구하기

### 2. 쌓기나무의 개수

1. 속을 비운 큰 정육면체의 조각 수 구하기
2. 세 방향 투영을 만족하는 전체 조각 수의 최솟값·최댓값 구하기
3. 중앙 구멍을 뚫은 정육면체의 개수와 겉넓이 구하기
4. 세 방향 투영을 만족하는 서로 다른 쌓기 방법 수 구하기
5. 계단 높이표에서 완전히 안쪽인 조각 수 구하기
6. 바닥 모양·전체 개수·높이 제한을 만족하는 방법 수 구하기

### 3. 색칠된 쌓기나무의 개수

1. 큰 정육면체에서 색칠되지 않은 안쪽 조각 수 구하기
2. 높이표 쌓기에서 특정 수의 면이 색칠된 조각 수 구하기
3. 층형 쌓기에서 특정 수의 면이 색칠된 조각 수 구하기
4. 높이표 쌓기의 색칠한 넓이 구하기
5. 직육면체에서 정확히 두 면이 색칠된 조각 수 구하기
6. 복합 높이표 쌓기에서 특정 수의 면이 색칠된 조각 수 구하기

### 4. 여러 가지 문제

1. 수평 절단면이 지나는 조각 수 구하기
2. 서로 수직인 세 중앙 절단면의 합집합 구하기
3. 평행 절단면들이 지나는 조각 수 구하기
4. 한 조각을 붙여 만드는 서로 다른 입체 모양 수 구하기
5. 좌표 색 규칙으로 정한 조각을 뺀 뒤 남는 수 구하기
6. 지정한 조각을 뺀 뒤 앞에서 본 칸 수 구하기

## 공개 전 필수 검사

- 세 방향 투영으로 높이를 특정해야 하는 경우, 위·앞·오른쪽 정보 또는 높이표를 모두 제시한다.
- 숨은 조각을 묻는 경우에는 전체 개수, 바닥 모양, 세 방향 투영, 높이 제한 중 필요한 조건을 지문에 고정한다.
- 방법 수를 묻는 문제는 가능한 높이표를 전부 열거해 답 숫자가 하나임을 확인한다.
- 색칠·겉넓이 문제는 바닥 포함 여부와 색칠 대상 면을 명시하고, 복셀 이웃 검사로 다시 계산한다.
- 절단면 문제는 절단면 수·방향·겹침 여부를 지문에서 고정하고 포함배제로 독립 검산한다.
- 회전 동치가 답에 영향을 주는 모양 문제는 같은 모양으로 보는 회전 기준을 고정하고 24방향 회전으로 중복을 제거한다.
- 그림에는 높이표, 투영 라벨, 격자 또는 대체 설명 중 필요한 읽기 단서를 반드시 넣는다.
- `space-solids-6-2-audit.js`의 독립 전수 검사와 `GEOMETRY_VALIDATION.md`를 통과한 유형만 생성 가능으로 표시한다.
