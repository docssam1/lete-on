# 5-2 직육면체 원본 정렬 기준

## 원본 범위

- 교재: `황소수학 5-2.pdf`
- 인쇄 쪽수: 48~59쪽
- PDF 쪽수: 50~61쪽
- 구성: 개념탐구 1~6과 각 개념탐구의 Mission

원본은 문제 구조와 난이도 판단에만 사용한다. 지문을 그대로 옮기지 않고 수치, 이름,
배치를 바꾼 생성 문제를 만든다.

## 유형 계약

### 1. 직육면체의 성질

1. 격자 직육면체의 작은 정육면체 수
2. 가장 큰 정육면체로 자른 개수와 정육면체 한 개의 모서리 길이 합
3. 두 방향으로 자른 합동 조각들의 모서리 길이 합
4. 정육면체 격자에서 만들 수 있는 서로 다른 직육면체 크기 수
5. 같은 직육면체 조각을 직육면체 배열로 쌓는 서로 다른 크기 수

### 2. 직육면체의 전개도

1. 그려진 전개도가 종이에 들어가는지 회전을 포함해 판정
2. 직사각형 모서리를 잘라 접은 상자의 모서리 길이 합
3. 그려진 일반 직육면체 전개도에 필요한 최소 도화지
4. 전개도를 오리고 남는 종이의 넓이
5. 다섯 칸에 한 칸을 붙여 완성되는 후보 위치 모두 찾기

### 3. 직육면체의 전개도와 겨냥도

1. 전개도를 접었을 때 한 꼭짓점에서 만날 수 없는 세 면
2. 한 모서리와 평행하거나 수직인 모서리 수
3. 한 꼭짓점에서 만나는 세 면의 수를 이용한 순위 계산
4. 마주 보는 세 면 쌍의 곱 비교
5. 이동 범위를 모서리로 고정한 최단거리

### 4. 직육면체의 활용

1. 높이표로 주어진 쌓기를 담는 최소 상자
2. 세 방향으로 두른 끈의 전체 길이
3. 작은 직육면체의 여섯 방향을 비교한 최대 포장 수
4. 매듭 여유까지 포함한 끈 길이로 상자 한 개의 높이 역산
5. 세 방향의 끈 길이로 가장 짧은 모서리 역산

### 5. 주사위에 관한 문제 1

1. 회전하여 같은 면 배치를 한 가지로 보는 경우의 수
2. 실제로 접히는 전개도에서 빈 면의 수
3. 같은 주사위를 세 방향에서 본 면의 합으로 숨은 면 추론
4. 같은 방향의 주사위 줄에서 맞닿은 면의 합
5. 접촉면과 바닥면이 동시에 가능한 쌓기의 보이는 면 합

### 6. 주사위에 관한 문제 2

1. 시작 방향과 격자 경로가 보이는 최종 윗면
2. 동서 또는 남북 굴림 기록으로 마주 보는 면 추론
3. 같은 주사위의 여러 격자 경로에서 최종 바닥면 합
4. 격자 경로의 각 도착 칸에서 본 윗면 합
5. 두 격자 경로의 윗면 합으로 미지의 면 추론

## 공개 전 필수 검사

- 유형 ID와 `data-cuboid-kind`의 대응을 고정한다.
- 전개도는 면 여섯 개가 서로 겹치지 않고 서로 다른 3차원 방향으로 접히는지 검사한다.
- 전개도 한 칸 완성 문제는 모든 인접 후보를 전수 확인하고, 가능한 번호를 모두 답하게 한다.
- 주사위는 24개 회전 상태를 전수 확인하고 정답 후보가 하나일 때만 통과시킨다.
- 쌓기와 포장은 모든 축 순서와 가능한 배열을 비교한다.
- 숨은 부분은 지문과 그림만으로 결정되어야 한다.
- 구하려는 모서리나 높이는 그림의 치수 글자로 미리 노출하지 않는다.
- 한 고리와 세 방향 고리는 그림의 고리 수가 지문과 정확히 일치해야 한다.
- 표준 주사위가 아닌 면 배치는 1부터 6까지의 수를 임의로 적었다고 명시한다.
- 주사위를 돌려 본 여러 모습은 시계·반시계 방향을 지문에 고정한다.
- 그림이 필요한 유형은 SVG와 대체 설명을 모두 제공한다.
- 데스크톱과 모바일에서 치수, 면 번호, 경로가 잘리거나 겹치지 않아야 한다.
- 생성기와 같은 공식을 되풀이하는 검사는 독립 검산으로 인정하지 않는다.
