# 황소 초등 유사문제 문제은행

중등 성취도 진단 문제은행과 분리된 초등 교재 전용 프로그램입니다.

## 분류 범위

- 학년: 4·5·6학년
- 학기: 1·2학기
- 문제은행 기준: 학년별 일반 문제보다 높은 `심화` 교재 구조
- 변형 단계: 심화 구조를 유지한 `심화 낮춤`·`심화 기준`·`심화 올림`
- 교재 분류: 6개 학기, 36개 단원, 218개 세부 유형
- 현재 생성 가능: 수식과 도형을 검산한 174개 유형
- 제작 대기: 추가 원문 분석 또는 전용 렌더 검수가 필요한 44개 유형

이 문제은행은 학년별 일반 난이도 문제가 아니라 심화 문제은행입니다. 심화 기준을 중심으로 같은 문제 구조에서 수 범위와 조건 수만 조금 낮추거나 올립니다.

## 제작 원칙

1. 원문 문제나 페이지 이미지를 웹에 복제하지 않습니다.
2. 교재에서 확인한 단원·유형 구조만 분류 근거로 사용합니다.
3. 생성 문제는 숫자와 조건을 새로 구성하고 정답과 풀이를 함께 계산합니다.
4. 그림이 핵심인 유형은 전용 렌더러가 검수되기 전까지 선택할 수 없습니다.
5. 유형별 검수에서 통과한 생성기만 `생성 가능` 상태로 유지합니다.

## 파일

- `curriculum.js`: 학기·단원·유형 분류
- `generators.js`: 난이도별 문제·정답·풀이 생성기
- `mixed-operation-audit.js`: 5-1 자연수의 혼합 계산 4유형의 식·답·유일한 기호 조합 검산
- `factors-audit.js`: 5-1 약수와 배수 12유형의 약수·소인수·공약수·공배수 조건 검산
- `correspondence-audit.js`: 5-1 규칙과 대응 4유형의 변환 규칙·대응표·도형 배열·실제 조건 검산
- `fractions-audit.js`: 5-1 약분과 통분 4유형의 조건식·기약분수·교차곱 비교·조건 분수 검산
- `fraction-add-sub-audit.js`: 5-1 분수의 덧셈과 뺄셈 4유형의 유리수 계산·빈칸·단위분수 조건 검산
- `perimeter-area-audit.js`: 5-1 다각형의 둘레와 넓이 4유형의 경계선·분할 넓이·배율·정사각형 조합·사각형 넓이 검산
- `range-rounding-audit.js`: 5-2 수의 범위와 어림하기 12유형의 범위·어림·묶음·구간 요금·원래 수 범위 역검산
- `fraction-multiplication-audit.js`: 5-2 분수의 곱셈 12유형의 연속 비율·규칙 곱·역산·기약분수 조건 독립 검산
- `congruence-symmetry-audit.js`: 5-2 합동과 대칭 24유형의 삼각형 조건·합동 활용·선대칭·점대칭 정답과 그림 조건 독립 검산
- `movement-audit.js`: 4-1 평면도형 이동 12개 세부 유형의 생성기 분기 고정 검산
- `GEOMETRY_VALIDATION.md`: 쌓기나무·입체도형·색종이 접기의 단일정답·가시성 검수 기준
- `app.js`: 필터, 선택, 학습지, 워터마크, 인쇄
- `index.html`, `styles.css`: 문제은행 화면

비공개 교재 파일, 절대 경로, 원본 페이지 이미지는 이 저장소에 포함하지 않습니다.
