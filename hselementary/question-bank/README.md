# 황소 초등 유사문제 문제은행

중등 성취도 진단 문제은행과 분리된 초등 교재 전용 프로그램입니다.

## 분류 범위

- 학년: 4·5·6학년
- 학기: 1·2학기
- 레벨: 일품(심화)·실력·경시
- 교재 분류: 6개 학기, 36개 단원, 174개 유형
- 1차 생성 가능: 수식으로 정답을 검산할 수 있는 67개 유형
- 제작 대기: 그림·그래프·전개도 등 별도 렌더 검수가 필요한 107개 유형

`일품(심화)`은 파일명에 남은 `심화` 교재를 일품 후보로 분리한 화면 이름입니다. 실력·경시 자료와 섞지 않습니다.

## 제작 원칙

1. 원문 문제나 페이지 이미지를 웹에 복제하지 않습니다.
2. 교재에서 확인한 단원·유형 구조만 분류 근거로 사용합니다.
3. 생성 문제는 숫자와 조건을 새로 구성하고 정답과 풀이를 함께 계산합니다.
4. 그림이 핵심인 유형은 전용 렌더러가 검수되기 전까지 선택할 수 없습니다.
5. 유형별 검수에서 통과한 생성기만 `생성 가능` 상태로 유지합니다.

## 파일

- `curriculum.js`: 학기·단원·유형 분류
- `generators.js`: 난이도별 문제·정답·풀이 생성기
- `app.js`: 필터, 선택, 학습지, 워터마크, 인쇄
- `index.html`, `styles.css`: 문제은행 화면

비공개 교재 파일, 절대 경로, 원본 페이지 이미지는 이 저장소에 포함하지 않습니다.
