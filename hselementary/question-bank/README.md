# 황소 초등 유사문제 문제은행

중등 성취도 진단 문제은행과 분리된 초등 교재 전용 프로그램입니다.

## 학생 이름 권한 계약

- 기본값은 로그인 이름 자동 입력 및 읽기 전용입니다.
- 이름 변경은 통합 관리자의 `초등 문제은행 · 학생 이름 변경` 권한(`hselementary:student-name:edit`) 또는 `window.HSELEMENTARY_ACCESS.studentNameEditors` 관리자 승인 목록에 포함된 경우에만 허용합니다.
- URL의 `student` 값은 기존 서재 연결을 위해 이름 전달에만 사용하며, URL 값만으로 편집 권한을 얻을 수 없습니다.
- 권장 로그인 세션 형식은 `window.HSELEMENTARY_SESSION = { name, permissions }` 또는 통합 로그인 세션 `window.GFIELD_SESSION`이며, 저장형 세션의 `hse-session`·`gfield-session`도 같은 JSON 구조로 읽습니다.

## 분류 범위

- 학년: 4·5·6학년
- 학기: 1·2학기
- 문제은행 기준: 학년별 일반 문제보다 높은 `심화` 교재 구조
- 변형 단계: 심화 구조를 유지한 `심화 쉬움`·`심화 기준`·`심화 어려움`
- 교재 분류: 6개 학기, 36개 단원, 174개 소단원, 런타임 964개 세부 유형 항목
- 현재 생성 가능: 수식과 도형을 검산하고 원문 구조 연결까지 확인한 894개 유형
- 검수 대기: 원문 답·조건·그림이 하나로 확정되지 않은 70개 유형
- 원문 문항 단위 매핑 완료: 4-1 전체 329개 + 4-2 분수 66개 + 삼각형 44개 + 소수 44개 + 사각형 10개 + 꺾은선그래프 22개 = 515개
- 4-1은 개념탐구 30개, 유제 119개, Mission 180개를 각각 한 유형으로 분리했습니다. 원문에 없는 3단원 개념탐구 6의 예제 6-4는 만들지 않았습니다.
- 기존 4-1 생성기 95개를 원문과 다시 대조해 정확히 일치한 연결만 남겼습니다. 큰 수 개념탐구 1·2·3·4·5·6의 원문 66항목과 각도 개념탐구 1·2·3·4의 원문 44항목은 각각 전용 생성기로 구현했습니다. 각도 개념탐구 5는 9항목, 개념탐구 6은 10항목만 단일 정답과 화면 가시성을 확인해 열었습니다. 곱셈 알아보기 개념탐구 1, 곱셈 응용 문제 개념탐구 2, 나눗셈 알아보기 개념탐구 3, 나눗셈 응용 문제 개념탐구 4도 각각 11항목을 원문 문제 단위의 독립 생성기로 열었습니다. 나눗셈의 나머지 개념탐구 5는 공식 답안과 독립 계산이 모두 확인된 10항목을 열고, 수 카드 예제 5-2는 공식 숫자 답이 비어 있어 전수검산 생성기만 준비한 뒤 잠금으로 유지했습니다. 평면도형의 이동 개념탐구 1은 10항목, 개념탐구 2는 8항목, 개념탐구 3은 9항목, 개념탐구 4는 8항목을 열었습니다. 막대그래프의 이해 개념탐구 1은 표·세로 막대·가로 막대·눈금 바꾸기 11항목을 원문 구조대로 열었습니다. 막대그래프의 활용 개념탐구 2는 본문·예제 2-3·Mission 1~5의 7항목을 원문별 독립 생성기로 열었고, 예제 2-1은 공식 답이 없으며 예제 2-2는 답이 여러 개, 예제 2-4는 총수와 답안 계산이 다르고 Mission 6은 답안이 다른 문제라 잠금으로 유지했습니다. 개념탐구 3의 예제 3-2는 뒤집기 기준에 따라 그림이 달라지고 Mission 4는 58개와 60개가 모두 가능해 잠금으로 유지했습니다. 개념탐구 4의 본문, 예제 4-2, 예제 4-4는 제공 답과 독립 계산이 달라 잠금으로 유지했습니다. 설명형은 답을 하나로 고정하고 수 카드·날짜·나머지·자리 합·도형 좌표 조건은 가능한 값을 모두 검사했습니다. 현재 4-1 공개 유형은 309개입니다.
- 4-2 분수의 덧셈과 뺄셈은 개념탐구 6구간의 본문·예제·Mission 66문항을 각각 독립 유형으로 나누고, 같은 유형 안에서도 조건과 수가 달라지는 유사문제를 생성합니다.
- 4-2 삼각형은 원문 44문항을 모두 문항 단위로 분류했습니다. 현재 원문 그림과 조건을 직접 대조하고 독립 계산까지 마친 32문항을 공개하며, 나머지 12문항은 전용 그림과 정답 검산이 끝날 때까지 잠급니다. 첫째 소단원 개념탐구 1은 인쇄된 8개 연속선과 10개 꼭짓점을 두 방식으로 전수 계산해 삼각형 40개를 확인했고, 왼쪽 빗변의 갈림점을 쓰는 21개와 쓰지 않는 19개로 다시 나누어 검산했습니다. 예제 1-1은 원본의 가로 4개와 두 사선 방향 각 4개, 모두 12개 연속선을 복원해 점 세 개와 선 세 개 방식이 모두 32개임을 확인했습니다. 개념탐구 2의 4×3 점판은 세 점의 모든 조합을 세 변 길이로 묶어 서로 다른 둔각삼각형이 9가지임을 확인했습니다. 예제 2-2와 Mission 2의 별 모양은 다섯 선분과 실제 교점을 전수 열거해 예각삼각형 5개, 둔각삼각형 5개를 확인했습니다. 예제 2-4와 Mission 3은 고른 두 각의 합이 180°보다 작고, 고른 각 또는 남은 각이 90°보다 큰 모든 짝을 전수 계산해 각각 10가지임을 확인했습니다. 둘째 소단원 Mission 1은 일반적인 선분 분할에서 둔각삼각형 0개부터 4개까지 모두 만들 수 있다는 독립 반례 두 건이 일치해 조건 부족으로 잠금을 유지합니다. 둘째 소단원 Mission 4는 모눈의 굵은 6개 선분과 모든 교점을 전수 계산해 예각삼각형 4개·둔각삼각형 8개를 확인했고, Mission 5는 정사각형 띠의 13개 선분과 모든 교점을 계산해 예각삼각형 1개·둔각삼각형 2개·차 1개를 확인했습니다. 셋째 소단원 Mission 1은 공통 밑변을 두 번 빼 원문 답 38cm, Mission 3은 이등변삼각형 50개 띠의 짧은 변 50개와 양 끝 변을 더해 320cm, Mission 6은 원 위 10점의 모든 세 점을 전수 열거하고 회전·뒤집기 중복을 세 변의 점 간격으로 제거해 서로 다른 이등변삼각형 4가지를 확인했습니다. 예제 3-2는 둘레와 한 삼각형의 세 변 길이 합으로 짧은 변 3cm를 확인했습니다. 정삼각형 Mission 3은 같은 길이 세 선분과 150°·60° 관계로 30°, Mission 4는 같은 길이 두 선분과 직각 관계로 15°, Mission 6은 평행한 두 변과 60°·150°·30° 관계로 윗변을 각각 독립 계산했습니다. 정삼각형 개념탐구는 성냥개비 12개 중 2개를 옮기는 모든 경우를 세 탐색 범위에서 전수 검사해 유효한 48개 배치를 찾고, 돌리거나 뒤집어 같은 모양을 묶어 답 5가지를 확인했습니다. 첫째 소단원 Mission 4의 원문 구조는 아래쪽 15개, 오른쪽 21개, 바깥 큰 삼각형 1개로 답 37을 확인했습니다. Mission 5는 원문의 7개 선분과 모든 교점을 전수 계산해 손글씨 19 대신 24개를 확인했습니다. Mission 6은 양쪽 변 5점의 두 부채꼴을 모두 이어 답 64를 확인했습니다.
- 4-2 소수의 덧셈과 뺄셈은 Mission 24문항에 더해 개념탐구 1의 `기준 무게에서 10배의 몸무게 거꾸로 구하기`와 개념탐구 4의 `범위 안의 소수 네 자리 수 세기`를 원문과 직접 대조해 공개했습니다. 첫 문제는 인쇄 조건만 사용해 원문 답 `709.3kg`을 확인하고 정수 g 단위로 20,005조합을 전수 검사했습니다. 둘째 문제는 `5.008`과 `5.1` 사이에서 소수점 아래 넷째 자리 숫자가 1부터 9인 수만 세어 원문 답 `828개`를 확인했습니다. 학생 화면에서는 `10분의 1`을 공통 세로 분수로 표시하며 불필요한 소수 끝자리 0을 없앴습니다. 현재 공개 26문항, 검수 대기 18문항입니다.
- 4-2 꺾은선그래프는 개념탐구 본문 2개, 예제 8개, Mission 12개를 22개 원문 항목으로 다시 나눴습니다. 풀이 구조가 같은 Mission 2개는 중복 유형에서 제외했고, 개념탐구 1의 서로 다른 9문항만 원자료·눈금·좌표·답을 독립 검산해 공개했습니다. 9월이 표시 점 사이에 있어 공식 답 없이 값을 확정할 수 없는 Mission 6과 개념탐구 2의 10유형은 검수 대기로 잠갔습니다.
- 주의: 전체 964개 중 원문 문항 ID와 쪽수가 확정된 것은 515개입니다. 나머지 학기·단원도 같은 방식으로 개념탐구, 예제, Mission을 한 문제씩 다시 매핑해야 합니다.

이 문제은행은 학년별 일반 난이도 문제가 아니라 심화 문제은행입니다. 심화 기준을 중심으로 같은 문제 구조에서 수 범위와 조건 수만 조금 낮추거나 올립니다.

## 제작 원칙

1. 원문 문제나 페이지 이미지를 웹에 복제하지 않습니다.
2. 교재에서 확인한 단원·유형 구조만 분류 근거로 사용합니다.
3. 생성 문제는 숫자와 조건을 새로 구성하고 정답과 풀이를 함께 계산합니다.
4. 그림이 핵심인 유형은 전용 렌더러가 검수되기 전까지 선택할 수 없습니다.
5. 유형별 검수에서 통과한 생성기만 `생성 가능` 상태로 유지합니다.
6. 작업 완료, 근거 검증, 공개 승인을 분리하고 문항별 검수 근거를 증거 장부에 남깁니다.

`EVIDENCE_PIPELINE.md`는 원본 대조부터 공개까지의 게이트와 풀이 장면 적용 범위를 정합니다. `.evidence-pipeline/pipeline.json`은 4-2 사각형 검수부터 실제 근거 위치와 상태를 기록하며, 원문·답안·비공개 경로는 담지 않습니다.
