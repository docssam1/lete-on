# 4-2 사각형 두 각도 유형 학년·화면 감사

## 범위

- 학습자 단계: `초등 4학년 2학기 심화`
- `4-2-u4-t2-4`: 평행선 사이의 두 각을 이용해 표시된 바깥쪽 각 하나를 구하는 유형
- `4-2-u4-t1-9`: 수직인 두 직선 사이에서 표시된 두 각 `㉠`, `㉡`을 각각 구하는 유형
- 이 감사는 위 두 유형만 다룹니다. 4-2 사각형 단원 전체의 공개 승인을 뜻하지 않습니다.

원문과 답안의 내용이나 경로는 이 파일에 기록하지 않습니다. 원문 구조 확인은 비공개 source-memory 기록 `hs-elementary.unit.4-2-4-quad`에서 수행합니다.

## 답 형식

- `4-2-u4-t2-4`: `single-value`. `㉠`에 들어갈 각도 하나를 씁니다.
- `4-2-u4-t1-9`: `ordered`. 화면에 표시된 순서대로 `㉠`, `㉡` 두 각도를 씁니다.

## learner-fit

### language

- 문제 지문은 `직선 가`, `직선 나`, `평행`, `수직`, `각의 크기`처럼 해당 학년 교재에서 쓰는 말로 묻습니다.
- 유형명의 `바깥각`은 각의 위치를 설명하는 데만 쓰며, 문제와 풀이에서 중학교의 외각 정리나 문자식 증명을 요구하지 않습니다.
- 풀이에는 덧셈·뺄셈과 `90°`, `180°`만 사용하고 상위 과정 용어를 넣지 않습니다.

### representations

- 평행선 또는 수직인 두 직선, 빗선, 꼭짓점, 각호, 각도 숫자와 `㉠`·`㉡`을 함께 보여 줍니다.
- 숫자와 물음 표시를 선 가까이에만 놓지 않고, 해당 꼭짓점에서 두 변 사이를 잇는 각호 안에 배치합니다.
- 색만으로 각을 구분하지 않으며 흑백 인쇄에서도 각호와 글자로 같은 정보를 읽을 수 있습니다.

### prerequisites

- 각의 크기와 도 단위, 직각 `90°`, 평각 `180°`, 삼각형의 세 각의 합을 알고 있다는 4학년 심화 교재의 앞선 학습을 전제로 합니다.
- 평행·수직의 성질을 현재 사각형 단원에서 함께 사용합니다.
- 닮음, 삼각비, 방정식, 중학교 평행선 정리 같은 뒤 학년 개념은 필요하지 않습니다.

### reasoning-load

- `4-2-u4-t2-4`는 삼각형의 남은 각을 구한 뒤 평각에서 빼는 두 단계입니다.
- `4-2-u4-t1-9`는 두 주어진 각을 각각 직각에서 빼는 독립된 두 단계입니다.
- 숫자만 크게 바꾸지 않고 원문과 같은 각 관계와 생각 순서를 유지합니다. 생성 각도는 양의 정수이며 그림에서 구분 가능한 범위로 제한됩니다.

### response-mode

- `4-2-u4-t2-4`는 단일 각도 직접 입력입니다.
- `4-2-u4-t1-9`는 `㉠`, `㉡`의 순서를 고정한 두 각도 직접 입력입니다.
- 선택지 모양이나 입력 칸 수로 답을 미리 알려 주지 않고, 풀이 화면에서 각 기호와 답의 대응을 유지합니다.

## 실제 화면 확인

확인일: 2026-08-30

### PC 1280×900

- 두 유형 모두 세 문항의 지문, 각호, 숫자, `㉠`·`㉡`, 답안 줄이 잘리지 않았습니다.
- `4-2-u4-t2-4`의 고정 회귀 사례 `54°`, `58°`에서 두 숫자는 각각 왼쪽 위 각과 아래 꼭짓각 안에 있고 `㉠`은 오른쪽 바깥쪽 각호 안에 있습니다.
- 풀이 화면에서 답과 계산 문장이 문항별로 분리되어 보입니다.

### 모바일 375×812

- 문항이 한 열로 바뀌며 그림과 답안 줄이 화면 너비 안에 들어옵니다.
- 각도 숫자와 각호가 선에 가려지지 않고, 두 각 문항의 `㉠`, `㉡` 순서가 유지됩니다.
- 가로 넘침은 발견되지 않았습니다.

### A4 PDF

- 실제 Chromium PDF는 A4 `594.96×841.92pt`, 한 페이지로 생성되었습니다.
- 문제 PDF에서 세 문항의 각호, 숫자, 물음 표시, 답안 줄을 직접 열어 확인했고 잘림이나 겹침이 없었습니다.
- 풀이 PDF에서 세 문항의 답과 계산 문장이 한 페이지 안에 들어오며 글자가 워터마크에 묻히지 않았습니다.
- 확인한 산출물 이름: `parallel-v/a4-problem.pdf`, `parallel-v/a4-solution.pdf`, `two-angles/a4-problem.pdf`, `two-angles/a4-solution.pdf`.

## Negative control

원본 작업 파일을 바꾸지 않고 시스템 임시 폴더에 `hselementary` 복사본을 만들어 두 브라우저 감사를 각각 깨뜨렸습니다.

- `4-2-u4-t2-4`: 임시 생성기의 `left-exterior` 각호 역할을 다른 이름으로 바꾸자 PC 3문항과 모바일 3문항에서 모두 해당 각 표시가 없다고 실패했습니다.
- `4-2-u4-t1-9`: 임시 생성기의 `target-left` 각호 역할을 다른 이름으로 바꾸자 PC 3문항과 모바일 3문항에서 모두 해당 각 표시가 없다고 실패했습니다.
- 증거 장부에서는 둘째 항목의 `learner-fit`을 임시로 `pending`으로 바꾸자 `verified`와 `eligible` 조건이 모두 거부되었습니다.
- 각 실행 뒤 임시 서버를 종료하고 임시 복사본을 삭제했습니다. Git 작업 파일은 바뀌지 않았습니다.

## 판정

두 유형은 `초등 4학년 2학기 심화`의 언어, 표현, 선수 개념, 생각 단계, 답하는 방법에 맞습니다. 답 형식은 서로 다르므로 장부에서 한 문항은 `single-value`, 다른 문항은 `ordered`로 분리합니다. 생성기·원문 위치·각호 렌더러·공통 수식 모듈 중 하나가 바뀌면 이 판정을 `stale`로 돌리고 다시 확인합니다.
