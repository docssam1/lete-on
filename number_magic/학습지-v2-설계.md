## 0. 참고한 샘플 (Drive, 원장 제공 교재 — git 금지, 구조만 참고)
- `초등연산 A01 STEP2.pdf` (더하기 1) · `중등연산 G24.pdf` (유리수 곱셈·나눗셈) · `고등 K29 유리식의 계산.pdf`
- 공통 구조
  1. **머리띠**: 왼쪽 학원 로고칸 · 가운데 색띠에 **유형 제목 + 부제** · 오른쪽 **코드**(A01-201, G24-102 …). 맨 위 작은 글씨로 반/날짜.
  2. **첫 장 = 개념 패널**: 연한 배경 박스 안에 정의·공식·**풀이 과정이 보이는 예제**(G24: 한 줄씩 부호 결정 → 절댓값 곱 → 답). 그 아래 "■ 계산을 하시오." 지시문과 **과정 빈칸이 있는 안내 문항** 몇 개.
  3. **다음 장부터 같은 유형만**: 번호 (1)…(20) 연속, **박스 없음**, 한 줄에 식 하나 + 빈 공간(= 뒤 여백). 초등은 1열×10, 고등은 2열×10(세로 방향으로 번호 진행). 페이지마다 코드 뒷자리 +1.
  4. 한 회차(예: G24)가 **한 유형** 14쪽. 난이도는 뒤로 갈수록 조금씩 올라간다. STEP2 = 같은 유형 추가 연습.

## 1. 지금 우리 학습지의 문제 (2026-09-04 캡처, C4-S1 / C30-S1)
- 표지 한 장이 거의 빈 종이. 개념은 **별도 장**에 유닛 노트를 통째로 부어 넣어(C30은 두 장 반) 문제와 떨어져 있다.
- 20문항에 유형 3~4개가 섞여(8+7+5) 유형당 5~8문항 — 연습이 안 된다.
- 문항마다 회색 박스, 4열 좁은 칸 → 중고등 분수·거듭제곱이 콩알만 하다.
- 풀이 과정을 보여주는 예시 문항이 없다.
- 온라인 "문제지"는 채점 뒤 "계속 연습"만 있고 몇 회째인지·유형별 반복이 보이지 않는다.

## 2. v2 구조 — "세션 = 유형별 회차 묶음"
세션(과정 N · S k)의 드릴 하나 = **회차 하나**. 세션 인쇄 = 드릴 순서대로 회차를 이어 붙인 것.

### 2-1. 회차 한 벌 (유형 = 스레드+레벨)
```
[첫 장]  머리띠 | 개념 패널(개념 문장 + 규칙) | ★예시 문항(빨강, 과정) | ■ 지시문 | 문항 (1)~
[둘째 장~] 머리띠 | 문항 이어서 (연속 번호)
```
- 문항 수 = 유형당 **N**(피커 10/20/40 — 이제 세션 총량이 아니라 **유형당** 수). 기본 20.
- 정답지는 세션 끝에 한 번(기존 `.nm-print-answer-key` 유지, 유형별로 소제목).
- 표지: 기본 **끔**으로 바꾼다(원장: 종이가 빈다). 켜면 기존 표지 그대로.
- "첫 장에 개념 넣기" 토글은 **개념 패널 켜기/끄기**로 뜻이 바뀐다(별도 장 아님). 기본 켬.

### 2-2. 머리띠 (`.nm-w2-head`)
- 좌: 학원명(`localStorage nm_brand_name` 있으면 그것, 없으면 `GFIELD`) 작은 상자.
- 중: 색띠(티어 accent) 안에 **유형 이름**(`NM_THREADS[t].name`) + 부제(과정 N · 과정 제목).
- 우: 코드 `C4-S1 · AD5-L1 · 1/3` (회차 안 쪽 번호). 맨 위 작은 줄: `이름 ______  날짜 ____ / 점수 ___ / N`.
- 아래 얇은 선. 높이 ≈ 22mm.

### 2-3. 개념 패널 (`.nm-w2-concept`) — 첫 장만
- 연한 배경(티어색 8%) 둥근 상자. 제목 줄 "개념" 뱃지 + 유형 이름.
- 본문: `NM_THREADS[t].concept`(3개 국어) 한 문단. 관련 마법 유닛이 있으면 `discover.rule`("마법의 규칙") 한 줄만 추가 — **stages 전체를 붓지 않는다**(지금처럼 두 장짜리 노트가 되지 않게). 높이 상한 ≈ 55mm, 넘치면 잘라 `…`.

### 2-4. ★ 예시 문항 (`.nm-w2-example`) — 첫 장, 빨간 과정
- 그 유형의 생성기로 문제 1개를 시드 고정으로 만들고(`hashSeed('ex'+code)`) 검은 식 + **빨간 풀이**를 보여준다.
- 풀이 원천, 우선순위:
  1. 생성기 `steps`(72개 스레드가 준다: `{tex, blank}` 배열) → 각 step의 `\square`에 `blank` 값을 넣어 빨간 글씨로 한 줄씩 `→` 이어 쓰고 마지막에 `= 답`.
  2. `steps`가 없으면: 식에 **답만 빨간색**으로 채운 한 줄 + 개념 문장 중 "예)"·숫자 예시가 있는 문장(정규식으로 `\d`가 든 문장 첫 것)을 빨간 작은 글씨로. 
  3. 세로셈(`parseVert`가 잡는 tex)이면 세로 배치 그대로 답을 빨간색으로.
- 라벨: `예시` 빨간 뱃지. 번호 없음(문항 번호는 (1)부터).

### 2-5. 문항 배치 (`.nm-w2-grid`) — 박스 없음, 페이지 가득
- 페이지 상자 `.nm-w2-page`는 **A4 고정 높이**(`@page A4 margin 10mm`; 페이지 = 277mm − 여백), flex column. 그리드가 남은 높이를 `flex:1`로 채우고 `grid-auto-rows:1fr` → 문항 수가 적어도 줄 간격이 균등하게 늘어난다.
- 유형 판정(회차 안의 문항 전체를 보고 **한 번** 결정, 문항마다 바뀌지 않음):

| 판정 | 조건 | 열×행/장 | 번호 진행 |
|---|---|---|---|
| 세로셈 | `parseVert(tex)` 성공 | 4×5 = 20 | 가로 |
| 짧은 식 | tex ≤ 16자, 분수·근호·지수 없음 | 2×10 = 20 | **세로**(1~10 왼쪽, 11~20 오른쪽 — 샘플 K29 방식) |
| 중간 식 | 그 외 tex ≤ 44자 | 2×8 = 16 | 세로 |
| 긴 식 | tex > 44자 또는 `steps` 위젯 3단 이상 | 1×8 = 8 | — |
| 문장제 | `p.word` | 1×6 = 6 | — |
| 그림형 | tex 없음(NL·십진블록·수직선) | 2×4 = 8 | 가로 |

- 문항 한 줄: `(n)` 회색 작은 번호 · KaTeX 식(끝이 `= \square`면 `\square`를 지우고 `=` 뒤 여백) · **테두리·배경 없음**. 세로셈은 기존 `nm-print-vp` 마크업 재사용하되 박스 제거.
- 답 쓰는 자리: 유아 밴드(`nm-print-age-young`)만 샘플처럼 작은 네모 칸 유지, 그 외는 빈 여백.
- 글자 크기: 짧은 식 15pt, 중간 14pt, 긴 식 13pt, 세로셈 14pt. KaTeX display 아님(inline).

### 2-6. 난이도 정렬
회차 안에서 **쉬운 것 → 어려운 것**으로 정렬한다. 기준(순서대로): 피연산자 자릿수 합 → `|answer|` → tex 길이. 문장제·그림형은 정렬하지 않는다. (샘플이 뒤로 갈수록 수가 커지는 것을 흉내.)

### 2-7. 코드·번호
- 회차 코드 = 기존 `NM_EXAM.worksheetCode({thread,level,count,seed})` 그대로(`?ws=` 도우미가 읽는다) — 머리띠 오른쪽에 짧게 `AD5-L1 · 1/3`, 맨 아래 작은 글씨에 전체 코드.
- 번호는 회차 안에서 1부터, 세션 전체가 아니라 **유형별로 리셋**(유형이 바뀌면 (1)부터).

## 3. 온라인 "문제 단계" — 새 문제로 여러 번
학습지 모드 문제지(`runGridExam`)와 연산 로드맵 세션에 **같은 회차 구조**를 쓴다.
- 로드맵 세션 카드에 `💻 화면으로 풀기` 추가 → 그 세션의 드릴을 **유형별 탭**(AD5 · SB4 · NS1)으로 열고, 탭마다 개념 패널 + ★예시(빨강) + 문항 N개 + 채점.
- 채점 뒤: `🔁 새 문제로 다시 (n회째)` — 같은 유형 새 시드. 회차 카운터와 **이 유형 최고 점수**를 카드 위에 표시(`NM_STATS.sessionsOf(thread)` 길이·최대 rate에서 읽는다 — 저장 스키마 추가 없음).
- 채점 전에도 `새 문제` 버튼은 항상 보인다(지금은 채점 후에만).
- 80% 이상이면 탭에 ✅, 60% 미만이면 "한 번 더" 안내.

## 4. 중·고등 특별 규칙
- 개념 패널: `concept` 문장 + 공식이 있으면 KaTeX 한 줄(concept 안 `=`가 든 식 조각을 그대로 표시하지 않고, 스레드 `formula` 필드가 있으면 그것 — 없으면 문장만).
- 예시 풀이: MD 스레드는 `steps`가 5개뿐이라 대부분 2-4의 2번 경로. **답이 배열**([p,q,r] 등)이면 `answerShape`에 맞춰 사람이 읽는 형태로(분수는 `\frac{p}{q}`, 근의 공식은 `x=\frac{p\pm\sqrt{q}}{r}`) — `check-answerable.js`/드릴 화면이 이미 쓰는 표시 규칙을 재사용한다.
- 배치: 분수·근호·다항식은 자동으로 "중간/긴 식"이 되어 2×8·1×8로 넉넉히 간다.

## 5. 손대지 않는 것
- 생성기·threads.js·courses.js·인쇄 코드 형식(`?ws=`)·정답지 채점 규칙·편지함 봉투의 데이터 계약.
- 학년별(교과) 학습지 단일 유형 인쇄(`renderPrint`)는 **같은 회차 렌더러를 쓰되** 옵션이 바뀌지 않는다.
