# 사람 아바타(주인공) 작화 지시서

> 수신: 캐릭터 아트 담당(GPT 등 이미지 생성) · 발신: Numbers of Magic 제작팀
> 산출물: **PNG 8장(투명 배경, 512×512, 같은 캔버스·같은 기준점)**. 아래 파일명 그대로.
> ⚠️ 성패는 둘: ① 기존 숫자·기호 캐릭터 21종과 **한 세트로 보이는가** ② 8장을 **겹쳐 놓았을 때 딱 맞는가**.

## 0. 왜 사람인가 (설계 배경 — 마을세계관-설계.md §1)

지금은 아이 자신이 숫자 캐릭터(3, 8…)다. 바꾼다: **아이는 사람**이고, 고른 숫자·기호
캐릭터가 **한 명 따라다닌다**(동행). 그래서 사람 그림은 동행 캐릭터와 **같은 키·같은
질감**이어야 하고, 앱이 색을 입힐 수 있게 **레이어로 나눠** 받는다.

## 1. 반드시 먼저 볼 것 — 기존 캐릭터

```
number_magic/assets/characters/numi-0.png  num-1.png … num-10.png  sym-plus.png … sym-infinity.png
```
GitHub: https://github.com/docssam1/lete-on/tree/main/number_magic/assets/characters

기존 화풍(이대로):
- 통통하고 둥근 **3D 젤리/풍선 질감**, 부드러운 광택 하이라이트, 은은한 그림자
- **큰 눈 두 개**(흰자 + 검은 눈동자 + 작은 반사광), 작은 미소
- 짧은 팔다리, 정면 전신 1포즈, 밝고 친근함

## 2. 사람 아바타 — 마법 견습생 아이

- **2등신**(머리 1 : 몸 1). 머리가 크고 둥글다. 나이 느낌 6~9세, 성별 중립
- 키는 숫자 캐릭터와 **같게** — 옆에 세우면 눈높이가 맞아야 한다
- 옷: 소매 있는 **견습 마법사 튜닉** 한 벌(무릎 위, 허리끈). 모자·망토는 그리지 않는다(앱이 따로 얹음)
- 손은 살짝 벌린 자연 자세, 두 발 나란히. 소품 없음
- 표정은 숫자 캐릭터와 같은 눈·입 — 사람이라고 사실적 눈으로 바꾸지 말 것

## 3. 레이어 8장 (겹치면 한 명이 된다)

전부 **같은 512×512 캔버스**에서 **같은 자리**에 그린다. 몸의 위치·크기가 8장 모두 픽셀 단위로 같아야 한다.
가장 쉬운 방법: 완성된 한 명을 먼저 그린 뒤, 부분만 남기고 나머지를 지워 저장.

| # | 파일명 | 내용 | 색 |
|---|---|---|---|
| 1 | `kid-body-light.png` | 몸 전체(얼굴·팔·다리·눈·입) + 튜닉 **없이** 흰 속옷·신발 | 피부 밝은 톤 |
| 2 | `kid-body-tan.png` | 1과 완전히 같은 그림 | 피부 중간 톤 |
| 3 | `kid-body-brown.png` | 1과 완전히 같은 그림 | 피부 짙은 톤 |
| 4 | `kid-hair-short.png` | 짧은 머리(둥근 컷) — 머리카락만 | **밝은 하늘색 단색** |
| 5 | `kid-hair-bob.png` | 단발 — 머리카락만 | 밝은 하늘색 단색 |
| 6 | `kid-hair-pony.png` | 높은 포니테일 — 머리카락만 | 밝은 하늘색 단색 |
| 7 | `kid-hair-curly.png` | 곱슬 — 머리카락만 | 밝은 하늘색 단색 |
| 8 | `kid-tunic.png` | 견습 마법사 튜닉 + 허리끈 — 옷만 | 밝은 하늘색 단색 |

- 하늘색 단색인 것(머리·옷)은 **앱이 색을 다시 입힌다**(기존 num-*.png와 같은 방식). 그러니 한 가지 색, 무늬 없음. 광택·그림자는 그 색 안에서만
- 머리카락 4종은 **정수리 위치가 같아야** 모자가 맞는다. 정수리 기준점: 캔버스 가로 중앙, 위에서 **20%** 지점
- 튜닉은 몸 위에 얹었을 때 팔·목이 자연스럽게 나오게. 소매 안쪽·목선 안쪽은 투명

## 4. 규격

| 항목 | 규격 |
|---|---|
| 형식 | PNG, **투명 배경(알파)**, 512×512, 8장 모두 같은 캔버스 |
| 구도 | 정면 전신, 중앙, 상하좌우 여백 각 6% (기존 캐릭터와 같음) |
| 금지 | 배경·바닥 그림자·테두리·글자·로고·모자·망토·소품 |
| 확인 | 8장 중 1·4·8을 포개면 한 명의 완성된 아이가 되어야 한다 |
