## 1. 쓰이는 곳 (바뀌지 않음)
수학사 네 컷 만화 101편(380여 컷)의 인물. 한 컷은 200×140 비율, 인물은 컷 높이의 약 38%(50~55px).
앱 화면 기준으로 인물이 **작게** 보이므로 **실루엣과 머리 위/손의 표식**이 여전히 가장 중요하다.
다만 이번엔 얼굴·옷 주름·손이 살아 있어야 한다(확대해서 봐도 어색하지 않게).

## 2. 공통 스타일 규격 (12종 동일 — 한 사람이 그린 한 세트)

| 항목 | 규격 |
|---|---|
| 형식 | PNG, **투명 배경(알파)**, **512×512px** 정사각형 |
| 구도 | **정면 또는 3/4 정면 전신 1포즈**, 가운데. **머리끝~발끝이 캔버스 높이의 88%**, 위 6%·아래 6% 여백, **발이 캔버스 아래 94% 선에 닿게**(코드가 이 비율을 가정한다) |
| 화풍 | **정통 교과서 위인전 일러스트** — 수채+잉크 느낌, 부드러운 명암 한 단계, 얇은 갈색/남색 윤곽선. 만화체·치비·애니 얼굴 금지 |
| 비율 | 성인 **6.5~7등신**, 아이(boy·girl) **5등신**. 머리만 크게 키우지 말 것 |
| 표정 | 차분하고 호기심 있는 자연스러운 표정(이목구비 또렷하게). 12종 표정 톤 통일 |
| 조명 | 12종 모두 **왼쪽 위 광원**, 바닥 그림자·후광·테두리·배경 일체 없음 |
| 손 | 손가락 5개 자연스럽게. 소품(지팡이·깃펜 등)은 손에 제대로 쥘 것 |
| 색 | 아래 팔레트를 **기조색**으로. 명암·피부·머리색 등은 자연스러운 톤 허용(팔레트 밖 형광색 금지) |

### 반드시 지킬 것
- **실존 인물의 실제 얼굴을 그리지 말 것.** 뉴턴·가우스·유클리드 등도 "그 시대 복장의 일반적인 인물"로만(초상권·정확성 회피).
- 종교 상징, 특정 민족 희화화, 브랜드 로고, 글자(텍스트) 삽입 금지.
- 12종이 **같은 붓·같은 선 굵기·같은 광원·같은 채도**로 보이게.
- 어린이 앱이므로 **무섭거나 자극적인 표현 금지**(부드럽고 따뜻하게).

## 4. 생성 팁 (GPT 이미지 생성용 프롬프트 뼈대)
```
Classic children's educational biography illustration, watercolor and ink, soft single-step shading,
thin warm-brown outline, realistic human proportions (7 heads tall), calm natural face.
Subject: <표의 역할·복식·핵심 표식>. Full body, standing, front three-quarter view, feet visible,
light from upper left. Plain solid white (or chroma green) background, no shadow, no ground, no text.
```
- 배경은 **단색(흰색 또는 크로마 그린)** 으로 뽑고, **배경 제거 후 투명 PNG로 저장**(가장자리 흰 테 남기지 말 것).
- 12장 중 한 장을 **기준 컷**으로 승인받은 뒤, 나머지는 그 기준 컷을 레퍼런스로 같은 화풍으로 생성하면 일관성이 높다.
- 먼저 `boy.png`·`wig.png`·`sage.png` **3장 시안**을 제출 → 제작팀(원장) 확인 → 나머지 9장 진행.

## 6. 제작팀 참고 (작화 담당은 안 읽어도 됨)
- 반영: `number_magic/scripts/comic-helpers.js`의 `charImg()`가 `assets/images/characters/<이름>.png`를 그대로 읽는다. **파일만 교체하고 `node scripts/build-comics.js`(필요 시 `node scripts/check-comics.js`)를 돌리면 101편 전체에 반영**되며 만화 소스는 수정 불필요. 현재 PNG는 256×256이고 코드는 크기 무관(비율만 가정) — 512로 교체해도 동작한다.
- 현재 인물 확대 배율 `CHAR_BOOST=1.3`(2026-10-04). 새 그림은 얼굴이 크게 보이므로 교체 후 `comics-view.html?u=A-07,B-04,M-03`으로 겹침 재확인.
- 11종(numi 제외)은 만화에서만 쓰인다. `numi.png`는 개념 노트(`app/main.js` `nm-story-numi`)와 `scripts/build-counting-art.js`(세기 그림)에서도 쓰이므로 **numi는 건드리지 않는 것을 권장**. 인쇄 만화(`app/exam.js`)는 NM_COMICS를 그대로 쓰므로 빌드 후 인쇄 경로도 한 번 열어 볼 것.
