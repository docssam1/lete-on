## 하지 않기로 한 것

| 항목 | 이유 |
|---|---|
| 도형 유닛 추가 | 연산 앱에 도형은 넣지 않는다(`과정-로드맵.md`). 읽을거리는 기사로 싣는다 |
| 수식 문자열 입력·파싱 | 답은 언제나 정수 몇 개(`MASTER-ROADMAP.md` §7) |
| 로드맵으로 과정 잠그기 | 원장 원칙 — 추천일 뿐 게이트가 아니다 |
| 교재 원문 수록 | 라이선스. 개념 설명과 단원 제목까지만 |
| 유아 N-01~N-15에 확인·도전 넣기 | 이전 목록의 오판. 유아는 `tier:'basic'`이라 `app/main.js`의 `BASIC_FLOW_KEYS`가 확인·도전·타이머를 **정책으로** 건너뛴다(GPT 검수 지적, 코드로 확인) |
| 미니게임 챕터 G0·G1 채우기 | 이전 목록의 오판. 두 챕터는 유닛 대신 `game:'make10'`·`'make10_3'`으로 **이미 게임**이다 |
