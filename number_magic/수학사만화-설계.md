# 수학사 네 컷 만화 — 저작 설계서

> 대상: 만화 파트를 그리는 구현 에이전트. 이 문서와 예시 파트 2개를 읽은 뒤 작업할 것.
> 설계·검토: Fable / 구현: 에이전트. 최종 그림은 검토자가 전수 육안 확인한다.

## 무엇을 만드나

`story.history`(수학사 한 줄)를 가진 유닛마다 **네 컷 만화 소스 파트** 1개.

- 위치: `number_magic/data/story-comics-src/<유닛ID>.js` (유닛당 1파일 — 절대 다른 파일 건드리지 말 것)
- 형식:
```js
/* M-08 — 유한소수 판별 */
'use strict';
module.exports = function(H){
  const {C,svg,stick,arrow,paper,bubble,txt,ground}=H;   // 필요한 것만
  return { panels:[
    { art: svg( /* …도형… */ ),
      text:{ ko:'…', en:'…', zh:'…' } },
    /* ×4 — 정확히 4컷 */
  ]};
};
```
- 파트는 `node scripts/check-comics.js --part data/story-comics-src/<ID>.js` 가 **통과해야 완성**.
  통과 못 하면 고쳐서 다시 돌린다. 검사기 출력의 경고(warn)도 읽고 고칠 수 있으면 고친다.

## 이야기 규칙 (캡션)

1. **원천은 그 유닛의 `story.history`뿐이다** (`data/units/<ID>.js`의 `discover.story.history`).
   거기 없는 연도·인명·일화를 **지어내지 말 것**. history가 "전해지는 이야기"라고 조심하면
   만화도 그 조심을 유지한다. hook(`story.hook`)과 유닛 주제(title·subtitle)는 참고해도 좋다.
2. **네 박자**: ①상황(옛날엔/문제가 있었다) → ②전개 → ③전환(발견·반전) → ④펀치라인(이 유닛의
   수학과 연결). 4컷을 읽고 나면 history 한 줄을 다 알게 되어야 한다.
3. 캡션은 **3언어**({ko,en,zh}) 전부. ko 기준 한 컷 40~90자. en/zh는 직역이 아니라
   그 언어로 자연스러운 다시쓰기(뜻은 동일). en에 한글 0자, zh에 한글 0자.
4. 어린이(N·A·B·C 유닛)는 존댓말 구어("~했어요"), 중·고(M·H)는 같은 톤이되 개념어 정확히.

## 그림 규칙 (art)

1. **전부 원본 도형** — 어떤 그림도 베끼거나 트레이스하지 않는다. viewBox는 `0 0 200 140` 고정
   (svg() 헬퍼가 붙여 준다 — 안에 들어갈 내용만 쓴다).
2. **그림 속 글자는 이야기의 대상만**: 수식·숫자·기호(−, dy/dx, √, ∫, %, 1489 …)와 이야기가
   다루는 낱말 자체(minus, radix …). 설명 문장은 절대 그림에 넣지 않는다(캡션이 할 일).
   3개 언어가 **그림 한 벌을 공유**하기 때문이다.
3. **색은 헬퍼의 `C` 팔레트만** 쓴다(C.ink·C.blue·C.gold·C.red·C.ok·C.paper·C.brown …).
   임의 hex를 새로 만들지 말 것 — 검사기가 잡는다.
4. 한 컷에 주인공 도형 1~2개 + 보조 요소 몇 개. **10~15개 요소를 넘기지 말 것**(200×140에서
   더 넣으면 뭉개진다). 주 선은 stroke-width 2 이상.
5. 헬퍼(stick·sheep·pouch·arrow·paper·bubble·txt·ground)를 우선 쓰고, 없는 것만
   기본 도형(rect·circle·ellipse·line·path·polygon·polyline)으로 직접 그린다.
   path를 쓸 땐 점 4~6개짜리 단순한 곡선까지만 — 복잡한 패스는 그리지 말 것.
6. 이모지는 표정·사물 강조에 한해 컷당 1개까지 허용(👑 ! ✨ 등은 txt()로).
7. 네 컷이 **연결돼 보여야 한다**: 같은 인물·사물은 같은 색과 같은 헬퍼로 반복 등장.

## 절대 금지

- 실존 위인의 얼굴 묘사 시도(막대 사람 stick()으로만 — 이름 표기도 그림엔 넣지 않는다. 캡션에서만)
- history에 없는 역사적 단정 · 다른 파일 수정 · viewBox 변경 · 외부 이미지(href/image 태그)

## 작업 순서 (유닛 하나마다)

1. `data/units/<ID>.js`에서 `story.history`(3언어)와 hook, title, subtitle을 읽는다.
2. 4박자 대본을 짠 뒤 파트 파일을 쓴다.
3. 검사기를 돌려 통과시킨다. 끝나면 다음 유닛.

## 예시

`data/story-comics-src/N-01.js`(유아: 인물 중심)와 `data/story-comics-src/A-10.js`(기호 변천:
타이포 중심)를 읽고 구도·밀도·캡션 호흡을 그대로 따를 것.

## 캐릭터 규칙 (2026-08-31 추가 — 원장 지시)

- **numi(x,y,s)** = 앱 마스코트 누미(고깔 모자 마법사)의 만화용 도형 버전.
  만화 속 **"궁금해하는 아이·관찰자·안내자"** 역할은 막대 사람 대신 누미를 쓴다.
  (컷에 이름 없는 질문자·구경꾼이 있거나, 물음표만 떠 있는 질문 장면이면 누미가 그 자리)
- **역사 인물·이야기 배역은 그대로 stick()**: 가우스·뉴턴·레코드처럼 캡션에 이름이 나오는
  실존 인물, 그리고 양치기·왕·현자·필경사·상인 같은 이야기 속 배역에는 누미를 쓰지 않는다
  — 누미가 실존 인물 행세를 하면 안 된다.
- 누미는 컷당 1명, 억지로 모든 만화에 넣지 않는다(어울리는 자리가 없으면 생략).
- sheep()은 뭉게 양털 버전(2026-08-31)이 기준. flip은 scale(-1,1)만 — translate 덧붙이면
  화면 밖으로 날아간다(실측으로 확인된 버그였음).

## 캐릭터 로스터 (2026-08-31 확장 — 원장 지시: "막대 안 돼, 실존 인물엔 맞는 캐릭터")

**stick() 막대 사람은 사용 금지**(호환용으로만 남아 있음 — 검사기가 경고한다).
인물은 전부 아래 치비 프리셋에서 고른다. 전부 원본 도형이며, 특정인의 실제 얼굴이 아니라
**시대·역할의 복장 기호**(왕관·터번·가발·토가…)로 나타낸다.

| 프리셋 | 쓰는 자리 |
|---|---|
| `king(x,y,s)` | 왕·황제 배역 (체스판 왕, 프톨레마이오스 왕…) |
| `sage(x,y,s)` | 현자·스승·연장자 배역 (수염+지팡이) |
| `greek(x,y,s)` | 고대 그리스 수학자 — 유클리드·피타고라스·아르키메데스·히파소스·탈레스 |
| `scholar(x,y,s)` | 이슬람·페르시아·인도 학자 — 알콰리즈미·브라마굽타·아부 알와파·알비루니 |
| `wig(x,y,s)` | 15~19세기 유럽 수학자 — 뉴턴·라이프니츠·데카르트·오일러·가우스(성인)·네이피어·월리스·비에트·레코드·오트레드·라안·데데킨트·바이어슈트라스·페르마·골드바흐 |
| `boy(x,y,s)` / `girl(x,y,s)` | 아이·학생 (어린 가우스는 boy) |
| `shepherd(x,y,s)` | 양치기 배역 |
| `scribe(x,y,s)` | 필경사·기록자 배역 (깃펜) |
| `merchant(x,y,s)` | 상인·장부 이야기 배역 (앞치마+동전) |
| `astronomer(x,y,s)` | 천문학자·항해사 배역 (초승달 고깔) |
| `numi(x,y,s)` | 앱 마스코트 — 이름 없는 질문자·관찰자·안내자 전용(실존 인물 행세 금지) |

- 키는 전부 약 34~40px(s=1), stick과 같은 자리에서 y만 살짝 조정하면 된다.
- 같은 만화에서 같은 인물은 같은 프리셋으로 반복 등장시켜 연속성을 지킨다.
- 중국·유럽 등 위 표에 없는 지역·시대의 학자는 가장 가까운 역할 프리셋을 쓰되
  로브 색으로 구분하려 하지 말고(파라미터 없음) 그대로 쓴다.

### GPT 캐릭터 아트 발주 (2026-08-31)

캐릭터 12종의 **PNG 아트 제작을 외부(GPT)에 발주**했다. 작업지시서와 현재 도형 시안은
Google Drive 폴더 `NumbersOfMagic-캐릭터작화`에 있고, 저장소에도 `캐릭터-작화지시서.md`로
같은 내용을 둔다.

**받은 PNG를 반영하는 방법**: 만화 소스는 캐릭터를 `king(x,y,s)` 같은 함수 호출로만
부르므로, `scripts/comic-helpers.js`의 캐릭터 함수 12개를 `<image href="...">`로 바꾸고
다시 빌드하면 **95편 380컷에 한 번에 반영**된다. 소스 파트는 한 줄도 고칠 필요 없다.
(주의: 검사기가 `href=`를 외부 참조로 막고 있으니, PNG를 data URI로 인라인하거나
검사기의 해당 규칙을 "assets/ 하위 경로는 허용"으로 완화해야 한다.)
