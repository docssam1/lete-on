## 1. 반드시 먼저 볼 것 — 지금 마을

```
number_magic/assets/map.jpg  (1024×687)
```
GitHub: https://github.com/docssam1/lete-on/blob/main/number_magic/assets/map.jpg

이 그림이 **화풍의 기준**입니다. 새 그림은 이 마을을 가운데에 **그대로 다시 그려 넣고**
(건물 종류·배치·색 유지), 바깥을 넓힙니다. 지금 마을에 있는 것:
- 왼쪽 위: 펼친 책 모양 지붕의 **도서관**(NUMBERS LIBRARY)
- 가운데 위: 종탑 있는 작은 집 + 필름 릴 얹은 **타운홀**(TOWN HALL OF MAGIC)
- 그 오른쪽: 필름 릴 얹은 **극장**(Magic Theater)
- 오른쪽 위: 둥근 지붕 **정자**(가제보)와 정원, 강
- 오른쪽 아래: 천막 **시장**, 작은 분수, 붉은 지붕 집
- 왼쪽 아래: 알록달록한 **작은 집들**(노랑·주황·분홍·보라)
- 가운데: 큰 **분수 광장**, 벤치, 잔디, 돌길, 시냇물과 다리들

## 2. 원하는 분위기 — "머무는 마을"

넥슨 **마비노기(에린의 티르 코네일)** 를 떠올려 주세요. 따라할 대상은 그래픽이
아니라 **분위기**입니다:
- 따뜻하고 부드러운 **오후 햇살**, 긴 그림자 없음(아이용이라 밝게)
- 완만한 **초록 언덕**, 멀리 낮은 산, 양 몇 마리, 풍차 하나, 밭
- 마을이 **살아 있는 느낌** — 빨래줄, 굴뚝 연기, 우물, 나무 울타리
- 마을 밖으로 **흙길이 이어지고**, 길 끝이 화면 가장자리에서 살짝 넘어감

**단, 게임처럼 보이면 안 됩니다.** 무기·몬스터·던전 입구·HUD 같은 것 금지.
그림책의 한 장면처럼.

## 3. 새로 넓힐 네 방향 (가운데 마을 밖)

지도는 **약간 위에서 내려다보는 시점**(지금 마을과 같은 각도)을 유지합니다.

| 방향 | 무엇이 있나 | 역할(전부 Numbers of Magic 안의 구역) |
|---|---|---|
| **서쪽(왼쪽)** | 알록달록 작고 둥근 집들이 모인 **아기 마을** — 낮은 울타리, 그네, 모래밭, 큰 숫자 블록 장난감 | 수의 나라(6~7세 유아 구역) |
| **동쪽(오른쪽)** | 강을 건너는 **긴 돌다리**, 건너편에 조금 더 격식 있는 **학교 건물**(붉은 벽돌, 시계탑) | 중등·고등 수학으로 가는 길 |
| **북쪽(위)** | 언덕 위 **탑** 하나 — 무섭지 않게, 등대처럼 둥글고 창이 많은 | 경시(어려운 문제)의 탑 |
| **남쪽(아래)** | 큰 **호숫가** — 나무 선착장, 배 한 척, 등불, 피크닉 자리 | 쉬는 곳(극장·편지함이 여기로 옮겨올 수 있음) |

각 방향은 화면 가장자리에서 **한 화면 안**에 다 보이게 — 넓은 빈 땅으로 채우지
마세요. 마을과 관문 사이는 길·밭·나무·언덕으로 **촘촘히**.

## 4. 규격 (어기면 못 씁니다)

| 항목 | 규격 |
|---|---|
| 크기 | **2560×1600**(16:10). 가운데 마을이 전체의 약 40% 폭을 차지 |
| **글자 금지** | 지도 안에 **어떤 글자·간판 문구도 넣지 마세요**(NUMBERS OF MAGIC 배너 포함). 이름표는 앱이 3개 언어로 얹습니다. 지금 map.jpg에 있는 영어 간판은 **빼고** 그려 주세요 |
| 테두리 금지 | 지금 map.jpg의 크림색 액자 테두리는 빼고, 가장자리까지 그림으로 |
| 캐릭터 금지 | 숫자·기호 캐릭터, 사람은 넣지 마세요(앱이 따로 얹습니다). 양·새 같은 동물은 OK |
| 색 | 지금 마을과 같은 채도·밝기. 바깥으로 갈수록 살짝 부드럽게 |
| 시점 | 지금 마을과 같은 각도. 관문 4곳이 화면 안에서 **아래쪽으로 갈수록 크게** 보이는 자연스러운 원근 |
