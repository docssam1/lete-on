## 2. 원하는 분위기 — "머무는 마을", 그리고 **3D 렌더 느낌**

넥슨 **마비노기(에린의 티르 코네일)** 를 떠올려 주세요. 따라할 대상은 그래픽이
아니라 **분위기**입니다:
- 따뜻하고 부드러운 **오후 햇살**, 아이용이라 밝게
- 완만한 **초록 언덕**, 멀리 낮은 산, 양 몇 마리, 풍차 하나, 밭
- 마을이 **살아 있는 느낌** — 빨래줄, 굴뚝 연기, 우물, 나무 울타리
- 마을 밖으로 **흙길이 이어지고**, 길 끝이 화면 가장자리에서 살짝 넘어감

### 시점과 입체감 (중요 — 지금 map.jpg와 달라지는 부분)
지금 마을은 위에서 내려다본 평면 지도에 가깝습니다. 새 그림은 **3D 게임 화면을
캡처한 것처럼** 그려 주세요:
- 카메라를 **낮춰서**(지면에서 약 30~35° 내려다보는 3/4 시점) 건물의 **정면과 옆면이
  같이 보이고**, 지붕 아래 벽이 드러나게
- 건물·나무·언덕에 **부피감** — 부드러운 명암, 바닥에 닿는 연한 그림자
- **원근** — 앞(아래)은 크고 또렷, 뒤(위)로 갈수록 작고 옅게(공기 원근, 먼 산은
  푸르스름하게 흐림)
- 질감은 **3D 카툰 렌더**(마비노기·오버워치풍의 매끈한 셀 셰이딩). 사실적 3D 사진풍 금지,
  거친 수채화도 금지 — 첨부 캐릭터들(3D 젤리풍)과 한 세계로 보여야 합니다
- 단, **글자·UI·미니맵·HUD** 같은 게임 화면 요소는 절대 넣지 마세요 — "게임 화면
  같은 시점의 그림책 삽화"입니다

### 지형의 높낮이 (중요 — 평평한 땅 금지)
땅이 한 장의 평면이면 안 됩니다. **굴곡이 있는 지형**으로 그려 주세요:
- 마을은 **완만한 언덕 사이 분지**에 앉아 있고, 사방으로 갈수록 땅이 **오르내립니다**
  (북쪽 탑은 마을보다 눈에 띄게 높은 언덕 위, 남쪽 호수는 마을보다 낮은 곳)
- 높이가 바뀌는 곳마다 **돌계단·석축·낮은 절벽**이 있고, 길은 계단으로 층을 오르내립니다
  — 최소 3곳: ①마을 광장에서 북쪽 탑으로 올라가는 긴 돌계단 ②마을에서 남쪽 호숫가로
  내려가는 넓은 계단 ③서쪽 아기 마을로 가는 낮은 계단(2~3단, 짧게)
- 마을 안에도 **한두 단의 단차** — 도서관·타운홀 쪽이 광장보다 살짝 높은 테라스처럼,
  가장자리는 돌로 쌓은 낮은 벽과 작은 계단
- 언덕은 **부드럽게 굴러가는 능선**으로, 단면이 드러나는 곳은 풀 아래 흙·바위층이 보이게
- 계단·석축은 마을 돌길과 같은 회색 돌, **난간 없이** 낮고 넓게(아이용, 위험해 보이지 않게)

**단, 게임처럼 보이면 안 됩니다.** 무기·몬스터·던전 입구·HUD 같은 것 금지.

## 3. 새로 넓힐 네 방향 (가운데 마을 밖)

지도는 **약간 위에서 내려다보는 시점**(지금 마을과 같은 각도)을 유지합니다.

| 방향 | 무엇이 있나 | 역할(전부 Numbers of Magic 안의 구역) |
|---|---|---|
| **서쪽(왼쪽)** | 알록달록 작고 둥근 집들이 모인 **아기 마을** — 낮은 울타리, 그네, 모래밭, 큰 숫자 블록 장난감 | 수의 나라(6~7세 유아 구역) |
| **동쪽(오른쪽)** | 강을 건너는 **긴 돌다리**, 건너편에 조금 더 격식 있는 **학교 건물**(붉은 벽돌, 시계탑) | 중등·고등 수학으로 가는 길 |
| **북쪽(위)** | 언덕 위 **탑** 하나 — 무섭지 않게, 등대처럼 둥글고 창이 많은 | 경시(어려운 문제)의 탑 |
| **남쪽(아래)** | 큰 **호숫가** — 나무 선착장, 배 한 척, 등불, 피크닉 자리 | 쉬는 곳(극장·편지함이 여기로 옮겨올 수 있음) |

각 방향은 화면 가장자리에서 **한 화면 안**에 다 보이게 — 넓은 빈 땅으로 채우지
마세요. 마을과 관문 사이는 길·밭·나무·언덕으로 **촘촘히**.

## 4. 규격 (어기면 못 씁니다)

| 항목 | 규격 |
|---|---|
| 크기 | **1536×1024**(3:2). 가운데 마을이 전체의 약 40% 폭을 차지. 더 큰 크기는 제작팀이 확대함 |
| **글자 금지** | 지도 안에 **어떤 글자·간판 문구도 넣지 마세요**(NUMBERS OF MAGIC 배너 포함). 이름표는 앱이 3개 언어로 얹습니다. 지금 map.jpg에 있는 영어 간판은 **빼고** 그려 주세요 |
| 테두리 금지 | 지금 map.jpg의 크림색 액자 테두리는 빼고, 가장자리까지 그림으로 |
| **땅 모양 금지** | 땅이 **동그란 섬·네모난 판·떠 있는 조각**처럼 잘려 보이면 안 됩니다. 지형은 화면 네 변 끝까지 **끊기지 않고 이어지는 대륙의 일부**여야 합니다(길·언덕·강이 화면 밖으로 계속 나가는 느낌) |
| 캐릭터 금지 | 숫자·기호 캐릭터, 사람은 넣지 마세요(앱이 따로 얹습니다). 양·새 같은 동물은 OK |
| 색 | 지금 마을과 같은 채도·밝기. 바깥으로 갈수록 살짝 부드럽게 |
| 시점 | §2의 3/4 시점(30~35°). 아래쪽일수록 크고 또렷, 위쪽일수록 작고 옅게 |
| 지형 | 평평한 땅 금지. 언덕·분지·단차가 있고 **돌계단 최소 3곳**(§2 지형의 높낮이) |
