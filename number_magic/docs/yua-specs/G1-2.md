### 3-1. 2쪽·8쪽·13쪽① 점 잇기 (B)
- **현재**: `nl2_seq` mode `dots`(nl.js:294~307) + `dotToDot`. 1→n 정순, 도형 16종(점 3~11), lab 3문항. 교재 차이: ① **큰 수부터(9→1)** 없음 ② 점 수가 9 를 넘는 도형 있음(별 10·나무 11) ③ **일부 선이 미리 그려진** 도입 없음 ④ 교재 그림(배·자동차·햄스터·모자·토끼·다람쥐)이 없음.
- **결정 B** — `dots` 확장:
  - `order:'up'|'down'`. problem 에 `order` 와 `labels`(점마다 표시 숫자) 추가. `down` 이면 `labels[i]=n-i`, **눌러야 하는 순서는 라벨이 큰 것부터**. 위젯 `renderDotToDot`는 `i===next` 비교를 `labels` 기준으로(내부 `seqIdx` 배열로 눌러야 할 점 인덱스를 만든다). 완성 시 `onAnswer(problem.answer)`(= 점 개수) 그대로.
  - `max:9`: 도형 풀에서 점 ≤9 만(`pts.length<=max`). practice 는 점 3~6.
  - `pre:k`: 처음 k 개 선분을 미리 그려 둔다(교재 2쪽처럼 일부 이미 그려진 형태, practice 에서 k=2).
  - 그림 추가(점 ≤9, 원본 실루엣; 구현자가 좌표 설계): **자동차·햄스터·토끼·다람쥐**. 규칙: 닫힌 도형, 순서대로 이으면 선이 교차하지 않을 것, 이웃 점 간격 ≥ 12(뷰박스 0~100), 점마다 번호 글자가 겹치지 않게. (배·모자는 기존 `배`(5)·`왕관 모자`(3) 사용.)
  - 힌트 문구 3언어화: "1️⃣ 부터 차례대로!"→`order` 별 문구("작은 수부터"/"큰 수부터")를 `S.lang`으로, "🎉 완성!"도 3언어.

- **인쇄**: `nlDotsSvg`(exam.js:3070)가 `i+1` 을 찍으므로 `p.labels`가 있으면 그것을, `pre` 개 선분을 미리 그린다. 답칸 "점은 모두 몇 개?"(nlPrintAsk)는 기존 그대로.

### 3-2. 3쪽·7쪽①·13쪽② 화살표 길 채우기 — `pathFill` (C, 이 호의 핵심)
- **현재 없음.** `seqFill`(widgets.js:1071)은 **한 줄·빈칸 1개·3지선다**(보기는 위젯이 난수로)라, 교재의 굽이진 길(원 6개 중 여러 칸이 빈)·사슬 4개·빈칸 2~4개를 못 한다.
- **결정 C** — 신규 위젯 `pathFill`, mode `path`. 이 위젯 하나가 G1-2 의 3·4(②)·5·7(①③④⑥)·10·11(②③)·13(②④⑤⑥)쪽을 전부 맡는다.
- **problem**:
  ```
  { widget:'pathFill', answerType:'number', answer:B,          // B = 빈칸 수(대표 숫자)
    nodes:[{x,y,v:number, show:bool, shape:'circle'|'box'}],   // x,y 0~100 뷰박스, v=정답 값
    edges:[{a,b,draw:'arrow'|'line', style:'single'|'double'|'solid'|'dashed'|'none'}],
    bank:[..숫자(빈칸 값 + 방해 1~2)], layout:'row'|'zig'|'snake'|'ring'|'grid',
    legend?:{ko,en,zh}, rule:'step'|'pattern' }
  ```
  - 각 노드의 정답 `v` 는 생성기가 계산해 둔다(위젯은 풀이 불필요). `show:false` 가 빈칸. 빈칸은 한 줄(연결 성분)당 **최소 하나의 보이는 노드**가 있게 하고 `rule:'step'`일 때는 이웃 노드와의 차가 화살표/선으로 추론되게 한다.
  - `rule:'step'`: 간선 `a→b` 의 변화량 `v[b]-v[a]` ∈ {+1, −1, +2, −2}. `style` 이 규칙 기호(단 화살표=1씩, 이중 화살표=2씩 / 실선=1큰 수, 점선=2큰 수). 방향은 화살표가 가리키는 쪽이 **뒤**(값이 커짐 = `+`; "큰 수부터" 문항은 값이 줄어드는 `−`로 같은 간선 방향). `draw:'line'`(화살표 없음) 사슬은 문항 지시문("작은 수부터/큰 수부터")이 방향을 정한다.
  - `rule:'pattern'`(11쪽 반복 격자): `v` 가 `pattern[i%len]`(예 1·2·3·4, 3·2·1·3)이고 `legend`에 "1, 2, 3, 4가 차례대로 반복돼요"를 싣는다. **빈칸 앞에 패턴이 한 바퀴 이상 보이게** 한다.
- **위젯 동작**: 길 위의 원/네모를 SVG 로 그린다(화살표·점선·두 줄 화살표 포함). 빈칸은 점선 원. 아래에 숫자 타일(`bank`, 보기 순서는 생성기가 섞어 둠). **포커스는 길 순서대로 첫 빈칸 → 다음**으로 자동 이동하고, 다른 빈칸을 직접 눌러 옮길 수도 있다. 타일을 누르면 맞으면 그 칸에 들어가고(`found` 스타일), **틀리면 칸을 비운 채 shake**(오답 기록 안 함, 다시 선택). 모든 빈칸이 채워지면 600ms 뒤 `onAnswer(B)`. (`matchLine`과 같은 "틀린 것은 놓이지 않는" 방식이라 유아에게 좌절이 적다.)
- **레이아웃 템플릿**(nl.js 상수 `PF_LAYOUTS`, `PATH_SHAPES`(nl.js:733)와 같은 방식으로 뷰박스 좌표만 정의):
  - `row`: 가로 한 줄(원 4~6개, 사슬 4개 = 3쪽 하단/7쪽①).
  - `zig`: 위아래로 굽이진 길(3쪽 첫 문제, 4쪽 V자·지그재그).
  - `snake`: 직각으로 꺾인 길(3쪽 둘째 문제, 네모).
  - `ring`: 3~6개 노드가 원/타원 호를 따라 도는 길(5·10쪽 화살표 규칙; 호 모양 화살표).
  - `grid`: 칸이 붙어 이어진 꺾인 길(11쪽·13쪽⑥). 노드는 네모 칸, 간선은 칸 경계라 그리지 않는다(`style:'none'`).
- **정답 판정**: 칸마다 `tile===node.v`. 같은 값이 여러 칸에 있으면 `bank` 에서 개수만큼 타일을 둔다(중복 허용).
- **난이도/범위**: 값은 1~9. practice: row·zig, 빈칸 1~2, 방해 타일 0~1. main: ring·snake·grid, 빈칸 2~4, 방해 1~2. "큰 수부터" 비율 40%. 규칙 간선(단/이중)은 main 에서만 섞는다(practice 는 단 화살표 하나만).
- **3언어**: ko "작은 수부터 차례로 세어 빈 칸을 채워요" / en "Count up in order and fill the blanks" / zh "从小到大按顺序数，填空"; 큰 수부터: ko "큰 수부터 거꾸로 세어…" / en "Count down from the big number…" / zh "从大到小倒着数…". 규칙 범례 예: ko "→ 는 1씩, ⇒ 는 2씩 뛰어 세어요" / en "→ counts by 1, ⇒ counts by 2" / zh "→ 每次数1个，⇒ 每次数2个".
- **인쇄**: `nlVisualHtml` 에 `pathFill`: 같은 노드·간선을 SVG 로(빈칸은 점선, 굵은 화살표 머리·이중 화살표/점선 표기는 흑백에서도 구분되게 선 굵기·이중 선으로) + 하단에 규칙 범례. 답칸은 빈칸 자체(손으로 씀). `nlAnswerLabel`: `pathFill` → 빈칸 정답을 길 순서로 `4·5·6`. 
- **인쇄 치환**: "숫자 타일을 눌러 채워요" → "빈 칸에 알맞은 수를 써요".

### 3-3. 4쪽① 2씩 뛰어 센 수에 색칠 (C) · 7쪽②③·13쪽③ 가까운 수 표시 — `numPick`
- **현재 없음**. 칸 칠하기(`gridPaint` count)는 "개수만" 보고 어느 칸인지 보지 않는다.
- **결정 C** — 신규 위젯 `numPick`: 숫자 칸(타일) 여러 개 중 조건에 맞는 것을 **표시**한다. G1-3(5쪽 □ 범위, 11쪽 큰/작은 수)와 공용.
  ```
  { widget:'numPick', answerType:'number', answer:K,   // K = 맞는 표시 총수
    tiles:[v..]  // 중복 없는 수(표시는 칸 인덱스로 판정)
    marks:[{sym:'color'|'○'|'△'|'×', set:[tile 인덱스..]}],  // 표시 종류와 정답 집합
    form?:'row'|'circles' }
  ```
  화면: 위에 표시 도구(1~2개, 예 ○·×) 선택 칸, 아래 타일 줄. 타일을 누르면 선택한 표시가 붙는다(다시 누르면 지움). ✔ 로 제출: 모든 표시 종류의 집합이 정확히 같으면 `onAnswer(K)`, 아니면 shake + `onAnswer(-1)`.
- **이 호의 mode**:
  - `skipPaint`(4쪽①): 1~9 타일 한 줄. 시작 수 `s∈{1,2}`, 규칙 "s 에서 2씩 뛰어 센 수에 색칠". 1 이면 {1,3,5,7,9}, 2 이면 {2,4,6,8}. `marks:[{sym:'color',set}]`. 교재의 예시 한 개 칠한 상태(`pre`)를 practice 에서 준다.
  - `nearest`가 아닌 **수 표시형 가까운 수**(7쪽②, 13쪽③): 기준 수 b, 후보 4~5개 → "가장 가까운 수 ○, 가장 먼 수 ×". 거리가 **유일**(동점 없음)해야 한다: 후보를 `|x-b|` 가 모두 서로 다른 값이 되게 뽑는다. practice 는 ○ 하나만.
- **인쇄**: 타일 줄(네모 칸) + 규칙 문장, 정답지는 표시한 수 `(○ 5, × 9)` 식 문자열.
- **그림**: 없음(타일은 CSS).

### 3-4. 5쪽·10쪽·13쪽⑤ 화살표 규칙 (C)
- `pathFill` `layout:'ring'`, `rule:'step'` 로 처리(3-2). 5쪽: 단 화살표 1씩 / 이중 화살표 2씩, 노드 3~5개. 10쪽: **실선 = 1큰 수, 점선 = 2큰 수**(표기만 다름, 데이터는 `style:'solid'|'dashed'`), 노드 4~6개. 교재처럼 일부 화살표는 값이 이미 알려진 쪽을 향하게(빈 칸의 앞 값은 뒤 값에서 거꾸로 추론) 만든다.
- 범례를 문항 위에 반드시 표시(위젯 상단 `legend`).

### 3-5. 6쪽 가까운 수 — 물건 세고 후보에서 고르기 (B)
- **현재**: `tapCount`(widgets.js:827)는 세어서 **그 수 자체**를 3지선다로 고른다. 후보를 문항이 정하지 못하고 위젯이 `answer±1,±2` 로 만든다(`:873`). `nl7_relation` oneStep 은 "1 큰/작은 수"만.
- **교재 확인(이미지)**: 사물 하나의 장면(사과 5·연필 7 등)과 오른쪽에 세로로 후보 4개. 후보에는 **세어 나온 수가 없을 수도** 있다(예 연필 → 3·5·6·9) → 정답은 `|개수 − 후보|`가 최소인 수.
- **결정 B** — `tapCount` 확장, mode `nearest`:
  ```
  { widget:'tapCount', answerType:'number', answer:x, ask:'nearest',
    items:[…기존…], choices:[후보 4개], count:c }
  ```
  `choices` 를 생성기가 준다(`tapCount`는 `problem.choices`가 있으면 자동 후보 대신 그대로 사용 — 위젯 한 줄 변경). 후보는 서로 달라야 하고 거리가 **유일한 최솟값**(동점 금지). practice: 후보에 개수 자체가 들어가는 쉬운 경우 50%, main: 개수가 후보에 없는 경우 100%.
- **범위**: 개수 3~9, 후보 1~9. 3~4지선다 → 위젯의 3개 고정 보기 한도(`picks.length<3`)를 `choices.length` 로.
- **3언어**: ko "개수를 세어 보고, 그 수에 가장 가까운 수를 골라요" / en "Count them, then pick the number closest to the amount" / zh "数一数，选出最接近这个数量的数".
- **인쇄**: 기존 `nlSceneHtml` + 후보 숫자 4개 ○ 표시(`① 3 ② 5 ③ 6 ④ 9`), 정답지는 후보 숫자. `nlAnswerLabel` 에 `ask:'nearest'` 추가(후보 숫자 그대로 이므로 `null`이어도 됨).
- **그림(신규 소품)**: `pencil`(연필), `eraser`(지우개), `paper-clip`(클립), `pear`(배), `marble`(구슬). 사과는 기존.

### 3-6. 9쪽 가까운 수 — 수직선에 놓고 순서 쓰기 (C)
- **현재 없음**(`numline` 위젯(widgets.js:1979)은 덧셈 점프용 별개).
- **결정 C** — 신규 위젯 `orderTiles`(G1-3 4쪽 정렬과 공용), mode `nearOrder`:
  ```
  { widget:'orderTiles', answerType:'number', answer:N, otype:'near',
    base:b, tiles:[..N개 중복 없는 수], line:{min:0,max:9} }
  ```
  - `tiles` 의 기준 수까지 거리가 **모두 달라야** 한다(교재 예 기준 2 → 3·5·6·7·9: 거리 1·3·4·5·7).
  - 화면: 0~9 수직선(기준 수 b 표시), 말풍선 속 타일 N 개(섞여 있음), 아래 순서 칸 N 개. 타일을 **가까운 순서대로** 눌러 채운다. 맞는 타일은 칸에 들어가며 수직선 위에 점이 찍히고 기준에서 그 점까지 점선 호가 그려진다(교재의 호 모양 그림). 틀린 타일은 shake, 칸에 안 들어감. 다 채우면 `onAnswer(N)`.
  - 교재의 두 단계(수직선에 표시 → 순서 쓰기)는 **한 동작으로 합친다**(D): 타일을 누르면 자동으로 수직선에 놓이며 그 과정이 곧 "수직선에 표시". 아이가 점을 직접 찍게 하는 터치 UI 는 만들지 않는다.
- **범위**: practice N=3, 기준 수 2~8, 수 1~9. main N=4~5. 기준 양쪽에 수가 오도록 최소 한 개는 반대편에 둔다(양방향 거리 비교 훈련).
- **3언어**: ko "기준 수 5와 가까운 수부터 차례로 눌러요" / en "Tap from the number closest to 5 to the farthest" / zh "从离5最近的数开始依次点".
- **인쇄**: 수직선(눈금 0~9, 기준 상자) + 원 안 수 + 빈 순서 칸. 정답지는 `3-5-6-7-9`. `nlAnswerLabel` 에 `orderTiles` → 정답 순서열.

### 3-7. 11쪽 규칙 찾기 (B + C)
- ① **B** 반복 수열(9876 9876 ____ 9876 등): `nl2_seq` mode `repeat` 신설(NL4 레벨 5). `seqFill` 로 처리하되 빈칸 한 칸만 묻는다. 수열 길이 8~9(위젯 칩 폭 확인 필요), 패턴은 `[1,2,3,4]`·`[9,8,7,6]`·`[1,2,3]`·`[3,2,1]`·`[3,2,1,3]` 중. **`seqFill` 의 보기 생성(`answer±step`)은 반복 패턴에 부적합**하므로 `problem.choices`(패턴 안의 다른 수 2개 + 정답)를 생성기가 줘서 위젯이 그대로 쓰게 한다(widgets.js:1094 한 줄 변경). `max:9`.
- ③ **B** 교차 수열(1 9 2 9 3 9 4 9 ??): 같은 `repeat` mode 의 `kind:'inter'`. 두 줄이 섞여 홀수째 1→2→3→4, 짝수째 9. 빈칸 1개 문항으로(교재는 4칸이지만 위젯 한 칸).
- ② **C** 격자 경로(꺾인 칸 길 123 반복류): `pathFill` `layout:'grid'`, `rule:'pattern'`(3-2).
- **인쇄**: `nlSeqStripHtml` 은 칸이 많으면 줄바꿈이 필요(길이 9칸 → 2줄); 반복 패턴은 칸 폭을 줄여 한 줄 유지.

### 3-8. 12쪽 핀볼게임 (C+D)
- **현재 없음**. 교재: 1에서 9 까지 상하좌우로 이어지는 칸을 지나며(●칸 통과 불가, 한 번 지난 칸 재통과 불가) 번호를 채우는 길 찾기. 일부 숫자는 미리 적혀 있다(하나 이상의 해가 가능).
- **결정 C(+D)** — 신규 위젯 `pinball`, mode `pinball`:
  ```
  { widget:'pinball', answerType:'number', answer:L,    // L = 마지막 수(5~9)
    cells:[[r,c]..], blocks:[[r,c]..], given:{ "r,c": n }, start:[r,c], L }
  ```
  - 칸 모양은 십자·다이아몬드 등 5~7칸 폭(교재)이지만 5~7세용으로 **practice 3×3~4×4, L=4~5 / main 4×4~5×5, L=6~9** 로 줄인다(D).
  - 생성: 자기회피 경로 `1→…→L` 를 먼저 만들고(해), 경로 밖 칸 중 일부를 `●`로 막고, 숫자 일부(1, L, 중간 몇 개)를 `given` 으로 공개한다. 이후 DFS 로 `given`·`blocks`를 만족하는 경로 수를 세어 **≥1**임을 보증(유일할 필요 없음; 교재도 설계형).
  - 화면: 격자 칸, ●는 막힌 칸, 공개된 숫자는 칸에 인쇄. **1 칸에서 시작해 이웃 칸을 차례로 누르면** 다음 번호가 찍힌다. 이웃이 아니거나 ●·이미 지난 칸이면 shake. 이미 번호가 인쇄된 칸에 들어갈 땐 **그 번호가 현재 차례와 같을 때만** 허용. 마지막으로 놓은 칸을 다시 누르면 한 칸 취소. L 까지 채우면 `onAnswer(L)`.
- **인쇄**: 격자 SVG(공개 숫자·●), 답은 빈 칸에 쓰는 형태. 정답지는 한 가지 해(`solution`)를 칸 번호로 출력 → 생성기가 `solution:[[r,c]..]`를 같이 싣는다. `nlAnswerLabel` 은 숫자 L 그대로.
- **우선순위**: 높은 난이도 활동. 유닛 lab 에는 넣지 않고 스레드 레벨 4(T-NEAR)에만 둔다.

### 3-9. 13쪽 확인학습 나머지
- ① `dots` 역순(3-1) · ② `pathFill`(2,_,4,5,_ 풍선: 원을 풍선 모양으로 꾸밀 수 있으나 데이터는 같음) · ③ `numPick`(기준 2 → 후보 중 가장 가까운 수 ○) · ④ `pathFill`(+2 사슬 / −2 사슬) · ⑤ `pathFill` ring · ⑥ `pathFill` grid `pattern:[3,2,1,3]`.
- 7쪽 확인학습도 3-2~3-4 와 같은 위젯의 재활용(위 요약표).

## 4. 이 호가 요구하는 새 위젯 / 새 소품 / 새 인쇄 표현 총정리

### 4-1. 위젯
| 구분 | 이름 | 동작(한 줄) |
|---|---|---|
| 신규 | `pathFill` | 굽이진 길·사슬·원형 화살표·격자 위 빈칸 여러 개를 숫자 타일로 채운다(틀린 타일은 안 놓임) |
| 신규 | `numPick` | 숫자 타일 중 조건에 맞는 것에 색칠/○/△/× 표시, 집합 일치로 판정(G1-3 공용) |
| 신규 | `orderTiles` | 숫자 타일을 정해진 순서(가까운 순·작은 순·큰 순)로 눌러 채우고 수직선 호를 그린다(G1-3 공용) |
| 신규 | `pinball` | 막힌 칸을 피해 1 → L 로 이웃 칸을 차례로 눌러 길을 만든다 |
| 확장 | `dotToDot` | `order:'down'`, `labels`, `pre`, 힌트 3언어화 |
| 확장 | `seqFill` | `problem.choices` 지원(반복 패턴·`between`) |
| 확장 | `tapCount` | `choices`(후보 3~4개) + `ask:'nearest'` |

### 4-2. 소품
`pencil`(연필), `eraser`(지우개), `paper-clip`(클립), `pear`(배), `marble`(구슬). 점 잇기 그림 4종(**자동차·햄스터·토끼·다람쥐**)은 실사 PNG 가 아니라 **좌표 윤곽(벡터)** — 구현자가 점 ≤9 로 설계. 사과는 기존 `apple`.

### 4-3. 인쇄 표현(exam.js)
- `nlVisualHtml` 신규 분기: `pathFill`(길·화살표 SVG), `numPick`(타일 줄), `orderTiles`(수직선+순서 칸), `pinball`(격자).
- `nlDotsSvg` 에 `labels`·`pre`. `nlSeqStripHtml` 에 긴 수열 줄바꿈.
- `nlAnswerLabel` 에 `pathFill`(빈칸 값 열), `numPick`(표시 수), `orderTiles`(순서열) 추가.
- `NL_PRINT_WORDS` 추가 치환: `숫자 타일을 눌러 채워요→빈 칸에 알맞은 수를 써요`, `가까운 순서대로 눌러요→가까운 순서대로 써요`, `칸을 차례로 눌러요→칸에 번호를 차례로 써요`, `눌러서 색칠해요→색칠해요`. 영어·중국어 한 줄씩.
