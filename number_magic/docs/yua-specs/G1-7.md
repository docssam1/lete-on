### 0.2 공통 계약 (7·8·9호 공통)
1. **정답은 항상 정수 하나** (`answerType:'number'`). 여러 칸을 채우는 위젯은 칸마다 내부 판정, 전부 맞으면 `onAnswer(problem.answer)`; `answer` = 채운 칸 수(완주 신호)로 두고 **실제 정답 값은 `solution` 배열에 따로 싣는다**(인쇄 정답지·검산용).
2. **칸 하나를 틀리면** 칸이 흔들리고 `onAnswer(-1)` 호출 → 호스트가 "다시 해볼까?" 음성만 낸다(감점 없음 확인). 같은 칸에서 연속 2번 틀리면 정답 후보 하나에 힌트 테두리.
3. **입력은 `numRow`**: 0~9 한 줄(5개씩 2줄) 큰 버튼(터치 56px 이상). 기존 3지선다는 찍기가 33% 라 덧셈·뺄셈 *값*을 묻는 문항에는 쓰지 않는다. 탭 즉시 입력, 별도 확인 버튼 없음. 선택 범위가 0~9 라 숫자패드(두 자리·OK 키)보다 유아에 맞다. (`NM_WIDGETS.numRow(el,{min,max,onPick})` 신규 공용 부품)
4. **수 범위**: 모든 수·합·차는 0~9. 생성기가 `a op b = c` 를 만든 뒤 `0≤각 수≤9` 를 assert.
5. **같은 장면에서 문항 4개를 뽑는 교재 형식**(동전 4식·배 4식)은 앱에선 **문항 1개 = 식 1개**로 나눈다(같은 장면, 식 형태만 바뀜). 인쇄 한 칸에 장면+식 1개. 정답은 하나로 고정된다.
6. **채점이 모호한 교재 문항**(식 자유 작성·복수 정답)은 (a) 선택형으로 바꾸거나 (b) "조건 만족하는 아무 쌍이나"를 규칙형으로 검사(pairFind `need`) 한다.
7. **언어**: 문구는 prompt ko/en/zh 3벌. 화면 문구에 "톡톡·콕"을 쓰면 `NL_PRINT_WORDS` 에 인쇄용 치환쌍을 같이 추가한다(아래 §3 각 항목에 쓴 문구가 이미 치환쌍을 포함하는 표현이면 그대로 둔다). 숫자 읽기 보조: 모든 prompt 는 🔊 재낭독(storyCard 패턴, `NM_SAY`) 대상.

## 2. 공용 위젯 명세

### 2.1 `eqFill` — 식 빈칸 + 장면
```js
{ prompt:{ko,en,zh}, widget:'eqFill', answerType:'number', answer:N,
  layout:'h'|'v',                          // 가로식 / 세로식(위·아래·줄·결과)
  eq:{ a:int, op:'+'|'-', b:int, c:int },  // 항상 a op b = c 가 성립 (0~9)
  blank:'a'|'b'|'c',                       // 빈칸 정확히 1개 (그 값이 answer)
  showEq:true,                             // false = 식을 숨기고 장면만 (물건 사기)
  scene:null | { kind:'dice'|'price'|'domino'|'coins'|'group2'|'dots'|'legend', … },
  unit?:{ko:'원',en:'coins',zh:'元'} }
```
화면: 위에 장면(있으면) → 식(빈칸은 흔들리는 노란 칸) → `numRow`. 맞으면 빈칸에 숫자가 채워지고 `onAnswer(answer)`; 틀리면 흔들림 + `onAnswer(-1)`.
- `scene.dice`: `{slot:'a'|'b'}` — 그 슬롯은 처음에 눌러야 하는 주사위(탭 → 0.8초 굴림 → `eq[slot]` 눈이 보임). 굴리기 전에는 `numRow` 비활성. 눈 값은 생성기가 미리 정해 두므로(rng) 정답 고정.
- `scene.price`: `{items:[{e:토큰, price}, {e:토큰, price}]}` — 물건 둘, 각자 말풍선 가격. 식 숨김(`showEq:false`).
- `scene.domino`: `{top, bottom, hidden:null|'top'|'bottom'}` — §3 p5.
- `scene.coins`: `{n, a, b, toss}` — 별무늬면 a개·달무늬면 b개, n=a+b (9호 p5·p11 공용).
- `scene.group2`: `{a:{e,n}, b:{e,n}}` — 두 무리가 곡선으로 갈라진 그림(9호 p7·p13).
- `scene.dots`: `{given}` — 이미 놓인 ○ given개 + 탭으로 ○를 더 쌓는 판. 입력이 `numRow` 대신 **탭 쌓기**이며 `answer` = 더 쌓은 ○ 수(= 빈칸 값).
- `scene.legend`: `{map:[{e,v}…]}` — "🍎=2 🐟=1 ⭐=3" 범례. 식 `a,b` 칸이 숫자 대신 기호로 보인다(`eq.symA`,`eq.symB` 토큰).
인쇄 `nlEqHtml(p)`: 세로식 = 위/기호+아래/가로줄/결과 상자(기존 `.nm-print-item-vp` 세로셈 모양 재사용 가능), 가로식 = `□ + 1 = 6`. 빈칸은 네모, 장면은 SVG/이모지, 주사위 슬롯은 미리 정한 눈을 `nlDiceHtml` 로 찍음. 정답지: 빈칸 값 숫자.

### 2.2 `hopLine` — 수직선 뛰기 (§3 p4·p10)
```js
{ widget:'hopLine', mode:'read'|'draw', answerType:'number', answer:N,
  max:9, mover:'frog'|'animal:rabbit',
  hops:[{from,to}, …],           // 1~2개. 첫 호는 항상 0→a, 둘째 호는 a→c (앞으로/되돌아옴)
  eq:{a,op,b,c}, blank:'a'|'b'|'c' }
```
0~9 눈금, 호(위쪽 곡선)와 화살촉. `read` = 호가 이미 그려짐 → 식 빈칸을 `numRow` 로 채움. `draw` = 눈금만 있음 → 아이가 **눈금을 순서대로 탭**(0→a, a→c)하면 호가 그려지고 그 뒤 빈칸 입력 활성(식에 빈칸이 둘인 `□+□=9` 류는 `blank:'ab'` 자유형 — a 눈금을 탭하면 b=c−a 가 자동 채워지고 완주, `answer`=c).
인쇄 `nlHopSvg(p)`: 눈금 SVG + (read 이면 호 그림, draw 이면 호 없음 — 아이가 연필로 그림) + 식 한 줄.

### 2.3 `pairFind` — 합·차가 같은 쌍 찾기 (7쪽 p6·p7-⑤, 8쪽 p3·4·5·9·11, 9쪽 p6·p12 …)
```js
{ widget:'pairFind', answerType:'number', answer:need,
  layout:'ring'|'scatter'|'grid'|'row'|'cards',
  rule:{ op:'sum'|'diff', target:int },
  items:[{ id, v:int, x?,y?, r?,c? }],      // ring/scatter 는 x,y(0~100) · grid 는 r,c · row/cards 는 순서
  adj:'any'|'4'|'8'|'row',                  // 짝으로 인정하는 위치 관계
  need:int,                                 // 찾아야 하는 쌍 수
  reuse:false,                              // 한 수를 두 번 쓰면 안 됨
  showEq:false,                             // true 면 찾은 쌍을 "a+b=t" 칩으로 아래에 적어 줌
  solution:[[id,id],…] }
```
동작: 수 둘을 차례로 탭 → 규칙(합/차=target)과 `adj` 를 만족하고 둘 다 안 쓰였으면 두 수가 같은 색으로 묶이며 선(ring·scatter)·테두리(grid·row·cards)가 생김, 아니면 흔들림+`onAnswer(-1)`. `need` 쌍을 모으면 `onAnswer(need)`. **"모든 쌍"(`need` = 가능한 쌍 수)** 과 **"아무 한 쌍"(`need:1`)** 을 같은 위젯이 처리 — 판정은 규칙형이라 복수 정답이 자연스럽다.
생성기 검증: ①`need` 쌍이 실제로 존재 ②"모든 쌍" 문항은 각 수의 짝이 유일(합 규칙은 보수가 하나뿐이라 자동, 차 규칙은 x, x+d, x+2d 사슬을 만들지 않음) → 어떤 순서로 찾아도 완주 가능 ③0 포함 가능(차 0·합=수 자체 허용).
인쇄 `nlPairHtml(p)`: 점·숫자 배치 그대로 + "두 수를 선으로 잇거나 ○로 묶어요". 정답지: 쌍 목록 "1+8, 2+7, …"(`nlAnswerLabel`).

### 2.4 `valuePick` — 식·쌍 칩에서 고르기
```js
{ widget:'valuePick', answerType:'number', answer:need,
  chips:[{ txt:'8 - 2', v:6, ok:bool }, …],     // 4~8개
  cond:{ kind:'equals', value:7 } | { kind:'odd' } | { kind:'max' } | { kind:'between', lo,hi } | { kind:'order', dir:'desc' } | { kind:'count' },
  need:int }                                    // ok 칩 수 (단일 선택 = 1)
```
`need=1`(odd·max·between): 탭 즉시 판정(정답 칩이면 `onAnswer(1)`, 아니면 흔들림+`onAnswer(-1)`). `need>1`(equals): 여러 칩 토글 → 확인 버튼(✔) → 정확히 일치하면 `onAnswer(need)`, 아니면 흔들림+`onAnswer(-1)`. `order`: 칩을 큰 합부터 차례로 탭. 칩의 값은 생성기가 계산하되 `txt` 는 식 문자열 또는 "(3, 5)" — 값이 같은 칩을 서로 다른 식으로 섞어 값 비교가 되도록.
인쇄 `nlValueHtml(p)`: 칩을 상자로 나열 + "○표 하세요"(치환 문구). 정답지: 해당 칩 식("8−2, 4+3").

### 2.5 `ruleTable` — 규칙표 (지붕·가로 두 줄·연쇄)
```js
{ widget:'ruleTable', layout:'house'|'strip'|'chain', answerType:'number', answer:blanks.length,
  rule:{ kind:'add'|'sub'|'colsum', k:int, shown:bool },     // shown=false 면 규칙 숨음(strip)
  roof:['+2'] | ['+5','-4'],                                   // house: 지붕 라벨(들)
  rows:[{in:int|null, out:int|null}, …]                        // house(세로 목록) / chain 은 in,mid,out
  cols:[{top:int|null, bottom:int|null}, …]                    // strip(가로 두 줄)
  solution:[…] }
```
빈 칸 탭 → `numRow`로 값 입력 → 맞으면 칸이 확정, 틀리면 흔들림. 전부 맞으면 `onAnswer(answer)`. strip(숨은 규칙)은 **채워진 열이 최소 2개**이고 그 두 열이 하나의 규칙(+k/−k/열합k)을 유일하게 결정하도록 생성기가 검증. 규칙은 항상 한 가지 연산.
인쇄 `nlRuleTableHtml(p)`: house = 지붕 삼각형+표, strip = 두 줄 표, chain = 화살표 달린 표.

### 2.6 `hiddenBeads` — 숨은 구슬 (7쪽 p12)
```js
{ widget:'hiddenBeads', answerType:'number', answer:N,
  whole:int, visible:int, hidden:int,          // whole = visible + hidden, 0≤…≤9
  ask:'hidden'|'whole'|'visible',              // 빈 가르기 칸 위치
  bond:{ top:int|null, left:int|null, right:int|null } }
```
실 한 줄에 구슬 `whole`개, 일부가 상자(불투명 카드)에 가려지고 `visible`개만 밖에 보임. 오른쪽에 가르기 도식(큰 수→작은 두 수) 빈칸 1개를 `numRow` 로 채움. 틀리면 상자 위에 "?" 가 깜박(힌트). `ask:'whole'` 은 두 부분(visible·hidden)이 도식에 적혀 있고 전체가 빈칸 — 그림은 보조.
인쇄 `nlBeadsHtml(p)`: 구슬 줄 SVG + 상자 사각형 + 가르기 도식(빈 네모). 상자 안 구슬 수는 그리지 않음(가림).

### 2.7 `codeBreak` — 그림 암호 (7쪽 p9)
```js
{ widget:'codeBreak', answerType:'number', answer:3,
  symbols:[{ e:토큰, eq:{a,op,b}, v:int }, …],  // 3~4개, v(결과값) 서로 달라야 함
  secret:[idx, idx, idx] }                       // 해독할 3칸
```
1단계: 기호 카드마다 식(🍎 = 3 + 4)이 있고 아이가 결과값을 `numRow` 로 채움 → 표 완성. 2단계: 숫자 3개("5 4 3")가 나오면 표를 보고 알맞은 기호 카드를 순서대로 탭 → 맞으면 칸에 기호가 들어감. 3칸 완성 시 `onAnswer(3)`.
인쇄: 기호별 식 4개 + 숫자열 + 기호를 그려 넣는 3칸. 정답지: 기호 3개(`nlAnswerLabel`).

### p9 암호 — **D**
- **교재 판독 확정**: 한글 자모 9개(ㄹㅅㅇㄴㄷㅣㅡㅏㅕ)에 식이 붙어 있고 값은 0~9 열 개 중 9개(ㅅ=0, ㅣ=1, ㅡ=2, ㄴ=3, ㅕ=4, ㅇ=5, ㄷ=6, ㅏ=8, ㄹ=9). 숫자열 "543 083" → 연산, "62 919" → 드릴(= "연산 드릴"). 즉 풀이 후 단어를 만들어 쓰는 퍼즐.
- **앱 입력으로 불가한 점**: 한글 단어 쓰기(키패드 없음), 영·중 사용자에겐 자모가 의미 없음.
- **대체안(D)**: 자모 대신 **그림 기호**(기존 16종 토큰) 4개에 식을 붙이고 값 표를 채운 뒤, 숫자 3개를 보고 기호를 순서대로 탭해 숨은 그림 낱말(예: 🍎🐟⭐)을 완성. `codeBreak`(§2.7). 3~4개 기호, 결과값 서로 다름, 모든 계산 0~9.
- **구현**: NL12 `nl13_puzzle` mode `code`(level main 만). problem: §2.7 스키마.
- **인쇄**: 기호별 식 4개 표 + 숫자열 + 기호를 그릴 3칸.
- **3언어**: ko "그림마다 식을 계산해서 암호표를 만들어요. 숫자를 보고 그림을 맞춰요" · en "Solve each picture's sum to make a code table, then decode the numbers." · zh "先算出每个图案的得数做成密码表，再根据数字找出图案。"
- **그림**: 기존 16종 토큰으로 충분. 우선순위 낮음(활동 하나뿐인 갈래).

### p10 수직선 — **C**
- **교재**: 6문항. ①②는 호 일부 제공(`5+□=6`, `□−□=6`), ③~⑥은 눈금만(`1+□=4`, `7−□=4`, `□+□=9`, `□−□=5`). 아이가 호를 그려 넣고 식을 채움.
- **구현**: NL21 mode `draw`(level main). 식 하나 + 빈 눈금. 아이가 눈금을 탭해 호를 그리고(0→a→c) 빈칸을 `numRow`. `□+□=c`·`□−□=c` 는 `blank:'ab'` 자유형(위 §2.2) — 정답이 여럿이라 규칙형 판정(`answer`=c). 한 눈금씩 탭이 5~7세에 어려우면 "개구리 뛰기 버튼"(탭 1회 = 한 칸 앞으로)으로 대체 가능(선택 설정 `hopStep:true`).
- **problem**: `hopLine` `mode:'draw'`, `eq`, `blank`, `hops`(정답 호, 인쇄 정답지·그리기 검증용).
- **인쇄**: 눈금만 있는 선 + 식 한 줄(아이가 연필로 호를 그림). 정답지는 빈칸 값(자유형은 "예: 3+6").
- **풀**: ≈200.
- **3언어**: ko "눈금 위에서 개구리를 뛰게 하고 빈 칸을 채워요" · en "Make the frog hop on the number line, then fill the box." · zh "让青蛙在数轴上跳一跳，再填空。"

### p11 표 채우기 — **C**
- **교재 판독 확정**(6표, 위·아래 두 줄): 규칙은 표마다 하나이고 **전부 한 가지 연산**: +2, −1, −3, +1, +4, −2. 칸 2~3개가 빈칸이고(위·아래 섞임) 채워진 열 2개 이상이 규칙을 정한다.
- **구현**: NL11 level `strip`. `ruleTable` `layout:'strip'`, `rule.shown:false`, 열 5~6개, 위쪽 수 0..9, 규칙 ±1..±4(결과 0..9), 빈칸 2~3개(채워진 열 최소 2개). level 2에서 일부 열은 위·아래 양쪽 빈칸(채워진 열이 규칙을 정하면 풀림).
- **정답 판정**: 칸별 비교(규칙이 유일하므로 각 빈칸 값 유일).
- **인쇄**: 두 줄 표(교재와 같은 모양). 정답지: 빈칸 값 나열.
- **3언어**: ko "위와 아래 수에 숨은 규칙을 찾아 빈 칸을 채워요" · en "Find the hidden rule between the top and bottom numbers and fill the blanks." · zh "找出上下两行数字之间的规律，填空。"

### p12 숨은 구슬의 개수 — **C**
- **교재**: 구슬 8개 꿴 실이 상자에 반쯤 가려짐 → 가르기 도식(큰 수→두 수)에서 숨은 수를 구함. 예시(8=3+5) + 6문항. 일부는 전체가 빈칸, 일부는 안 가려진 수가 빈칸.
- **앱에 있나?** 수학은 `nl4_bond` split/join 과 같다(`numberBond`). 그림(상자 가림 구슬)만 없음.
- **구현**: NL2 `nl4_bond` 에 level 4: `{mode:'hidden', level:'main'}`. `hiddenBeads`(§2.6). `whole 3..9`, `visible 0..whole`, `ask`: `hidden`(전체·보이는 수 주어짐 → 숨은 수), `whole`(두 부분 주어짐 → 전체), 가끔 `visible`(전체·숨은 수 주어짐). 0 포함(보이는 구슬 0개 = 전부 상자 속).
- **정답 판정**: 단일 정수.
- **인쇄**: 구슬 줄 + 상자(가림) + 가르기 도식 빈 네모.
- **풀**: (whole,visible) 약 45 × ask 3 ≈ 130.
- **3언어**: ko "구슬이 모두 {w}개예요. 상자 속에는 몇 개 숨어 있을까요?" · en "There are {w} beads in all. How many are hidden in the box?" · zh "一共有{w}颗珠子，盒子里藏着几颗？"
- **그림**: 구슬(유리구슬, 한 종 — 서로 다른 색 3~4종이면 좋음), 상자(불투명 카드; CSS 로 충분하나 실사화하려면 종이 상자 PNG) — 신규.

### p13 확인학습(마무리) — 6문항, 각각

| 번호 | 교재 요지 | 결정 | 구현 |

| ② | `□ + 2 = 7` 이 되게 ○ 그리고 □ 쓰기 | **D** | NL18 mode `dots`. 손으로 ○를 그리는 활동 → **탭으로 ○ 쌓기**. `eqFill` `scene.dots` `{given:2}`, `eq` `a=□`(빈칸), 판에 ○ 탭해 쌓은 개수 = □. 입력 완료(✔)로 `onAnswer(개수)`. 인쇄는 교재처럼 ○를 직접 그려 넣는 칸 + □ |

## 5. 이 호가 요구하는 새 위젯 / 새 소품 / 새 인쇄 표현 총정리

**새 위젯(공용, 8·9호도 씀)**
1. `numRow` 0~9 입력 줄(공용 부품)
2. `eqFill` — 장면 슬롯 7종(dice·price·domino·coins·group2·dots·legend)
3. `hopLine` — read / draw / 자유형
4. `pairFind` — ring·scatter·grid·row·cards, 규칙형 판정 `need`
5. `valuePick` — equals(다중)·odd·max·between·order·count
6. `ruleTable` — house·strip·chain, 규칙 보임/숨음, 열합 규칙
7. `hiddenBeads` — 상자 가림 구슬 + 가르기 도식
8. `codeBreak` — 그림 암호 2단계
9. `matchLine` 확장 — `cardType:'pairSum'`
(`numberMachine`·`nl4_bond` 등 기존 위젯은 새 mode 추가만, 코드 수정 최소)

**새 소품(실사 PNG)**

|---|---|---|
| 주사위 눈 1~6(6면 또는 윗면 6장) | p2, 이후 호에서도 | 필수 |
