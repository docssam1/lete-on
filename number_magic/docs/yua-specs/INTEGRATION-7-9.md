## ④ 알려진 한계 · 명세 대비 차이
- **N-07 유닛**: 제목·practice(주사위)·lab(수직선 읽기)·discover 를 G1-7 로 교체. N-08 은 lab 만 `nl42_rules` 수 상자(입구도 구하기)로, N-09 는 practice(동전 던지기)·lab(수나무)·discover 를 교체. 예전 "수 이웃과 10 짝꿍"·"피라미드와 10원 세기"는 NL6·NL5 드릴로 남는다(과정 편성에서 NL6/NL5 가 빠지지 않게).
- **막힌 확장 → 새 레벨로 대체**: nl8_machine guess 확장(ask in)·sum2 → `machineBox`(NL42 L6~8) · nl4_bond 숨은 구슬 → `hiddenBeads`(NL43) · nl13_puzzle code → `codeBreak` · matchLine pairSum → `sumMatch`(NL43 L5) · 4줄 피라미드 → 위젯 `pyramid4`(화면은 기존 pyramid 를 그대로 호출, 인쇄는 전용). `numRow` 는 widgets.js 를 못 고쳐 위젯 파일 안에 자체 구현.
- **자유 답 행 미구현**: G1-9 p9 의 +2/−2 "마지막 행 마음대로"(`blank:'ac'`)는 문항이 4가지뿐이라 레벨당 24문항 조건을 못 채워 뺐다. 수직선 자유형(□+□=c, NL41 L4)은 개구리 종류를 변수로 48문항 확보.
- 마주 보는 수(NL40 L8): 완전한 짝이 하나 보이면서 모든 빈칸을 유일하게 풀려면 빈칸이 2개가 최대라 main 3칸 안은 2칸으로 줄였다(합 S 는 표시 안 함).
- 그림 암호는 인쇄 칸 높이 때문에 기호 3개로 고정(명세 3~4).
- 4×4 판(NL39 L11)은 이웃 차 쌍 정확히 3개로 만들되, 헷갈려 막힌 경우를 위해 묶인 칸을 다시 누르면 풀린다.
- 위젯은 `S.lang`(ko/en/zh) 을 직접 읽는다. 동전 던지기·주사위 굴림·수직선 자유형 완주는 연출 때문에 0.5~1.2초 뒤 `onAnswer` 를 부른다.
- 한 칸이 많은 줄(NL39 L10, 11개 한 줄)은 버튼 폭이 22px 까지 줄어든다(터치는 되나 작다).
