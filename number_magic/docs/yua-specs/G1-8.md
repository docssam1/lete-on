## 2. 8호 전용 새 위젯

### 2.1 `vertexSum` — 꼭지점 합 도식 (6쪽 · 7-⑥ · 12쪽 · 13-⑥)
```js
{ widget:'vertexSum', shape:'tri'|'quad', answerType:'number', answer:blanks.length,
  verts:[int|null, …],                       // tri 3개(위·왼아래·오른아래), quad 4개(시계방향)
  edges:[{i:int,j:int,v:int|null}, …],       // tri 3개, quad 4개. 변 가운데 원 = verts[i]+verts[j]
  blanks:[{kind:'v'|'e', idx:int}],
  solution:[int,…] }
```
- 꼭지점은 회색 네모, 변 위 합은 흰 원(교재 모양 그대로). 빈 칸 탭 → `numRow` → 맞으면 확정(공용 계약 §0.2). 전부 맞으면 `onAnswer(answer)`.
- **모든 수·합은 0~9**(꼭지점 0..5 안팎, 변의 합 ≤9).
- 생성기: 꼭지점 값을 정하고 변의 합을 계산한 뒤 빈칸을 고른다. 빈칸 조합은 **전파로 풀리는 것만** 채택(세 값 중 둘을 알면 나머지가 정해지는 규칙을 반복 적용해 전부 구해지는지 시뮬레이션). 유형: (a) 꼭지점 전부 주어짐·변의 합 전부 빈칸, (b) 꼭지점 1~2개 빈칸 + 인접 변 합이 주어짐(역산, 교재 6쪽 뒤 문항·7-⑥).
- 인쇄 `nlVertexHtml(p)`: 삼각형/사각형 SVG, 회색 네모(주어진/빈)와 흰 원(주어진/빈). 정답지 "원: 4, 8, 6" 식으로 빈칸 값 나열.
- 3언어: ko "네모 안의 수는 양쪽 꼭지점을 더한 값이에요. 빈 곳에 알맞은 수를 써요" · en "Each circle is the sum of the two corners next to it. Fill the blanks." · zh "圆圈里是两边顶点的和，把空格填出来。"

### 2.2 `wheelFill` — 바퀴 (7-② · 10쪽)
```js
{ widget:'wheelFill', mode:'sectors'|'opposite', answerType:'number', answer:blanks.length,
  // sectors: 가운데 S, 5칸, 칸마다 안쪽 inner + 바깥 outer = S
  center:int, sectors:[{inner:int|null, outer:int|null}, …],
  // opposite: 6등분 원, 마주 보는 두 칸의 합이 모두 같다
  wedges:[int|null, …6],
  solution:[…] }
```
- `sectors`(7-②, 교재 확정: 가운데 9, 바깥 [?,1,5,0,7]·안쪽 [6,8,?,?,?], 각 칸의 안쪽+바깥=9): S `5..9`, 칸 5개, 각 칸에 **빈칸 최대 1개**(짝이 보이도록), 빈칸 3~4개. 사실상 "S 의 짝꿍 찾기" 반복.
- `opposite`(10쪽): 6칸 `i` 와 `(i+3)%6` 이 짝. 합 `S∈3..9`는 화면에 **표시하지 않는다**(교재와 같음). 완전한 짝이 1개 이상 보여서 S 를 추론할 수 있어야 한다. 빈칸 practice 2 / main 3. 값 0 포함.
- 입력 `numRow`. 인쇄 `nlWheelHtml(p)`: SVG 원(5/6등분, sectors 는 이중 원).
- 3언어: ko(sectors) "가운데 수와 같아지도록 빈 칸을 채워요" / ko(opposite) "마주 보는 두 수의 합이 모두 같도록 빈 칸을 채워요" · en "Fill the blanks so each pair adds up to the center number." / "Fill the blanks so opposite numbers always have the same sum." · zh "填空，使每一对数相加都等于中间的数。" / "填空，使相对的两个数的和都一样。"

### 2.3 `opGrid` — 가로 더하기·세로 빼기 표 (13-②)
```js
{ widget:'opGrid', answerType:'number', answer:blanks.length,
  g:[[a,b,c],[d,e,f],[g,h,i]],      // 일부 null. 행: g[r][0]+g[r][1]=g[r][2]  열: g[0][c]-g[1][c]=g[2][c]
  blanks:[[r,c],…], solution:[…] }
```
- 교재 판독(13쪽 ②): `6 3 □ / □ 2 6 / □ □ □` → 정답 `6 3 9 / 4 2 6 / 2 1 3`. 규칙 = 가로로 첫째+둘째=셋째(⊕ 화살표), 세로로 첫째−둘째=셋째(⊖ 화살표) — 3×3 에서 두 규칙이 동시에 성립한다(`(g00+g01)−(g10+g11) = (g00−g10)+(g01−g11)`).
- 생성기: `g00,g01,g10,g11` 을 정하고 `g02=g00+g01≤9`, `g12=g10+g11≤9`, `g20=g00−g10≥0`, `g21=g01−g11≥0` 를 만족시키면 나머지가 자동 정해진다. 빈칸 3~4개를 전파로 풀리게 골라(한 칸은 한 번의 덧셈/뺄셈) 낸다. **유아에겐 3×3 이 많아 D**: level practice 는 2×3(행 2개) 또는 빈칸 2개.
- 인쇄 `nlOpGridHtml(p)`: 격자 + 위쪽 ⊕ 화살표·왼쪽 ⊖ 화살표. 우선순위 낮음(교재에서도 이 권 확인학습 한 문항뿐).
- 3언어: ko "가로로는 더하고, 세로로는 빼요. 빈 칸을 채워요" · en "Add across, subtract down. Fill the blanks." · zh "横着加，竖着减，把空格填出来。"

### 2.4 기존 위젯 확장
- **`numberMachine`**: `mmode:'guess'` 에 `ask:'in'|'out'`, `skin:'box'`(교재의 입구·출구 상자 모양: 위에서 입력이 들어가고 아래로 출력) 추가. 새 `mmode:'sum2'`(입구 2개 → 출력 1개). 입력은 현재 숫자패드 그대로(최대 2자리) — 값 범위가 0~9 라 `numRow` 로 바꿔도 되며 선택.
- **`matchLine`**: 8호엔 불필요.
- 공용 `pairFind`·`valuePick`·`eqFill`·`numRow` 는 G1-7 정의 그대로. 8호가 쓰는 추가 필드: `pairFind` 의 `layout:'ring'` 에 `shape:'circle'`, `valuePick.cond.of:'sum'|'diff'`, `cond.kind:'order'`.

## 3. 활동별 상세

### p2 수 상자 — **B**
- **앱에 있나?** 부분. `nl8_machine` guess = 예시 2개를 보고 규칙을 추리해 `target` 의 출력을 구함(`nl.js:686-720`). 교재와 같은 점: 규칙이 숨겨짐·예시 2개. 다른 점: ①**상자가 3개 가로 한 줄**이고 그중 하나가 빈칸이 아니라 **빈 칸이 입력 쪽일 수도 있음**(행 3·4: `?→8`, `?→3` — 역산) ②수 범위 0~9 ③입·출구 모양의 상자.
- **교재 확정**(4행×3상자): 행마다 한 규칙 — (+3), (−1), (+4), (+3). 빈 칸: 행 1 = 출력(4), 행 2 = 출력(3), 행 3 = 입력(4), 행 4 = 입력(0).
- **구현**: `nl8_machine` mode `guess` 에 params 추가: `cap:9`(입력·출력 모두 0..9 — 기존 `maxN` 대신), `ask:'out'|'in'`(무작위; practice 는 `out`만), `skin:'box'`, `qPos:0|1|2`(물음 상자가 몇 번째 칸인지, 시각 변화용). `delta` 풀: practice `[1,2,3]`, main `[-4..4]\{0}`. `ask:'in'` 이면 `target`=출력값, 답=입력값.
- **problem**(추가 필드): `{mmode:'guess', skin:'box', ask:'in'|'out', examples:[[3,6],[4,7]], target:int, answer:int}`.
- **정답 판정**: 단일 정수(규칙이 하나라 유일).
- **인쇄**: `nlMachineHtml` 의 guess 분기를 `ask:'in'` 일 때 **빈칸이 입력 쪽**이 되게(예: `□ → ⚙ → 8`), 상자 3개를 가로 한 줄로(`skin:'box'`).
- **풀**: 규칙(8) × (예시1,예시2,물음) ≈ 2300 → cap 불필요.
- **3언어**: ko "상자마다 같은 규칙이에요. 규칙을 찾아 빈 칸에 알맞은 수를 써요" · en "Every box follows the same rule. Find it and fill in the blank." · zh "每个盒子的规则都一样，找出规则填空。"
- **그림**: 없음(상자는 도식).

### p3 차가 일정한 두 수 찾기 — **C**
- **교재 확정**: 2×2 격자 3개 × 6줄(=18). 목표 차 3,1,2,2,0,1. **각 격자에 차가 목표인 쌍은 정확히 1개**(위치는 가로·세로·대각선 제각각 — 예: `[[1,6],[2,4]]` 차 3 → 대각선 1과 4).
- **구현**: NL19 `nl19_pairfind` layout `grid`, params `{size:2, op:'diff', targetPool:[0..4]}`. 값 0..9. 생성기: 4칸을 만든 뒤 6쌍의 차를 계산해 **목표 차인 쌍이 정확히 1개**가 되게 재시도(차 0은 같은 수 2개). `adj:'any'`, `need:1`.
- **problem**: `pairFind` 스키마(G1-7 §2.3), `items:[{id,v,r,c}]×4`.
- **입력**: 두 칸을 탭 → 맞으면 둘이 칠해짐(교재의 색칠). 틀리면 흔들림.
- **인쇄**: 2×2 표 + "차가 {t}인 두 칸을 색칠해요". 정답지: "(위 오른쪽 6, 아래 오른쪽 4)" 처럼 칸 위치.
- **풀**: 10⁴ 이상.
- **3언어**: ko "차가 {t}인 두 수를 찾아 색칠해요" · en "Find the two numbers whose difference is {t} and color them." · zh "找出差是{t}的两个数并涂色。"

### p4 선 긋기 — **C**
- **교재 확정**: 4칸(합 6·7·8·9), 칸마다 0~9 숫자 10개가 흩어져 있고(각 수 한 번씩) 합이 목표인 쌍을 잇는다. 합 6 → 쌍 3(0-6,1-5,2-4, 3·7·8·9 는 짝 없음), 합 7 → 4쌍, 합 8 → 4쌍(4 는 짝 없음), 합 9 → 5쌍(전부).
- **구현**: NL19 layout `scatter`, params `{op:'sum', n:6|8|10, targetPool:[6..9]}`. 위치·크기·기울기는 `nl.js` `dress()` 재사용, 숫자 글꼴 `'num:v'` 토큰. `need` = 가능한 쌍 수(전체), `reuse:false`. 합 규칙은 보수가 유일하므로 순서에 관계없이 완주. practice 는 숫자 6개·쌍 2~3, main 은 0~9 전체 10개.
- **problem**: `pairFind` scatter, `items:[{id,v,e:'num:6',x,y,r,s,f}]`.
- **입력**: 두 숫자를 차례로 탭 → 곡선 선이 그려짐(matchLine 의 선 스타일 재사용).
- **인쇄**: 흩어진 손글씨 숫자 + "합이 {t}인 두 수를 선으로 이어요". 정답지: 쌍 나열.
- **3언어**: ko "합이 {t}이 되는 두 수를 선으로 이어요" · en "Join each pair of numbers that add up to {t}." · zh "把和是{t}的两个数用线连起来。"
- **그림**: 'num:' 손글씨 숫자 토큰 재사용(신규 없음).

### p5 수 묶기(7×7) — **D**
- **교재**: 물고기 안 7×7 숫자판에서 가로·세로·대각 이웃 중 차가 2인 쌍을 ○로 묶는다. 쌍 개수 제시 없음(탐색형).
- **유아에게 과한 점**: 49칸을 전부 훑는 탐색, 정답 쌍 개수 불명 → 완주 판정 불가.
- **변형**: 4×4(16칸), 이웃 8방향, 차 d(1~3), `need:3`(비중첩 쌍 3개 찾으면 완주, 더 많아도 인정). `plantPairs` 로 3쌍을 먼저 심고 나머지를 채운 뒤 `maxMatching ≥ 3` 을 검증. 배경은 **물고기 윤곽**(기존 🐟 토큰 크게 깔아 교재 느낌 유지).
- **problem**: `pairFind` grid, `adj:'8'`, `size:4`, `need:3`, `reuse:false`.
- **인쇄**: 물고기 모양 SVG 안 4×4 표 + "차가 {d}인 이웃한 두 수를 3쌍 ○로 묶어요". 정답지: 심어 둔 쌍(+ "그 밖에도 가능").
- **3언어**: ko "옆·위·아래·비스듬히 이웃한 수 중 차가 {d}인 쌍을 3개 찾아요" · en "Find 3 pairs of neighbours (including diagonals) that differ by {d}." · zh "找出3组相邻（含斜着）的、差是{d}的数。"
- **그림**: 물고기(기존 `🐟`).

### p6 꼭지점의 수 더하기(삼각형) — **C**
- **교재 확정**: 예시 `4(위) 2·5(아래)` → 변 합 6·9·7. 6문항 중 앞 2개는 꼭지점 주어짐·합 3원 빈칸, 뒤는 일부 꼭지점이 빈칸(합 → 꼭지점 역산, 두 단계 푸는 문항 포함).
- **구현**: NL20 `nl20_diagram` mode `vertex`, `shape:'tri'`. level practice: (a) 유형, 빈칸 1~2개. main: (a) 전부 + (b) 역산 혼합. 모든 값 0..9.
- **problem**: `vertexSum`(§2.1).
- **인쇄/정답지**: §2.1.
- **풀**: 꼭지점 조합 수백.

### p7 확인학습(중간) — 6문항, 각각
| 번호 | 교재 요지 | 결정 | 구현 |
|---|---|---|---|
| ① | 5쌍 중 두 수의 합이 가장 큰 것 | **C** | NL17 mode `pick`, `valuePick` `cond:{kind:'max'}`, 칩 5개 `(1,6)(3,3)…`, 최댓값 유일 |
| ② | 동심원 바퀴, 가운데 9 | **C** | NL20 mode `wheel` sectors(§2.2). 교재 해석: 각 칸 안쪽+바깥=9 |
| ③ | "동화책 7권 중 2권을 읽었다. 안 읽은 책은?" | **A** | 기존 `nl15_logic` story 의 덜기(start 7, change 2). 소품만 기존 풀에서 바뀜. 문구 변형 불필요 |
| ④ | 4의 가르기, 5의 가르기 식 빈칸 | **C** | NL17 mode `blank`(§3 아래). `eqFill` 가로식 `a + b = whole`, `whole` 고정, 빈칸은 a 또는 b |
| ⑤ | 차가 3인 쌍에 ○ | **C** | NL17 mode `same`(`of:'diff'`), 칩 5개 중 정답 1~2개, `valuePick` multi |
| ⑥ | 보기와 같은 규칙으로 삼각 도식 | **C** | NL20 mode `vertex` tri 역산. 교재 판독: 보기 = 위 꼭지점 1, 변 합 4·3, 아래 꼭지점 3·2 와 아래 변 5 → **꼭지점 합 삼각형**(위쪽을 꼭지점으로 놓은 배치) |

**NL17 mode `blank`(8호 신규 정의)** — 일반 가로식 빈칸. params `{whole?:int, op:'+', level}`. `whole` 이 주어지면 `c=whole` 고정, `a+b=whole`, 빈칸 a 또는 b(가르기식 4=□+1…). 없으면 a,b,c 무작위(합 ≤9, 뺄셈도 허용 `op:'mix'`). problem `eqFill` `layout:'h'`, `blank`. 풀: `whole` 3..9 × 분해 ≈ 40, 일반 330. 인쇄 `nlEqHtml`(G1-7).
- ④ 3언어: ko "{w}을 두 수로 가르는 식이에요. 빈 칸을 채워요" · en "Split {w} into two numbers. Fill the empty box." · zh "把{w}分成两个数，填空。"

### p8 수 상자(입구 둘) — **B**
- **교재 확정**: 입구 2개·출구 1개. 출력=두 입력의 합. 9상자 중 출력 빈칸 3, 입력 빈칸 5~6(역산, 0 포함: `5,□→5`, `□,3→3`).
- **구현**: `nl8_machine` 새 `mmode:'sum2'`(NL11 level 5). params `{cap:9, ask:'out'|'in1'|'in2'}`. `in1+in2=out≤9`, 0 포함(practice 는 0 제외). 규칙은 화면에 안 보이지만 "두 수를 넣으면 합이 나와요"를 prompt 에 말한다(교재 지시).
- **problem**: `{widget:'numberMachine', mmode:'sum2', skin:'box', a:int|null, b:int|null, out:int|null, ask, answer}`.
- **인쇄**: 입력 2칸 → 상자 → 출력 칸, 빈칸 하나(`nlMachineHtml` 에 `sum2` 분기).
- **풀**: 55 × 3 = 165.
- **3언어**: ko "두 수를 상자에 넣으면 합이 나와요. 빈 칸에 알맞은 수를 써요" · en "Put two numbers in the box and their sum comes out. Fill the blank." · zh "往盒子里放两个数，出来的是它们的和。填空。"

### p9 합이 일정한 두 수 찾기 — **C**
- 3쪽과 같은 모드의 합 버전: NL19 `grid` size 2, `op:'sum'`, 목표 6~9, 2×2 안에 합이 목표인 쌍이 **정확히 1개**. 교재 확정: 5행(6,7,9,8,9)×3격자, 쌍 위치는 격자마다 다름(가로·세로·대각 포함).
- 인쇄·문구·풀은 3쪽과 같다(문구 "합이 {t}인 두 수를 찾아 색칠해요").

### p10 마주 보는 수 — **C**
- **교재 확정**: 6등분 원 6개, 마주 보는 두 칸의 합이 모두 같다(S 는 문제에 없음). 칸마다 1~3개의 수가 주어지고 나머지는 빈칸.
- **구현**: NL20 mode `wheel` opposite(§2.2). S `3..9`(9 초과 없음), 빈칸 practice 2 / main 3, 값 0 허용.
- **problem**: `wheelFill` `mode:'opposite'`.
- **인쇄**: 6등분 원, 빈 칸은 비워 둠. 정답지: 빈칸 값 나열.
- **풀**: S × 조합 ≈ 수백.

### p11 수 묶기(한 줄) — **C**
- **교재 확정**: 예시(차 3) + 6줄(목표 4,2,1,1,2,3). 12개 숫자가 한 줄, **서로 이웃한** 두 수의 차가 목표인 쌍을 ○로 묶는다. 쌍은 여러 개일 수 있다.
- **구현**: NL19 layout `row`, `adj:'row'`, `op:'diff'`, 목표 1..4. practice 수 8개·`need:1`, main 수 10~12개·`need` 2~3(`reuse:false`, 비중첩 쌍 `need`개가 존재함을 검증).
- **problem**: `pairFind` row.
- **입력**: 이웃한 두 수를 탭 → 둘을 묶는 둥근 표시. 떨어진 수를 누르면 흔들림.
- **인쇄**: 한 줄 숫자 + "이웃한 두 수의 차가 {t}인 쌍을 ○로 묶어요".
- **3언어**: ko "옆에 붙은 두 수의 차가 {t}인 쌍을 찾아 묶어요" · en "Circle the neighbours whose difference is {t}." · zh "圈出相邻的、差是{t}的两个数。"

### p12 꼭지점의 수 더하기(도형 3종) — **D**
- **교재**: 삼각형(원 3), 사각형+대각선(원 5), 오각형+별(원 10) — 도형이 복잡해질수록 어느 두 꼭지점의 합인지 선을 따라가야 한다.

## 5. 이 호가 요구하는 새 위젯 / 새 소품 / 새 인쇄 표현 총정리

**새 위젯**: `vertexSum`(tri·quad), `wheelFill`(sectors·opposite), `opGrid`. 공용(G1-7 정의) 재사용: `pairFind`(grid·scatter·row·ring/circle), `valuePick`(max·order·of:diff), `eqFill`(`blank` 모드), `numRow`, `ruleTable` 해당 없음.
**기존 위젯 확장**: `numberMachine`(`ask:'in'`·`skin:'box'`·`mmode:'sum2'`), `nl4_bond`(`frame:'hands'`·⚫).
**새 소품**: 없음. 기존 `num:` 손글씨 숫자, 🐟(물고기 윤곽), ⚫(바둑돌), 기존 소품 4종(기호 라벨) 재사용.
**새 인쇄 표현**: `nlVertexHtml`(삼각/사각), `nlWheelHtml`(5·6등분 원), `nlOpGridHtml`(3×3 + ⊕⊖ 화살표), `nlPairHtml` 의 grid(2×2·4×4)/scatter/row/ring(circle) 분기(7호 정의), `nlMachineHtml` 의 `ask:'in'`·`sum2`·`skin:'box'` 분기, `nlValueHtml` 의 order(칩 옆 번호 칸). 정답지 `nlAnswerLabel` 에 쌍·빈칸 값 나열 라벨.
