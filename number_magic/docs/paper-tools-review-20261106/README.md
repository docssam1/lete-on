# 종이 교구 용어·인쇄 디자인 점검 — 2026-11-06

담당: Mac mini Codex / GPT-6.1 Sol. 모델 전환·새 에이전트·음성 제작 없음.

## 반영 내용

- **10칸 수판(십틀)**은 2행×5열의 빈 칸, **십막대(십 모형)**는 낱개 10개를 한 줄로 묶은 수 모형으로 구분했다. 연결 큐브 구매 예시를 수판 자체의 설명과 섞지 않고 대체 교구로 안내한다. 받아올림을 설명하며 쓰던 ‘빌려 오기’를 없애고, 8개와 7개를 먼저 놓고 2개를 옮겨 10과 5로 만드는 순서를 완결했다.
- 수판 한 칸 설계 치수 **15→19mm**, 원 조각 지름 **11→17mm**. A4 본문 폭에서 잰 실제 크기는 약 **18.79mm·16.81mm**다. 백/십/일 모형의 공통 단위는 **6→8mm**로 확대했고 실제 낱개 약 **7.91mm**, 십막대 약 **7.91×79.11mm**로 10:1 관계를 유지한다. 프린터 배율에 따라 달라질 수 있다.
- 기존 승인 PNG 숫자 캐릭터를 재사용했다. 두 종류의 수 조각은 색과 함께 **점·고리**로 구별해 흑백에서도 쓸 수 있다. 자르는 바깥 점선과 남겨 두는 내부 실선을 구분하고, 놀이 순서와 보호자 준비 안내를 분리했다. 교구의 칸·분할선은 치수가 정확해야 하므로 수학 도형으로 구성한다. 새로 대충 그린 인물/동물 삽화를 추가하지 않았다.
- 펜토미노는 마지막 줄 조각이 원래 viewBox 높이84 밖(내용 하단102)에 있어 잘렸다. 12조각을 3열×4줄로 재배치하고 판과 조각의 칸 크기를 함께 6→8mm로 확대했다. I 조각은 회전해 배치하며, 같은 넓이의 조각에 쓰던 ‘큰 조각부터’ 안내도 고쳤다.
- 분수 원판의 그림 및 설명·놀이·선택 교구 안내에 남아 있던 슬래시 분수를 세로 분수로 표시하고, 원판 아래 분수 이름이 다음 줄 원판과 붙지 않도록 간격을 조정했다.
- 종이 저울이 실제로 기울어진다고 읽히던 설명을 카드의 값을 비교하는 활동으로 바로잡았다. 없는 ‘12 카드’를 요구하는 대신 1과 2를 나란히 놓는 방법을 안내했다.
- `ws.html#nm-paper-tool` 링크는 글꼴·학습지 준비 후 교구 쪽으로 바로 이동한다. 일반 학습지 시작 위치는 바꾸지 않는다. 390px 휴대폰에서는 종이 축소율과 별도로 상단 메뉴 높이를 빼서 교구 제목이 가려지지 않게 보정했다.
