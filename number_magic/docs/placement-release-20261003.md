# 진단·목표 경로 배포 계약 — 2026-10-03

작업 키: `NumbersMagic/fixed20-goal-roadmap/20261003/v1`. 사용자 요청은 기존 커리큘럼을 유지한 진단·목표 안내의 main 반영과 공개 배포이다. 원본 교재, 학생 자료, 다른 작업자의 미반영 변경은 배포 대상이 아니다.

## 이번 변경

- 유아 8주제와 기존 C1~C73에서 실제 배운 범위를 선택하고, 이전 6 / 현재 10 / 다음 4의 고정 20문항을 시작 전에 만든다.
- 교재 선택 186조합 중 좁은 두 주제의 6조합만 자동 시작점 후보이다. 나머지 180조합은 공부한 내용 확인이 필요하다. 연령이나 책 번호만으로 숙달·학원 진도를 확정하지 않는다.
- 교과 기반, 소마·필즈 목표, 이과 최상위권 준비의 세 목표를 제공한다. 소마 A·필즈 E1·필즈 S·프리미어는 안내 목표이며 합격이나 도달 시점의 인증이 아니다.
- 선택한 본진도와 이전/현재의 보강·재확인 위치를 구분한다. 다음 표본만 틀렸다고 이미 배운 영역의 약점으로 저장하지 않는다.
- 주 1/2회는 사용자가 정한다. 목표 선택으로 문항·점수·진도·코인·해금을 바꾸지 않는다. 같은 버전의 진행 중 진단은 재진입 때 보존한다.
- 새 진단 지문은 영어에서도 GCD/LCM 대신 전체 교과 용어를 쓴다. 개념에서 약어를 정의하는 것과 문제를 약어로 출제하는 것은 다르다. 기존 전체 학습 생성기의 영어 표현을 전수 교체했다는 뜻은 아니다.

## 검수 계약과 증거

필수 게이트는 `check-answerable`, `print-lang`, `ladder`, `stages`, `about-stats`, `roadmap-sync`, `session-roles`, `weekly-sheets` 8종이다. 통과 전에 main에 올리지 않는다. 새로운 레벨을 추가하지 않았으며 295유닛·308유형·998레벨·74과정·563회차를 유지한다.

별도 진단 게이트는 2,800계획과 조건 fixture 4,645건, 영어 교과 용어 60개 fixture, 목표 경로 7,938조합, UI 통합 계약을 검사한다. 독립 검토는 구현자의 고정 시드가 아닌 81단계×5의 405계획·8,100문항을 확인한다.

`learner-fit`의 exact `learner_stage`는 `f-count5`, `f-quantity5`, `f-compare5`, `f-order10`, `f-split5`, `f-split9`, `f-join9`, `f-ten10`, `c1`~`c73`이다. 각 단계에서 다음 다섯 기준을 독립 기록한다.

- `language`: 실제 선택한 주제의 세 언어 지시와 결정 조건, 시험 지문에 약어를 쓰지 않는 규칙.
- `representations`: 소스의 계산·수량·빈칸 표상을 유지하고 그리기를 숫자 응답으로 몰래 바꾸지 않는다.
- `prerequisites`: 연령 규준 대신 실제 배운 우리 과정 기준을 사용하고 C0→C1은 10 이하의 작은 수로 제한한다.
- `reasoning-load`: 이전/현재/다음의 역할을 보존하며 다음 네 표본을 승급·약점의 근거로 사용하지 않는다.
- `response-mode`: 누르기·만들기·선택·순서 있는 숫자/음수/소수/복수 답의 입력 계약을 보존한다.

이 기록은 선택한 우리 과정의 소스 보존·표상·응답·분기 적합성 검수이다. 모든 교재와의 동등성, 학교 연령 표준화, 전 문항의 교육학적 효과, 실제 학생 관찰을 뜻하지 않는다.

검수 원자료는 E:의 비공개 산출물 `release-20261003/final/checks.json`, `final-independent-learner-fit.json`, `final-independent-release-review.md`, `goal-paths/goal-browser-release-final.json`에서 현재 소스 해시와 연결한다. 재실행 전의 실패와 변경 중 실행은 삭제하지 않으며 최종 PASS와 구분한다. `session-roles`의 기존 검사 범위는 C0~C37이고 `roadmap-sync`의 단계 차이 32건은 검토 보고 항목이다.

C48의 과거 13px 넘침은 이번 환경의 전체 실행 및 별도 0.7/1/1.5배·폰트 로드 후 측정에서는 재현되지 않았다. 인쇄 코드를 수정해 해결했다고 주장하지 않는다. 실제 PC 실물 인쇄는 별도 확인 사항이다.
