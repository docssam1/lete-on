## 결정 및 적용 범위

- 원장 답변 **“19”**: 실제 N-11은 「식과 숫자 카드」이므로 2회차에서 **19회차로 이동**. 2회차는 수 배열·이어 세기·점 잇기, magic 권 없음.
- 원장 승인: 레이아웃·폰트 크기 제안 수용. 기존 표지·캐릭터·삽화·15개 원본 유닛 파일은 유지.
- 19회차×60문항×3일. 1~18회차는 그림과 말, 19회차에 +·−·= 도입. 세로셈·10원 동전 뛰어 세기는 C0에서 제외.
- 기존 학생 회차 기록의 형식·내용을 변환하거나 삭제하지 않음. 새 편성은 같은 회차 번호에 적용되므로 재출력 내용은 개정판이 됨. C1~C73 과정 데이터 73개는 기준본과 JSON 완전 일치.

## 파일과 이유

- `data/courses.js`: 5개 인지 블록, 학교·독셈·적용 활동을 함께 재배치. 48+6+6=60을 고정. 활동별 6/12문항이며 부분 메타데이터 로더는 미완전 표시 후 출력 시 명시적으로 실패.
- `engine/c0-cognitive.js` 신규: C0 출력에만 수 범위·조사·동물 단위 적용. 점 잇기 5~10개, 평면 모양 종류 1~3가지, 수열의 실제 빈칸 위치와 정답 보존. C1 이상은 기존 생성기 그대로 호출.
- `app/exam.js`: C0 레벨별 제목·개념, 단원 경계를 지키는 3일 최적 분할. 그리기·연결·복잡한 도식은 한 쪽 최대 4문항. 프로필은 try/finally로 복원해 다른 과정에 남지 않음.
- `app/c0-paper.js` 신규: 12pt 지시문, 그리기 칸 약1.3배, 1·2·3일차 표시, 작은 회색 관리 코드, 연결 번호 숨김(정답지 유지), 보호자 안내. 앞18회 기호를 전체 수식 단위로 말로 바꾸고 반복 안내를 지면 위로 이동.
- `app/paper-examples.js`: 새 편성에서 드러난 빈 예시 보충(텐프레임 칠하기·몇째·격자·막대·수 규칙·짝·십자). 하나 큰/작은 수는 센 개수와 답 구분. 색의 좌우가 다른 가르기는 ordered로 검산. strip 규칙표의 열 좌표를 정확히 사용.
- `data/lang-think.js`: C0 실제19회 이해편의 상황·미지수·세 무리·수직선을10이하로 제한. 비교/변화 요약 구분. 비유아84조건 HTML 동일.
- `data/placement-plan.js`, `data/stages.js`: 유아8단계의 실제 출처 회차와 안내를 재배치에 맞춤. 진단20문항·6/10/4 유지.
- 네 진입 HTML: 새 C0 모듈 로드와 캐시 갱신. 생성 서버 runtime은 과정 메타데이터를 재빌드한 것뿐이며 DB/서버 함수 배포·실제발송 없음.
- 검사: `check-c0-cognitive.js` 신규, 기존 풀이예시·진단 검사의 관련 계약/회차 갱신.
