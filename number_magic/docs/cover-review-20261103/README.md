# 수의 마법 과정별 공통 학습지 표지 검수 (2026-11-03)

원장 지시(Codex 경유): 기존 과정별 표지 기준으로 검수하고 결함을 반영. 표지 정본(배경·색·캐릭터·글꼴·자리·이름칸)은 그대로 두고 **그림만** 과정 내용에 맞게 고쳤다.

| 파일 | 내용 |
|---|---|
| 01·02 | 고치기 전 전체 74과정 표지(유아·초등 / 중·고등) |
| 03·04 | 고친 뒤 전체 74과정 표지 |
| 05 | 실제 A4 PDF(ws.html 인쇄) 표지·안내 쪽 — 컬러 / 흑백(C0·C17·C31·C62) |
| 06 | 영어·중국어 제목, 긴 제목 줄바꿈, 빈 이름칸, 중1·중3 선택 심화 표지 |
| 07 | 휴대폰(390px) 화면 |

찍은 방법: `ws.html`을 연 뒤 실제 CSS 위에서 `NM_WORKSHEET_SERIES.front()`로 과정마다 다시 그려 표지 요소만 캡처. A4는 Chromium 인쇄 PDF를 `pdftoppm`으로 그림(흑백은 `-gray`).
