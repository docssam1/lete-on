## 작업 범위와 설계

문제의 수학 내용·답·난수 규칙·계정 권한·유아 타이머 정책은 바꾸지 않는다.
등록된 학습 내용을 찾고, 추천 위치에서 시작하고, 같은 유형을 풀이/인쇄하는 흐름을 고친다.

- 문제은행의 주업무: 유형 찾기 → 예시 확인 → 풀이 또는 인쇄.
- 탐색 갈래와 기존 손질된 유형명은 보존. 새 레벨은 threads에서 자동 연결한다.
- 검색은 전체 갈래, 빈 검색은 현재 탭. 검색 범위와 실제 결과 수를 명시한다.
- 검색과 탭 변경은 선택 및 학습지 코드를 지우지 않는다.
- 선택 후 모바일/키보드는 작업대로 바로 이동하며 목록 복귀를 제공한다.
- 목록/선택/작업대 위계를 구분하고, 새 장식 카드나 효과를 추가하지 않는다.
- 문제은행은 흰 읽기 면, 중립 배경, 청색 주행동, 16px 입력, 44px 조작 영역,
  명확한 선택·초점·빈 결과를 사용한다. 인쇄와 문제 그림은 별도 보존한다.
- 스토리 추천은 과정 지도와 같은 현재 과정에서 고른다. ‘처음부터 둘러보기’는
  추천과 별개이며 저장 진도나 시작점을 초기화하지 않는다. 모든 과정 자유 선택 유지.

## 다음 권고 — 남은 문제와 설계 방향

1. **질문과 생성기의 의미 대조:** MX4 표제 범위 불일치는 실제 생성 범위에 맞춰 수정했다.
   남은 점은 양의 제곱근과 ‘제곱근 전체’의 질문 구분이다. 특히 □² 형태와 양수 정답 계약을 함께 검토해야 한다.
   이번 연결 수정에서 문항 계약을 임의로 바꾸지 않았다.
2. **교육 편성 32관계 분류:** 첫 학습/복습/확장을 구분한 뒤 단계 안내를 조정한다. 모두 누락이나 오류로 취급하지 않는다.
3. **필즈·소마·KMO 진도 비교 — 보류:** 사용자 의도는 학습 속도로 해당 진도 수준을 안내하는 것이다.
   단순 교재→우리 과정 연결이 아니다. 사용자가 나중에 하자고 했으므로 이번에는 구현하지 않는다.
4. **배포 전 공개 범위 점검:** 기존 배포는 폴더 전체를 복사한다. 내부 Markdown·검수 문서의 공개/비공개 목록을 정한 뒤 배포한다.
5. **추가 기능은 그 뒤:** 제곱근 대소관계 등 작은 교과 공백, 이어서 분배법칙→곱셈공식→인수분해 실험실 순.

기존 할 일의 G0·G1은 정상 게임 노드이고, 유아 check/arena 생략은 기존 정책이다.
필즈·소마 세 파일도 승인 흐름이 달라 무조건 삭제/통합하지 않는다.
