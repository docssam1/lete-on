# 마을 지도 로우폴리 시안 (2026-11-08)

원장 요청 「마을 지도 고정 그림으로 시안 만들어」. 지금 쓰는 그림 지도(`assets/map.jpg`)를
Polyfork 무료 로우폴리 모델로 다시 지은 장면을 **한 장의 그림**으로 찍은 시안이다.
**아직 앱에는 넣지 않았다.** 원장이 고르면 `assets/map.jpg`만 바꾸면 된다.

| 파일 | 내용 |
|---|---|
| `map-lowpoly-draft.jpg` | 새 지도 2000×1342 (지금 지도와 같은 크기) |
| `pc-old.jpg` · `pc-new.jpg` | 실제 마을 화면 PC(1280×800) — 지금 / 새 지도 |
| `phone-new.jpg` | 실제 마을 화면 폰(390×844) — 새 지도 |
| `source/` | 장면 코드(`scene.js`)와 찍는 스크립트 |

## 자리 맞춤
건물은 손으로 놓지 않았다. `main.js`의 `TOWN_SPOTS`·`TOWN_GATES` 자리(화면 %)에서 땅으로
광선을 쏘아 그 지점에 세웠다. 그래서 지금의 누르는 자리·이름표·걷기 좌표를 하나도 안 바꿔도 맞는다.

| 장소 | 건물 |
|---|---|
| 챌린지 (언덕) | 망루 (Watchtower) — 언덕 위 |
| 프라임 | 2층 여관 (Village Tavern) |
| 학습지·시험 (극장 자리) | 돌 예배당 (Stone Chapel) |
| 어드밴스 | 2층 집·초가집·대장간 |
| 베이직 | 버섯 집 5채 (색 4가지) + 그네·미끄럼틀 |
| 옷장 | 천막 5개 + 장터 가판 |
| 동쪽 관문 | 풍차 (+ 물레방아·헛간) |
| 남쪽 관문 | 호수 선착장 + 보트 |
| 서쪽 관문 | 이정표 |

## 라이선스
- 무료 로우폴리 모델: 상업적 사용 가능, 출처 표시 필요 없음(모델 파일 머리말·polyfork.dev/licensing).
- **우리 저장소에는 그림(렌더 결과)만 둔다.** 모델 코드 파일(`*.mjs`)은 재배포 금지라 올리지 않는다.
  다시 만들 때 `source/scene.js`가 쓰는 모델을 `https://polyfork.dev/cdn/<id>.mjs`에서 받아 `m/`에 둔다.
- 쓴 모델: Medieval Village 키트(망루·여관·예배당·2층 집·초가집·대장간·풍차·물레방아·헛간·장터·우물·
  가로등·건초·울타리·참나무·사과나무·덤불·돌·풀), 버섯 집, Campground 키트(천막·소나무·선착장),
  Neighborhood 키트(그네·미끄럼틀), 해적 키트(보트), 나무다리.

## 다시 찍기
1. `npm pack three@0.180.0` → `lib/package/`, 모델 `.mjs` → `m/` (scene.js 안의 이름 그대로)
2. 그 폴더에서 `python3 -m http.server 8811` → `node shot.cjs map-lowpoly.jpg`
3. `node app-shot.cjs map-lowpoly.jpg <폴더>` — 실제 앱 화면에 끼워 PC·폰 캡처(지금/새 지도)

## 앱에 넣을 때
`assets/map.jpg`를 이 그림으로 바꾸고 styles.css 캐시 꼬리표를 올린다. 지도를 쓰는
다른 자리(`styles.css`의 첫 화면·온보딩 배경)도 같은 그림을 쓰게 되니 함께 확인한다.
