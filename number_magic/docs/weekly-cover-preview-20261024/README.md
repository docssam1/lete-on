# 수의 마법 주간 학습지 표지 비교본

후속: 원장님이 ‘유아·초등은 우리 캐릭터, 중·고등은 이 디자인, 레벨·월별 전체 학습지 시리즈’로 방향을 확정했다. 이전 표지 선택 질문은 이 정정으로 대체됐다. 실제 교재 미리보기는 `../worksheet-series-preview-20261024.html`, 운영 모듈은 `app/worksheet-series.js`와 CSS다. 아래는 이전 시안 시점의 기록이다.

2026-10-24, Mac Codex. GFIELD 교재 디자인 스킬과 기존 `fields-classic/question-bank/design-draft/covers.html`의 A/B/C 틀을 참고했다. 운영 renderer·문항·속도·회원·문자 발송 코드는 변경하지 않았다. 표지 적용 방식에 대한 사용자 선택 대기 중이다.

- 실제 과정명: 공식 과정 로더에서 추출한 `catalog.json`(유아/구구/나눗셈/정수/제곱근/다항식/명제/극한/중3 선택 심화).
- 그림: 직접 작성한 SVG 수 배열·묶음·소인수분해 나무·8×8 정사각형·넓이 모형·함수 그래프. 생성형 이미지 API 사용 없음.
- 글꼴/로고: 기존 수의 마법 자산. 텍스트는 이미지에 포함하지 않는다.
- 이름/날짜/속도 입력은 표지 비교용이다. 이 시안에서는 실제 문항 배정을 바꾸거나 실학생 상태를 저장하지 않는다.
- 기존 운영 학습지는 공통 생성기/편집 틀을 사용하고 저장된 개인 계획에 따라 범위·속도·심화·문항 수를 배정한다. HTML/PDF의 이름·주차 표시는 문자열 삽입이며 AI 생성 요청이 아니다. 문자비/서버·Storage 사용량과는 구분한다.
- 현재 운영 SMS용 member resolver는 비식별 설정만 전달하므로 웹 표지는 이름이 빈칸일 수 있다. PDF batch 경로는 `n`으로 받은 이름을 표시한다. 이번 시안을 근거로 SMS 웹 표지에도 이미 이름이 자동 표시된다고 보고하지 않는다.
- 검증: 1440px/375px, 9개 과정×3안의 제목·부제/이름 영역·가로 넘침 검사, A4 크기의 중3 B안 시각 확인. B안 그림이 발행처 줄에 닿던 것을 수정했다. 표지 쪽 번호 없음. 실제 PDF 파일을 생성한 검사는 아니며 A4 print media 렌더를 확인했다.
- 근거: 대화 시각화 폴더 `nm-weekly-cover-review-20261024/`의 비교 이미지·A4 이미지·검사 보고서.

`index.html`을 로컬 HTTP 서버로 열어 비교한다. 운영 적용은 사용자가 고른 방식으로 후속 진행한다.
