# 학습 시작점 진단 — 고정 20문항 설계

## 사용자 기준

- 기존 넘버스 커리큘럼을 유지한다. 진단을 이유로 과정·학습 레벨·점수·코인·완료 기록을 바꾸거나 과정을 잠그지 않는다.
- 한 번의 진단은 이전 진도 6문항(30%), 현재 진도 10문항(50%), 다음 진도 4문항(20%)이다. 시작 전에 전체 문항을 고정하며, 한 문제를 맞혔다고 멀리 도약하지 않는다.
- 유아는 수 세기, 수량과 숫자, 많고 적음, 수의 순서, 5까지 가르기, 9까지 가르기와 0, 모으기, 10의 짝꿍을 분리한다. 유아를 한 단계로 뭉치거나 C0 회차 번호를 능력 순서로 간주하지 않는다.
- 소마 첫 연산 시험은 **5세 11월 입학 참고**, 필즈 7세 1차는 **7세 11월 입학 참고**이다. 이전의 ‘필즈 6세 말’ 해석은 사용하지 않는다.
- 원장 설명(2026-10-17 재확인): **빠른 아이들은 6세 3월에 두뇌로 과정 1을 하고 이후 한 달에 1과정씩 진행한다.** 사진에는 나이·월령 기준이 보이지 않는다. 위 입학 참고와 별도이며 모든 6세의 규준이나 우리 과정의 강제 편성이 아니다.

## 진입과 범위

현재 진입 화면의 세 경로는 **나이·학년으로 / 완료한 교재로 / 처음 시작해요**이다.
나이를 먼저 선택하고 실제 학년이 다를 때만 바꾼다. 나이·학년만으로 문제 수준을 확정하지 않는다.

교재 경로에서는 **마지막으로 완료한 교재**를 선택한다. 권·레벨·학습지 번호 자유 입력과
‘진행 중’ 선택은 진입 화면에 두지 않는다. 소마셈은 P/K/A/B/C의 1~8권과 D의 1~6권을
목록으로 고른다. 두뇌로는 Level 1/2/3을 고른 다음 해당 Level의 **마지막 완료 교재 과정**을
반드시 고른다(각각 1~10/11~16/17~25). 값은 `selection.bookCourseNumber`에 숫자로
저장하며, Level·교재를 바꾸면 번호와 직접 고른 진단 범위를 비운다. 결과·로드맵과 인쇄본에서
교재 표기와 이 앱의 진단 범위를 구분한다. 교재 선택은 이후 로드맵 비교의 입력 자료다.
새로 고른 교재에만 `selection.bookStatus: completed`를 기록한다. 이전 화면의 ‘공부한 교재’
저장값은 완료 확인이 아니므로 기준 선택 화면에서 다시 고르게 하고, 이미 답한 20문항은
보존한다. 과거 결과의 교재 표기는 ‘기록된 교재 · 완료 여부 미확인’으로 구분한다.

교재의 권 번호와 앱 과정 번호를 1:1 대응시키지 않는다. 권별 내용·판본 및 앱 문항과의 대조가
끝나지 않은 경우 보호자가 **완료한 내용에 가장 가까운 앱 진단 범위**를 목록에서 확인한다.
진단 20문항은 그 앱 범위의 이전 6/중심 10/다음 4문항으로 고정된다. 따라서 지금의
6/10/4가 각각 교재의 앞권/완료권/다음권에서 출제됐다는 뜻은 아니다. 완료한 권을 골랐다는
사실만으로 숙달·승급·월별 학습 속도를 추정하지 않는다. 엄격히 확인한 대표 주제 두 개만
자동 시작점 후보를 제시하고, 나머지는 실제 배운 내용에 맞춘 앱 범위 선택이 필요하다.
상세 출처·남은 확인은 `placement-book-provenance.md`에 있다.

나이·학년 경로는 나이와 학년에 따른 후보 시작점을 제시한다. 실제 배운 범위가 다르면
‘다른 내용부터 확인하기’에서 시작점을 바꿀 수 있다. **학교 학기·단원 전체와 우리 과정이
동등하다는 표는 아직 없다.** 유아 8개 기초는 세부 주제 진단이지만, C1 이후 선택은 기존
과정 안의 여러 연산 주제를 함께 확인한다. 특정 학교 단원 하나만의 정밀 표준 시험으로 소개하지 않는다.

첫 기초에서 ‘이전’은 같은 기초의 더 작은 수를 확인한다. 마지막 과정에는 없는 다음 교육과정을 만들지 않고 같은 과정의 추가 확인으로 표시한다.

## 독립 응답과 결과

학습용 위젯은 정답을 자동 완성하거나 개수를 알려줄 수 있으므로 진단에 그대로 쓰지 않는다. 별도 진단 표상은 틀린 답도 제출할 수 있어야 하며 힌트·재시도 자동 통과·정답 피드백을 진행 중에 주지 않는다.

- 그림 누르기: 선택 개수뿐 아니라 대상 그림을 정확히 선택했는지 검증한다. 개수는 진행 중 표시하지 않는다.
- 수량 만들기: 목표와 다른 개수, 0개도 제출할 수 있다. 목표 개수에서 자동 제출하지 않는다.
- 비교: 저울의 기울기로 답을 알려주지 않는다.
- 가르기·모으기·순서·10의 짝꿍: 보여 줄 값과 입력할 빈칸을 분리한다.
- 수식: 기존 생성기의 실제 입력 대상을 표시한다. 분자만 쓰는 문항과 분모·대분수 배열 문항을 구분한다. 음수·소수·9자리 숫자·각 칸의 음수를 허용한다.
- 학습용 계산 요령과 중간 계산값은 진단에 표시하지 않는다. 필요한 답 형식만 남긴다. 주어진 분모, 기약분수와 약분 전 분수, 몫과 나머지의 순서, 특정 자리 숫자 등 정답을 결정하는 조건은 한국어·영어·중국어에서 보존한다.
- 모름은 오답과 구분해 저장한다. 같은 제출은 한 번만 기록하며 화면 교체 뒤의 연속 탭도 차단한다.
- 새로운 문제와 결과는 지시문부터 읽도록 화면 위에서 시작한다. 같은 기준 선택 화면의 입력 변경은 현재 스크롤 위치를 유지한다.

결과는 표본에 근거한 연습 제안이다. 20문항으로 전체 과정의 숙달이나 입학 합격을 선언하지 않으며 임의의 시간 컷으로 능력을 낮추지 않는다. 유아 결과는 주제를 먼저 보여주고 실제 활동 회차는 별도 기록한다. C0 지도 시작 회차는 능력 등급이 아니다.

후속 목표 경로에서는 **선택한 본진도와 보강·재확인 주제를 분리**한다. 기존 채점기의 보수적 추천은 참고로 보존하고, 한 번의 오답이 본진도 전체를 바꾸지 않게 한다. 세 목표와 주당 횟수는 학습 제안·로드맵에 연결되며 문항·채점·기존 완료 기록을 바꾸지 않는다. 목표별 자동 학습지 편성이나 정확한 외부 목표 대응이 끝났다는 뜻은 아니다. 자세한 기준은 `placement-goals.md`를 본다.

## 구현과 검수 경계

- `data/placement-plan.js`: 실존 생성기·고정 레벨 참조, 중복 없는 계획, 채점과 추천. 빈/가득 찬 열 칸은 진단 전용 단일 대상 변환으로 구분하며 학습 레벨을 추가하지 않는다.
- `data/placement-books.js`: 짧은 공식 주제 메타데이터 및 확인 필요 상태. 교재 문항·풀이·도판은 싣지 않는다.
- `data/placement-paths.js`: 공통 진단 위의 목표별 학습 제안. 본진도·오답 보강·모름 재확인·다음 주제 미리보기를 구분한다. 검증되지 않은 도달 기간은 수치로 만들지 않는다.
- `app/placement-ui.js` / `.css`: 세 진입 경로와 독립 응답 화면. `main.js`의 실제 진단 진입은 이 모듈만 사용한다. 저장된 구형 도약형 진단은 새 기준 선택부터 다시 시작한다.
- `scripts/check-placement-plan.js`: 2,800개 계획, 6/10/4, 수학값, 출처 보존, 음수·배열·모름·중복·유아 추천 반례와 답 형식·필수 조건 4,645건. 여기에는 질문 분기 1,140건, 정수 인수분해 정답 유일성 1,000건, 일대일대응 정답 유일성 1,000건, 선행 0 입력 검증이 포함된다. 브라우저 형태의 VM 검사는 실제 화면 검수와 다르다.
- `scripts/check-placement-integration.js`: 교재 대응 ID, 로딩 순서, 입력 파싱, 새 진입 경로와 화면 전환 스크롤 계약 7건. DOM 모형 검사는 실제 브라우저의 좌표·스크롤 검수를 대신하지 않는다.
- `scripts/check-placement-paths.js`: 81시작 범위·7응답 패턴·세 목표/네 세부 목표·주 1/2회 7,938조합. 목표별 문항·채점 불변, 본진도 유지, 실제 보강 위치, 모름 분리와 기간 미확정 상태를 확인한다. 실제 UI와 학습 효과 검수는 별개다.

모바일 390px·데스크톱 실제 화면, 진짜 더블클릭, 입력 가시성, 기존 진도 보존, 기존 8개 회귀 검사를 별도로 확인한다. **로컬 구현 / 커밋 / main 병합 / 배포는 별개 상태**이며 이 문서 자체는 배포 완료 증거가 아니다. 현재 검수 기록은 비공개 E: 검수 산출물에 보존하며 private 원자료와 절대 경로는 공개 저장소에 넣지 않는다.

## 인쇄용 시험지 (2026-10-04, Claude)

`placement-sheet.html?b=<시작 범위 id>&l=ko|en|zh&seed=<문자열>&n=<이름>` — 온라인 진단과 **같은 `NM_PLACEMENT_PLAN.build(b, seed)`의 20문항**을 종이용으로 그린다(문항·정답·이전6/현재10/다음4 구성 불변). 교재 경로에서는 `series`, `step`, 두뇌로인 경우 `bookCourseNumber`를 추가해 선택한 **마지막 완료 교재**를 종이에 표시한다. 이 교재 표기는 `b`의 앱 진단 기준 주제와 별도로 보이며 문항 생성에는 쓰지 않는다.
- 틀은 주간 학습지(매거진형)와 같다: 청록 띠·금 줄·명조 제목·푸터 코드(`PL-<범위>-<seed>-<언어>`). `app/exam.js`의 `.nm-mzs-*`·`.nm-w2-page` 스타일을 그대로 쓴다.
- 급별로 다르다(원장 2026-10-04 "유아·초등·중등이 달라야지, 단 잡지형 유지"): 유아 기초 8범위는 쪽당 5문항·큰 그림 한 열, C1~C16(저학년)은 쪽당 7문항 한 열, C17~C28(중학년)과 중등 이상은 쪽당 10문항 두 열. 이전 구간이 유아 기초 그림인 범위(C1 등)는 문항 무게로 쪽을 채운다.
- 종이에서는 탭·버튼 대신 ○ 하기·쓰기 칸으로 답한다. 학생 쪽에는 구간(이전/현재/다음) 표시가 없다. 마지막 쪽이 보호자·선생님용 정답·구간·채점표다.
- 화면 아래 ‘채점 입력’에서 ○/×/모름을 넣으면 온라인과 같은 `summarize`로 추천 시작 회차를 보여 준다(인쇄에는 나오지 않음).
