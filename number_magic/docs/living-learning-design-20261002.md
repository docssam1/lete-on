# 살아 있는 수 교구 · 화면 개편

범위: N-07(10의 보수), M-01(양수·음수), 학습 화면 글씨, 마을 왕복. 문항 수·과정·진도는 변경하지 않는다.

- 화면의 일: 구경이 아니라 **예측 → 직접 조작 → 변하지 않는 관계 확인 → 다른 수에 적용**.
- N-07: 8·9·7·6개에서 10을 채우는 수를 먼저 생각한다. 입체 낱개를 하나씩 옮기면 열 칸과 식이 동시에 변한다. 기존 수와 옮긴 수는 색과 위치로 구별한다. 10을 넘겨 넣지 않는다.
- M-01: 붉은 양수·검은 음수를 한 개씩 짝짓는다. 0인 짝은 옆으로 옮겨 두고 남은 수를 확인한다. 양수와 덧셈, 음수와 뺄셈을 동일시하지 않는다. 양·음·0 결과를 모두 다룬다.
- 안내자: 마을의 `char3d` 숫자 0 누미를 공유한다. 실제 입체 형상·관절·시선·짧은 반응으로 안내한다. 이미지 평면을 회전시키거나 읽는 동안 교구를 저절로 바꾸지 않는다.
- 구성: 제목/한 줄 물음 → 실제 교구 → 현재 식 → 조작/되돌리기 → 다음 개념. 같은 정지 그림과 만화를 연이어 반복하지 않는다. 역사 설명은 접어 두되 내용은 확인 가능하게 한다.
- 연령: 열린 유닛을 기준으로 유아/초등/중고등 글씨를 고른다. 문장은 읽기 쉬운 고딕, 수식은 기존 수학 글꼴. 휴대폰에서 네 컷을 3+1로 밀어 넣지 않는다.
- 접근성: 화면 교구 탭과 동등한 HTML 버튼, 키보드 조작, 읽어 주기용 현재 수, 다시 하기. 동작 줄이기는 같은 계산을 즉시 표시한다. WebGL 실패도 조작·계산은 그대로 가능하다.
- 성능: 화면을 떠나면 GPU·이벤트·관찰자를 해제한다. 화면 밖/다른 탭에서는 멈춘다. DPR 1.5, 그림자 1024 이하. 지도 복귀는 카메라와 위치를 복원한다.

금지: 평면 캐릭터를 입체라고 부르기, 의미 없는 반복 춤/반짝임, 조작과 식의 불일치, 근거 없는 어원을 역사 사실로 단정하기, 기존 인쇄물/문항량 조절 변경.

완료 증거: 수 개수·0쌍 불변식 자동 검사, 실제 앱에서 N-07/M-01 조작, 390px·태블릿·PC, 동작 줄이기·WebGL 미지원, 마을 왕복, 필수 회귀 검사. 전 유닛 3D 전환을 완료했다고 보고하지 않는다.
