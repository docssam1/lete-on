# 고정 20문항 진단 — 검수와 남은 범위

2026-10-03 로컬 작업 기록. 공개 사이트 반영이나 배포 완료 보고가 아니다.

후속 목표 경로 및 영어 교과 용어 정정을 포함한 배포 계약·최종 검사 연결은 `placement-release-20261003.md`에서 구분한다. 아래 이전 실행과 C2 해시는 당시 검수 근거로 보존한다.

**후속 목표 경로 추가:** 아래 Final6 해시·브라우저 기록은 세 목표를 넣기 전의 고정 20문항 검수이다. 목표 선택·본진도/보강 분리·로드맵 연결·재진입 보존을 추가한 뒤의 범위는 `placement-goals.md`의 후속 검수 기록으로 구분한다. 기존 진단 코어는 같은 C2 해시지만 UI·main·HTML은 후속 변경됐으므로 이전 UI 해시를 현재 버전 해시로 사용하지 않는다.

## 구현 범위

- 기존 커리큘럼·생성기·레벨은 유지했다. 새 학습 레벨은 추가하지 않았다.
- 유아 8개 기초와 기존 C1~C73을 시작 범위로 제공한다. 계획은 이전 6 / 현재 10 / 다음 4문항으로 고정한다.
- 교재, 학교 교과 진도, 실제 배운 내용의 세 진입 경로를 제공한다. 연령만으로 난도를 확정하지 않는다.
- 교재 선택 186조합 중 자동 후보는 엄격히 확인한 2개 주제의 진행 상태 6조합뿐이다. 나머지 180조합은 실제 배운 내용 확인이 필요하다. 자동 대응이 전부 완성된 상태가 아니다.
- 소마 5세 11월 입학, 필즈 7세 11월 입학, 두뇌로 6세 3월 상위권 사례를 서로 다른 참고선으로 기록했다. 입학 합격·공통 연령 규준으로 사용하지 않는다.

## 실제 화면 검수 원칙

화면 전환과 마지막 일대일대응 지문 수정 후 코드 고정 상태에서 새 계획 검사 2,800건·VM 동등성 84건·조건 검사 4,645건, 교재 선택 186조합·입력 9종·스크롤 계약 모형 7건, 전체 81시작 범위×100시드=8,100계획, 구문 검사 6종과 diff 검사를 다시 실행해 통과했다. 실행 전후 진단 관련 파일 6개 해시는 동일하다.

지문 보완 전후 8,100계획·40,500응답 시나리오를 비교해 수식·정답·표상·문항 선정·추천이 불변임을 확인했다. 이 결과는 학습 지문에서 추출한 명확한 계산 단서의 중립화 근거이며, 원래 수식에 포함된 모든 학습용 발판까지 제거했다는 뜻은 아니다.

390px·1280px에서 실제 앱 진입, 독립 응답, 모름·오답 구분, 각 입력칸의 음수, 9자리 숫자, 연속 제출 차단, 결과와 지도 복귀, 진도·코인 보존을 확인한다. 별도 생성기 렌더링 표본은 실제 20문항 흐름 검수와 구분한다.

이전 실행에서 폰트 캡처 시간 초과와 검수 포트 충돌이 있었으며 원로그를 지우지 않았다. 중간 소스 변경이 있었던 실행은 최종 소스 동결 통과로 집계하지 않는다. 최종 코드와 연결되는 검사 결과·전후 파일 해시·스크린샷은 E: 검수 산출물에 보존한다.

학습 UI 검토에서 발견한 계산 단서, 작은 분수 숫자와 휴대폰 입력 잘림을 진단 전용 코드에서 보완한다. 학습 화면의 개념·예시를 삭제한 것이 아니다.

일반 수식 영역은 모바일 26px·데스크톱 34px로 확대했다. KaTeX 인라인 분수의 분자·분모는 그 0.7배인 18.2px·23.8px이며, `dfrac`나 유아 큰 글씨와 같은 크기라고 보고하지 않는다. 긴 식은 수식 영역 안에서 가로로 이동해 읽도록 했으며 문서 전체가 옆으로 밀리지 않는지 별도 확인한다.

화면 전환 수정 전 고정 코드의 일반 브라우저 36사례·786검사는 통과했지만, 별도 자연 클릭 검수에서 이전 화면의 스크롤 위치가 남아 지시문을 가리는 결함 4건을 확인했다. 자동 기능 통과만으로 화면이 완성됐다고 보고하지 않는다. 새 문제·결과로 전환할 때만 위로 이동하도록 보완했고, 같은 기준 선택 화면의 스크롤은 유지한다. 이 수정 뒤 실제 브라우저 재검수 결과를 별도로 연결한다.

수정 뒤 자연 클릭 전환은 두 폭에서 10검사 통과했다. 새 문제·결과의 스크롤 0, 지시문·결과 제목의 가시성, 같은 기준 선택 화면의 스크롤 유지와 기존 기록 보존을 확인했다. 추가로 360×640·390×720의 유아 가르기·수 세기·다중 음수 입력 6흐름·140검사가 통과했다. 작은 화면은 필요한 만큼 세로로 스크롤해 답 버튼에 도달하는 방식이며, 모든 요소가 한 화면에 동시에 표시된다는 뜻은 아니다.

화면 전환 수정 후 일반 36사례의 원실행은 786검사 중 785통과였다. 남은 1건은 ‘이전 클릭 좌표가 다음 제출 버튼과 겹친다’는 검수 전제였고 원래 실패 기록을 유지했다. 폰트와 좌표가 안정된 후 실제 버튼을 맞추는 양폭 재검수 28건은 통과했다. 같은 좌표 더블클릭 직후·지연 후 응답은 1건, 새 문항 입력 오염은 없었다. 별도 추적에서는 폰트 로딩 전후 모바일 버튼 위치가 35.5px 바뀌었고 스크롤·포커스는 변하지 않았다. 실물 기기와 폰트 로딩 전 화면 안정성 전체의 검증은 남아 있다.

관련 수식·입력·교재 후보 22사례·398검사와 세 언어 순환소수·긴 식 14사례·208검사도 통과했다. 뒤쪽의 생성기 제한 렌더링은 실제 전체 진단 경로와 구분했다. 이 육안 검수에서 추가로 발견한 일대일대응 유형의 풀이 설명은 마지막 단일 지문 보완 대상으로 따로 확인했다.

마지막 보완은 MD127@3 한 곳의 지문만 바꿨다. 풀이 요령인 양 끝 대응 방법을 제거하되, 일대일대응·실수 구간·제시된 계수 부호·a, b의 입력 순서를 남겼다. 구간과 부호에서 계수를 독립 계산한 1,000시드 검사가 통과했다. 변경 전후 8,100계획 중 이 지문 100개만 변경됐고 수식·정답·문항 선정·표상·빈 답 템플릿·중복 서명은 동일했다. 40,500개 결과·추천 시나리오도 동일했다. 앞선 광범위 화면 결과는 동일한 UI 등 5개 파일 및 이 비교 근거로 연결하고, 이 마지막 유형의 새 지문 화면은 최종 코어로 별도 재검수한다.

최종 코어의 MD127@3 화면 재검수는 세 언어·두 폭의 대표 6사례 240검사와 실제 기준 선택·시작·12문항 이동의 2사례 48검사가 통과했다. 대표 사례는 전체 C55 계획의 문항을 네이티브 UI로 보여 준 표본이며, 실제 경로 2사례는 검수에서만 초기 시드를 고정했다. 두 실행의 진단 파일 6개 해시는 불변이고 런타임 예외·외부 쓰기 시도는 없었다. 부호·일대일대응 조건, 독립 계수 계산, a·b 입력 순서와 긴 식의 내부 스크롤을 확인했다. 최초 포트 충돌 0사례와 초기 시드 전제 실패 2건은 원로그에 보존했다.

최종 코어 SHA-256은 `C2D039E133AF991D771D5FABCFBF66CBA7DD85F96E3D233D6DD96A89011B1728`, UI는 `827F150376864797AA9C1E03B6117C153E804ADD2A001E434382126C878EFF5F`이다. 진단 자동 검사 10개 작업의 최종 통과 기록과 소스 전후 해시는 `final6-placement-checks.json`에, 마지막 브라우저 검수의 범위와 실패·재시도 연결은 `FINAL6.md`에 별도 보존한다. 이 증거는 기존 필수 인쇄 검사 실패를 없애거나 공개 배포를 뜻하지 않는다.

선택 작화 감지용 `cube-blue.png`의 기존 404와 외부 정적 리소스 네트워크 오류는 원로그에 남겼다. 진단 화면의 문항 그림에는 영향이 없었지만, 이를 전체 자산·네트워크 무오류나 3D 마을 렌더 통과로 보고하지 않는다.

## 아직 완료로 보고하지 않는 것

설계 기준은 `placement-design.md`, 교재 출처와 대응 한계는 `placement-book-provenance.md`에서 확인한다. 원본 시험 문항·도판·학생 데이터·비공개 원자료 경로는 공개 저장소에 싣지 않는다.
