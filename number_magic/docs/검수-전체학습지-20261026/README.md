# 수의 마법 전체 학습지 검수 — C1~C73 + 중등 선택 심화 (2026-10-26)

> 원장 지시: 「C0 외 같은 방법으로 검수」(Drive `수의마법-전체학습지-검수-20261026/01-과정별-PDF`).
> 방법은 C0 때와 같다. 실제 학습지를 전부 다시 출력해 글자본으로 만들고, 한 회차씩 끝까지 읽었다. 정답은 직접 계산해 대조했고, 문제가 보이면 생성 코드에서 원인을 찾았다.
> 고칠 일은 GPT 작업 지시서 `../gpt-작업지시-C1-C73-학습지-수정-20261026.md`에 있다.

## 범위와 방법

- **대상**: 정규 C1~C73(73과정)과 중1~중3 선택 심화(M1E~M3E). 미리보기 화면 기준으로 **379회차·수업**이다. C0는 따로 끝냈다(`../gpt-작업지시-C0-인지순서-재편-20261025.md`).
- **출력**: `scripts/render-worksheet-text.js`. 미리보기 화면(`docs/worksheet-series-preview-20261024.html`)이 `ws.html`에 붙이는 값을 그대로 쓴다.
  - 중등·고등: `hp=1`. 이 값이 빠지면 학생이 받는 「수업」 묶음 대신 옛 세션 낱장이 나온다.
  - 선택 심화: 배달 계획(`dv`·`dp`).
- **읽기**: 10개 구간으로 나눠 회차 전체를 읽었다. 구간별 원문은 이 폴더의 `B1`~`B10` 파일이다.
  - 정답 대조: 유형마다 5문항 이상 직접 계산했다. 문장제·언어사고력·마법 노트 핵심 체크는 전부 계산했다.
  - 화면 확인: 그림이 문제인 곳은 화면을 찍어 확인했다.
- **Claude 재확인**: 영향이 큰 지적은 코드와 화면으로 다시 확인했다. 아래 「확인」 열의 ✔가 그것이다.
- **자동 검사**: `scripts/check-worksheet-text.js`. 조사, 조판 흔적, 하루 분량, 정답 정렬을 잡는다.

### 읽을 때 주의 — 검수용 출력에서 생긴 착시 두 가지

1. **회차끼리 숫자가 똑같은 것은 결함이 아니다.** 문항 숫자를 정하는 시드는 「주차+과정+칸 번호」이고 회차 번호는 들어가지 않는다(`app/exam.js:9054`). 검수용으로 모든 회차를 같은 주(W43)로 뽑으면 같은 칸이 같은 숫자로 나온다. 실제 학생은 회차마다 다른 주에 받는다.
   - 다만 미리보기 화면과 Drive의 과정별 PDF도 W43 하나로 만들어져 있어서, 그것을 보는 사람에게는 반복으로 보인다(→ 지시서 P1-12).
   - 결함으로 센 것은 두 가지뿐이다. 같은 유형·레벨이 진전 없이 되풀이되는 것, 한 장 안의 중복.
2. **중등·고등은 「수업」 단위다.** C29~C73은 수업 하나가 학습 2~3개를 묶고, 5일 또는 2~3일로 나눈다. 처음 출력에서 `hp=1`이 빠져 옛 낱장을 읽었다. B6·B7·B9·B10 구간은 실제 배부본(`hp=1`)으로 다시 확인했고, 배부본에 없는 지적은 지웠다.
