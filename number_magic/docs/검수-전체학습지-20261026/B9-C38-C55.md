## C43 고차방정식
- [발문누락] [상] MD101-L1/L2/L3 — 무엇을 구하는지가 문제에 없음(공통 원인 1, 생성기 mid18.js:118-123).
  - x³−5x²+6x=0 → 답 0 (가장 작은 근)

1. **발문(prompt)이 인쇄본에서 사라짐** [상] — 원인 `number_magic/app/exam.js:5080`.

   - 영향: C40(MD96), C41(MD98), C43, C44, C45, C46, C47, C50, MD99·MD118.
   - 고칠 방향: 인쇄할 때 프롬프트를 문제 머리에 찍음. 종류가 섞이는 생성기는 tex 안에도 종류를 넣음.
2. **개념 글의 `<`가 지워짐** [상] — `exam.js:5373` `stripConceptTags`가 `/<[^>]+>/g`로 「x<3 … x>」 구간을 태그로 보고 지움.

   - `M-29.js:47`의 `&lt;`, M-107.js:37·M-108.js:36-37의 `<` 문구도 같은 계열.
   - 고칠 방향: 진짜 태그만 지우는 패턴으로 바꾸거나, 데이터에 `\lt`로 적음.
