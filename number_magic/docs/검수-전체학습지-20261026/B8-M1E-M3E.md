## 먼저: 받은 글자본(clean/M?E-*.txt)은 심화 학습지가 아니다

`scratchpad/renderall.js`는 심화 과정을 `ws.html?c=C31&s=N`처럼 **기본 과정의 N번째 회차로** 찍었다. 미리보기 페이지(`number_magic/docs/worksheet-series-preview-20261024.html` 38~39행)가 붙이는 배달 계획 값(`dv`·`dp`·`k`·`cad`·`amt`, `extensionAnchor`)이 빠졌기 때문이다. 그래서 받은 글자본에 생긴 문제는 다음과 같다.
- clean/M1E-r01의 제목은 「부호와 괄호의 종합 계산」인데 내용은 C31-r01과 똑같다(MD7-L1·MD8-L1·MD47-L3).
- C34는 회차가 9개뿐이라 M2E-r10~r12가 모두 C34 1회차로 다시 돌아간다.

그래서 미리보기 페이지와 같은 값을 붙여 36회차를 모두 다시 찍었고, 아래 검수는 이 자료로 했다.

- 원문: `…/scratchpad/mxe/out/*.txt`

## 구간 공통 문제

1. **[상] 심화 설계 자체(`data/middle-extension.js:11~54` PLANS)**
   - 심화는 「기존 고급 레벨을 골라 다시 묶은 것」이다(파일 70행 contentNote가 그렇게 밝힌다). M1E·M2E는 정규 레벨을 반복하고, M3E는 다음 과정(고1)을 앞당긴다.
   - 「종합·연결」 문항은 한 개도 없다. 유형 셋을 따로 나열할 뿐이다.
   - 같은 레벨이 반복된다:
     - M1E MD49@3 6회

     - M2E MD63@3·MD72@3·MD50@4 3회씩
     - M3E MD19@8·MD20@6·MD93@3·MD94@3 2~3회
