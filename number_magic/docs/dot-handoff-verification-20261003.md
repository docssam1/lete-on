## 구현된 동작과 수학 불변식

### 마을

- 지형·길·장소 간격을 1.35배 확장하고 건물의 실제 크기는 유지한다.

- 안내 마법사는 기존 승인 자산을 사용하며 첫 안내는 “어디로 가 볼까?”이다.
- 조이스틱은 흰색 반투명 148px 원판·64px 손잡이, 안전영역 여백을 사용한다.
- 단일 포인터 소유권·영역 밖 capture·두 번째 손가락 무시·취소/blur/메뉴 진입 시 정지/중앙 복귀를 적용했다.
- 키보드와 조이스틱이 같은 충돌·시간 기준 이동 함수를 사용한다. 건물·나무·바위·분수와 물 경계를 확인한다.
- 방문 후 카메라·플레이어·장소 선택 및 학습 목록의 스크롤·초점을 복원한다. 기존 2D 화면을 3D 뒤에 남겨 두지 않는다.

### 8+7

- 조각 ID는 L01–L08·R01–R07이며 선택한 오른쪽 조각 자체가 이동한다. 새 조각을 대신 만들지 않는다.
- 한 개를 옮긴 9/6 상태에서는 식이 여전히 `8 + 7 = ?`다.
- 두 개 이동 후 `8 + 7 = 8 + 2 + 5`, 학습자의 10 묶음 확인 후 `8 + 2 + 5 = 10 + 5`, 답 확인 후 `10 + 5 = 15`이다.
- 장면 전환은 앞 장면을 닫고 새 ID 집합으로 시작한다. 15개를 14개로 슬쩍 바꾸지 않는다.
- 예상·선택·이동·묶음 확인·직접 답 입력·뜻 확인이 필요하다. 자동 재생으로 완료하지 않는다.

### 정수

- 처음 수는 출발, 뒤 수의 부호는 보는 방향, 가운데 연산은 앞으로/뒤로 걷기다.
- −2+(−3): 0→−2, 왼쪽을 보고 앞으로 세 칸, −3→−4→−5.
- +2−(−3): 0→+2, 왼쪽을 보고 뒤로 세 칸, +3→+4→+5. 오른쪽으로 돌아서 앞으로 가는 것으로 바꾸지 않는다.
- 준비 이동과 본 걸음을 분리하고 −8~8의 고정 눈금·0을 유지한다. 실제 관절 있는 사람 모델의 앞뒤·신발을 사용한다.
- “플플·마마는 플, 플마·마플은 마”는 연산과 뒤 수 부호를 합친 **이동 방향**이다. 결과의 부호를 정하는 규칙이라고 설명하지 않는다.

### 최대공약수·최소공배수

- 6개와 8개는 따로 나눈다. 공통 후보 1·2를 찾고 학습자가 최대 2를 고른다.
- 배수 두 길은 같은 0·같은 축척이다. 0이 아닌 첫 만남 24를 학습자가 확인한다.
- 두 발견 후에만 새로운 U01–U48의 6×8 배열을 열고, **2개씩 24묶음**으로 다시 묶는다. 24개씩 2묶음이 아니다.
- 휴대폰에서도 48개를 유지하고 12개씩 네 구역으로 보여준다.
- 리본은 길이(m), 신호는 시간(분)으로 표시한다. 리본은 최대공약수만, 신호는 최소공배수만 요구한다. 신호의 정답 확인 뒤에도 24에서 만난 두 길을 유지한다.
- A·B·L·G의 뜻을 정의하고 `A × B = L × G`를 확인한 다음 “아빠는 LG를 좋아해요” 기억법을 제시한다. AB를 두 자리 수로 다루지 않는다.
- 코드 내부 수학 함수와 달리 학습자 문제에는 `gcd(...)`, `lcm(...)`, `mod`를 쓰지 않는다.
