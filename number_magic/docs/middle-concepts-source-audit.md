# 중등 개념 설명 보강 — 2026-09-22

## 범위와 원칙

사용자가 지정한 중등연산 원본을 읽고, 현재 앱의 중등 MD 유형별
한국어 학습지 설명을 보강한다. 이 문서에는 확인을 마친 유형만 기록한다.
MD라는 접두어만 보고 고등 유형까지 중등으로 분류하지 않는다.
소인수분해 등 다른 접두어의 공통 유형과 2학기 도형·통계의 전체 내용까지
이번에 새로 제작했다는 뜻은 아니다. 필즈·소마·KMO 진도 비교는 사용자 요청으로 보류한다.

원본 PDF·쪽 이미지·문항·비공개 경로는 저장소에 복사하지 않는다.
아래 교재 쪽을 직접 보며 설명 순서와 수학적 조건을 확인했고,
학습자에게 보이는 문장·수치 예시는 별도로 작성했다.
기존 난수 문제, 정답, 레벨별 개념, 재입력 코드 계약은 유지한다.

## 학습 흐름과 UI

1. **왜 이렇게 할까요?**: 정의와 규칙의 이유를 먼저 읽는다.
2. **핵심 식**: 식과 필요한 조건을 함께 확인한다.
3. **세 단계 절차**: 학생이 다시 실행할 수 있는 순서로 설명한다.
4. **헷갈리지 않기**: 부호·0·정의역·단위 등 오개념을 짚는다.
5. **이번 단계에서는**: 기존 레벨별 학습 목표를 보존한다.
6. **실제 풀이 예시 → 따라 풀기 세 문항 → 독립 연습 → 별도 정답지**로 이어진다.

개념과 예시는 첫 쪽, 따라 풀기는 다음 쪽으로 분리하여 쓰기 공간을 확보한다.
그래프 따라 풀기는 모눈을 축소하지 않고 2문항/1문항으로 두 쪽에 나눈다.
예시·따라 풀기의 그림은 각 생성 문항의 `p.graph`를 그대로 사용한다.
문제에 없는 정답 그래프를 덧그리는 방식이 아니다.
중등 일반 계산은 최대 2열×5행을 유지한다. 2026-09-22 추가 요청에 따라 그래프·문장제는
2열×3행(6문항), 수직선은 그림 옆에 답을 배치한 1열×6행으로 변경했다.
개념·예시·따라풀기 전용 쪽은 별도이며, 마지막 연습 쪽에는 선택한 총 문항 수의 나머지를 싣는다.
반비례는 xy=a를 근거로 a>0에서 제1·3사분면, a<0에서 제2·4사분면임을 설명한다.
영어·중국어는 기존 설명을 보존하며, 새 한국어 설명을 번역 완료라고 표시하지 않는다.
점검용 `noTeach` 회차에는 개념·예시·따라 풀기를 넣지 않는다.
