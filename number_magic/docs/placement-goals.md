# 진단 목표와 학습 경로

2026-10-03 사용자 승인 방향. 기존 단일 커리큘럼과 고정 20문항은 유지한다.

후속 배포 계약과 최종 검사 연결은 `placement-release-20261003.md`를 본다. 아래 로컬 작업 기록의 미반영/이전 해시 표현은 당시 상태이며 이후 배포 상태를 대신하지 않는다.

## 화면의 역할

- 기준 선택: 학습 목표, 주당 횟수, 실제 배운 범위를 고른다. 목표가 진단 문항·채점·난도를 바꾸지 않는다.
- 결과: 선택한 본진도, 실제 오답의 보강 주제, 모름의 재확인 주제를 분리한다. 한 문제 오답으로 본진도 전체를 되돌리지 않는다.
- 로드맵: 본진도와 보강 위치를 각각 볼 수 있고 목표를 이어서 확인한다. 진단만으로 학습 완료·코인·점수·해금을 바꾸지 않는다.

## 목표

1. 탄탄한 교과 학습을 위한 연산: 개념 이해·정확한 계산·교과 문장제 적용.
2. 소마·필즈 목표 진도에 맞춘 연산: 소마 A·필즈 E1·필즈 S·프리미어를 세부 선택한다. 수 구조·창의 연산·조건 해석·문장제의 확인도 필요하다. 정확한 목표 도달 시점은 원자료 대조 전 확인 필요이다.
3. 이과 최상위권 진도를 준비하는 연산: 다음 교과의 선수 연산을 준비한다. 단순 속도 배수로 학습 완료·경시 준비·합격을 판정하지 않는다.

세 목표 모두 개념·교과·창의 연산·문장제 연결을 유지한다. 새 진도표 세 벌을 만들거나 검증되지 않은 연습 비율을 적용하지 않는다.

## 추천의 의미와 경계

- 본진도는 사용자가 실제 배웠다고 선택한 진단 기준이다. 숙달을 확인했다는 뜻이 아니다.
- 이전·현재의 오답은 유형·레벨별 보강 후보로, 모름은 재확인 후보로 묶는다. 다음 4문항은 다음 학습의 표본이며 승급 근거로 쓰지 않는다.
- 기존 보수적 시작점 추천은 보강 참고로 보존하고 별도 경로 제안에서 본진도와 분리한다. 기존 채점기를 바꾸지 않는다.
- 다음 주제는 실존하는 인접 단계만 안내하며 최종 과정에서 없는 다음 단계를 만들지 않는다. 유아 주제 순서와 실제 활동 회차는 구분한다.
- 주 1/2회는 사용자가 고른 계획 조건이다. 예상 기간은 실제 학습 기록·보강량과 검증된 목표 대응표가 없으면 수치로 만들지 않는다.
- 목표별 안내는 학습 구성 제안이다. 목표별 학습지 자동 재편성·교재/학원 진도 대응표·추가 언어사고력 진단의 구현 완료가 아니다.

## 시각·접근성

종이형 결과 지면에 본진도 → 보강/재확인 → 목표별 방향 → 다음 주제를 순서대로 둔다. 긴 목표명은 줄바꿈하고 버튼 최소 48px, 키보드 초점과 모바일 가로 넘침을 확인한다. 진단 진행 화면의 표상·폰트·응답 방법은 이번 목표 추가에서 변경하지 않는다.

## 로컬 구현·후속 검수

- 세 목표, 네 세부 목표, 주 1/2회 선택을 구현했다. 결과와 로드맵에 목표·본진도·보강/재확인 위치를 연결했다. 주당 횟수만 명시적 계획 설정으로 저장하고, 목표 선택만으로 빠르기를 올리지 않는다.
- 같은 버전의 선택 화면과 진행 중 진단은 재진입 시 보존한다. 완료한 진단의 문항을 재사용하지 않고 새 확인은 새 계획으로 시작한다. 구형 적응형 상태는 재해석하지 않는다.
- 기존 `recommendation`은 보강 참고 근거로 보존하고, `pathRecommendation`의 본진도와 분리한다. 로드맵의 `weak` 요약도 이전·현재 오답의 보강 후보만 반영한다. 다음 표본의 오답이나 모름을 이미 배운 영역의 취약점으로 붙이지 않는다.
- 최종 자동 검사 10개 작업 통과: 목표 경로 7,938조합, 2,800계획·조건 4,645건, 전 81단계×100시드=8,100계획, 통합 검사(재진입 5·실제 결과 콜백 3 포함), 구문과 diff 검사. 검사 전후 앱 파일 7개 해시가 같다. 진단 코어는 기존 C2 SHA-256 그대로다.
- 한국어·영어·중국어 × 세 목표 × 390/1280px의 18흐름은 17개 원실행 완료와 한 개 동일 코드 재시도로 445검사를 연결했다. 그 뒤 main의 `weak` 대입 한 줄만 보완했다. 나머지 6파일의 바이트 동일성과 18실행의 보강 요약 불변을 대조했고, 최종 코드에서 다음 표본만 오답인 2흐름·54검사를 다시 통과했다. 마지막 한 줄 보완 뒤 18개를 전부 다시 실행했다고 보고하지 않는다.
- 본진도/보강 버튼이 정확한 과정 노드를 화면 안으로 이동하고 초점·강조를 주는 동작은 양폭의 2흐름·55검사로 별도 확인했다. 대표 한국어·영어·중국어의 설정·결과·로드맵 캡처를 직접 확인했다.
- 최초 포털 재진입 대기 가정 실패, 영어 PC의 새로고침 시간 초과, 추가 모바일 시간 초과 원로그를 보존했다. 마지막 모바일 실패에서는 외부 폰트/CSS 요청이 남아 있었고 DOM은 loading이었다. 동일 코드 재시도는 통과했지만 최초 영어 실패의 원인까지 확정한 것은 아니다. 통합 검사 모형에 `renderMath` 스텁이 누락된 초기 실패도 모형 보완 후 다시 확인했다.
- 실제 계정·학생 데이터는 사용하지 않았다. 검수는 가상 로컬 저장 상태와 읽기 전용 서버로 진행했다. 런타임 예외·외부 쓰기 시도는 없었고 본인 소유 서버/브라우저만 종료했다. 기존 자산 404 등 콘솔 기록은 유지한다.

최종 연결 근거는 E: 검수 산출물의 `goal-paths/final-goal-evidence.json`, 최종 자동 검사는 `goal-checks-final.json`, 실제 새로고침·결과·로드맵 검수는 각 `goal-browser-*.json`에 있다. 이 파일명은 공개 저장소에 원본 교재나 학생 데이터를 넣는 지시가 아니다.

실제 iOS/Android·3D 마을·실물 인쇄·목표별 학습 효과 검수는 이번 범위가 아니다. 외부 목표의 정확한 과정 대응, 도달 기간, 목표별 학습지 자동 편성은 남아 있다. 기존 C48 13px 인쇄 넘침을 이번에 수정하지 않았으며 기존 필수 8종 전체를 이번 목표 변경 뒤 다시 실행한 것은 아니다. 커밋·푸시·main 병합·배포도 하지 않았다.
