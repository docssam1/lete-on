## 0. 원장 결정 — 먼저 읽을 것

1. **C0는 「인지 순서」대로 배열한다.** 지금은 창의수연 유아 연산드릴 원본 15권(N-01~N-15)을 한 주에 한 권씩 원본 순서대로 실었다(2026-09-19 결정). 이 원본 순서를 버린다. 아이가 수를 익히는 순서로 다시 배열한다.
   - 원본 15권은 **전부 그대로 싣는다**(빼지 않는다). **놓는 주(週)만 바꾼다.**
2. 대상은 **대치동 기준 5세, 주 1회**다. 한 회차 = 3일 분할 학습, 60문항. 회차 수(19)와 회차당 문항 수(60)는 바꾸지 않는다.
   - 바꾸면 광고·소개 숫자(`check-stages`)가 깨진다.
3. **연산 기호(+ · − · =)는 C0의 마지막 다리 주(19주)에만 쓴다.** 로드맵 원칙이 「+는 과정 1에서 처음 만난다」(`data/stages.js` numberland `symbolNote`)이다.
   - 그 전 주에서는 「모으면 모두 몇」처럼 그림과 말로만 다룬다.
4. 아르곤 리포트의 「11~15회차에 기호와 가로셈·세로셈 도입」 제안은 **채택하지 않는다**. 위 3번과 충돌한다.
   - **세로셈은 C0에서 뺀다**(C1 이후로).

## 1. 인지 순서 — 5단계 블록 (19주)

수의 범위는 블록마다 넓힌다. 블록의 순서 자체가 인지 순서다. **한 주 안에서도 쉬운 레벨 → 어려운 레벨 순서**로 싣는다.
- 지금 1회차는 1일차에 `NL1@4`(섞인 그림 속에서 9개까지 골라 세기)를, 2일차에 `NL1@1`(10칸 틀에 1개)을 싣는다. 순서가 거꾸로다.

| 블록 | 주 | 핵심 | 수 범위 | 쓰지 않는 것 |
|---|---|---|---|---|
| A 수 세기·수량 | 1~5 | 하나씩 짚어 세기 → 수량과 숫자 짝짓기 → 이어 세기·수의 순서 → 몇째(서수) → 많고 적음 비교 | 1~5에서 시작해 5주까지 1~10 | 기호, 한자어 수(일·이·삼), 덧셈 퍼즐 |
| B 수의 여러 표현 | 6~8 | 손가락·10칸 틀·점·탤리(산가지) → 고유어 수 이름(하나·둘) → **그다음** 한자어 수 → 0, 거꾸로 세기, 2씩 뛰어 세기, 수직선 → 분류·간단한 표 | 1~10, 0 포함 | 기호 |
| C 모으기·가르기 | 9~12 | 5까지 가르기 → 9까지 가르기(0 포함) → 모으기 → 세 수로 가르고 모으기 → 10의 짝꿍(보수) → 주사위·도미노로 「모두 몇」 | 1~10 | 기호 |
| D 기호 없는 이야기·규칙 | 13~16 | 그림·말로 하는 합·차 이야기(문장제) → 수 기계·규칙표·숫자 기차 → 저울 비교 심화(분동) | 1~10 | 기호, 두 자리 수 |
| E 추론 퍼즐 + 다리 | 17~19 | 17~18주: 이웃 수 피라미드·수나무·더하기 모양(십자) 퍼즐·합이 같은 퍼즐·겹친 도형·순위 추론·같은 그림=같은 수·고대 숫자(로마 숫자 IV의 빼기 원리 포함). 19주: **처음으로 + · − 기호**, 9까지 한 자리 덧셈·뺄셈(AD1·SB1), +1·−1 | 1~10 (19주 덧뺄은 9까지) | 세로셈, 두 자리 수, 10원 동전 뛰어 세기(100까지) |

### 원본 15권(magic) 배치 제안
GPT가 각 권의 실제 내용을 열어 확인한 뒤 확정한다. 권 이름은 `data/courses.js` 과정 0의 `perSessionDrills` 주석에 있다.
- **A:** 1주 N-01 수 세기 · 2주 N-11 수 배열·이어 세기 · 3주 N-02 수의 순서 · 4주 N-05 생활 서수 문장제 · 5주 N-03 몇째와 크기 비교
- **B:** 6주 N-04 기수법 놀이(탤리) · 7주 N-14 산가지와 규칙 · 8주 N-10 자료 분류와 표
- **C:** 9주 N-06 모으기와 가르기 · 10주 N-12 무당벌레와 저울 · 11주 N-07 수 이웃과 10 짝꿍 · 12주(권 없음, 가르기·보수 다지기)
- **D:** 13주 N-15 문장제와 논리 · 14주 N-08 수 기계와 매직 퍼즐 · 15·16주(권 없음, 규칙·저울 다지기)
- **E:** 17주 N-09 수 피라미드 · 18주 N-13 수 퍼즐과 추론 · 19주(권 없음, 기호 다리)

권 안에 블록보다 어려운 활동이 섞여 있으면, **활동(스레드)만 뒤 블록으로 옮긴다.** 권 자체는 그 자리에 둔다.
- 예: N-04 기수법 놀이의 「고대의 숫자」 `NL29` → E블록.
- 예: N-11의 「식 빈칸과 세로셈」 `NL52` → 세로셈은 빼고, □ 값만 19주로.

### 지금 위치가 특히 문제인 활동 (모두 확인함)
- **1회차 3일차 이웃 수 피라미드(`NL5@1`):** 「5 + 4 = 9」. 모으기보다 먼저, 기호까지 써서 나온다 → E블록.
- **1회차 `NL17@2`:** 한자어 수(일·육·구·팔)를 첫 주에 연결한다 → B블록. 고유어 다음에 둔다.
- **2회차 화살표 길(`NL19@2`):** 실선 +1 / 점선 +2, 큰 수부터 → B블록 뒤쪽 이후.
- **4회차 고대의 숫자(`NL29`):** 로마 숫자 → E블록.
- **5회차 달리기 순위 추론(`NL33`):** 2~3개 조건을 엮는 문제 → 쉬운 것은 A블록 몇째, 조건 2개 이상은 E블록.
- **11회차 세로셈(`NL52@3`):** C0에서 뺀다.
- **16·17회차 10원 동전 뛰어 세기(`NL5@3`, 90원까지):** C0 수 범위 밖 → C1 이후로.
  - 참고: 16회차 것은 2026-10-18 Claude가 창의 칸(`COURSE_STRATEGY[0]`)을 주차별로 올리면서 생겼다. 재배열하면서 이 목록도 새 순서에 맞게 다시 쓴다.

### 편성 위치 (코드)
- `data/courses.js` 과정 0(`{id:0, …}`)의 `magic`·`perSessionDrills`(19개, 주마다 교과 드릴 지정)·`creative`(19개)
- `data/courses.js` `COURSE_STRATEGY[0]`(19개, 독셈 칸)
- 이 넷을 함께 새 순서로 바꾼다. 원래 `perSessionDrills`는 「원본 한 권 = 한 주」 1:1이었다. 주석을 「인지 순서 블록」 설명으로 고쳐 쓴다(바꾼 이유 = 원장 2026-10-25 결정).
- `data/stages.js` numberland의 `learn`·`how` 문구가 새 순서와 맞는지 본다.
- **진단이 C0 회차 번호를 직접 가리킨다:** `data/placement-plan.js` `FOUNDATION`의 유아 기초 8단계(f-count5 ~ f-ten10)가 `session` 번호로 C0의 주를 가리킨다(예: f-split5 = 6주, f-ten10 = 7주). 활동을 옮긴 주로 같이 고친다.

## 3. 하지 말 것

- C0 밖의 과정(C1~)을 바꾸지 않는다. C0에서 뺀 세로셈·동전·두 자리 수가 이미 C1 이후에 있는지만 확인하고 기록한다.
- 회차 수 19, 회차당 60문항, 3일 분할을 바꾸지 않는다.
- 원본 15권의 그림·지문을 새로 베끼거나 빼지 않는다. 놓는 주만 바꾼다.
- 학생 진도 기록 형식을 바꾸지 않는다(회차 번호로 저장된 진도는 그대로 둔다).
