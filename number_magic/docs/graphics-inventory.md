## 진행 방식 제안 (원장 "하나씩 체크")
1. **유닛 단위로**(N-01 → N-02 …): 유닛 하나를 열어 그 유닛의 그림을 전부 뽑아 목록에 추가 → GPT 작화 → 도착분부터 `real-art.js` 에 연결 → 원장 확인.
2. 여러 유닛에 공통인 것(유아 물건·동물·UI 아이콘)은 **한 번에** 만들어 두면 재사용된다 — 지시서 A·B 가 그것.
3. #5·#6(개념 장면·3D)은 양이 커서 유닛별 목록을 만든 뒤 우선순위를 정한다.
4. #7(기호 친구·숫자 캐릭터)과 #10(UI 이모지)은 **방향 결정**이 먼저다(캐릭터풍을 남길지, 이모지를 어떤 그림으로 바꿀지).
