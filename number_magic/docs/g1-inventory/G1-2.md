## 이 호의 핵심 개념
- 1~9를 작은 수/큰 수부터 차례로 세기(점 잇기·화살표 수), 거꾸로 세기
- 2씩 뛰어 세기(홀수열·짝수열) 및 화살표 종류로 규칙 표시
- 가까운 수 찾기(사물 개수·수직선 위 거리 기반)
- 반복·교차 수 규칙 찾아 빈칸 채우기, 격자 경로 따라가기
- 규칙에 따른 경로 설계(핀볼게임)

## 앱으로 옮길 때 주의할 점
- **점 잇기(2·8쪽, 확인학습 1번)**는 그림 완성이 목적 — 앱에서는 점 번호 위치 좌표 데이터와 선 긋기(탭 순서) 인터랙션, 완성 그림 SVG 자산이 필요. 사진처럼 번호가 작은 쪽도 있어 확대 필요.
- **화살표 경로 문항(3·5·10쪽, 확인학습)**은 원 위치와 화살표(실선/점선/단·이중) 렌더링이 필수. 좌표·방향이 고정된 템플릿 설계 필요. 레이아웃이 문항마다 다름.
- **격자 경로·수열**(11쪽, 확인학습 6번)은 칸 이어짐 규칙 이해가 어려워 입력 UI(경로 하이라이트)가 있어야 함.
- **핀볼게임**(12쪽)은 정답이 여러 개일 수 있는 경로 설계 — 검증 로직(장애물 회피·순서 증가·중복 방문 금지) 구현 필요, 문제 난이도 이질적.
- **수직선 표시**(9쪽)는 터치로 수직선 위에 점 찍기 UI + 순서 쓰기 2단계.
- 6쪽은 사진형 사물 그림 6종이 필요하고, 사물별 개수는 이 목록에서 판독하지 않았으므로 앱 이관 시 원본에서 세어 확정할 것.
