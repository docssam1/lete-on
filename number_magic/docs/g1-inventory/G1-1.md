## 이 호의 핵심 개념
- 1~9(10까지 근접)의 수를 숫자·한자어 수·고유어 수·손가락·점(10칸 틀)으로 서로 변환하기
- 흩어진 대상의 분류 세기(방해 요소 걸러 세기), 개수에 맞춰 칠하기·그리기
- 격자·쌓기나무 같은 도형의 개수 세기(공간 세기)
- 점판 위 길이를 칸 수로 재기(단위 1)
- 표(날씨 표)를 읽고 개수로 바꾸기

## 앱으로 옮길 때 주의할 점
- **그림 의존이 매우 높음.** 흩어진 숫자·그림 세기(3·4·9쪽), 쌓기나무(11쪽), 점판 선분(12쪽)은 앱에서 해당 그림 자산(렌더링된 SVG/Canvas)이 없으면 성립 안 함. 변형 글꼴 숫자(3·9쪽)는 폰트 변형이 필요.
- **손으로 그리는 활동**(동그라미 나누기의 선 긋기, 점판 선 긋기, 네모 칠하기 자유 작도, 선 잇기)은 정답이 하나가 아니거나 입력 방식(터치 선 긋기)이 필요. 정답 판정 규칙(조각 수만 확인, 칸 수만 확인 등) 설계가 먼저.
- 한자어 수·고유어 수 병기(일·삼·육·여덟 등)는 한국어 교재 특유 요구 — 앱의 한국어/영어/중국어 다국어 설계에서 어떻게 처리할지 결정 필요.
- 확인학습 7쪽 3번은 문제에 그림이 없어 문의도가 불명확, 13쪽 4·5번 도형 그림은 판독 불가이므로 원본 확인 후 이관.
