## 이 호의 핵심 개념
- 0~9의 구성: 범위(보다 크고/작은)·홀수/짝수 조건으로 수를 찾고 개수를 센다.
- 홀수/짝수 = 2씩 뛰어 세기(1에서 시작=홀수), 0, 1에서 2씩 떨어진 수.
- 수를 나타내는 여러 표기(고대 6개 문명 숫자·도형수 격자): 같은 수를 다른 기호·위치로 표현하는 약속 읽기.
- 수 채우기·자물쇠: 규칙 찾기와 조건 소거 논리.
- 10칸 틀(2×5)로 수를 ○로 나타내기(확인학습).

## 앱으로 옮길 때 주의할 점
- 그림 의존도 높음: 고대 숫자 기호(이집트 막대, 그리스 ㄱ자·막대, 중국 산가지, 메소포타미아 y, 마야 점·막대, 로마)는 SVG/폰트로 따로 만들어야 하고, 원문 기호를 그대로 베끼지 말고 직접 그린 아이콘으로.
- 도형수(2×2, 1×4 칸에 ○)는 클릭으로 ○를 찍는 격자 위젯이 필요. 그리기 문항이므로 터치 입력 설계 필요.
- 연결 원 사슬·달팽이/뱀 경로·3×3 자물쇠는 레이아웃 컴포넌트가 별도로 필요.
- 서술형(주머니 보석)은 숫자 입력 칸으로 단순화 가능하나 다중 조건 글이 길다 — 유아 앱에서는 읽기 부담이 큼(읽어주기 음성 권장).
- 손으로 그려야 하는 활동(5·10·13쪽의 ○ 그리기)은 탭 배치로 대체. 이 호는 N-01~N-15 유아 단계보다 상당히 높은 수준(홀짝·논리 퍼즐·고대 숫자)으로 판단됨.
- 판독 불가: 4쪽·7쪽 일부 기호의 정확한 빈칸 수.
