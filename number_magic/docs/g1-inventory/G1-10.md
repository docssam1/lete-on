## 이 호의 핵심 개념
- 더하기·빼기를 이야기·그림·표로 읽고 식으로 바꾸기(문장제)
- 합과 부분의 관계(가르기), 합·차 구하기, 얼마나 더 많은지 비교
- 자료 조사: 그림 격자·표에서 종류별로 세어 정리하고 비교
- 틀린 서술 검산하며 바르게 고치기(논리적 점검)
- 직접 문장제 문제 만들기(창작)

## 앱으로 옮길 때 주의할 점
- 거의 전부 글이 길고 읽기 의존이 높다. 유아 단계(음성 안내 중심) 앱에 그대로 쓰기에는 무리. 1학년 읽기 수준 전제.
- 틀린 부분 찾기·문장제 만들기는 자유 서술 활동이라 자동 채점이 어렵다. 선택형(어느 부분이 틀렸나 고르기)이나 보기 조합으로 바꿔야 함.
- 숫자 이야기는 보기 수를 끌어다 놓는 방식으로 쉽게 옮길 수 있다.
- 조사하기·분류하기는 그림 격자와 표가 필요하다(과일 5종, 날씨 3종 아이콘 세트). 세어서 칸에 쓰는 입력 UI 필요.
- 확인학습 일부(묶음 세기·똑같이 나누기)는 곱셈·나눗셈 맛보기라 N-01~N-15 범위를 벗어날 수 있음.
