## 이 호의 핵심 개념
- 양의 수(개수)와 순서수(몇째)를 문맥에서 구분하기.
- 줄·자리표에서 앞·뒤·좌·우 기준 순서수로 위치 읽기, 전체 인원 구하기(앞+뒤+1).
- 막대그래프·표 읽기와 자료 비교(많다/적다, 같은 수).
- 틀린 부분 찾기: 서술형 논리 점검.
- 조건 소거로 수 찾기(숫자 카드 보기).

## 앱으로 옮길 때 주의할 점
- 그림 의존: 줄 서기·자리표·시상대·그래프가 문항의 일부이므로 전부 직접 그린 SVG가 필요. 이름 5×6 격자는 데이터로 생성 가능.
- 서술형 '고쳐 쓰기'(4·10쪽)는 자동 채점 어려움 → 틀린 문장을 선택하고 올바른 수를 고르는 선택형으로 변환 필요.
- 글 길이가 길고 문장형 문제가 많음(읽기 부담 큼). 유아 앱(N-01~N-15)과 직접 대응하는 쪽은 거의 없으며, 순서수 도입 정도가 겹칠 가능성.
- ○ 그리기(11쪽 2번)는 탭으로 ○를 놓는 위젯으로 대체.
- 판독 불가: 8쪽 책 그림 일부, 9쪽 상자 숫자 외 세부 칸 수는 개략적으로만 셌음.
