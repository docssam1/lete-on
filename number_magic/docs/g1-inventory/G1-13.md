## 이 호의 핵심 개념
- 1~9 안의 덧셈을 제약 조건(합 같게, 최소 합)이 있는 퍼즐에서 반복 사용한다.
- 가로·세로 합이 같아지는 칸 채우기(역으로 빈칸 구하기, 몇 번 더해 목표 합).
- 겹친 도형(사각형·원) 안의 수를 영역별로 합산한다.
- 저울과 분동으로 무게를 합·차로 만든다(1g·2g·4g, 1g·3g·9g).
- 경로의 합 최소화 — 비교와 계획적 선택.

## 앱으로 옮길 때 주의할 점
- 그림 의존도 매우 높음: 겹침 도형(사각·원)은 영역 판정이 핵심이라 단순 이미지로는 안 됨, 영역별 클릭/입력 구조 필요. 저울·분동 그림도 SVG화 필요.
- 손으로 선을 긋는 활동(4·10·7·13쪽 경로)은 칸 터치로 경로를 이어 가는 입력으로 바꾸고 합은 자동 계산해야 함.
- 가로·세로 합 표, 십자·삼각형 배치는 숫자 입력 + 실시간 합 검증으로 쉽게 이식 가능.
- 정답이 여러 개일 수 있는 문항(분동 6쪽, 카드 묶기)은 "조건 만족 여부"로 채점해야 함.
- 난이도는 유아 단계(N-01~N-15)보다 훨씬 높음: 1~9 덧셈·뺄셈 + 논리 퍼즐 수준(판독 불가 문항 없음).
