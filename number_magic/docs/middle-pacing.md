# 중등 핵심 연산 — 주 2회 권장 편성

2026-09-24 사용자 요청까지 반영한 **학년별 7주 × 주 2회 = 14회** 자체 권장안이다.
쉬운 갈래는 12문항, 핵심·복합 유형은 24문항, 집중 반복이 필요한 유형은 36문항이다.
사용자의 추가 지시에 따라 어려울수록 충분히 연습하도록 늘렸으며 30~40분 가정은 폐기했다.
소요시간은 개인차가 있다. 이해가 부족하면 회차를 나누고 일정 때문에 이해를 건너뛰지 않는다.
디딤돌 개념연산의 공식 진도표나 교재 전 소유형 완주 인증이 아니다. 기본 14회는
1학기 연산을 빠르게 훑고, 확인한 2학기 비도형 유형은 보충 목록과 정규 과정에서 이어 간다.

## 기존 자료와 기록

- 정본은 `data/middle-pacing.js`의 `NM_MIDDLE_PACING.grades`다.
- 기존 `NM_COURSES`, C29~37, 과정 내 세션 순서, 학생 통과·인쇄 기록은 변경하지 않는다.
- 로드맵 중1·중2·중3 구간의 **핵심 연산 선행** 목차에서 회차별 학습지를 연다.
- 미리보기를 열거나 출력해도 기존 세션 완료로 처리하지 않는다. 날짜 경과도 완료로 간주하지 않는다.
- 기하는 제외한다. 2학기 비도형은 원본에서 실제 확인한 범위만 넣고, 본문이 없는 단원은 잠근다.

## 회차와 문항 수

한 회차에는 관련 유형·세부 갈래 최대 3개를 넣는다. 쉬운 확인·연결은 12문항,
핵심·복합 연습은 24문항, 추가 반복은 36문항으로 정한다. 회당 총36~60문항을 중심으로 편성한다.
직접 그리기는 빈 좌표평면에서 6문항을 수행한다. 학생이 그리는 활동을
숫자 답 입력이나 완성된 그래프 읽기로 대체하지 않는다.

계획 안에 선택되지 않은 레벨도 기존 전체 과정에서 계속 접근할 수 있다.
마지막 확인 회차는 선정한 핵심의 보충 필요를 살피는 자리이지 모든 소유형의 성취 판정이 아니다.
제곱근 대소 관계는 MD15 4~6단계로 보강했다. 복잡한 연립방정식 등의 알려진 공백은 완료 처리하지 않는다.

## 구현 계약

- 회차: `{id,title,week,day,minutes:null,timeNote,checkpoint,blocks}`.
- 수치 연습: `{t,lv,n,role}`. UI와 출력은 반드시 `n`을 실제 `count`로 전달한다.
- 그리기: `{kind:'drawing',mode,n:6,role:'graph-drawing',title}`.
- API: `NM_EXAM.openMiddlePacing(grade,sessionId)`.
- 자료의 원본 확인 범위는 `middle-concepts-source-audit.md`와 현재 검수 근거를 함께 읽는다.
- 편성·구식 과정 보존·세 페이지 로딩 검사는 `node number_magic/scripts/check-middle-pacing.js`.
- 이 데이터 검사는 학생의 일정 시간 내 완주, 시각적 A4 품질, 자동 성취 판정을 증명하지 않는다.
