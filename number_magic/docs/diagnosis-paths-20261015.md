# 진단·학습 경로 변경 계약 — 2026-10-15

원장님 최신 결정: 나이를 먼저 고른 뒤 ‘아직 배우지 않음 / 현행 / 나이에 맞게’로 시작한다. 종이는 O/X로 채점한다. 진단 직후 학습량을 늘리지 않고 관찰한 다음 점진적으로 조정한다.

- 작업 키: `lete-on/number_magic/diagnosis-paths-20261015`. 기존 고정 20문항(6/10/4), 생성기, 과정과 채점은 유지한다. 기존 교재 대응은 삭제하지 않는다.
- 학습자: 유아부터 고등. 유아는 보호자 읽기 지원, 수량·그림 응답 유지. 연령은 출발 후보이지 숙달 판정이 아니다. 안 배운 아이는 나이에 관계없이 첫 수 세기로 시작할 수 있다. 출발 후보는 언제든 낮추거나 바꾼다.
- 현행의 학년/학기는 맥락이다. 현재 데이터에 학기별 정확한 대응이 없으므로 학기 이수 판정이나 공식 시험이라고 표시하지 않는다. 기존 학년 진입 과정만 재사용한다.
- 종이 채점: 미입력은 오답/모름으로 바꾸지 않는다. 20개 표시를 완료해야 분석한다. ‘안 배움’은 선택적 기록이며 오답과 구분한다. O/X만으로 속도, 실수 원인, 사고력 또는 입학 준비도를 판단하지 않는다.
- 진단은 기존 속도·분량을 변경하지 않는다. 기본 제안은 유지·관찰이며, 다음 4개 오답은 현재 진도 결손으로 처리하지 않는다. 기존 진단 기록은 소급 변경하지 않는다.
- 향후 목표 예측: 실제 회차와 기록된 학습시간에 기반해야 한다. 관찰 기간·점진 증량을 포함하고 가정과 기록을 구분한다. 예상 경로 선택은 실제 진도·점수·코인을 변경하지 않는다. 외부 목표의 미확인 대응을 만들지 않는다.
- 3D: 기존 Three.js 로드맵과 단일 커리큘럼을 사용한다. 실제 위치/보강 후 합류/현재 속도/증량 예상은 서로 다른 의미로 표시한다. 장식 갈림길만으로 구현 완료라고 하지 않는다.

## 남은 범위와 제한

- 3D는 **보호자용 조건부 계획 비교 초안**이다. 마을 전체를 새 갈림길 세계로 바꾸거나 실제 이동 완료로 기록하지 않는다. 기존 마을·아이의 실제 진도와 분리한다.
- 입력한 관찰 기록을 자동 수집·인증하지 않는다. 2주·4회는 최소 입력 조건이지 검증된 숙달 기준이 아니다. 실제 학습 기록 연동과 과거 시나리오 저장은 후속 작업이다.
- 현재 진단에는 학년 진입 과정만 연결한다. 학기별 전체 범위 대응, 소마/필즈 목표의 정확한 과정·날짜 대응은 확인 필요 상태를 유지한다.
- 비교의 횟수 증량 경로는 주 +1회 모의이다. 필요 횟수 안내가 이보다 크면 그 안내 자체를 자동으로 적용하지 않는다. 목표 범위/날짜 또는 추가 시나리오 검토가 필요하다.
- 새 레벨·문항·회차를 추가하지 않았다. 학습 효능, 모든 실제 기기의 GPU, 실물 인쇄 및 교사 검토는 미실행. 전체 `check-*.js`를 모두 돌렸다고 보고하지 않는다.
- 이 기록 시점에는 main 미반영·미배포. 공개 확인은 별도 배포 권한 및 실제 배포 후 증거가 필요하다.
