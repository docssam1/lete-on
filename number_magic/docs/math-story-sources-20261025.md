## 내용의 질·정확한 분수 표기 보완 (2026-10-25 후속)

새6편을 ‘설명과 정답’만 읽는 글에서 **먼저 생각할 오개념 → 그림으로 구조 확인 → 새 상황을 자기 말로 설명 → 필요할 때 힌트·이유 확인**으로 고쳤다. 기존8편의 내용과 기사 수14는 유지한다. 인쇄는 기사마다 한 쪽, 마지막에 두 줄의 설명 칸을 둔다. 앱/공유 미리보기의 힌트와 이유는 접힌 상태이며 인쇄 지면에는 나오지 않는다. 중학년 대상의 생각 물음에는 기존 원장 캐릭터 자산을 재사용한다.

- **분수:** 기준은 ‘크기가 같은 빵 한 개’다. 두 빵을 셋씩 자르면 총6조각이지만, 기준 빵 한 개에는3조각이므로 한 조각은3분의1이다. 한 사람이 두 빵에서 한 조각씩 받은 양은3분의2다. A/B/C 문자로 색에만 의존하지 않고, 한 몫을 원래 한 빵의 틀에 옮겨 담는다. 3개를4명에게 나누는 후속 질문으로 조각 수와 기준 전체의 혼동을 확인한다.
- **등분제·포함제:** 눈금 있는1L 용기의4분의3과4분의1씩 담긴3컵을 비교한다. 이미 아는 수가 사람/몫의 수인지 한 몫의 양인지 구분하고, 결과가 컵 수3이라고 해서 물이3L가 되는 것이 아님을 설명한다. 다른 총량에서도 단위를 붙여 판단하도록 묻는다.
- **가우스:** 한쪽이1커질 때 다른 쪽이1작아져 짝의 합이 일정함을 설명한다. 같은 두 계단이 가로11칸×세로10줄의 직사각형을 만드는 그림으로 두 벌의 합110과 한 벌55를 잇는다. 그림의 칸은 합동 직사각형이므로 영어도 square가 아닌 cell로 쓴다. 홀수9항의 가운데5를 확인하고1~20/1~21의 합 차이를 묻는다.
- **이진법:** 같은11도 진법에 따라 다르며,1101의0을 지우면 자리가 달라짐을 설명한다.8·4·2·1 네 카드의 최대15와16을 나타내려면 필요한 새 카드를 묻는다.
- **로그:**10을 몇 번 곱하는지부터 표→덧셈→원래 수로 돌아가는 순서를 설명한다. 로그값의 합과 실제 곱을 구분하며, 근삿값은≈로 표시한다. 네이피어의 역사적 동기와 현대 상용로그 예를 구분한다.
- **제논:** ‘거북이의 이전 위치에 도착’과 ‘지금 거북이를 만남’을 혼동하는지 묻는다. 같은 시각의 위치 표(행은 초/미터 단위)를 비교한다. 단계가 줄어드는 무한합과 매번 같은 양을 더하는 합을 구분하며, 간격을 닫는 속도→식으로 연결한다. 선행 거리를 바꿔 설명하도록 묻는다.

### 분수 표시 규칙

- 본문·생각 물음·힌트·이유의 숫자 분수는 기존 자체 탑재 KaTeX의 **가로 분수선 위 분자/아래 분모**로 렌더한다. KaTeX가 없는 시점에는 native MathML의 mfrac로 같은 형태를 유지한다. 원자료의 슬래시 표기는 화면에 그대로 노출하지 않는다.
- 언어 공통 SVG는 분자·분모를 별도 text로 놓고 수평 line으로 분수선을 직접 그린다. 유니코드 축약 분수도 같은 규칙을 적용한다. 로그 밑과 이진법의 밑 표기는 분수가 아니다.
- 세 언어·앱/인쇄/외부 미리보기에서 같은 공유 렌더러를 사용한다. 학생 풀이 문항·정답·과정 속도·코인·발송 설정 변경은 없다.

원장님 후속 지시로 `mz-tile`의 제목을 **신라의 미소 찾기**로 바꾸고, [국립경주박물관 공식 소장품 페이지](https://gyeongju.museum.go.kr/kor/html/sub04/0402.html?mng_no=395&mode=V)의 얼굴무늬 수막새 **경주1564** 실제 정면 사진을 넣었다. 같은 이름의 조선/베트남 유물 사진과 혼동하지 않았다. 공식 페이지가 명시한 **공공누리 제1유형(출처표시)**에 따라 화면·인쇄에 출처와 링크를 표시했다. 원본 JPEG600×584는 크롭·재생성·보정 없이 저장했고, 아래 원의 작도는 여전히 별도의 원리 설명 모형이다. 사진에서 반지름46 같은 실측을 했다고 주장하지 않는다.
