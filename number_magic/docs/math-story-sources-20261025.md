# 수의 마법 매거진·수학 이야기 보충 근거

2026-10-25 · Mac Codex · number_magic 범위. 기존 학습지 승인 뒤 읽을거리 보충 요청, 제논의 역설, 『수학자가 들려주는 수학 이야기』와 『수학 뒤집기』 목록 조사, 분수/등분제/포함제 질문을 반영한다. 도서의 본문·그림을 확보하거나 전재한 작업이 아니다. 아래 도서명은 소재 탐색용 서지 정보이며, 기사의 대사·사례·수치·SVG는 자체 작성했다.

## 목록에서 확인한 것

- 자음과모음몰의 [NEW 01~88권 세트](https://www.jamomall.com/) 및 [기존 01~88권 세트](https://www.jamomall.com/goods/goods_view.php?goodsNo=1000000581) 안내를 확인했다. 개정판과 구판에서 순서가 달라 권 번호를 혼용하지 않는다. 전체 88권의 개별 목차·본문을 읽었다는 뜻은 아니다. 일부 개별 상세 페이지는 검색 색인에서는 확인되지만 직접 요청은 502 오류였다.
- [가우스가 들려주는 수열의 합 이야기](https://www.jamomall.com/goods/goods_view.php?goodsNo=4002)는 출판사 서지에서 확인했다(구판 번호86, NEW 번호와 다름). 이름에 연결된 합 주제를 쓰되 어린 시절 대사·상황을 사실처럼 지어내지 않는다.
- [라이프니츠가 들려주는 기수법 이야기](https://search.kyobobook.co.kr/search?chrcCode=1118456202&keyword=%EA%B9%80%ED%95%98%EC%96%80)는 NEW 목록에서 확인했다. 어린 학습 화면의 용어는 기존 지시대로 ‘여러 방법으로 수 나타내기’를 유지한다.
- [시리즈 안내](https://event.kyobobook.co.kr/detail/237913)와 공개 서지에서 네이피어의 로그, 페르마의 약수와 배수, 디오판토스의 일차방정식, 데카르트의 좌표, 칸토어의 집합·무한, 리만의 적분 등도 소재 후보로 확인했다. 이번 신규 기사로 구현한 것은 아래 6편이다.
- 성우 [공식 연혁](https://www.sungwoobook.com/company/history)은 수학 뒤집기 기본편40권과 꼬마 수학50권의 출간을 안내한다. [공식 수학 영상 목록](https://www.sungwoobook.com/lecture/06)의 검색 색인에서 ‘곱셈과 곱셈구구’, ‘나눗셈’, ‘분수와 소수’, ‘신기한 계산’, ‘재미있는 수’, ‘길이 재기’, ‘들이 재기’ 등을 확인했다. 공식 페이지는 클라이언트 로딩만 반환하는 경우가 있어 심화편 전체 권수·전체 목차를 확정하지 않았다. 공식 소개는 관찰→이야기→활동 구성의 참고이며, 그 동화·그림을 재사용하지 않는다.
- 제논은 위 수학 시리즈의 한 권이라고 단정하지 않는다. 『제논이 들려주는 논리 이야기』는 별도 철학 시리즈로 확인된다. 이번 기사는 Stanford/Open University의 제논 역설 해설을 별도로 대조했다.

## 지면 연결

기존8편은 보존, 총14편. 전편 한국어/영어/중국어와 표제1+본문3개 SVG. 새6편에 활동 물음과 근거 링크를 함께 둔다. 앱 매거진과 인쇄가 같은 데이터를 쓴다. 선별은 나이대 일치 안에서 실제 스레드/유닛 우선, 없으면 기존 봉투 해시. 기존 매칭이 나이대를 무시하던 갈래를 보완했다.

유아/초저(young)는 기존 언어사고력 지면/시작 회차를 유지한다. 주간 중고등 compactHigh에서도 기사 한 쪽은 허용한다(과거에는 이 조건으로 모든 읽을거리가 빠졌음). 속진 묶음(pacing)은 기존대로 제외한다. 문제·정답·문항 순서·과정 속도·발송 규칙 변경 없음. 새로 만든 기사 미리보기는 `docs/math-story-preview-20261025.html`에서 실제 인쇄 함수를 재사용한다.
