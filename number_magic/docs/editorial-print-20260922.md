## 요청과 설계

- 자동으로 남은 지면을 채우던 풀이·검산 / 풀이·메모 상자는 제거한다.
- 문항에 필요한 필산 칸, 분수 쓰기 칸, 문장제 식·답 칸은 유지한다.
- 학습 UI 편집 기준: 흰 지면, 먹색 본문, 청록 강조, 얇은 구분선. 본문의 금색 이중 테두리, 둥근 제목 글꼴, 진한 칠판과 장식 마스코트는 쓰지 않는다.
- 내용이 많은 저학년 세로셈은 설명 장과 연습 장을 분리해 답 칸을 확보한다.
- 중등 마지막 두 연습 장은 가능하면 각각 최소 6문항으로 배분한다. 예: 12문항은 10+2 대신 6+6. 문항·정답·순서를 변경하지 않는다.
- 수직선은 그림 옆에 답을 쓰고, 재도전 QR은 하단의 작은 안내로 정돈한다.

## 함께 발견한 출력 문제

중등 일부 짧은 지수식이 저학년 큰 숫자 렌더러를 타며 `a^2`로 찍혔다.
MD 스레드는 이 경로에서도 수식 렌더러를 사용하도록 고쳤다.
문제 생성기·난수·정답·학생 기록은 변경하지 않았다.
