# 칸 교구 한 화면 배치 — 2026-10-12

원장 요청: "이게 한 화면에 들어오도록 만들어야 하는거 아니야/"

## 설계와 범위

한 문제에서 해야 할 일은 안내 읽기 → 칸 조작/세기 → 답 확인입니다.
안내와 교구를 같은 화면에 두고, 문제의 숫자·본문은 읽기 좋은 글꼴을 유지합니다.
학습 화면 디자인 스킬의 한 화면 한 업무, 어린이 글자 크기, 최소 터치 크기를 적용했습니다.

- 대상: `g13Grid` 3~5열 교구의 기본 연산/매직 랩. 다른 위젯의 배치와 크기는 유지합니다.
- PC: 안내를 왼쪽, 교구를 오른쪽에 명시적으로 배치합니다.
- 세로 휴대폰: 안내 → 교구 → 확인 순서입니다. 칸의 실제 크기를 남은 높이와 너비에 맞춥니다.
- 칸은 최소 44px, 안내는 유아 기존 20px 산세리프입니다. 확인 버튼과 개수 표시는 교구 아래 같은 줄입니다.
- 아주 낮은 가로 휴대폰 또는 확대된 창에는 읽을 수 있는 스크롤 폴백을 둡니다. 내용을 잘라 숨기지 않습니다.
- 첫 문제부터 현재 문항 지시를 보여 줍니다. 일반 도입 안내의 음성은 유지합니다.
- 개념 이야기·만화의 스크롤, 10칸 한 줄 교구의 순서, 나머지 위젯, 인쇄, 편성, 생성기, 채점 기준은 변경하지 않습니다.

## 원인과 수정

기존 PC CSS의 교구 `zoom:1.3~1.75`와 `grid-auto-flow:dense` 자동 배치가 겹쳤습니다.
교구가 커지면서 안내가 교구보다 아래 행으로 밀리고 화면 밖으로 나갔습니다.

대상 화면에만 안내/교구 그룹과 명시적 그리드 영역을 붙였습니다.
고정 확대율을 제거하고 교구 컨테이너의 실제 높이·너비로 칸 크기를 정합니다.
칸의 선택/취소와 확인은 키보드 Enter/Space로도 가능합니다.
