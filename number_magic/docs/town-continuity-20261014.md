## 실제 확인과 수정

- 기존 390/1280px 실제 3D 왕복은 정상: 여섯 목적지의 이동 경로, 포인터 capture/취소,
  도감·N-07 학습 복귀의 카메라·목록·초점 보존, 떠난 GPU 컨텍스트 해제, 옛 지도 비노출.
- 그래픽 연결을 강제로 끊으면 복구 안내/버튼이 없었다. `context-before/390-context-failure.png`와 초기 실패 로그가 근거다.
- 연결을 잃으면 이동 입력과 애니메이션을 멈추고 현재 위치·카메라를 유지한다.
  안내와 다시 연결 버튼을 표시하고, 끊긴 동안 키보드·줌·이동 요청을 쌓지 않는다.
- 연결 복구는 기존 장면/캔버스를 사용한다. GPU에서 만들었던 환경광 텍스처는 같은 코드로 다시 만들고,
  첫 복구 프레임을 실제로 그린 뒤 안내를 치운다. 점수·코인·진도는 변경하지 않는다.
- 복구 요청에 응답이 없으면 5초 뒤 다시 시도할 수 있고, 기존 메뉴로 나갔다 돌아오는 방법을 알린다.
- 휴대폰에서 오른쪽 메뉴가 안내를 가리는 것을 캡처에서 발견해 카드 폭/여백을 고쳤고,
  한글 낱말이 중간에서 끊기지 않게 했다. 메뉴와 카드 겹침도 검사한다.
- 일반 화면 이탈 시 연결 해제는 복구 오류로 표시하지 않는다. 종료 시 복구 타이머·이벤트도 정리한다.

