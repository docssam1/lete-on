## 9. 3차 — 짝꿍 목표수와 공개 문장제 메모

P3-3의 NS3·NS4는 레벨에 적힌 5·10·100·1000을 고정 목표로 묻도록 변경했다. 기존에는 중복을 줄인다는 이유로 목표5에서 7까지, 목표100에서 작은 배수까지 바뀌었다. 비C0의 실제 문제 수량은 의도적으로 바로잡았다. 난수 호출 횟수와 시드 형식은 보존한다. 목표수 또는 단위가 달라지는 다음 레벨을 같은 장의 자동 도전으로 넣지 않는다.

NS3는 그림만으로 식의 여덟 변형이 구분되지 않던 문제도 고쳤다. 그림 아래에 해당 식을 함께 인쇄하고, 한 쪽 2열×3행을 사용한다. 정답만 같고 숨은 식만 다른 문항을 서로 다른 그림 문제처럼 다루지 않는다. C0는 기호 도입 시점과 기존 생성 규칙을 그대로 유지한다. WP3 정답 메모에서 교사용 상황 분류를 빼고 연산 이름만 남겼다. 문장·보기·정답은 그대로다.
