### 12-3. 화면·교재 디자인 업그레이드

승인된 마법 책상·책·마을·캐릭터·과정별 표지를 유지한다. 다른 브랜드의 팔레트나 새 3D 조작을 도입하는 제안이 아니다.

1. **휴대폰 읽기와 A4 보기 분리**: 현재 `ws.html:260`은 390px에서 A4를 약 47%로 축소한다. 가로 넘침은 없지만 작은 글씨가 읽기 어려워진다. `종이 모양 보기`는 보존하고, 같은 생성 문항을 한 단으로 읽는 `크게 보기`를 제공한다. 전환 시 재생성하지 않고 문항·답·스크롤 위치를 유지한다. 현재 45px 인쇄 버튼은 크기 문제가 없고, 종이 안 작은 참고 링크와 수식이 우선 대상이다.
2. **개념→그림 예시→함께 풀기→혼자 풀기**: 개념 쪽과 첫 연습 쪽을 연결하고, 따라풀기는 새로운 행동을 하나씩 안내한다. C0 AD1 같은 동일 식 중복은 줄이고 두 무리 그림을 사용한다. 그림이 없는 문제에 ‘그림을 보고’라고 쓰지 않는다.
3. **답칸·수식·풀이 공간을 함께 설계**: C14 대표 지면은 넓은 여백에 작은 식이 흩어져 있다. 큰 수식과 쓰기칸, 필요한 풀이선으로 공간 목적을 명확히 한다. 여백을 채우기 위한 문제 추가나 전 과정 일괄 폰트 확대는 하지 않는다. 유아는 큰 답칸을 유지하고 같은 수·그림·식의 색을 대응시킨다. 색 외에도 위치·라벨을 함께 쓴다.
4. **학습과 참고 읽을거리 구분**: 중고등 압축 수업에 46~56개 본문 페이지 요소가 생기는 사례가 있다. 문항 수만 보고 부담을 판단하지 말고 개념/필수 연습/선택 읽을거리/정답을 묶어 표시한다. 매거진·수학사는 없애지 않고 읽을거리 탭·목차로 쉽게 찾게 한다. 필수 설명은 선택 읽을거리로 밀어내지 않는다.
5. **월별 계획과 문자 배부의 같은 출처**: 화면의 예상 완료일, 다음 학습, 심화 선택 시 변화는 배부 계획 하나에서 계산한다. 기본 2.5/4/3개월은 기준 속도의 근사 기간으로, 실제 달력에는 시작일·주1/2회·다섯 속도 단계에 따른 날짜를 표시한다. 타 학원 레벨은 근거가 있는 참고 목표로 구분한다.

390px/큰 글씨/키보드, 실제 A4와 흑백 출력, 큰 답칸·긴 수식·그림·긴 제목을 따로 통과시킨다. UI/UX Pro Max, GFIELD 디자인 규칙, 기존 교재 디자인·PDF 검수 지침을 사용했으며 수학 타당성 판정은 별도 코드·내용 대조로 수행했다.

### 12-4. 채택하지 않은 주장과 검수 중 오탐

- 아르곤의 옛 중등 42/100주 이중화·100주 유지 제안은 현재 파생 구조와 승인 기간을 반영하지 않는다. 기간을 되돌리지 않는다.
- ‘기적의 계산법↔수의 마법↔필즈·소마 완벽한 1:1 대응’은 단원/기술별 근거가 없는 상태에서 채택하지 않는다. 앞선 상담 자료 위치 확인과 실제 능력 대응 검증은 다르다.
- ‘MD62 적분 생성기 없음’은 틀리고 **있지만 배부되지 않음**이 맞다. MD155도 전체 부재가 아니라 일부 레벨 미도달이다.
- 산점도에 분산 숙달을 무조건 선행시키거나, 모든 레벨을 숫자순으로 강제하는 것도 잘못이다. 기존 스레드 prerequisite를 그대로 잠금 규칙으로 바꾸지 않는다.
- C1 화면의 ‘30에서·34에서·91에서’를 ‘300·340·910’으로 오독한 초기 의심은 DOM 원문과 10,000시드(10~99) 대조로 제외했다. C1에서 확인된 문제는 **공통 개념 설명**이다.
- 첫 PDF 실험의 123MB/25쪽은 인쇄 매체를 명시적으로 준비하지 않은 검수 출력이었다. 실제 코드는 `exam.js:23`에서 이미 배경을 제외한다. print 매체 전환 후 안정화한 C1은 **1,522,234바이트/24쪽**. 추가 배경 숨김 CSS 전후에 페이지 수·전체 페이지 텍스트·파일 크기가 모두 같았다. 따라서 새 배경 제거를 제품 수정안으로 내지 않는다. 큰 파일을 보고 운영 PDF가 모두 그렇다고 일반화하지 않고, 자동 PDF 검수의 매체·레이아웃 준비 절차를 고정한다.
