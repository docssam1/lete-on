## 수업 결정

원장님 설명을 수업의 동작 규칙으로 사용합니다.

- 정수: 수의 부호는 방향, 크기는 칸 수. 더하기는 뒤 수의 방향대로, 빼기는 반대로.
- `−2+(−3)`: 0 → −2 → −5. `+2−(−3)`: 0 → +2 → +5. 빼기는 뒤 수의 원래 화살표를 뒤집은 후 이동합니다.
- “플플·마마는 플, 플마·마플은 마”는 **연산 기호와 바로 뒤 수의 부호**를 정리하는 기억법입니다. 음수 두 수의 덧셈 결과를 양수로 설명하면 안 됩니다.
- “아빠는 LG를 좋아해요”는 `A×B=L×G`의 기억법입니다. 두 자연수 A·B, 최소공배수 L, 최대공약수 G를 정의합니다. AB는 두 자리 수가 아니라 A×B입니다.
- 학생에게 계산을 요구하는 문제에는 최대공약수·최소공배수를 그대로 씁니다. 설명하지 않은 `gcd`·`lcm` 함수 표기를 넣지 않습니다.
- 교과 계산의 의미 → 계산 전략 → 연결 문장제로 이어갑니다. 예측만 하거나 장면을 본 것만으로 기존 단원 진도를 완료하지 않습니다.

최종 계산 결과와 기억법·연결 문장제는 마지막 확인 단계에서 열립니다. 첫 화면 범례에 아직 배우지 않은 최소공배수·최대공약수 값을 노출하지 않습니다.

연결 문장제는 예시가 바뀔 때 함께 바뀌며 13개 지문이 서로 다릅니다. 블록 모으기, 점수·기온·잠수함 높이·승강기, 두 수의 곱과 최대공약수에서 최소공배수 구하기로 연결합니다. 잘못 고르면 같은 문제를 다시 생각할 수 있는 힌트를 주고, 확인 전 정답을 칠하지 않습니다. 이는 입문 장면의 적용 확인이며 기존 학습지 연습량을 대체하지 않습니다.
