# 공부한 교재로 진단 범위 찾기 — 근거와 제한

## 2026-10-15 진입 화면 정리

이 절은 당시 화면과 근거의 기록이다. **현재의 마지막 완료 교재 선택 방식은 아래
「2026-10-17 마지막 완료 교재 선택」을 따른다.**

원장님 정정: ‘나이에 맞게’와 ‘현행’은 중복이므로 하나로 합친다. 나이를 먼저 선택하고 **나이·학년 / 공부한 교재 / 처음 시작** 중 하나를 고른다. 실제 학년이 다를 때만 변경할 수 있다. 기존 `school` 입력과 진행 중 고정20 계획은 삭제하지 않는다.

기존 소마셈 P/K/A/B/C, 기적의 계산법 판·권·확인 단원, 구몬 단계 및 원리셈·창의셈 목록을 UI에 다시 연결했다. 단일 ‘내용 확인’ 항목은 무의미한 드롭다운으로 반복하지 않고 실제 교재에 적힌 권·레벨·학습지 번호를 선택적으로 기록한다. 확인된 좁은 단원 두 개만 자동 후보이며 나머지는 현재 공부한 주제를 한 번 확인한다. 완독/권 번호로 자동 승급하지 않는다.

**두뇌로**는 원장님 요청의 브랜드 선택이다. 2026-10-16 Windows 인수인계에 받은 사진의 Level 구간이 기록됐고, 2026-10-17 Mac에서 사용자 제공 원본 PNG를 직접 열어 **Level 1=교재 과정 1~10, Level 2=11~16, Level 3=17~25**를 재확인했다. 이 세 레벨과 기존 `contents`(다른 표기) 항목을 목록에 표시한다. 원본은 1044×709px·1,273,751바이트, SHA-256 `664af28885e475e90c94f8dc5db5a317f1fb7951df7212c1de0fbe2c19791301`이다. 표에는 각 과정의 1~4주차가 보인다. 2026-10-17 Claude 독립 검수에서 Level 3 과정 17~20 주차 칸을 확대해 ST곱·AS곱·99단 곱·19단 곱과 제곱수 범위 **코드명 일부**를 읽었고, 원본 SHA-256도 재확인했다. 코드명의 뜻·교재 간 기법 동일성·전체 세부 주제·판본·발행일은 확인되지 않았다. 따라서 사진은 **인쇄된 Level·과정 범위와 위 코드명 일부의 직접 근거**이지 공식 최신 전체 단계표나 우리 C과정 대응표가 아니다. 이 범위는 **우리 C과정 번호·연령 규준·자동 진단 시작점과 동일시하지 않는다.** 실제 공부한 내용을 직접 선택하는 경로를 유지한다.

원본 PNG는 기존 수의마법 검수 폴더의 [Drive 파일](https://drive.google.com/file/d/1kBoTuAFS_bKijicnzZP3F7jtzWvI-UZG/view)(ID `1kBoTuAFS_bKijicnzZP3F7jtzWvI-UZG`)에 보관했다. 업로드 뒤 내려받아 원본과 바이트 수·SHA-256이 같은 것을 확인했다. 공개 Git에는 사진 파일이나 교육내용 원문을 넣지 않는다.

기존 공식 교재 자료 확인일: 2026-10-03. 두뇌로 Level 범위는 2026-10-17 사용자 제공 사진 원본에서 직접 확인했으며, 공식 출판사 메타데이터 확인과는 구분한다. 대상: 학습 경험을 바탕으로 **현재 연산 범위 후보**를 찾는 진단 입력. 학교 학년, 학원 진도, 교재 단계와 우리 과정 번호를 동일시하지 않는다. 기존 전체 과정·학습 진도·점수·코인은 변경하지 않는다.

## 2026-10-17 마지막 완료 교재 선택

원장님 후속 요청에 따라 진입 화면에서 권·레벨을 텍스트로 쓰거나 ‘진행 중’을 고르게 하지
않는다. 소마셈 P/K/A/B/C는 각 1~8권, D는 1~6권을 선택 목록으로 제공한다. 이는
판매처의 [P](https://www.yes24.com/product/goods/23896146)·[K](https://www.yes24.com/product/goods/23896127)·[A](https://www.yes24.com/product/goods/23895517)·[B](https://www.yes24.com/product/goods/23895543)·[C](https://www.yes24.com/product/goods/23896229)·[D](https://www.yes24.com/product/goods/75525550)
세트 구성의 **권 번호**에 관한 근거다. 판매처 페이지 중 P·K·A·C·D에는 권별 목차도
실려 있으나(2026-10-17 확인), 이를 전권·판본·앱 문항과 대조한 검증표로 사용하지 않았다.
두뇌로는 사진에서 확인한 Level 1의 과정 1~10, Level 2의
11~16, Level 3의 17~25 안에서 **마지막 완료 과정 번호를 필수로** 고른다. 원본과 비공개
주차별 전사본을 공개 Git에 옮기지 않는다.

교재와 완료 권/과정은 기록하되, 검증되지 않은 대응에서는 보호자가 **실제로 마친 내용에
가까운 앱 진단 범위**를 별도 목록에서 확인한다. 고정 20문항의 이전 6·중심 10·다음 4는
그 앱 진단 범위의 앞뒤 주제로 편성한다. 소마 P3 또는 두뇌로 과정 7을 골랐을 때 각 권의
직전·해당·직후 내용이 정확히 6/10/4 비율로 출제되는 기능은 아니다. 인쇄용 시험지도
‘마지막 완료 교재’와 ‘앱 진단 기준 주제’를 별도 표시하며, 교재 표기는 문제 생성의 기준이
아니다. 완료 기록만으로 숙달·자동 승급·연령별 속도를 판단하지 않는다.
새 선택에만 `bookStatus: completed`를 남긴다. 기존 ‘공부한 교재’ 저장값은 완료를 뜻하지
않으므로 미응답 기준 선택은 다시 고르게 하고, 응답 중인 계획은 유지한다. 과거 결과는
‘완료 여부 미확인’으로 표시한다.

교재 자체에 상대적인 6/10/4를 만들려면 **판본과 권/과정별 주제·실존 앱 문항 참조 풀·선수
관계**를 검증하고, 완독한 권의 여러 주제를 대표하도록 문항을 배분해야 한다. 특히 두뇌로의
주차 전사만으로는 문제 형식과 앱 생성기의 동등성, 누락된 앱 주제를 확정할 수 없다. 기존
Claude 제안의 A안 표는 **현재 배우는 과정의 새 주제**를 기준으로 만든 토론용 후보라서
**마지막으로 완료한 과정**의 진단지 대응표로 재사용할 수 없다. 같은 번호를 앱 C과정이나
교재의 앞뒤 권으로 바꾸어 계산하지 않는다.

## API와 확인 상태

### 2026-10-17 여러 완료 교재와 학교 진도 경로

한 학생이 기적의 계산법과 소마셈처럼 여러 교재를 병행할 수 있으므로 새 진입값은
`selection.completedBooks[]`에 교재별 마지막 완료 권·과정과 `bookStatus: completed`를
각각 기록한다. 화면에서는 최대 8개까지 추가·삭제한다. 교재 경로와 별도로 **학교 진도만**
선택할 수 있으며 이때 학년·학기를 기록하고 실제 배운 연산 내용을 직접 고른다. 학교
학년은 앱 범위의 참고 시작점일 뿐 학기별 숙달이나 현재 학교 단원을 자동 증명하지 않는다.

소마셈 [2019년 발행 P 세트](https://www.yes24.com/product/goods/75530645)와
[2013년 발행 P 세트](https://www.yes24.com/product/goods/8653849)의 권별 짧은
주제 표기가 서로 다르다. 따라서 P는 발행본 미상·2019·2013·기타, K/A/B/C/D는
발행본 미상·2019·기타를 선택한다. 2019년 세트의 번호는
[K](https://www.yes24.com/product/goods/75529132)·[A](https://www.yes24.com/product/goods/75532218)·
[B](https://www.yes24.com/product/goods/75533479)·[C](https://www.yes24.com/product/goods/75534465)·
[D](https://www.yes24.com/product/goods/75525550)에서도 확인했다.
`getEditions(seriesId)`와 `getSteps(seriesId, editionId)`가 이 표기를 제공한다.
발행 연도는 서지 식별값이며 판형·쇄·실제 소장 책을 자동 판별하지 않는다. 공개 자료의
짧은 주제 단서는 원문 문제나 앱 문항과 동등하다는 뜻이 아니다.

이번 시험지는 여러 완료 교재를 **진단의 배경 정보**로 보여 주고, 선택한 앱 진단 범위의
이전 6·중심 10·다음 4문항을 만든다. 선택한 교재들의 각 직전·완료·직후 권에서
6·10·4문항을 합성한 교재 상대 편성은 아직 아니다. 여러 교재의 주제 순서는 서로
다르며, 기적의 계산법·소마셈·두뇌로 모든 판본과 권/과정에 대해 실제 앱 생성 문항의
숫자 범위·올림/내림·답 형식까지 대조한 풀과 병행 가중치가 없다. 확인되지 않은
태그만으로 교재 상대 편성이라고 표시하지 않는다. 종이 시험지에도 완료 교재 목록과
별도 앱 진단 범위를 분리해 적고, 학교 진도만 선택한 시험지에는 교재 목록을 싣지 않는다.
기존 단일 교재 결과·인쇄 링크는 읽기 호환을 유지한다.

`data/placement-books.js`는 `window.NM_PLACEMENT_BOOKS`의 `series`, `getEditions(seriesId)`, `getSteps(seriesId, editionId)`, `getBookCourses(seriesId, stepId)`, `resolve(seriesId, stepId, progress, editionId)`를 제공한다. 라벨은 `ko/en/zh` 객체이며 고유명사는 보존한다.

- `getSteps()`는 소마셈 P/K/A/B/C 각 1~8권, D 1~6권의 선택지를 준다. 권 번호는 식별 자료이며 `baselineId`가 아니다.
- `getBookCourses()`는 두뇌로 Level 1/2/3에서 사진으로 확인한 인쇄 과정 번호 `1~10` / `11~16` / `17~25`를 숫자 배열로 제공하고 다른 항목에서는 `[]`를 반환한다. 두뇌로 경로에서는 마지막 완료 과정 번호를 선택해야 진단을 시작할 수 있다. 새 기록은 해당 `selection.completedBooks[i].bookCourseNumber`에 숫자(미선택 `null`)로 보존한다. 과거 단일 기록의 `selection.bookCourseNumber`도 읽는다. 교재나 Level을 변경하면 해당 행의 이전 번호를 지운다.
- 선택한 교재 번호는 결과와 로드맵에서 이 앱의 과정 번호와 별도로 표시한다. 향후 두 로드맵을 비교할 때 사용할 입력 자료이며, 번호 간 대응표·자동 시작점·연령 기준·한 달 한 과정 자동 편성은 구현하지 않았다.

- `coverage`: 현재 `data/threads.js`에 실존하는 `thread@level` **주제 후보**. 교재와 숫자 범위·표현·풀이 형식까지 같은 문항이라는 뜻이 아니다. 문제 생성이나 점수 결정에 그대로 쓰지 않는다.
- `sourceVerification: verified`: 공식 출판사 페이지에서 해당 판의 짧은 주제 메타데이터를 확인했다는 뜻. 프로그램의 전체 과정과 동등하다는 뜻이 아니다.
- `verification: verified`와 `baselineId`가 함께 있는 단원만 확인 없이 기준 단계를 반환한다. 현재는 예비초등 수의 순서 → `f-order10`, 10 모으기·가르기 → `f-ten10` 두 단원으로 한정한다.
- 이 두 자동 기준도 **겹치는 대표 주제의 검사 시작점 후보**이지 교재 단원 전체와의 동치·숙련 판정이 아니다. 특히 `f-ten10`은 단원 일부인 10의 짝꿍/빈 10칸 수를 확인한다. 해당 단원의 모든 모으기·가르기 활동을 검사했다고 말하지 않는다. 코어의 단일 목표·0/10 경계 변환은 `placement-plan.js` FOUNDATION의 `diagnosticTransform`에서 구분한다.
- 나머지는 `resolve()`가 `baselineId: null`, `needsTopicConfirmation: true`, `verification: topic-confirmation`을 반환한다. 실제 공부한 단원 내용과 우리 단계 제목을 보고 **직접 선택해야 한다**. 이 경로를 자동 대응 완료라고 표시하지 않는다.
- `resolve()`는 이전 호출과 저장 자료의 호환을 위해 `progress` 인자를 받지만 진입 화면에는 시작/중간/완료 진행률 선택을 노출하지 않는다. `start/middle/complete`(동의어 `beginning/early/mid/completed/end`)와 미선택은 좁게 확인된 두 단원에서 같은 주제 후보를 반환한다. 근거 없는 진행률별 과정 추정이나 완료 후 다음 과정 승급은 하지 않는다. 알 수 없는 값은 내용 확인으로 돌아간다.
- 없는 교재/단원 ID는 `null`, 없는 교재의 `getSteps()`는 `[]`이다. 학생 자료·계정·서버 저장·네트워크 호출을 사용하지 않는다.

단일 기준 ID만 받는 진단 코어에서는 교재의 좁은 주제와 과정의 모든 소재가 같지 않다. 예를 들어 우리 C20은 다른 분모 분수뿐 아니라 제곱근도 포함한다. 교재에서 분수만 공부했다는 이유로 C20 전체를 자동 확정하지 않는다. 교재별 부분집합 진단은 이 데이터만으로 구현된 기능이 아니다.

## 기존 문서와 충돌한 근거

기존 `CURRICULUM-SOURCES.md` §9는 검색/OCR 및 이전 대조의 요약이므로 정확한 판·단원 대응표로 재사용하지 않았다.

- 확인한 2021판 7권은 자연수 곱·나눗셈 범위이다. 같은 분모 분수 덧뺄은 8권에서 확인했다. §9의 7권 분수 덧뺄 표기를 자동 대응 근거로 사용하지 않는다.
- 2021판 12권의 마지막은 중학 혼합계산이다. 방정식 네 단계라는 기존 요약을 적용하지 않는다.
- 실제 `threads.js`의 비·백분율은 **MX3**이다. **MX4는 제곱근**이므로 기존 §9의 MX4 비율 표기 대신 실제 등록 정의를 사용한다.
- `courses.js` C0의 NL2@3 주석에 가르기라고 적힌 부분과 달리 실제 `threads.js` NL2@3은 **모으기**이다. 주석보다 등록 레벨의 실제 수학 행동을 기준으로 삼는다.

## 평가 경계와 남은 확인

- 원장 정정: 소마 첫 연산 시험은 **5세 11월 입학 참고**, 필즈 7세 1차는 **7세 11월 필즈 입학 참고**. 이전 6세말 해석은 사용하지 않는다. 이는 우리 연령·연산 단계와 별개이며 합격 판단/컷을 가져오지 않는다.
- 원장 설명(2026-10-17 재확인): **빠른 아이들은 6세 3월에 두뇌로 과정 1을 하고, 이후 한 달에 1과정씩 진행한다.** 이번 사진 자체에는 나이·월령 기준이 보이지 않는다. 일반 6세 규준·입학 기준·전체 커리큘럼 강제 진도가 아니며 위 두 입학 참고 기준과도 별도이다. 확대 판독한 Level 3 코드명 일부를 넘어 불확실한 숫자·전체 교육내용을 전사하지 않는다.
- 교재 경험과 별개로 **나이·학년 경로는 후보 시작점을 제시하고**, 실제 배운 범위가 다르면 ‘다른 내용부터 확인하기’에서 바꿀 수 있다. **처음 시작해요** 경로는 수 세기부터 확인한다. 교재 상품의 학년 표기만으로 현행 학습 수준을 확정하지 않는다.
- 진단 20문항의 이전6/현재10/다음4 구성·영역 결과·모름 응답은 진단 코어의 계약이다. 이 교재 목록이 20문항 문항집이나 검증된 교재별 합격선을 제공하는 것은 아니다.
- 소마의 실제 판본과 권별 목차·앱 문항 정밀 대응, 원리셈 권별 범위, 창의셈 정확한 책 식별, 구몬 교재 번호별 범위는 확인 필요이다. 소마의 **권 번호 목록**이 곧 **권별 문제 대응**은 아니다. 자동 대응 대신 실제 완료 내용과 가까운 앱 진단 범위를 고르는 경로를 제공한다.
- 출판사와 판매처의 짧은 제목/주제 메타데이터만 인용·요약했다. 출판사 문항·정답·풀이·도판·긴 목차, 비공개 교재 PDF/경로, 학생 개인정보는 저장하지 않았다. 제휴·공식 인증·책 구매 추천을 뜻하지 않는다.
- 유아 8개 주제와 전체 81시작 범위의 고정 20문항·6/10/4·중복 검사는 기존 8,100계획에서 통과했다. 마지막 완료 권 목록 추가 뒤 교재 통합 검사에서는 321선택 중 자동 후보 6·실제 학습 내용 직접 확인 315를 확인했다. 종전 198선택(직접 확인 192)은 소마셈 권 목록 추가 전 측정값이다.
- 대표 브라우저 사례에서 두 자동 주제와 소마 P·K의 내용 확인 경로, 390px·1280px의 입력과 진도 보존을 확인했다. 이 결과를 모든 교재·판·권·단원 대응이나 전 연령 learner-fit 검증으로 확대하지 않는다. 실제 기기의 키보드·학습자 적용과 미확인 교재 목차 대조는 남아 있다.
