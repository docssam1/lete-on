# 기존 캐릭터·마을 작화 재사용 기준

2026-10-03 읽기 전용 대조 결과. 새 그림 제작·교체나 3D 마을 개선 완료 보고가 아니다.

## 실제로 확인한 것

- 숫자 캐릭터 happy/think 6장, 인물 초상 4장, 학습 배경 JPG 4장과 수학사 배역 PNG 12종은 이미 저장소에 있다. 단순히 다시 복사하는 것은 개선이 아니다.
- 현재 `NM_COMICS`에 등록된 수학사 만화는 101편·404컷이다. 과거 작화 문서의 95편·380컷을 현재 통계로 사용하지 않는다.
- 숫자 캐릭터·마법사 PNG는 볼륨감 있는 렌더풍이고 수학사 배역은 평면 작화이다. PNG 초상은 움직이는 3D 모델이 아니다.
- 마을은 실제 3D 지오메트리·관절 캐릭터·건물 간판을 사용한다. 기존 작화 지도는 배경과 2D 대체 경로에도 쓰이지만, 앞으로의 3D 마을 개선에서는 배치·색·실루엣 참고 자료로 사용한다.
- Drive 파일과 로컬 파일은 이름이 같아도 형식·크기가 다른 경우가 있다. 원격 바이너리 해시 대조 전에는 동일 파일이나 개선된 버전이라고 단정하지 않는다.

## 적용할 방향

1. **진단:** 문제 영역은 밝고 중립적인 지면을 유지한다. 20문항 진행 중 happy/think 표정으로 정오를 암시하지 않는다. 캐릭터는 시작·완료 안내에서만 제한적으로 사용할 수 있다. 몸이 0·3·8인 숫자 캐릭터를 수량 세기의 낱개 그림으로 대체하지 않는다. 그림의 개수와 몸에 적힌 수를 혼동하지 않게 한다.
2. **학습:** 기존 캐릭터의 배역·색·실루엣은 유지하면서 실제 조작과 수량 이동을 먼저 설계한다. 표정 그림을 추가한 것만으로 교육적 상호작용이나 살아 움직이는 장면이 완성됐다고 보고하지 않는다.
3. **확대 초상:** 실제 표시 배율에서 현재 이미지가 흐린 경우에만 고해상도 원본 교체 후보를 비교한다. 픽셀 크기·투명 배경·시선·여백·압축 용량을 확인한 뒤 같은 화면에서 전후를 검수한다.
4. **마을:** 오래된 평면 지도로 되돌리지 않는다. 넓이·카메라·길 찾기·간판 가독성·캐릭터 움직임은 3D 코드에서 개선한다. 과거 문서의 플랫 2D 제작 지시는 현재 입체 방향보다 우선하지 않는다.
5. **커리큘럼:** 배경 4장은 새 진도 4단계를 뜻하지 않는다. 원래 과정·레벨·회차·학습 기록을 그대로 유지한다.

## 별도 확인이 필요한 것

- 기존 WebGL 실패 경로는 옛 `townWorld`를 다시 보여줄 수 있다. 지도 깜빡임 개선 작업에서는 실패·재진입·메뉴 전환을 함께 확인해야 한다. 이번 진단 변경에서 이 경로를 수정하거나 검수하지 않았다.
- 수학사 인물의 입체 재구성은 연령별 읽기 부담, 이야기 역할, 표정·행동과 실제 렌더 성능을 함께 검토한다. 과거 배역 PNG를 3D 마을 캐릭터로 그대로 덮어쓰지 않는다.
- 전체 Drive 이미지의 원격 바이트·해상도·시각 품질 비교와 실제 기기 3D 성능 검수는 아직 미실행이다. 이번에는 실제 파일 목록·작화 문서와 저장소의 대표 이미지·사용 코드를 대조했다.
