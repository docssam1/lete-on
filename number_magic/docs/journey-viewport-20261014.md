## 설계와 구현

- 휴대폰은 현재 지시→교구→식→주요 조작, PC는 교구 왼쪽·식/조작 오른쪽이다.
  10칸 교구는 240px 이상을 유지하며, 카메라 여백을 줄여 기존 3D 조각을 또렷하게 한다.
- 회차/보조 표시는 작고 조용하게, 교구·수식·주요 버튼은 읽기/조작 크기를 유지한다.
  오른쪽 조각 선택은 한 줄 레일로 스크롤한다. 도움·처음부터·저장 재시도는 도구 안에 있다.
  되돌리기·마을로는 따로 유지하고 다음 장면은 확인을 마친 때 표시한다. 저장 실패 시 도구를 자동으로 연다.
- 조각 선택 때 DOM을 다시 만들어도 같은 조각 버튼에 키보드 초점을 유지한다.
  주요 조작 후 교구를 보여 주는 위치로 돌아오며, 저장된 재진입 위치는 기존 방식대로 복원한다.
- 이동 중에는 이전 식/현재 지시·개수 표시를 유지한다. 실제 렌더러가 도착 프레임을 그린 뒤
  식·개수·다음 조작을 표시한다. 750ms 타이머로 도착을 추정하지 않는다.
- 탭/교구가 숨겨지면 해당 이동 시간을 멈추고, 복귀 시 남은 이동을 이어 간다.
  동작 줄이기·기존 DOM 대체 경로는 즉시 같은 끝 상태를 보여 준다.
- 렌더러 완료 콜백에서 화면을 다시 그릴 때 RAF를 이중 예약하지 않도록 했다.
  정수·약수/배수의 기존 진행 규칙은 유지한다.
