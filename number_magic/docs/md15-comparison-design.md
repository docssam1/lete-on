상태: 2026-09-24 로컬 구현·검증 완료. MD15 4~6레벨, 문제은행 검색, 7주 권장 편성,
개념·예시·따라풀기·정답지에 연결했다. 기존 MD15 1~3레벨의 같은 시드 결과는 보존했다.

## 원본 근거와 범위

디딤돌수학 개념연산 3-1A, 인쇄 36쪽(변환 파일 `page-0036.jpg`)을 직접 시각 확인했다. 양수 제곱근의 대소, 음수 제곱근의 역순, 분수·소수가 근호 안에 있는 비교와 양의 유리수-제곱근 비교를 확인했다. 원본 문제·도판은 복제하지 않고 같은 수학적 기능을 갖는 독자 문항을 생성한다. 전권 상세 검수가 완료되었다는 뜻은 아니다.

## 기존 계약 및 안전한 확장점

- `data/threads.js` MD15는 `md15_sqrtValue`, `numpad`, 숫자 정답을 사용한다. 레벨 1~3은 각각 `perfect`, `squareOfSqrt`, `absValue`이다.
- `engine/threads/mid3.js`의 MD15 함수에서 기존 분기보다 앞에 새 mode 분기만 추가한다. 기존 3개 mode의 난수 호출 순서와 결과를 보존한다.
- 기존 MD1 대소 문제는 큰/작은 **값 자체**를 입력하는 방식이다. 무리수 값을 입력할 수 있는 기존 계약은 확인되지 않았으므로 새 비교 문제는 1/2/3 번호 입력을 사용한다.
- 매 문항에 `① 왼쪽이 큼 ② 같음 ③ 오른쪽이 큼`을 명시한다. 한국어·영어·중국어 prompt를 각각 제공한다. 인쇄에서 prompt가 생략되어도 의미가 남도록 문제 수식에도 `① > ② = ③ <` 안내를 둔다.
- 채점 answer는 숫자 1/2/3을 유지하되 비교 메타데이터에 왼쪽·오른쪽 수식과 실제 관계를 보존한다. 정답지에는 번호와 실제 부등식/등식을 함께 표시해야 한다.
- 현재 `app/exam.js`의 `ansTex`는 answerShape+배열 계약이며 임의 answerTex를 받지 않는다. 따라서 생성기만 추가하면 정답지가 bare number가 된다. 비교 메타데이터 처리와 답지 검증까지 완료하기 전 노출 금지.

## 추가 레벨

| 레벨 | mode | 범위 | 개념과 주의 |
|---|---|---|---|
| 4 | comparePositive | 양수 제곱근끼리 비교, 같음 포함 | 두 수가 모두 음이 아니면 제곱한 값의 순서와 같다. |

각 레벨별 개념 문구와 예시를 제공한다. `middle-concepts.js` 공통 MD15 패널만 긴 비교 설명으로 바꾸면 기존 1~3레벨 학습에 불필요한 개념이 섞이므로 레벨별 설명 우선이다.

## 정확 판정 모델

항을 부호 s, 종류 root/rational, 정수 분자 n, 양의 정수 분모 d로 표현한다. 소수도 정수/10 또는 정수/100으로 보존한다. 0은 별도로 정규화한다.

1. 부호가 다르면 부호로 비교한다.
2. root의 절댓값 제곱은 n/d, rational의 절댓값 제곱은 n²/d²이다.
3. 두 제곱값 A/B와 C/D를 정수 교차곱 AD와 CB로 비교한다.
4. 두 항이 음수이면 비교 방향을 뒤집는다. 같음은 뒤집어도 같다.
5. 결과 >, =, <를 각각 입력 정답 1, 2, 3으로 바꾼다.

범위를 작게 제한해 모든 교차곱이 Number 안전 정수 안에 들어오게 한다. 실제 채점에 Math.sqrt 반올림이나 epsilon을 사용하지 않는다. 해설에는 부호 판정, 절댓값 제곱 비교, 실제 관계와 선택 번호를 보여 준다.

## 노출 전 필수 검증

- 신규 3레벨 각각 1,000개 이상의 seed와 반복 문항을 독립 계산으로 검산한다.
- 각 레벨에서 정답 1/2/3, 같음, 좌우 교환, 음수 역전의 출현과 정답을 확인한다.
- Lv6은 분수 교차곱·유한소수·다른 표기의 같은 값(예: sqrt(25/16)과 5/4)·서로 다른 부호를 명시 fixture로 검증한다.
- 기존 MD15 1~3레벨의 같은 seed 결과가 변경 전과 일치하는지 회귀 검사한다.
- 새 레벨 metadata, 앱 선택, 문제 입력/정오답, 3언어, 개념 패널, 교사용 답지의 번호+관계, 학생 답 누출 여부를 검사한다.
- 실제 데스크톱·390px·A4/PDF를 확인한다. 문항/안내/해설이 넘치면 노출하지 않는다.
- 모든 검증 후에만 신규 레벨을 등록하고 7주 계획의 범위/공백 안내를 갱신한다. 새 thread나 unit를 만들지 않는다.

구현은 실수 근삿값을 쓰지 않고 부호와 유리수 교차곱으로 판정한다. 전용 검사에서 각 풀의
모든 표시 문항, 3개 선택지 출현, 좌우 교환·같음·음수 역전·분수·유한소수 fixture,
기존 1~3레벨 시드 회귀, 60문항 중복 없는 생성을 확인한다. 실제 앱의 전체 중등 인쇄 검사는
상위 통합 검수에서 별도로 반복한다.
