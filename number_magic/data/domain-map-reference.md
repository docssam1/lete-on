# 교과 문제은행 설계 참고자료 (내부용)

> 2022 개정 초등수학 교육과정의 영역·소주제·학년군 순서를 우리 표현으로 재정리.
> 성취기준 원문은 인용하지 않음(공식 문구 재수록 금지 원칙 유지).
> 구조 검증은 DECK6/korean-elementary-learning-map(MIT)로 대조, 텍스트는 전부 새로 씀.
> 창의적 연산(PRIME A~I, ADVANCE A~H)은 "수와 연산" 영역의 연산 전략만 다루므로,
> 아래 나머지 영역(변화와 관계·도형과 측정·자료와 가능성)이 "문장제/교과 문제은행"의 재료.

---

## 영역별 소주제 순서 (학년군별)

### 수와 연산 (창의적 연산이 이미 커버 — 문제은행에서는 문장제로만 보강)
- 1-2학년군: 네 자리 이하의 수 → 두 자리 수 덧셈뺄셈 → 한 자리 수 곱셈
- 3-4학년군: 다섯 자리 이상의 수 → 세 자리 수 덧셈뺄셈 → 세 자리 수 곱셈 → 나눗셈 → 어림셈 → 분수 → 소수 → 분수/소수 덧셈뺄셈
- 5-6학년군: 혼합계산 → 올림·버림·반올림 → 약수와 배수 → 분수 덧셈뺄셈/곱셈나눗셈 → 분수와 소수 관계 → 소수 곱셈나눗셈

### 변화와 관계 (CHALLENGE 등급의 핵심 재료)
- 1-2학년군: 규칙 찾기
- 3-4학년군: 규칙을 수/식으로 나타내기 → 등호와 동치 관계
- 5-6학년군: 대응 관계 → 비와 비율 → 비례식과 비례배분

### 도형과 측정 (문장제/응용 문제은행 재료)
- 1-2학년군: 입체도형 모양 → 평면도형 구성요소 → 양의 비교 → 시각과 시간 → 길이
- 3-4학년군: 도형의 기초 → 평면도형 이동 → 원 → 삼각형 → 사각형 → 다각형 → 시각과 시간 → 길이 → 들이 → 무게 → 각도
- 5-6학년군: 합동과 대칭 → 직육면체/정육면체 → 각기둥/각뿔 → 원기둥/원뿔/구 → 입체도형 공간감각 → 다각형 둘레와 넓이 → 원주율과 원의 넓이 → 겉넓이와 부피

### 자료와 가능성 (문장제 재료)
- 1-2학년군: 자료의 정리
- 3-4학년군: 자료의 수집과 정리
- 5-6학년군: 자료의 수집과 정리(심화) → 가능성

## 우리 등급과의 매칭 제안

| 우리 등급 | 나이대 | 끌어올 영역 |
|---|---|---|
| BASIC (수의 나라) | 5~6세 | 수와 연산 1-2학년군 도입부 + 도형과 측정(양의 비교, 입체도형 모양) — 문장제는 그림 중심 |
| PRIME (창의적 연산 A~I) | 만5세+ | 수와 연산 전략은 이미 있음 → **문장제만 추가**(같은 전략을 실생활 상황으로) |
| ADVANCE (분배법칙·곱셈) | 7세+ | 수와 연산(곱셈) + 변화와 관계 초급(규칙을 식으로) 응용 문장제 |
| CHALLENGE (상관관계·경시) | 초1말+ | 변화와 관계 전체(대응관계·비와 비율·비례식) + 도형과 측정 심화 — 경시 스타일 문장제 |

## 문제은행 데이터 스키마 제안

기존 `data/units/A-01.js`의 유닛 구조를 재사용하되, 문장제 전용 필드를 추가:

```js
window.NM_WORDPROBLEMS['A-01'] = {
  unitRef: 'A-01',           // 어느 연산 유닛과 짝인지
  domain: 'number-operations', // 수와연산 | 변화와관계 | 도형과측정 | 자료와가능성 (내부 태그, 화면 노출 안 함)
  problems: [
    {
      id: 'A-01-wp-01',
      ko: '누미가 사탕을 3개 가지고 있었는데 친구가 7개를 더 줬어요. 누미는 사탕을 몇 개 가지고 있을까요?',
      en: '...', zh: '...',
      answer: 10,
      strategy: '더해서 10 만들기',   // 어떤 전략을 문장제로 풀게 하는지
      hint: { ko: '3과 7을 먼저 짝지어 보면 어떨까?' }
    }
    // ...
  ]
};
```

- 문항 텍스트는 전부 창작(실존 교재 문장 베끼지 않음)
- `domain` 태그는 나중에 "다양한 영역 골고루" 안배할 때만 내부적으로 씀 — 학생 화면엔 안 보임
- 아레나/매직랩과 달리 문장제는 서술형이라 숫자패드 대신 객관식(4지선다) 또는 짧은 답 입력으로 설계 예정
