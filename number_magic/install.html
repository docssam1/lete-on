수의 마법을 앱으로 쓰기

한 번 설치하면 홈 화면에서 바로 열려요. 다 받아 두면 인터넷 없이도 공부할 수 있어요.

지금 앱으로 열려 있어요. 설치는 끝났어요. 아래 「다 받아 두기」만 한 번 해 두면 좋아요.
수의 마법 열기
이 기기

설치하기

카카오톡·네이버 같은 앱 안의 창에서는 설치가 안 돼요. 크롬으로 열어 주세요.
크롬으로 열기

두 가지 중 편한 것으로 하세요. 둘 다 같은 수의 마법이고, 로그인하면 기록이 그대로 이어져요.

APK 받기
  1. 크롬 오른쪽 위 ⋮(점 세 개)을 눌러요.
  2. 「앱 설치」 또는 「홈 화면에 추가」를 눌러요.
  3. 홈 화면에 생긴 수의 마법 아이콘으로 열어요.
APK는 무엇이 다른가요?

APK는 공부 알림(매일 정한 시간)과 화면 꺼짐 방지가 더 있어요. 받은 파일을 열면 「출처를 알 수 없는 앱」을 허용할지 물어요 — 이번 한 번만 허용하면 돼요. 플레이 스토어 앱이 아니라서 그래요.

지금 창에서는 홈 화면에 추가가 안 될 수 있어요. 주소를 복사해 사파리에서 열어 주세요.
사파리로 열기
  1. 사파리 아래쪽(아이패드는 위쪽)의 공유 단추 를 눌러요. 안 보이면 주소창 옆 …을 먼저 눌러요.
  2. 목록을 아래로 내려 「홈 화면에 추가」 를 눌러요.
  3. 오른쪽 위 「추가」를 누르면 홈 화면에 수의 마법이 생겨요.

아이폰·아이패드는 앱 스토어 앱 대신 이 방법으로 써요. 열면 주소창 없이 앱처럼 화면 가득 열리고, 새 버전은 저절로 받아요.

  1. 크롬이나 엣지로 이 화면을 열어요.
  2. 주소창 오른쪽의 설치 아이콘 을 누르거나, 메뉴 ⋮ / … → 「앱 설치」(엣지는 「앱 → 이 사이트를 앱으로 설치」)를 눌러요.
  3. 시작 메뉴·바탕 화면에 수의 마법이 생기고, 따로 창으로 열려요.

맥의 사파리는 메뉴 파일 → Dock에 추가로 같은 일을 해요.

다 받아 두기

공부에 쓰는 그림·소리·문제를 이 기기에 한 번에 받아 둬요. 그 뒤로는 인터넷이 끊겨도 열려요. 와이파이에서 해 주세요.

공부 알림

매일 정한 시간에 「오늘의 마법을 풀 시간이에요」 알림을 띄워요. 이 기기에서만 울려요.

휴대폰으로 열기

휴대폰 카메라로 비추면 이 안내 화면이 열려요. 주소로 열려면

lete-on.gfieldacademy.net/app

궁금한 것

새 버전은 어떻게 받나요?

저절로 받아요. 앱을 연 채로 새 버전이 나오면 아래에 「새 버전이 있어요」가 떠요 — 「새로 열기」를 누르면 돼요.

로그인·기록은 어떻게 되나요?

회원 로그인과 공부 기록은 지금처럼 인터넷으로 이어져요. 앱으로 설치해도 같은 계정으로 들어가면 그대로예요.

얼마나 차지하나요?

다 받아 두면 약 100MB 안팎이에요. 지우고 싶으면 앱을 지우거나 브라우저의 사이트 데이터를 지우면 돼요.

앱을 지우려면?

홈 화면 아이콘을 길게 눌러 「삭제」(아이폰은 「앱 제거 → 홈 화면에서 제거」)를 누르면 돼요. 회원 정보는 지워지지 않아요.
