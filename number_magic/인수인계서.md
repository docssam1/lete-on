**생성기를 쓸 때의 계약**

| 규칙 | 내용 |
|---|---|
| 난수 | `Math.random()` 절대 금지. `R(rng,a,b)` · `pick(rng,arr)`만 |
| 답 | 항상 **정수 몇 개**. 수식 문자열을 입력받거나 파싱하지 않는다 |
| 답 환원 | 근호·분수는 정수 둘로 — `4√3`은 `[4,3]`, 근의 공식은 `[D, 2a]` |
| 역산 | 답을 **먼저** 고르고 계수를 거꾸로 맞춘다. 그래야 나눗셈이 늘 떨어진다 |
| 풀이 | `solution[]`의 **마지막 단계 `blank`가 `answer`와 같아야** 한다 |
| 표기 | 계수 1·0과 지수 1을 노출하지 않는다. 음수는 괄호로 감싼다(`(-3)^2`) |
| 말투 | 중등·고등은 **"…합니다"체**, 초등·유아는 **"…해요"체** |
| 언어 | `ko` `en` `zh` 셋 다 채운다 |

## 8. 실제로 데인 곳 — 다음 사람은 여기서 안 데이길

| # | 무슨 일이 | 교훈 |
|---|---|---|
| 1 | 새 유닛이 `index.html` 태그 목록에 없어 앱에서 통째로 로드 안 됨 | **폴더를 읽는 검사기와 태그를 읽는 브라우저는 다르다** |
| 2 | 같은 유닛이 `roadmap.js`에 없어 학습지에만 나오고 앱 지도에는 없음 | **유닛은 두 곳에 각각 실린다** |
| 3 | `-10^2`이 −100으로 읽혀 풀이가 거짓이 됨 | 음수를 거듭제곱 자리에 넣을 땐 **반드시 괄호** |
| 4 | 분수 빈칸이 분수선에 붙어 인쇄됨 | 한 분수 안에 `\square`가 **2개 이상**일 때만 간격 보정이 걸린다 |
| 5 | 말투 변환이 미분 단원을 통째로 건너뜀 | ko 문자열이 작은따옴표만인 줄 알았는데 `f'(x)` 때문에 큰따옴표였다 |
| 6 | 정답이 늘 제일 긴 보기였다(다른 책에서 67%) | 사람도 모델도 **자기보고는 증거가 아니다.** 측정해야 안다 |
| 7 | 저장소만 고치고 드라이브 사본을 안 바꿔 두 벌이 어긋남 | **같은 문서가 두 곳에 있으면 1·2번과 똑같은 일이 벌어진다.** 저장소가 정본, 드라이브는 공유용 스냅샷 |
| 8 | 같은 중등 내용을 정규 과정(113회)과 별도 권장 편성(42회)이 서로 다른 주차로 안내함(2026-09-24~25) | **정본은 하나.** 다른 화면은 정본에서 계산한다 — `middle-pacing.js` 는 이제 보기일 뿐 |
| 9 | 회차의 `creative` 한 칸이 초등에선 "창의 연산", 중등에선 "적용"으로 찍혔지만 실제로는 같은 단원의 어려운 드릴이었다 | 이름이 역할을 보장하지 않는다. 역할을 데이터로 나누고 **회차마다** 검사한다(`check-session-roles`) |
| 10 | "문장제로 바뀌는 유형"을 이름으로 짐작했더니 17개가 틀렸다 | 앱의 실제 변환으로 확인한 표(`data/wordable.js`)만 쓴다 |
