## 1. 두 개의 트랙, 하나의 세계

```
  [교과 트랙 · 계산의 길]        [마법 트랙 · 전략의 길]
   개념 ▶한 줄 + 드릴 학습지      창의수연 기반 전략 유닛
   "정확하고 빠르게"              "다르게, 영리하게"
        │                             │
        └──── 필수 연산 관문 ─────────┘
     (마법 과정 입구에 교과 노드가 선수로 연결)
```

- **교과 트랙**: 이 문서 §4~§6의 유형 카탈로그. 유형마다 ①개념 한 줄 ②예시 1개(mathSteps)
  ③생성기 ④학습지 스레드. 반복 드릴 성격 — 교과연산 교재의 촘촘한 계단을 참고하되 편성은 교육과정.
- **마법 트랙**: 기존 BASIC(유아)·PRIME(초급)·ADVANCE(중급 8단계)·CHALLENGE(고급). 완성돼 있거나(B/P/A) 설계 예정(C).
- **필수 연산 관문**: "이 마법을 배우려면 이 계산이 손에 붙어 있어야 한다"를 노드 연결로 표현.
  관문은 **잠그지 않고** 추천 배지로만 보여준다. 예: 관문 미통과 상태로 진입하면 "먼저 ○○를 다지고 오면 더 쉬워요" 안내.

## 2. 스토리 모드 구조

### 화면 개념
세계 지도 위에 **월드(과정)** 가 길로 이어져 있고, 월드 안에 **노드(마디)** 가 있다.
기존 리빙타운·학년별 교실을 대체하지 않는다 — **세 번째 진입로**다(마을 건물 하나로 추가).

### 노드 5종
| 노드 | 내용 | 엔진 |
|---|---|---|
| 📖 개념 | 개념 한 줄 + 예시 + 확인 4문항 | 기존 discover/check 재사용 |
| 🔬 **개념 실험실** | **조작형 시각 개념** — 함수·수를 직접 바꿔 보며 원리를 눈으로 확인하고, 바로 유사문제로 이어짐 | `fields-classic/calculus` 방식(캔버스+슬라이더+예시 버튼+유사문제 탭)을 표준 템플릿으로 |
| ✏️ 드릴 | 유형 1개 20문항 (인쇄 학습지와 동일 세트) | NM_TGEN + threads.js |
| ✨ 마법 | 기존 매직넘버스 유닛 | 기존 유닛 그대로 |
| 👑 보스 | 월드 마무리 시험, 80% 통과·재시험 | 기존 course test 규칙 재사용 |

**개념 실험실 원칙** (원장 지시 2026-08-23: "fields-classic/calculus 이런 식의 개념도 좋아"):
- 계산 규칙만 있는 유형(사칙·지수법칙 등)은 📖 한 줄 개념으로 충분하다.
- **눈으로 봐야 이해되는 유형은 🔬 실험실로 만든다.** 대상:
  W8 수직선 위 정수 덧뺄 · W9 일차함수 기울기 · W10 이차함수 꼭짓점·판별식 ·
  W12 직선·원의 방정식(좌표평면) · W13 지수·로그·삼각함수 그래프, 수열의 합 쌓기 ·
  W14 극한·접선·극값·넓이 — **W14는 이미 있는 `fields-classic/calculus`(극값·부정적분·적분조건·유사문제 4탭)를 그대로 링크·이식**한다. 새로 만들지 않는다.
- 실험실도 끝은 항상 **유사문제 테스트**로 닫는다(실험→문제 연결, calculus 랩과 동일 구조).

### 시작점 선택
- 최초 진입: **진단**(기존 placement 설계 재사용) → 추천 시작 월드 제시
- 또는 지도에서 **아무 월드나 선택** — 잠금 없음, 추천 경로만 별·리본으로 표시
- 진행상황은 노드 단위 저장(`profile.story = {nodeId:{done,stars}}`)

### 중1 (W8) — G권 계단 참고

| 문자와 식의 값 | 문자에 수를 넣을 땐 곱셈 기호를 살려서 대입 | x에 정수/분수 대입, 답은 수 |

| 일차방정식 | 등식의 성질로 x만 남을 때까지 양변을 같게 조작 | 이항 1회→분수계수, steps 위젯 |

### 3번 규약 확장 — W13·W14에서 새로 정한 답 환원 규약 (2026-08-25)
답 환원 원칙이 통하지 않을 것 같았던 자리(로그·삼각비 근호·수열·Σ·극한·미분·적분)까지
전부 정수/기약분수로 환원된 사례. 상세 역산 로직은 각 생성기 주석(`engine/threads/
mid6.js`·`mid7.js`) 참조.

| 유형 | 답 형태 | 역산 요령 |
|---|---|---|
| 유리수 지수(MD36) | `[분자,분모]`(기약분수) | m=p×k, n=q×k로 만들어 항상 p/q로 기약 |
| 로그값(MD37·38) | 정수 하나 | N=aˣ를 forward로 구성. 나눗셈이 필요한 순간(예: 로그의 곱)은 지수의 합/차 범위를 먼저 정하고 밑을 역산해 큰 수 폭주도 함께 막음(§13-보강) |
| 삼각비 특수각(MD39) | 정수 / `[분자,분모]`(fraction) / `[계수,근호안,분모]` / `[계수,근호안]` | 값의 형태 4종으로 분기(§13-보강). 근호가 섞인 분수는 근의 공식(MD28)처럼 tex에 \square 3개를 그대로 박아 새 answerShape 없이 순서로 받음 |
| 등차·등비수열(MD40·41) | `[a1,d]`/`[a1,r]`(일반항 역산) 또는 정수(n항값·합) | 등차합은 n(n-1)이 항상 짝수임을 이용해 나눗셈 없이 정수 보장. 등비합은 공식 대신 항을 나열해 더하는 루프로 계산해 부동소수점을 원천 차단 |
| Σ 계산(MD42) | 정수 하나 | Σk=n(n+1)/2, Σk²=n(n+1)(2n+1)/6이 항등적으로 항상 정수 — 무지개 덧셈법·제곱수의 합과 같은 공식이라 별도 역산 불필요 |
| 극한(MD43) | 정수 하나 | 0/0 꼴은 분자를 (x-a)(x-c) 형태로 **곱해서** 만들어 약분 후 항상 정수(나눗셈 자체가 없음) |
| 미분·적분(MD44·46) | 계수 다칸 또는 정수 하나 | 미분은 정수 계수에 정수를 곱하니 항상 정수. 적분은 계수를 (차수+1)의 **배수**로 역산해 나눗셈 없이 몫이 정수가 되게 만듦 |

이 확장으로 확인된 위험 신호(후속 작업 시 참고): **나눗셈이 필요한 자리는 전부 "나눗셈이
아니라 배수/곱으로 역산"하는 방식으로 피해야 한다.** 반대로 결합 지수(로그의 밑변환 b^r,
Σ의 n)를 무심코 넓히면 학습지 중복률(과정-로드맵.md §12 학습지 빌더 설계 참조)은 낮아지지만 답이 천문학적 수로
치솟거나(실제로 N이 10²¹까지 치솟아 문자열 보간이 지수표기로 깨진 버그 발생·수정) 20문항
안에서 조합이 바닥나 중복률이 60~75%까지 치솟는(삼각비 특수각처럼 표 자체가 14개뿐인
경우) 정반대 실패도 함께 온다 — 두 실패 모두 실측 후 수정됨(검증 스위트: 중복 감사
15% 상한 통과, 안전정수·지수표기 잔존 0건).
