## 0. 먼저 첨부할 참고 이미지
- 배경 4장 → `map.jpg` (마을 지도. 저장소 `number_magic/assets/map.jpg`)
- 표정 6장 → 그 캐릭터의 원본 PNG (`numi-0.png` / `poco-3.png` / `momo-8.png`, 저장소
  `number_magic/assets/characters/`)

## 1. 배경 4장 (1024×1536 세로, 글자·캐릭터 없음)

배경 공통 꼬리말 — 네 프롬프트 끝에 모두 붙인다:
```
Same art style as the attached town map: storybook illustration, soft painterly, warm afternoon light,
3/4 view. Portrait 1024x1536. The top 40% shows the room (window, furniture); the bottom 60% is a
very simple, bright, even floor and wall in a warm off-white (#F3EFE6) with no objects, because a
math problem and a number pad will be drawn on top of it. Low saturation and low contrast, as if
seen through a thin haze. No text, no letters, no numbers, no characters, no UI, no logo.
```

### stage-numberland.png — BASIC 수의 나라 (5~7세)
```
Interior of a cozy mushroom-house playroom for small children: a round window with warm yellow
light, wooden blocks and a soft plush toy on a low table, a small rug. Gentle, playful, safe.
```
### stage-prime.png — PRIME 초급
```
Interior of a friendly library whose roof is shaped like an open book: tall bookshelves, a long
wooden desk with a small lamp, and a large window through which a storybook village is visible.
```
### stage-advance.png — ADVANCE 중급
```
A study room inside a village house: a chalkboard (blank, no writing), a globe on a shelf, a
wooden desk, and a window looking out onto a small garden gazebo. Calm and focused.
```
### stage-challenge.png — CHALLENGE 고급
```
Interior of a tower on a hill at night: a spiral staircase curving up along the wall, a tall
window showing a starry sky and a crescent moon, soft blue night light with a warm lantern glow.
Wondrous and inviting, not scary.
```

```
Redraw the attached character EXACTLY: same size, same position in frame, same colors, same

512x512 PNG. Change ONLY the facial expression and the arms as described. No text, no background,
no shadow, no props.
```
