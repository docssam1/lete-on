# Numbers of Magic — 실사 그림 작화 지시서 (유아 단계 · 수학이야기 소품)

> 수신: 이미지 생성 담당(GPT) · 발신: Numbers of Magic 제작팀 (2026-10-04)
> 원장 지시: **"실사 같지 않은 모든 그림"을 실사로 바꾼다.** 지금 앱의 물건·동물·소품은 제작팀이 직접 그린
> 벡터(SVG)라 만화풍이다. 아래 목록을 **사진처럼 보이는 투명 배경 PNG**로 만들어 주세요.
> 사람 캐릭터는 별도 문서(`캐릭터-작화지시서-v2-사실적.md`)이고, 이 문서는 **사람이 아닌 모든 그림**이다.

---

## 1. 반영 방식 (먼저 읽기)
- 그림이 **한 장씩** 도착해도 된다. 제작팀이 `data/real-art.js` 에 한 줄만 추가하면 **그 물건만** 실사로 바뀌고,
  아직 없는 물건은 지금의 그림 그대로 나온다. 전부 모일 때까지 기다리지 않는다.
- 화면(앱)과 **인쇄 학습지**에 같은 PNG가 쓰인다. 인쇄는 흑백 레이저일 수 있으니 **윤곽이 또렷한** 사진일 것.
- 먼저 **시안 3장**(`apple.png` · `rabbit.png` · `sheep.png`)을 올려 주세요. 화풍 확인 후 나머지를 진행합니다.

## 2. 공통 규격 (전부 동일)
| 항목 | 규격 |
|---|---|
| 형식 | PNG, **투명 배경(알파)**, **512×512px** 정사각형 |
| 구도 | 한 개체를 **가운데**, 개체가 캔버스의 **약 88%**를 채움(위·아래 여백 6%) |
| 느낌 | **사진처럼**(포토리얼). 만화·일러스트·3D 장난감 느낌 금지. 어린이가 봐도 편안한 밝은 색과 부드러운 질감 |
| 조명 | 12장 모두 **왼쪽 위 부드러운 스튜디오 조명**, 그림자는 **넣지 않는다**(앱이 바닥 그림자를 따로 얹음) |
| 시점 | 과일·물건은 **살짝 위에서 본 3/4**, 동물은 **옆모습(오른쪽을 봄)** 전신 |
| 가장자리 | 배경 제거 후 **흰 테두리·후광 없이** 깨끗하게(어두운 배경에 올려도 어색하지 않게) |
| 금지 | 글자·숫자·로고·워터마크·브랜드 표식·사람 얼굴·무서운 표정 |
| 줄여도 구분 | 앱에서 **40px 정도로 줄여 써도** 무엇인지 보여야 한다. 디테일보다 **실루엣과 색**이 먼저 |

## 5. C. 수학이야기 N-01 소품 (양치기 이야기) — 먼저 이것부터
수학사 네 컷에 쓰는 소품. 사람(양치기)은 별도 문서의 캐릭터를 쓴다.
| 파일명 | 무엇 | 비고 |
|---|---|---|
| `sheep.png` | 흰 양 한 마리(옆모습, 오른쪽 봄, **털이 복슬복슬**) | 얼굴 검은색 또는 크림색 |
| `sheep-back.png` | 같은 양, 왼쪽을 보는 컷이 필요하면 **앱이 좌우반전**하므로 불필요 | (만들지 않아도 됨) |
| `pebble-1.png` `pebble-2.png` `pebble-3.png` | 회색 **몽돌 3가지 모양**(둥근·납작·길쭉) | 한 개씩, 하이라이트 |
| `pouch.png` | 가죽 주머니 — 입구를 **끈으로 묶은** 모습(안은 비어 있음) | 갈색 가죽 |
| `pouch-stones.png` | 같은 주머니에 **조약돌이 입구 위로 보이는** 모습 | 돌 3~4개 |
| `fence.png` | 나무 울타리 3칸(옆에서 본 모습) | 거친 나뭇결 |
| `cloud-1.png` `cloud-2.png` | 뭉게구름 2종(투명 배경) | 가장자리 부드럽게 |
| `sun.png` / `moon.png` | 해(맑은 낮), 초승달(저녁) | 사진 합성 허용 |
| `meadow.png` | **풀밭 바닥 띠**(가로 1600×400, 투명 위쪽 가장자리 부드럽게) | 컷 아래쪽에 깔림 |
이 소품을 앱의 네 컷 장면에 제작팀이 배치한다. **장면 전체**를 한 장으로 완성해 주시는 것도 환영
(`scene-n01-1.png` … `scene-n01-4.png`, 4:3 가로, 1200×900, 배경 포함, 양치기는 고대 복식의 **일반 인물**로).
네 컷 줄거리: ① 양이 한 마리 나갈 때마다 조약돌을 주머니에 넣는다 ② 양 3마리 ↔ 조약돌 3개를 하나씩 짝짓는다
③ 저녁에 양이 돌아올 때마다 돌을 하나씩 꺼낸다 ④ 돌이 하나 남음 = 양이 한 마리 안 돌아옴.

## 6. D. (2차, 선택) 숫자 0~9 사물 — 글꼴이 아닌 **실제 물건**의 숫자
"글꼴이 제각각인 숫자들 사이에서 같은 숫자 세기" 활동용. 숫자 한 개짜리 **실물 사진**
(`num-<숫자>-<재질>.png`, 재질 5종: `wood`(나무 블록) · `magnet`(플라스틱 자석 글자) · `metal`(금속 주물) ·
`paper`(색종이 오려 붙인) · `clay`(점토). 예: `num-7-wood.png`). 10개 숫자 × 5재질 = 50장 — **시안 후 협의**.
