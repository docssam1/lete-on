# 실사 그림 놓는 자리

`data/real-art.js` 의 `NM_REAL_ART` 표에 **파일명이 적힌 것만** 화면·인쇄에서 실사 PNG 로 쓰이고,
표에 없거나 파일이 없으면 직접 그린 SVG(`app/object-art.js`·`app/animal-art.js`)가 그대로 나온다.
그래서 GPT 가 그림을 한 장씩 올릴 때마다 표에 한 줄씩만 추가하면 된다(전부 모일 때까지 기다릴 필요 없음).

규격과 목록은 저장소 루트 `number_magic/실사-그림-작화지시서.md`.

## 현황 (2026-10-05)
1차 23종 적용 — 세는 물건 16종 전부 + 동물 `rabbit·turtle·bear·fox·raccoon·squirrel` + `sheep`.
미제작 15종(deer·wolf·duck·tiger·pebble-1~3·pouch·pouch-stones·fence·cloud-1·2·sun·moon·meadow)은 SVG 그대로.
GPT 쪽 최종 작화 검수 전 상태 — 사진 표현·동물 옆모습·가장자리 후광은 눈으로 확인 필요.

## 2차 적용 (2026-10-07)
실사-2차 폴더 25장 중 19장 적용 — 구슬 4·동전 2(별·달)·상자 2(닫힘·열림)·개구리·분동·기차 객차·럭비공·야구공·포도·수박·참외·배·연·비구름.
**보류 6장: die-1~6** — 윗면 눈은 맞지만 옆면 두 곳의 눈까지 보여, 40px 에서 "1" 주사위가 점 여러 개로 보인다(눈 세기 문항이 헷갈림).
윗면만 보이는 정면(또는 바로 위에서 본) 주사위로 다시 받으면 적용. 배(pear)는 서양배 모양 — 2026-10-08 원장 결정으로 그대로 쓴다(재작업 취소).

## 3회분 적용 (2026-10-08)
20장 중 19장 적용 — 기관차(`g:train`)·시상대·매표소·칠판·번호표·책상·접시·케이크·초·자물쇠·보석·번호 카드(`g:card`)·양팔저울(`g:scale`, 머리 아이콘만)·손 `hand-0`~`hand-5`.
원본이 1254×1254·최대 2.6MB 로 와서 512×512 로 줄여 넣었다(모두 400KB 이하). `node scripts/check-real-art.js` 가 크기·투명·용량을 지킨다.
- **손**: `app/g1/1-3.art.js` `handSvg()` 가 실사가 있으면 공통 viewBox(5 1 54 63)로 잘라 쓴다 — 좁은 손(1)도 넓은 손(5)과 같은 높이. 화면 카드에서 높이 56px(두 손 42px).
- **시상대**: 실사엔 숫자가 없으므로(지시서대로) 계단 앞면에 1·2·3 을 얹는다(화면·인쇄). 계단 위치는 그림에서 잰 값(가운데 19/51/83%).
- **칠판**: 정사각 그림이라 실사일 때 칸 비율을 1:1 로.
- **보류 1장: dart-target** — 진짜 다트판(20칸·빨강/초록)이라, 아이가 점수를 매기는 3겹 과녁(빨강·흰·파랑, 띠 폭 같음)과 다르다. 재작업 요청.
- **그대로 둔 그림**: 과녁 본체(`G.dartSvg`, 띠 반지름으로 점수)·기울어지는 양팔저울 본체들(실사는 수평)·인쇄에서 CSS 로 그리는 접시·케이크·칠판·자물쇠·책상.
- 보석(gem)은 지시서의 '연한 하늘색'이 아니라 진한 파랑이지만, 지금 화면에 쓰이는 곳이 없어 그대로 넣었다.
- 주사위 die-1~6 재작업분은 아직 안 옴. 배(pear)는 서양배 그대로 쓰기로 함(재작업 취소).

## 4회분 적용 (2026-10-09) — 실사-2차 주문 완료
