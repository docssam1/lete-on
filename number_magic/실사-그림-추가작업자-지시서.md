## 1. 공통 규격 (모든 그림 동일)
| 항목 | 규격 |
|---|---|
| 형식 | PNG, **투명 배경(알파)**, **512×512px** 정사각형 |
| 구도 | 물건 하나를 **가운데**. 물건이 캔버스의 **약 88%**를 채움 |
| 느낌 | **사진처럼(포토리얼)**. 만화·일러스트·3D 장난감 렌더 느낌 금지. 견본 23장과 같은 밝고 부드러운 톤 |
| 조명 | **왼쪽 위에서 오는 부드러운 스튜디오 조명**. **바닥 그림자는 넣지 않는다**(앱이 따로 얹음) |
| 시점 | 물건은 **살짝 위에서 본 3/4**, 동물은 **옆모습 전신·오른쪽을 봄** (항목에 따로 적힌 경우는 그것을 따름) |
| 가장자리 | 배경을 지운 뒤 **흰 테두리·후광이 남지 않게**. 어두운 배경에 올려도 어색하지 않아야 함 |
| 금지 | **글자·숫자·로고·워터마크·브랜드 표식**, 사람 얼굴, 무서운 표정 |
| 작게 봐도 | 앱에서 **40px**까지 줄여 씁니다. 세부보다 **실루엣과 색**이 먼저 알아보여야 함 |

> ⚠ **숫자를 그림에 넣지 마세요.** 주사위 눈(점)은 괜찮지만, 카드·번호표·시상대·분동·기차 칸에
> 숫자를 쓰면 안 됩니다. 숫자는 앱이 그림 위에 얹습니다. 그래서 그 자리는 **비워 두어야** 합니다.
