# 학생용 문장 검토

32개 현행 단원 교재와 등록된 학기평가의 검토한 문장을 단원별로 보관한다.
일반 낱말 치환기가 아니며, `v2/student-language-review.js`가 실제 원고를 읽은 뒤 적용한다.

- `text`: 문장 전체가 같은 경우에만 사용하는 수정 전/후 쌍. 자료의 수치·단위·비교 조건은 보존한다.
- `questions`: 문항 ID와 전체 이전 객체의 `languageFingerprint`로 고정한 수정. `authored` 문항의 발문·자료·보기·해설만 바꾼다. 원문과 정답·응답 계약은 바꾸지 않는다.
- `studentHeaders`: 학생 인쇄물의 설명과 표제. 교사용 원문 등록·검토 정보와 구별한다.

수정 문항은 새 버전과 수정 전 전체 사본을 함께 갖는다. 이전 답안과 고정 시험지는 원래 버전을 복원한다. 문항에 미래 필드나 다른 원고가 들어오면 다시 검토해야 하며, 지문 일부가 비슷하다는 이유로 적용 범위를 넓히지 않는다.

원문 발문·자료·보기·해설에 있는 문자열은 HTML 보정 사전에서 제외한다. 같은 표현이 정답이나 채점 기준에 있는 경우에는 단순히 지우지 말고 답 인정 범위를 함께 검토한다.

검사: `node --experimental-vm-modules --test science-lab/v2/student-language-review.test.mjs`. 기존 화면·인쇄·저장 답안 회귀 검사와 은행 감사도 함께 확인한다.
