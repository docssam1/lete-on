# GFIELD Science Lab 참고 자료 도입 기록

확인·작성: 2026-09-25

사용자 요청: 안쌤 블로그와 영재고사 사이트를 살펴보고 활용할 부분을 가져온다. 적용 대상은 `lete-on/science-lab`의 독쌤 학습 흐름이다. MSG 저장소가 아니다.

이 요청으로 참고 분석·로컬 학습 화면 개선을 진행한다. 실학생 답안 외부 전송, 유료 호출, 운영 저장, 배포·병합까지 승인된 것으로 해석하지 않는다. 원문 문제·풀이·브랜드·이미지·상업 운영 문구를 복제하는 대신 기존 Science Lab 문항과 수동 점검을 개선한다.

## 1. 확인 방법과 상태 구분

- **공개 확인**: 로그인 없이 공개된 페이지의 본문/HTML에서 확인했다. 페이지에 UI가 존재한다는 뜻이며 모든 상호작용을 실행 검증했다는 뜻은 아니다.
- **운영 안내**: 사이트가 구매 후 제공한다고 설명하는 정책·기능이다. 로그인 후 실제 작동 여부는 검증하지 않았다.
- **미확인**: 공개 범위에서 확인할 수 없거나 참고 자료에 없는 기능이다.
- 영재고사는 확인일 현재 판매 시작 전이라고 표시했다. 구매·충전·사진 제출·첨삭 결과 열람은 수행하지 않았다. 제작진 학력과 합격 실적은 자체 소개이므로 독립 검증 결과로 취급하지 않는다.
- 안쌤 블로그는 지필 답안 작성의 교수용 조언으로 사용한다. 모든 영재원/영재학교에 통용되는 공식 채점 규칙이라는 뜻이 아니다.

## 3. 우리 계약에 추가한 해석

아래는 참고 사이트에 구현되어 있다고 주장하는 항목이 아니라 Science Lab에 맞춘 설계다.

1. `assessmentKind`를 설명(`explanation`), 아이디어(`ideas`), 설계(`design`)로 등록한다. 입력 형식 `written/free`와 별개이며, 기존 자유형의 내용·구성·표현·맞춤법 4영역 각 5점 계약을 바꾸지 않는다. 평가 종류만으로 점수나 새 영역을 추가하지 않는다.
2. 서술형의 원점수·원만점을 보존한다. 현재 `required/pass`만 있는 문항은 수치 배점이 확정될 때까지 학생의 수동 점검으로 제공한다. 보고서용 5점 환산은 원점수와 구분한다.
3. 채점 기준에는 근거·배점·부분점수·점수 상한·적용 우선순위를 명시한다. 동일 누락을 두 번 감점하지 않고, 규칙이 없으면 모델이 점수를 만들어 내지 않게 한다.
4. 문항과 루브릭의 버전을 제출 당시 고정한다. 기준 수정에 따른 재채점과 학생이 고쳐 쓴 새 답을 구분하며, 동일 답 재채점을 서로 다른 오개념 증거로 세지 않는다.
5. 원본 사진, 전사문, 학생 확인, 채점 결과, 교사 수정, 처방 결과를 연결한다. 참고 사이트에서 OCR·학생 전사 확인·QR·오개념 진단을 확인한 것은 아니다.
6. 학생에게는 맞은 생각·빠진 생각·다음 행동을 먼저 보여 준다. 창의성의 자동 희귀도, 영재 여부, 합격 가능성은 산출하지 않는다.

자세한 데이터·검증 계약: [GRADING-CONTRACT-DRAFT.md](./GRADING-CONTRACT-DRAFT.md).

## 4. 도입 범위에서 제외한 항목

- 유료/무료 공개 문제와 풀이 원문, 화면 디자인 코드, 로고·브랜드 자산의 복제.
- 포인트 충전, 추천 보상, 구매·환불 및 출시 알림. 현재 학습 개선 요청에 필요한 범위가 아니다.
- 참고 사이트의 성인/학부모 계정 정책이나 법률 설명을 우리 서비스 정책으로 그대로 사용하기.
- 검증하지 못한 서재·첨삭 기능을 실제 동작 확인 또는 완성된 벤치마크로 보고하기.
- 승인되지 않은 문항 배점, 실학생 AI 전송, 사진 보존 정책, 공급자 비용, 배포·병합.
