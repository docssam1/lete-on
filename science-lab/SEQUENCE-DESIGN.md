## 2. 설계 기준 (제안 — 이 기준으로 순서를 판단)

1. **예측이 먼저, 답은 나중.** 결과를 보여 주기 전에 반드시 자기 예측(가설)을 적는다. (예측-관찰-설명 POE)
2. **한 장 = 한 행동.** 읽기·쓰기·조작을 한 장에 섞지 않는다(이미 지키고 있음).
3. **스스로 공부는 한 번에 20~25분.** 넘으면 두 차시로 나눈다. 차시 끝은 "정리"로 닫는다.
4. **쓰기는 꼭 필요한 곳에만.** 생각을 드러내야 할 곳(가설·결론·오개념 되묻기)은 쓰기, 나머지는 고르기·끌어 놓기·짧은 답으로. 쓰기 칸은 차시당 5~6개 이내.
5. **직접 해 보기가 읽기보다 먼저.** 집에 재료가 없는 학생에게 "실험 순서 5장 읽기"는 활동이 아니다. 3D 실험실이 주 활동, 실제 실험 순서는 한 장 요약 + 교재로.
6. **개념은 경험 뒤에(5E의 Explain).** 이미 지키고 있음.
7. **확인은 중간에도.** 개념 직후 1~2문제로 바로 확인(인출), 끝에 나머지. 틀린 오개념은 진단표로 처방.
8. **확장은 고르게.** 토의·창의·영재 3장 연속 쓰기는 피로. 스스로 공부에서는 하나를 고르게 하거나 「도전」으로 선택.
9. **가르치기와 스스로 공부는 같은 뼈대, 다른 속도.** 교실은 토의·배틀·실물 실험이 중심, 집은 3D 실험실·셀프 체크가 중심.

## 4. 제안 순서 (초안)

### 스스로 공부하기 — 2차시로 나눔

**1차시 「해 보기」(약 20~25분)**

| # | 장 | 형식 | 비고 |
|---|---|---|---|
| 1 | 표지 + 오늘의 질문 | 읽기 | 질문 하나를 크게(예: 「왜 어떤 자석은 떠 있을까?」) |
| 2 | 이런 모습 본 적 있나요? | 읽기 | |
| 3 | 미리 생각하기 | **쓰기 1** | 2장 → 1장으로 합침 |
| 4 | 3D로 먼저 보기 — **준비 장면만** | 보기 | 1~2단계(재료·상황)까지만 재생, 결과 장면은 숨김 (`mount3D preview` 이미 있음) |
| 5 | 탐구 목표 | 읽기 | 준비물은 교재로 |
| 6 | 가설 | **쓰기 2** | "~할수록 ~할 것이다" 틀 제공 |
| 7 | 실험 설계 | 고르기 | 바꿀·같게 할·잴 것을 **보기에서 골라 끌어 놓기**(쓰기 대신) |
| 8 | 실험 순서 한눈에 | 읽기 | 5장 → 1장 요약 + 주의 사항. "집에서 해 보려면 교재 ○쪽" |
| 9 | 3D 실험실 | 조작 | 표에 2번 이상 기록해야 다음 |
| 10 | 결과 정리 | **쓰기 3** | 표를 보고 한 문장 |
| 11 | 1차시 정리 | 읽기 | "내 가설은 맞았을까? 다음 시간에 확인해요" |

**2차시 「알아 가기」(약 20~25분)**

| # | 장 | 형식 | 비고 |
|---|---|---|---|
| 1 | 지난 시간 내 가설·결과 다시 보기 | 읽기 | 1차시에 쓴 글을 그대로 보여 줌 |
| 2 | 3D로 다시 보기 — **전체 재생** | 보기 | 이제 결과 장면까지 |
| 3 | 결론 내리기 | **쓰기 4** (핵심 1문항) | 3문항 → 1문항 + 나머지는 고르기 |
| 4 | 개념 노트 | 읽기 | |
| 5 | 바로 확인 1~2 | 선택 | 개념 직후 인출 |
| 6 | 개념 플러스 | 읽기 | |
| 7 | Q. 이런 경우는? | **쓰기 5** | 새 상황에 개념 적용 |
| 8 | 도전 하나 고르기 | 선택 → **쓰기 6** | 토의 / 창의 / 영재 중 하나 |
| 9 | 확인 문제 4개 | 선택 | 틀린 문제 → 진단·처방 |
| 10 | 오늘 배운 것 + 셀프 체크 | 읽기 | |

→ 쓰기 칸 20개 → **6개**, 장 수 31 → **21장(11+10)**, 한 번에 20~25분.

### 가르치기 (90분, 한 차시) — 뼈대는 유지, 순서 두 곳만 고침

- **3D 장면은 가설 뒤로**: 도입에서는 준비 장면만 → 가설·설계 → 실물 실험·배틀 → 결과 뒤 3D 전체 재생으로 확인.
- 「주의하세요」는 실험 전(설계 끝)으로 옮김.
- 토의·창의·영재는 교사가 **그날 하나 고름**(나머지는 숙제·교재).
- 시간표는 그대로: 도입 10 · 설계 15 · 실험 25 · 결과·결론 15 · 개념 10 · 확장 10 · 확인 5.
