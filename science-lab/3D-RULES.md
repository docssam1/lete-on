# 3D 실험실·장면 작성 규칙

> 원장 지시(2026-09-29): "첫 화면의 그림이 가장 확실한 시점으로… 사용자 중심… 이미지가 잘리고 그런 게 아니라."
> 3D 실험(`v2/lab-*.js`)이나 장면(`scenes/*.js`)을 새로 만들거나 고친 사람은 **이 문서를 먼저 읽고, 끝나면 검사기를 돌린다.**

```bash
node scripts/check-science-3d.mjs              # 5실험 × 7화면, 실패하면 exit 1
node scripts/check-science-3d.mjs s41-u03b     # 지정 단원만
SHOTS=/tmp/3d node scripts/check-science-3d.mjs # 화면마다 캡처도 저장(눈으로 한 번 더)
```

검사기는 로컬 정적 서버를 직접 띄우므로 따로 서버를 켤 필요가 없다. **실패 0건이 아니면 main에 올리지 않는다.**

---

## 1. 카메라 — 거리는 쓰지 말고 각도만 정한다

엔진(`engine.js`)이 **자동 맞춤(autoFit)** 을 한다. 장면이 정한 각도(`theta`·`phi`)는 그대로 두고, 보이는 물체가 모두 화면 안(여백 `fitMargin` 0.88)에 드는 **가장 가까운 거리와 가운데**를 직접 계산한다.

| 언제 다시 맞추나 | 설명 |
|---|---|
| 처음 뜰 때 · `stage.setView()` | 항상 |
| 캔버스 비율이 바뀔 때 | 덱·페이지·모바일·전체 화면 전환 포함 |
| 캔버스를 DOM에서 옮길 때 | `canvas.dispatchEvent(new Event('stage:moved'))` — 전체 화면(`addLandscape`)이 이미 쏜다 |
| 실험 중 물체가 움직여 틀이 크게 어긋날 때 | 0.6초마다 잰다. 넓혀야 하면 바로, 좁혀도 되면 1.2초 그대로일 때만, **부드럽게** 옮긴다 |

사용자가 돌리거나 확대한 뒤에는 **절대 카메라를 빼앗지 않는다**(단, 전체 화면을 켜고 끌 때는 새로 잡는다).

### 해야 할 것
- `setView({ theta, phi, dist, target })` — `dist`·`target`은 첫 프레임용 기본값일 뿐, 곧 자동 맞춤이 덮어쓴다. **각도를 신중히 고른다**: 실험의 핵심(뜬 틈, 물 높이, 흙이 쌓인 곳)이 가려지지 않는 각도.
- **움직이는 물체가 있는 실험**(떨어지는 포일, 놓이는 비커 등)은 `frame`으로 "다 놓였을 때"의 작업 공간을 직접 준다.
  ```js
  stage.setView({ theta: 0.75, phi: 1.18, dist: 4.1, target: [0.15, 1.3 + TH, 0],
                  frame: [[-0.8, TH, -0.8], [0.8, TH + 1.9, 0.8]] });   // 삼발이·램프·포일(놓인 뒤)
  ```
- **바닥 역할인 큰 물체**(책상·받침판)는 `obj.userData.noFrame = true`. 이걸 맞춤에 넣으면 주인공이 작아진다(화산 책상이 그랬다).
- 장면 모듈(Player)은 기본적으로 **나중에 나타날 물체까지 포함해** 맞춘다(`frameHidden`). 이야기 도중 카메라가 들썩이지 않게 하려는 것. 끄려면 모듈에 `frameHidden: false`.

### 하지 말 것
- ❌ 거리 숫자를 손으로 맞추기(`dist: 6.6` 하나로 모든 화면을 해결하려는 것). 덱 653×458·폰 322×300·전체 화면 896×760에서 전부 다르게 잘린다 — 2026-09-29 전까지 5개 실험 **전부** 잘렸던 이유.
- ❌ `stage.fitWidth` — 예전 방식. 자동 맞춤이 켜진 무대에서는 무시된다.
- ❌ `orbit.dist`를 update 루프에서 직접 바꾸기. 필요하면 `setView`.
- ❌ 크기 40 넘는 판(배경·바닥)을 맞춤 대상으로 기대하기 — 자동으로 빠진다.

맞춤에서 자동으로 빠지는 것: 입자(`Points`)·선(`Line`)·`noFrame`·크기 40 넘는 판·**아직 숨은 라벨**. InstancedMesh는 인스턴스 전체 상자로 들어간다.

## 2. 라벨

- 라벨은 `kit.label(...)`(스프라이트, `userData.isLabel`)만 쓴다. 엔진의 `fitLabels`가 매 프레임:
  - 화면 크기에 맞춰 글자 크기를 정하고,
  - 좌우 가장자리 밖이면 안으로 밀고,
  - **겹치면 뒤의 것을 아래로**(최대 한 칸), 위아래 가장자리 밖이면 안으로 민다.
- 라벨 위치는 물체 **바로 옆**에. 두 라벨을 같은 높이·가까운 곳에 두지 않는다(좁은 화면에서 연못 「땅」·「물가」가 겹쳤다).
- 라벨에 `center`를 직접 바꾸지 않는다(겹침 보정이 원래 값을 `userData.cy0`에 기억해 쓴다).

## 3. 조작 — 사용자가 길을 잃지 않게

| 입력 | 동작 |
|---|---|
| 끌기 | 돌리기. 일반 화면의 폰은 **옆으로만**(위아래는 페이지 스크롤), 전체 화면은 위아래도 |
| Ctrl+휠(PC) · 두 손가락(폰) | 확대. 범위는 맞춘 거리의 0.35~1.8배 |
| 돌리거나 확대하면 | 캔버스 왼쪽 아래에 **「↺ 처음 시점」** — 누르면 부드럽게 돌아감 |
| 두 번 클릭 | 처음 시점 |

- 물체를 **누르는** 조작(흙 언덕 컵 자리, 연못 심기, 고리 뒤집기)은 `pointerdown`~`pointerup`이 **8px 이내·약 0.4초 이내**일 때만 누른 것으로 친다. 끌기와 구분하려는 것이니 새 실험도 같은 방식.
- **「누르고 있기」 단추**는 `pointerdown/up/leave/cancel` + 키보드(Space·Enter keydown/keyup) + `contextmenu` 막기 + CSS `touch-action: none; user-select: none` 을 모두 갖춘다(`lab-hill3d.js` 참고).
- 안내 문구(`stage3d-hint`)는 기기별: 마우스면 "Ctrl+휠", 손가락이면 "두 손가락".

## 4. 실험 상태 — 버튼을 누르기 전에는 아무것도 저절로 움직이지 않는다

- 초기값으로 "아직 안 함"을 표시하는 변수(예: `foilY: 4` = 아직 안 올림)는 **감소·진행 조건에도 그 범위를 넣는다**.
  ```js
  if (S.foilY > 0 && S.foilY < 3.9) S.foilY = Math.max(0, S.foilY - dt * 4);   // ✅ 누른 뒤에만
  if (S.foilY > 0) S.foilY -= dt * 4;                                          // ❌ 로드되자마자 떨어짐
  ```
  2026-09-29까지 화산 포일·비커가 이 버그로 저절로 떨어졌고, 느린 기기에선 **공중에 멈춰** 보였다.
- `stage.update`가 `opts.isActive()`로 멈출 수 있다는 것을 기억한다 — 멈춘 사이 중간 상태가 화면에 남으면 안 된다.

## 5. 전체 화면

- `addLandscape(host, into)`(`v2/mounts.js`)가 캔버스를 `host` 맨 앞으로 옮기고 나머지를 오른쪽 조작판(`.fl-panel`)에 넣는다. 캔버스를 옮기면 반드시 `stage:moved`를 쏜다(이미 되어 있음).
- 엔진의 보임 감시(IntersectionObserver)는 **마지막 항목**으로 판단한다. 캔버스를 옮기면 한 번에 "안 보임→보임" 두 개가 오는데, 첫 것을 쓰면 3D가 **멈춘다**(2026-09-29 수정).

## 6. 새 실험을 추가할 때 체크리스트

1. `v2/home.js`의 `LABS`와 **`scripts/check-science-3d.mjs`의 `ALL`** 둘 다에 단원 id 추가.
2. `setView`는 각도 위주로. 움직이는 물체가 있으면 `frame`. 바닥은 `noFrame`.
3. 덱에 「3D 실험실 · …」 슬라이드가 있어야 검사기가 찾는다(제목이 `3D 실험실`로 시작).
4. `node scripts/check-science-3d.mjs <id>` → 실패 0.
5. `SHOTS=…`로 캡처해 **눈으로도** 본다: 주인공이 화면의 중심에 크게, 잘린 곳 없이, 라벨이 겹치지 않게.
6. `node --test science-lab/bank/*.test.mjs science-lab/v2/*.test.mjs` → 실패 0.
7. CSS를 바꿨으면 `v2/index.html`·`intro/index.html`의 `?v=` 올리기.
