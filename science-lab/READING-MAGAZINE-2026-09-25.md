# 독쌤 화산 읽을거리 — 잡지형 적용 기록

상태: **화산 읽을거리 로컬 구현·검수 통과 / 원장 최종 확인·공개 배포 전**

## 승인 범위

- 사용자가 제공한 잡지형 참고 이미지의 편집 방식을 읽을거리에 적용한다.
- 대상은 lete-on의 GFIELD Science Lab / 독쌤이다. MSG 별도 저장소·로고·우루사쌤은 변경하지 않는다.
- 화산 단원 `s41-u03b`에 먼저 적용한다. 실험·문제·정답·기존 음성·사진·영상은 유지한다.
- 전체 프로젝트 완료를 뜻하지 않는다. 커밋·푸시·배포·main 병합은 하지 않았다.

## 내용과 재사용 근거

- 제목: 「화산이 지나간 자리에는 무엇이 남을까?」
- 네 꼭지: 산꼭대기 호수 / 현무암과 가스 방울 / 땅속 열 / 이로움과 피해.
- 사진은 기존 `Pahoehoe_toe.jpg`, 영상은 기존 `media.explore`, QR은 기존 `qr-s41-u03b-lab.svg`를 재사용한다.
- 사진 출처: [Hawaii Volcano Observatory (DAS) / USGS, Public domain](https://commons.wikimedia.org/wiki/File:Pahoehoe_toe.jpg).
- 사실 대조: [Smithsonian 백두산](https://volcano.si.edu/volcano.cfm?vn=305060), [UNESCO 제주](https://whc.unesco.org/en/list/1264), [USGS 화성암](https://www.usgs.gov/faqs/what-are-igneous-rocks), [USGS 기공](https://www.usgs.gov/educational-resources/find-feature-vesicles), [USGS 지열](https://www.usgs.gov/volcanoes/coso-volcanic-field), [USGS 화산재·항공](https://pubs.usgs.gov/fs/2010/3116/), [USGS 화산재·농업](https://volcanoes.usgs.gov/volcanic_ash/agriculture.html).
- 천지는 칼데라호로 구분한다. 모든 현무암에 구멍이 있다거나, 모든 온천이 화산 때문이라고 일반화하지 않는다.
- 학습 UI 편집 스킬의 큰 사진·짧은 꼭지·제한된 강조색·모바일 한 단 기준을 적용했다.

## 검수 증거

- Node 테스트 20개 통과(읽을거리·음성 매핑 9, 기존 서술형·오개념·감사 11).
- 문제은행 감사: 기본 문항 70개, 유사 문항 310개 통과. taxonomy JSON 4개 동기화 확인.
- 격리된 새 Chrome에서 PC 1280px, 모바일 390/320px 학습·읽기·교재를 검사했다. 기존 사용자 브라우저 프로필이나 학생 기록에 접근하지 않았다.
- 수업 → 읽을거리 → 학생/교사용 전환 → 인쇄 요청 → 3D 실험실 진입 확인.
- 새 읽기 화면만 이용할 때 학습 기록을 변경하지 않음 확인. 기존 수업/실험 진입의 진도 기록은 기존 동작 그대로다.
- 교재 학생·교사용 12쪽, 읽을거리 7쪽, 네 꼭지 전체 표시, 아래쪽 잘림·꼬리말 겹침 없음 확인.
- 소개 페이지 실제 책에서 PC/390px 새 읽을거리 쪽을 넘겨 표시하고, 고정 A4 두 단 유지와 페이지 안 맞춤 확인.
- 새 읽을거리 학생용 PDF: A4 1쪽, 네 꼭지 텍스트 포함, 교사용 문구 없음, 실제 PDF 렌더 육안 확인.
- PDF의 실험실 링크에 localhost가 들어가지 않고 공개 실험실 주소가 포함됨 확인.
- 최종 PDF 렌더의 QR을 실제 해독한 주소와 링크가 일치:
  `https://lete-on.gfieldacademy.net/science-lab/v2/#/s41-u03b/2/lab`
- 공개 v2 진입점 HTTP 200 확인. 이것을 공개 읽을거리 배포 또는 원격 3D 상호작용 검수로 간주하지 않는다.
- 검사 중 로컬 JavaScript 오류·로컬 404 없음. 다른 단원의 기존 읽기 형식 유지.

## 남은 경계

- 원장 디자인 확인, 다른 단원 확대, 공개 배포는 별도 승인 후 진행한다.
- 전체 교재의 원본 대조·내용·안전 재검수는 이 한 쪽 검수와 별개다. 점검 중 발견한 기존 항목: 공통 탐구 돌아보기의 ‘실제 강’ 문구가 화산 교재에도 나오는 점, 기존 화산 준비물의 ‘석면 그물’ 표현. 이 작업에서는 원본을 임의 변경하지 않았으며, 실제 수업 사용 전 우선 검토가 필요하다.
- 실제 학생 QR 식별·사진 전사·학생 확인·AI 채점은 기존 승인 대기 설계 범위를 그대로 유지한다.

## 추가 승인: 살아 있는 책 → 전체 화면 실험실

사용자 요청: 웹에서는 책 안에서 영상을 재생하고, 실험실로 슬라이드 이동해 큰 화면으로 학습한다. 모바일보다 태블릿·PC를 우선한다.

- 읽을거리의 기존 USGS 화산 영상을 페이지 내부에서 재생한다. 재생 버튼을 눌렀을 때만 영상 소스를 연결한다. 다른 페이지나 팝업으로 보내지 않는다.
- 「실험실로 이동」과 교재의 실험 버튼은 같은 전체 창 실험실을 연다. 280ms 슬라이드이며 동작 줄이기 설정에서는 즉시 전환한다.
- PC·가로 태블릿은 실험 장면과 조작부를 두 열로 나란히 둔다. 세로 태블릿은 위아래 배치한다. 브라우저 자체 전체 화면은 별도 버튼을 눌렀을 때만 요청한다.
- 닫았다 다시 열어도 같은 실험 DOM·진행 상태를 사용하며 책 위치와 버튼 포커스를 복원한다. 단원 이동이나 책 재구성 시에는 실험 리소스를 정리한다.
- 영상·독쌤 안내 음성의 중첩을 막는다. 실험실 진입, 책장 넘김, 탭 숨김, 인쇄 시 영상을 멈춘다. 닫힌 실험실은 입력과 실험 진행을 멈춘다.
- 인쇄는 기존 사진·출처·공개 실험실 QR을 유지한다. 원본 음성·영상·캐릭터 파일을 새로 생성하지 않았다.
- 학습 UI 편집·애니메이션·Three.js 스킬의 읽기 순서, 짧은 전환, 동작 줄이기 및 숨은 장면 정리 기준을 적용했다.
