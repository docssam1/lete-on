# 자바실험실 참고와 사이언스 랩 적용 기준

- 조사일: 2026-10-03
- 사용자 요청: 우리 사이언스 랩에서도 자바 실험실 내용을 참고한다.
- 참고 대상: 자바실험실(Javalab, javalab.org). 공식 설명 페이지와 현재 사이언스 랩 코드를 대조했다.
- 상태: 참고 조사·후속 구현 기준. 아래 개선 기능은 이번 문서 작성으로 구현된 것이 아니다.

## 확인한 내용과 적용할 부분

| 참고 자료 | 공식 페이지에서 확인한 내용 | 우리 프로그램에 적용할 기준 |
| --- | --- | --- |
| [자기력](https://javalab.org/ko/magnetic_force/) | 같은 극·다른 극의 상호 작용을 자기력선과 연결하여 설명한다. 나침반 추가도 안내한다. | 고리 자석의 마주 보는 극과 밀어냄·끌어당김 방향을 선택적으로 표시한다. 방향 화살표와 자기력선은 서로 다른 표시로 다룬다. |
| [물의 상태](https://javalab.org/ko/status_of_water/) | 온도 조절로 상태 변화를 관찰하고 증발도 설명한다. | 기존 얼리기·녹이기 실험 뒤 물속 확대 모형을 연결하여 상태 변화의 까닭을 살핀다. 온도 조절·기체 실험은 현재 얼음 병 실험과 구별되는 후속 확장이다. |
| [재결정](https://javalab.org/ko/recrystallization/) | 가열하여 녹인 물질이 식으면서 결정으로 나오고, 거르는 과정을 설명한다. | 기존 백반 식히기 실험에 녹아 있던 백반이 결정으로 모이는 과정을 설명한다. 냉각 속도 비교와 재결정·분리 실험의 목적을 구분한다. |
| [용수철 저울](https://javalab.org/ko/spring_scale/) | 질량 조절, 힘의 크기·방향 표시, 측정 범위 선택과 질량·중력 단위를 설명한다. | 용수철 단원의 후속 제작·MSG 비교 검수에 활용한다. 영점 확인 → 알맞은 측정 범위 → 추 달기 → 안정된 눈금 읽기 순서를 원본 교재와 맞춘다. |
| [여러 모양 지층 만들기](https://javalab.org/ko/stratum_making/) | 변화를 조합하고 실제와 차이가 있는 수학적 모형임을 밝힌다. | 흙 언덕에서도 실제 교구 기록과 가상 모형 기록을 구분한다. 지층 변형은 현재 침식·퇴적 실험과 다른 확장 단원이다. |

## 현재 구현과 다음 개선 순서

현재 확인한 구현: 고리 뒤집기와 높이·떠 있는 층 기록, 물/얼음 높이·무게 기록, 언덕 경사·물의 양과 깎임·쌓임 기록, 백반 냉각과 결정 크기·개수, 연못 식물·장소 비교. 5단원 교사용 2팀 대결과 새 대결 초기화는 37차에서 구현했다.

1. 자석의 힘 방향 보기: 기존 3D 교구를 재사용하고 표시 켜기/끄기로 마주 보는 극과 상호 작용을 확인한다. 고리 틈의 임의 모형 값을 실제 힘(N)으로 표시하지 않는다.
2. 실험 기록 비교 그림: 확정한 기록에서 높이·무게·깎임·쌓임을 큰 막대 그림으로 비교한다. 조건과 단위를 함께 쓰고, 빈 기록은 0으로 만들지 않는다. 이 기능은 우리 기록 표를 바탕으로 제안한 것으로 자바실험실의 그래프 기능을 확인했다는 뜻이 아니다.
3. 물속 확대·백반 결정 과정: 본 실험과 연결된 선택형 확대 모형으로 원인을 설명한다. 기존 물의 양, 무게 보존과 백반 모형 안내를 유지한다.
4. 용수철 저울: 현재 지필드의 공개 조작형 5단원에는 없는 후속 단원이다. MSG의 용수철·P5 영점 구조와 지필드 원본 단원 구성부터 대조한다.

## 수업·스스로 공부하기 연결

- 실험 안에서 조건 하나 바꾸기 → 관찰 → 표에 적기 → 내 예상과 비교하기를 이어 준다.
- 교사용은 학생이 직접 나와 조작하고 두 팀 기록을 비교하는 흐름으로 연결한다.
- 스스로 공부하기는 예상과 실험이 끝난 뒤 확대 설명을 열어 원리를 확인하도록 한다. 독쌤 자동 안내 대사는 기능이 확정된 후 정리한다.
- 입자 모형·힘 방향·그래프는 기본 화면에 한꺼번에 노출하지 않고 필요한 설명 단계에서 크게 보여 준다. 공식(예: F=mg)과 입자 용어는 학년별 확장으로 다룬다.
- 입자는 이해를 돕는 모형이며 실물 촬영 영상이나 정확한 분자 크기로 안내하지 않는다. 물 분자가 상태 변화만으로 다른 물질이 되는 설명을 만들지 않는다.

## 제작·검수

우리의 기존 Three.js 교구·교육영상·그림·OmniVoice를 재사용하여 자체 구현한다. 출처 제목과 URL은 참고 기록에 남긴다. 자바실험실의 [저작권 정책](https://javalab.org/ko/copyright/)에서 캡처·임베딩의 출처 표시 조건과 시뮬레이션 소스 복제 금지를 확인했다.

3D 수정 전 .claude/skills/science-lab-3d/SKILL.md와 3D-RULES.md를 적용한다. 결과 설명이 예측 단계에 먼저 드러나지 않는지, 표시를 켜고 꺼도 실험 값이 유지되는지, 기록과 그래프 수치·단위가 같은지, 두 팀 상태가 섞이지 않는지 확인한다. PC·390px·전체 화면·키보드·새 대결 초기화 검수와 3D 검사 실패 0 확인 후 main에 반영한다.

음성 생성은 전체 기능 완성·검수 후 한 번에 한다. 기존 음성과 도구는 보존하고 Google TTS는 켜지 않는다.
