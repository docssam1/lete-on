`data/book/s41-u03b.book.js`의 `chapter`와 `plan`을 공통 내용 원장으로 쓴다. 실제 교재는 학생용 A4 책(웹에서는 영상과 3D가 살아 움직이고, 인쇄에서는 정지 화면·QR·출처), 스스로 공부하기, 강의용 16:9 전자칠판으로 나눈다. 학생용 자습에서만 독쌤이 눌러 보기·쓰기·사진 찍기·풀이 설명을 권하고, 맞으면 근거를 칭찬하며 틀리면 힌트를 주고 재시도하게 한다. 강의용에는 독쌤 캐릭터와 자동 음성 설명을 넣지 않는다. 교사는 실험·영상·단계별 답 공개와 교사 노트를 제어한다. 웹 책의 영상은 쪽 안에서 바로 재생한다. `실험실 열기`를 누르면 책이 슬라이드되며 전체 화면 실험실로 넘어가고, 닫으면 원래 쪽·스크롤 위치로 돌아온다. 인쇄에는 영상 대신 출처를 적은 정지 화면과 QR을 남긴다. 말풍선·입 움직임 때문에 책 배경이 깜빡이면 안 된다.

## 자습 상호작용 계약

1. 독쌤은 한 화면에서 한 행동만 안내한다. 학생이 눌러 보고 쓸 시간을 준 뒤 다음 대사로 넘어간다. 음성 끄기·자막·다시 듣기 지원.
2. 예상/결과/결론/안전 규칙/풀이 설명을 활동별로 저장한다. 학생이 최소 한 번 쓰기 전 예시 답 자동 노출 금지. 빈칸을 정답 처리하지 않는다.
3. 사진은 촬영·파일 선택·미리보기·재촬영·삭제를 우선 구현한다. 제출·QR 인쇄·사진 전사·학생 확인·AI 채점은 별도 승인 게이트다. 로컬 미리보기를 “제출 완료”라고 쓰지 않고 학생 사진·이름을 무단 전송하지 않는다.
4. 풀이 설명은 `무엇을 관찰했나 → 근거는 무엇인가 → 결론은 무엇인가`를 학생 말로 쓰거나 녹음하게 한다. 녹음은 명시적 시작·정지·재생·삭제, 저장 범위 고지가 필요하다. 자동 서술 채점이 없으면 “스스로 비교”로 표기한다. 키워드 하나로 맞음/틀림 판정하지 않는다.
5. 선택형 첫 오답에서는 정답 색·정답 문장·해설을 노출하거나 버튼을 잠그지 않는다. 짧은 힌트 후 재선택한다. 다중 선택은 `확인` 버튼으로 채점한다. 정답/풀이 공개는 정답 도달 또는 한 번 시도한 뒤 명시적으로 `풀이 보기`를 누를 때. 보여 준 문항 변형의 ID와 실제 보기 내용을 기억해 같은 변형 재선택을 금지하며, 후보가 소진되면 소진을 알린다.
6. 정답 칭찬은 관찰 근거와 연결한다. 오답은 오개념 확인 질문을 주되 답을 직접 말하지 않는다. 브라우저 저장만 되면 다른 기기에서 기록이 사라질 수 있음을 밝힌다. 교사용 화면에 학생 개인 기록을 섞지 않는다.

## 독쌤 자산 운영

기존 `science-lab/assets`의 독쌤 표정과 승인된 음성·교육영상 자산을 먼저 전수 조사해 재사용한다. 광고 대사를 수업에 억지로 재사용하거나 처음부터 다시 생성하지 않는다. 새 안내는 `cueId / 화면 ID / 표시 문장 / 음성 파일(또는 미제작) / 표정(말하기·기대·칭찬·재도전) / 자막 / 시작·끝 이벤트`로 관리한다. 음성이 없으면 텍스트로만 안내하고 음성이 있다고 표기하지 않는다. 입 움직임은 실제 오디오 재생 상태와 연결한다. 강의용에서는 캐릭터·자동 내레이션을 끈다.
