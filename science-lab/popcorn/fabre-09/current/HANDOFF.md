# 팝콘 실험실 · 파브르 9호 · 전류 파일럿 인수인계

## 사용자 결정

- 3단원 전류부터 파일럿. 스스로 공부하고 집에서 조립할 때 포기하지 않도록 돕는다. 현장 강의에도 사용한다.
- LEGO 안내처럼 부품과 전선을 단계별 3D로 살핀다.
- **모습 선택 없이 한 명**. 첨부 시트의 흰 실험복 코미가 전신으로 움직이며 직접 말한다.
- **넘버스의 누미 목소리**를 OmniVoice로 이어 읽는다. 기존 독쌤 음성·도구는 보존, Google TTS는 사용하지 않는다.

## 구현

- 시작 화면의 자습·조립 도우미·강의 세 가지 진입. 학생은 설명을 듣고 활동을 확인해야 다음으로 간다. 설명 종료만으로 조립 단계를 넘기지 않는다.
- 20단계: 예상 → 안전 확인 → 전지 비교 → 부품 → 종이 → 소켓 → 스위치 → 전선 5단계 → 판 조립 → 밝기 비교 → 관찰 표 → 개념 → 답 확인 → 설명 초안 → 기록 저장·인쇄.
- 전구의 두 접점, 전지끼우개 두 개, 스위치 공통/LOW/HIGH 단자, 판 A–F를 3D로 구성. 연결 단계에는 앞판을 숨겨 전선이 보인다. D판 종이는 스위치 구멍을 덮지 않는다. 확대·회전·분해·조립·위치 강조.
- OFF: 열린 회로. LOW: B1 하나. HIGH: B1/B2 직렬. 별도 병렬 비교에서 하나를 제거해도 남은 전지가 공급한다. 같은 전구/전지 규격에서 약 1.5V/3V를 정성 비교한다.
- 전신 말하기·대기·격려 프레임. 입과 몸의 움직임은 실제 오디오 재생 시각에 연결한다. 잠깐 멈춤·음소거·버퍼링·종료·화면 숨김·단계 이동 시 정지. 음소거는 다음 단계에도 유지. 모션 줄이기 지원. 정밀 음소 립싱크는 아니다.
- 막혔을 때 네 가지 도움말. 뜨거워짐은 실험을 멈추고 보호자가 확인했다고 표시하기 전 재개하지 않는다. 도움말 창만 닫아서는 정지가 풀리지 않는다.
- 3D 전체 화면에서도 코미가 함께 보이고 ‘작게 보기’로 돌아온다.
- 강사용은 자동 음성과 캐릭터 없이 수업을 진행한다. 학생의 로컬 기록을 덮어쓰거나 학생 설명을 투사하지 않는다.
- 말하기 → 수정 가능한 글 초안 → 학생 수정 → 기준과 비교 → 학생 확인. 자동 서술형 점수 없음. 브라우저 인식 서비스로 전달될 수 있음을 안내한다. 앱은 녹음 파일을 저장하지 않는다.
- 이름·학생 ID·사진·QR 인증·서버 업로드·자동 채점 없음. 학습 기록은 기기 로컬 저장, 인쇄와 JSON 내려받기 제공.

## 원본 및 자산 보존

- 비공개 교사용 PDF 21–28쪽·39쪽(인쇄 45–52쪽·63쪽)에서 목표·부품·연결을 확인했다. 원문 PDF·페이지 이미지·원문 해설은 공개 저장소에 넣지 않는다. 문장과 확인 문제 3개는 새로 작성했다.
- 팝콘 대사는 이 폴더의 `narration.json`. 독쌤의 자동 음성 생성 목록에 섞지 않는다.
- 참조 음성·중간 WAV·모델·검수 중간 자료는 E: 비공개 경로 보존. 새 검수 MP3와 발음 검수 요약만 앱 자산이다. 기존 OmniVoice 환경이나 승인 파일은 수정·삭제하지 않았다.
- 새 작업본은 E:의 별도 checkout. 기존 물의 여행 이미지/영상 작업본과 C: 원본을 수정·삭제하지 않았다.

## 확인 범위와 다음 작업

- 사진 기반의 **설명용 3D**이다. 실물 판의 치수·홈·단자 배열을 실제 키트와 맞추는 검수는 필요하다.
- 전구의 3V 사용과 건전지 규격은 보호자 확인. 병렬 비교는 화면에서 진행한다. 화면 밝기는 실제 전류·전지 수명 계산이 아니다.
- 마이크 실제 서비스 연결은 검수하지 않았다. 초안 입력·수정·확인 흐름은 모의 인식 결과로 확인했다. 브라우저·권한·환경에 따라 마이크 사용이 다르다.
- 인쇄는 브라우저 인쇄 화면까지 확인. 개인 인쇄 교재용 QR/사진 채점 설계는 별도 기존 설계 범위이며 이 파일럿에서 구현하지 않았다.
- 검수/실행 방법: [README](README.md), `check.mjs`, `check-3d.mjs`, `assets/audio/voice-qa.json`.
- 완료 검수: 이름·폰트 수정 후 브라우저 학습 흐름 29건, 파일럿 3D 91건, 기존 전체 3D 109건 실패 0. 기존 단위 검사는 101 통과·2 skip·실패 0. 누미 안내 음성 24개 모두 완성·재전사 검수 통과.
