# 팝콘 실험실 · 파브르 9호 · 전류 파일럿

고정된 흰 실험복 코미가 누미의 기존 목소리를 OmniVoice로 이어 읽는다. 모습 선택은 제공하지 않는다. Google TTS와 기기 음성 합성은 사용하지 않는다.

## 실행

저장소 루트에서 정적 서버를 실행하고 `science-lab/popcorn/fabre-09/current/`를 연다. HTML을 파일로 직접 열면 모듈과 음성을 불러올 수 없다.

## 세 가지 진입

- **스스로 공부하기**: 예상 → 안전 확인 → 전지 연결 비교 → 단계별 조립 → 관찰 → 답 확인 → 수정 가능한 설명 초안 → 기록 저장·인쇄. 활동 확인 후 다음 단계로 이동한다.
- **조립 도움 받기**: `assembly.html`의 별도 조립 슬라이드. 코미를 누르면 봉투가 투두둑 뜯어지고 판 부품이 펼쳐진다. 부품을 떼는 준비부터 완성·정리까지 16단계를 따른다. 봉투 소리는 화면에서 끌 수 있으며 기존 안내 음성은 유지한다. 질문·개념·관찰 기록은 요구하지 않는다. 각 단계의 주의점과 도움 요청 문장을 선생님·보호자에게 직접 보여주거나 복사해 전달한다. 실험 학습의 기존 20단계와 기록은 그대로 보존한다.
- **선생님 수업하기**: 자동 음성과 캐릭터 없이 수업을 직접 진행한다. 3D 실험과 전체 화면을 사용하며 학생 저장 기록은 변경하지 않는다.

## 독쌤 사이언스랩 수업 흐름 반영

- 학습 시작 클릭으로 전체 화면에 진입한다(지원되는 브라우저). PC·가로 태블릿은 3D, 코미, 이전/다음을 한 화면에 유지하고 읽을 내용만 내부에서 스크롤한다. 휴대폰은 읽기 흐름과 하단 진행 버튼을 유지한다.
- 단계 목록은 필요할 때 열며, 학생은 완료한 범위로만 이동한다. 키보드 다음도 학생 활동 확인을 건너뛰지 않는다.
- 강사용에는 예상 손들기 집계, 접어 둔 정답·해설 열기, 단계별 발문 노트와 키보드 진행을 제공한다. 입력칸·3D 조작 중에는 진행 단축키가 작동하지 않는다.
- 조립 시범을 누르면 전선이 시작점부터 연결되고 소켓·스위치·판이 조립 위치로 이동한다. 기름종이는 붙인 모습을 보여 준다. 모션 줄이기 환경에서는 완성 위치를 바로 표시한다. 실물로 조립했다는 확인과 화면 연습 기록은 구분한다.
- 설명 후 학생이 사용할 곳과 완료 후 다음 버튼을 강조한다. 학습 활동은 시간만으로 완료되지 않는다.
- `check-class.mjs`로 수업 화면·발문 노트·예상 집계·정답 열기·키보드·조립 시범을 재검수한다.

## 말하고 움직이는 코미

- 첨부 캐릭터의 전신 말하기·대기·격려 프레임을 사용한다.
- 실제 오디오 `playing`에 맞춰 입과 몸이 움직인다. 현재 오디오 시각에 따라 닫힌 입을 섞어 표현한다. 정밀한 음소 립싱크는 아니다.
- 일시 정지·음소거·오류·버퍼링·재생 끝·화면 숨김·단계 이동 시 움직임과 음성이 멈춘다.
- 학습 확인 후 격려 동작, 말하기 초안·셀프 체크 시 듣기 동작. 모션 줄이기 설정을 존중한다.
- 첫 화면의 설명 듣기와 학습 시작은 학생의 클릭으로 시작한다. 학습 진입 후 단계 안내가 자동 재생되며 조립은 학생이 직접 확인한다.

## 원본 근거와 해석

비공개 교사용 PDF의 21–28쪽 및 39쪽(책 인쇄 45–52쪽·63쪽)을 읽고 전류 단원 구조와 스탠드 연결을 확인했다. 원본 PDF·페이지 이미지·원문 해설은 저장소에 넣지 않는다. 화면 문장과 확인 문제는 새로 작성했다.

회로: B1+ → 전구 → 스위치 공통 단자. B1−와 B2+ 사이 연결점은 1단 단자로, B2−는 2단 단자로 이어진다. 가운데는 열린 회로, 1단은 전지 한 개, 2단은 두 개 직렬이다. 병렬 비교는 별도 화면 회로로 구성했다.

전구·전지는 같은 규격·상태를 전제로 약 1.5V / 3V를 비교한다. 밝기는 정성 모형이고 실제 전류·전지 사용 시간을 계산한 물리 시뮬레이션이 아니다.

## 확인할 범위

- 책의 조립 영상: [2단 밝기 스탠드 조립 QR](https://m.site.naver.com/1e5E0). 원본 PDF 23쪽(인쇄 47쪽)에서 확인한 주소이며, 세 가지 모드의 부품 준비·조립·완성 실험 화면에서 새 창으로 연다. 외부 QR 페이지의 영상과 학습 기록은 별개다.

- 3D 판의 치수와 홈은 사진을 해석한 안내 모형이다. 실물 CAD 또는 실제 교구 조립 정합성 검증은 아직 필요하다. 화면 연습과 실물 확인을 별도로 기록한다.
- 음성은 누미 참조와 중간 WAV를 E: 비공개 경로에 보존하고, 검수를 통과한 MP3와 발음 검수 결과만 앱에 넣는다.
- 브라우저 말하기 입력은 지원 여부와 마이크 허용에 따라 달라진다. 결과는 수정 가능한 초안이다. 브라우저의 음성 인식 서비스가 음성을 처리할 수 있으며 이 앱은 녹음 파일을 저장·전송하지 않는다.
- 기록은 현재 기기 로컬 저장소에만 남는다. 이름·학생 ID·사진·서버 업로드·자동 서술형 채점은 구현하지 않았다. 셀프 체크는 체크 기준을 제공한다.
- 병렬 건전지 연결은 화면에서 비교한다. 실제 연결·전구 사용 전압은 보호자가 확인한다. 뜨거워짐 도움말은 실험을 정지시키며 보호자 확인 전 재개하지 않는다.

안전 근거: [Energizer 사용 지침](https://oem.energizer.com/english/dos-donts/), [전지 설계·안전 자료](https://data.energizer.com/pdfs/design_and_safety_overview2.pdf).

## 검수

`check.mjs`는 외부 Playwright 런타임을 `SCIENCE_PLAYWRIGHT`로 지정해서 실행한다. 로컬 서버 주소는 `PILOT_URL`, 캡처 폴더는 `PILOT_SHOTS`로 지정한다. 학생 활동 게이트, 회로 상태, 실제 음성 재생 동작, 정지·음소거, 도움말 정지, 강사용 기록 분리, 모바일·전체 화면을 검수한다.

파일럿은 기존 독쌤의 공용 3D 엔진과 로컬 Three.js를 재사용한다. 기존 단원의 라우팅·음성·영상은 수정하지 않는다. 별도 파일럿이며 기존 6개 단원 검사에 통과했다는 이유로 이 파일럿 검수 완료를 주장하지 않는다.

### 완료 검수 (2026-10-06)

- 수업 흐름·조립 시범 보완 후 학생 학습 전체 흐름 29건·실패 0: PC, 390/360px 모바일, 전체 화면에서 캐릭터 동반·복귀, 실제 음성 움직임·정지·음소거, 강사 기록 분리 확인. 최종 브라우저 흐름은 기본 GPU 경로에서, 3D 크기·잘림 검사는 소프트웨어 WebGL에서 확인했다.
- 독쌤 수업 흐름 보완 검사 17건·실패 0: 1024×768 자습에서 코미·진행 버튼 고정, 학생 키보드 활동 확인 유지, 강사 발문 노트·키보드·집계·정답 열기·입력칸 진행 방지, 전선 연결 시범, 전체 화면 높이, 모바일 강사 화면 확인.
- 실제 음성 24개: 원문 자막 일치, MP3 재생 시간 확인, 재전사 최대 CER 0.103. 누미 참조·중간 WAV는 공개하지 않았다.
- 3D 파일럿 112건·실패 0: 학생/강사 PC, 폰, 작은 폰, 태블릿, PC 전체 화면, 폰 가로 전체 화면. 잘림·크기·맞춤·정리 및 소켓·스위치·판 조립 시범의 실제 시작 위치가 프레임 안에 들어오는지 확인.
- 기존 사이언스랩 전체 3D 109건·실패 0. 기존 단위 검사 101 통과·2 브라우저 검사 skip·실패 0. 파일럿의 브라우저 흐름은 별도 실행한다.
- 음성 동작 별도 검수: 실제 재생·입 프레임·잠깐 멈춤·음소거·단계 간 음소거 유지·종료·격려·듣기·정리 통과.
- 마이크 입력 경계 검수: 모의 인식 결과가 수정 가능한 초안이 되는 것, 미확인 상태에서는 다음 단계가 잠기는 것, 학생 수정·확인 후 진행되는 것 통과. 실제 음성 인식 서비스는 확인하지 않았다.
- 인쇄: 브라우저 인쇄 화면에서 교안/메뉴 제외, 학생 관찰·설명 기록 표시 확인. PDF 파일의 실제 프린터 출력은 확인하지 않았다.

- 이름 최종 결정: **코미**. 제목·브랜드·코미 이름에는 기존 Gaegu 디자인 폰트, 본문에는 읽기용 Pretendard를 사용한다. 24개 안내 음성에는 이전 화면 표현인 “팝콘 도우미”가 포함되지 않아 음성은 재사용했다.

## 스스로 공부하기와 과학 읽을거리

화면과 이어지는 학생용 8쪽 교재, 교사용 3쪽 지도자료, 관찰 메모·인쇄 사용법은 [WORKBOOK.md](WORKBOOK.md)에 정리했다. 첫 화면의 ‘교재 펼치기’ 또는 단계별 ‘교재 보기’에서 이용한다.

- 매 단계에 남은 행동을 구체적으로 표시하고, 용어·조작·설명 쓰기 도움을 펼쳐 볼 수 있다. 비교 활동은 원본에 맞게 한 개/직렬/병렬 및 직렬·병렬 각각 한 개 제거를 구별해 기록한다.
- 화면 안전 약속과 실물 준비 확인은 분리한다. 실물 활동을 표시하려면 기존 보호자·전구 규격 확인을 완료해야 하며, 확인 후 하던 단계로 돌아간다.
- 중간 관찰과 스위치 관찰, 단계 이동을 저장하고 홈에서 이어 할 수 있다. 교사 기록은 학생 저장값과 분리한다.
- ‘과학 읽을거리’는 생활 속 전지 연결, 에디슨·테슬라, 건청궁 최초 전등 이야기와 교재 QR 영상 네 개를 제공한다. 역사 참고 영상 두 개에는 영어/한국어·재현 행사 안내가 있다. 선택 부록을 열어도 실험 상태와 진도는 바뀌지 않는다.
- 출처와 교과 경계는 [READING-SOURCES.md](READING-SOURCES.md)에 기록했다. 20단계 원문, 3D 회로 계산, 기존 음성 파일은 유지한다.
- 추가 검사: `check-study.mjs`를 기존 `SCIENCE_PLAYWRIGHT`, `PILOT_URL`, `PILOT_SHOTS`로 실행한다. `PILOT_CASES`에 쉼표로 구분한 case 이름을 지정하면 해당 회귀만 실행한다. 브라우저들은 순차 실행한다.

## 코미와 조립하기 검수

`check-assembly.mjs`는 데스크톱·휴대폰·가로 전체 화면의 16개 조립 슬라이드, 봉지 열기, 보호자 확인, 실제 전지 모형의 제거·복귀, 3D 잘림·크기, 도움 문장 복사, 뜨거워짐 중단, 기존 학습 기록 보존, 모션 줄이기를 확인한다. 기존 검사와 같은 `SCIENCE_PLAYWRIGHT`, `PILOT_URL`, `PILOT_SHOTS` 설정을 사용한다. `PILOT_CASES`로 검사할 화면을 선택할 수 있다.
