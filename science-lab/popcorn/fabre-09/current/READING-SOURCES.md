## 교육과정 기준

사용자가 제공한 교사용 원본의 Unit 3 「2단 밝기 스탠드」(인쇄 45–52쪽)를 읽기 전용으로 확인했다. 핵심 목표는 전지의 직렬·병렬 연결의 차이와 스탠드 밝기 조절 원리 설명이다. 원본의 실험·개념·생활 적용·탐구 보고서 순서를 기존 20단계 안에서 보조한다. 원본 PDF, 교사용 답안 및 캡처는 공개하지 않는다.

- 전지 한 개, 직렬 두 개, 병렬 두 개의 밝기를 관찰한다.
- 직렬과 병렬 각각에서 전지 한 개를 제거해 관찰한다. 다섯 관찰을 별도로 저장하며 전지가 모두 빠진 상태는 제거 비교 완료로 처리하지 않는다.
- 1단은 전지 한 개, 2단은 두 개 직렬, 가운데는 열린 회로라는 기존 계산·3D·음성은 유지한다.
- 읽을거리와 영상은 선택 부록이며 진도·정답 통과 조건이 아니다.
- 화면 안전 수칙 이해와 실물 준비 확인은 별도 기록이다. 기존 보호자·규격 확인을 실물 활동에 적용한다.
- 기존 24개 코미 음성과 자막은 유지한다. 새 안내와 기사는 글로 제공하며 대체 음성을 생성하지 않는다.

설계는 사용자 요청에 따라 Astra가 수행했고, 원본 텍스트와 이미지에 맞춰 구현 범위를 검토했다. 원본 파일·본문은 뉴턴 9호로 표시되고 앱은 기존 사용자 지정 파브르 9호를 사용한다. 이번 작업은 명칭을 변경하지 않는다.

문안은 아래 자료를 바탕으로 새로 요약했다. 초상·원본 사진·영상은 복제하지 않았다. SVG는 회로 연결과 장치 역할을 설명하는 자체 개념도이며 역사 현장을 재현한 그림이 아니다.
