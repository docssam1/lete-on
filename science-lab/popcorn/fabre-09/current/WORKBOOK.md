## 화면에서 사용하기

- 홈의 **교재 펼치기** 또는 학습 화면 상단의 **교재 보기**를 누른다. 현재 단계에 맞는 교재 쪽이 열리고, 쪽 번호로 이동할 수 있다.
- 학생은 **내 기록**과 **빈 교재**를 고른다. 선생님 수업에서는 **교사용 지도자료**와 **학생용 빈 교재**를 고르며 학생의 저장 내용을 읽거나 수정하지 않는다.
- 교재의 실험 이동 버튼은 이미 도달한 단계에만 열린다. 교재를 열고 닫는 동안 현재 단계·전지 선택·3D 객체·저장 기록을 보존한다. 닫기와 Esc로 돌아오며 Tab은 모달 안에서 이동한다.
- 8쪽의 읽기 버튼은 기존 과학 읽을거리로 이어진다. 생활·역사 기사와 원본 교재 영상은 선택 자료이며 학습 완료 조건이 아니다.
- 기존 교재의 영상 주소 네 개를 새 창으로 연다. 주소는 인쇄 교재에도 표시한다. 원본 영상·사진을 복제하거나 재업로드하지 않았다.

## 기록 방식

관찰 다섯 가지마다 밝기와 이유를 선택적으로 적을 수 있다. 예상의 까닭, 막힌 곳과 고쳐 본 방법, 바뀐 생각, 다음 질문도 선택 메모다. 메모만 적어서는 관찰 완료나 단계 통과가 되지 않는다.

- 저장 키는 기존 `popcorn.fabre09.current.v1`을 유지한다. 비교 메모는 `comparisonNotes`, 네 가지 생각 메모는 `workbookNotes`에 저장한다.
- 스위치 관찰은 `recordSets.screen`과 `recordSets.real`로 나눈다. `recordKind`를 바꾸면 해당 출처의 기록을 불러오며 `records`는 현재 선택한 기록을 유지한다.
- 이전 단일 `records`는 기존 `recordKind`에 해당하는 묶음으로 옮겨 읽는다. 없는 출처·메모·밝기를 만들어 채우지 않는다.
- 실물 관찰로 바꾸려면 보호자와 준비 확인 세 가지를 마쳐야 한다. 미확인 상태에서는 안전 화면으로 돌아간다. 확인 후 원래 화면에서 실물 교구를 선택해 기록한다.
- 관찰 완료 ID만 있고 직접 적은 내용이 없으면 **관찰함 · 내용 미기록**으로 표시한다. 예상 답이나 모범 답안을 자동으로 넣지 않는다.
- 기록은 현재 기기의 현재 브라우저·사이트 로컬 저장소에만 남는다. 다른 기기와 동기화하지 않으며 서버 제출·학생별 인증·사진 채점은 구현하지 않았다. 저장한 글은 HTML로 실행하지 않고 문자로 표시한다.

## 교재와 인쇄

**교재 인쇄**는 현재 선택한 교재만 출력한다. 빈 교재에는 학생 기록이 없고, 내 기록에는 직접 남긴 내용이 들어간다. 교사용 설명은 학생 화면·학생 인쇄에 넣지 않는다. 길게 쓴 설명과 메모는 9쪽부터 **내 기록 이어쓰기**로 이어지므로 내 기록의 실제 쪽 수는 8쪽보다 늘 수 있다.

| 경로 | 용도 |
| --- | --- |
| [docs/student-workbook.pdf](docs/student-workbook.pdf) | 배포용 학생 빈 교재 8쪽 |
| [docs/teacher-guide.pdf](docs/teacher-guide.pdf) | 별도 교사용 지도자료 3쪽 |
| [workbook.html](workbook.html) | 저장 기록을 읽지 않는 학생 빈 교재 미리보기 |
| [workbook.html?teacher=1](workbook.html?teacher=1) | 저장 기록을 읽지 않는 교사용 미리보기 |

인쇄에는 선택 교재만 임시로 만들고, 인쇄가 끝나면 제거한다. 실험 화면·3D·도구 모음은 교재 인쇄에서 제외한다. 학생과 교사의 화면·출력 분리는 UI 동작이며, 공개 정적 교사용 파일에 접근 권한 인증을 추가한 것은 아니다.

## 개발·검수 도구

저장소 루트를 제공하는 정적 서버가 필요하다. 해당 폴더에서 실행하며 공유 Playwright를 사용할 때는 `SCIENCE_PLAYWRIGHT`에 해당 모듈의 파일 URL을 지정한다. 미지정 시 설치된 `playwright`를 사용한다. 브라우저 검사는 순차 실행한다.

```powershell
Set-Location 'E:/Codex/workspaces/popcorn-fabre09-20261006/science-lab/popcorn/fabre-09/current'
$env:PILOT_URL = 'http://127.0.0.1:39247/science-lab/popcorn/fabre-09/current/'
$env:PILOT_SHOTS = 'E:/Codex/visualizations/2026/10/06/popcorn-fabre09/workbook-qa'
node ./check-workbook.mjs
node ./export-workbook.mjs
```

- `check-workbook.mjs`: 저장·복원·출처 분리·안전 확인·모달·교사 분리·문자 이스케이프·인쇄·긴 기록·1440×900/390×844/844×390 화면을 검사한다. `PILOT_CASES`에 사례 이름을 쉼표로 지정하면 일부만 실행한다. 예: `comparison-notes,record-sources-safety,long-report-print`. 실패해도 `PILOT_SHOTS`에 `workbook-qa.json`과 진단 화면을 남긴다.
- `export-workbook.mjs`: 화면과 같은 교재 렌더러로 학생 빈 교재·교사용 A4 PDF를 만든다. 학생 저장값을 읽지 않는다. 기본 출력은 이 폴더의 `docs/`이며 `PILOT_PDF_OUT`으로 다른 경로를 지정할 수 있다. `PILOT_SHOTS`를 지정하면 `workbook-pdf-layout.json`도 남긴다.
- 주요 구현은 `notebook.js`/`notebook.css`(선택 메모), `workbook-pages.js`(학생 교재), `workbook-teacher.js`(교사 자료), `workbook.js`/`workbook.css`(보기·인쇄), `workbook.html`(독립 미리보기)이다. `app.js`가 실험 화면과 연결한다.
