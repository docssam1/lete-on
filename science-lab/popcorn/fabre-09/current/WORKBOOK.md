# 전류 탐험 교재 · 사용과 인수인계

2026-10-07 개정. 사용자 제공 팩토사이언스 플러스 뉴턴 9호 Unit 3의 책 45–52쪽(PDF 21–28쪽)을 읽기 전용으로 확인하고, 기존 20단계 실험에 학생용 17쪽·교사용 4쪽을 연결했다. 원본의 실험·개념·생활·보고서·평가를 복원하고 실사와 팝콘 설명, 읽을거리와 영상으로 확장했다. 자료와 이용 조건은 [READING-SOURCES.md](READING-SOURCES.md)에 있다.

영재성 탐구는 원본 개념에 기초한 추가 문제이며 능력 판정 검사가 아니다. 원본 Unit 3에는 ‘영재성 검사’라는 제목의 코너가 없다. 자기평가는 학생의 돌아보기이며 점수로 진단하지 않는다. 사용 시간은 직접 측정하지 않았다면 개념 설명으로 구별한다.

교사용 T1은 목표·20단계 매핑·안전·발문, T2는 기대 관찰과 원본 문제의 설명, T3는 추가 탐구의 근거와 발문, T4는 역사·영상 활용과 출처다. 학생의 개인 기록을 교사용 렌더러에 전달하지 않는다.

## 살아 있는 책으로 읽기

- 홈의 **교재 펼치기**, 실험 중 **교재 보기**로 현재 단계의 지면을 연다. 앞·다음·쪽 번호·모아 보기를 사용한다. 교재를 닫으면 기존 실험과 3D 객체가 그대로 남는다.
- 사용자가 제공한 팝콘 랩코니 포즈를 17개 지면에 재사용했다. 설명은 새 지면 문장이고, **실험 안내 듣기**는 기존 승인 MP3와 그 원문 자막이다. 새 설명을 기존 음성이 읽는 것처럼 표시하지 않는다. 말하는 동안 포즈를 바꾸며 동작 줄이기에서는 정지 포즈를 쓴다.
- 원본 문항은 고른 뒤 확인할 때 해설 모듈을 불러온다. 고른 답을 바꾸거나 학생 기록을 자동 정답으로 채우지 않는다.
- 자기평가와 확인문제 선택은 이번 교재 읽기 동안 유지된다. 교재를 다시 열거나 종류를 바꾸면 초기화되며 서버·기기 저장 기록으로 표시하지 않는다.
- 역사 기사 전체를 지면에서 읽는다. 원본 영상 5개는 QR·새 창 링크, 역사 영상 2개는 선택 삽입 재생·새 창 링크·인쇄 QR로 제공한다. 페이지 이동·교재 닫기·인쇄·화면 숨김에서 음성과 삽입 영상을 멈춘다. 자동 재생하지 않는다.
- 실험 사진을 확대해 보고 Esc로 사진만 닫을 수 있다. 원본 비교 사진은 다섯 관찰을 마친 뒤 화면에서 공개한다. 인쇄에서는 3–4쪽 관찰 후 8쪽을 살펴보도록 안내한다.
- 실사 사진과 Pretendard·팝콘 이미지가 준비되어야 인쇄 버튼을 켠다. Gaegu는 표지의 짧은 주석에만 쓴다. 원본의 하늘색·민트·분홍·연두를 활동 구분에 재사용한다.

## 기록·인쇄·분리

기존 저장 키 `popcorn.fabre09.current.v1`, `comparisonNotes`, `workbookNotes`, `recordSets.screen`·`recordSets.real`, `recordKind`를 유지한다. 기존 단일 기록은 자신의 출처로만 읽고, 없는 결과를 만들어 넣지 않는다. 선택 메모는 단계 완료를 대신하지 않는다. 실물 준비 확인은 화면 안전 약속과 별도다.

**빈 교재**는 학생 답이 없는 17쪽이다. **내 기록**은 직접 남긴 글과 현재 읽기의 선택만 출력하며 긴 글은 18쪽부터 이어쓴다. **교사용 지도자료**는 별도 4쪽이다. 모범 답·교사 설명을 학생 인쇄에 넣지 않는다. 교사 정적 파일의 분리는 인증 기능을 의미하지 않는다.

교재에서 작성하는 선택에는 서버 제출·기기 간 동기화·학생별 인증·사진 채점을 추가하지 않았다. 기존 장문 기록은 지우거나 줄이지 않고 문자로 출력한다. 인쇄 중에는 선택 교재만 만들고 종료 후 제거한다. 준비 중인 교재는 준비 안내만 출력한다.

## 구현과 검수

정적 서버가 저장소 루트를 제공해야 한다. `SCIENCE_PLAYWRIGHT`에 공유 Playwright 파일 URL, `PILOT_URL`에 파일럿 주소, `PILOT_SHOTS`에 검수 폴더를 지정한다. 브라우저 검사는 순차 실행한다.

- `check-workbook.mjs`: 기존 기록·출처·안전·교사 분리·모달·장문·응답 이스케이프·세 화면·실제 인쇄 버튼 회귀. `PILOT_CASES`로 실패 사례만 재실행할 수 있다. 반복 인쇄는 headless Chromium 취소 후 제한을 고려해 3초 간격으로 검사한다.
- `check-living-book.mjs`: 팝콘 17지면·원본 확인문제·자기평가·실제 승인 음성·동작 줄이기·영상 삽입/복귀·빈 인쇄·개인 기록 보호를 세 화면에서 검사한다.
- `export-workbook.mjs`: 같은 렌더러로 A4 PDF를 만든다. 실제 A4 내용 폭에서 높이를 검사하고 넘치면 출력 작업을 실패시킨다. `PILOT_PDF_OUT`으로 출력 위치를 바꿀 수 있다.
- `check-study.mjs`와 `check-3d.mjs`: 기존 자습·읽기·안전과 관련 3D 회귀다.

현재 검수 근거: `E:/Codex/visualizations/2026/10/07/popcorn-complete-book/`. 교재 11사례·300항목(최초 실패 사례를 수정 후 재검사한 합본), 살아 있는 책 3화면·45항목, 독립 학생/교사 6사례·54항목을 확인했다. 학생·교사 A4 전체 21쪽의 렌더·글자 경계·워터마크를 확인했고, 72줄 기록은 실제 24쪽에 순서대로 전부 남는다. 교사 자료를 불러오는 중에는 준비 안내 1쪽만 출력된다. 글꼴은 실제 Chromium에서 Pretendard·Gaegu 로드를 확인했다. 자습 7사례·223항목과 관련 3D 112사례도 통과했으며 `test`·`compare`의 두 전지 복귀를 재확인했다.

외부 영상은 삽입 대상·출처·새 창 대체·페이지 이동 시 종료를 확인했다. 모든 기기의 전체 영상 재생과 실물 프린터 출력은 확인하지 않았다. 기존 승인 음성 24개, 20단계, 회로 조건, 3D 코드·실험 사진·공용 글꼴을 작업 시작 커밋과 대조한다. 공개 배포 여부는 별도 검증 기록으로 확인한다.

원본 PDF·공식 답안·전체 페이지 캡처·사용자 원본 캐릭터는 기존 위치에 보존한다. 개별 실험 사진과 승인 포즈를 재사용하고, 건청궁 현재 사진은 공식 공개 자료의 공공누리 출처를 표시했다. 새 개발·검수 자료는 E:에 저장한다. C: 원본·세션·기존 프로젝트는 이동하거나 삭제하지 않는다.
