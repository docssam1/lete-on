# Grade 6 학생·교사 실제 운영 흐름

기준일: 2026-08-28
대상: `asm-bdg-grade6-entry-plan-v1`
상태: 서버·콘텐츠 출시 기반 구현 중, 실제 학생 응시 잠금

## 1. 제품 경계

공개 홈·카탈로그·진단 페이지는 프로그램 구조를 설명하는 미리보기다. URL의 `role=student` 또는 `role=teacher`는 화면 설명을 바꿀 뿐 권한을 부여하지 않는다. 실제 학생 기록, 문항, 배정, 채점, 교사 근거는 인증 뒤의 별도 전달 경로에서만 제공한다.

```text
공개 안내
  ├─ 목표·학년·영역 지도
  ├─ 학생/교사 흐름 미리보기
  └─ Grade 6의 42문항 설계와 현재 잠금 상태

인증된 학생
  └─ 오늘 학습 → 응시 → 교사 검토 대기 → 결과 → 확인된 연습 → 유지 확인

인증된 교사
  └─ 설계표 → 근거 검토 → 교사 채점 → 경로 확인 → 자료 배정 → 유지 확인
```

현재 Grade 6 계획은 5개 영역·10개 클러스터·42개 슬롯이다. 기초 10, 핵심 22, 심화 10이며 자동채점 32개와 교사채점 10개로 구성된다. 이는 폼 설계 계약이지 공개 시험이 아니다. 42개 슬롯 모두에 독립 검수와 서버 서명이 끝난 문항이 연결되기 전에는 배치 진단을 시작할 수 없다.

## 2. 학생 화면

학생 홈의 첫 목적은 지금 해야 할 한 가지를 명확히 보여 주는 것이다.

1. `Grade 6 · 현재 단원 · 배정 상태`
2. 오늘 할 일: 활동명, 클러스터, 목적, 예상 시간
3. 공개된 진단 결과: 5개 영역, 클러스터 근거, 오류 유형, 문항번호별 코멘트
4. 교사가 확인한 다음 연습: 보완, 핵심 적용, 전이·심화
5. 완료 기록과 최소 7일 뒤의 유지 확인

실제 배정이 없거나 콘텐츠가 잠겨 있으면 `학습 시작` 버튼을 만들지 않는다. 잠금 이유와 다음 해제 조건만 표시한다. 학생에게는 다른 학생, 내부 문항 ID, 정답, 풀이, 루브릭, 채점키, 정책 소유자, 교사 그룹을 전달하지 않는다.

```text
no-assignment
  → assignment-pending-release
  → assigned-ready
  → in-progress
  → submitted
  → automatic-score-complete
  → teacher-review-pending
  → result-published
  → route-candidate
  → teacher-confirmed
  → practice-assigned
  → retention-due
  → retention-complete
```

학생 브라우저는 원응답만 제출한다. `awardedPoints`, `errorType`, `scoringReview`, 정답 또는 루브릭을 포함한 요청은 서버가 거절해야 한다.

화면의 진행 문구와 데이터베이스 상태는 같은 값으로 뭉치지 않는다. 배정은 `assigned → opened → submitted → closed`(중간에 `cancelled` 가능), 응시는 `in-progress → submitted → scored → finalized`(중간에 `void` 가능)로 각각 단방향 전이한다. 두 행은 트랜잭션 종료 시 함께 검사하므로 제출·종료·취소 중 하나만 바뀐 모순 상태는 커밋되지 않는다. 철회·정지·폼 또는 정책 종료 뒤에도 서버는 `void → cancelled` 정리를 한 트랜잭션으로 완료할 수 있다. 학생 화면의 `teacher-review-pending` 같은 문구는 이 두 상태와 교사 검토 건수를 조합한 표시일 뿐 별도 권위 상태가 아니다.

## 3. 교사 화면

교사 홈의 첫 목적은 점수표를 보는 것이 아니라 근거를 확인하고 검수된 자료만 배정하는 것이다.

1. 42개 슬롯의 문항 상태: 없음, 검토 중, 서명됨, 철회됨
2. 학생별 영역·클러스터·오류 근거와 교사 채점 대기열
3. `보완 우선`, `핵심 적용`, `전이·심화` 그룹 제안
4. 학생·클러스터·학생 자료·교사 자료를 함께 확인하는 배정 작업대
5. 진단, 단원 숙달, 유지 확인, 교사 검토를 묶은 학교 검토 자료

그룹은 자동 반 배정이 아니다. 교사가 근거를 확인하고 수정한 뒤에만 배정 초안이 된다. 교사는 서버에 명시적으로 연결된 학생만 볼 수 있어야 한다.

학생은 `student` 대상의 최종 리포트·로드맵만 읽는다. 유효한 학생 범위를 가진 교사는 검토를 위해 `teacher` 대상 초안과 최종본을 읽을 수 있지만, 학생 대상 초안이나 다른 학생 자료는 읽을 수 없다. 계정이 정지되거나 학생이 비활성화되거나 교사 범위가 끝나는 즉시 기존 연결도 접근 권한을 잃는다.

```text
blueprint-template
  → reviewed-items-bound
  → signed-content-available
  → evidence-review
  → group-suggestion
  → teacher-confirmed
  → assignment-draft
  → assignment-published
  → student-submitted
  → teacher-review-complete
  → result-published
```

## 4. 서버 권위 데이터

브라우저 저장소와 공개 JSON은 권위 데이터가 아니다. 서버는 최소 다음 기록을 소유한다.

| 데이터 | 서버가 보장할 것 |
| --- | --- |
| 평가 폼과 폼 문항 | 42개 고유 슬롯, blueprint 버전·정렬된 42-slot 계약 hash·정확한 slot ID, 문항 버전·서명 배포본·manifest 공개 hash |
| 학생 배정 | 학생 계정, 폼, 정책 버전, 기한, 상태 |
| 응시와 원응답 | 학생 본인 소유권, 제출 후 불변 기록 |
| 자동·교사 채점 | 브라우저 입력과 분리된 서버 계산 및 교사 검토 |
| 정책과 증거 | 학교가 버전 관리하는 기준, 진단·숙달·유지·검토 근거 |
| 리포트와 로드맵 | 서버가 원자료를 다시 계산해 발급한 불변 스냅샷 |

계정의 `gmt-...` 공개 ID와 분석 엔진의 `lrm-bdg-...` 학습자 ID는 서버 전용 매핑으로 연결한다. URL, 쿼리 문자열 또는 브라우저 저장소에 이 매핑을 넣지 않는다.

## 5. 출시 게이트

아래 조건은 모두 이진 검사로 통과해야 한다.

- 폼이 Grade 6 설계의 42개 고유 슬롯을 정확히 채운다.
- 각 문항의 영역, 클러스터, 난이도, 응답형식, 채점방식이 슬롯과 일치한다.
- 모든 문항은 유효한 signed release이며 철회되지 않았다.
- 철회는 서명 행을 덮어쓰지 않고 관리자·사유·시각을 가진 별도 append-only 기록으로 남는다.
- 학생 전달과 리포트에서 정답·풀이·루브릭·private hash 누출이 0건이다.
- 학생은 자기 배정·응답·리포트만 읽고 쓸 수 있다.
- 학생 제출에는 원응답만 있으며 브라우저가 점수를 지정할 수 없다.
- 원응답을 새로 쓰거나 고칠 때마다 열린 배정, 진행 중 응시, 활성 계정·학생, 공개 중인 폼·정책, 42개 서명·미철회 문항을 서버가 다시 확인한다.
- 자동채점 32개와 교사채점 10개가 모두 확정되기 전에는 최종 리포트를 발급하지 않는다.
- 서버 재계산 결과가 저장 점수·영역 합계·문항 순서와 정확히 일치한다.
- 어떤 점수에서도 `automaticPromotion`은 `false`이고 결과는 `school-review-required`다.
- 서명된 학습 콘텐츠와 교사 확인이 없으면 로드맵 자료와 다운로드는 잠긴다.

## 7. 화면·출력 기준

- 모바일 학생 화면은 한 열이며 오늘 할 일이 가장 먼저 보인다.
- 모바일 교사 화면은 넓은 표 대신 접히는 근거 카드를 사용한다.
- 320px에서 가로 넘침이 없어야 하고 모든 주요 조작 영역은 최소 44px다.
- 키보드 건너뛰기 링크, 논리적 탭 순서, 선택 상태, 포커스 복귀를 제공한다.
- 상태 변경은 `aria-live="polite"`로 알리고 색만으로 수준을 구분하지 않는다.
- 평가 중 화면, 타이머, 정답, 교사 전용 근거는 인쇄하지 않는다.
- 교사가 승인한 리포트·워크북만 서버 발행본과 워터마크로 출력한다.
- `prefers-reduced-motion`에서는 상태 애니메이션을 즉시 완료한다.
