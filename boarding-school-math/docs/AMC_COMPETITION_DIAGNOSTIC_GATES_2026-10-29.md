# 경시 대비 진단: 현재 범위와 출시 관문

작성일: 2026-10-29 (KST)

## 현재 제품에서 가능한 것

- Grade 6 AMC 8 브리지의 GFIELD 자체 제작 10문항을 풀고, 이 세트의 문항별 첫 응답·재시도 횟수를 브라우저에 기록한다.
- 자체 제작 10문항은 문항별 응답만 보인다. 해당 세트의 영역별 점수, 강점·약점, 준비도 등급, AMC 점수 환산, 수상·자격 예측, 다음 학습 처방은 제공하지 않는다.
- 답안 기록은 현재 브라우저에만 저장되며 계정·교사 성적부로 전송되지 않는다.
- 학생에게 보이는 이름은 **AMC 8 주제 연습 · GFIELD 자체 제작**이다. 공식 AMC 진단이나 모의고사가 아니다.
- 별도 수동 복습 화면은 사용자가 채점한 외부 AMC 시험의 문항 응답을 요약한다. 완전한 25문항 입력에 한해 역사적 MAA 시험지 배점 방식에 따른 참고 원점수를 보여 주며, 공식 성적표와 선택한 시험지의 지시를 대체하지 않는다.
- 사용자가 실제 성적표에서 옮긴 AMC 8/10/12 원점수는 대회별 기록표에 나란히 입력할 수 있다. 기록은 현재 탭 메모리에만 두고 JSON 파일로 직접 저장·가져오며, 이름·답안·교사 계정은 기록하지 않는다. 시험지 난도 보정, 성장 등급, 준비도 판정은 하지 않는다.
- 2026–27 미국·캐나다 AMC 10/12의 AIME 고정 원점수 기준은 사용자가 응시 지역에서 미국·캐나다 MAA 경로를 명시적으로 선택했을 때만 공개된 MAA 안내에 따라 참고 정보로 표시한다. 이는 자격 판정이 아니며, 2027년 AIME에는 만 13세 이상 및 기타 조건이 별도로 적용된다. 국제 AMC 경로를 선택하면 점수 기준을 표시하지 않고 국가별 International Group Leader 안내로 연결한다.

### 외부 학교 평가 입력 경계 (2026-10-30)

학교 Placement, MAP Growth, ERB CTP, SSAT, ISEE 입력 화면은 원점수·성적표 백분위·비교집단·Stanine과 사용자가 선택한 현재/목표 과정을 나란히 보여 준다. MAP의 RIT를 학년 등급으로 바꾸거나, 전체 점수·백분위에 임의의 GFIELD 준비도 밴드를 붙이지 않는다. 영역 성적표 값을 낮은 순으로 정리할 수 있지만, 내부 70% 컷이나 자동 약점·수업 기간 처방은 적용하지 않는다. ISEE의 Quantitative Reasoning 및 Mathematics Achievement Stanine은 별도 값으로 유지하고 평균을 만들어 공식 점수처럼 표시하지 않는다. 학교가 직접 제공한 Placement 컷을 사용자가 입력한 경우, 그 컷 충족 여부만 표시하고 최종 배정은 학교 판단으로 둔다.

이 경계는 MAP의 RIT가 학년별 문항 난도와 직접 동치가 아니며, 백분위가 같은 학년·과목 규준집단에서의 상대 위치라는 NWEA 설명 및 ERB의 percentile/stanine 정의를 따르는 최소한의 표시 규칙이다. 점수의 규준연도와 비교집단은 성적표를 우선한다. Sources: [NWEA: Comparing RIT scores across grade levels](https://connection.nwea.org/s/article/Comparing-RIT-scores-across-grade-levels), [NWEA 2025 MAP Growth norms](https://www.nwea.org/map-growth-norms/), [ERB CTP score report help](https://www.erblearn.org/ctpscorereporthelp/).

10문항은 영역별 1–3문항으로 나뉘며 일부 주제는 한 문항뿐이다. 표본 응답과 독립적인 타당도 근거도 없으므로 Grade 7 학생의 영역 숙달, AMC 준비도, 점수 예측을 판단할 수 없다. 현재 세트는 Grade 6 개념 연결 연습이라는 원래 범위를 유지한다.

## AMC 8 공식 범위 경계

MAA의 현재 AMC 안내는 AMC 8을 Grade 8 이하 대상 25문항·40분 시험으로 설명하며, 중학교 수학 중 경우의 수와 확률, 어림, 비례 추론, 기초 기하(피타고라스 정리 포함), 공간 시각화, 그래프와 표 해석, 일부 초기 대수 주제를 열거한다. 자격과 운영 규칙은 바뀔 수 있으므로 실제 응시 안내는 MAA의 현재 규정에 연결한다.

- 공식 개요: https://maa.org/student-programs/amc/
- 공식 정책: https://maa.org/student-programs/amc/maa-american-mathematics-competitions-policies/
- 확인일: 2026-10-29

공식 범위·형식은 GFIELD가 직접 쓴 새 문항을 설계할 때 참고할 수 있다. 공개 기출·해설을 복제하거나 외부 공개 화면에 재배포하는 권한으로 해석하지 않는다. 상업적 재현·배포 권한이 필요하면 MAA의 서면 허가 절차를 별도로 확인한다.

## 정식 자체 진단을 만들기 위한 제안 관문

아래는 출시 기준을 만들기 위한 설계 제안이며, 검증된 측정 규준이나 AMC 등가 점수 기준이 아니다.

1. **범위표와 청사진 승인**
   - MAA의 AMC 8 범위에 맞는 보고 축, 문항 수, 난도 분포, 풀이 시간, 문항 순서를 사전에 고정한다.
   - 영역별 결과를 내보내려면 그 축마다 여러 독립 문항을 배정한다. 초기 청사진은 축당 6–8문항을 검토 시작점으로 삼되, 시범 자료가 적절성을 뒷받침하지 않으면 영역 결과는 계속 숨긴다.
   - 공식 25문항 시험 형식을 그대로 모방하거나 “AMC 8 모의고사”라고 부르지 않는다. 별도 모의 형식이 필요하면 명칭과 사용 목적을 따로 검토한다.

2. **문항·언어 검토**
   - 모든 문항은 독립적으로 창작하고 출처 계보를 보존한다.
   - 정답 유일성, 수학적 풀이, 오답의 그럴듯함, 난도 의도, 학년 적합성을 작성자와 독립된 수학 검토자가 각각 확인한다.
   - 한국어·영어·중국어 번역은 수학 의미와 읽기 부담을 별도 검토한다. 문항 하나의 오답만으로 개념 결손을 확정하지 않는다.

3. **교사 주도 시범 응시**
   - 실제 사용 대상 학년의 동의된 표본으로 문항 난도·변별도·응답 시간·영역별 일관성을 검토한다.
   - 합격 기준, 제외 기준, 표본 수, 결측 처리와 재검토 시점을 자료를 보기 전에 정한다. 임의의 컷 점수나 AMC 경계 점수를 만들지 않는다.
   - 문항의 어려움, 언어 부담, 시험 익숙함을 수학 개념 결손과 구분한다.

4. **결과 검증과 사람의 확인**
   - 영역 수준 관찰을 교사 검토 및 별도 수학 수행 자료와 비교해 오분류를 기록한다.
   - 자동화가 승인되기 전에는 학생 답에서 생성한 결과를 교사가 검토하고, 학생에게 학년·등급·배치 결과로 표시하지 않는다.
   - 다음 학습 제안은 별도 문항·수업 자료의 검토와 교사 확인 후에만 연결한다.

5. **점수·수상·자격 예측은 별도 연구**
   - 실제 AMC 점수나 AIME 진출 가능성은 동의된 연결 자료, 외부 검증, 오차·불확실성 분석, 법무·개인정보 검토 없이는 출력하지 않는다.
   - 사용자가 외부 성적표의 원점수를 입력하여 같은 대회 점수를 단순 기록·비교하는 기능, 공식 과거 시험지의 배점식을 참고 원점수로 계산하는 기능, 명시한 사이클 MAA 기준을 안내하는 기능은 허용하되 시험 간 난이도 조정·상위 퍼센트·수상 확률·AIME 자격/예상·학년 배치를 출력하지 않는다.

6. **운영·공개 관문**
   - 비공개 문항과 답안의 저장·접근권한·로깅·보존기간을 정하고, 권한 없는 브라우저에서 정답·루브릭·문항 자료가 노출되지 않는지 검사한다.
   - 모든 문항 버전, 검토자, 시범 자료, 권리 상태, 승인자를 릴리스 manifest에 고정한다.
   - 출시 문서가 이 관문 통과를 명시하기 전까지 GFIELD 자체 연습의 출력은 문항별 응답 기록으로 한정한다. 외부 경시 결과는 위에 적은 수기 원점수 기록 및 출처가 붙은 사이클 참고 정보에 한정한다.

## Grade 7 비공개 후보 작성 현황 (2026-10-29)

기존 Grade 6 브리지 10문항은 비례 추론 2, 경우의 수·확률 3, 기하 2, 표·그래프 2, 규칙·대수 1문항이다. 공간 시각화와 어림의 직접 표본이 없고, 모든 영역이 충분한 반복 문항을 갖지 않는다. 이 분포는 영역 성적표로 전환하지 않는다.

2026-10-29 현재 제안된 청사진을 기준으로 42개 후보 문항(7개 축 × 6개)을 비공개 작업 폴더에 작성했다. 후보는 영어·한국어로 초안화했으며, 구조 검사와 Claude Opus AI 비평을 반복 적용하고 있다. 정답 값 순위 편향을 줄이는 수치 보기 수정도 했으나, 이 결과는 독립 수학·언어 검토 또는 파일럿 근거가 아니다. 문항 수와 foundation/core/stretch 라벨은 작성 의도일 뿐이며, 평가도구로 승인된 형식·AMC 난도 구간·대회 점수 동등성을 뜻하지 않는다.

교사용 전용 문항 작업대와 비공개 Form R6 후보 순서를 만들었다. Claude Max의 R9 검토에서 비례·대수·확률·경우의 수·입체 문항의 겹침과 직접 그래프 해석 표본 부족을 찾아 문항을 재설계했다. R10 전체 재풀이에서는 42개 정답에 중대 오류가 없었고, 문구·오답 설명·난도 메타데이터의 지적을 반영했다. D04 그림그래프 문항은 R11/R12 검토 후 두 언어의 용어·팀 표기·기호 설명·숫자 보기 순서를 정리하고 버전을 0.4.0-draft로 올렸다. 정답 위치 변경에 따라 R6 순서를 다시 계산했으며, 42개 문항이 한 번씩 있고 축별 6개, 절반별 3개, 각 14문항 구간별 축 2개를 유지한다. 정답 위치 A/B/C/D는 10/10/11/11이고 각 구간마다 각 위치 3–4개다. 모든 후보는 계속 잠겨 있다. 이전 화면·A4 출력 QA는 기존 폼과 문항 버전에 대한 기록일 뿐이며, 현재 R6의 브라우저/인쇄 시각 재검수는 완료되지 않았다. Claude Max R7 순서 검토는 새 정답 분포를 확인하고 비공개 교사용 순서로 수용 가능하다고 판단했으며, 약한 국소 패턴을 별도 기록했다. R13 D04 재검토에서는 남은 문항 이슈를 찾지 못했다. AI 검토는 사람의 수학·언어 검토, 문항 유사도/권리 판단, 파일럿 또는 타당도 승인이 아니다. 독립 검토용 답안 비공개 패킷은 최신 R6 기준으로 갱신했으나 사람 검토는 아직 기록되지 않았다.
