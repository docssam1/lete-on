# GFIELD Boarding School Math
## 제품 정의·진단 로직·첫 화면 재설계안

기준일: 2026-08-27
범위: 미국 K–8 학교 수학, 싱가포르식 숙달, Math Kangaroo, SASMO, AMC 8
검토 방식: 공개 사이트·저장소·공식 대회/교육과정·주요 학습 제품의 1차 자료 대조
운영 전제: **GFIELD Boarding School Math는 비수익 교육 목적 프로젝트**로 운영한다. 콘텐츠 권리 필드는 `noncommercial_educational` 사용 모드를 기준으로 판단하며, 향후 유료화·광고·후원 연계 등 수익 모델이 생기면 공개 전 항목별 권리를 다시 검토한다.

> 결론부터 말하면, 현재 공개 페이지는 **운영되는 학습 프로그램이 아니라 잘 보호된 커리큘럼·자료 계획 뷰어**다. 기반은 가치 있지만 사용자는 진단도, 경시 준비도, 실제 수업도 시작할 수 없다. 다음 버전은 학년 목록을 더 늘리는 작업이 아니라 **진단 → 영역별 실력 지도 → 학생별 수업 → 경시 확장 → 재검증**의 한 사이클을 실제로 열어야 한다.

검토용 반응형 첫 화면은 [home-v2.html](../prototypes/home-v2.html)에 별도 제작한다. 공개 운영 페이지는 이 설계가 검수되기 전까지 변경하지 않는다.

## 1. 지금 페이지에서 사용자가 막히는 이유

현재 Hero는 “학교 수학에서 경시까지”와 “진단·수업·워크북·승급의 연결”을 약속한다. 하지만 실제 상호작용은 언어, 학생/교사 미리보기, 학년, 단원 필터뿐이다. 프로그램 카드는 링크가 아닌 `<article>`이고, 진단 엔진을 불러오지만 화면에서는 사용하지 않는다. 학생/교사 전환도 로그인 권한이 아니라 자료명 메타데이터 미리보기다.

| 사용자가 첫 화면에서 묻는 질문 | 현재 답 | 판정 |
|---|---|---|
| 이 프로그램으로 무엇을 할 수 있나? | 넓은 설명만 있고 지금 가능한 행동은 뒤에서야 드러남 | 부분 |
| 실력 진단은 어디서 시작하나? | 시작 버튼·문제·OMR 없음 | 실패 |
| SASMO/싱가포르 경시는 어떻게 준비하나? | `Singapore`, `SASMO`가 장식과 비상호작용 카드로만 존재 | 실패 |
| 학생용과 교사용은 무엇이 다른가? | 아래쪽 잠긴 자료명만 바뀜 | 부분 |
| 학년별·영역별 실제 실력은 어디서 보나? | CCSS 영역명은 있으나 점수·근거 수·강약점 없음 | 실패 |

근거: [현재 공개 페이지](https://lete-on.gfieldacademy.net/boarding-school-math/), [현재 `index.html`](../index.html), [`app.js`](../app.js), [`README.md`](../README.md).

### Algebra 2가 더 명확했던 이유

Algebra 2는 범위가 한 과목이어서만 쉬웠던 것이 아니다. 첫 화면부터 `문제 풀이 → OMR → 학부모 리포트 → 로드맵` 탭이 있고, 40문항, 점수, 영역 차트, 약점, 로드맵, 워크북·해설 다운로드가 실제 행동으로 연결된다. 현재 Boarding에는 그 기반 계약 일부만 있고 전달 화면과 콘텐츠가 없다. [Algebra 2 공개 페이지](https://docssam1.github.io/algebra2/), [Algebra 2 소스](https://github.com/docssam1/algebra2).

Boarding에 반드시 복원할 최소 기능은 다음과 같다.

1. 실제 진단 뷰어와 OMR
2. 학년 × 영역 × 스킬 분석
3. 문항별 점수·오류 유형·코멘트
4. 선수개념 결손과 다음 개념 연결
5. 학생별 수업 로드맵
6. 학생 워크북과 별도 교사용 해설·수업안
7. 학부모용 성장 리포트
8. 저장·불러오기·인쇄·HTML/PDF 출력
9. 학생/교사/학부모의 실제 화면과 권한 분리

## 2. 제품을 한 문장으로 다시 정의한다

### 첫 문장

> **수학 실력은 학년 하나로 보이지 않습니다.**

### 설명

> 미국 K–8 영역별 실력을 진단하고, 싱가포르식 깊은 숙달과 Math Kangaroo·SASMO·AMC 8 목표를 하나의 검증 가능한 성장 경로로 연결합니다.

### 제품 약속

> 학교에서 필요한 수학, 깊이 이해한 수학, 경시에서 꺼내 쓸 수 있는 수학을 같은 스킬 기록으로 보여준다.

첫 화면에서는 이 세 가지를 **Evidence Graph**로 보여준다.

| 축 | 학생에게 묻는 것 | 남겨야 할 근거 |
|---|---|---|
| **School Ready** | 현재 학년의 핵심을 수행할 수 있는가? | 표준·영역·스킬별 진단/숙달/유지 확인 |
| **Deep Mastery** | 원리를 설명하고 다른 표현·조건에도 적용하는가? | 개념, 모델, 변형 연습, 성찰, 지연 재평가 |
| **Challenge Ready** | 처음 보는 비정형·제한시간 문제에 전이하는가? | 경시 유형, 난이도, 시간, 전략, 모의평가 |

이것이 GFIELD의 방어 가능한 차별점이다. “미국 과정도 있고 경시도 있다”는 목록이 아니라, **같은 스킬이 학교 기초에서 깊은 숙달과 경시 전이로 어떻게 성장했는지를 하나의 기록에서 증명하는 것**이다. 이는 비교 제품에서 확인한 공백에 기반한 제품 전략이며 시장 전체에서 유일하다는 주장은 아니다.

## 3. 서로 다른 다섯 경로를 정확히 분리한다

### 학교 핵심 수학

- 종류: 교육과정·학교 준비 경로
- 기준: 미국 K–8 표준의 학년·영역·클러스터 구조
- 현재 자산: K–8 9개 학년, 94개 검증 클러스터 앵커
- 결과: 영역별 위치, 보정 수업, 단원 숙달, 유지 확인, 교사 검토 자료

[Common Core 수학 표준](https://corestandards.org/mathematics-standards/)은 `영역 → 클러스터 → 표준` 구조이며 개념 이해와 절차 능력을 함께 평가해야 한다고 설명한다. 94개 앵커는 94개의 공개 문항이나 완성된 워크북을 뜻하지 않는다.

### 싱가포르식 숙달·모델 메서드

- 종류: 학습법·교육과정 렌즈
- 대회가 아님
- 화면에 보여줄 사이클: `개념·모델 → 충분한 연습 → 성찰·오류 수정 → 비정형 확장 → 유지 확인`

싱가포르 MOE는 수학적 문제 해결을 중심에 두고 개념, 기능, 과정, 메타인지, 태도를 함께 다룬다. 초등 내용은 Number and Algebra, Measurement and Geometry, Statistics의 세 내용 축과 이를 가로지르는 수학적 과정으로 구성된다. [Singapore MOE Primary Mathematics Syllabus](https://www.moe.gov.sg/-/media/files/primary/2021-primary-mathematics-syllabus-p1-to-p6-updated-october-2025.pdf).

### Math Kangaroo USA

- 공식 범위: G1–12. K 학생은 G1 수준에서 독립적으로 읽고 풀 수 있을 때 G1 시험지 참가 가능
- G1–4: 75분, 24문항, 최대 96점
- G5–8: 75분, 30문항, 최대 120점
- 3·4·5점 구간, 오답 감점 없음
- 공식 가이드는 두 학년 묶음, 순위는 개별 학년

CTA: `내 학년 준비 진단` / `공식 일정·등록 확인`.
근거: [공식 시험 형식](https://mathkangaroo.org/mks/faqs/about-the-test/), [공식 점수 규칙](https://mathkangaroo.org/mks/resources/math-kangaroo-scoring/), [공식 학년별 가이드](https://mathkangaroo.org/mks/resources/math-kangaroo-curricula/).

### SASMO

- 정확한 이름: **SASMO — Singapore & Asian Schools Math Olympiad**
- K2: 60분, 15문항
- G1–12: 학년별 다른 시험지, 90분, 25문항
- 주요 축: 산술·통계, 기하·측정, 모델 메서드 문장제, 패턴·나눗셈 성질·공간·논리·복면산 등 비정형 문제
- 미국식 일반 K와 K2를 자동으로 같다고 처리하지 않고 확인 질문을 먼저 한다

CTA: `K2/학년 확인 후 준비 시작` / `국가 파트너·공식 일정 확인`.
근거: [SASMO 공식 형식·교육과정](https://sasmo.simcc.org/), [공식 등록 안내](https://sasmo.simcc.org/register/).

### AMC 8

- 공식 참가 조건: G8 이하이면서 시험일 기준 만 15.5세 미만 — 현재 시즌 기준
- 40분, 25문항, 5지선다, 계산기 금지
- 영역: counting/probability, estimation, proportional reasoning, elementary geometry, spatial visualization, graphs/tables, beginning algebra 등
- GFIELD의 G6–8은 **준비 권장 밴드**이지 MAA 공식 참가 학년 규칙이 아니다
- 과거 시즌과 나이 조건 차이가 있었으므로 시즌·검증일을 함께 저장한다

CTA: `AMC 8 준비 진단` / `학교·공식 시험장 개최 여부 확인`.
근거: [MAA AMC 공식 개요](https://maa.org/student-programs/amc/), [MAA AMC 정책](https://maa.org/student-programs/amc/maa-american-mathematics-competitions-policies/).

### SMO Junior는 조건부 확장

SMO Junior는 SASMO와 다른 대회다. 현재 Singapore Mathematical Society 경로는 Secondary 1/2와 관할·등록 조건이 있으므로 미국 K–8 일반 학생에게 즉시 `등록` 버튼을 보여주지 않는다. 자격을 확인한 경우에만 `SMO Junior readiness`를 연다. [SMO Junior](https://sgmathsociety.org/junior/), [등록 지침](https://sgmathsociety.org/singapore-mathematical-olympiad-smo/registration-instructions/).

## 4. 학년만 고르지 말고 세 좌표를 함께 본다

학생마다 다음 세 값이 다를 수 있다.

1. **재학 학년** — 학교에서 공식적으로 속한 학년
2. **영역별 진단 위치** — 수와 연산은 G5, 기하는 G6, 식과 방정식은 G7처럼 서로 다를 수 있음
3. **목표** — 현재 학년 보완, 상위 과정, Math Kangaroo, SASMO, AMC 8

첫 화면과 리포트의 핵심 시각화는 `학년 × 영역` 지도다.

| 학년 | 주요 CCSS 영역 | 현재 클러스터 앵커 수 |
|---|---|---:|
| K | 수 세기, 연산 사고, 십진 기초, 측정·자료, 기하 | 9 |
| G1 | 연산 사고, 십진 수, 측정·자료, 기하 | 11 |
| G2 | 연산 사고, 십진 수, 측정·자료, 기하 | 10 |
| G3 | 연산 사고, 십진 수, 분수, 측정·자료, 기하 | 11 |
| G4 | 연산 사고, 십진 수, 분수, 측정·자료, 기하 | 12 |
| G5 | 연산 사고, 십진 수, 분수, 측정·자료, 기하 | 11 |
| G6 | 비·비례, 수 체계, 식·방정식, 기하, 통계·확률 | 10 |
| G7 | 비·비례, 수 체계, 식·방정식, 기하, 통계·확률 | 10 |
| G8 | 수 체계, 식·방정식, 함수, 기하, 통계·확률 | 10 |

각 셀은 단순 점수 대신 다음을 표시한다.

- `미진단`
- `근거 부족`
- `보완 필요`
- `학교 핵심 도달`
- `깊은 숙달 근거 있음`
- `경시 전이 근거 있음`

그리고 반드시 문항 수, 평가 목적, 마지막 평가일, 유지 확인 여부를 함께 보여준다.

## 5. 하나의 시스템 로직

현재의 `course → unit → skill → level → testType → resourceType` 계약은 버리지 않는다. 그 바깥에 목표·영역·근거를 추가한다.

```text
학생 + 재학 학년 + 목표 + 목표일
  → 과정 → 학년 → 영역 → 단원/클러스터 → 원자 스킬 → 수준
  → 평가 설계 → 검수된 문항 버전 → 응시
  → 근거(정오·반응형식·시간·오류·출처)
  → 학생별 학습 경로 → 역할별 자료
  → 지연 유지 확인 / 경시 모의
  → 교사 검토 리포트 / 학교 설정 승급 상담 자료
```

### 진단 종류

| 목적 | 문항·시간 원칙 | 말할 수 있는 것 | 말하면 안 되는 것 |
|---|---|---|---|
| 빠른/단원 스크리너 | 12문항 | 다음 확인 단원·경로 제안 | 학년 배치·승급 결정 |
| 전체 배치 진단 | 36–60문항, 4개 이상 영역, 난이도·응답형식 균형 | 영역별 현재 근거와 보정 우선순위 | 검증 없는 규준·공식 컷 |
| 단원 숙달 | 정의된 단원·스킬의 직접/전이 문항 | 단원 학습 상태 | 전체 과정 배치 |
| 유지 확인 | 최소 7일 뒤 별도 응시 | 기억의 유지 여부 | 첫 학습 직후 점수만으로 장기 숙달 주장 |
| 경시 베이스라인/모의 | 해당 대회 공식 형식에 맞춘 별도 평가 | GFIELD 준비도·시간 전략 | 공식 예상 점수·수상 예측 |

### 오류 분류

- 선수개념 결손
- 현재 개념 결손
- 그림·모델·표현 해석 결손
- 비정형 전이·추론 결손
- 계산·절차 오류
- 문장/언어 해석 오류
- 시간 전략·미응답
- 주의 실수 추정 — 교사 확인 필요

사용자가 요청한 `기초 오답`, `심화 정답`, `선수개념 결손`, `계산 실수`는 이 체계 안에서 문항 난이도·선수관계·오류 증거로 분리해 기록한다.

### 결과 리포트에 반드시 보일 것

| 층위 | 필수 표시 |
|---|---|
| 전체 | 평가명·목적·버전·응시일, 총점/만점, 완료 문항 수, 내부 GFIELD 상태 밴드와 한계 |
| 영역 | 학년·영역·스킬, 점수, 근거 문항 수, 기초/핵심/심화 분포, 강점·약점, 선수개념 |
| 문항 | 화면 문항번호, 배점/획득점수, 응답 유형, 정오, 오류 유형, 학생용 코멘트, 교사용 검토 상태 |
| 연결 | 이전 과정에서 보완할 내용, 현재 과정의 다음 단원, 이후 과정·경시에 미치는 영향 |
| 계획 | 회차·시간·수업/가정학습 구분, 워크북·과제·퀴즈, 유지 확인일, 교사 코멘트 |

원점수와 GFIELD 내부 준비 상태는 보여주되, 표본·타당화 전에는 `공식 등급`, `공식 예상 점수`, `수상 예측`으로 표현하지 않는다.

## 6. 학생·교사·학부모는 같은 화면의 토글이 아니다

로그인 전에는 세 역할의 **미리보기**만 제공한다. 로그인 후에는 권한과 정보가 분리된 별도 홈으로 들어간다.

### 학생용

학생의 질문: “오늘 무엇을 왜 해야 하지?”

- `오늘`
- `내 스킬 지도`
- `학습·재확인`
- `경시 도전`
- `성장 기록`

보이는 것: 재학 학년, 영역별 위치, 목표, 다음 한 과제, 진행률, 다음 유지 확인.
보이지 않는 것: 정답표, 교사용 해설, 내부 문항 ID, 권리 기록, 승급 정책 내부값.

### 교사용

교사의 질문: “누구에게 무엇을 배정하고 어떤 근거로 확인하지?”

- `학급`
- `진단`
- `스킬 히트맵`
- `배정·개입 그룹`
- `유지 확인`
- `리포트`
- `콘텐츠 검수`

보이는 것: 학생별 문항/스킬 근거, 오류 유형, 개입 그룹, 자료 버전, 답·해설·루브릭, 출처·권리·검수 상태, 교사 확인, 정책 버전.

### 학부모용

학부모의 질문: “지금 어디에 있고 무엇이 좋아졌으며 다음에 무엇을 하나?”

- `현재 위치`
- `이번 주 계획`
- `학교·경시 준비도`
- `공유 리포트`

보이는 것: 강점, 약점, 시작 대비 성장, 일정, 목표 정렬, 교사 코멘트, 한국어/영어/중국어 리포트. 정답과 내부 판정 데이터는 보이지 않는다.

## 10. 원본 문제·한영중 번역의 권리 경계

수학적 사실과 풀이 방법이 있다고 해서 **문제의 정확한 문구, 도형, 선택지, 해설 문장, 시험지 편집물**이 자동으로 자유 이용되는 것은 아니다.

- **MAA AMC 공개 기출·공식 해설:** MAA 공식 해설지는 교육자가 학생에게 교육 목적으로 문제와 공식 해설을 공유하도록 권장하고, 각 문항에 대회명·연도·문항 번호를 표시하라고 명시한다. 수익 발생 목적의 출판·복제·전달은 서면 허가가 필요하다. 따라서 이 비수익 프로젝트에서는 공개가 끝난 기출을 수업·학생 학습에 출처와 함께 사용할 수 있다. 단, 실제 대회 보안 제한 기간에는 공개하지 않으며, 이 안내가 불특정 다수 대상 공개 Git 재배포나 번역의 포괄 허가까지 명시한 것은 아니므로 해당 범위는 별도 필드로 관리한다. [MAA 공식 해설의 권리 고지](https://maa.org/wp-content/uploads/2024/08/2022-AMC-10A-solutions.pdf), [MAA AMC 정책](https://maa.org/student-programs/amc/maa-american-mathematics-competitions-policies/)
- **Math Kangaroo SMART-840:** CC BY-NC-SA 4.0을 따르므로 비수익 교육 목적 사용, 출처 표시, 변경 사실 표시, 동일조건 공유가 기본이다. 그러나 공식 신청 페이지에는 사용·연구결과 공개 전에 프로젝트 설명 제출과 제작자의 서면 승인을 받으라는 추가 조건과 AI 모델 학습 금지가 함께 있다. 따라서 승인 전에는 데이터셋을 반입하지 않고 `approval_required`로 둔다. 승인 후 번역은 변경물임을 밝히고 원문 출처와 동일조건 공유 표시를 유지한다. 이 조건을 다른 Math Kangaroo 기출 전체에 자동 확대하지 않는다. [SMART-840 조건](https://mathkangaroo.org/mks/smart840gr1-12/)
- **SASMO:** 최근 시험지는 회원 LMS로 제공되며, 검토한 공식 공개 페이지에서 원문·도형·해설의 공개 재게시와 한영중 번역을 포괄적으로 허용하는 조건을 확인하지 못했다. 비수익 프로젝트라도 근거가 생기기 전에는 `link_only` 또는 `permission_required`로 둔다. [SASMO 등록/LMS 안내](https://sasmo.simcc.org/register/)

권리는 대회 이름 하나로 일괄 판단하지 않고 **문항·연도·원본 파일 단위**로 기록한다.

- `owned_original` — GFIELD 독립 제작·검수 문항
- `educational_share_with_attribution` — 학생 대상 비수익 교육 공유와 요구 출처를 확인한 자료
- `licensed_cc_by_nc_sa` — 승인과 CC BY-NC-SA 조건을 모두 충족한 자료
- `approval_required` — 신청·서면 승인 전 잠금
- `link_only` / `permission_required` — 공식 링크만 제공하거나 별도 허가 전 잠금
- `competition_blackout` — 해당 시즌 보안 제한 해제 전 잠금

번역은 `translation_scope`를 별도로 두고 원문 언어, 번역 언어, 번역자, 검수자, 변경 표시, 허용 대상과 공개 범위를 기록한다. 원문 사용이 가능해도 번역·공개 범위가 확인되지 않으면 번역본은 공개하지 않는다.

따라서 공개 GitHub에는 다음만 둔다.

- 대회명·형식·자격·공식 URL·검증일
- GFIELD가 독립 제작하고 검수한 문항
- 해당 원본의 정확한 조건이 공개 재배포를 허용하고, 필요한 출처·변경·동일조건 공유 표시를 갖춘 원문과 번역

학생·교사에게 제공할 수 있지만 공개 Git 재배포 범위가 명시되지 않은 공식 기출은 인증된 교육 공간 또는 공식 링크로 제공한다. 원문과 번역은 원본 버전, 권리 근거, 번역자, 검수자, 허용 언어·대상·기간을 함께 관리한다.

## 11. 승급 표현과 데이터 저장

미국의 교육과정·입학·졸업 요구는 주·지역·학교가 정한다. 따라서 `미국 공식 승급 점수`, `진급 보장`, `학교 공식 성적표`라고 쓰지 않는다. 권장 표현은 다음과 같다.

> 학교와 공유 가능한 표준 연계 성장 기록<br>
> 과정 배치·진급 상담을 위한 교사 검토 보조 근거

근거: [U.S. Department of Education — Federal Role in Education](https://www.ed.gov/about/ed-overview/federal-role-in-education).

비용을 줄이는 기본 구조:

- GitHub Pages: 공개 UI, 커리큘럼 지도, 대회 공식 메타데이터·링크, 권리 확인 샘플, 로컬 데모
- 브라우저 저장: 한 학생의 일회성 데모만
- 비공개 인증 저장소: 실제 학생 기록, 정답·해설, 제한 자료, 역할 권한 — 운영 단계에서만 연결
- Cloud Run: 핵심 진단·리포트·워크북에는 불필요. 비공개 권한 검증이나 선택형 AI 기능이 필요할 때만 사용

API 키와 학생 정보를 GitHub Pages에 넣지 않는다.

## 14. 현재 주장할 수 없는 것

- GFIELD 진단이 심리측정학적으로 검증되었다는 주장
- 점수로 공식 학년 배치·승급을 자동 결정한다는 주장
- 대회 수상 확률이나 공식 예상 점수
- 94개 클러스터가 94개 완성 워크북·문항이라는 주장
- 모든 원본 대회 문항에 대한 포괄적 공개·한영중 번역 권리
- 한영중 전체 콘텐츠가 검수 완료되었다는 주장

이 한계를 숨기지 않는 것이 제품 신뢰도를 높인다.
