# 2026년 9월 챌린지 대비 학습 설계

## 범위

`studio.html`, `studio.js`, `studio.css`만의 화면이다. 기존 성적 저장, 로그인, 권한을 연결하거나 우회하지 않는다. 학생 입력은 메모리에만 남으며 새로고침하면 사라진다. 교사의 로컬 채점과 공식 성적은 구분한다.

하이퍼 포커스 안의 챌린지 대비 과정이다. `access-service.js`의 기존 인증 세션 기반 승인 확인을 읽어 각 회차와 각 원본 유형별로 표시·생성을 제한한다. `localhost/127.0.0.1`에서 `?teacherPreview=1`을 명시한 경우만 로컬 교사 검토를 허용한다. 파일 URL이나 다른 호스트에서 매개변수만 붙여서는 허용하지 않는다. 서버가 배포 준비를 확인하지 않으면 학생 화면은 잠긴다. 이 UI 제한만으로 공개된 정적 문항 파일의 다운로드를 보호한다고 주장하지 않는다.

학생 출력의 워터마크는 서버 확인 `watermarkIdentity()`의 이름을 사용한다. 승인 학생 ID와 이름은 구성 시 고정되고 다른 학생으로 바뀌면 출력하지 않는다. 자유 입력 이름은 로컬 교사의 채점 라벨에만 쓰며 승인 이름으로 취급하지 않는다. 만료·로그아웃·권한 변경 이벤트에서 그림·답안·진단·출력 화면을 즉시 비운다. 별도 개인정보 저장이나 승인 변경 호출은 하지 않는다.

## 구성

- 채점·진단: 회차 선택, 문항별 미입력/정답/오답, 60점 기준과 영역별 근거.
- 오답 유사문제: 현재 회차에서 실제로 오답 표시한 본시험 문항만. 다른 필터도 이 범위를 넘지 않는다.
- 회차별 문제은행: 영역→소영역→유형의 위치, 현재 원문 미리보기, 개별·일괄 선택, 별도 구성 요약.
- 더 쉽게/같게/어렵게는 공급자의 검증 상태를 그대로 사용한다. 준비되지 않은 유형을 다른 쉬운 문제로 대체하지 않는다.
- 구성할 때만 문항을 생성한다. 구성한 문제·순서·학생 표시는 고정 복사본이며 보기·답안·인쇄 전환으로 재생성하지 않는다.

## 시각 방향

작업 배경 #F5F6F8, 종이 #FFFFFF, 본문 #182230, 보조 #566274, 선택 #EAF0FF, 실행 #2456C4. 한글 시스템 산세리프를 쓰고 제목은 28px, 기본 16px. 로고 아래 LETE-ON을 유지한다. 회차와 업무 탭을 상단, 목록을 넓은 본문, 구성 요약을 옆에 둔다. 상단 점수 카드, 장식 도형, 복제된 경쟁학원 표지, 반복된 둥근 카드는 쓰지 않는다.

문항·조건·그림은 공급자 데이터의 원문을 그대로 표시한다. 출제 정답은 명시적으로 답안 보기 전까지 문항에 넣지 않는다. 인쇄는 단일 열, 큰 풀이 공간, 로고와 워터마크, 별도 답안 시작을 사용한다. 화면의 자료 확인과 수학·원본 검수는 별개다.

## 검수 근거

`validate_challenge_studio.cjs`에서 로컬 교사 검토, 미입력·55점·60점 기준, 대영역/소영역/유형, 오답 범위, 한글 조합, 검색 밖 선택 보존, 원문과 생성문항 확대 미리보기, 답안 숨김, 고정 생성본, 네 가지 인쇄 범위, 실제 PDF 페이지 수, 양면 빈 면과 홀수 답안 표지, 390px 및 키보드, 승인 취소와 학생 변경을 확인한다. 승인 이름 검수는 실제 학생이 아닌 명시적인 가상 프로필로 수행한다.

큰 그림과 긴 글은 A4 너비에서 높이를 재어 한 면에 최대 두 문제로 배치하고, 넘치면 한 문제씩 배치한다. 풀이도 실제 높이에 따라 최대 네 문제까지 배치한다. 모바일에서는 그림을 원래 크기로 확대하여 내부 영역을 좌우로 이동할 수 있고, 학습지를 보는 동안 구성 도구막대는 숨긴다. 명칭과 로고 아래 LETE-ON, 승인 학생 워터마크는 문제·풀이·빠른 정답·답안 표지 모두 유지한다. 양면 인쇄용 빈 면에만 표시하지 않는다.

아직 확인하지 않은 사항: 실서버 승인 배포와 실제 사용자 로그인, 비공개 문항 전달, 학생별 공식 성적 저장. 정적 문항 자산을 서버 권한으로 보호하는 배포가 완료되기 전에는 학생 운영 출시를 주장하지 않는다. 유형별 새 문항 제공 가능 여부는 공급자의 현재 검증 상태에 따르며, 목록의 104개 원문이 모두 유사문제 생성 가능하다는 뜻은 아니다.
