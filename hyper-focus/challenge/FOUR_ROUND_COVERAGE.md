# 챌린지 모의고사 4회 현행 구성

회당 본시험 20문항과 추가 연습 6문항으로 구성한다. 현재 출력물은 각 21쪽이며 정답과 풀이 표지는 15쪽에서 시작한다.

## 2026-09-10 개념 교재 반영 수정

- 1회: 3번은 여러 저울의 치환 관계, 12번은 4×4 바탕의 5회 주사위 굴리기, 14번은 연필·지우개·클립 길이 치환으로 수정했다.
- 2회: 이번 수정에서는 문항을 바꾸지 않았다.
- 3회: 1번 받아내림·받아올림, 6번 대각선 경로 비교, 7번 `2년이 지난 후`, 9번 검은 지점을 피하는 최단거리, 15번 검정·흰색 교차 쌓기나무, 18번 구멍이 있는 테트라큐브, 19번 5×4 모든 칸 지나기로 수정했다.
- 3회 추가 연습: 1번 같은 모양으로 나누며 표시 하나씩, 3번 A·B 블록, 4번 연필·지우개·클립, 6번 쌓기나무 개수와 점선 상자 채우기로 교체했다.
- 4회: 4번은 계단처럼 꺼인 모양의 두 조각 선택, 11번은 서로 이웃하지 않은 세 쌍 연결, 12번은 옆모양 없는 A·B 블록 개수, 17번은 여러 저울의 치환 관계, 18번은 같은 모양 나누기로 교체했다.
- 4회 추가 연습 1~6번은 본시험에 쓰지 않은 유형으로 교체했다: 물건 길이 치환, 교차 쌓기나무, 구멍 테트라큐브, 최단거리, 점선 상자 채우기, 지점을 다시 지나지 않는 길.

## 검증

- 본시험 20문항과 추가 연습 6문항의 정답을 독립 계산하고, 저장된 정답을 오염시켜 틀린 답이 거부되는지 확인했다.
- 4회 추가 연습은 여섯 유형이 서로 다르고, 본시험의 유형과도 겹치지 않는다.
- 1·3·4회를 A4와 390px에서 다시 렌더링했다. 모든 회차는 21쪽, 응답란 26개, 정답 표지 15쪽이며 넘침·잘림·응답란 겹침이 없다.
- 개념 1·2권은 각 83쪽으로 다시 생성했다. 1권 120문항, 2권 117문항의 문제·응답란·풀이를 확인했다.

원본 사진은 참고만 했으며, 배포물에 복사하지 않았다. 난이도는 풀이 단계·조건 수·수 범위를 늘려 조정했으며, 아동 정답률을 사용한 실측 보정은 별도이다.
