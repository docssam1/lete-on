# 6세 챌린지 원본 구조 접수표

이 문서는 사용자 제공 그림을 복사해 보관하지 않고, 새 문제 제작에 필요한 구조만 기록한다. 빨간 채점선·동그라미·연필 답과 메모는 근거에서 제외한다.

학생에게는 아래 세부 항목을 메뉴로 노출하지 않는다. 모든 유형은 다음 두 회차에만 묶는다.

1. 수 · 규칙 · 순서와 논리
2. 도형과 공간

## 생성·전수검산 완료

| 내부 유형 | 원본 구조 | 검산 기준 |
|---|---|---|
| `split-merge-chain` | 연결된 수 가르기·모으기 | 모든 빈칸 후보 열거 |
| `animal-race-order` | 동물 달리기 등수 조건 | 모든 순열 열거 |
| `card-sum-count` | 중복 숫자 카드로 목표 합 만들기 | 모든 카드 부분집합 뒤 같은 수 조합 중복 제거 |
| `total-difference` | 전체와 차로 두 묶음 구하기 | 가능한 두 양의 정수 전수검사 |
| `family-comparison` | 가족의 많고 적음 관계 | 가능한 기준값 전체에서 차가 일정한지 검사 |
| `line-position-total` | 앞·뒤 인원으로 전체 구하기 | 앞 + 본인 + 뒤 |
| `mountain-digit-count` | 커지는 산 모양 수 배열 | 줄별 직접 생성·개수 대조, 실전 8번 이내 |
| `triangle-number-rule` | 삼각형 안팎 수 규칙 | 가능한 빈칸 수 전수검사 |
| `rotated-grid-pair` | 3×3 색칠 모양 회전 짝 | 0·90·180·270도 회전 전체 비교 |
| `apartment-floor-order` | 층 범위와 바로 위아래 조건 | 5명 전체 순열 열거 |
| `cyclic-picture-pattern` | 반복 그림의 n번째·개수 | 위치별 패턴을 직접 생성해 대조 |
| `number-property-filter` | 여러 조건을 모두 만족하는 수 | 보기 전체 조건식 검사 |
| `balance-weight-order` | 두 양팔저울로 무게 순서 찾기 | 세 물체의 모든 순열 열거 |
| `inverse-story-problem` | 관계·참새·버스·귤의 거꾸로 푸는 문장제 | 정방향 식에 대입해 원상 복원 |
| `arrow-number-move` | 화살표에 따라 1 또는 10만큼 수 이동 | 정방향·역방향 누적값 대조 |
| `symbol-equation` | 연결된 세 식의 기호값과 마지막 식 | 0부터 9까지 모든 기호값 대입 |
| `minimum-sum-pyramid` | 네 카드로 합 피라미드 꼭대기를 가장 작게 만들기 | 모든 카드 순열의 꼭대기 수 비교 |

## 구조 접수·검수 대기

- 도형 패턴: 화살표 방향, 크기·색·모양 복합 반복, 원형 분할 색칠, 6칸·9칸 색칠, 바둑돌 색과 개수 규칙
- 수 규칙: 한 단계·두 단계 대응, 파스칼 삼각형 빈칸, 서로 다른 세 수로 가르기, 기호 넣기, 4×4 가로 규칙
- 도형 구성: 패턴 블록 채우기, 테트로미노 두 조각 합치기, 합동 모양으로 삼등분, 선을 따라 그릴 수 있는 네모 세기
- 공간: 색 주사위 전개도, 마주 보는 눈의 합이 7인 주사위 전개도, 쌓기나무 블록 수
- 경로: 같은 도형끼리 겹치지 않게 연결, 숫자 순서로 모든 칸 지나기, 번개 칸을 피한 한붓길
- 길이: 모눈 선 길이 순서, 집까지 경로 길이, 지우개·연필·클립을 이용한 간접 비교
- 저울: 동물·과일·물건의 가장 무겁고 가벼움, 단위 추론
- 기타: 도미노 수 규칙, 종이 접기 대칭, 자릿값 그림, 벌과 꽃 구역 나누기, 220원 만들기

검수 대기 항목은 그림 구조를 좌표나 관계식으로 다시 만들고, 가능한 답 전체를 독립 계산하기 전에는 모의고사에 넣지 않는다.

## 고정 편집 규칙

- 개념 교재는 2회이며 각 회차는 `워밍업 → 예제 → 유제 → 리뷰`로 구성한다.
- 모의고사는 2회, 회당 20문항이다.
- A4 세로 단면, 문제 페이지당 3문항이다.
- 1쪽 표지, 2쪽 완전 빈 페이지, 3쪽부터 문제를 배치한다.
- 문제 페이지에는 `GFIELD · LETE-ON · 학생이름` 대각선 워터마크를 세 줄 넣는다.
- 원본 스캔, 원본 문장, 로고, 채점 표시, 손글씨는 공개 저장소에 넣지 않는다.
