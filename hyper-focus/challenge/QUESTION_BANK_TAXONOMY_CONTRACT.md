# 챌린지 문제은행 분류·생성 계약

범위는 `hyper-focus/challenge/**`의 2026년 9월 챌린지 대비 자료만이다. 기존 Hyper Focus 54유형이나 필즈 더 클래식 자료를 합치지 않는다. 필즈 더 클래식 문제은행은 화면 구조와 검수 원칙만 참고한다.

## 1. 분류 단위

- 원문 위치: 4회 × (본시험 20 + 추가 연습 6) = 104개
- 영역: 8개
- 대유형: 14개
- 소유형: 60개
- 안정적인 원문 키: `occurrenceId`
- 풀이 원리 기준 소유형 키: `taxonomy.typeId`

같은 풀이 원리의 문항이 여러 회차에 있어도 원문 키를 합치지 않는다. 검색·학습지 선택은 소유형으로 묶을 수 있지만 승인, 출처, 정답, 생성 검증은 104개 원문 위치를 각각 추적한다.

화면 표기는 다음 한 방향만 사용한다.

```text
영역 → 대유형 → 소유형 → 원문 위치
```

## 2. 생성 계약

유사문항은 숫자만 바꾸는 치환본이 아니다. 소유형의 풀이 원리와 답 형식은 유지하면서, 가능한 범위에서 다음 축을 함께 바꾼다.

- 조건의 조합과 제시 순서
- 그림의 좌표·방향·색·배치
- 보기의 구성과 순서
- 이름·물건·상황
- 경로·연산·질의 방식
- 난이도에 따른 추론 단계

같은 seed는 같은 문항을 재현해야 하며 다른 seed는 의미 있는 구조 시그니처를 만들 수 있어야 한다. 모든 생성 결과는 원문 위치와 난이도별로 다음 검사를 통과해야 한다.

1. 생성 오류 0건
2. 독립 답 계산과 생성 답 일치
3. 정답 후보 1개
4. 빈 조건, `undefined`, `NaN`, 그림 밖 좌표 0건
5. 같은 학습지 안의 문제·조건·그림 중복 0건
6. 숫자를 지운 뒤에도 확인되는 구조 다양성

여러 고정 문항 풀을 한 학습지에 섞을 때는 `seed`, 난이도, 출처·유형 ID, 정답 같은 생성 메타데이터를 제거한 뒤 문장·그림·조건을 정규화하여 비교한다. 이미 선택한 실제 변형과 같으면 그 후보를 버리고 다음 후보를 고른다. 충돌한 후보를 그대로 넣거나 단지 다른 `seed`라는 이유로 다시 넣는 코드 경로는 허용하지 않는다. 요청 수만큼 고유한 후보가 실제로 부족할 때만 학습지 생성을 중단하고 기존 학습지를 유지한다.

구조상 경우의 수가 제한된 유형은 무한 생성을 주장하지 않는다. 검증된 서로 다른 구조 수를 공개 메타데이터에 기록하고, 준비된 수보다 많이 요청하면 생성 전에 막는다. 구조 다양성이 부족한 유형은 숫자만 늘려 통과시키지 않고 `held`로 남긴다.

## 3. AI 개념보기 계약

AI 개념보기는 답을 대신 말하는 기능이 아니다. 사용자가 제공한 개념 교재, 대본, 해설과 현재 분류표의 `nextStep`에서 확인된 풀이 원리만 짧은 6세용 문장으로 다시 구성한다.

- 소유형 이름과 `영역 / 대유형 / 소유형` 경로
- 핵심 원리 1개
- 순서가 있는 풀이 단계 3개
- 자주 하는 실수 1개
- 답을 쓰기 전 스스로 확인할 질문 1개
- 근거 상태

특정 원문의 숫자 답, 정답 보기, 전체 해설은 개념보기에 넣지 않는다. 근거를 확인하지 못한 설명은 추측하여 생성하지 않고 `확인 필요`로 잠근다. 정답·풀이는 기존의 명시적인 보기 동작 뒤에서만 불러온다.

개념 교재·대본·해설에서 만든 개념 문구는 공개 자바스크립트에 넣지 않는다. 원격 화면에서는 해당 소유형의 이용 권한을 다시 확인한 뒤 비공개 콘텐츠 경로로 불러오고, 권한이 바뀌거나 창을 닫으면 화면의 개념 문구를 모두 제거한다. `evidenceId`는 실제 개념 카탈로그 항목 또는 실제 원문 위치의 검증된 풀이와 자동으로 대조한다.

## 4. 완료 기준

- 104개 원문 모두 분류되고 누락·중복 원문 키 0건
- 60개 소유형 모두 개념보기 존재
- 영역·대유형·소유형별 검색·전체 선택 가능
- 승인되지 않은 원문·개념·답안 노출 0건
- 생성 재현성·단일 정답·구조 다양성 검사 통과
- PC, 390px, 키보드, hover, A4 문제/답안 인쇄와 3줄 학생 워터마크 회귀 통과
