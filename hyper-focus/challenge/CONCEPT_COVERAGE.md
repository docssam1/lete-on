# 챌린지 개념 교재 수록 및 검수

2026-09-09. 현행 교재는 `concepts.html?round=1`, `concepts.html?round=2`, 인쇄본은 `output/pdf/challenge-concepts-round1.pdf`, `challenge-concepts-round2.pdf`이다. 기존 104쪽 통합 PDF는 이전본이다.

## 범위와 한계

- 74개 세부 유형을 16개 큰 단원, 2회로 묶었다. 아래 표의 개념 번호는 기존 세부 유형 ID이며 새 책의 단원 번호가 아니다. 실제 매핑은 `concept-book-plan.js`에 있다.
- 회당 8단원, 각 유형 1문제 + 유제 4문제, REVIEW 15문제다. 단원별 연습 6문제는 제외했다. O/X 개념 확인도 실제 적용 유제로 사용하지 않았다.
- 110개 수록 문제를 독립 풀이로 검산한다. 각 회차 안에서 동일 문제 키는 중복하지 않는다. 서로 관련된 유형을 묶은 것이므로 한 엔진의 숫자만 바꾼 5문제 구성은 아니다.
- 예제의 정답과 풀이는 학생 학습 페이지에 노출하지 않고 뒤쪽 답안에만 수록한다. 답안 표지는 각 PDF의 홀수 페이지에서 시작한다.
- 화살표는 보기와 공간 경로를 읽는 형식으로 개념에도 반영했다. 1회 6단원 유형은 위 −10 / 아래 +10, REVIEW 12는 위 −8 / 아래 +8이다. 좌우는 1씩 변한다.
- 예제 일부는 자체 모의고사에서 가져왔다. 전부 새로운 문제이거나 시험과 겹치지 않는다고 주장하지 않는다.
- 원본의 학습 개념을 참고하되 원본 스캔이나 경쟁학원의 그림은 교재 자산으로 사용하지 않았다.
- 최신 첨부 20번의 원래 규칙은 확인되지 않았다. 33단원은 선 도형 변화의 관련 유형이며 원형과 완전 동일하다는 뜻이 아니다.
- 지정 조각 수 패턴블록은 유일한 채우기 사례다. 여러 해 전체 찾기는 별도 확장이다.
- 나사·막대 원형의 별도 문제 생성기는 이번에 추가하지 않았다. 물체와 단위 물건의 길이 비교 개념 및 다른 배열의 적용은 51단원에 수록했다.
