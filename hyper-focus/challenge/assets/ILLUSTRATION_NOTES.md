# 시험지 일러스트 제작 기록

최종 사용 파일: `exam-objects-illustration.png`.

제작 방식: 내장 이미지 생성 도구로 일러스트를 생성한 뒤, 같은 도구로 배경만 흰색으로 수정했다. 실사풍 시안은 시험지에서 사용하지 않는다. 과일·사탕·참새가 담긴 3열×2행 PNG를 화면에서 나누어 표시하며, 원본 비트맵을 다시 그리거나 색을 바꾸지 않는다.

최종 생성 요청: 1536×1024, 흰 배경, 3열×2행, 각 칸에 물체 한 개. 위에는 사과·한국 배·딸기, 아래에는 귤·포장 사탕·참새. 어린이 수학 교재용으로 부드러운 윤곽과 밝은 색을 가진 깔끔한 일러스트. 실사·3D·사진 질감·사람·졸라맨·문자·로고·그림자는 제외.

배경 수정 요청: 여섯 물체의 위치·크기·색·윤곽을 유지하고 어두운 배경과 후광만 완전히 흰색으로 변경. 크기와 3열×2행 배열 유지.

텍스트, 도형의 선, 빈칸, 수 배열은 이미지에 맡기지 않고 검산 가능한 도식으로 조판한다. 이 삽화는 원본 교재에서 복제한 그림이 아니다.
