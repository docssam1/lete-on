# 첨부 이미지 유형 반영표 — 챌린지 모의고사 1·2회

## 우선 보완본이 현재 기준

후속 문항 이동: 1회 집 순서 문제는 현재 10번, 동물 수 조건은 1번, 같은 무게 교환은 3번이다. 2회 참새 역산은 15번, 과일식은 1번이다. 추가 연습 번호는 유지한다. 색종이 추가 3번의 곡선 접기 화살표·겹침 표시도 수정했다.

2026-09-09 후속 요청으로 6문항을 교체했다. **현재 배치·제외 유형·검수 근거는 `PRIORITY_REVISION.md`가 우선한다.** 1회 본14는 단위 길이, 추가2는 위에서 본 입체, 추가3은 접기·구멍이다. 2회 본12는 경로 가짓수, 본18은 대각선 길이, 추가2는 수 카드 크기 순서다. 아래의 ‘11유형 보완’은 과거 상태이며 전체 첨부를 빠짐없이 반영했다는 뜻이 아니다.

## 최신 상태: 회차별 추가 연습 6문항

### 후속 2회 수정 반영

2회 3번은 접기 대칭 선택에서 **모눈 다각형 거울상 그리기**로, 5번은 홀짝 별 배열 규칙에서 **여섯 가지 색칠 배치 중 빠진 한 그림 그리기**로 교체했다. 따라서 이전 별 배열의 홀짝 교차 규칙 형식은 현재 본시험에 없다. 14번은 선 도형 회전 유형을 유지하되 아홉 그림을 보고 18번째를 구한다. 17번에 **세 양팔저울 무게 순서**가 다시 들어갔고, 20번에는 기존 HF Q39 원리를 참고한 **친구·과일 ○·× 논리표**가 들어갔다. 이전 둘레 세기와 참 문장 하나 찾기는 제외했다. 추가 연습 12문항은 변경하지 않았다. 아래 과거 대조표의 옛 문항 위치보다 이 단락과 `EDITION_REVIEW.md`의 현재 배치표가 우선한다.

본시험은 각 20문항 그대로 유지하고, 아래 12유형을 추가 연습으로 각 6문항씩 넣었다. 따라서 이전에 미반영으로 분류한 11개 출제 형식은 이제 추가 연습에 있다. 거울 디지털 식 1유형을 새로 더했다. 아래쪽의 본시험 대조표는 추가 연습을 넣기 전의 기록이다.

## 아래는 추가 연습을 넣기 전의 본시험 대조 기록

기준: 2026-09-09 컬러 교체본, 각 20문항. 현재 시험지에 실제 출제된 문항만 반영으로 센다. 일반 생성기에 남아 있어도 현재 시험지에 없으면 미반영이다. 원본 이미지·공식 답안은 이 문서에 복제하지 않는다.

## 결론

최근 13장에서는 중복 삼각형 수 배치 1장과 색칠 답안 양식 1장을 제외한 11개 문제 예시를 반영했다. 이 중 별 배열과 선 도형 규칙은 원본의 의도된 규칙을 확정한 것이 아니라, 규칙과 답을 검산할 수 있도록 새로 구성한 변형이다.

그러나 이전 첨부까지 합치면 아래 **11가지 출제 형식은 현재 40문항에 없다.** 넓은 개념이 비슷한 문제를 넣었다는 이유로 해당 형식까지 반영했다고 보지 않는다.

| 미반영 출제 형식 | 현재 문제와의 차이 |
|---|---|
| 원과 네 칸 막대를 함께 사용한 수 표현 | 1회 20번은 네 칸 이진 표현이므로 서로 다른 부호 규칙이다. |
| 벌·꽃을 하나씩 포함하도록 같은 모양으로 영역 나누기 | 대칭·회전·도형 세기는 있으나 같은 모양의 영역 분할은 없다. |
| 여러 식의 빈칸 값을 비교하여 가장 작은 것 고르기 | 연결된 기호식 계산만 있고, 여러 식 사이의 최솟값 비교는 없다. |
| 정해진 차가 되는 뺄셈식을 만들 수 있는 경우의 수 | 1회 11번은 목표 합의 카드 조합이다. 차가 일정한 뺄셈식 세기와 다르다. |
| 기울어진 저울 관계로 가장 무겁고 가벼운 것 판단 | 1회 10번은 같은 무게의 교환 관계다. 기존 2회 11번 무게 순서는 교체됐다. |
| 모든 수 카드를 한 번씩 써서 여러 목표 합에 분배 | 기존 2회 10번이 삼각형 수 배치로 교체됐다. |
| 겹친 도형의 안과 밖을 바꾸는 유추 | 기존 2회 8번은 교체됐다. 새 3×3 배열 규칙은 안팎 교환 유추와 다르다. |
| 사다리꼴 안에서 크고 작은 일반 사각형 모두 세기 | 1회 19번은 격자의 직사각형·정사각형 세기다. 비직각 사각형까지 세는 형식은 없다. |
| 색과 모양이 서로 다른 주기로 반복되는 복합 규칙 | 기존 1회 5번은 분할 도형 색칠 규칙으로 교체됐다. 두 속성의 독립 주기 문제는 없다. |
| 일의 자리와 십의 자리를 비교하여 조건에 맞는 수 모두 고르기 | 2회 7번은 자리 숫자 조건으로 한 수를 찾는다. 여러 보기를 모두 고르는 형식은 없다. |
| 여러 범위 조건을 만족하는 수 중 가장 큰 수 찾기 | 1회 3번은 조건을 만족하는 수가 하나뿐이다. 남은 후보끼리 최댓값을 고르는 단계는 없다. |

세부 변형까지 엄격히 보면 원탁의 ‘이웃하지 않는다’ 조건, 세 번의 승하차를 역산하는 버스 상황, 점 개수를 세는 도미노, 수 카드 세 장의 3층 피라미드도 현재 원형 그대로는 없다. 관련 핵심 개념의 변형은 아래 표에 구분했다.

## 해석 범위

- 반영표는 사용자 첨부와 현재 모의고사의 유형 대조이지, 필즈 공식 문항과의 일대일 원문 일치 검증이 아니다.
- 목표 난이도 약 80%는 출제 기준이며 실제 응시 결과로 측정한 비율이 아니다.
- 이번 수정은 시험지에만 적용했다. 개념 수업 전체나 일반 유사문항 생성기에 새 11유형이 모두 통합됐다는 뜻이 아니다.
