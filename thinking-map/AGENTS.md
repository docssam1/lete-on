# 사고력 유형지도·통합 사고력 문제은행

G·MAP/boarding-school-math와 별개인 사고력 문제은행의 실행 코드 보존 위치다.

- 완료 필즈 더클래식1·2과정과 기존 소마 분석을 재연구하지 않는다. 기존 유형·문항 ID와 검산 버전을 유지한다.
- 원문 교재·교사용 답안/페이지·OCR·비공개 분석 장부·사용자DB·인증·세션은 이 공개 저장소에 넣지 않는다. 데이터·검수·완성물은 기존 소유자 Drive 위치를 사용한다.
- code-manifest.json은 보존한 코드/고정 공개 Git 의존성의 해시다. private-data-manifest.json은 외부 데이터의 해시/파일명만 담는다. 검사 통과를 원문 난도·교사 승인으로 확대 해석하지 않는다.
- 라이브 작업 공간은 Git 외부의 기존 content-map 작업본이며 restore.py는 다른 내용의 파일을 덮어쓰지 않는다. private workspace, 사용자DB와 이관 전 item_archive를 삭제하지 않는다.
- 450공통후보/423검산대표/62입력생성유형은 다른 집계다. 원본/생성 유사문제·정답/학생문제·사고력/교과 연계를 구별한다.
- 최소 능력은 학년 대신 수 범위·연산·표현·행동으로 쓰고, 후속 교과 활용을 필수 선수로 바꾸지 않는다.
- 테스트는 임시DB와 별도 포트를 사용한다. 18766·18767과 운영 중18768을 다른 작업으로 종료하지 않는다. 외부 AI API/Drive 쓰기/배포는 현재 사용자 승인 범위를 확인한다.
