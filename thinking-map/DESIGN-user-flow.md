# 사용자 중심 문항 탐색

교사/학부모가 ‘어느 유형인가→무슨 문제인가→어떤 유사문제를 쓸까→문제지에 담기’를 한 화면에서 이어간다. 원본 대조는 교재 위치에서 열고 원본·생성 문항을 구분한다.

구성: 상단의 책/유형/문제 입력/문제지 이동 → 왼쪽 분류 경로와 짧은 유형명 → 오른쪽 실제 문제. 조건과 답은 구분하고 학습 연결·교재 위치는 접어서 연다. 모바일은 같은 순서의 한 열이다. 화살표로 형제 유형에 필수 선수 순서를 부여하지 않는다.

기존 제품의 흰색#FFFFFF·본문#193D3B·선택#226B5B·경계#C4CEC4·보조면#EEF5F0를 사용한다. 현재 한글 서체를 유지하고 본문16px/제목28px/하위제목21px, 왼쪽 정렬과44px이상 조작 영역을 둔다. 의미 없는 애니메이션·장식은 넣지 않는다. 분류 경로가 시각적 중심이며 큰 통계판은 추가하지 않는다.

전체450후보를 임의의4단계에 배치하지 않는다. 두 집합으로 확인한 유형은 사용자 제안의 분류안 경로를 표시하고, 검토 전 유형은 기존 유형군과 검색으로 접근한다. 조건 변형 VN02/VN06은 같은 짧은 유형 이름 아래 선택할 수 있으나 원래ID/검산/난도를 합치지 않는다. VN07의 두/네모둠 혼합은 두집합으로일괄귀속하지않는다.

문제는 기존 구조화 지문·필수도형·정답·풀이와 생성기를 재사용한다. 학생에게 풀이 설명 그림을 더하지 않는다. 저장 완료/오류·답 숨김·키보드·320/390px·문제지 학생/교사 인쇄를 실제 흐름으로 확인한다.
