배포 https://lete-on.gfieldacademy.net/roadmap/

우리 아이 위치를 표준 진도 다섯 개와 겹쳐 보여 준다.

## 2. 표준 로드맵 다섯 개

| 레벨 | 무엇을 기준으로 한 진도인가 |
|---|---|
| L0 | 선행이 빠른 프리미어 합격생 |
| L1 | 프리미어 표준 진도 |
| L2 | 챌린지 합격 후 P2·S2 선발 진도 |
| L3 | 필즈 주2회 E2 수준 |
| L4 | 안정적 상위권 소마 A반 |

각 레벨은 같은 축들을 갖습니다 — **소마 진도 · 필즈 진도 · 교과 응용/심화 · 사고력1 ·
사고력2 · 추천 가정학습 · 연산과정**. 레벨이 낮을수록 뒤쪽 축(프리미어·최상위)이 빠집니다.

**시간축의 주요 분기점**: 소마 선발 → RAY B 완료 → 프리미어 RISE 시작 → P1 선발 →
소마 입학 → 프리미어 선발(4월) / 필즈 입문 → 입학 테스트 1차 → 2차·3차 승급 → 필즈 S 선발

## 3. 수의 마법과 맞닿는 곳 — **연산 축**

이 로드맵의 연산 축은 **소마셈 K·P → 기적의 계산법 2~6권**입니다.
그런데 `number_magic/`(수의 마법)이 바로 그 자리를 채우는 우리 자체 연산 커리큘럼입니다.

- 기적의 계산법과 우리 사다리의 대조는 이미 해 두었습니다 — `number_magic/CURRICULUM-SOURCES.md` §9.
  뼈대: 12권 × 10단계 = 120단계, 초1~초6. 권의 마지막 단계는 언제나 "N학년 방정식"(역연산).
- **아직 안 한 것**: 이 로드맵의 "기적의 계산법 N권" 칸에 **우리 과정 번호를 나란히 적는 것**.
  그게 되면 상담에서 "지금 기적 3권이면 수의 마법 과정 ○○"이라고 한 줄로 이어집니다.
  → `number_magic/앞으로-진행할-것.md` 에 항목으로 올려 두었습니다.
