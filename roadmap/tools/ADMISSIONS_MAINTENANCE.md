# 고입 요강 갱신

기준 데이터: `../demo2/planner-highschool-data.js`. 화면은 `planner-highschool.js`의 `freshness`로 확인 후 30일 또는 다음 접수·평가 7일 전부터 재확인을 표시한다. 공개된 학교·교육청 원문만 사용하며 미공개 날짜를 다른 연도에서 옮기지 않는다.

1. `node roadmap/tools/check-admissions.mjs`로 학교별 재확인 대상을 확인한다. `--links`는 원문 접속도 확인한다. HTTP 성공은 내용 검수 완료가 아니다.
2. 학교의 요강과 정정·변경 공지를 대조한다. 원서·온라인 입력·서류 도착/소인·전형료·단계별 평가·발표·등록 마감을 구분한다. 시각이 없으면 만들지 않는다.
3. 변경한 학교의 학년도, `checked`, 원문 URL과 쪽수, 비교 8항목, 일정·미정 일정을 함께 갱신한다. 다른 학교의 확인일은 올리지 않는다. 새 학년도는 별도 학교-학년도 자료를 추가하도록 모델을 먼저 확장하며 전년도 일정을 치환하지 않는다.
4. `node --test roadmap/demo2/planner-highschool.test.mjs`를 실행하고 해당 학교의 조건·일정 화면과 미래 학년도 미전용을 확인한 뒤 배포한다.

2026-11-03 추가 대조: 경기과학고 PDF 1~5쪽(일정 3쪽), 상산고 1~8쪽(일정 1쪽), 하나고 PDF 4·13~16쪽, 동탄국제고 5·8·10~12·17~18쪽. 경기과학고 PDF의 오래된 원서접수 도식보다 3쪽 최종 일정표를 사용한다. 동탄국제고는 이미지 PDF를 직접 판독했다. 원본은 재배포하지 않고 학교 링크를 제공한다.
