GitHub 검색으로 기존 로고 사용 문서도 확인했다. 성장 그림과 풍경은 이미 승인된 `learning-growth-symbols-20261101.webp`, `learning-landscape-20261023.png`다. 글꼴은 프로젝트의 Pretendard다.

성장 그림의 이동·확대와 지도/선/선택 표시를 조합한 모션 그래픽이다. 새로 생성한 인물 동작 영상이나 실제 사용자 화면 녹화는 아니다. 표와 그래프는 소개용 예시이며 실제 학생의 성적·입시 결과나 제품의 산출 데이터를 주장하지 않는다. 학생 이름·개인 기록을 포함하지 않는다. 이번 영상 작업에 생성형 영상 API·음성 API·외부 음악·추가 유료 API를 쓰지 않았다. `soundtrack.py`가 표준 라이브러리만으로 원본 연주음을 합성한다.

## 다시 만들기

Node.js + Playwright, Python 3, ffmpeg가 필요하다. 프로젝트 루트의 로컬 정적 서버를 시작한 후:

```sh
node roadmap/demo2/tools/promo-reel/render.cjs
```

`REEL_BASE`, `FFMPEG`, `PYTHON` 환경변수로 서버 주소와 실행 파일을 지정할 수 있다. 프레임 검수 이미지와 WAV는 임시 폴더에 보관하며 저장소에 넣지 않는다. Playwright는 Node의 일반 모듈 탐색 경로를 사용한다. 렌더링은 외부 네트워크 요청을 차단한다.
