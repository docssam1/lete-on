# 캐릭터 연기 애니메이션 — 2026-11-01

사용자는 앞선 확대·이동 중심의 소개 영상을 수정 요청했다. 실제 캐릭터가 성장하고 고민하며 공부하는 애니메이션이 목적이다.

## 완성본과 포함 범위

`../../assets/roadmap-character-animation-20261101.mp4`: 720×1280, 24fps, H.264/AAC, 13초. 캐릭터 연기 원본 10초 + GFIELD 브랜드 마무리 3초다. 기존 25초 모션 그래픽 파일은 보존하고 계정 화면의 연결을 새 파일로 바꾼다.

- 책장을 넘기고 함께 읽는 어린 남녀 학생.
- 성장한 학생이 연필을 멈추고 한 손으로 볼을 괸 채 고민하는 표정.
- 선생님이 옆에서 노트에 적으며 안내하고 학생들이 함께 살펴보는 동작.
- 더 성장한 학생들이 다시 노트를 읽고 쓰는 동작.
- 원본 GFIELD 로고, “성공하는 공부습관 만들기” 마무리.

고등학생까지의 뚜렷한 성장 장면은 이번 파일에 포함하지 못했다. 추가로 요청한 10초 후반 장면은 생성 서비스가 미성년자 관련 사유로 거절했다. 재시도로 우회하거나 기존 완성본을 고등학생 성장 장면으로 표시하지 않았다.

## 생성·편집

Mac의 기존 Gemini 앱 `동영상 만들기`를 UI로 사용했다. 화면에는 Omni 모델로 만들기가 표시되어 있었으며 세부 엔진 버전은 확인하지 않았다. 별도 유료 API·결제·요금제 변경은 하지 않았다. 연결된 Weave 모델 검색은 계정 미연결 응답으로 끝났고 생성 실행은 하지 않았다.

주요 생성 지시: 따뜻한 아이보리 서재의 부드러운 3D 애니메이션, 같은 갈색 곱슬머리 남학생과 라일락 리본의 여학생, 책 넘기기·쓰기·연필 멈추기·볼 괴기·시선·눈 깜빡임·선생님과 노트 보기, 성장에 따른 얼굴·체형·옷 변화, 음성·자막·로고 없이 실제 연기 동작. 요청 길이는 24초였으나 서비스 출력은 10.03초였다. 결과를 그대로 24초라고 보고하지 않고 실제 길이에 맞춰 13초 광고로 편집했다. 생성 대화는 Gemini의 `GFIELD Growing Together Animation`이며, 사용자 학생 사진·성적·대화 기록은 전송하지 않았다. 새 가상 캐릭터를 텍스트로 지시했다.

원본은 `output/video/character-growth-v2/source-gemini.mp4`에 보존한다(공개 사이트에 복사하지 않음). SHA-256: `d4a9f2c7b1b944cabf6959e1853209cb8057bc9ebae7a1c8efb7b693f0450ebe`. Gemini 다운로드 원본과 생성 표시를 보존한다. 실제 녹음된 음성은 사용하지 않도록 원본 오디오를 제거하고, 기존 `soundtrack.py`의 직접 합성한 연주음만 넣었다. 청취 검수는 미실시이며 오디오 소스 구성과 스트림을 확인했다.

`finish-character.cjs`가 원본에 로고·한국어 자막·브랜드 마무리·배경음을 붙인다. `REEL_FONT`에 Pretendard 600 TTF를 지정했다(프로젝트 OFL WOFF2에서 변환한 편집용 로컬 사본). 원본 SVG는 WebP 이미지를 내장하므로 그 페이로드를 직접 PNG로 디코딩해 영상에 넣었다. SVG를 일반 래스터 처리할 때 로고가 누락되는 문제를 주요 프레임 검수에서 찾아 수정했다.

```sh
REEL_FONT=/absolute/path/to/pretendard-600.ttf node roadmap/demo2/tools/promo-reel/finish-character.cjs /absolute/path/to/source.mp4
```

`FFMPEG`, `PYTHON` 실행 경로를 지정할 수 있다. 두 번째 원본을 전달하면 23초 편집도 가능하지만 현재 배포본은 첫 번째 원본만 쓰는 13초다.

## 확인

원본·최종 주요 프레임, 책장·손·표정·나이 변화, 자막·실제 로고·마지막 브랜드 화면을 확인했다. 데스크톱 1440×1000·모바일 390×844·가로 844×390에서 13초/720×1280·무음 자동 재생·음소거 전환·일시정지·다시 보기·동작 줄이기 설정을 확인했다. 버튼 44px·가로 넘침 없음·브라우저 오류 0건이다. 실제 스마트폰 기기 검수는 아니다. 시각 검수 및 브라우저 결과는 기존 `output/video/character-growth-v2/`에 보관한다. 인증·회원 데이터 코드는 수정하지 않았다.
