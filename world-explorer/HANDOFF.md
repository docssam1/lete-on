- 진입점: `/world-explorer/index.html`

## 2. 확정된 사용자 경험

첫 접속의 순서는 다음과 같다.

```text
제공된 MP4 인트로 영상
→ 탐험가 로그인 화면
→ 기존 탐험가 선택 또는 새 탐험가 만들기
→ 탐험가 이름 입력
→ 4자리 비밀번호 생성 및 재확인
→ "세계 여행을 준비하는 중..." 로딩
→ 3D 세계 탐험 마을
```

- 인트로는 정적 로고 화면보다 먼저 나오는 **첫 화면**이다.
- 영상 파일: `assets/intro/gfield-world-explorer-intro.mp4`
- 시작 버튼을 누르거나 영상이 끝나면 탐험가 로그인으로 넘어간다.
- 로그인은 서버 계정이 아니라 기기 안의 탐험가 프로필 선택 방식이다.
- 탐험가별 이름, 4자리 비밀번호, 진행도, 캐릭터 상태를 localStorage에 분리 저장한다.
- 모바일 가로 화면을 기본으로 하며, 가능한 브라우저에서는 전체화면을 지원한다.
- 한·중·일·영 언어 토글은 로그인 화면과 앱 안에 모두 제공한다.

## 3. 게임 세계와 핵심 루프

3D 마을은 하나의 중앙 허브다. 195개 나라별 마을을 따로 만드는 구조가 아니다.
탐험가가 마을 안을 이동해 각 게임 존에 들어간다.

| 마을 장소 | 연결 기능 |
|---|---|
| 국기 광장 | 국기를 보고 나라 맞히기 |
| 세계 도서관 | 지리·문화·역사 단서를 보고 나라 맞히기 |
| 지도 전망대 | 세계지도 기반 위치 게임 4종 |
| 여행자 상점 | 캐릭터 선택, 의상/모자/큐비 꾸미기 |
| 탐험 안내소 | 큐비의 게임·교과 안내 |

지도 전망대의 게임은 다음 네 종류다.

1. 제시된 나라를 지도에서 찾기
2. 강조된 위치를 보고 나라 이름 맞히기
3. 나라 윤곽을 보고 맞히기
4. 국기를 보고 지도에서 나라 찾기

문제를 해결하면 포인트·연속 정답·나라 발견 기록이 저장된다. 해결한 나라를
지도와 수집 진행에 반영하는 것이 기본 보상 루프다.

## 4. 교육 콘텐츠 원칙

국기 퀴즈만 만드는 것이 아니라 초등 사회 학습에 도움이 되는 세계 탐험 게임을 목표로 한다.

- 국가 위치와 대륙/지역
- 수도와 인구·면적 규모
- 자연환경과 기후
- 언어·생활·문화 등 인문 정보
- 대표적인 역사 사실과 세계사적 의미
- 국가별 정보 카드와 단계형 힌트

힌트는 한 번에 답을 공개하지 않고 이름 글자 수, 지역, 인구·면적 규모, 첫 글자 순서로 제공한다.
통계성 정보에는 향후 기준 연도와 출처를 명시해야 한다. 현재 195개국 기본 데이터가 있지만,
긴 설명의 정확성·표현·다국어 완성도는 별도의 콘텐츠 감수를 계속해야 한다.

## 5. 3D 마을 디자인 방향

목표는 따뜻하고 풍성한 생활형 3D 마을이지만 특정 상용 게임의 그래픽·캐릭터·건물을
복제하지 않고 **GFIELD 고유의 아기자기한 세계 탐험 마을**로 만든다.

현재 반영된 요소:

- 아이소메트릭/탐험/3인칭 카메라 전환
- 가상 조이스틱, 터치 이동, WASD/방향키 이동
- 큐비 동행 캐릭터와 사람형 탐험가/NPC
- 중앙 분수, 게임 존 건물, 길, 조명, 벤치
- 둥근 수관의 나무와 일부 과일나무
- 꽃 관목, 꽃밭, 연못, 해안, 바위, 울타리, 표지판
- 피크닉 공간과 건물 창틀·화분·굴뚝 디테일
- 나뭇잎 바람, 관목 흔들림, 물결 애니메이션
- 건물/나무/연못/소품 충돌 판정

외부 고용량 3D 모델 없이 모바일 성능을 지키는 저폴리 메시로 구성돼 있다. 향후 GLB/GLTF
자산을 추가할 경우에도 모바일 성능 등급과 자산 레지스트리를 먼저 설계한다.

## 6. 캐릭터와 상점

사람형 탐험가를 선택하고 색상과 장비를 꾸미는 구조다. 큐비는 주인공 대신 동행 가이드 역할을 한다.

- 선택 프로필: 아리, 루카, 미나, 유준(Yujun), 유빈(Yubin) 등
- 커스터마이징: 피부색, 머리색, 재킷, 스카프, 모자, 큐비 색상
- 유준·유빈은 `character-data.js`의 `CHARACTER_PROFILES`에 등록돼 있다.
- 캐릭터 선택 UI는 프로필 배열을 순회하므로 프로필 수를 고정값으로 가정하지 않는다.
- 유료 모자: 사파리 헬멧, 탐험왕 왕관, 마법사 모자 등에 서로 다른 3D 지오메트리가 구현돼 있다.
- 구매, 보유, 장착 상태는 탐험가 계정별 localStorage에 저장한다.

주의: 유준·유빈 및 유료 모자 3종의 코드 존재는 확인했지만, 최신 마을 개선 커밋 이후
각 조합의 구매→장착→새로고침 복원까지 전부 다시 촬영한 회귀 검증은 남아 있다.

## 7. PWA와 저장 구조

- manifest: `manifest.webmanifest`
- 서비스 워커: `sw.js`
- 현재 캐시: `world-explorer-shell-v11`
- 서비스 워커 등록 경로/범위: `/world-explorer/sw.js`, `/world-explorer/`

- 설치 배너: `beforeinstallprompt` 지원 브라우저 처리
- iOS: 홈 화면 추가 안내
- standalone 감지와 전체화면 API 기능 감지

서비스 워커나 정적 파일을 수정할 때는 캐시 이름과 `index.html`의 `?v=` 버전을 함께 올린다.
Geometry/Numbers World 캐시를 precache하거나 삭제하지 않는다.

## 11. 금지 사항

- `/geometry/` 또는 Geometry World 코드를 이번 앱 작업 때문에 수정하지 않는다.
- Geometry/Numbers World의 manifest, 서비스 워커, 저장 키를 재사용하지 않는다.
- 195개 나라가 모두 완성 검수됐다고 보고하지 않는다. 기본 데이터 존재와 교육 콘텐츠 감수는 별개다.
- 모바일에서 데스크톱 UI를 단순 축소하지 않는다.
- 국기나 지도 도형이 없을 때 ISO 문자만 크게 띄우는 것을 완성된 국기 화면으로 간주하지 않는다.
- 특정 상용 게임의 캐릭터·건물·UI를 그대로 복제하지 않는다.
- 검증하지 않은 구매/저장/오프라인 동작을 완료로 보고하지 않는다.
- 기존 사용자 localStorage를 마이그레이션 없이 초기화하지 않는다.

## 12. 작업 재개 체크리스트

```powershell
git status --short --branch
git fetch origin --prune
git log -8 --oneline --decorate
python world-explorer\validate_build.py
```

그다음 로컬 HTTP 서버를 저장소 루트에서 실행하고 `/world-explorer/`로 접속한다.
인트로·로그인·로딩·마을·세 게임 존을 확인한 뒤에만 커밋/푸시한다.
