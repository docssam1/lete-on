# 과정별 선발·입학·편입·누적 진단

`hsmiddle`과 데이터가 섞이지 않는 독립 프로그램입니다. 첫 구현은 `SH` 고등과정 선발이지만, 전체 제품은 중1 시작·입학, 중등 입반·편입, 고등과정 선발, 공통수학 입학·편입을 시험 버전별로 다룹니다. `누적테스트`는 실제 누적 평가인 시험에만 사용합니다.

학원·운영 주체는 `programCode`, 지원 목적은 `trackId`, 실제 범위는 `scopeKey`로 분리합니다. 같은 코드 안에서도 중1 시작반과 공통수학 입반의 원본·답·배점·컷을 공유하지 않습니다.

## 화면

- `promo/` 소개·신청 동선
- `login.html` 이름 + 승인번호 로그인
- `library.html` 승인/잠금 상태가 함께 보이는 시험지 서재
- `exam.html` 세로 시험지 뷰어 + 단일·복수칸·순서목록·순서무관집합·자기확인 답안 입력
- `report.html` 인쇄 가능한 진단 분석지
- `admin/` 학생별 시험지 승인 관리
- `admin/review.html` SH-R01 40문항 검증 상태·개별 승인 관리
- `admin/item-review.html` 관리자 전용 문제·원답·독립 검산 보호 이미지 대조
- `question-bank/` 현행 교육과정 분류와 유사문제 생성 준비 상태

광고 페이지에는 검색 근거가 있는 실제 학원명을 표시합니다. 로그인 이후 시험·문항·분석 데이터는 `SH/DP/WM/ED/DG/SM` 코드로만 분리합니다.

## 상태 원칙

시험 공개는 두 조건을 모두 만족해야 합니다.

1. 학생이 해당 시험을 승인받음
2. 시험 원본·답안·유형·교육과정 감사가 끝나 `released` 상태임

검수 전 시험은 목록에는 보이지만 열리지 않습니다. 답안이 없으면 채점과 분석을 만들지 않으며, 강의가 없으므로 영상 UI도 없습니다.

커트라인은 학원 공통 숫자로 저장하지 않습니다. 학원 코드·지점·과정·시험 회차·교육과정 버전이 모두 맞는 정책을 시험별로 사용자가 승인한 경우만 판정하며, 나머지는 `합격 기준 확인 필요 — 점수/진단만 제공`으로 표시합니다.

## 비공개 자료 원칙

- 원본 PDF/HWP, 답안, 대형 페이지 이미지를 이 공개 코드 폴더에 넣지 않습니다.
- 브라우저에 PDF URL을 전달하지 않습니다.
- 운영 뷰어는 서버가 권한 확인 후 반환하는 짧은 만료시간의 페이지 이미지 목록만 사용합니다.
- 승인번호 원문을 정적 JavaScript에 저장하지 않습니다.
- `assets/private/` 같은 폴더를 만들지 말고 비공개 저장소와 운영 API를 연결합니다.
- 원본·쌍둥이·유사 문제는 출처 지문과 계보만 공개 코드에 두고, 실제 문항 페이지는 학생·시험별 단기 서명 래스터로 전달합니다.

## 현재 구현 범위

첫 시험 `SH 고등 선발 대비 1회`는 원본 구조(40문항, 문제 8쪽, 답·풀이 3쪽)를 확인했습니다. 7개 교정 보호 산출물과 확인필요 분류 12건은 에이전트 검수로 확정했습니다. 이름+승인번호, 시험별 권한, 단기 서명 페이지, 무답안 응답 스키마, 비공개 채점 어댑터, 제출·분석지 API는 `server/`에 격리 구현했고 통합 검증을 통과했습니다. 실제 비공개 학생·정답·페이지 설정과 시험 1회 최종 확인을 운영 환경에 연결하기 전에는 `review_pending`으로 잠겨 있습니다. 배포·비공개 설정 계약은 `docs/SERVER-DEPLOYMENT.md`에 있습니다.

문항 검수 화면은 후보 분류와 중립 교정 종류만 공개 데이터에서 읽고, 답 검산·분류 검증·시각 감사·원본 및 보호 교정 산출물 지문 일치 상태는 운영 서버에서만 받습니다. 문항은 에이전트가 `검증 확정`, `대체 검증`, `채점 제외` 중 하나로 안전 처리합니다. 사용자는 문항마다 다시 승인하지 않고 40문항 처리가 끝난 시험 1회 전체만 최종 확인합니다. 정적 화면이나 브라우저 저장값으로 처리 상태를 만들 수 없습니다.

학생 화면에는 기관명이 아니라 `SH`, `DP`, `WM`, `ED`, `DG`, `SM` 코드만 사용하고 작성자는 `T`로 표시합니다.

진단지는 황소 초등 40문항 분석 구조를 주 기준으로 삼아 `○/×`, 영역·학년학기·단원·세부유형·난이도, 근거 기반 다층 코멘트, 회차 비교를 제공합니다. 돌파 중1 입학 선수 과정 성적표는 해당 프로필의 보조 자료로만 사용합니다.

DP 중2-2 편입 원본형은 중1-1~중2-2 누적 30문항 판본을 별도 트랙으로 감사했습니다. 원답 29개와 원답 공란 1개까지 독립 검산을 마쳤으며, 공개 코드는 값 없이 문항별 분류·난이도·응답형과 검증 상태만 가집니다. 보호 채점기·인쇄 안전본·서명 자산·회차 전체 확인 전에는 조립·채점·학생 공개를 차단합니다. 자세한 근거 상태는 [DP-MIDDLE22-202404-REVIEW-INVENTORY.md](docs/DP-MIDDLE22-202404-REVIEW-INVENTORY.md)를 참고하세요.

진단 뒤에는 승인된 `원문 -> 쌍둥이 -> 유사문제` 계보를 이용해 반복 연습 세트를 만들 수 있습니다. 숙달 상태별 1·3·14일 간격, 낮춤·기준·올림 난이도, 최근 동일 문항 제외, 한 세트 내 계열 중복 방지를 적용하며 세트 자체도 사용자 승인 전에는 공개하지 않습니다. 상세 정책은 `docs/PRACTICE-BANK-REPETITION.md`에 있습니다.
