# O/X 결과 코멘트 연결과 원수학 용어 교정

운영 중인 결과 화면과 선생님의 제출 결과에 같은 학습 코멘트를 표시한다. 저장된 O/X·미확인 상태와 문항의 영역·단원·유형만으로 이번 기록 요약, 최대3개의 재풀이 유형, 학부모 확인 문장을 만든다. 과거에 저장한 결과도 열면 적용되며 별도의 결과 DB 수정이나 외부 AI 전송은 필요 없다. 학생 화면에서는 X/미확인 문항과 정답·풀이로 바로 이동하고 학부모 문장을 복사할 수 있다.

기존 report-builder의 근거 연결 원칙을 운영 self-report 형식에 맞춰 `shared/self-check-comments.js`에서 적용한다. 미확인 문항은 오답이나 약점으로 세지 않는다. 정답률에 따른 합격·진도 준비·실력 판단을 만들지 않고 관찰한 O/X와 문항 번호를 제시한다. 합계와 번호가 맞지 않는 기록에는 코멘트를 생성하지 않는다. 이전 자동채점 기록의 채점·승인·판정 로직은 바꾸지 않는다.

원수학 공통수학1 기본반 5회250문항의 문제·풀이·현재 유형명을 점검해20문항의 명칭이나 설명을 교정한다. 1회38번은 공간대각선이라는 불필요한 명칭을 빼고 그림의 꼭짓점 A와 B 사이 표면 경로를 직접 묻는다. 실근, 사건의 독립, 여사건, 정의역 등의 명칭은 중등 문맥의 해·조건·반대 경우·x의 값의 범위로 풀어 쓴다. 함수기호를 겹쳐 쓰던2문항은 같은 조건을 일차함수의 x와 y 값 및 대입으로 표현한다. 답, 수치 조건의 의미, 문항번호, 도형은 유지한다.

교육부 고시 제2022-33호 별책8의 중등 용어 목록에 있는 포물선·함숫값·항등식·근·근의 공식은 과정 밖 용어로 분류하지 않는다. 이번 교정은 명칭·기호·설명에 대한 검수이며 학원 심화 문항의 모든 성취기준 적합성 재심사와 구분한다. 원문·답안·PDF·보호 페이지는 공개 Git에 두지 않고 기존 Drive 파일과 비공개 운영 페이지를 교정한다. 기존 결과의 원수학 유형명7건은 표시 시에만 새 표현으로 연결하며 저장한 O/X와 성적 기록을 수정하지 않는다.
