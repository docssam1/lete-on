# 도형 문항 생성기 참고 자료와 적용 원칙

## 적용 결론

Geometry3K, PGPS9K, GeoGen은 외부 문제 그림을 그대로 가져오는 창고가 아니라 도형을 `점·선·원 등의 대상`, `평행·수직·합동·닮음 등의 관계`, `주어진 조건`, `구할 것`, `정리 기반 풀이 과정`으로 저장하는 방법을 참고하는 자료로 사용한다.

우리 도형 문항은 다음 순서로 만든다.

1. 원문 문항의 조건과 구할 것을 구조화한다.
2. 조건끼리 모순이 없는지 검사한다.
3. 점의 좌표를 배치한다.
4. 같은 조건에서 SVG 도형을 새로 그린다.
5. 문제 제작 계산과 다른 방식으로 정답을 다시 계산한다.
6. 가능한 답을 검사해 정답이 하나인지 확인한다.
7. 글자·각 표시·점 이름·선분이 겹치지 않는지 PC, 모바일, 인쇄 화면에서 확인한다.
8. 검수에 실패한 문항은 학생에게 보이지 않게 잠근다.

## 확인한 참고 자료

| 자료 | 확인한 내용 | 우리 사용 방법 |
|---|---|---|
| Geometry3K / InterGPS | 3,002문항, 도형 주석과 논리 형식, 저장소 MIT | 기하 관계와 형식 언어 구조 참고 |
| PGPS9K | 9,022문항, 서로 다른 도형 4,000개, 30개 문제 유형, 정리 기반 풀이 프로그램 | 세부 유형·구조/의미 관계·풀이 경로 필드 참고 |
| GeoGen | 생성, 좌표 배치, 그리기, 풀이, 목표 찾기, 검증 모듈을 분리한 MIT 코드 | 우리 SVG 생성기와 감사기를 분리하는 구조 참고 |
| GeoEval | 본 평가 2,000문항, 역방향 750문항, 표현 변경 2,000문항, 고난도 300문항 | 난도·표현 변화·그림 의존성 평가 참고. 자료는 학술 신청형이므로 직접 수집하지 않음 |
| DL4GPS | 기하 문제풀이 연구와 데이터셋을 모은 목록 | 새 자료를 찾을 때만 사용하는 탐색 목록 |

## 사용 제한

- 저장소 코드의 MIT 표시는 곧바로 모든 원문·출판사 문제·도형 이미지의 판매 권리를 뜻하지 않는다.
- 외부 데이터의 원문과 그림은 공개 판매 문제은행에 자동 등록하지 않는다.
- 공개 문제에는 우리가 가진 사용 권한이 확인된 원문 또는 조건을 독립적으로 설계해 새로 만든 문항만 넣는다.
- 도형 생성기는 수치만 바꾸지 않고 조건 수, 보조선 필요 여부, 정리 연결 수, 보기 구조로 난도를 조절한다.
