# 모의고사 표시 문구

2026-11-26 원장 지시: 학생·교사용 화면과 새로 제작·개정하는 시험지, 정답·풀이, 학습분석지에는 ‘지필드 자체제작’, ‘지필드 자체 제작’, ‘자체 제작 대비’ 표현을 넣지 않는다.

과정과 회차로만 이름을 붙인다. 예: ‘이든 중1 시작반 대비 1회’. 범위는 ‘초5·초6 전 과정’처럼 표시한다.

공식 기출이라고 바꾸어 표시하지 않는다. 내부 출처·제작 이력과 기존 보관 원본은 보존한다. 기존 PDF 내용까지 수정한 것으로 표시하려면 해당 PDF와 보호 뷰어의 실제 페이지를 별도로 확인해야 한다.
