# DP 중2-2 편입 1차 모의고사 원본 검수 목록

## 확인된 구조

- 트랙: 중2-2 편입
- 범위: 중1-1~중2-2 누적
- 문항: 30문항
- 원본 구성: 표지 1쪽, 공백 1쪽, 문제 8쪽, 답안 1쪽
- 시간: 150분(해당 판본 전용)
- 기준: 20문항(해당 판본 전용·운영 미승인)
- 답안: 30개 번호행 중 1번 원답 공란, 2~30번 빠른 답 존재
- 상세 해설: 없음
- 제공 형태: 원본은 출제 근거로 보존, 학생용은 공통 A4 폼의 1차 판매용 모의고사

유사한 `중2-2` 반 표기를 가진 고등 선행 자료는 이 트랙과 연결하지 않는다. 같은 범위의 다른 월별 판본도 별도 회차로 보존하며, 시간과 기준을 서로 승계하지 않는다.

## 문항 구성

원본 페이지별 문항은 `1~4 / 5~8 / 9~12 / 13~16 / 17~20 / 21~24 / 25~28 / 29~30`이다. 도형·닮음·각 추적이 중심이며 일차함수, 연립일차방정식의 활용, 확률이 함께 출제된다.

문항별 공개 검수 데이터에는 다음 정보만 둔다.

- 중립 문항 ID와 원본 페이지 번호
- 2022 개정 기준 학년·학기 후보
- 대단원·세부유형 후보
- 기준/올림 난이도 후보
- 단일 입력, 순서 없는 복수답, 분리된 복수 입력 후보
- 원본→유형→쌍둥이·유사문제 계보 ID

문제 원문, 답 값, 원본 파일명, 로컬 경로, 파일 지문은 공개 코드에 넣지 않는다.

## 출시 상태

문항 분류와 인쇄 배치를 시각 검수했고 2~30번 원답 29개는 독립 검산과 일치했다. 원답이 비어 있던 1번은 결정적인 작도 조건으로 비공개 보완했으며, 공개 코드에는 값이나 풀이를 넣지 않았다. 따라서 문항 단위 답안 감사는 끝났지만 현재 상태는 다음과 같다.

- 조립: 가능
- 자동 채점: 차단
- 학생 공개: 차단
- 판본 전용 기준 적용: 차단

보호 채점 정책, A4 인쇄 안전본, 300dpi 서명 페이지 자산은 검증을 마쳤다. 회차 전체 확인이 끝난 뒤에만 자동 채점과 학생 공개 상태를 승격한다.
