# 원수학 중2-2 기본반 편입 대비 4회

중2-1 대수 기본형 25문항과 중1-2 기하 심화형 25문항(통계 제외)을 기존 시험지 뷰어에 추가한다. 모두 주관식이며, 학생은 종이에 풀고 정답·해설과 대조하여 O/X를 저장한다.

- 시험 시간: 대수 70분, 기하 70분. 교시 사이 20분, 전체 진행 160분이다. 공식 공지의 휴식행 10분과 교시 시각 사이의 간격은 구분한다. 기존 1~3회 이력은 보존한다.
- 문서: 시험지 22쪽, 정답·해설 26쪽, 학습 분석지 5쪽. 작도 문항은 70mm의 작업 공간을 배정했다.
- 도형: 학생용 26개와 해설 전용 작도 그림 1개. 길이는 가는 바깥 곡선 점선, 각은 안쪽 각호로 표시한다. 개별 SVG 스타일을 해당 도형에만 적용해 음영과 화살표가 다른 도형의 스타일에 영향을 받지 않게 했다.
- 내용 검수: 수학·정답 50문항과 학교 범위, 실제 PDF 53쪽, 글꼴 내장·수식·번호·표·잘림을 점검했다. 첫 출력에서 발견한 음영 누락과 수정 후 재검수 기록을 보관했다. Apple Vision OCR은 보조 점검으로 사용했다.
- 연결: 기존 인증·학생 권한·자기 확인 채점 방식과 보호 이미지 저장소를 사용한다. 공개 저장소에는 문항 원문·정답·풀이·시험지 이미지·인증 정보를 넣지 않는다.

등록 코드는 기존 37회 1440문항을 보존하고 38회 1490문항으로 늘어난다. 운영 반영 여부는 배포와 실제 모바일 검수 결과로 별도 확인한다. 학생 응시 시간의 실측과 실물 출력 검증은 남아 있다.

비공개 원고·PDF·검수 기록은 기존 Drive의 `highschool-selection/deliverables` 제작 폴더에 보관한다. 원본 문제은행의 잠금은 변경하지 않는다.
