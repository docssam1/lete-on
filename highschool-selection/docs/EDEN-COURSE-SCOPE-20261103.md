## 기존 이든 1·2회 수정

- 이전 명칭 `고등선행 대비`를 `이든 공통수학1 기본반 입반 대비`로 바꾼다. 이 자료를 대수 기본·실력·심화 대비로 소개하지 않는다.
- 중2-1·중3-1의 수·식·부등식·방정식·함수 문항 1~20번은 대수 영역으로, 21~30번은 기하 영역으로 구성한다.
- 각 회차 기존 26번(경우의 수·확률)과 30번(통계)을 중등 기하 자체 제작 문항으로 교체한다. 이전 문제와 교정 해설 PDF는 보존한다. 교체한 4문항은 공식 기출이 아니다.
- 두 회차 모두 30문항·100분·서술형이다. 시험지·정답해설의 표지, 머리말, PDF 제목, 파일명과 목록 정보를 함께 수정한다.
- 기존 답안 O/X 확인표를 유지한다. 자동 답안 입력·합격 판정을 추가하지 않는다.
- 공식 공지의 21문항 이상 기준은 풀이 과정과 영역 균형 검토를 포함한다. 우리 모의고사의 자동 합격선으로 적용하지 않는다.
- 원래 8회·290문항 검수 이력과 신규 대체 4문항 검수 이력은 분리한다. 새 4문항의 독립 검수가 끝나기 전에는 수정 후보를 공개·배포하지 않는다.

호환성을 위해 시험 ID `ed-high-advance-entry`와 인트로의 기존 `high-advance` 과정 링크는 보존하고, 사용자에게 보이는 과정명과 `courseCode=common1-basic`을 바로잡는다. 중립적인 시험 분류는 `common-math-entry`에 배정한다. 인증 정보·원문 PDF·정답은 공개 Git에 넣지 않는다.
