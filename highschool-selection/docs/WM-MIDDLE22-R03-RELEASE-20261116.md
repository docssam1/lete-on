# 원수학 중2-2 기본반 편입 대비 3회

중2-1 대수 기본형25문항과 중1-2 기하 심화형25문항(통계 제외), 전부 주관식50문항의 3회를 추가한다. 시험지25쪽·정답해설26쪽·학습분석지5쪽을 기존 보호뷰어와 O/X 자기 확인에 연결한다. 별도의 수치 답안 입력은 받지 않는다.

[최신 공식 편입 공지](https://blog.naver.com/wonmath563/224470731361)의 대수16:00~17:10·기하17:30~18:40을 적용한다. 각70분, 풀이시간 합계140분, 교시 사이20분, 전체160분이다. 공식 휴식행의10분과 남은10분의 용도를 구분하며, 전체 간격을 휴식20분으로 표시하지 않는다. 과거1회와2회의 시간·문항·페이지는 보존한다.

50문항의 독립 풀이와 답 대조, 학교범위·구성, 학생도형20개와 해설전용도형1개, 실제PDF56쪽을 검수했다. 길이는 바깥 곡선점선과 실제 글자 간격, 각은 안쪽 각호, 도형은 가는 선을 사용한다. 일부 문항은 앞선 원문·힌트 노출을 기록했으며 전50문항 완전 블라인드로 표현하지 않는다. 실물 인쇄·학생 풀이시간과 난도 실측은 별도 후속 점검이다.

기존36회와 인증·관리자·채점 코드를 보존한다. 새 회차가 포함된 공개 목록은37회·1,440문항이다. 기존 비공개 이미지262개에 새56개를 추가하며, 기존 경로와 바이트는 보존한다. 이미지·PDF·원문·정답·승인번호는 공개 Git에 넣지 않는다.

공개 전에 검수용 계정으로 모든 보호 이미지, 390px 모바일의 페이지 이동·확대·문서 전환·위치 복원, O/X50개 초안과 서버 저장·재입장·DB 일치, 미배정 계정·서명 변조·만료·origin 거부를 확인한다. 임시 업로드 경로를 제거하고 검수 계정과 세션을 종료한다. 실제 배포와 검수 결과는 기존 Drive 프로젝트의 인수인계와 별도 배포 증빙에 기록한다.
