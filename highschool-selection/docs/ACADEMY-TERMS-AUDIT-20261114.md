# 과정별 용어 점검

기존 원수학 공통수학1 기본반 5회에 이어, 운영 서버의 다른 19회 700문항을 확인한다. 공개된 18회 670문항과 공개 목록에 없는 이든 중1 시작반 30문항을 구분하고 공개 여부는 바꾸지 않는다. 초5·6, 중1, 중2·3 누적, 공통수학1 및 공통수학2 도형의 방정식의 범위를 각각 적용한다.

공식 공지의 이미지와 현재 시험지·풀이의 스캔 부분은 Apple Vision으로 읽고, 원본 문항·그림 및 국가 교육과정의 용어 목록과 대조한다. 중등의 중근·함숫값·포물선, 실제 고등 범위의 복소수·판별식·행렬·순열·조합은 유지한다. 계승·수열 기호는 중1에서 같은 수의 곱·규칙으로 나타내고, 공간대각선·켤레·세바선 등의 불필요한 이름은 그림의 선분·분모의 유리화·중선 등으로 표현한다. 독립협회·독립신문 같은 고유명사는 확률 용어와 구분한다.

돌파 2회 22번의 실제 원뿔 문제에 정사면체로 붙어 있던 유형명도 바로잡는다. 기존 결과는 화면에 표시할 때 새 유형명으로 연결하며, 저장한 O/X·문항 번호·배정·채점 기록은 유지한다. 비공개 PDF·문항 원문·정답·이미지는 공개 Git에 포함하지 않는다. 외부 검수 AI API는 사용하지 않는다.

이 기록은 용어·기호·표현에 대한 교정이며 모든 심화 문항을 국가 성취기준 내 난도로 인증하는 뜻은 아니다. 실제 교정본·변경 문항·파일 체크섬·운영 검증 결과는 기존 Drive 프로젝트 위치에 보관한다.
