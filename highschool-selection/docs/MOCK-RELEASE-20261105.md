# 2026-11-05 검수 모의고사 16회 운영 반영

현재 검수판 16회·610문항을 기존 학생 로그인과 회차별 승인, O/X 자기 확인 동선에 연결한다. 시험지·정답해설·빈 학습분석지는 각 16개, 총 48개 PDF에서 만든 보호 페이지 549쪽이다. 원본 PDF와 실제 문항·정답·페이지 바이트는 공개 Git에 넣지 않는다.

기존 13회 중 원수학1회의 이전40문항 판본을 최신50문항으로 바꾸고2~4회를 추가한다. 나머지도 에이전트 검수 후 교정된 최종판으로 연결하며 모든 등록 회차의 공개 상태를 `released`로 둔다. 연구용 청사진·미완성 원본·클리닉은 추가하지 않는다. 기존 시험ID, 학생별 배정과 제출 기록을 유지한다. 판본이 바뀐 시험의 이전 화면 제출은 버전 불일치로 거부하며 새로 연 시험은 새 판본을 사용한다.

서버는 `paper`, `answers`, `analysis`를 별도 서명 종류로 검증한다. 학습분석지 보기도 로그인·현재 활성·만료·회차 권한을 다시 확인한다. 학생 화면에는 숫자 답안 입력 없이 문항마다 O/X와 미확인만 있으며 고정 합격선이나 자동 정답 판정을 만들지 않는다. 원수학은 전체 풀이시간140분과 영역별70분·별도 휴식20분을 구분한다.

새 페이지 함수들을 별도 버전 이름으로 먼저 배포하고 메인 시험 함수를 마지막에 교체한다. 기존 함수·운영 백업은 롤백용으로 보존한다. 실제 파일·페이지 해시, 운영 API·서명 종류 변조·권한 거부·O/X 저장·배포 결과는 비공개 운영 기록에 보관한다. 실제 학생 응시·실물 출력·실측난도 보정은 이번 사이트 공개 검증과 별개다.
