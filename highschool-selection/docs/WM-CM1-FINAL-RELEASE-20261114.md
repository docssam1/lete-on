# 원수학 공통수학1 기본반 최종(마무리)회

원수학 공통수학1 기본반 입학 대비 1~4회에 최종(마무리)회를 추가한다. `wm-common1-basic-final`, 과정 `WM:common1-basic`. 대수25/기하·확률25 전 문항 주관식, 각90분, 휴식20분 별도. 고등 공통수학 내용을 배우기 전 중2·중3 범위를 다루는 자체 제작 모의고사다. 기존 중2-1 기본반 과정의 70분 시험과 구분한다.

시험지·정답해설·학습분석지는 기존 A4 2단 명조 양식을 재사용하고 그림은 흑백 SVG로 작성한다. 제작자와 별도 에이전트가 질문만 보고 독립 풀이한 뒤 정답·중등 해설·그림을 대조한다. PDF·문항 원문·정답·보호 이미지 바이트는 공개 Git에 넣지 않는다. 공개에는 회차·범위·시간·문항 수·페이지 수만 추가한다.

운영 API의 기존 시험·권한·학생 기록은 보존하고 신규 회차만 추가한다. 단기 서명 페이지, O/X 자기 확인과 실제 서버 저장을 사용하며 자동 합격 판정을 만들지 않는다. 최종 배포·실행 검수 결과와 정확한 파일 SHA는 기존 프로젝트 Drive의 해당 최종회 폴더에 남긴다. 물리 출력·실제 학생 시간 측정은 별도 항목이다.
