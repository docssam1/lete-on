## 실제 배포와 보존

- 메인 앱 main 46, 보호 페이지 reader A 128·reader B 23으로 반영했다.

- 비공개 이미지 저장소에는 새 표지 10개만 추가됐다. 전체 1,045개이며 이전 1,035개 객체의 지문은 변경되지 않았다. 저장소는 비공개, 파일 한도 1 MiB, JPEG 전용 설정을 유지한다.
