## 수정

- 원수학 조사표에 남아 있던 7월 40문항·각50분을 현행 10월 50문항·각70분으로 정정. 7월은 과거 구성안으로 명시한다. 12월 공통수학1 기본반의 각90분과 혼합하지 않는다.
- 깊은생각 예비고1 범위에 남아 있던 2025년 중3-1 별도 범위를 제거. 공식 신청 화면의 2027 범위를 사용한다. 레벨을 임의로 배정하지 않는다.
- 생수 2회 14번의 중1 소인수분해 단독 문항을 중3 제곱근 조건 문항으로 교체. 시험지·해설·O/X 분석지·보호 이미지·분류를 함께 갱신하고 판본을 변경했다. 다른 29문항과 다른 17회 메타데이터는 보존했다. 새 문항은 소인수 지수 분석과 정수 완전탐색으로 각각 확인했다. 새 Claude/API 검수로 표시하지 않는다.
- 돌파 12월 공지의 커트라인 추후 발표, 생수 10월 공지의 전체 성적순 선발, 이든 12월 공지의 21문항·영역 균형·서술 과정 검토를 구분한다. 자동 합격 판정에는 연결하지 않는다.
- 황소 송파 시간·위례 컷을 대치의 활성 근거에서 제거. 대치 고등 시작반 시험시간은 후속 원장 확인으로 110분 확정했다. 공식 공개 안내의 문항 수·레벨 컷은 별도 확인하며 시간 확인을 근거로 다른 수치까지 확정하지 않는다.
- 원수학·깊은생각·생수의 확인된 공식 채널을 연결. 과정 화면에는 해당 지점·과정·모집 회차의 공식 링크를 짧게 표시한다.
- 이든 공통수학2 실력·대수 기본 안내의 누락된 정책 항목은 준비 중으로 명시하며 기존 공개 권한을 확대하지 않는다.

분당 돌파는 공식 진도표에서 공통수학1 기본반의 중2-1~중3-2와 150분을 확인했다. 대수까지 150분, 미적분1 포함 시험은 180분이다. 분당 깊은생각의 예비고1 공식 범위 조회는 현재 비어 있어 대치 범위·시간을 복사하지 않았다. 동명 학원을 분당 지점으로 추정하지 않는다.
