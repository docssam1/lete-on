# 원수학 중3-1 기본반 편입 대비 최종(마무리)

중2-1 대수 심화 25문항과 중2-2 기하 심화 25문항(경우의 수·확률 포함)을 추가한다. 대수 70분, 휴식 20분, 기하 70분으로 구성하며 전체 진행 시간은 160분이다. 2026년 10월 과정의 공식 수정 범위를 기준으로 제작했다. 다음 모집 일정을 뜻하지 않는다.

## 자료와 이용 흐름

- 시험지 26쪽, 정답·해설 31쪽, 학습 분석지 7쪽.
- 종이에 풀고 보호 뷰어의 해설과 비교한 뒤 O/X로 확인한다. 숫자 답안 입력은 추가하지 않는다.
- 기존 1~4회 다음에 최종(마무리)을 표시한다. 다른 과정이나 기존 회차의 범위·시간은 바꾸지 않는다.
- 문제·정답·해설·페이지 이미지는 공개 Git에 넣지 않는다. 기존 비공개 이미지 저장소와 인증된 페이지 조회를 이용한다.

## 내용·인쇄 검수

50문항의 독립 풀이와 정확한 판본별 정답 대조를 확인하고, 난도 검토에서 지적한 32문항을 재구성했다. 전체 편성과 새 교체 문항을 별도로 검토했다. 발상형 문항과 완급을 주는 문항을 함께 배치했으며, 모든 문항이 최고난도라는 뜻은 아니다.

실제 PDF 64쪽을 개별 열람해 글씨·수식·표·그림·답 칸·쪽 나눔을 확인했다. A4 크기와 글꼴 포함을 검사했고, Apple Vision 66이미지 검사는 문자 누락의 보조 확인으로 사용했다. 도형은 학생용 주어진 조건과 교사용 풀이 보조그림을 구분했다.

실학생 풀이 시간과 종이 출력은 미측정이다. 교시별 70분 안에 모든 문제를 완주한다고 보장하지 않으며, 미완주를 포함하는 선발 대비 훈련으로 편성했다.

## 배포 확인

완성 PDF와 비공개 원고·검수 자료는 기존 Drive 위치에 보관했고 전체 바이트·해시를 대조했다. 기존 보호 이미지 599쪽과 신규 64쪽의 원격 바이트·해시를 확인했다. 비공개 저장소의 익명 접근은 차단되며 임시 업로드 기능은 종료했다.

배포 전 390px 모바일 검수에서 시험지·해설·분석지 64쪽을 모두 열고 쪽 이동·확대·좌우 이동을 확인했다. O/X 50개의 임시 저장, 서버 저장, 재접속 복원 및 미승인 접근 차단을 확인했다. 공식 범위·과정 연결 검사 21건은 통과했다. 전체 검사에는 이번 변경 이전에도 재현된 실패 5건이 남아 있으며, 새 회차의 통과 결과와 구분한다. 운영 사이트에서도 배포 완료 후 같은 흐름을 확인한다.

기존 인증·관리자·채점 코드와 저장소 접근 정책은 유지한다. 검수에는 별도의 임시 시험 계정을 사용하고 검수 기록과 함께 정리한다.
