# 원수학 중2-2 기본반 편입 대비 최종(마무리)회

중2-1 대수 기본형 25문항과 중1-2 기하 심화형 25문항(통계 제외)의 최종회를 추가한다. 모두 주관식이며 종이에 푼 뒤 정답·해설과 대조하여 O/X를 저장한다. 기존 1~4회는 유지한다.

- 시간: 대수 70분, 기하 70분. 최신 공지의 두 교시 시작·종료 시각에 따라 교시 사이 20분, 전체 160분으로 표시한다. 공지에 적힌 휴식 10분과 교시 사이 간격을 구분한다.
- 문서: 시험지 25쪽, 정답·해설 29쪽, 학습 분석지 5쪽. 학생용 도형 23개와 해설 전용 도형 2개를 구분한다. 길이는 가는 바깥 곡선 점선, 각은 안쪽 각호로 표시한다.
- 검수: 독립 수학·정답 검수 50문항, 실제 PDF 59쪽의 시각 검수, A4·글꼴 내장·수식·번호·표·잘림 점검을 마쳤다. Apple Vision OCR은 보조 검사로 사용했다. 실물 출력과 학생 응시 시간은 실측하지 않았다.
- 보관: 최종 PDF 3종과 제작·검수 자료를 기존 Drive 제작 폴더에 보관하고 전체 원격 바이트와 내부 파일 체크섬을 검증했다. 원본 문제은행과 잠금은 변경하지 않는다.
- 연결: 기존 인증·학생 권한·보호 이미지 뷰어·O/X 자기 확인 방식을 사용한다. 공개 저장소에는 문항 원문·정답·풀이·시험지 이미지·인증 정보를 넣지 않는다.

공개 목록은 기존 38회 1490문항에서 39회 1540문항이 된다. 보호 이미지 연결과 390px 모바일 페이지 이동·문서 전환·초안 복원·서버 저장은 운영 반영 과정에서 별도 검증한다.
