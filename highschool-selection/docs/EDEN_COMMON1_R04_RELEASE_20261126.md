# 이든 공통수학1 기본반 4회 — 공개 반영 완료

중2·중3 전 과정의 대수 20문항·기하 10문항, 30문항·100분 모의고사다. 시험지는 13쪽, 정답·해설은 16쪽, 학습분석지는 4쪽이다. 공개 페이지는 기존 보호 뷰어와 O/X 자기채점 흐름을 사용한다.

문항·정답·풀이·분류, native 도형과 33쪽 PDF의 독립 검수 및 수정 후 재검수를 마쳤다. 공개 저장소에는 기존 보호 시험 ID의 과정·회차 연결과 표시 메타데이터만 있다. 문제, 정답, 해설, PDF, 이미지 원본, 내부 은행과 학생 자료는 포함하지 않는다.

실제 공개 사이트에서 격리된 390×844 브라우저 컨텍스트로 시험지 13쪽, 정답·해설 16쪽, 학습분석지 4쪽을 열었다. 33개 이미지 응답 모두 1500×2122 크기였고 동결 manifest와 바이트·SHA가 일치했다. 페이지 이동, 200%·300% 확대, 가로·세로 이동과 최소 44px 터치 버튼을 확인했다. O/X 30개를 저장하고 새로고침·결과 재열기·로그아웃·새 로그인 뒤 서버 저장 내용 복원을 확인했다. 검증한 QA 표시 집계는 O 10개·X 20개였다. 실물 휴대전화에서 시험하지는 않았다.

회수 전용으로 만든 QA 계정 2개와 그 계정의 세션 11개·응시 4개를 제거했다. 기존 학생 64명, 세션 187개, 응시 140개와 기존 저장 자산은 보존했다. 공개 목록은 49회·1,920문항이며, 나머지 11회·330문항은 준비 중이다.
