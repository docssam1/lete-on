# 이든 공통수학1 기본반 4회 — 로컬 배포 후보 준비

중2·중3 전 과정에서 대수 20문항·기하 10문항을 다루는 주관식 30문항·100분 모의고사다. 시험지 13쪽, 정답·해설 16쪽, 학습분석지 4쪽이다. 학생은 기존 보호 뷰어에서 페이지를 보고 O/X로 응답한다.

문항·정답·풀이·분류의 독립 검산과 도형·33쪽 PDF 검수가 완료됐다. 공개 브랜치에는 기존 보호 exam ID와 회차 메타데이터·과정 연결만 준비한다. 원고, 정답, 풀이, PDF, 이미지, 보호 페이지 경로, 학생 데이터와 보관 ZIP은 공개 저장소에 포함하지 않는다.
