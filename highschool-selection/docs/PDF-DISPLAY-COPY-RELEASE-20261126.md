# 모의고사 표시 문구 개정 — 2026-11-26

과정과 회차만 표시하도록 ‘지필드 자체제작’ 계열 표현을 정리했다. 화면의 이름·범위·기존 결과 제목 정리는 PR1525로 main에 반영했으며, 이번에는 보호뷰어가 실제 제공하는 페이지를 교체한다.

대상은 이든 중1 시작반 1·2·3·4·최종(마무리)과 공통수학1 기본반 3회다. 시험지·정답해설·학습분석지 18종 198쪽 중 197곳을 수정했다. 수정 영역 밖의 본문·수식·도형은 원본과 RGB 픽셀 차이가 없고, 두 독립 PDF 시각 검수의 수정 요청은 0건이다. 기존 원본과 내부 제작 이력은 보존한다. 공식 기출로 바꾸어 표시하지 않는다.

기존 Drive PDF 18개를 같은 파일 ID로 갱신하고 원격 전체 바이트·SHA256을 대조했다. 보호뷰어는 기존 비공개 저장소와 권한 검사를 유지하며, 새 경로 197개와 기존 표지 1개를 사용한다. 다른 14회차의 663쪽과 전체 48회차의 문항·판본·시험시간은 유지한다. 실제 운영 경로 861쪽은 원격 전체 바이트·SHA256을 확인했다.

서버는 기존 함수 세 개만 갱신했다. `highselect-exams`는 45, 페이지 제공 A/B는 125/22다. 다른 운영 함수 97개와 기존 중1 시작반 1회 제공 함수는 변경하지 않았다. 임시 업로드 경로는 닫았으며, 승인 없는 시험·다른 학생 결과·변조된 링크·공개 저장소 직접 접근 거부를 확인했다. 새 키·유료 모델 API·스키마 변경은 없다.

실제 사이트의 390×844 모바일 브라우저에서 198쪽의 확대·가로 이동·쪽 이동을 확인했다. 배포 전 저장한 여섯 회차의 O/X가 배포 뒤 복원됐고, 회차별로 다른 O/X를 저장한 뒤 새로고침·새 로그인에서도 같은 결과를 확인했다. 로컬 Apple Vision의 실제 머리글 이미지 198개에서도 해당 문구가 검출되지 않았다. 이는 디지털 브라우저 검수이며 실물 기기·인쇄 검증을 뜻하지 않는다.

추가 세로 이동 검수도 198쪽 모두 통과했다. 같은 탭을 다시 불러올 때 남아 있는 이전 이미지로 검사하지 않도록, 탭 요청·이미지 로딩 처리가 끝난 뒤 위치를 확인했다. 조기 검사의 실패 기록은 보존했으며 제품 UI 코드는 변경하지 않았다. 표지 중간 화면 12개도 독립 시각 검수를 통과했다.

테스트용 두 계정과 해당 세션·응시 기록은 회수했다. 회수 직전 정상 응답하던 미만료 페이지 링크와 이전 승인번호·세션이 모두 거부되는지 확인했다. 기존 학생 64개·세션 187개·응시 140개의 내용 지문은 작업 전과 동일하다. 초기 원본·완성본 보관 ZIP 521개 항목과 배포 검수 추가 ZIP 1,079개 항목은 기존 Drive 폴더에 보관하고, 원격 전체 바이트·ZIP CRC·모든 원본 항목의 SHA256을 확인했다. 인증 자료는 보관본에서 제외했다.

이번 변경은 새 모의고사 제작 수에 더하지 않는다. 공개 12과정 48회·1,890문항이며, 기존 60회 목표에서 남은 12회·360문항은 계속 제작한다. 다른 구판 PDF 전체의 문구 정리를 완료했다고 집계하지 않는다.
