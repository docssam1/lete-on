# 돌파 문제 자료 사용 순서

## 먼저 쓰는 자료

- 돌파 중2-2 과정 이름이 붙은 원본 시험지는 원본 자료로 보존하되, 현재 입반 범위에 맞는 문항만 사용한다.
- `2-1S 입반테스트 3` 원본 30문항은 문항별로 다시 읽었고, 현재 범위 안 28문항과 범위 밖 2문항을 분리했다.
- 돌파 공통수학1 입학 회차 30문항(원본 29문항·검산 완료 대체 1문항)
- 원본 문제 한 개를 문제 유형 한 개로 나눈다.
- 학년·학기, 단원, 무엇을 구하는 문제인지 함께 적는다.
- 원문 조건이 불완전해 교체한 문항은 원본으로 부르지 않고 `검산 완료 대체 문항`으로 표시한다.

## 추가 연습 문제

- 고쟁이와 다른 참고 문제는 돌파 원본 문제가 아니다.
- 참고 문제는 원본 유형과 풀이 방법이 같은지 확인한 뒤 추가 연습 문제로만 쓴다.
- 확인이 끝나기 전에는 돌파 문제 수에 넣지 않고 학생에게 보여 주지 않는다.

## 현재 상태

- 현재 돌파 문항 DB에는 원본 시험지 3회, 90문항이 있다. 이 가운데 원본 89문항과 검산 완료 대체 1문항이 분리되어 있다.
- 중2-2 입반 대비는 현재 범위 안 원본 후보 37문항 중 30문항을 실제 구성으로 골랐고, 7문항은 예비 문항으로 남겼다.
- 실제 구성 30문항은 정확한 범위의 `2-1S 입반테스트 3` 원본 28문항과, 다른 검수 완료 돌파 원본 2문항으로만 이루어진다.
- 범위 밖인 `2-1S 입반테스트 3` 1번(중3-1 제곱근과 실수), 5번(중2-1 일차함수)은 DB에는 보존하지만 현재 시험 구성에서는 제외한다.
- 답과 문제 내용은 공개 파일에 넣지 않는다.
- 유사문제는 아직 만들어졌다고 표시하지 않는다.
