# 돌파 문제 자료 사용 순서

## 먼저 쓰는 자료

- 돌파 중2-2 과정 이름이 붙은 원본 시험지는 문항 범위와 관계없이 전부 문항 DB에 보존한다.
- `2-2S 입반테스트 1(중1-1~중2-1 전체)` 원본 30문항은 일차함수까지 확인한 전 범위형이며 대표 시험의 첫 원본으로 사용한다.
- `2-1S 입반테스트 3` 원본 30문항은 중간 단원 종료형으로 따로 표시하고, 범위 안 보완 문항으로만 사용한다.
- 돌파 공통수학1 입학 회차 30문항(원본 29문항·검산 완료 대체 1문항)
- 원본 문제 한 개를 문제 유형 한 개로 나눈다.
- 학년·학기, 단원, 무엇을 구하는 문제인지 함께 적는다.
- 원문 조건이 불완전해 교체한 문항은 원본으로 부르지 않고 `검산 완료 대체 문항`으로 표시한다.

## 추가 연습 문제

- 고쟁이와 다른 참고 문제는 돌파 원본 문제가 아니다.
- 참고 문제는 원본 유형과 풀이 방법이 같은지 확인한 뒤 추가 연습 문제로만 쓴다.
- 확인이 끝나기 전에는 돌파 문제 수에 넣지 않고 학생에게 보여 주지 않는다.

## 현재 상태

- 현재 돌파 문항 DB에는 원본 시험지 4회, 120문항이 있다. 이 가운데 원본 119문항과 검산 완료 대체 1문항이 분리되어 있다.
- 중2-2 중간반 대표 범위는 중1-1부터 중2-1 일차함수까지다. 범위 안 원본 후보 72문항 중 전 범위형 원본 30문항을 실제 구성으로 우선 고정했고, 42문항은 예비 문항으로 남겼다.
- `2-2S 입반테스트 1`은 `full_range`, `2-1S 입반테스트 3`은 `mid_unit_cutoff`로 기록했다. 다른 혼합 원본은 `mixed_range`로 두고 문항별 범위를 확인한다.
- 원본 시험지 안의 범위 밖 문항도 DB에서는 삭제하지 않는다. 시험을 만들 때만 선택 범위에 따라 제외한다.
- 답과 문제 내용은 공개 파일에 넣지 않는다.
- 유사문제는 아직 만들어졌다고 표시하지 않는다.
