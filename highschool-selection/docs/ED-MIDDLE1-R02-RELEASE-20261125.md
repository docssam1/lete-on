# 이든 중1 시작반 자체 제작 대비 2회

대치 초등관 중1 시작반 대비에 2회를 추가한다. 초5·초6 전 과정의 주관식 30문항·100분이며 공통수학1 기본반 과정과 구분한다. 시험지 13쪽, 정답·해설 16쪽, 학습분석지 4쪽을 기존 보호 뷰어와 O/X 자기 확인에 연결한다.

## 내용과 보관

문항만 본 독립 풀이 30개와 정확한 판본별 정답 대조, 학생용 도형 11개 및 실제 PDF 33쪽의 검수를 마쳤다. PDF·원고·도형·검수 결과는 기존 Drive 폴더에 보관했고 전체 바이트와 SHA-256을 확인했다. 원본 은행의 잠금은 유지한다.

원고·문항·정답·풀이·페이지 이미지는 공개 Git에 넣지 않는다. 공개 코드에는 회차의 범위·시간·쪽 수와 과정 연결만 둔다. 기존 43회 공개·비공개 메타데이터와 인증·관리자·채점 코드는 보존한다.

## 연결 검증

독립 정적 검수에서 기존 43회와 신규 30개 분류, 33개 이미지의 유일한 페이지 경로·바이트 크기·SHA가 일치했다. 과정 연결·공식 규격·권한·비공개 저장소 회귀검사 37개가 통과했다. 추가 후 목록은 44회·1770문항이다.

운영 보호 서버에 새 회차를 추가하고 기존 663쪽과 새 33쪽, 총 696개 이미지의 원격 전체 바이트·SHA를 대조했다. 최종 reader에서 업로드 경로를 제거했고, 익명·미배정·서명 변조·만료·외부 Origin·Storage 직접 접근 차단을 확인했다.

배포 전 로컬 화면과 운영 API를 연결한 390px 모바일 검수에서 33쪽의 실제 이미지 로드와 쪽 이동, 확대 후 좌우 이동, O/X 30개의 임시 저장·서버 저장·새로고침 후 결과 재열기를 확인했다. 수치 답안 입력은 없다. 기존 시간 표기의 캐시 검사까지 포함한 관련 검사 41개가 통과했다. 전체 검사에는 기존 과정대장·홍보 문구 검사와 설치되지 않은 브라우저 테스트 의존성에 따른 실패가 별도로 있어 전체 통과로 표시하지 않는다.

메인 반영 뒤 운영 사이트의 과정 선택·회차 이동·같은 모바일 동선과 검수 계정 종료 결과는 비공개 배포 기록에 남긴다.

실물 출력과 실제 학생 풀이 시간은 미측정이다. 모든 학생의 100분 완주나 공식 시험과의 난도 등가는 주장하지 않는다.
