# 학원 → 과정 → 회차 선택 흐름 (2026-11-07)

학원을 눌러도 큰 소개 상자와 긴 과정 목록 아래에서 시험을 찾아야 했던 문제를 고쳤다. 학원 선택 직후 공개 과정 배너를 먼저 보여주고, 과정을 누르면 해당 과정의 회차 선택 화면으로 전환한다.

## 화면과 동선

- 기존 여섯 학원 색과 공식 로고를 유지한다. 공개 과정에는 학원색, 준비 중 과정에는 옅은 색과 상태 문구를 쓴다.
- 과정 배너에는 범위·문항 수·시간·공개 회차 수를 표시한다. 회차 선택 화면에서 배너 목록을 반복하지 않는다.
- 깊은생각 중1 시작반과 예비고1 입학 과정을 분리한다. 공개되지 않은 과정에 다른 과정 시험을 대신 연결하지 않는다.
- ‘학원 바꾸기’·‘과정 바꾸기’, 직접 링크, 브라우저 뒤로가기와 키보드 초점을 지원한다.
- 자체 탑재 Pretendard를 사용하고 글씨 굵기를 700 이하로 정리했다. 단순 책·기하 선 그림을 장식으로 사용하며 보조기술에서는 숨긴다.
- 회차 입장은 기존 보호 로그인으로 연결한다. 공개 18회·670문항, 시험 시간·범위, O/X 자가 확인, PDF·인증·DB는 바꾸지 않았다. 황소는 110분을 유지한다.

## 스킬 근거

[스킬 지도](https://github.com/docssam1/agent-skill-atlas)의 현재 index.html을 확인했다. 지도 등록과 실제 설치 상태는 구분했다. 실제 읽고 적용한 지침은 frontend-design, gfield-design-system, ui-ux-pro-max, ux-writing과 공용 협업 기준이다. web-ui-library-picks는 저장소 main의 현재 본문을 확인했다. 새로운 UI 라이브러리·폰트·유료 API를 추가하지 않았다.

## 검증

- 관련 Node 계약 검사 39개 통과: 과정별 공개 회차 연결, 18개 시험 누락·중복, 다른 레벨 혼입과 비공개 회차 차단, 공식 범위·정책·공개 데이터 보호.
- Playwright: 7개 공개 과정 × 4개 화면 폭(1440·768·390·320), 총 28개 동선 검사 통과. 키보드 이동, 초점, 뒤로가기, 직접 링크, 준비 중 상태, 공지 필터, 줄어든 동작, 가로 넘침, 폰트·로고 로드를 확인했다. 콘솔 오류 0.
- 돌파 공개 과정 배너는 390px 화면에서 위쪽 약253px부터 보이며, 선택 후 첫 회차는 약485px부터 보인다. 두 단계 모두 첫 화면에서 선택할 수 있다.
- 학원색 여섯 배경의 글씨 대비는 모두 4.5:1 이상이다(최저 5.05:1).
- 공개 배포는 stage-public-intro.cjs의 명시적 허용 목록만 사용한다. 문항 원문·정답·서버 파일을 추가하지 않는다.

화면 캡처·전체 실행 결과·검사 스크립트는 기존 Drive deliverables의 all-academies/ux-course-flow-20261107에 보관한다. 위 검증은 브라우저 동작 검증이며 실제 학생·학부모 대상 사용성 조사 결과를 뜻하지 않는다.
