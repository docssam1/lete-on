# 원수학 중2-1 기본반 입학 대비 최종(마무리)

공개ID는 `wm-middle21-basic-final`, 과정은 `WM:middle21-basic`이다. 기존1~4회 다음에 최종회를 연결해 총5회로 구성한다. 중2-2·중3-1 편입 및 공통수학1 기본반과 구분한다.

- 중1-1 대수25문항과 중1-2 기하25문항, 통계 제외.
- 대수70분·기하70분, 휴식20분 별도. 시험140분, 휴식 포함160분.
- 전부 주관식, A4 2단 명조·흑백 벡터도형29개. 시험지19쪽·정답해설20쪽·빈 학습분석지5쪽.
- 온라인은 숫자 답안 입력 없이 O/X 자기확인. 미확인은 오답과 구분하며 공식 합격·반배정을 자동 결정하지 않는다.

규격 근거는 [원수학 대치의 2026년10월 신입 안내](https://blog.naver.com/wonmath563/224393421982)다. 해당 모집 당시의 평가 규격이며 현재 모집·결원을 뜻하지 않는다.

## 검수와 보존

9개 출처군에서50문항을 구성하고 한 군 최대6문항을 확인했다. 필수 출처군 조건을 유지했다. 기존1~4회200문항과 의미·풀이구조를 대조해 근접중복6곳을 교체하거나 부분 제외했다.

문항만 본 독립 풀이와 답·풀이 대조, 최종 교정 확인을 거쳐50문항 PASS다. 도형29개와 실제 최종PDF44쪽을 검수했고, Apple Vision으로 시험지 본문번호1~50의 누락이 없음을 확인했다. 공식 답안 직접대조가 가능한 자료와 독립 풀이·교차검수에 의존한 자료는 비공개 보고서에서 구분했다. OCR 번호 점검을 수학 풀이 검수의 대체로 사용하지 않았다.

운영v24는 기존27개 시험·관리자 참고자료·인증 코드를 그대로 유지하고 새 회차만 추가했다. 배포 후 운영 소스4개를 다시 받아 후보 판본과 정확히 같은지 확인했다. 새44쪽의 보호 이미지 묶음5개는 별도 함수로 제공한다. 공개 Git에는 원문·정답·PDF·페이지 이미지·계정 인증 자료를 넣지 않는다. 원본DB5개·기존 잠금·구판은 보존했다.

과정 연결·규격·브라우저·O/X 관련 로컬 검사56개와 별도 정적 릴리스검수9건을 통과했다. 배포 전 실제 운영 API에서 보호 이미지44개 전체의 SHA 일치, 익명·미배정·서명변조·만료·허용되지 않은 Origin 거부를 확인했다. 390px에서 이전/다음·마지막 페이지·문서전환과 위치복원, O/X 임시표시·서버저장·새로고침·재입장을 확인했다. 공개 사이트 배포 후 같은 검수를 다시 수행하고 운영 영수증에 기록한다.

[완성본·검수·운영 증빙 보관 폴더](https://drive.google.com/drive/folders/1YMtKVF939UcJ_a8f8RO7KMeezVLbqcRQ). PDF3종과 공개 전 증빙ZIP5개는 원격 전체읽기·크기/SHA·CRC 및 내부803파일 검증을 마쳤다. 이후 배포 증빙은 같은 폴더에 추가한다. 검증된 미사용 자기 사본만 정리하며 실제 학생·인증·공유 작업본·다른 작업자는 보존한다.
