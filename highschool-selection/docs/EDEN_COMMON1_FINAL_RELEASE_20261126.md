# 이든 공통수학1 기본반 최종회 공개 — 2026-11-26

## 공개 상태

2026년 11월 26일 실제 사이트에 최종(마무리)회를 연결했다. 현재 공개 목록은 50회·1,950문항·1,880쪽이다. 기존 49회는 메타데이터와 순서를 유지했다.

최종회는 30문항·100분이며 시험지 12쪽, 정답해설 16쪽, 학습분석지 4쪽으로 제공한다. 응답 방식은 O/X 자기 확인이다. 과정 순서는 1·2·3·4·최종(마무리)이다.

## 화면과 저장 검수

실제 공개 사이트의 390×844 CSS 픽셀 브라우저 화면에서 시험지·정답해설·학습분석지 32쪽을 열고 페이지 이동, 200%·300% 확대와 가로 이동을 확인했다. 최초 응시 중 실제 제공된 32개 이미지 본문은 모두 검수된 바이트와 일치했다.

O/X 30개를 저장한 뒤 새로고침, 결과 재열기, 로그아웃과 새 로그인 후 결과 복원을 확인했다. 새 로그인 후 저장된 응답은 복원됐다. 전체 이미지 로드 확인은 새 로그인 직후 화면 캡처와 별도로 최초 응시 중에 수행했다.

이 검수는 실제 웹사이트의 모바일 크기 브라우저에서 수행했다. 물리 휴대전화와 인쇄물은 확인하지 않았다.

## 배포 기록

공개 변경은 PR #1532에서 병합했고 GitHub Pages 배포가 성공했다. 저장된 O/X와 페이지 접근 권한은 승인된 계정으로 확인했다. 원본 PDF와 정답 데이터를 공개 저장소에 포함하지 않았다.

전체 모의고사 확장 목표는 진행 중이며 이후 회차와 문항은 별도 검수 후 추가한다.
