# 이든 중1 시작반 4회 연결

이든 중1 시작 과정에서 1·2·3회 다음으로 4회를 선택할 수 있다. 초5·초6 전 과정, 주관식 30문항·100분이며 시험지 16쪽·정답해설 16쪽·학습분석지 4쪽을 기존 보호 뷰어로 제공한다. 학생은 O/X만 표시한다.

저장 결과를 새로고침한 뒤 로그아웃해도 보고 있던 회차가 입장 화면에 남는다. 로그인 화면 제목을 되돌리고, 로그아웃할 때 이전 결과와 시험 목록의 내용을 비운다. 서버 인증·승인·채점 규칙은 바꾸지 않는다.

검증:

- 기존 공개 45회 메타데이터와 보호 페이지 730개를 보존하고 새 36쪽을 추가했다. 보호 이미지 766개의 전체 바이트·SHA와 권한·서명 변조 거절을 확인했다.
- 새 회차 연결 및 보호 기능 관련 46개 검사 통과. 전체 일반 검사 800개 중 798개 통과, 기존 과정-문제은행 매핑 및 홍보 근거 문구 검사 2개 실패는 그대로다.
- 배포할 파일 구성으로 390×844 CSS 화면에서 36쪽 좌우 이동, 쪽 경계·확대·스크롤, O/X 30개 저장·새로고침·새 로그인 복원을 확인했다. 결과 화면 새로고침 후 로그아웃하는 회귀도 확인했다.
- 독립 코드 검수와 로그아웃 회귀 합성 검수를 마쳤다.

## 배포 후 확인

PR #1518은 `c0a6b69ee3d54706fd1255d203fae129b629e220`으로 메인에 병합됐다. [Pages 실행 45623935094](https://github.com/docssam1/lete-on/actions/runs/45623935094)의 첫 시도 성공과 실사이트 파일 26개의 전체 바이트 일치를 확인했다. 공개 목록은 46회·1,830문항이다.

실서비스에서도 390×844 CSS 화면으로 시험지 16쪽·정답해설 16쪽·분석지 4쪽을 열고 좌우 이동, 확대, 경계 이동, 문서별 위치 복원을 확인했다. O/X 30개를 저장한 뒤 결과 새로고침과 새 로그인에서 같은 상태가 서버로부터 복원됐다. 결과를 다시 열면 보호된 해설로 연결되고, 로그아웃 뒤에도 선택한 회차가 유지됐다.

이 작업의 검수용 학생 2명·세션 6개·응시 2개만 회수했다. 회수 전부터 있던 학생 64명·세션 184개·응시 140개의 행 지문은 동일하며, 회수한 승인번호·세션·만료 전 서명 링크는 모두 거절됐다. 실제 학생 응시 시간이나 실물 출력 검증을 뜻하지 않는다.

운영 근거는 비공개 Drive의 같은 파일 ID로 보관했다. 제작 대장과 인수인계 4개 문서를 원격 전체 바이트로 대조했고, 배포 검수 증분 ZIP 344항목의 전체 바이트·CRC·항목별 SHA256을 확인했다.

공개 저장소에는 회차 메타데이터와 뷰어 코드만 둔다. 원고·정답·페이지·임시 검수 인증 정보는 포함하지 않는다. 원본 문제은행은 보존한다.
