# 이든 중1 시작반 4회 연결

이든 중1 시작 과정에서 1·2·3회 다음으로 4회를 선택할 수 있다. 초5·초6 전 과정, 주관식 30문항·100분이며 시험지 16쪽·정답해설 16쪽·학습분석지 4쪽을 기존 보호 뷰어로 제공한다. 학생은 O/X만 표시한다.

저장 결과를 새로고침한 뒤 로그아웃해도 보고 있던 회차가 입장 화면에 남는다. 로그인 화면 제목을 되돌리고, 로그아웃할 때 이전 결과와 시험 목록의 내용을 비운다. 서버 인증·승인·채점 규칙은 바꾸지 않는다.

검증:

- 기존 공개 45회 메타데이터와 보호 페이지 730개를 보존하고 새 36쪽을 추가했다. 보호 이미지 766개의 전체 바이트·SHA와 권한·서명 변조 거절을 확인했다.
- 새 회차 연결 및 보호 기능 관련 46개 검사 통과. 전체 일반 검사 800개 중 798개 통과, 기존 과정-문제은행 매핑 및 홍보 근거 문구 검사 2개 실패는 그대로다.
- 배포할 파일 구성으로 390×844 CSS 화면에서 36쪽 좌우 이동, 쪽 경계·확대·스크롤, O/X 30개 저장·새로고침·새 로그인 복원을 확인했다. 결과 화면 새로고침 후 로그아웃하는 회귀도 확인했다.
- 독립 코드 검수와 로그아웃 회귀 합성 검수를 마쳤다. 실서비스 배포와 배포 후 검수 결과는 운영 인수인계에 별도로 남긴다.

공개 저장소에는 회차 메타데이터와 뷰어 코드만 둔다. 원고·정답·페이지·임시 검수 인증 정보는 포함하지 않는다. 원본 문제은행은 보존한다.
