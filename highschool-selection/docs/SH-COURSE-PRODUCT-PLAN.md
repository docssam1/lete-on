40문항·110분은 **우리 모의고사 설정**이다. 2주·4회·120분·최대 6명은 이번 설계에서 제안한 값이다. 다른 학원의 수업·시험에 공통 적용하지 않는다.

중등 진도가 크게 비어 있는 학생은 먼저 해당 단원의 개념 학습을 안내한다. 이 4회 과정에서 중등 전 범위를 새로 가르친다고 약속하지 않는다.

## 2. 학습 목표와 확인 방법

| 수업 후 할 수 있어야 할 일 | 수업 활동 | 교사가 남길 근거 |
| --- | --- | --- |
| 문제의 조건을 빠짐없이 풀이에 옮긴다 | 조건 표시, 식·그림으로 바꾸기, 누락된 조건 찾기 | 처음 풀이와 교정한 풀이의 조건 사용 비교 |
| 틀린 풀이의 원인을 설명하고 다시 푼다 | 개념·조건 해석·계산·풀이 선택·시간 부족 중 실제 원인 확인 | 학생의 원인 설명과 힌트 없이 다시 쓴 풀이 |
| 같은 유형의 새 문제에 풀이 방법을 적용한다 | 승인된 쌍둥이·유사문제 연습 | 새 문제의 정답과 핵심 풀이 근거 |
| 제한시간 안에서 풀 문제와 돌아올 문제를 고른다 | 첫 시험의 시간 기록, 짧은 재점검, 풀이 순서 복기 | 막힌 지점·건너뛴 시점·다시 시도한 순서 |

정답만 맞힌 경우와 풀이 근거까지 설명한 경우를 구분한다. 결과는 `혼자 해결 / 힌트 후 해결 / 추가 학습`으로 기록한다. 이는 수업 확인 기준이며 시스템의 숙달 판정이나 학원 합격 판정과 다르다.

## 3. 차시별 수업안

| 회차 | 120분 구성 | 학생 활동 | 남기는 자료 |
| --- | --- | --- | --- |
| 1회 — 모의고사 | 응시 안내 10분 + 모의고사 110분 | 시험을 풀고 답안과 풀이를 제출. 답을 바꾸거나 오래 멈춘 문항을 표시 | 답안, 풀이, 시험 중 시간 기록 |
| 2회 — 틀린 이유 확인 | 기억으로 다시 풀기 10분 + 공통 오류 설명 25분 + 교사와 풀이 교정 35분 + 휴식 5분 + 개별 재풀이·쌍둥이 연습 35분 + 정리 10분 | 개인별 우선 유형 2개를 정하고 첫 번째 유형의 풀이를 고침 | 첫 진단지, 우선 보완 유형, 교정한 풀이 |
| 3회 — 조건이 달라진 문제 | 지난 유형 회상 10분 + 두 번째 유형 설명 25분 + 단계별 연습 30분 + 휴식 5분 + 개별 유사문제 풀이 35분 + 풀이 설명 15분 | 같은 유형에서 조건·표현이 달라져도 풀 수 있는지 확인 | 승인된 연습지, 힌트 사용 기록, 설명 기록 |
| 4회 — 혼자 다시 풀기 | 회상 10분 + 새 문제 재점검 30분 + 휴식 5분 + 재점검 풀이 교정 30분 + 남은 약점 재구성 25분 + 다음 공부 정리 20분 | 두 우선 유형을 새 문제로 확인하고 남은 공부 순서를 정함 | 수업 전후 확인표, 다음 2주 학습 계획 |

1회 이후 교사는 다음 수업 전까지 채점과 풀이 검토를 마친다. 2회부터는 공통 설명 뒤 학생별 문제를 달리 배정한다. 4회 종료 자료는 학생별 검토를 마쳐 다음 날까지 보호자에게 전달하는 운영안이다. 이 준비·검토 시간은 수업 480분과 별도로 잡는다.

과제는 2·3회 사이에 각각 20~30분 분량을 제안한다. 승인된 자료에서 학생별로 고르며, 사용할 문제 수는 자료 확보 후 정한다. 4회 재점검은 30분짜리 부분 평가다. 두 번째 40문항 모의고사를 제공한다고 안내하지 않는다.

같은 문제를 기억해 맞힌 결과를 새 문제 해결로 세지 않는다. 시험과 부분 평가의 문항 수·난도가 다르므로 총점 상승률로 비교하지 않는다. 첫 시험에서 틀렸던 유형을 새 문제에서 어떻게 해결했는지 비교한다.

## 4. 학부모에게 전달할 결과

첫 진단지에는 문항별 결과와 단원·유형을 표시하고, 우선 보완 유형 2개를 풀이 근거와 함께 적는다. 시간 부족은 실제 기록이나 학생 확인이 있을 때만 원인으로 적는다.

마지막 확인표는 다음 형식으로 작성한다. 아래는 항목 설명이며 실제 학생 성과를 나타내지 않는다.

| 항목 | 기록할 내용 |
| --- | --- |
| 처음 막힌 지점 | 문항 번호·유형과 학생이 한 풀이 |
| 수업에서 고친 부분 | 빠뜨린 조건·잘못 세운 식·계산 또는 풀이 선택 |
| 새 문제 확인 | 독립 해결 여부, 설명 내용, 힌트 필요 여부 |
| 다음 공부 | 공부할 단원·할 일·다시 확인할 날짜 |

합격 가능성, 반 배정, 다른 학생 대비 등수는 제공 결과에 넣지 않는다. 지점·과정·회차와 승인된 기준이 일치하는 판정 정책이 별도로 갖춰진 경우에만 운영 기준에 따라 추가한다.

## 5. 소개 화면의 구성과 실제 문구 초안

작성 방향: 기존의 `모의고사 → 진단 → 보완` 구성을 구체적인 수업 활동으로 풀어 쓴다. 설명 대상은 수업 신청을 검토하는 보호자다.

### 첫 화면

현재의 검정 배경과 학원별 컬러·로고 카드를 유지한다. 카드에는 학원명과 과정 구분만 짧게 넣는다. 클릭하면 해당 학원 소개와 과정 목록이 열린다.

선택 경로는 `생각하는황소 → 고등과정 시작·선발 → 수업 구성`이다. 학원 소개와 지필드의 독립 대비 수업을 구분해 표시한다.

### 황소 과정 화면

**제목**

황소 고등 선발 대비

**첫 설명**

중등 전 범위를 배웠다면, 40문항 모의고사로 점검해 보세요. 틀린 문제의 풀이를 살펴보고, 같은 유형의 새 문제를 혼자 풀 수 있는지 확인합니다.

**수업 요약 — 구성 확정 후 사용**

2주 동안 4회 수업합니다. 한 번에 120분씩 진행하며, 첫 수업에는 110분 모의고사를 봅니다.

**대상 안내**

중등 전 범위를 한 차례 공부한 학생을 위한 수업입니다. 신청 전 지원 과정과 지금까지 공부한 범위를 함께 확인합니다.

**차시 제목**

1. 40문항 모의고사 풀기
2. 틀린 이유 찾고 풀이 고치기
3. 조건이 달라진 문제 풀기
4. 혼자 다시 풀고 다음 공부 정하기

**받는 자료**

모의고사 결과와 단원·유형별 진단, 수업에서 고친 풀이, 보완 연습지, 다음 2주 학습 계획을 드립니다.

**버튼과 상태**

- 준비 중: `수업 구성 보기`로 본문 이동. 신청 일정은 `신청 일정은 추후 안내합니다.`로 표시.
- 모집 확정 후: `일정과 수강료 보기`로 운영 정보 이동.
- 시험 공개·모집·신청 경로가 모두 준비된 후: `이 수업 신청하기`.

**하단 안내**

지필드가 운영하는 독립 대비 수업입니다. 실제 학원의 시험 범위와 시간은 지원할 지점의 해당 회차 공지를 확인해 주세요.

### 화면 배치

과정 선택 아래에 `대상과 범위 → 모의고사 문항·시간 → 4회 수업 순서 → 받는 자료 → 일정·수강료·신청` 순서로 배치한다. 기존 우측의 작은 수업 구성 박스는 본문 폭을 쓰는 차시 안내로 바꾸는 안이다. PC는 4개 차시를 가로로, 모바일은 세로 순서로 읽게 한다. 전체를 동일한 작은 상자로 나누지 않는다.

학원별 색을 제목·회차 번호·선택 표시로 이어 쓴다. 긴 본문은 대비가 충분한 단색 면에 둔다. 수업료와 일정이 비어 있을 때 임의 가격이나 결제 버튼을 넣지 않는다.

## 6. 제작과 모집을 열기 위한 남은 일

| 순서 | 작업 | 완료 기준 |
| --- | --- | --- |
| 1 | 수업 구성 검토 | 2주·4회·120분, 최대 6명, 과제·결과 전달 방식 확정 |
| 2 | 보완 자료 확보 | 사용할 유형별 쌍둥이·유사문제, 난도 후보, 풀이·그림 검수와 필요한 승인 완료. 부족한 유형 명시 |
| 3 | 교사용 운영 자료 작성 | 시간표, 풀이 원인 기록지, 개인별 문제 배정표, 첫·마지막 진단 양식 준비 |
| 4 | 일정·수강료 확정 | 강사·교실·정원·개강일·수강료·신청 경로 확정 |
| 5 | 소개 화면 반영 | 대상·시간·차시·제공 자료를 초안 표시와 함께 확인하고, 모바일 선택 동선 검수 |
| 6 | 모집 준비 점검 | 표준 시험지 공개 조건과 보완 세트 승인, 신청 연결이 모두 확인된 뒤 모집 가능 상태로 전환 |

보완 자료는 `PRACTICE-BANK-REPETITION.md`의 원문·쌍둥이·유사문제 계열, 난도 후보, 문항·세트 승인 조건을 따른다. 준비된 계열이 부족하면 미검증 문제를 수업에 넣지 않고 해당 수업안의 준비 상태를 다시 표시한다.

가격 산정은 `(강사 수업·준비·검토 비용 + 교실·자료·운영 비용) ÷ 실제 모집 기준 인원`을 바탕으로 한다. 최대 정원 충원을 가정한 원가만으로 가격을 정하지 않는다. 이 문서에는 가격·할인·합격 보장·마감일을 임의로 만들지 않았다.

## 7. 다른 학원으로 확장할 때

같은 항목 구조를 사용하되 학원마다 지원 과정, 시험 범위, 시험 길이, 보완 수업량을 따로 설계한다. 황소의 40문항·110분 또는 이번 4회 구성을 돌파·원수학·이든·깊은생각·생각하는수학에 복사하지 않는다. 시험 시간이 다른 과정은 첫 수업 길이부터 다시 잡는다.
