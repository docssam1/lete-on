# hsmiddle 40문항 구조 재사용표

확인일: 2026-08-21
대상: 기존 `repo/hsmiddle` 읽기 전용 조사
새 적용 대상: `repo/highschool-selection`

| 항목 | hsmiddle 확인 내용 | SH 적용 |
|---|---|---|
| 시험 문항 수 | 모의 1·2·3회와 파이널 모두 40문항 | SH 1회 40문항 고정 |
| 답안 배치 | 데스크톱 4열 답안표 | 4열 유지, 모바일 3열 |
| 기본 입력 | 문항별 텍스트 입력 | 서버 입력 스키마의 `input` |
| 복수 답안 | 파이널 26번처럼 칸 분리 | `multi_input`과 `fields[]` |
| 그림·작도 | 정답 그림을 보여 주고 O/X | `self_check`, `singleAnswerVerified=true`, 학생별 서명 정답 이미지 (`ox`는 수신 호환 별칭만 허용) |
| 정규화 | 전각/반각, 공백, 단위, 쉼표, 수치·분수·집합형 처리 | 공통 채점기 정책으로 이전하고 문항별 모드화 |
| 분석 축 | 학기·영역·난이도·단원·유형 | 학년·학기·대단원·소단원·세부유형·난이도로 확장 |
| 점수 | 진단 화면은 40×2.5점 | SH 배점은 사용자 확정 전 미설정 |
| 워터마크 | 페이지마다 학생명 3회 대각 배치 | 같은 3중 대각 배치 유지 |
| 인쇄 | 시험지와 분석지 인쇄 CSS | 유지, 학생 이름 워터마크 포함 |
| 승인 | 시험별 접근 목록 | 서버의 학생×시험 승인 행으로 이전 |
| 유사문제 | 문항별 이미지 세트 및 오답 유형 묶기 | 문항 원문·학생·답 데이터는 가져오지 않고, 검수된 유형 계보만 원본→쌍둥이→유사 반복연습 ID로 연결 |
| 영상 | 문항별·전체 풀이 영상 | 현재 강의가 없으므로 전부 제외 |

## 그대로 복사하지 않는 부분

- 학생·승인번호·정답을 정적 JavaScript에 저장하는 방식
- `assets/print/...`처럼 영구 이미지 주소가 노출되는 방식
- 브라우저의 접근 목록만 신뢰하는 방식
- 학생이 답안 보기 버튼으로 원답을 바로 열 수 있는 방식
- 강의가 없는 시험에 영상 버튼을 표시하는 방식
- `hsmiddle/data.js`와 `exam-data.js`를 새 프로그램에서 직접 불러오는 방식

## 반복연습 재사용 원칙

- 초등 누적 범위가 필요한 트랙은 hsmiddle에서 승인된 유형 메타데이터만 별도 중립 ID로 옮길 수 있습니다.
- 학생 이름·승인번호·응시 이력·정답 배열·영구 이미지 주소는 옮기지 않습니다.
- 같은 유형이라도 원본, 쌍둥이, 유사 문항은 각각 출처 계보와 사용자 승인을 가져야 합니다.
- 오답 뒤에는 낮춤→기준→올림 중 필요한 단계만 배정하며, 최근에 푼 같은 문항군은 연속 배정하지 않습니다.
- 재응시에서는 단순 점수 상승뿐 아니라 `미해결·해결·유지·재발` 상태를 기록합니다.

## SH 1회 공개 조건

40문항 답안표라는 형식은 확정하지만, 문항별 정답·배점·입력 방식은 아직 확정하지 않습니다. 원답 대조와 사용자 검수가 끝난 뒤 서버의 `response-schema`와 비공개 채점 데이터에만 반영합니다.
