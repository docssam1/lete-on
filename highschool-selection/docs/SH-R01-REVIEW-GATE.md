3. 독립 검산 가능한 문항의 별도 검산
4. 입력형·복수입력형·그림 확인형 확정
5. 2022 개정 중학교 학년·학기·대단원·소단원·세부유형 확정

7. 사용자 문항별 승인을 폐지하고 검수자가 40문항을 해소
8. 원본→쌍둥이→유사 세트는 별도 문제은행 승인 경계로 유지

## 현재 화면 동작

- 서재에는 `SH 고등 선발 대비 1회`, 40문항, 검수 상태가 표시됩니다.
- 학생 승인이 있어도 `releaseStatus=released` 전에는 열리지 않습니다.
- 운영 서버와 학생별 단기 서명 이미지 URL이 없으면 열리지 않습니다.
- 학생용 페이지 응답은 정확히 8장만 허용합니다.
- 9–11쪽 답·풀이 페이지, PDF URL, 비공개 저장경로는 브라우저로 전달하지 않습니다.
- 답안 입력 구성에 정답·풀이 키가 포함되면 뷰어가 응답을 거부합니다.
- 기존 hsmiddle의 40문항 4열 답안표, 복수 답안 칸, 그림 정답 O/X, 3중 대각 워터마크, 인쇄 분석지 구조를 계승합니다.
- hsmiddle의 정적 답안 배열·정적 시험 이미지·영상 버튼은 재사용하지 않습니다.
- 답안 임시 저장 키에는 학생 ID와 시험 ID를 모두 넣어 같은 브라우저를 쓰는 학생끼리 답안이 섞이지 않게 합니다.
