# SH 고등 선발 대비 1회 검수 게이트

작성자: T
상태: `review_pending`
공개 여부: 잠금

## 확인 완료

- 원본 PDF 11쪽
- 학생용 문제 구간 1–8쪽
- 비공개 문항별 답·풀이 구간 9–11쪽
- 문제 번호 1–40 연속
- 중등 누적 대표 영역 초안 합계 40문항
- PDF와 HWP가 같은 원고 계열이라는 표본 대조
- 전 11쪽 2배율 시각 감사에서 페이지 누락·본문 겹침·경계 잘림 없음

## 전 페이지 시각 감사 차단 항목

- 10쪽 Q34 풀이의 의심 글리프를 HWP 또는 독립 정답 자료와 대조
- 11쪽 Q39 풀이 표의 잘린 행 이름을 원자료와 대조하고 표 폭 보정
- Q30~Q35·Q39~Q40 번호 색·굵기·들여쓰기의 의도 여부 확정
- 상단 가장자리 선을 원본 충실형과 프린터 안전형으로 각각 시험 출력

## 공개 전 필수 검수

1. 1–40번 PDF/HWP 수식·그림·조건 대조
2. 9–11쪽 문항별 답·풀이의 답과 전개를 PDF/HWP 및 독립 검산으로 대조
3. 독립 검산 가능한 문항의 별도 검산
4. 입력형·복수입력형·그림 확인형 확정
5. 2022 개정 중학교 학년·학기·대단원·소단원·세부유형 확정
6. 배점·시험시간·난이도·커트라인은 근거 자료가 있을 때만 입력
7. 사용자 문항별 승인
8. 원본→쌍둥이→유사 세트의 단계별 승인과 반복 배정 규칙 확인

## 현재 화면 동작

- 서재에는 `SH 고등 선발 대비 1회`, 40문항, 검수 상태가 표시됩니다.
- 학생 승인이 있어도 `releaseStatus=released` 전에는 열리지 않습니다.
- 운영 서버와 학생별 단기 서명 이미지 URL이 없으면 열리지 않습니다.
- 학생용 페이지 응답은 정확히 8장만 허용합니다.
- 9–11쪽 답·풀이 페이지, PDF URL, 비공개 저장경로는 브라우저로 전달하지 않습니다.
- 답안 입력 구성에 정답·풀이 키가 포함되면 뷰어가 응답을 거부합니다.
- 기존 hsmiddle의 40문항 4열 답안표, 복수 답안 칸, 그림 정답 O/X, 3중 대각 워터마크, 인쇄 분석지 구조를 계승합니다.
- hsmiddle의 정적 답안 배열·정적 시험 이미지·영상 버튼은 재사용하지 않습니다.
- 답안 임시 저장 키에는 학생 ID와 시험 ID를 모두 넣어 같은 브라우저를 쓰는 학생끼리 답안이 섞이지 않게 합니다.

## 사용자 확정이 필요한 값

- 시험 공개 제목 최종안
- 시험시간
- 문항별 배점 또는 균등배점 여부
- 문항별 입력 방식
- 문항별 정답
- 문항별 현행 교육과정 분류
- 난이도와 선발 커트라인

위 항목이 확정되기 전에는 채점·진단·유사문제 연결을 활성화하지 않습니다.
