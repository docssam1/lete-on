# 원수학 중2-2 기본반 편입 대비 2회

원수학 중2-2 기본반 편입 대비 과정에 주관식 50문항의 2회를 추가한다. 중2-1 대수 기본형 25문항과 중1-2 기하 심화형 25문항으로 구성하며 통계는 제외한다. 시험지 23쪽, 정답·풀이 22쪽, 학습분석지 5쪽을 기존 보호 뷰어와 O/X 자기 확인에 연결한다.

## 시험 시간

2026년 12월 [공식 편입 공지](https://blog.naver.com/wonmath563/224470731361)의 대수 16:00–17:10, 기하 17:30–18:40을 적용한다. 영역별 70분, 풀이 시간 합계 140분, 전체 진행 160분이다. 교시 사이 간격 20분을 공식 공지의 휴식 행 10분과 구분하여 `교시 사이 20분`으로 표시한다. 남은 10분의 용도는 확인하지 못했으므로 휴식으로 단정하지 않는다.

과거 9월 공지를 적용한 1회는 각 70분과 휴식 10분을 유지한다. 과정 공통 시간은 `회차별로 다름`으로 안내하고 회차마다 해당 시간을 표시한다. 새 시험 화면 코드의 캐시 버전도 갱신한다.

## 검수와 보존

- 50문항 독립 풀이·풀이 대조, 교과 범위, 선택 도형과 PDF 50쪽 검수를 완료했다.
- 기존 공개 35회의 메타데이터와 인증·채점 코드를 보존한다. 새 회차를 포함한 목록은 36회·1,390문항이다.
- 원본 PDF·문항·정답·페이지 이미지·승인번호는 공개 Git에 넣지 않는다. 기존 비공개 저장소의 212쪽에 새 50쪽을 추가하며 임시 업로드 경로는 제거한다.
- 390px 모바일에서 전 페이지, 문서 전환·페이지 위치 복원, O/X 50개 초안·서버 저장·복원과 접근 권한을 확인한다. 테스트 계정만 사용한다.
- 실물 출력 및 실제 학생의 풀이 시간·난도 실측은 후속 점검 사항이다. 학원의 실제 시험이나 합격 가능성과 동일하다고 표시하지 않는다.

완성 PDF와 비공개 검수 증빙은 기존 Drive 프로젝트 폴더에 보관한다. 운영 배포·실제 모바일 검수·보관 검증 결과는 해당 폴더의 현재 인수인계에 기록한다.
