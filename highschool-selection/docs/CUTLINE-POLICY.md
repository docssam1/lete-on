# 커트라인 적용 정책

커트라인은 학원 단위의 고정 숫자가 아니다. `programId + branchId + courseId + roundId + curriculumVersion`이 모두 맞는 근거 레코드로 저장한다.

- 공개 검색에서 확인한 숫자는 기본적으로 `reference-only`이다.
- 학생 점수에 합격·불합격을 표시하려면 해당 모의고사의 `examId`에 사용자가 승인한 정책을 별도로 연결해야 한다.
- 익명 결과 문자에 나온 불합격 점수는 관찰값이지 커트라인이 아니다.
- 지점, 과정, 회차 중 하나라도 다르면 기존 숫자를 재사용하지 않는다.
- `확인 필요` 상태에서는 합격·불합격 대신 점수·정답률·영역별 진단만 제공한다.
- 원수학처럼 전체 컷과 영역 과락이 함께 있는 경우 단일 총점 규칙으로 축약하지 않는다.

현재 공개 참고 레코드:

- SH: 위례점 2026년 6월 고등과정 시작반의 레벨별 공개 결과
- DP: 대치 2026년 공통수학2 기본반 입학 공지
- WM: 대치 2025년 9월 공통수학1 기본반 공지

ED, DG, SM은 회차가 일치하는 공식 판정 근거가 없어 커트라인을 저장하지 않는다.
