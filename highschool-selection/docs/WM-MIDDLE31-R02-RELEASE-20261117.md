# 원수학 중3-1 기본반 편입 대비 2회

중2-1 대수 심화형 25문항과 중2-2 기하 심화형 25문항(경우의 수·확률 포함)을 추가한다. 모두 주관식이며 종이에 풀고 기존 보호 뷰어에서 O/X로 확인한다. 중3-1은 입반할 과정 이름으로, 시험 범위와 구분한다.

## 과정·시간

- 원수학 대치 공식 블로그의 2026년 10월 과정 공지와 수정 범위(9월 3일), 포스터를 11월 17일 재확인했다: https://blog.naver.com/wonmath563/224397883830
- 각 70분, 휴식 20분, 전체 160분. WM22의 다른 시각표와 미설명 구간을 가져오지 않았다.
- 다음 모집 날짜는 미확정이다. 과거 모집일을 미래 일정으로 게시하지 않는다.

## 산출물·내용 검수

시험지 22쪽, 정답해설 28쪽, 분석지 5쪽이다. 수학·키 대조 50문항, 학생 SVG 23개, 해설 전용 SVG 2개와 PDF 전쪽을 검수했다. 최종 표지 한 쪽을 별도 확인하고 나머지 54쪽의 이미지가 이전 검수본과 동일한지 체크섬으로 검증했다. A4·전체 글꼴 임베딩·문항 및 O/X 번호·수식·표·도형의 배치를 검사했다. Apple Vision은 판독을 보조하며 실제 그림 열람을 대체하지 않는다.

이전 미공개 원고의 기존 독립검수와 답 노출 후 재계산을 연결한 한 문항이 포함되어, 새 블라인드 검수 50개라고 주장하지 않는다. 공개 학생 조건과 비교했지만 과거 OCR·미확보 그림에 한계가 있다. 실제 학생의 응시 시간과 실물 출력은 미측정이며 공식 난도·출제 비율과 같다고 주장하지 않는다. 선정 제외 옛 후보 5판본과 원본 4은행·잠금을 유지한다.

## 반영 범위

공개 목록은 39회 1,540문항에서 40회 1,590문항으로 늘어난다. 기존 39회 메타데이터는 보존하고 새 회차만 WM 중3-1 과정에 연결한다. 문제·답·해설·원본 SVG/PDF는 공개 Git에 넣지 않는다. 신규 서버 문항 DTO에는 번호·분류·자가채점 방식만 포함한다. 기초 완충 문항 9개의 진단 난도는 `standard`로 매핑했다.

기존 보호 이미지 430장과 신규 55장, 총 485장의 응답 바이트·체크섬을 검증했다. 직접 스토리지 접근 66건의 차단과 임시 업로드 경로 제거를 확인했다. 기존 서버 인증·관리자·채점 코드를 유지하고 보호 리더 두 개와 시험 메타데이터만 확장한다. API v36, 리더 a64/b13이다.

## 실행 검증

과정·회차·공식 범위 관련 테스트 21개와 채점·권한·보호 저장소 관련 55개를 통과했다. 넓은 검사에서 드러난 기능 기대값 5건은 변경 전 HEAD의 최소 소스로 같은 실패를 재현했다. 기존 WM22 시간 문구, 돌파 회차 수, 문제은행 과정 연결, 옛 홍보 문구와 캐시 기대값이며 별도 후속 항목으로 보존한다. Playwright 모듈 경로 문제는 번들 경로를 지정해 구분했다.

390px 모바일 사전 검수에서 실제 55쪽 이동·확대·문서 위치 복원·O/X 50문항 초안과 서버 저장·재입장을 통과했다. 저장한 50개 응답과 결과 상태가 DB에도 일치했다. 배포 후 재검증과 자체 QA 계정 종료는 공개 절차에서 별도로 확인한다. 최종 증빙은 비공개 제작 폴더의 공개 영수증과 검수 보고서를 기준으로 한다.
