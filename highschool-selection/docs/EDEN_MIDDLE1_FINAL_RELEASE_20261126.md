# 이든 중1 시작반 최종(마무리) 공개 준비

초5·초6 전 과정의 주관식 30문항, 100분 모의고사를 기존 1~4회 뒤에 연결한다. 학생은 시험지·정답풀이·학습분석지를 보고 O/X로 자가채점한다. 숫자 답 입력은 없다. 시험지 16쪽, 정답풀이 17쪽, 학습분석지 4쪽이다.

원고 30문항, 도형 18개, 실제 PDF 37쪽의 독립 검수를 완료했다. PDF 3종과 원고·검수 기록의 변경분 372항목은 기존 지필드메모리 Drive 폴더에 보관하고 전체 원격 바이트·SHA-256, ZIP CRC와 모든 항목의 SHA-256을 확인했다. 유료 모델 API를 추가로 사용하지 않았다. 원본 문제은행의 잠금은 유지한다.

보호 저장소는 기존 766쪽을 보존하고 신규 37쪽만 추가했다. 전체 803쪽의 원격 바이트와 SHA-256을 확인했다. 연결 함수의 현재 버전은 main 43, reader A 100, reader B 20이며, 관련 없는 97개 함수와 로그인·권한·채점 코드는 보존했다. 임시 업로드 처리는 닫혔다.

공개 전 Chromium 모바일 에뮬레이션(390×844 CSS px)에서 37쪽의 좌우 확대, 이전·다음·직접 이동과 문서 간 위치 복원을 확인했다. O/X 30문항(10 O·20 X)의 임시 저장, 서버 저장, 결과 재진입, 새로고침, 로그아웃 후 새 로그인 복원을 확인했다. 물리 휴대폰·실물 인쇄·학생의 100분 완주 실측을 뜻하지 않는다. 메인 병합 뒤 실사이트에서 같은 검사를 다시 진행한다.

변경 관련 검사 34개 통과. 비브라우저 전체 검사 804개 중 802개 통과, 기존 실패 2개는 그대로다: `WM.middle22-basic` 문제은행 연결 대상 누락, 이전 홍보 문구를 기대하는 테스트. 전체 검사 통과로 표시하지 않는다.

반영 후 공개 목록은 47회·1,860문항이다. 현재 12과정의 5회 구성 목표(60회·2,250문항)에서 남은 13회·390문항, 진단 인쇄·재시험·과정 안내·신규 과정 조사·이전 도형 교정은 계속 진행한다. 비공개 원고·정답·보호 페이지·임시 계정·세션은 공개 Git에 포함하지 않는다.
