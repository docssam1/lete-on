# 이든 중1 시작반 최종(마무리) 공개·모바일 검수 완료

초5·초6 전 과정의 주관식 30문항, 100분 모의고사를 기존 1~4회 뒤에 연결한다. 학생은 시험지·정답풀이·학습분석지를 보고 O/X로 자가채점한다. 숫자 답 입력은 없다. 시험지 16쪽, 정답풀이 17쪽, 학습분석지 4쪽이다.

원고 30문항, 도형 18개, 실제 PDF 37쪽의 독립 검수를 완료했다. PDF 3종과 원고·검수 기록의 변경분 372항목은 기존 지필드메모리 Drive 폴더에 보관하고 전체 원격 바이트·SHA-256, ZIP CRC와 모든 항목의 SHA-256을 확인했다. 유료 모델 API를 추가로 사용하지 않았다. 원본 문제은행의 잠금은 유지한다.

보호 저장소는 기존 766쪽을 보존하고 신규 37쪽만 추가했다. 전체 803쪽의 원격 바이트와 SHA-256을 확인했다. 연결 함수의 현재 버전은 main 43, reader A 100, reader B 20이며, 관련 없는 97개 함수와 로그인·권한·채점 코드는 보존했다. 임시 업로드 처리는 닫혔다.

공개 전과 배포 후 실사이트의 Chromium 모바일 에뮬레이션(390×844 CSS px)에서 37쪽의 좌우 확대, 이전·다음·직접 이동과 문서 간 위치 복원을 확인했다. O/X 30문항(10 O·20 X)의 임시 저장, 서버 저장, 결과 재진입, 새로고침, 로그아웃 후 새 로그인 복원도 통과했다. 실사이트의 페이지 37쪽 검수 후 O/X 단계는 복원된 표시를 UI에서 지우고 다시 검사했다. 기능 및 보호 파일에 변경이 없어 앞서 확인한 페이지 검수를 승계했고 그 범위와 근거를 기록했다. 물리 휴대폰·실물 인쇄·학생의 100분 완주 실측을 뜻하지 않는다.

콘텐츠 PR #1520의 병합은 `f1b3620a2b00c9c5ed57a14b84f4c211f4ac0956`이다. 전체 사이트 배포에서 수의 마법 안내의 이전 레벨 수(1,327)가 실제 데이터(1,348)와 달라 실패했고, 안내 한 곳만 PR #1521로 바로잡았다. 검사 조건은 유지했다. 교정 병합 `8b2df70a63cd9fffa89502c8277ae7f2162c14c6`의 Pages 실행 `45644811615`가 성공했으며 실사이트 26파일의 전체 바이트가 배포 준비본과 일치한다.

자체 검수용 학생 2명과 그 세션·응시만 회수했다. 기존 학생 64명·세션 187개·응시 140개의 지문은 전후 일치한다. 회수한 승인번호·세션과 만료 전 서명 링크는 모두 401로 차단됨을 확인했다.

변경 관련 검사 34개 통과. 비브라우저 전체 검사 804개 중 802개 통과, 기존 실패 2개는 그대로다: `WM.middle22-basic` 문제은행 연결 대상 누락, 이전 홍보 문구를 기대하는 테스트. 전체 검사 통과로 표시하지 않는다.

공개 목록은 47회·1,860문항이며 이든 중1 시작반의 1·2·3·4·최종(마무리) 5회 구성이 완성됐다. 현재 12과정의 5회 구성 목표(60회·2,250문항)에서 남은 13회·390문항, 진단 인쇄·재시험·과정 안내·신규 과정 조사·이전 도형 교정은 계속 진행한다. 다음 제작은 이든 공통수학1 기본반 입반 대비 3회다. 비공개 원고·정답·보호 페이지·임시 계정·세션은 공개 Git에 포함하지 않는다.
