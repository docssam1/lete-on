# 돌파 공통수학1 기본반 입학 대비 3회

돌파 공통수학1 기본반 과정에서 1·2·3회를 선택할 수 있도록 `dp-common1-r03`를 추가한다. 중2-1~중3-2 누적 주관식30문항·150분 연습판이다. 중2-2 편입 대비5회와 별도 과정이다. 학원 공식 시험과 동일하거나 합격을 예측하는 판본으로 표시하지 않는다.

시험지16쪽·정답해설15쪽·학습분석지4쪽을 기존 보호뷰어와 O/X 자기 확인에 연결한다. 수치 답안 입력은 없다. 기존1·2회 실제60문항을 대조하고, 새30문항의 중등 풀이와 답의 유일성, 학생도형14개·해설도형1개, 최종35쪽을 독립 검수했다. 근접한 구조의 문항을 교체했고 근호 표시 간섭과 도형 라벨을 수정했다. 학생용에는 풀이 전개도를 싣지 않는다.

기존32회·1,250문항의 메타데이터와 원본 DB·잠금, 학생 계정·권한·기록을 보존한다. 기존 비공개 Storage와 두 페이지 제공 함수를 확장하며 새 함수나 공개 읽기 정책을 만들지 않는다. 문제·정답·해설·페이지 이미지는 공개 Git에 추가하지 않는다. 이번 회차를 포함하면 공개 목록은33회·1,280문항이다.

원고·출력·검수 근거는 기존 Drive 프로젝트 보관 위치에 저장했다. 실제 인쇄·학생 풀이시간·회차 간 난도 동등성은 미실측이다. 운영 검수 결과는 실제 배포·모바일 확인 후 추가 기록한다.
