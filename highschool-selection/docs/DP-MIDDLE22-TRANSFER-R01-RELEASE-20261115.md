- 원본 대표 30개 계보를 유지하면서 객관식 발문을 직접 답하는 형식으로 바꾸었다. 조건 명확화와 출처·분류 변경은 비공개 원고에 기록했다. 원본 DB의 기존 잠금과 과거 판본은 변경하지 않았다.

## 검수 및 운영

문항만 전달한 독립 풀이를 1~15번과 16~30번으로 나누어 검수했다. 모두 답이 일치했다. 후속 해설·교육과정 용어·그림·출력 검수에서 발견한 표현과 쓰기선 문제를 교정하고 재확인했다. 현재 필수 수정 및 미확정 항목은 0개다. 실물 출력과 실제 학생 풀이 시간 검증은 별도로 남는다.

과정 연결·시간·문항 수 검사 12개와 학생 화면 회귀 검사 20개가 통과했다. 실제 운영 API에서 보호 이미지 22개의 전체 바이트/SHA-256 일치, 익명 401, 미배정 403, 서명 종류·만료·Origin 변조 차단을 확인했다. 모바일 390px에서 앞뒤·쪽 선택, 시험지/해설/분석지 전환, O/X 임시 보존, 서버 저장과 재열기·새로고침 복원을 확인했다. O/X 시험 계정만 사용했다.

기존 운영 24개 판본의 메타데이터·문항 분류는 보존하고 새 판본 하나만 추가했다. 메인 함수는 v20이며, 페이지 묶음은 플랫폼 배포 크기 제한에 맞추어 두 보호 함수로 분리했다. 인증·세션·시험별 배정·단기 서명 계약은 기존 구현을 재사용한다. 답안 입력·자동 합격 판정은 추가하지 않았다.

공개 목록은 총 9과정·24회·950문항이다. 별도 이든 중1 자체 제작 1회·30문항은 계속 공개 목록 미연결 상태이며 이번 공개 수에 포함하지 않는다.
