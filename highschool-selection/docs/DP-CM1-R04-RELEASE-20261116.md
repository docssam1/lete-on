# 돌파 공통수학1 기본반 입학 대비 4회

돌파 공통수학1 기본반 과정에 `dp-common1-r04`를 추가해 1·2·3·4회를 선택할 수 있게 한다. 중2-1~중3-2 누적 주관식30문항·150분 연습판이다. 중2-2 편입 대비5회와 별도 과정이며 학원 공식 시험이나 합격 예측으로 표시하지 않는다.

대상은 대치 중등관의 현 초6 공통수학1 기본 입반이다. [중등관 12월 공식 안내](https://blog.naver.com/dpmath/224407474293)의 테스트 범위표에서 중등2·3 전 과정, 30문제·2시간30분을 확인했다. 과정 이름과 근거에 중등관을 명시하고, 기본과정120분을 안내하는 제로관 모집은 별도로 표시한다. 기존 시험 내용과 시간을 일률 변경하지 않는다.

시험지16쪽·정답해설15쪽·분석지4쪽을 기존 보호뷰어와 O/X 자기 확인에 연결한다. 수치 답안 입력은 없다. 기존 공개90문항의 실제 본문과 대조하고, 새30문항의 중등 풀이·유일해·학생도형17개·최종35쪽을 독립 검수했다. 자연수 지수의 풀이 범위, 최단거리 전개의 근거, 수식 줄바꿈과 도형 라벨을 교정했다. 최종 PDF3종과 전체 검수 증빙은 기존 Drive 프로젝트 위치에 보관하고 원격 전체 읽기·크기·체크섬을 확인했다.

기존33회·1,280문항, 학생 계정·권한·기록, 원본 DB·보류 잠금을 보존한다. 기존 두 페이지 함수와 비공개 저장소를 확장하며 새 함수나 공개 읽기 정책을 만들지 않는다. 문항 원문·정답·풀이·페이지 이미지는 공개 Git에 넣지 않는다. 이번 회차를 포함하면 공개 목록은34회·1,310문항이다.

실제 인쇄·학생 풀이시간·회차 간 난도 동등성은 미실측이다. 운영 결과는 실제 배포·모바일 확인 후 기록한다.
