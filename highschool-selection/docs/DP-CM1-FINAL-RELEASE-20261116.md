# 돌파 공통수학1 기본반 입학 대비 최종(마무리)

`dp-common1-final`을 대치 중등관 공통수학1 기본반 과정에 연결해 1·2·3·4회와 최종(마무리), 총5회를 선택할 수 있게 한다. 중2-1~중3-2 누적 주관식30문항·150분이며, 중2-2 편입5회와 별도 과정이다.

대상과 시간은 [대치 중등관 현 초6·12월 개강 공식 안내](https://blog.naver.com/dpmath/224407474293)의 중등2·3 전 과정/30문제·2시간30분 기준을 따른다. 제로관 기본120분 모집은 별도다. 공식 실제 시험문제나 학생 실측 난도와 같다고 표시하지 않는다.

시험지17쪽·정답해설16쪽·분석지4쪽을 기존 보호뷰어와 O/X 자기 확인에 연결한다. 숫자 답안 입력은 없다. 기존 공개120문항의 실제 본문과 대조하고, 새30문항의 학교 풀이·유일해·교과범위와 저자 풀이를 검수했다. 도형16개와 PDF37쪽은 실제 렌더를 열어 확인했다. 풀이의 연산 서술·끝점 경우, 긴 수식의 줄나눔과 도형 라벨을 교정했다. 선행 자료 선별 때 일부 검산값과 제작정보를 본 이력은 검수서에 남겼으며, 원자료 공식 답안 대조나 완전한 블라인드 검수로 표시하지 않는다.

완성PDF3종과 디지털 검수 ZIP은 기존 Drive 프로젝트 위치에 보관했다. PDF 원격 전체 읽기·크기/체크섬과 ZIP 내부215파일을 검증했고, 확인된 미사용 시안·ZIP 사본만 정리했다. 원자료·현재 PDF·도형·폰트·은행은 보존한다.

기존34회·1,310문항, 실제 학생·권한·기록, 원본 DB·잠금과 기존175개 보호객체를 보존한다. 기존 두 페이지 함수와 비공개 저장소를 확장하며 새 함수·공개 읽기 정책을 만들지 않는다. 원문·정답·풀이·이미지·기밀은 공개 Git에 넣지 않는다. 이번 회차를 포함한 공개 목록은35회·1,340문항이다.

실제 종이 출력과 학생 풀이시간·난도 동등성은 미실측이다. 운영 배포·모바일 O/X·실제 DB 저장 검수 결과는 실행 후 별도로 기록한다.
