# 원수학 중3-1 기본반 편입 대비 3회

검수한 3회를 기존 중3-1 기본반 편입 과정에 추가한다. 중2-1 대수 심화형 25문항과 중2-2 기하 심화형 25문항(경우의 수·확률 포함)이며, 모두 주관식이다. 종이에 풀고 기존 보호 뷰어에서 정답·해설을 보며 O/X로 확인한다. 중3-1은 입반할 과정 이름으로 시험 범위와 구분한다.

## 과정과 검수본

2026년 10월 과정 공지와 9월 3일 수정 범위가 근거다: https://blog.naver.com/wonmath563/224397883830. 11월 17일 직전 회차에서 실제 본문·포스터를 확인한 증빙을 사용하며 이번 회차에서 새로 재열람했다고 주장하지 않는다. 각 70분, 휴식 20분, 전체 160분이다. 다음 모집 날짜는 미확정이고 다른 원수학 과정의 시각표를 가져오지 않는다.

시험지 24쪽·정답해설 28쪽·분석지 5쪽, 총 57쪽이다. 문항별 독립풀이를 동결한 뒤 저자 답안과 대조했고 학생 SVG 22개와 교사용 수직선 1개를 검수했다. 실제 PDF 이미지 57쪽을 개별 확인한 뒤 수식 안 한글의 글꼴을 통일한 한 쪽을 별도 확인했다. 나머지 56쪽의 동일성은 이미지·PDF 바이트로 검증했다. A4·글꼴 포함·수식·표·도형·번호와 14번의 그리기 여백 70mm를 확인했다. Apple Vision은 최초 57쪽과 변경 1쪽의 판독을 보조했다.

검수자의 사전 노출과 역할을 문항별 보고서에 구분했다. 전체를 한 명이 완전히 미노출 상태로 검수했다고 주장하지 않는다. 공개 학생 조건과 일부 실제 근접 원문을 대조했으나 과거 OCR과 미확보 그림의 한계가 남는다. 저자 예상 시간은 대수 57.1분·기하 55.2분이며 학생 실측이나 완주 보장이 아니다. 실물 출력도 미측정이다. 선정에서 제외한 이전 후보와 원본 4은행·잠금은 유지한다.

## 반영 범위

공개 목록은 40회 1,590문항에서 41회 1,640문항으로 늘어난다. 기존 40회 메타데이터를 보존하고 새 회차만 중3-1 기본반 편입 과정에 연결한다. 문제·답·해설·원본 SVG/PDF와 임시 인증 자료는 공개 Git에 넣지 않는다. 비공개 서버 문항 메타데이터는 번호·분류·자가확인 방식 3필드, 학생에게 반환하는 문항 DTO는 번호·자가확인 방식 2필드만 포함한다.

기존 비공개 저장소의 이미지 485장에 새 57장을 더한다. 기존 버킷·정책과 인증·관리자·채점 로직을 유지하고 기존 보호 리더 두 개와 시험 메타데이터만 확장한다. 운영 반영 전 API v36·리더 a64/b13·총 100개 함수와 실제 학생 1명/응시 0건을 집계와 지문으로 기록했다. 개인 이름·승인번호·키는 보고서에 출력하지 않는다.

## 실행 검증과 상태

로컬 과정·회차·공식 범위 검사 21개, 채점·서버 흐름·권한·보호 저장소 검사 51개, 서버 카탈로그 검사 5개를 통과했다. 운영 API v37·리더 a70/b14에 반영하고 새 이미지 57장과 기존 485장의 실제 응답 바이트·체크섬을 대조했다. 직접 저장소 접근 72건 차단과 양 리더의 임시 업로드 경로 제거를 확인했다.

390px 모바일 사전 검수에서 실제 57쪽 이동·확대·위치 복원·O/X 50문항 저장/재입장을 통과했다. 응답 50개와 결과 상태 50개가 DB에도 일치했다. 공개 메뉴 배포 뒤 실제 사이트 검수와 자체 QA 계정·세션 종료는 별도로 확인한다. 기존 기능 기대값 5건은 직전 회차에서 변경 전 소스에도 재현한 후속 항목이며 이번 77개 통과와 구분한다. 최종 배포·검증 결과는 비공개 제작 폴더의 공개 영수증을 완료 기준으로 삼는다.
