# 원수학 공수1 기본반 1–4회 운영 연결

사용자 요청에 따라 검수된 자체 제작 4회·200문항을 원수학 공통수학1 기본반 과정에 추가한다. 새 시험 ID는 wm-common1-basic-r01~r04이며, 기존 중2-1 입학 4회 ID와 기록을 바꾸지 않는다. 회당 대수25·기하와확률25, 각90분·휴식20분 별도다.

원본 PDF와 문항·정답·이미지 바이트는 공개 Git에 넣지 않는다. 시험지·정답해설·분석지12PDF의 지문을 확인하고 보호 페이지120쪽을 별도 버전의 비공개 함수에 먼저 배포한다. 현재 운영 메인 함수의 기존19시험과 코드·adminReferences를 보존하고4개 메타데이터만 추가한다.

공개 소개는 기존18회에4회를 더해22회를 과정별로 연결한다. 다른 작업자의 별도 이든 시험은 기존 비공개 운영 상태를 그대로 보존한다. 기존 이름+승인번호·시험별권한·서명종류·만료·O/X 자가확인 규칙을 유지하며 합격판정을 만들지 않는다. 새 회차는 선생님의 기존 승인 화면에서 배정한다.

구현 검증: 과정 라우팅/시간/범위/중등기본 분리, 기존 모바일·저장회귀 검사. 운영 검증과 배포 커밋·함수버전·120쪽 해시·실제 모바일 이동/OX저장/복원·권한거부·기술확인계정중지 결과는 비공개 배포 기록에 보관한다. 실제학생 응시와 실물출력 시간실측은 별도다.

저장한 O/X를 새로고침 후 같은 판본에서 다시 열면 표시가 비던 문제를 보완했다. 현재 임시 표시가 있으면 우선 유지하고, 임시 표시가 없을 때만 서버의 같은 시험ID·판본·자가확인 결과를 복원한다. 이전 판본·자동채점·타회차 결과는 가져오지 않는다.
