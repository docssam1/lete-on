# 이든 중1 시작반 자체 제작 대비 3회

초5·초6 전 과정 대비 30문항, 100분인 3회를 기존 이든 중1 시작 과정에 추가한다. 학생은 시험지를 보고 종이에 풀이한 뒤 O/X로 확인한다. 정답 숫자를 입력하는 칸은 추가하지 않는다.

시험지 14쪽, 정답·해설 16쪽, 분석지 4쪽을 기존 비공개 보관함과 보호 reader로 제공한다. 문제·해설·그림·원고는 공개 저장소에 넣지 않는다. 공개 회차 목록에는 제목·범위·시간·문항 수·쪽수만 둔다.

30문항의 독립 풀이 대조, 12개 native 도형과 실제 PDF 34쪽 검수, 기존 1·2회와의 의미 중복 대조를 완료했다. 중복 우려 문항은 구조를 바꿔 교체하고 다시 독립 검수했다. 실제 학생 정답률이나 공식 시험과의 동급 난도를 주장하지 않는다.

기존 44회 목록·비공개 데이터·관리자 참고자료, 인증과 O/X 저장 처리, 기존 696개 Storage 객체의 매핑을 보존한다. 새 회차가 추가되면 목록은 45회·1800문항, 공유 reader 매핑은 730개가 된다.

보호 서버에는 새 34쪽과 45회 목록을 반영했다. 기존 696쪽과 새 34쪽 전체의 원격 바이트·SHA를 대조했고, 관련 없는 서버 함수 97개와 기존 인증·저장 처리는 보존했다. 임시 업로드 경로는 닫았으며 익명·미배정·서명 변조·외부 출처 요청 차단을 확인했다.

실제 배포용 26파일 산출물을 390×844 CSS 화면에서 열어 시험지 14쪽·해설 16쪽·분석지 4쪽의 좌우 이동, 이전·다음 쪽과 경계, 300% 확대를 확인했다. 별도 검수 계정으로 미확인 문항 안내, 임시 O/X의 새로고침 복원, 30문항 저장과 결과 재입장 복원을 확인했다. 실제 학생의 응시 시간이나 성취도 측정 결과는 아니다.

변경 관련 검사 26개는 통과했다. 비브라우저 전체 검사는 796개 중 794개가 통과했으며, 기존 과정-문제은행 대응 검사와 홍보 출처 표기 검사 2개 실패는 변경 전에도 존재한다. 독립 코드 검수와 실제 공개 산출물 경로 검수에서 필수 수정 사항은 없었다.

이 기록은 병합 전 검증 결과다. GitHub Pages 배포 완료와 운영 사이트의 이동·O/X 저장은 병합 후 별도로 확인한다. 나머지 모의고사 제작과 개인별 인쇄 진단·재시험·과정 안내는 전체 계획에서 계속 진행한다.
