# 원수학 중2-1 기본반 4회 세트

현재 준비된 원수학 중2-1 기본반 입학 대비 세트의 운영 상태입니다.

## 구성

- 1회부터 4회까지, 총 4세트
- 세트마다 40문항
- 중1 대수 20문항 + 중1 기하 20문항
- 중1 통계는 넣지 않음
- 대수 50분, 기하 50분
- 한 장에 네 문제씩 배치: 왼쪽 두 문제, 오른쪽 두 문제
- 시험지와 정답·해설지를 별도 파일로 제공
- 입학 준비 안내문과 합격 뒤 첫 4주 안내문 제공
- 회차별 학습 분석지 4부와 작성 예시 1부 제공
- 분석지는 총점·대수·기하, 40문항 결과, 취약 유형, 다음 공부 순서, 문항별 재풀이 기록으로 구성
- 그래프 3종과 선생님 상세 코멘트, 2주 학습 순서를 담은 확장 작성 예시 1부 제공

## 검수 결과

- 네 세트 모두 문항 번호 1~40 확인
- 네 세트 모두 원문과 풀이 연결 확인
- 네 세트 모두 별도 계산 검산 확인
- 분수·음수·단위 표기 확인
- A4 크기와 네 문제 배치 확인
- 빈 페이지와 통계 문항 없음
- 세트 사이 같은 원문 문항을 다시 쓰지 않음
- 분석지 5개 파일, 10쪽 전체 렌더링과 한글·레이아웃 확인
- 분석지의 160개 문항 분류가 검증된 공개 진단 메타데이터와 일치
- 프로그램 전체 자동 검수 312개 통과

## 점수 안내

2026년 7월 공개 안내에서 확인한 참고값은 총 40문항 중 28문항 이상, 대수 13문항 이상, 기하 12문항 이상입니다. 25문항 이상이면 풀이 과정을 함께 살펴보는 대상으로 안내되었습니다.

이 숫자는 원수학의 공개 회차를 참고한 값입니다. 우리 모의고사의 합격·불합격 판정으로 자동 사용하지 않으며, 사용자가 회차를 확인하기 전까지는 시험과 서비스 공개를 잠급니다.

## 파일 보관 위치

원본 PDF, 정답, 풀이, 검산 기록은 공개 Git 코드와 분리해 다음 위치에 둡니다.

`G:\내 드라이브\지필드메모리\highschool-selection\deliverables\wm-middle21-basic-entry-4set`

분석지는 위 폴더의 `분석지`에 둡니다. 작성용 1~4회와 실제 학생 결과가 아닌 작성 예시 1부를 구분해 제공합니다.

분석지는 `scripts/build-wm-middle21-analysis-sheets.py`로 다시 만들 수 있습니다. 문제 문장과 정답은 사용하지 않고, 검증된 단원·세부유형·난이도 정보만 읽습니다.

학생의 채점 결과가 있으면 같은 도구에 결과 JSON 파일을 넣어 개인 학습 분석 PDF 한 부를 만들 수 있습니다. 원수학 개인 분석지는 3쪽 구성을 표준으로 사용합니다. 1쪽은 전체 결과와 취약 유형, 2쪽은 40문항 진단과 재시험 기록, 3쪽은 영역·난도·세부유형 그래프와 상세 코멘트입니다. 입력하는 내용은 이름, 응시일, 1번부터 40번까지의 `정답·오답·다시 확인` 표시, 재시험 점수뿐입니다. 학생이 쓴 답, 정답, 풀이, 문제 출처는 받지 않으며 이런 항목이 들어오면 생성을 중단합니다.

개인 결과 파일은 `개인 결과 · 자동 생성`으로 표시됩니다. 빈 작성지는 `학생용 · 채점 뒤 작성`, 예시 파일은 `작성 예시 · 실제 학생 결과 아님`으로 구분합니다.

`--detailed-example` 옵션을 사용하면 영역별 정답률, 난도별 정답률, 취약 세부유형 그래프와 결과 해석·학습 상태·우선 교정 유형·2주 학습 순서를 포함한 3쪽짜리 작성 예시를 한 부 만듭니다. 그래프와 코멘트는 예시의 40문항 표시에서 다시 계산하며 임의 점수를 따로 넣지 않습니다.

공개 코드에는 문제 문장, 정답, 풀이, 원본 파일 경로를 넣지 않습니다. 학생 화면은 승인된 시험만 열고, 시험지는 짧은 시간 동안만 유효한 페이지 이미지로 전달합니다.

## 다음 작업

1. 사용자가 1회 시험지와 1회 학습 분석지를 함께 확인합니다.
2. 수정이 있으면 해당 회차만 다시 검수합니다.
3. 1회 승인 뒤에만 운영 공개 상태로 바꿉니다.
4. 이후 블랙라벨·절판 교재·황소 중등 자료에서 부족한 세부유형을 문항은행에 추가합니다.
