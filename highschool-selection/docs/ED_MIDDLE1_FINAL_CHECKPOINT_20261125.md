# 이든 중1 시작반 최종(마무리) 제작 체크포인트

2026-11-25 체크포인트 v4는 주관식 30문항 원고와 독립 수학 검수 30문항, 실제 도형 시각 검수 4개를 보관한 단계다. 대상은 대치 초등관의 초5·초6 전 과정 대비이며, 기존 1~4회와 같은 100분·O/X 자기채점 방식을 따른다.

## 검수 및 남은 제작

- 기존 120문항의 학생 조건과 비교하고, 풀이 구조가 가까운 한 문항을 교체해 다시 독립 검수했다. 현행 30문항 모두 독립 정답과 일치한다.
- 초등 풀이·범위·조건·중복·분량 검토와 문구 수정 승계를 기록했다. 편집 분류는 기본 8·응용 17·심화 5문항이다. 공식 시험과 같은 난도나 학생 전원의 100분 완주를 보증하는 분류가 아니다.
- 최소값을 묻는 문항은 달성례와 더 작은 값이 불가능한 근거를 함께 확인했다. 경우를 모두 조사한 교사용 확인표도 보존한다.
- 체크포인트의 실제 도형 시각 승인은 4/18개이며 PDF는 아직 0종이다. 나머지 도형, 시험지·해설·분석지 PDF, 실제 쪽 검수, 사이트 연결과 모바일/O/X 검수가 남아 있다. 이 최종회는 공개 목록에 추가하지 않았다.

현재 공개 12과정의 목표 60회·2,250문항 가운데 공개는 46회·1,830문항이다. 미공개 14회·420문항에는 이 최종회 원고 30문항이 포함된다. 별도 진단 인쇄·재시험·과정 준비 및 수업 안내도 전체 작업 범위에 남아 있다.

## 원본 보관과 재개

보관 경로는 `코딩관련/지필드메모리/highschool-selection/deliverables/all-academies`의 기존 폴더 안이다. 폴더와 기존 파일 ID를 유지한다. 최종회 원고·교사용 답안·도형·검수 입력은 비공개 Drive에 보관한다.

체크포인트 ZIP 83항목의 전체 바이트, ZIP CRC, 항목별 SHA256을 원격 읽기로 확인했다. 원격 검증 후 미사용 로컬 ZIP 전송 사본 하나를 정리했다. 현행 원고·폰트·도형·검수 입력과 활성 Python 의존성은 보존한다. 이 체크포인트는 완성 시험지 PDF나 공개 회차를 뜻하지 않는다.

새 유료 모델 API 호출은 0회이며 원본 문제은행의 잠금은 유지한다. 다음 작업자는 기존 운영 인수인계와 같은 ID의 제작 대장을 읽고, 도형·PDF 검수 결과부터 이어서 기록한다.
