배포 때 이 문서(`*.md`)와 `*.mjs`는 지운다(`.github/workflows/deploy-pages.yml`). 설계서 원본은 원장 Mac의 `~/Documents/소마레이/레이키즈-A1-3-설계.md`.

## 정한 것 (원장 2026-11-12)
- 주소 `lete-on.gfieldacademy.net/sm/`. 원생만(DEMO 없음). 학부모가 필즈 더 클래식과 같은 방법(승인번호 + 아이 이름, `fields-auth`)으로 로그인.
- 들어가는 권한: 관리자(DOCSSAM) 또는 승인 관리(`fields-classic/admin.html`)에서 **「레이키즈」** 권한을 켠 승인번호.
  서버 `supabase/functions/fields-approval-admin`의 `PRODUCT_IDS`에도 넣었다 → **함수 다시 배포 전에는 권한을 켜도 저장되지 않는다.**
- 5세용: 지시는 독쌤 음성(기기 음성), 큰 단추(72px 이상·주요 104px), 틀리면 결과 장면 + 격려, 맞으면 팡팡(색종이·별·도장·소리).
- 무게 단원은 필즈 2권 3D 저울 구성을 가져온다. 무게 지도는 「가장 가벼운 것(블록)에 1 쓰기」.
- 원본 순서 그대로. 원본 스캔·정답은 저장소에 두지 않는다. 그림은 코드가 다시 그린다.

## 2단원 1차시 단계 (원본 쪽)
1. 30쪽 시소 타기 — 시소를 태워 보고 더 무거운 친구 고르기(곰돌이)
2. 31쪽 저울 놀이(게임) — 화살판 2번 → 곰 2마리, 독쌤도 2번, 기울 쪽 예상 → 저울 풀기, 3판
3. 32쪽 무거운/가벼운 물건 — 컵>모자, 가방>컵
4. 34쪽 아빠곰 1 = 아기곰 3 — 하나씩 올려 수평, "같아요"
5. 35쪽 1 쓰기 — 아기곰과 큐브 중 가벼운 것 → 큐브에 1 쓰기
6. 35쪽 공 = 큐브 7, 원뿔 = 큐브 5 — 큐브를 올려 수평 → 세기(틀리면 같이 세기)
7. 36쪽 아빠곰 = 큐브 12

넣지 않은 것: 33쪽(정답이 하나로 안 정해짐 — 정답지 확인 필요), 37쪽 활동판(실물 무게라 수치 없음 — 원장이 가상 무게를 정하면 넣음).
가정한 값: 엄마곰 8(원본에 없음. 일반 곰돌이 교구 기준). 화살판 칸(아빠·엄마·아기 1/3씩)도 원본에 그림이 없어 정한 값.
